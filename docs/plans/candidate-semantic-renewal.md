# 후보 의미·검색 문서 전수 개선 실행 계획

2026-10-18 · H 단독+F2 운영 기준선 유지 · 조건부 전수 확대

전체18,250 CID의 기존 원문·조건·효과·RID·12101개 binding을 보존하는 편집
정본을 만든다. 의미와 검색 단서, 대상·행동·관계 및 적용 조건을 분리해 보강한다.
Gemini는 호출하지 않는다. 공통 positive 풀 전체, 슬롯당 BM25F1회·로컬
임베딩/cosine1회, RRF10, CID당 actual RID 및 top8을 고정한다. 미판정/틀린
결과에 감점을 주지 않는다. CURRENT와 설치 선택 파일은 자격 통과 전 유지한다.

1. **원본·보호·정본.** 운영 H-F2 세대를 검증해 Git 소유의 canonical 편집
   정본으로 무손실 export하고 full corpus hash·CID/RID·조건·효과를 검증한다.
   작업 전 dirty·CURRENT·설치 config를 봉인한다. 검증 후 커밋한다.
2. **보강 계약·컴파일러.** 출처 인용을 가진 요약·대상/행동/관계·검색 단서·
   슬롯 제안을 정의한다. 원래 D 단서/순서를 보존하고 새 설명의 실제 BM25F/
   임베딩 입력 포함을 검사한다. native 권한은 생성하지 않는다. 검증·커밋한다.
3. **96개 파일럿·평가 동결.** option48/profile24/bundle12/mechanism6/
   concept3/diagnostic3을 선택한다. 기존12개 graph 사례와 기존 적합 후보,
   고정 seed의 표본을 포함한다. 671판정·126적합 연결·67개 H query와 기존
   신규4요청/8목표 자료를 재사용한다. 목록·입력·기준을 점수 전에 봉인·커밋한다.
4. **Luna max 보강·대조 검토.** Luna에 원문과 중립 slot catalog만 제공한다.
   query·정답·순위는 제공하지 않는다. 근거 없는 의미 변경은 보류한다.
   출처/구조 검사는 전수 수행하고 parent가 새 표현과 원문 의미를 대조한다.
   검증된 파일럿 보강을 커밋한다.
5. **전체 경쟁 A/B/C.** A=설치 기준선, B=기존 사실을 사용한 개선 컴파일러,
   C=B+검토한 보강이다. 모든 arm에서18,180 positive CID 전체의 전역 통계를
   재계산하고 동일 query/벡터 공간·F2 가중치·RRF/top8을 적용한다. 새 문서만
   로컬 임베딩하며 검증 계약이 같은 기존 실행 증거는 재사용한다. 저장된 모든
   전체 순위와 알려진 적합 연결을 독립 재계산한다. 결과·판정을 커밋한다.
6. **통과 시 전수 배치.** 16–32개로 시작하고 긴 profile/bundle은 축소한다.
   재개 가능한 체크포인트·검토 상태·실패 목록·원문 계보를 남긴다. 배치별
   검증·커밋한다. 모든 CID를 처리하며 그대로 유지와 보류도 구분해 기록한다.
7. **전수 무결성·품질.** CID/RID·출처·조건·효과·참조·native 검토 계약을
   검사한다. 의미가 바뀐 대상에 과거 판정을 자동 재결속하지 않는다. 전체 풀
   검색의 Recall@8/목표 회수율, strata별 손익, 미판정 범위를 보고·커밋한다.
8. **운영 세대 설치.** 최종 기준을 통과한 새 H-F2/native 세대를 만들고,
   네트워크/연구 경로를 차단한 실제 기본 스킬 실행 후 설치 선택을 갱신한다.
   native CURRENT는 유지한다. 이전 세대는 복구·기존 receipt용으로 보존한다.

## 사전 통과 기준

- 주 지표 분모: 기존 판정의 명시적 적합 goal/CID/RID126연결, 지원 목표40개.
  27개 미판정 목표 및 다른 결과는 negative나 실패로 세지 않는다.
- A를 설치된 H-only+F2로 직접 재현한다. 기대값은55/126·28/40이며 불일치하면
  원인을 확인하고 평가를 중단한다. 예전 최고59/30을 A로 대체하지 않는다.
- C의 Recall@8은 A보다 **5%p 이상**, 즉 적합 최소62/126이어야 한다.
  목표 Hit@8은 A 이상이며 C는 B보다 적합 연결을 최소1개 더 회수해야 한다.
  내용 보강의 추가 이득 없이 전수 보강으로 확대하지 않는다.
- 개별 목표의 완벽한 무회귀, precision, 부적합 개수는 통과 조건이 아니다.
  새 회수/누락과 데이터 변경의 영향은 모두 기록한다.
- source/RID 누락, 의미·조건·효과의 무근거 변경, 벡터/평가 증거 오류,
  추가 query/검색 lane, 원격 fallback은 허용하지 않는다.
- 96개 파일럿의 검색 대상만 좁혀 평가하지 않는다. 조건·가중치·분모를 결과를
  본 뒤 변경하지 않는다. 미달 시6–8단계는 실행하지 않고 현재 운영을 유지한다.

Luna 파일럿 결과를 이용해 묶음당 입력/출력량과 전수 비용을 추정한다. 파일럿
검토와 데이터/컴파일러 효과를 먼저 확인하며, 전수 처리 완료를 미리 주장하지 않는다.
