## 1. 결론과 조사 방법

코스프레는 하나의 의복 장르가 아니라 **원작과의 관계, 형상, 착용 방식, 재료와 표면, 분장, 소품, 인체·객체 관계, 장면과 촬영**이 교차하는 분야다. `cosplay` 하나에 세부 의상을 묶거나 모든 용어에 이미지를 하나씩 배정하면 비슷한 뜻의 중복, 비가시적 제작 과정의 시각화, 인물·장비의 임의 추가가 생긴다. 원문의 각 표 행을 아래 전수 목록에 보존하되, 한 행 속 개념은 필요할 때 따로 분해한다. 레코드 생산 여부는 기존 원본과 의미 단위까지 대조한 후 결정한다.

## 4. 제안하는 데이터 설계

### 4.1 어휘 목록과 시각 의미를 분리

- 원문 행 ID `COS-T01-001` … `COS-T17-019`를 부여하고, 다중 개념은 `a/b/...`로 분리한다. 행당 원문 표기, 개념 정규형, 한·영·일 별칭, 문화/지역, 개념 종류, 의미 설명, 출처·근거 범위·신뢰도, 시각성, 기존 후보 연결, 처리 상태를 기록한다. 메모에 대화의 18개 절과 표 행 번호를 남긴다.
- 후보의 핵심은 이름이 아니라 **완전한 선택 가능한 시각 명제**다. 객체와 소유자, 수량·위치·연속/분리·겹침·접점·가시성, 해당하면 방향·상태·시간적 순간을 보존한다. 장르 또는 한 단어에 여러 세계관과 의상을 암묵적으로 연결하지 않는다.
- 뷰는 원본의 `/content/en`, `/content/ko` 등의 실제 quote·record hash를 보존한다. 번역/검색 동의어는 의미를 넓히지 않는다. 원본으로부터 도출할 수 없는 프레임 밖 인물·감정·성적 맥락·효과를 뷰에 삽입하지 않는다.
- 실제 schema·validator가 지원하는 필드만 사용한다. 별도 연구 원장에 필요한 메타데이터가 있더라도 런타임 포맷을 임의로 확장하지 않는다. 신규 slot은 필요한 근거와 전체 영향 확인 전 보류한다.

- **D07 pose/photo framing**: 자세, 카메라 높이, 크롭, 렌즈 원근, 조명의 독립 잠금과 충돌 확인.
- **D08 착용품/신체**: 동물 귀 파츠와 신체 일부, 가면과 실제 얼굴, 프로스테틱과 피부 표현을 분리. 사진에서 보이지 않는 착용 경계는 확정하지 않음.
- **D09 adult/style/content rating**: 성인임이 명시된 조건, 의복 종류, 연출의 관능성, 콘텐츠 등급은 각기 다른 주장이다. 사람의 나이·의도는 외형으로 확정하지 않는다.

검색 질의는 한국어·영어·해당 일본어 별칭을 지원하되 원문 전체 명제와 관계를 보존한다. 별칭이 다의적이면 개념별 뷰를 따로 두고 무관한 단어를 무조건 확장하지 않는다. 뷰 생성 후 source hash, pointer, quote 및 번역의 관계·한정어가 일치하는지 검사한다.

## 5. 실행 순서와 완료 조건

1. **인벤토리 동결:** 원문 356개 행과 10개 예시를 행 ID로 옮기고 다중 개념을 쪼갠다. 비시각 항목에도 `context-only`, `process-only`, `diagnostic`, `reuse`, `candidate`, `hold` 중 적용 상태와 이유를 남긴다. 각 행이 최소 한 처리 상태를 갖고 중복·누락을 점검한다. 별칭 개수나 행 수를 후보 목표로 삼지 않는다.
2. **원문·근거 검증:** 박물관/전문 제작자/촬영 원자료를 우선한다. 각 구조의 정의와 작성한 선택적 명제를 구분하고, 자료가 직접 증명한 내용·저자의 조합·추정을 따로 표시한다. 모호한 일본어 팬덤 용어, 상표, 시대·문화 의상, 성인 스타일은 개별 출처와 용례를 추가 확보한다. 이 보고서가 직접 검증하지 않은 항목은 출처 확인 전 미검증 상태로 둔다.
3. **중복·공백 조사:** manifest를 기준으로 각 개념의 원본 전문·aliases·조건·effects·bindings·실현과 view를 확인한다. 완전히 같은 의미는 재사용, 기존 후보를 약화시키지 않는 새 관계만 별도 작성, 차이를 입증하지 못하면 보류. 문자열 검색 0건은 결핍 판정이 아니다. 교복·메이드·웨이트리스·수도복과 진행 중 변경을 우선 대조한다.
4. **영역별 분할 작성:** (A) 의복·표면·신발·갑옷, (B) 가발·분장·파츠, (C) 포즈·소품·다인 관계, (D) 장르·성인·호러·문화 맥락과 촬영. 각 영역마다 완전한 한영 선택지와 해당되는 선택적 binding, source-grounded context view, 진단을 독립 검토한다. 별개의 owner·관계를 조합한 큰 문장은 요청을 불필요하게 제한하지 않도록 더 작은 완결 명제와 비교한다.
5. **정적 검증:** 관련 validator와 테스트로 ID 고유성, 스키마, 양방향 후보–binding 참조, 슬롯 존재, 진단의 positive pool 유입 방지, 한영 의미·수량·owner·관계·조건, quote/pointer/hash, manifest 중복, 원본과 뷰의 coverage를 검사한다. 변형된 source/view 중 하나만 갱신된 경우 실패시킨다.
6. **검색 검증:** 작성자가 만든 개발 질의와 별도로 봉인된 독립 holdout을 만든다. 영역·언어·별칭별 positive, 유사어 혼동, 비관련 query, 제약·제외가 담긴 query를 포함한다. 예: `가터벨트의 클립이 스타킹 윗단에 닿음` 대 `허벅지 밴드만`, `오프숄더` 대 `어깨 구멍만`, `발도` 대 `칼을 세워 듦`, `latex costume` 대 `liquid latex makeup`, `아와세 2인` 대 `코스카드`. 정확한 기대 후보는 독립 검토자가 사전 지정한다. 한영 검색 노출과 top-k/MRR, 구분 실패, 비관련 회귀를 기존 릴리스와 동일 설정으로 보고한다. 점수 목표는 데이터 확정 전에 정하고 회귀 원인을 개별 검토한다.
7. **런타임 검증:** 정식 설치 절차에 따라 소스·뷰 해시, 모델 공간, 인덱스 generation 및 선택된 H-F2 릴리스가 일치하는지 각 환경에서 확인한다. 색인 구축 성공, 검색 노출, 후보 적격성·채택은 각각 기록한다. source만 추가하고 설치가 완료됐다고 주장하지 않는다.
8. **이미지 검증:** 별도 승인된 이미지 생성 시에만 의상 연결, 표면, 헤어, 소품 접점, 2인 관계, 촬영 구도를 대표하는 테스트를 사전 등록한다. 동일 요청·시드/조건에서 baseline과 신규 후보 채택을 비교하고, 최종 프롬프트와 실제 채택 ID를 기록한다. 평가자는 가급적 블라인드로 전체 관계를 확인한다. 가림·프레임 밖은 `unobservable`, 실수는 `fail`, 조건 충족만 `pass`. 반복 샘플과 실패를 모두 보고하고 생성 성공을 개선의 증거로 삼지 않는다.
9. **수용·인계:** 사용자의 원래 의도와 보존 잠금이 유지되는지 확인하고, 증거가 있는 범위만 수용한다. 데이터 커밋이나 인덱스 배포는 별도 실행 작업이다. 진행 중인 다른 변경을 보존하며 범위·검증 결과·미해결 항목을 인계한다.

### 핵심 확인 항목

- 모든 원문 행이 추적되고 비시각 항목도 명시적으로 처리됐는가?
- 기존 자료를 의미와 조건까지 비교해 중복 여부를 판단했는가?
- 원본 명제와 뷰가 주체·접점·가시성·수량·제외를 보존하는가?
- 통과한 것은 정적 무결성, 검색, 실제 채택, 이미지 관찰 중 정확히 무엇인가?
- 성인, 손상, 문화·직업·원작 관계를 외형에서 임의로 만들어내지 않았는가?

## 6. 자료의 한계

이 문서의 356개 행 목록은 Chrome에 표시된 원문 표를 근거로 한다. 같은 행의 연결 표기가 개념적 동의어인지는 항목별로 다르다. 박물관·촬영·제작 출처는 위에서 연결한 구체 주장과 제작 사례에 대한 근거이지, 모든 용어의 보편적 정의나 각 이미지 생성 모델의 성능 근거가 아니다. 현재 파일 표본 문자열 검색은 retrieval·의미 중복·설치된 인덱스를 평가하지 않았다. 데이터 생성, 색인 설치, 검색 실험, 이미지 생성 및 인과적 품질 평가는 수행하지 않았다.
