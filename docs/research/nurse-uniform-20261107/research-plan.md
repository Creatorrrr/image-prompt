## 2. 원자료에서 확인한 중요한 차이

1. **현대 의료복은 복수의 형태다.** [FOLK 의료복 분류와 케이시 설명](https://www.folk.co.jp/item/medical/casey.aspx)은 스크럽·바지·원피스·튜닉·케이시 등을 별도 분류한다. [Cherokee CK4728](https://cherokeeuniforms.com/collections/womens-navy-blue-scrubs/products/womens-mock-wrap-princess-seam-solid-scrub-top-ck4728cl)은 모크 랩 V넥, 프린세스 절개, 앞 패치 포켓, 기구 고리, 요크와 옆트임을 한 실제 상품에 조합한다. 따라서 핏·절개선이나 드레스만으로 성인 의상인지 판정하지 않는다. 케이시의 일본어 별칭은 원문 검색 경로에 두고, 구체 여밈은 확인된 형태로만 서술한다.
2. **보호 장비와 기본 복장은 계층이 다르다.** [CDC 치과 감염관리 설명](https://www.cdc.gov/dental-infection-control/hcp/dental-ipc-faqs/personal-protective-equipment.html)은 일반 스크럽을 PPE로 보지 않으며, 장갑·마스크·보호복을 별도 설명한다. 백의도 모든 경우 PPE 또는 비-PPE로 일반화하지 말고 용도·사양별로 다룬다. 시각 후보는 '가운이 스크럽 위에 놓임'을 기술하고 실제 보호 성능은 추론하지 않는다.
3. **역사는 조합이 아니라 특정 표본에 연결한다.** [Mütter Museum의 1925년 Vera Sweet 제복](https://muttermuseum.org/stories/posts/note-nursing-uniform-brief-history/)은 청백 줄무늬 면 드레스, 분리형 칼라·커프스·보닛, 2부 앞치마 및 울 코트를 설명한다. [London Museum의 1914–18 실물](https://www.londonmuseum.org.uk/collections/v/object-86267/uniform-womans-uniform/)은 청색 chambray 긴소매 드레스의 중앙 히든 버튼, 흰 면 앞치마, 캡 및 표장을 기록한다. 둘은 별도 표본이며 어느 하나가 전 시대·국가의 보편형은 아니다. 현재 아이디어의 '줄무늬+탈착 칼라+교차끈+케이프'는 서로 다른 자료의 창작 조합일 수 있다.
4. **모자 이름·기능·정체성을 분리한다.** [간호사학 전시](https://cnh.omeka.net/exhibits/show/uniforming/caps)는 winged·cupcake와 일부 학교의 띠를 설명한다. 이 출처는 기원에 대한 특정 견해를 제시하므로 논쟁적인 단일 기원이나 띠=보편적 계급 표식으로 저장하지 않는다. 전통 캡, 묶는 scrub cap, 둥글게 모인 bouffant, 장식용 mini cap은 별개다.
5. **성인 패션도 실제 제품별로 다르다.** [Catalyst Latex](https://www.catalystlatex.com/product-page/nurse-set)는 V넥·A라인 치마·뒤 지퍼 드레스에 별도 가슴받이 앞치마와 선택 모자를 판다. [Libidex](https://libidex.com/sister-uniform.html)는 코르셋 내장 드레스·앞치마·캡을 조합한다. 이 두 사례는 성인 패션의 가능한 구성이며 '라텍스=몸에 밀착된 미니+앞지퍼'라는 고정 규칙이 아니다. 광택은 관찰 가능한 외관, 라텍스/PVC는 출처나 명시 요청이 있는 재질 속성으로 분리한다.
6. **호러의 상태와 작품 식별은 별도다.** [Smiffys 좀비 의상](https://www.smiffys.com/products/zombie-nurse-costume)은 헤드피스·마스크·라텍스 상처 파츠가 있는 드레스와 혈흔 프린트의 구성을 기술한다. 얼룩·튐·번짐·입체 파츠는 별도 속성이다. [Gecco Bubble Head Nurse](https://gecco.co.jp/en/product/bubble-head-nurse/)와 [Dead by Daylight의 The Nurse](https://deadbydaylight.com/game/chapters/the-last-breath/)는 각각 특정 작품의 고유 식별자다. 이름을 일반 붕대 간호사와 동의어로 쓰지 않는다.
7. **동음이의와 표장.** [NCT](https://www.nct.org.uk/information/pregnancy/wellbeing-and-lifestyle-pregnancy/maternity-bras-and-nursing-bras-what-you-need-to-know)의 nursing bra는 수유용 브라다. nursing dress도 수유 의복과 검색이 혼동될 수 있어 문맥을 확인한다. [ICRC](https://www.icrc.org/en/law-and-policy/use-emblems)는 적십자 표장의 식별·보호 목적과 사용을 설명한다. 의료 상징 일반이나 직업 자격으로 치환하지 말고 명시된 시각 요소와 맥락을 보존한다.

## 6. 데이터 설계와 배치 계획

### 6.1 한 행도 빠뜨리지 않는 인벤토리

1. 원 대화의 각 표 행에 `source_section`, 순서, 원문 한글·영어·일본어 label, 설명, 원문 locator, 원문 기준 fingerprint를 부여한다. 같은 행의 여러 개념은 별도 concept ID로 쪼개되 원래 행과 연결한다. 표제/대조/대표 조합도 별도 타입으로 보존한다.
2. 각 concept에 `visual_object | attribute | relation | pose | scene | role_context | ambiguity | historical_claim | IP | composite`를 부여한다. 공통 용어의 한글/영문/일문 표현과 문맥의 중의성은 같은 alias 배열로 무비판적으로 합치지 않는다.
3. **각 행별 disposition**은 `reuse_exact`, `reuse_partial_plus_new`, `new_candidate`, `context_only`, `diagnostic_only`, `hold_needs_evidence` 중 하나 이상이며, 정확한 기존 CID·출처 필드·차이·근거를 기록한다. 미검토/근거 부족은 별도 상태로 남긴다. 모든 행이 어떤 후보 하나를 의무적으로 만들 필요는 없다.
4. 후보 조사는 manifest에 실제 등록된 전체 candidate/binding/retrieval view를 대상으로 원문 검색 + 한영일 변형 검색 + 실제 검색 결과를 결합한다. 단순 문자열 미발견은 부재 증거가 아니다. 같은 후보라도 정의, owner, 수량, 관계, source application contract, 조건, effects, binding 및 의존성의 완전 동등성을 대조한다.

### 6.2 세 계층을 분리한 예상 파일과 계약

- 시각 의미 레지스트리: 예 `assets/photo_nurse_uniform_semantics_20261107.json`. 출처를 확인한 용어·경계·원문 행 맵과 완전한 한영 선택 명제, 명시적 관찰 게이트, 근거 범위, 대조 결과를 기록한다. 진단과 고유명은 별도 타입이다. 미래 구현 시 날짜·schema는 해당 시점 규약으로 정한다.
- 후보와 슬롯: 예 `photo_candidate_nurse_uniform_*.json`, `photo_candidate_nurse_uniform_bindings_*.json`. 프로젝트의 실제 v3 스키마와 현재 전체 manifest/ID 생성 규약을 먼저 확인한다. 가능한 선택지를 완전한 원문 단위로 두고 단일 소유자·부위·양끝점·수량·효과·조건·의존성을 보존한다. 슬롯은 검색/표시 태그이며 소유권, 효과 허가, native role 적격성의 증거가 아니다. 신규 binding은 별도 근거가 있을 때만 제안한다.
- 연구 맥락 뷰: 원 대화 정의·근거·출처 범위·다의성·CID 대조를 저장. 텍스트는 출처 pointer/hash를 묶고 **context-only**, `native_approval: false`로 표시한다. 기록 내용은 자동 프롬프트 지시가 아니다.
- 검색용 retrieval view: 해당 후보의 `whole`과 근거가 있는 `context`를 현행 `photo-candidate-retrieval-views/v1` 및 인덱서 계약에 맞춰 따로 작성. 원문 전체와 정확한 source quote/pointer/record hash를 보존한다. 새 역할, 빠진 파츠, 노출/폭력, 가상의 사실을 뷰에서 덧붙이지 않는다. 진단·금지 예시는 양성 검색 본문에 넣지 않는다.
- 실물 사료·제조사 자료는 정의/실물 사실을 뒷받침하며, 저자가 만든 특정 포즈/조명/복합 구도는 `authored`로 표시한다. 제품 이미지의 재사용 허가와 텍스트 조사 근거는 별도다.

### 6.3 진행 순서

1. **기준 고정**: 작업 시점 Git 상태와 다른 작업을 기록하고 현재 source manifest, 검색 release, 모델·인덱스 해시를 확인한다. 동시 변경과 겹치는 파일을 덮어쓰지 않는다.
2. **전 행 재고 및 출처 확인**: 대화 전체를 행별 목록화하고, 세부 용어/지역/시대/실물의 근거를 평가한다. 현재 조사에서 직접 확인하지 않은 원문 주장·희귀 용어는 추가 자료 확인 전 `hold_needs_evidence`.
3. **기존 후보 대조**: 전역 후보 검색 및 원본 review로 exact/partial/none 판정. 각 결과에는 CID, 버전, 전체 문장 및 조건·효과 비교와 근거를 남긴다.
4. **시각 선택지·진단 작성**: N01–N30을 시작점으로 결손만 보충한다. modern/historical/PPE/adult/horror/pose/context를 모두 다루되 서로의 속성을 자동 주입하지 않는다. 원본 보존, 한영 동등성, 가려진 연결의 판정, 사람과 소품 소유자를 검토한다.
5. **모듈과 뷰 작성**: 프로젝트 검증기를 통과하도록 registry, candidates, bindings, 연구 맥락 뷰, positive retrieval views를 분리한다. 기존 레코드 수정이 더 맞다면 전체 출처와 의존성을 검토하고 영향 범위를 고정한다.
6. **통합**: 실제 working manifest에 필요한 모듈을 병합하고 hash/중복/참조를 검증한다. 선택된 sealed release의 build 지침과 provider·모델·차원을 확인해 별도 스테이징, 전체 소스 및 벡터 커버리지 검증 후 활성화 여부를 판단한다. working source 변경만으로 설치 완료를 주장하지 않는다.
7. **검색·적용·픽셀**: 7절을 순서대로 통과시킨다. 현존 후보와 비교해 개선이 없는 경우 신규안을 줄이거나 보류한다.

## 7. 평가와 수용 기준

- **커버리지**: 원문 표 행 수와 inventory의 고유 source-row 수가 일치하고 모든 row에 disposition·판정 이유가 있다. 다중 개념 행은 concept 분리를 검증한다. 보류 건수와 근거 없는 항목을 따로 보고한다. 전 행 독립 사실 검증이 되기 전에는 그렇게 주장하지 않는다.
- **무결성**: JSON schema/ID 충돌/참조/quote/hash/원문 전체 보존/한영 의미/진단의 양성 검색 제외/manifest closure 검사를 실시한다. 기존 후보·바인딩의 ID와 참조를 보존한다.
- **검색**: 개발 질의와 작성자가 미리 보지 못한 한·영·일 holdout을 분리한다. 사례: `ナース服 ケーシー 斜め留め`, '앞지퍼 스크럽', '접힌 간호캡과 부팡 차이', '1925 줄무늬 드레스 탈착 칼라', 'adult latex nurse apron rear zip', '붕대 얼굴 간호사 낡은 밑단', '청진기를 손에 든 간호복', 'nursing bra 수유', 'surgical theatre clothes', 'white stockings vs compression'. 각 질의에 의도 대상, 허용 가능한 기존/신규 CID, 피해야 할 오검색, 실제 top-k/rank와 실패 이유를 기록한다. 개발 질의 점수는 독립 holdout 결과가 아니다.
- **회귀**: 일반 간호복에 성인·상처·주사기·특정 성별/인물을 자동 추가하지 않는 대조와, 반대로 성인/호러를 명시한 요청이 밋밋한 실무복으로 치환되지 않는 대조를 함께 둔다. 메이드/웨이트리스/수녀/교복, 의료 드라마, 유사 캡·앞치마·주머니·복식 일반 질의의 baseline과 비교한다. 모호한 nurse/nursing, 단색/압박/소재/표장·IP 경계도 검사한다.
- **실행**: source 등록→설치된 release에서 검색 노출→실제 원본 조건·효과 심사→선택/거부→제출된 프롬프트→저장된 이미지 관찰→사용자 수용을 별도 로그로 남긴다. `native_approval: false`와 검색 성공은 role/owner/effect 적격성이나 사용 허가가 아니다.
- **이미지/인과**: 사용자가 이후 이미지 검증을 승인하거나 요청한 범위에서 공통 참조·요청·도구 조건을 고정하고 기존 baseline 대 신규 후보 적용군을 독립 비교한다. 시각 게이트를 선고정해 전체 파츠·연결을 판정하고 프레임 밖/가림은 `UNOBSERVABLE_NOT_PASS`, 호출 차단은 `BLOCKED_UNSCORED`로 기록한다. 이미지 생성 한 장이나 검색 순위만으로 품질 향상·원인·사용자 수용을 주장하지 않는다.

## 8. 남은 불확실성과 제안 우선순위

- **P0**: 원문 전 행 inventory와 전역 후보 대조, 현대복/역사/보호복의 구분, 분리 의복·소품 연결, 진단/positive 계층 분리.
- **P1**: 성인 의상과 호러의 요청별 선택지, 한영일 검색 및 상호 오염 회귀, 포즈의 손·지지·시선 연결.
- **P2**: 지역·기관·연도별 사료 보강, 세부 섬유/마감의 입증 가능성, 다국어 별칭 확장, 작품별 버전 범위.
- 문맥 및 용어가 넓고 각 제품·사료가 보여주는 사례는 제한적이다. 원 대화의 각 행을 외부 1차 출처로 개별 교차검증하지 않았으며, 전역 후보 exact 매칭·검색/랭킹·실행·이미지 테스트도 아직 수행하지 않았다. 이러한 공백은 구현 단계에서 명시적으로 해소하거나 보류한다.
