프로필 정의는 앞면 또는 옆면에서 두 판이 겹치는 구조를 허용하지만 필수 영어 증거는 앞면만 받아들였다. 실제 소비자는 올바른 옆면 겹침 증거를 거절했다. 원래 한국어 성분은 위치가 중립적이므로 한국어 전체가 앞면으로 제한됐다고 주장하지 않는다.

성분 대안과 영어 증거의 배열 두 곳에 옆면 대안을 덧붙였다. 기존 영어·한국어 앞면/중립 표현을 삭제하지 않았고, 끈·단추·스냅·버클 선택, 다섯 필수 그룹·게이트, 프린트/트임/스카프와의 구분, 증거 길이 기준을 유지했다. 옆면을 가리는 새로운 촬영 조건이나 노출·자세·의복을 추가하지 않았다.

## 실제 전후 결과

옆면 겹침과 기존 앞면 대조를 같은 원본 네 계약으로 정상 공개 CLI에 전후 실행했다. 두 AFTER 모두 성공했고, 각 팩에서 팩 ID와 두 의도한 대안 배열만 바뀌었다. 29개 후보 모음의 ID·순서·개수·기록 전체와 코어는 동일했다.

두 최종 구성물도 실제 전체 구성 감사 CLI에서 종료 코드 0, 실패 0이다. 원래 본문·성인·단추·허리·실제 패널과 아래판·스튜디오 3/4 시점을 그대로 보존했다. 앞면 증거는 전후 모두 통과하고, 같은 옆면 증거는 이전의 시각 증거 감사에서 앞면 앵커가 없어 실패하다가 수정 후 통과한다. 각 전체 감사의 비치명적 커버리지 경고 3개는 공개 결과에 남겼다.
