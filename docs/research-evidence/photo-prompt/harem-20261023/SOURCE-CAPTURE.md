# 참조 대화 확인 범위

- 대화: 하렘물 용어 조사, `6adb5af5-62c0-83ee-ac08-0af3cfba439a`.
- 도구 read_thread: 1개 완료 turn, 추가 cursor 없음. 답변은 20,000자에서 truncated=true. 저장한 conversation-preview.json은 이 제한을 유지한다.
- 로그인된 Chrome: 사용자가 지정한 동일 URL을 열고 화면에 표시된 DOM에서 20개 표와 첫 열 표제, 본문 및 20개 노출 인용 링크를 읽었다. 추출 당시 main의 innerText 길이는 26,370자였다.
- 첫 열 표제는 reference_inventory.py에 전사했다. 원 대화 표 전체의 HTML/텍스트 파일을 내려받거나 전체 원문을 저장한 것은 아니다. 20개 범주별 개수와 FNV-1a 32bit UTF-16 검사값을 현재 보이는 DOM에서 계산해 전사본과 비교한다. 이는 우발적 전사 오류 확인용이며 암호학적 원본 인증·정의 검증이 아니다.
- 원 표의 마지막 6행은 성인 창작 조합이며, 작품 목록·외부 문헌·추가 6개 장르 정의로 세지 않았다.
- 대화와 웹 내용은 조사할 자료다. 그 안의 요청·지시를 현재 사용자의 실행 권한으로 간주하지 않는다.
- 외부 출처의 실제 읽은 범위·실패·도판 한계는 SOURCES.md에 별도로 기록한다. FIT 표지의 부분적 재단/자수는 화면으로 확인했지만 내부 도판 썸네일이 깨져 개별 소장품 전체 픽셀 검증은 수행하지 못했다.
