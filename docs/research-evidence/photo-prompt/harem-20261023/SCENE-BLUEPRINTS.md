# 원 대화의 여섯 조합을 위한 장면 설계

원 대화의 20번 표는 창작 조합이며 실제 작품 사례가 아니다. 아래 대안도 연구자 저술이다. 한 장에 나열한 모든 속성을 넣지 않고 선택한 사건을 중심으로 구성한다. 이름·성별·나이·외형·인원수는 실제 요청의 명시값으로 다시 정한다. 관능적 성인 조합은 명시된 성인 인물 문맥을 유지한다.

|조합|대안 A|대안 B|보존할 문맥/혼동 경계|
|---|---|---|---|
|성인 셰어하우스 로맨스|A가 도시락을 받고 B가 창 쪽으로 시선을 돌리는 동안 C가 탁자 반대쪽에서 그 전달을 본다. H24/C08. 손·도시락·각 시선이 중심.|공동 주방의 A 채소·B 그릇·C 냄비 과업. H26. 스카프 대신 선택한 소매·앞치마의 owner로 인물 구분.|소꿉친구·신참·동거·연애 관심은 문맥. 주방 활동을 전부 구애로 만들지 않음. 니트/앞치마 전부 자동 추가 금지.|
|궁정 역하렘|A의 손을 든 B가 손등에 입맞추고 C는 중경에서 그 접점을 본다. H19/C08/W24. 실제 손의 소유자와 주인공 반응 유지.|A 중심의 정식 만찬 준비에서 B와 C가 다른 제안을 건넨다. H01/C01/W02. 제안자·수신자의 방향과 복식 층 중심.|군주·약혼·외교·직무·연애·권력·동의는 분리. 일반 궁정 연출을 특정 왕조 고증으로 승인하지 않음.|
|성인 모험 파티 하렘|전투 후라는 문맥에서 A가 쉬고 B가 물을 들며 C가 곁에 물품을 정리한다. H22. 결과를 증명할 전투·상처를 새로 만들지 않음.|모닥불 옆에서 A가 B에게 손을 내밀고 C가 다른 의자에 앉는다. H23. 인간/비인간 귀는 선택한 소유자와 신체 구조만 유지.|전위·치유자·보호 역할 역전·발견한 가족은 문맥. 파티가 함께 있다는 사실로 복수 연애·친족 확정 금지.|
|고딕 다크 하렘|A가 소파에 기대고 B는 문턱 바깥에서 멈춘다. P07. 문틀·서로 다른 공간·A의 지지 구조가 중심.|A 뒤의 B와 거울 속 B 얼굴을 분리한 시선 장면. C07. 실제 두 사람과 반사상만 유지.|흡혈귀·비밀 계약·금단·집착은 문맥. 벨벳·초커로 동의나 감금·성행위·정체성을 새로 만들지 않음.|
|근미래 AI 하렘|A가 편 손을 내밀고 B는 손을 자기 몸 가까이 두며 C가 둘을 본다. H23/C08. 수락 이전의 틈을 유지.|같은 제복의 A/B/C에게 요청한 서로 다른 국소 색을 붙이고 A→B·B→C의 시선을 분리한다. A02/H04.|기계 식별점은 요청한 부위에만. 의복·미소·손 접촉이 자발적 애정·기억 연속성·인격·소유권을 증명하지 않음.|
|관능적 성인 로맨스|명시된 성인 A/B가 키스 전 간격을 남기고 C가 별도 위치에 머문다. H20. 얼굴·입술 상태가 중심이므로 복식 미세 구조를 필수화하지 않음.|A/B의 상대 손깍지를 근접 투샷으로 보이고 선택한 로브/캐미솔 층을 주변에 둔다. H07/W14. 상호 다른 신체 소유자 유지.|상호 합의된 복수 관계는 선언한 문맥. 성인·란제리·부두아르가 구체 성행위·노출 확대의 자동 근거는 아님.|

각 대안은 독립 요청 envelope/core에서 시작한다. 카드 조합표를 사용자의 필수 의미나 출처가 입증한 장면으로 바꾸지 않는다. 사진과 키아트·이벤트 CG는 별도 출력 형식으로 설계한다.
