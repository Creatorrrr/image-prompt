# 첫 이미지 비교 계획

실행 상태: **NOT_RUN, 이미지 호출 0**. 12장면×2팔=24장을 제안한다. 연구 문장 자체는 독립 실험의 사용자 요청이 아니므로 실제 요청과 core를 별도로 동결한다. 한 장면이 모든 카드를 시연하게 만들지 않는다.

|번호|대상 카드|핵심 장면과 가시 gate|가까운 실패|
|---|---|---|---|
|01|H01/H03|두 별도 제안자가 같은 성인 수신자에게 별도 선물을 내밈. 사람/선물 주인·방향 유지.|독립 식사 집단을 구애로 읽거나 인물/선물 증식|
|02|H05|B손→A소매 천→A팔의 연속 경로.|자기 소매·A손목 피부 파지·다른 사람 팔|
|03|H07|A와 B 손가락의 번갈아 교차와 각 손목→자기 팔 연결.|같은 사람 손깍지·융합 손·손바닥만 접촉|
|04|H09|중앙 A의 양어깨·양팔과 양측 B/C의 서로 다른 접점.|A팔이 같은 쪽으로 복제되거나 두 사람이 같은 팔 잡음|
|05|H14|A머리→B허벅지, A몸통→벤치, B앉음이 함께 읽힘.|머리 부유·머리가 배로 이동·지지 없는 몸통|
|06|H15|A의 두 팔이 각각 B등·무릎을 지지하고 B신체 연속성 유지.|부유 B·A세 팔·등/무릎의 지지점 누락|
|07|H16|A손→벽·B머리 옆 위치·B얼굴과 A팔 경로.|손이 얼굴 관통·벽 대신 허공·자의적 로맨스/위협 확정|
|08|H20|분리된 두 입술과 남은 간격.|이미 접촉한 키스·겹친 얼굴|
|09|W17|허리밴드→두 가터끈→클립→각 스타킹 윗단의 연결.|허벅지 링·클립 부유·가터가 다른 옷에 붙음|
|10|W19|레이스 개구 아래 별도 불투명 안감이 이어짐.|피부 비침 자동 추가·프린트만 존재|
|11|C05|베젤 안의 초상/패널과 화면 밖 실물의 경계.|네 패널을 실제 네 명으로 생성·UI를 마음 상태로 승인|
|12|C07|B실제 몸과 거울틀 안 B반사상, A의 독립 위치.|반사상을 제삼자로 생성·틀 경계 무시|

각 저장 이미지에서 파일 hash·해상도·원본 경로·선택한 후보/거절 이유·최종 prompt hash·실제 요청 receipt를 남긴다. 문서에 적은 포즈를 픽셀 근거로 복사하지 않는다. 신체 주인·지지·접촉·주요 방향·화면 경계는 각각 살펴본 다음 전체 장면 판정을 내린다. 강한 그림 인상이나 의상 완성도가 관계 실패를 상쇄하지 않는다.

상태는 FULL_PASS / FAIL / PARTIAL_FAIL / UNOBSERVABLE_NOT_PASS / BLOCKED_UNSCORED로 분리한다. 개발용 24장의 집계와 독립 holdout 결과를 합치지 않는다. stage가 노출·채택됐는지 확인하지 못한 비교는 데이터 효과를 평가하지 않는다.

후속 일반 장면 검사는 공유 주방, 회의 집단, 공연 의상, 운동 후 홍조, 벽 소음 항의, 비성적 장비 하네스 등 6가지를 우선한다. 검색/compose의 원치 않는 의미 추가가 먼저 없어야 한다. 이미지가 추가로 필요하면 별도 비교 묶음으로 기록한다. 첫 12장면의 엄격한 gate 실패를 숨기거나 새 시도로 덮지 않는다.
