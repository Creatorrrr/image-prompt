# 시각 의미 카드

## H01 동일 수신자에게 향하는 복수 제안 — proxy

B와 C가 각자 포장 선물 하나를 A에게 내밀며 두 선물 모두 A 앞에 멈추고 A의 빈 두 손은 서로 떨어져 있다.

B and C each extend a separate wrapped gift toward A; both gifts stop in front of A, whose empty hands remain apart.

- gate: 두 제안자·두 선물·같은 수신자 A·미접촉 손이 함께 읽힘
- 경계: 선물 교환만으로 구애·하렘·합의를 증명하지 못함; 인원은 요청에서 결정
- 검토 role: prop_placement, relational_action; 출처: R01, R03
