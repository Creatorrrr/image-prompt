# 아직 직접 카드로 확정하지 않은 표제의 처리

이 목록은 삭제 목록이 아니다. 외형 36행과 문맥 38행에 대해 다음 심사가 무엇을 확인해야 하는지 명시한다. 원 대화의 정의를 독립 검증 완료로 복사하지 않았다. ‘재사용’도 현재 운영 승인 상태가 아니라 심사 방향이다.
