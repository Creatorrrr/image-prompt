# 메카물·로봇물 시각 의미와 후보 데이터 보강 리서치

조사일: 2026-10-24 KST. 초기 리서치와 반영 계획을 보존한 문서다. 후속 요청으로 실제 데이터 등록과 독립 이미지 3장 테스트를 실행했으며, 현재 상태·원본 이미지·검증 한계는 [INTEGRATION-RESULTS.md](INTEGRATION-RESULTS.md)에 기록한다.

참조한 [메카물 용어 외형 조사](https://chatgpt.com/c/6adb6fc3-d278-83ec-815b-82886efe83ae)의 원문 표 322행, 본문 별도 용어 `키블` 1건과 19개 범주를 보존했다. 322는 동의어를 잘라 늘린 개념 수가 아니라 조합 예시 8행까지 포함한 원문 표의 행 수다. 조회 도구는 답변을 20,000자에서 잘랐으므로 로그인된 Chrome에서 후반과 마지막 문단까지 읽어 보완했다.

이 자료는 단어 사전의 증량보다 **무엇이 무엇에 붙고, 누가 어디를 지지하며, 어느 층의 무엇을 보는지**를 보강하는 제안이다. 원문의 민감한 범주도 남겼다. 팬서비스·ASFR·섹스봇·동의와 소유·강제 개조·기계 고어는 각각 외형 후보와 맥락 진술을 분리한다. 성인 외형 후보는 성인을 명시했고, 원작의 미성년 인물을 성인 취향 문맥에 이식하지 않는다.

## 주요 조사 결과

### 1. 존재 종류를 외형·착용·조종 관계로 나눠야 한다

휴머노이드는 몸의 구성, 안드로이드는 인간 외관의 재현, 사이보그는 생물과 장치의 결합, 외골격은 몸 바깥에 착용하는 지지 구조, 탑승형 메카는 내부 조종석과 외부 기체의 관계가 핵심이다. 같은 금속 팔이나 인간형 실루엣이 이 분류를 모두 증명하지 않는다.

CYBERDYNE의 [HAL 설명](https://www.cyberdyne.jp/en/products/about-hal)은 피부 표면 신호와 착용 보조를 다룬다. 제조사의 Wearable Cyborg 명칭도 함께 보존하되, 모든 착용 외골격을 영구 의체화한 사람으로 분류하지 않는다. [Atlas 개발 설명](https://bostondynamics.com/blog/electric-new-era-for-atlas)처럼 인간형 몸 구성은 인간과 다른 가동 범위와 양립한다. 이는 현재 모든 로봇의 성능 규격이 아니다.

카드 A01–A11은 내부 좌석이 있는 기체, 인간형 몸 구성, 얼굴 점검구, 국소 의체 접속, 외부 커프·지지 프레임, 방호 외장, 원격 화면, 작업 말단, 의인화 장비, 구조 플랫폼, 기사형 문양을 구별한다. 기계생명체·의식·자율성·성별 코드는 N04–N05와 N18–N23으로 분리한다.

### 2. 기계 디테일은 부품의 양끝과 하중 경로가 있어야 한다

피스톤이 보인다는 표현만으로는 부족하다. B03은 실린더 몸통→위팔 링크, 로드→아래팔 링크, 그 사이의 팔꿈치 간섭을 함께 본다. B02는 두 링크와 회전축, B04는 레일·캐리지·로드, B05는 모터·축·감속기 입력을 구별한다. [Modern Robotics](https://modernrobotics.northwestern.edu/nu-gm-book-resource/2-2-degrees-of-freedom-of-a-robot/)의 관절·자유도 구분을 사용했지만 정확한 기구 설계나 실제 작동을 검증한 것은 아니다.

프레임·외장·장갑·추가 장갑은 다른 층이다. 탈거한 외장판이 정비 받침대에 있는 상태와 전투로 박리된 상태는 원인까지 같지 않다. 하드포인트는 지지·장착점이며 장비 팩과 분리해 작성한다. 그리블·패널라인은 구조를 암시하는 외관이지만 실제 기능의 증거가 아니다.

### 3. 변형·합체·환장·퍼지는 독립 의미다

B06은 본체와 분리 팩, B07은 자동차 지붕·바퀴가 남은 기체, B08은 서로 다른 모듈과 결합 칼라, B10은 본체에서 떨어진 장갑과 고정점이다. 이 네 가지를 `transformation`이라는 말로 합치지 않는다.

[Macross Zero 공식 소개](https://macross.jp/pages/series?title=macrosszero)는 특정 VF의 세 형태를 명명한다. 한 형태의 실루엣은 변형 경로·시간·질량 보존을 증명하지 않는다. 원 대화의 세부 VF 사양 PDF는 현재 404로, 가워크가 모든 변형에서 필수 경유 단계인지 같은 주장은 이 조사에서 채택하지 않았다.

### 4. 콕핏은 접점·좌석 순서·매체층을 함께 작성해야 한다

C01은 성인 손–해치 손잡이, 부츠–아래 발판, 뒤쪽 좌석을 함께 보인다. C02는 몸–좌석–버클–앵커, C03은 좌우 손–별도 조종간과 좌우 부츠–별도 페달이다. 여러 접점 중 일부만 보이면 전체 성공으로 처리하지 않는다. C04는 앞뒤 탠덤과 나란한 복좌를 구별한다.

[공식 ν 건담 자료](https://en.gundam-official.com/feature/pgu-rx93/)의 흉부 설명과 [흉부 도판](https://en.gundam-official.com/feature/pgu-rx93/images/system_img_chest_250603.png)을 확인했다. 도판은 여러 CG·애니메이션 장면을 합친 자료다. 실제 단일 사진이나 실제 치수·해치 동작으로 간주하지 않는다.

파노라마 콕핏·HUD·원격 모니터는 현실 공간과 표시 영상을 분리한다. [JPL 공유·원격 제어 자료](https://www-robotics.jpl.nasa.gov/what-we-do/research-tasks/shared-and-traded-control-for-remote-teleoperation/)는 조작소·원격 작업계·힘 반영 조종기를 구별한다. 같은 자세·화면·케이블을 보고 동기화율·정신 공유·통각·자율성을 확정하지 않는다.

### 5. 동력·추진·냉각을 하나의 발광 코어로 축소하지 않는다

D01은 벽 설비–연속 케이블–기체 접속구, D02는 분리 팩의 접점, D04는 호스 이음부–흐름 자국–웅덩이, D05는 패널–경첩–뿌리 배관, D06은 주 노즐과 다른 방향의 보조 노즐이다.

[NASA 서비스 모듈](https://www.nasa.gov/reference/european-service-module/)의 계통 구분과 [열 제어 자료](https://www.nasa.gov/smallsat-institute/sst-soa/thermal-control/)의 라디에이터 개념을 참고했다. 후보의 정확한 판 수·색·기체 부착 위치는 창작 제안이다. 배터리·발전기·반응로·축전기·AI 코어, 냉각수·유압유·혈액, 방열판·태양전지·실드·의장 날개는 외형만으로 동일시하지 않는다.

### 6. 무장은 작동 원리와 보이는 형상을 나눠야 한다

급탄 드럼과 탄띠, 포드 해치와 셀, 분리 전완과 배기, 손목 말뚝과 하우징의 축선, 고체 칼날과 발광 날, 본체와 분리 원격 유닛, 물리 방패 브래킷, 반투명 장벽, 장갑 단면을 각각 작성했다. 이 자료는 외형·장면 데이터이며 제작 지침이 아니다.

[NIST 레이저 설명](https://www.nist.gov/history/nists-role-laser-measurements-and-applications/what-laser)과 [ONR 레일건 설명](https://www.onr.navy.mil/media-center/news-releases/bang-navy-begins-tests-electromagnetic-railgun-prototype-launcher)은 빛과 물리 탄체의 구분을 뒷받침한다. 반짝이는 무기는 자동으로 레이저·레일건이 되지 않는다. 판넬·사이코뮤는 작품 고유 설정이고, 작은 분리체가 보인다고 정신 제어·공격 성공을 증명하지 않는다.

### 7. 의상은 형태·피복·기능·성인 맥락이 별도다

G01은 작업형 비행복, G02는 압력복처럼 보이는 연결부와 외부 호스, G03은 하체 덧층, G04–G05는 헬멧·바이저·마스크·호스·HMD, G06–G07은 정비복·제복·표식 매체다. G08–G14는 성인 밀착복·컷아웃·시어·광택·하이컷·인공 외장 노출·의상 파손·지퍼 동작이다.

[NASA 우주복 정의](https://www.nasa.gov/reference/11-0-spacesuits-vol-2/)는 LEA와 EVA를 사용 목적과 생명유지 구성으로 구별한다. 밀착복의 반사·색·커넥터만으로 압력 유지·방탄·항G·신경 연결을 인증하지 않는다. 항G복의 공식 검색 발췌는 확인했으나 본문 403으로 특정 모델의 정확한 봉제·주머니 구조는 보류했다.

팬서비스·ASFR·성적 기계 신체·동반자·섹스봇은 원문에서 제거하지 않았다. [de Fren의 인공 여성 신체 논문 발췌](https://escholarship.org/content/qt4qn696qm/qt4qn696qm_noSplash_003e980880283926108e8646b3a84a9a.pdf)는 별도 담론의 근거다. 성적 기능·관객의 취향·관계의 자발성은 여성형 실루엣·광택·노출·정지 자세로 추론하지 않는다. 해당 논문이 다루는 문화적 해석과 후보의 구체적 피복선은 다른 층이다.

### 8. 포즈는 체중·접점·방향·시선을 보강해야 한다

H01–H09는 입상, 세 지점 접지, 무릎 사격, 검끝 원근, 발진 고정, 인양 경로, 손바닥 위 성인, 손상 기체 지지, 부유 상태다. I01–I08은 버클과 끈 끝, 바이저 가장자리, 옆구리 헬멧, 점검구 공구 끝, 새들 좌석, 올려다보는 시선, 안드로이드 대기, 벤치와 헬멧이다.

검끝을 가까이 둔 원근은 검 자체의 거대화와 다르다. 세 접점은 세 끝점이 실제 지면에 함께 닿아야 한다. 인양은 크레인 훅부터 기체 고리까지 연결을 추적한다. 손바닥 위 성인은 몸의 지지가 보여야 한다. 정지 자세만으로 착지 완료·전투 피로·보호 의도·사랑·동의를 확정하지 않는다.

### 9. 파괴·바디호러는 재질과 소유자 경계를 유지한다

J01–J08은 기계 팔과 빈 어깨, 장갑 박리와 프레임, 인공 표피와 기계층, 유기형 다발과 소켓, 흉부 파열과 내부 좌석, 파열 코어, 표면 침입 덩어리, 다른 도색의 교체 팔이다. 기계 유체가 혈액으로 변하거나 무인 기체 손상에서 사람의 상해·사망이 자동 추가되면 의미가 바뀐다.

[Seager 논문 초록](https://iopn.library.illinois.edu/journals/jams/article/view/1186)은 신체 재편과 사회적 서사를 연결하는 해석을 제안한다. 이 조사에서 초록·서지를 확인했으며 논문 전문이나 모든 작품 프레임을 분석했다고 주장하지 않는다. 강제 개조·인격 말소·기억 소거·기생 제어·자폭 의도는 별도 맥락으로 보존한다.

### 10. 사진·도면·화면·시퀀스는 다른 표현 계약이다

K01–K07은 컷어웨이, 분해도, 삼면도, HUD, 스토리보드, 궤적 그림, 실루엣 공개다. 세부 기구를 설명하는 도면은 유용하지만 단일 사진 요청에 자동으로 끼워 넣지 않는다. 부분 공개는 가린 연결점을 검증한 것으로 바꾸지 않는다. 미사일 다량 배치와 이타노 서커스의 영상 운동·리듬은 같은 뜻이 아니다.

## 출처 한계와 남긴 보류

30건 중 25건은 본문·초록·PDF 텍스트 또는 이미지까지 확인했다. 나머지 5건은 항G 본문 403, VF 사양 PDF 404, 그리블 인용 지원 미확인, 친밀성 논문 브라우저 검사, 카토키 관련 원 기사 주소의 홈페이지 이동으로 제한됐다. 접근 실패와 아래 세부 보류는 구별하며 registry의 실제 접근 상태를 따른다. **접근 상태의 실제 집계는 validation-results.json의 source_access_counts를 우선한다.** 원 대화의 출처를 확인 없이 그대로 권위로 승격하지 않았다.

명시적 후보 보류는 G03의 실제 항G복 모델 구조, K06의 특정 영상 연출 기법 자격이다. F10의 그리블 구성은 창작 가능하지만 S24가 그 정의를 지원한다고 주장하지 않는다. 레이버의 기본 범위는 [Patlabor 공식 소개](https://ezy.patlabor.tokyo/), 예거·드리프트는 [Legendary 공식 줄거리](https://www.legendary.com/film/pacificrim/)로 보완 확인했다. 정확한 판본별 구조·도판, 카토키·이타노 명칭의 지원과 운동 규격은 추가 조사 목록에 남겼다. 생체모방 표면·합성피부·광택·세라믹풍 표면의 실제 성분도 증명하지 않았다.

## 다음 반영의 결론

우선순위는 **외골격/탑승형 구분 → 프레임·액추에이터 → 콕핏 접점 → 케이블·유체 경로 → 포즈 지지 → 표현층 경계**다. 이 관계를 먼저 구현하고, 표면 변형·복식·고유어·연출의 확장은 뒤에 연결한다. 구체적인 반영 경로와 합격 기준은 [ADOPTION-PLAN.md](ADOPTION-PLAN.md)에 정리했다.

초기 리서치 단계에서는 운영 후보 등록, typed source/native qualification, 인덱스 재빌드, installed release 설치·활성화, 실제 검색, 프롬프트 전달, 이미지 생성·픽셀 검증, commit/push를 수행하지 않았다. 당시 설치 recorder의 읽기 전용 점검 통과와 이미지 호출·source write 0은 반영 증거가 아니었다. 이후 사용자 요청으로 실행한 등록·검색·생성·픽셀 결과는 [후속 실행 보고서](INTEGRATION-RESULTS.md)에서 별도로 확인한다.
