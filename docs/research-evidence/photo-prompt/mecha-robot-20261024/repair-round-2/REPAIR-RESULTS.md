# 메카 시각 의미·후보 보완 및 독립 3안 재시험

데이터·샘플링·의도 범위를 보완하고, 같은 첨부 사진으로 독립 작성자 3명이 프롬프트를 작성해 built-in imagegen으로 각각 1회 생성했다. 원본 픽셀의 엄격한 전체 충족은 **0/3**이다. 후보 노출과 여러 접점은 개선됐으나 A의 양팔 소유자 혼합, B의 남은 과도한 전체 전완 받침 조건, C의 지지 손목 가림이 확인됐다. 실패 기록과 생성 전 기준은 그대로 보존했다. 관리 리뷰 기록은 세 안 모두 유효하며(record_valid=true), 기술적 전체 자격은 세 안 모두 실패다.

## 반영한 데이터와 노출 정책

- A05 하체 외골격을 상지용으로 재해석하지 않고 A12 상지 외부 지지 구조를 별도로 추가했다. 어깨 하네스 → 노출 브래킷 → 상완 커프 → 외부 팔꿈치 힌지 → 전완 커프와 그 밖의 같은 인간 손목을 구별한다. 완전한 한·영 후보 1개, 선택적 바인딩 3개, 방향 관계 7개를 추가했다. 연령·실제 출력·의학적 효능·제조사 모델은 관찰 조건으로 요구하지 않는다.
- 누적 메카 데이터: 의미 카드 109개, 방향 관계 420개, 후보 141개(긍정 107·진단 34), 선택적 바인딩 231개, 용어 라우트 323개. 이전 후보 140개·바인딩 228개·카드 108개와 기존 경계·라우트는 그대로다.
- A12 실제 CID는 `cand_9b87661850ec52c998e202554775318b`, 출처 SHA는 `e59ab2eab2d390e7609b1e50e6e2f9289b553548286e9a26980c770ef6c20f55`다. 모든 신규 출처의 native 승인은 false다.

기존 발급 창을 조사하니 A의 구조 조회에서 A12가 1위여도 균등 8/32 추출에서 빠졌다. 명시적으로 요청된 미노출 보완을 위해 샘플링 v2를 적용했다. 첫 적격 순위 후보 1개를 유지하고 나머지 7개를 균등 비복원 추출한다. 전체 풀 순위 점수·출처 필터·창의성별 순위 창/총예산은 그대로다(8/4, 32/8, 96/12, 256/16). 특정 CID·신규성·주제를 강제하지 않는다. 한 자리의 변동성은 줄어들며 모든 안의 신규 후보 노출·채택을 보장하지는 않는다.

원래 창·시드·조회 해시의 ID 전용 정책 재생에서도 차이를 검증했다. 재생은 새 검색·임베딩·자료 발급이 아니다. 실제 v2 실행은 정확히 같은 독립 동결 초안을 공식 새 실행에 복제한 뒤 한 번씩 조회했다. v1 준비 실행에는 이미지 호출이 없었으며 모두 보존했다.

## 작성 범위와 실제 후보 사용

주제 검색에는 선행 사용자의 `메카물 용어 외형 조사`와 좌우·연결·접점 가림이라는 시각 요구를 남겼다. 실행·위임·후보 노출 관리 지시는 원 요청에 보존하면서 시각 조회 범위와 분리했다. 참조 사진은 얼굴·머리의 속성만 보존한다. 의상·장소·광원·카메라 등 작성자의 선택을 사용자 의무 조건으로 올리지 않도록 범위를 바로잡았다. 실제 수정 대상 물체·도구·상호작용은 유지했다.

| 안 | 신규 메카 출처 실제 노출 | 전체 비교 후 반영 | native 선택 |
|---|---|---|---:|
| A 상지 외골격·벤치 클램프 | A12 1개 | A12 전체 의미를 참고 반영 | 0 |
| B 보행 메카 조종석·지도 | 0개 | 0개 | 0 |

각 작성자는 다른 안의 초안·후보 판단·이미지를 받지 않았다. A/B의 참조 메타데이터 복구에는 창작 내용을 포함하지 않은 공통 기술 도우미만 공유했다. 각 안의 조회 4건, 총 32회 출현을 모두 판단했다(A/B 각 30개, C 31개 고유 출처).

C는 A12를 작업자의 팔에 함께 착용하는 완전한 대안도 비교한 뒤, 분리 팔·지지 접점과 추가 소유자/관절의 경쟁 때문에 채택하지 않았다. 얼굴·머리 참조가 팔의 생물학적 구성을 잠근다는 이유로 제외하지 않았다. B도 조종사의 팔 조건을 기계 소유자의 포즈에 잘못 적용하는 충돌 이유를 제거했다. 미채택 출처를 부분 차용했다고 기록하지 않는다. B의 픽셀 수리 시험은 신규 출처 적용 성공으로 세지 않는다.

## 픽셀에서 확인된 후속 보완

`post-pixel-drafts/repair-plan.json`과 A/B/C의 구체적인 다음 프롬프트를 저장했다. 이들은 root가 원본 검토 후 작성한 **미생성·미검증 초안**이며 이번 독립 3장 결과를 대신하지 않는다.

- A: 왼쪽 상완·팔꿈치·전완·손과 클램프를 같은 몸쪽의 교차하지 않는 경로에 배치한다. 장비/동작/소유자를 유지한다.
- B: 다음 required assertion의 물체 식별을 ‘넓은 수평 ledge’로 줄이고 근거 없는 **전체 전완 받침** 범위를 제거했다. 실제 왼팔/받침대·오른손/지도 접촉은 보존한다. 현재 시험의 동결 assertion은 수정하지 않았다.
- C: 지지 손목과 소매를 전완 레일의 카메라 쪽 아래로 드러내고, 그 사이 인간 전완을 빈 배경 위에 보이게 한다. 지지점은 같은 노출 중간 프레임, 도구 끝은 같은 손목 체결점이다.

시각 의미 참조 문서에도 물체 식별 문장이 작성자의 임의 범위를 사용자 의무로 올리지 않도록 하는 지침과, 같은 팔 전체 경로/지지 손목 접근 경로 점검을 추가했다. 이 후속 초안의 픽셀 성공은 주장하지 않는다.
