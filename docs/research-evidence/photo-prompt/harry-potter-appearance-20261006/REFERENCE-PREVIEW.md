| **자신감이 흔들리는 장면형** | 매끈하던 앞머리가 이마로 떨어지고, 셔츠에 주름이 생기며 넥타이가 느슨해진다. 시선을 피하고 입을 굳게 다문다. |
| **경쟁 구도형** | 두 인물을 마주 세우고 한쪽은 팔짱, 다른 쪽은 책이나 지팡이를 든다. 턱의 높이·어깨 방향·시선의 각도로 대립을 만든다. |
| **냉정한 표정형** | 눈꺼풀을 약간 내리고 입을 다문다. 턱은 수평에 가깝게 유지하고 손과 어깨의 움직임을 줄인다. |
| **빈정거리는 표정형** | 한쪽 눈썹을 올리고 한쪽 입꼬리를 비틀어 올린다. 고개를 약간 젖힌 채 상대를 옆눈으로 바라본다. |

여기서 **‘영애’나 ‘순혈’은 눈으로 확인할 수 있는 신체 특징이 아닙니다.** 이를 외형으로 표현하려면 정돈된 재단, 비싼 직물처럼 보이는 표면, 작은 금속 장식, 손의 위치와 턱의 각도처럼 실제로 보이는 요소를 선택해야 합니다.

# 6. 위 디자인을 재사용하기 좋은 세부 용어

다음은 앞의 인물들을 묘사할 때 구분해서 쓰기 좋은 표현입니다. 오른쪽은 해당 단어를 쓰지 않고 형태를 직접 지시한 문장입니다.

| 용어 | 용어를 풀어 쓴 외형 묘사 |
|---|---|
| **Slicked-back hair — 슬릭백** | 이마의 머리카락을 뒤쪽으로 밀착해 넘기고, 표면의 잔머리를 줄인다. |
| **Sleek straight hair — 매끈한 생머리** | 머리카락이 큰 굴곡 없이 한 방향으로 내려오며 표면이 정돈돼 있다. |
| **Bushy hair — 부풀어 퍼진 머리** | 머리 전체의 부피가 크고, 바깥 윤곽에서 가는 잔머리가 여러 방향으로 퍼진다. |
| **Ringlets — 나선형 컬** | 머리카락을 굵은 줄 단위로 나누어 일정한 간격의 나선 모양으로 말아 내린다. |
| **Tousled hair — 헝클어진 머리** | 머리카락의 방향과 덩어리가 고르지 않고 일부가 들리거나 얼굴 앞에 내려온다. |
| **Stand collar — 스탠드칼라** | 옷깃이 접혀 눕지 않고 목 둘레를 따라 위로 서 있다. |
| **Cravat — 크라바트** | 넥타이보다 넓은 천을 목에 두르고, 앞에서 접거나 묶어 가슴 윗부분을 채운다. |
| **Jabot — 자보** | 목 아래에서 가슴 방향으로 레이스나 얇은 천의 주름이 여러 겹 내려온다. |
| **Brocade — 브로케이드** | 천의 바탕 위에 다른 광택이나 색의 문양이 직조돼 표면이 풍성하게 보인다. |
| **Velvet — 벨벳** | 짧은 털이 촘촘한 표면이 빛의 방향에 따라 어둡거나 부드럽게 반짝인다. |
| **Chiffon — 시폰** | 얇고 가벼운 천이 작은 바람에도 흐르며 겹쳐진 부분에서 색이 짙어진다. |
| **Tulle — 튈** | 가는 망사 조직을 여러 겹 쌓아 가벼우면서 부풀어 오른 부피를 만든다. |
| **Pleating — 플리츠·주름잡기** | 천을 일정한 폭으로 접어 세로 방향의 반복되는 골과 능선을 만든다. |
| **Tiered skirt — 층진 치마** | 길이가 다른 여러 천 단을 위아래로 겹쳐 치마의 가로 경계가 반복되게 한다. |
| **Ruffle — 러플** | 천의 한쪽을 촘촘하게 모아 가장자리가 파도처럼 굽이치게 한다. |
| **Appliqué — 아플리케** | 바탕 천 위에 잎·새·문양 형태로 잘라 만든 별도의 장식을 덧붙인다. |
| **Lacing — 레이싱·끈 여밈** | 양쪽 가장자리의 구멍을 끈이 교차하며 통과하게 하고, 간격과 조임을 드러낸다. |
| **Distressing — 해짐 가공** | 옷의 가장자리와 접히는 부위에 닳음, 풀린 실, 작은 찢김을 배치한다. |
| **Weathering — 사용감·환경 흔적** | 먼지, 물자국, 바랜 색, 반복된 마찰 흔적을 옷 전체에 불균일하게 더한다. |
| **Asymmetry — 비대칭** | 머리·장식·색·표정의 좌우를 다르게 배치해 균형이 한쪽으로 치우치게 한다. |
