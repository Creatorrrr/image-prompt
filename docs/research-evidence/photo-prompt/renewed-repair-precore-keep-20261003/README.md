# 수리 장면과 초기 관찰 카탈로그: 데이터 유지 판정

## 결론

이번 조사에서는 후보나 카탈로그를 추가하지 않았다. 장면의 중요한 관계를 기존 후보가 실제로 드러내는지와, 새 데이터가 정말 필요하며 중복이 적은지는 별도로 판단해야 한다.

### 지지된 부품 수리 장면

개발용 세 장면은 체결, 이물질 추출, 작은 부품 회수라는 서로 다른 사건이다. 기존 데이터에는 도구 접촉/작업 결과, 손잡이 파지, 하중 지지, 필요한 근거를 보존하는 구도·초점, 특정 도메인의 부품 트레이가 있다. 다만 일반적인 체결의 느슨한 부품–수용부 관계를 이 후보들이 전부 새로 작성해 주는 것은 아니다.

이미 작성된 도구 끝·접촉·수용부·지지점을 잘 보이게 하는 후보는 기존 보존 개념과 많이 겹친다. 반대로 부품을 받치거나 맞물리게 하거나 흩어진 부품을 용기에 옮기는 것은 장면의 동작·관계를 바꾸므로 구도 전용 후보로 표시해서는 안 된다. 도메인 제한이 있는 트레이나 전자제품 수리대를 범용 수리로 넓히지도 않았다.

개발용 검색 진단에서 세 입력 모두 64개 한도에 도달했고, 점검한 범용 도구/파지/지지/구도/초점 후보는 노출되지 않았다. 이는 전체 파이프라인이나 이미지 검증이 아닌 제한된 검색 관찰이다. 후보의 비노출만으로 새 동의어나 특정 장면 묶음의 필요성이 입증되지는 않는다. 전이/보류 사례나 다른 후보 실험 결과를 사용하지 않았다.

### 초기 관찰 카탈로그

현행 절차는 후보 조회 전에 독립적인 장면과 기본 프롬프트를 작성한다. 작성 전 허용되는 `precore/visual_feature_catalog.json`은 중립적인 관찰 범주를 제공하며, 후보 목록·장면 메뉴·프로필 트리거가 아니다.

카탈로그의 48개 범주는 이미 사물 중심 장면, 행동, 인과관계, 환경 흔적을 다룬다. 인물 중심 예시가 많고 살아 있는 비인간 주체의 명확한 예시가 부족한 점은 실제로 확인했다. 그러나 예시 추가가 장면 다양성을 개선한다는 독립 실험은 아직 없다. 범주 수를 늘리는 것 자체를 성과로 보지 않았다.

원래 45개 행을 보존하는 검사와 추가 범주의 의미 소유권을 존중한다. 보존 검사를 피하기 쉬운 위치라는 이유로 다른 범주의 내용을 Primary Object에 넣어서는 안 된다. 이후 제안은 의미에 맞는 중립적 범주 배치와 독립적인 선택 이득을 먼저 입증해야 한다. 이번 아카이브의 예시 아이디어는 검증되지 않은 가설이며 반영 권고가 아니다.

유지보수 조사 중 역사적 설계 문서에 포함된 과거 검증 요약을 보았으므로, 이 조사자를 다음 독립 초기 작성 실험의 작성자로 재사용해서는 안 된다. 해당 요약은 현재 판정의 근거나 품질 수치에 사용하지 않았다.

## 범위와 증거

후보/소스/런타임/카탈로그 수정, 색인 재생성, 제공자 호출, 이미지 생성은 없다. 두 조사 보고서, 점검한 정확한 원본 행과 해시, 재현 가능한 개발용 검색 진단, 향후 독립 비교 설계는 `diagnostic-evidence.tar.gz`에 보존한다. 원본 `18a46eb4` 시점의 관련 슬롯/카탈로그와 유지보수 지침을 기준으로 하며, 같은 작업 트리에서 별도로 수행한 biohybrid/summoner 메타데이터 수정은 이번 조사 성과가 아니다.
