# 후보 데이터 보강의 실제 기여 점검

2026-09-29. 분석 대상은 연구 반영 이후의 합성 컨셉 3개와 원래 주제 4개, 총 7개의 저장된 실행이다. 이번에는 스킬·후보 데이터·프롬프트를 수정하거나 이미지를 새로 생성하지 않았다. 현재 소스 99개 파일은 마지막 4개 주제 실행의 스냅샷과 모두 일치한다.

**판단: 대규모 자료 수집을 더 하기보다, 현재 자료를 검색하고 초안을 재구성하는 경로부터 개선하는 편이 우선이다.** 데이터의 범위는 넓어졌으나 최근 이미지가 좋아진 원인을 새 데이터로 설명할 직접 근거는 매우 약하다. 이는 새 데이터가 무가치하다는 증명과 다르다. 대부분 사용될 기회를 얻지 못했다.

후속 확인: [설정값 참조·의상 잠금의 실제 경로](control-reference-trace.md)에서 설정 구간도 문자 그대로 보존할 앵커를 요구하는 구조를 재현했다. 달의 폐허의 초기 메모리 접근도 추가로 확인했으므로 완전한 입력 격리 실험으로 해석하지 않는다.

선택된 다섯 종류의 기존 후보를 통합 전 HEAD의 원본 항목과 대조했다. 귀 장식 후보 `sff_pro_p07`만 의역과 문맥이 추가되어 있었고, 나머지 네 종류는 관련 필드가 모두 동일했다. 분장실 작성 기록은 새 `context_C024`를 참고했다고 명시한다. 따라서 이 한 건은 문맥 보강의 프롬프트 기여로 인정할 수 있다. 다만 귀 장식 조절·거울·표정·복장은 이미 기본 초안에 있었다. 이 한 건으로 전체 매력이 향상됐다고 결론 낼 수는 없다.

최근 4개 주제는 달의 폐허만 이미지가 반환됐다. 나머지 세 주제는 각각 4회 모두 출력 안전 필터에 막혔으므로 픽셀 비교 대상이 없다. 차단은 미적 품질 0점이 아니다. Sol max는 프롬프트 작성 모델이며 이미지 생성 도구는 정확한 백엔드 모델 버전을 공개하지 않았다.

## 개선을 가로막는 지점

### 1. 에이전트가 선택한 의상이 사용자 요구처럼 잠긴 사례

[달의 폐허 코어](../../../../../artifacts/photo-prompt-runs/integrated-original-four-3-3-20260929-151603/moon/authorial_core.json)의 `core_appeal`은 사용자 입력 `sensual_editorial=3, fetish_fashion=3`의 보존 근거로 다음 문구를 고정했다.

> a fitted corset-like bodice; pale satin straps cross her waist into small silver rings

사용자가 보존하라고 한 흰색·찢어진 드레스와 달리 코르셋형 상의·허리 끈·은색 고리는 에이전트가 고른 구현 방식이다. 이 문구를 필수 앵커로 삼으면 외형 차원을 열어 두어도 해당 표현을 없애기 어렵다. 더구나 대안 검색은 필수 앵커의 문구를 사용하므로, 코르셋이 없는 방향을 찾기 위한 검색에도 코르셋이 다시 들어간다. 이번에 복원한 대안 검색 문자열에서 실제로 확인했다.

현재 SKILL.md는 이미 에이전트 선택을 사용자 잠금으로 승격하지 말라고 안내한다. 따라서 단순히 비슷한 지침을 추가하는 것보다, 코어를 확정하기 전에 출처가 무엇인지 검토하고 잘못된 필수 문구를 찾아내는 실행 검증이 필요하다. 사용자의 강도·요청 의미는 보존하되, 그 강도를 실현하는 특정 의상과 포즈는 별도의 에이전트 선택으로 두어야 한다.

### 2. 검색 대상에 있어도 실제 후보팩에 거의 나오지 않음

합성 컨셉 세 개는 각각 새 후보 212개를 검색할 수 있었으나 새 후보 노출이 전부 0이었다. 편의점도 210개가 가능했으나 0이었다. 이 사례들은 잠금만 풀거나 데이터 양만 늘려 해결된다고 보기 어렵다.

현재 해당 두 축의 검색은 기본 초안 전체를 따르는 검색과 사용자 요청·앵커 중심의 대안 검색을 합친다. 각 축의 결과는 12개다. 이번 전체 장면 검색 문자열은 558–637단어, 대안 검색 문자열은 138–161단어였다. 작은 손동작·착용 방식·주의의 방향이 긴 전체 장면과 경쟁한다. 세 표현 범위에 대한 다양성 보정은 있으나, 그 보정에서도 동일한 전체 검색 문자열을 사용한다.

일반 v6 검색에는 다른 세부 검색 경로가 이미 있다. 모든 검색이 단 하나의 전체 문장만 사용하는 것은 아니다. 여기서 지적하는 한계는 `photo_contextual_appeal.py`의 두 축 검색에 관한 것이다.

달의 폐허 후보팩에는 빗자루 비행·대나무 숲 공중 대결 같은 후보도 있었다. 선언된 변경 차원을 통과하고 단어·의미가 비슷하다는 것만으로 현재 사진에 적용할 좋은 대안이 되지는 않는다. 후보 수를 무작정 늘리기 전에, 작은 관계를 별도로 검색하고 요청 장면과의 적합성을 비교하는 단계가 필요하다.

### 3. 데이터는 늘었지만 검색 가능한 표현이 얇음

신규 231개 중 행동 슬롯이 148개, 전체 의상 슬롯은 15개다. 세 표현 범위로는 장면·행동 관계 211개, 전체 방향 15개, 구조·소재 5개다. 이번 보강은 사용자가 원한 비의상 표현을 확장했지만, 231개의 서로 다른 강력한 전체 스타일 대안이 추가된 것은 아니다.

신규 231개 모두 별칭과 의역이 비어 있고, `concept_units`는 영어 라벨 한 문장을 그대로 반복한다. 관계의 주어도 모두 일반화된 동일 문구다. 의미 임베딩이 있으므로 의역이 없다는 사실만으로 검색 실패의 원인을 확정할 수는 없다. 다만 같은 생각을 다른 말로 찾거나 장면에 맞게 변형해 연결할 수 있는 입력이 부족하다.

어떤 맥락에서 그 단서가 매력적으로 읽힐 수 있는지에 대한 설명은 `contextual_usage`에 있으나 검색용 텍스트에는 들어가지 않는다. 반례·부정·사적인 욕망에 대한 추정을 그대로 긍정 검색어로 만들지 않는 것은 타당하다. 대신 현재의 구체적 시각 관계에 대응하는 긍정적인 표현 방식과 의미 있는 의역을 정제할 여지가 있다. 기존 후보 31개의 문맥 보강 중 검색 가능한 의역이 추가된 후보는 8개뿐이다.

### 4. 선택 단계에서 기본 초안과 동등한 대안으로 발전시키지 않음

분장실은 다른 전체 의상을 “선택한 검은 새틴과 가죽 구조를 대체한다”는 이유로 `conflicting`으로 기록했다. 여객선도 “에이전트가 정한 소재 관계를 바꾼다”는 이유를 썼다. 해당 의상이 최종적으로 더 나쁠 수는 있지만, 에이전트 자신의 선택을 바꾼다는 사실 자체가 사용자 요구와의 충돌은 아니다.

물 마시기는 캐미솔·데님 대안을 기존 코르셋보다 구조적인 표현이 약하다는 이유로, 고백은 단순한 끈 상의가 요청한 강도를 드러내지 못한다는 이유로 배제했다. 현재 설정 정의는 높은 강도가 특정 의상 종류를 지정하지 않는다고 명시한다. 기록상 실제 판단은 다시 코르셋·버클·광택 소재 쪽에 유리하게 작동했다.

후보의 단어 몇 개를 현재 완성된 초안과 바로 비교하면 초안이 유리하다. 대안도 해당 장면 안에서 착용 방식·표정·빛·거리 등의 관계를 가진 완성된 구상으로 발전시킨 뒤 비교해야 한다. 이는 무조건 새 후보를 채택하거나 익숙한 소재를 금지하자는 뜻이 아니다.

## 저장 이미지에서 확인 가능한 것

이번에 저장 원본 네 장을 다시 직접 열어 보았다. 아래는 현재 관찰이며 전후 통제 비교나 사용자 취향 판정이 아니다.

- 달의 폐허: 전신과 폐허·강한 광원·드레스·돌아본 얼굴이 전체 인상을 이룬다. 이 주요 선택은 기본 초안에 이미 있었다. 추가한 표면 장식 끈은 기존 상의 구조와 분리해 확실히 판별하기 어렵다.
- 분장실: 얼굴과 귀 장식에 닿은 손, 따뜻한 거울 조명은 보인다. 새 문맥으로 요구한 정확한 아래쪽 잠금쇠 접촉까지 별도로 확정하기는 어렵다. 전체 복장·거울 구도·표정은 이미 초안에 있었다.
- 정비소: 한쪽 어깨의 가죽 구조는 보이지만 추가 문구가 지정한 배우 기준 좌우와 다르다. 기존 결과의 정밀 관계 실패를 성공으로 바꾸지 않았다.
- 여객선: 손목 부근 주름은 보이나 팔걸이 접촉점은 프레임에서 확인되지 않는다. 붉은 반사의 광원 관계도 추가 문구의 유리면 정렬과 명확히 일치한다고 볼 수 없다.

따라서 “더 자세하게 추가했다”와 “더 매력적인 이미지가 됐다”를 연결할 근거가 부족하다. 새 후보의 노출·채택 비율을 올리는 것만으로도 최종 성공을 선언하면 안 된다.

## 권장 순서

1. **사용자 잠금과 에이전트 선택의 경계를 먼저 바로잡는다.** 흰 드레스·문구·필수 행동은 보존한다. 선택한 코르셋·소재·손 배치 등을 강도의 필수 증거로 고정한 항목은 구별한다. 강도 3을 특정 의상 종류로 판단하지 않는다.
2. **현재 풀을 더 잘 검색하고 다시 구성한다.** 전체 장면 검색은 유지하되, 그 장면에서 열려 있는 착용 방식·소재 반응·표정/행동 관계를 짧고 독립적인 검색으로 다룬다. 요청과 어울리지 않는 결과가 짧은 검토 목록을 차지하는 문제를 줄인다. 마지막 작가적 검토는 디테일 추가뿐 아니라 열린 선택의 교체·삭제·장면 재구성도 실제로 비교한다. 독립적인 최초 초안은 비교 기준으로 보존한다.
3. **지금 데이터의 표현과 적용 조건을 보강한다.** 명칭을 더 수집하기 전에 기존 후보에 자연스러운 의역, 관찰 가능한 표현의 핵심, 필요한 조건, 바꿀 수 있는 주변 요소, 다른 장면에서도 의미가 유지되는 범위를 검토한다. 후보의 효과나 조건을 지워 억지로 통과시키지 않는다. 의미가 달라지는 변형은 원본과 같은 후보인 척하지 않는다.
4. **그다음 부족한 영역만 추가 조사한다.** 검색으로 적절한 후보를 찾지 못한 실제 실패 장면, 후보를 보았으나 같은 강도의 유효한 대안으로 발전시키지 못한 부분을 수집 근거로 삼는다. 전체 스타일·착용 방식·사람과 장면의 관계를 함께 설명하는 사례가 필요할 수 있지만, 현재 통계만으로 그것을 새로운 의상 목록으로 한정할 이유는 없다.

새 ID 우대, 최소 채택 할당, 억지 의상 다양화는 권하지 않는다. 현재 후보가 이미 좋은 초안에 아무 도움도 주지 못하는 경우에는 그대로 유지하는 것이 맞다. 중요한 것은 유효한 대안과의 비교 기회가 실제로 있었는지다.

| C | 보강 후 자료 | 현재 방식 | B와 비교해 자료 추가 효과 분리 |
| D | 보강 후 자료 | 개선한 검색·재구성 | C와 비교해 활용 방식 효과 분리 |

먼저 이미지 없이 실제 후보 노출, 장면 적합성, 선택 이유, 최종 프롬프트의 의미 있는 차이를 확인한다. 결과가 같으면 같은 사진을 반복 생성하여 자료의 효과인 것처럼 해석하지 않는다. 차이가 있을 때만 같은 생성 환경에서 이미지 비교를 진행하고, 가능한 반복 표본과 조건명을 가린 사용자 비교를 사용한다. 생성 모델 버전이나 시드를 도구가 제공하지 않으면 통제했다고 주장하지 않는다.

판정은 요청 충실도·신체/물체 관계·전체 매력·표현 다양성을 구분한다. 마지막 두 항목의 핵심은 사용자 선호이며 후보 개수나 내부 감사 통과로 대신하지 않는다. 각 조건의 차단 여부와 실제 이미지 수를 별도로 기록한다. 후보 노출은 좋아졌는데 선호가 그대로라면 다음 투자는 추가 수집보다 장면 선택·표현·구성의 개선에 둔다.
