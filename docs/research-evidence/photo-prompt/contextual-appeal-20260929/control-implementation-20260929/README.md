# sensual · fetish 개선안 적용 기록

2026-09-29. 이전 파라미터 호환성이 필요 없다는 최종 요청을 반영했다.

## 적용한 변경

| 부분 | 현재 동작 |
|---|---|
| 표준 이름 | `sensual`, `fetish`만 입력·설정·출력에 사용 |
| 저장 기본값 | `sensual=1`, `fetish=0`; 두 값 모두 정수 0–3 |
| 초기 의미 | 사용자가 제안한 두 영문 정의를 그대로 채택 |
| 강도 | 0: 추가 처리 없음, 1: 은근한 보조, 2: 분명하게 읽힘, 3: 전체 매력과 방향을 주도 |
| 초안 입력 | 실제 적용값·범위·정의·선택한 단계 설명을 묶은 짧은 `authoring_brief` |
| 설정 증명 | 원문과 일치하는 덮어쓰기 값 및 설정 스냅샷 해시로 검사 |
| 시각 요구 | 설정을 제외한 요청 구간은 기존 앵커·속성·의미 검사를 유지 |
| 후보 검색 | 전체 장면·요청 기반 대안에 짧은 관계 질의와 약한 장면 관련성 재정렬을 추가 |
| 최종 선택 | 같은 강도의 구체적인 대안과 비교한 뒤 유지·교체·삭제·재구성 가능 |

설정 정의와 스냅샷은 v2, 맥락 후보 검색은 v2, 해당 차원 범위는 v4로 구분한다. CLI의 새 옵션은 `--sensual-intensity`, `--fetish-intensity`다. 이전 설정 키와 CLI 옵션을 위한 별칭은 만들지 않았다. 이전 실행 결과와 내장 정의는 수정하지 않았고, 현재 검증기에 대한 구 설정 스냅샷의 호환성은 제공하지 않는다.

기존 후보 데이터의 파일명·프리셋 ID·일부 태그에는 이전 문자열이 남아 있다. 이들은 파라미터 별칭이 아니다. 초기 작성에서는 후보 데이터를 읽지 않으며, 현재 v6 맥락 검색은 해당 축 태그를 자격 조건으로 사용하지 않는다. 태그·ID는 긍정 임베딩·키워드 텍스트에서도 제외된다. 실제 패션 후보의 의미나 자료 식별자를 이름 변경만을 이유로 바꾸지 않았다.

`popular`는 대중적인 매력 표현도 허용한다는 의미이며 유행 검색을 요구하지 않는다. `overt`는 가능한 표현이며 3단계의 의무가 아니다. 두 축은 같은 표현을 공유할 수 있다. 의상·소재·노출·항목 수로 단계를 고정하지 않는다. 기존 노출·안전 동작을 변경하는 별도 규칙은 추가하지 않았다.

## 설정과 시각 요구의 소유권

`sensual=3, fetish=3` 같은 순수 설정 구간은 의상 증거 없이 검증된다. 그 구간이나 그 안의 파라미터명만을 근거로 코르셋·끈·고리를 필수 앵커에 등록하면 정규화와 감사에서 거부된다.

설정과 시각 요구가 섞인 경우 설정 앞뒤의 시각 구간을 각각 보존한다. 예를 들어 `sensual=3, her red scarf; fetish=3, she waves`에서는 스카프와 손짓의 근거가 모두 필요하다. 파생된 구간은 원래 요청의 정확한 위치를 유지하고, 의미 단언은 원래 구간 ID를 계속 사용한다. 원문·활성 구간·요청 해시는 변경하지 않는다.

이미지에 넣을 인용 문구인 `a sign reads "sensual=3, fetish=3"`는 설정으로 해석하거나 검색에서 제거하지 않는다.

이 수정은 설정을 의상의 필수 보존 근거로 오인하는 경로를 차단한다. 일반 자연어 요구와 그 시각화가 의미상 일치하는지는 여전히 별도의 작성·검토 판단이 필요하다.

## 검색과 데이터 보강

초기 초안은 계속 후보 데이터와 분리한다. 이후 검색은 다음과 같이 변경했다.

- 요청 앵커에 해당 근거가 있을 때만 행동·관계·상황 등을 담은 짧은 질의를 최대 두 개 추가한다. 설정 대입문은 검색에서 제외한다.
- 장면의 요청어와 겹치는 후보에 제한적인 우선순위를 준다. 출처 ID·신규 여부·축별 회원 태그로 우대하지 않는다. 점수는 장면 적합성의 증명이 아니다.
- `fetish`라는 축 이름만으로 후보를 소재 디테일로 분류하지 않고 실제 영향 차원을 사용한다.
- 역할·배경·관계·타이밍 효과는 명시적으로 열린 차원에서만 허용한다. 기존 속성 잠금과 후보의 전체 효과·적용 조건은 유지한다.
- 최종 선택에서는 후보의 짧은 이름을 완성된 초안과 바로 비교하지 않고, 같은 강도에서 구체적으로 적용한 모습을 비교하도록 안내한다.

새로운 대량 수집 대신 기존 후보 24개에 긍정적인 한·영 의역 48개를 추가했다. 행동, 사물 선택, 작업 관계, 표정, 자세, 착용, 질감 등을 포함한다. 원래 시각 의미·효과·맥락 조건은 유지했다. 전체 231개 신규 후보를 모두 정제했다는 뜻은 아니다. 추가 내용은 [의역 목록](positive-paraphrases.json)에 보존했다.

전체 9,650개 검색 항목 중 이 24개만 텍스트와 벡터가 바뀌었음을 이전 인덱스와 비교했다. 현재 사전 해시·BM25F 파생물·모델·차원·샤드 해시 검사를 통과했다. 이전 인덱스 세대는 삭제하지 않았다. [인덱스 검증 기록](index-verification.json)

## 검증

- 현재 resolver CLI를 실행해 실제 3/3 작성 안내와 v2 스냅샷을 보존했다. [작성 안내](cli-smoke/authoring-brief.txt), [스냅샷](cli-smoke/creative_controls.json)
- 설정 구간·허위 의상 앵커·혼합 요청·속성 보존·구 이름 거부·스냅샷 결속·대안 검색·연구 통합·최종 작성 정책·v5/v6·CLI를 포함한 관련 테스트 104개 통과(중복 실행 제외).
- 설정 구간이 포함된 요청에서 코어 정규화 → 후보팩 → 최종 프롬프트 감사까지 통과했다.
- 사전 메타데이터 검사, skill-creator의 스킬 형식 검사 통과.
- 전체 생성기 검사 묶음은 변경과 무관한 오래된 장면의 전수 평가까지 포함해 중단했다. 통과로 계산하지 않는다. 대신 관련 v5/v6 코어·축 범위·CLI 회귀 검사와 변경된 기본값 단언을 직접 실행했다. 조합 검사 한 건은 무작위 선택이 항상 특정 소재를 포함한다는 테스트 전제를 바로잡고 재실행하여 통과했다. 실제 조합 규칙은 변경하지 않았다. [검증 내역](verification.json), [해당 진단](combination-regression.json)

위 검사는 설정 전달, 검색 가능성, 출처와 잠금, 감사 경로를 검증한다. 새 정의가 초안의 감각이나 의상 다양성을 얼마나 개선했는지, 실제 이미지에서 얼마나 매력적으로 구현되는지는 아직 측정하지 않았다. 초기 작성 비교와 이미지 비교를 실행한 것으로 간주하지 않는다. 이번 적용에서 새 이미지를 생성하지 않았다.
