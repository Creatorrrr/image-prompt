## 무엇이 달라졌나

의상·재료 이름에 치우친 기존 공급에 손과 물건의 접촉 관계, 착용 중간 단계, 작업 능력과 결과의 연결, 개인 물건을 향한 주의, 작은 실수의 수정, 표정과 행위의 관계 등을 추가했다. 어느 항목에도 `sensual_editorial`이나 `fetish_fashion`이라는 입장권 태그를 새로 붙이지 않았다. 기존의 문맥 검색과 선택 후 해석을 그대로 사용한다.

부분 일치와 동등한 의미를 구별했다. 예컨대 치아의 립스틱 자국을 닦는 행동은 빨간 립스틱 색상의 별칭이 아니고, 일반적인 가는 초커는 반복 고리가 있는 타투 초커와 다르다. 일반 펜슬스커트도 특정 색 블라우스와 아이보리 치마의 조합으로 합치지 않았다. 차를 따르기 전 멈춘 손을 커피를 따르는 동작의 동의어로 추가하지 않았다.

`existing_slot_context_extensions`는 기존 슬롯/ID에 검토된 의역과 선택적인 문맥 설명만 덧붙인다. 라벨·효과·속성·가드를 덮어쓰지 못한다. 기존 후보를 생성하는 별도 빌더를 다시 실행해도 이번 보강은 별도 확장 파일에서 유지된다.

긍정적인 시각 관계는 라벨·의역·개념·관계 필드로 검색된다. 일상적 해석, 반례, 성적 의미에 대한 추정, 한계와 출처 설명은 `contextual_usage` 또는 원본 연구 자료에 있으며 긍정 검색 텍스트로 투영하지 않는다. 내면의 욕망이나 보편적인 매력은 픽셀에서 판정하지 않는다. 이 구분은 복장이나 노출 수준의 새로운 기본 규칙이 아니다.

231개 중 213개는 변경 차원만 보면 현재 성인 표현 증강 범위 안에 있다. 나머지 18개는 `setting` 변경을 포함해 일반 후보 사전에는 존재하되 해당 증강 경로에서는 제외된다. 잠금을 통과시키려고 효과를 삭제하지 않았다. 213개도 장면 적합성·속성 잠금·다른 가드·검색 순위를 별도로 통과해야 한다. 고정된 장면에서 동작만 바꾸는 후보는 필요한 인물·물건·의상이 이미 있을 때만 적용한다. 얼굴·머리·몸·의상은 실제 변경하는 속성으로 판정하며 모든 신체 특징을 일괄적으로 정체성 변경이라고 분류하지 않는다.

저장된 기본값은 `sensual_editorial=1`, `fetish_fashion=0` 그대로다. 이번 세 이미지 실행에만 이전 비교 조건인 `3/3`을 사용했다. 요청 텍스트나 코어에 합성 테스트의 창작 세부를 사용자 직접 발화로 섞지 않았다.

## 검증의 경계

[로컬 검증](local-validation.json)은 데이터·계약·검색 투영의 검사다. 관련 단위 검사 70개와 사전 메타데이터 검사가 통과했고, 기존 조합 2,118회에서 선언된 모순 위반은 0건이었다. 장면 구조 112개 경로 검사와 9,650개 문서의 최종 인덱스 일치 검사도 통과했다. [어휘 검색 관찰](lexical-retrieval-results.json)은 반환된 89개 평가안에 들어 있는 178개 언어별 문자열을 BM25F로 조회한 진단이다. 63개 문자열에서 연결된 후보가 상위 20개에 있었고, 87개에서는 없었으며, 28개는 런타임 대상 자체가 없다. 일부 문자열은 촬영 요청이 아니라 검색 비교 등 검증 절차의 설명이다. 이 숫자는 평가안의 전체 행동 통과율도, 실제 하이브리드 후보팩의 성공률도 아니다. 제안된 기대 결과를 실행 성공으로 바꾸지 않았다.

세 이미지 테스트는 각자 독립적으로 고정한 컨셉·코어, 실제 하이브리드 후보팩, 최종 프롬프트, 생성 요청, 저장 이미지와 픽셀 검토를 별도 기록한다. 기본 프롬프트에 이미 있던 특징과 후보를 보고 새로 추가하거나 정교화한 특징을 구분한다. 세 사례만으로 보편적인 매력 향상이나 원인 효과를 입증하지 않는다.

**이미지 3장 생성은 완료했으나 새 후보 활용 검증은 실패했다.** 새 후보 231개 중 212개가 각 축의 검색 대상에 들어갔지만 세 후보팩 모두 최종 새 후보 노출이 0개였다. 기존 귀 장식 후보에 붙인 새 문맥 하나만 선택됐다. 이미지의 기본 관찰 기준은 정비소 2/5, 여객선 4/5, 분장실 3/5였고, 모든 기준을 충족한 사례는 없다. 부분 관찰은 실패로 계산했으며 이는 미적 품질 점수가 아니다.
