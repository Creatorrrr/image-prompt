# 격자 차폐 그림자의 선언된 대안 복구 — DATA 23

원래 연구·정의·후보·렌더 게이트는 잎, 슬랫, 격자 차폐물을 허용했지만 필수 구성요소와 증거는 잎/슬랫만 허용했습니다. EN/KO 격자 구성요소, 개념어, 증거 대안을 각각 추가한 4개 문자열의 추가형 수정입니다. 기존 앵커와 5개 필수 관계·게이트·최소 증거량은 유지했습니다.

## 실제 소비 경로 검증
- 동일한 고정 11개 입력으로 전후 실제 V6 CLI 모두 성공
- 전체 구성 감사는 BEFORE 26개, AFTER 28개가 각각 고정 기대 결과와 일치
- 정확 요청 EN/KO 2건은 격자 앵커 부족 실패에서 통과로 변경
- 구성요소 기반 EN/전부 한국어 2건은 실제 공개 선택 후보가 없음→노출됨으로 변경. 그 후 실제 노출 ID만 선택한 2개 전체 구성 감사도 통과
- 이전에는 후보가 없어서 이 2개 선택 감사를 실행하지 않았음. 28쌍의 전후 실행으로 표현하지 않음

- 구성요소 누락 20개, 증거 필드 누락 5개, 잘못된 관계 5개 및 프롬프트 문자 그대로의 결합 검사는 거부 유지

한국어 구성요소 팩에서 기존 선택 의미 `pc_pc27_owner_relation` 하나가 빠졌습니다. 이 후보는 대칭 건축물 속 비대칭 팔다리/고개와 얼굴 초점을 요구하지만 고정 요청은 사람이 없는 방의 회벽 두 면입니다. 기존에도 선택하지 않았고 이 사례의 요청 관계를 잃지 않습니다. 교체와 원본 후보를 보존하며 전체 순위 품질 향상을 주장하지 않습니다.

## 범위와 한계

중요하게, 정규 앵커를 부정하는 문장도 기존과 새 literal checker를 통과할 수 있습니다. BEFORE의 기존 부정 앵커와 AFTER의 기존/격자 부정 앵커 결과를 보존합니다. 문자열 감사 통과가 실제 차폐·기하·이미지 충실도를 증명하지 않으며, 의미 모순 처리는 별도 런타임 과제입니다.
