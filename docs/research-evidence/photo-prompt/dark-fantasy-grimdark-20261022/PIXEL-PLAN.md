# 이미지 평가 계획 — NOT_RUN

이번 연구에서는 이미지를 생성하지 않았다. 아래는 후속 반영의 가시 품질을 검증하는 제안이다.

## 첫 비교: 12개 사례 × 3 arm = 36장

| 사례 | 반드시 같은 시야에 남길 관계 | 가까운 오답 |
|---|---|---|
| D02 묘실 | 상부 바닥/하부 방/실제 연결 계단 | 별개 두 방 콜라주, 요청 없는 도해로 변경 |
| O01 성유물함 | 용기/창/그 창 너머 내용 | 금속 손모양 함 자체를 유해로 판정 |
| O03 향로 | 손/위 고리/각 세 사슬의 양끝/용기/연기 출발 | 한 사슬 분리, 다른 촛불의 연기 |
| O04 가고일 | 입 출수구/연속 물길/벽 바깥 낙하 | 단순 괴물 조각, 뒤쪽 폭포 |
| D13 상대 규모 | 성인/석재 벽/같은 지면 | 원근에 의한 작은 전경 모형 |
| R02 자원 접근 | 서기/장부/잠긴 곡물/기다리는 노동자 | 이 외형으로 노예 신분을 통과시킴 |
| R07 수호 | 괴물/피란민/그 괴물이 든 방패/방패에 박힌 화살 | 화살이 살에 박힘, 위협 행동으로 읽힘 |
| M06 융합 | 두 독립 몸/연속 조직/양쪽 접합 | 포옹, 옷으로 연결, 한쪽 접합 가림 |
| M07 생체 갑옷 | 판 안쪽/유기 접점/같은 착용자 피부 | 외부 장식, 다른 사람 피부, 기존 hollow 의무 소실 |
| M08 생체 건축 | 석재 문틀/연속 유기 내피/조직 경첩 | 덩굴이나 돌 리브 장식 |
| F01 명암 | 볼의 부피를 돌아가는 명암 변화 | 검은 실루엣·검은 필터 |
| F02 테네브리즘 | 화면의 어둠 우세/같은 성인의 국소 얼굴·손 | 전반 저노출, 실제 관계가 안 보임 |

각 사례에서 A는 독립 core의 작가적 기준선, B는 현재 검증 데이터로 구성한 결과, C는 staged 보강 데이터로 구성한 결과다. 세 arm은 같은 request/core/락/배제/컨트롤과 매체, 동일 모델·버전·크기·참조 조건을 유지한다. 기준선을 먼저 작성·고정하고 후보를 조사한다. 공통 core가 이미 요청자의 명시 의미를 포함해야 하며, 이를 약하게 만들어 C만 유리하게 하지 않는다.

한 실행에서 다음을 따로 기록한다.

1. **데이터/선택:** 실제 source/CID/RID/역할, 후보가 baseline에 추가·변경·삭제한 의미, 완전 의무, 선택하지 않은 대안과 이유.
2. **프롬프트/런타임:** 요청·core·데이터·pack·정확한 prompt/negative·reference hash 및 모델 요청 receipt. 메타데이터 합격을 픽셀 합격으로 승격하지 않는다.
3. **원본 픽셀:** 카드의 각 성분과 관계를 native scale에서 직접 본 뒤 visible/partial/unobservable 판정. 다중 endpoint는 전부 함께 보여야 한다. partial_is_fail.
4. **전체 장면:** 장르/정서의 인상, 행동과 반응의 이해, 시각 위계, 접점이 잘 보이도록 바꾼 구도가 장면을 어색하게 만들었는지 평가. 소품 수가 많다고 좋은 사진으로 판정하지 않는다.
5. **별도 판단:** 라벨을 가린 선호 비교와 사용자의 수용. 기술 구현과 취향은 각각 남긴다.

R02의 픽셀 gate는 자원 접근 정황에 한정한다. 노예제·강압·동의·실제 악취·시간 변화·영구 불사·관객 감정은 픽셀 PASS 항목으로 만들지 않는다. 의상이나 신체 외형에서 비가시 의미를 ‘그럴듯하다’며 통과시키는 것을 별도 실패로 기록한다.

첫 36장은 비용을 제한한 탐색 비교다. 한 장의 확률적 결과로 통계적 우위를 주장하지 않는다. 실행 전에 반복 조건을 고정하고, 효과가 불명확한 관계에는 같은 12사례를 각 arm 한 번 더 실행하는 36장 확장을 제안한다. 총 72장 역시 독립 표본/통계 검정 없이 일반적 우위를 입증하지 않는다. 추가 생성은 합의된 후속 범위에 따른다.

실패는 가림·owner 혼동·누락·매체 변경·의미 과잉·장면 약화로 분리한다. 같은 입력/seed 재현이 지원되지 않는 runtime이면 그 한계를 기록한다. 프롬프트가 바뀐 뒤에는 이전 리뷰 hash/receipt를 재사용하지 않는다. 호출이 차단되거나 결과가 없으면 그 사실을 남기고 몰래 다른 표현/모델로 우회하지 않는다.
