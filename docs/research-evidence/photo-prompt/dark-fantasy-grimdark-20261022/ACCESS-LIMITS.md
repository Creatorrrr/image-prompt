# 접근 범위와 남은 불확실성

- 원 대화 read_thread 결과와 preview가 모두 20,000자에서 잘렸다. 같은 ID의 로그인된 Chrome 화면에서 16개 용어 표 247행과 조합 표 7행을 읽었다. 마지막 어휘 Forsaken과 마지막 조합 ‘어두운 세계의 희망과 저항’을 확인했다. seeds.txt는 표의 항목명을 옮긴 것이다. 대화의 인용번호/기존 설명을 새 출처의 검증 결과로 재사용하지 않았다.
- Cambridge는 공개 Summary만 읽었다. 요약에서 인용한 기존 정의와 그 정의에 대한 저자의 이견을 구별한다. 유료 장 전문을 읽었다고 주장하지 않는다.
- SFE의 dark_fantasy 경로는 429였다. 이 실패 경로는 SOURCES.tsv의 46개 근거 수에 포함하지 않았다. Dying Earth의 실제 읽힌 entry는 별도로 포함했다.
- Paris ossuary 페이지는 검색에 노출된 공식 본문 설명을 읽었지만 직접 open은 실패했다. 상세 시설 형태·모든 시대의 catacomb 구조를 그 검색 결과만으로 확정하지 않는다.
- CCI 금속과 NASA 월식은 공식 페이지의 검색 노출 본문 대목을 읽은 범위를 적었다. 화학/보존 처치·천문 관측을 직접 수행하지 않았다.
- OHCHR/UN의 genocide 경로 open은 실패했고 근거 수에 넣지 않았다. 해당 항목은 원 대화 개념의 비추론 경계로 남겼으며 법률상 판단 기준을 구현하지 않는다. 구체적인 법적 분류가 필요해지면 정확한 현행 원전을 별도로 확인해야 한다.
- NCSF는 기관 페이지와 연결된 1페이지 Best Practices PDF 텍스트를 읽었다. 동의의 의미 구분을 위한 자료이며 법률 적용이나 실제 당사자 동의의 증거가 아니다.
- Met·Historic England의 작품/사물 설명과 BFI 비평의 해당 대목을 읽었다. 원본 작품 전체 픽셀·장편 영화·원자료를 직접 분석한 것으로 보고하지 않는다. 원격 이미지/영상을 내려받거나 재배포하지 않았다.
- Wight, draugr, lich 등은 어휘/원전 맥락이 다른 사례를 구분한다. D&D는 읽은 legacy 2014 페이지 범위다. 현재판 전체 규칙이나 다른 게임에 일반화하지 않는다.
- 46개 출처가 247개 개별 정의를 독립 검증했다는 뜻은 아니다. 자료는 개념군·주요 구분·판정 한계를 뒷받침한다. 구체적인 geometry/카메라/소품 배치는 저술한 연구안이다. Oubliette 역사, Goetia 문헌, abjection 원전 이론, 팬덤 분류의 범위는 추가 근거가 필요하다.
- exact-field lexical audit의 0건은 의미 부재를 입증하지 않는다. 실제 검색/role/native source-unit/최종 프롬프트/픽셀/사용자 선호의 검증은 수행하지 않았다.
- 다른 작업이 진행 중이라 조사 중 manifest 모듈 수와 설치 포인터가 변했다. 기존 파일을 덮거나 되돌리지 않았다. BASELINE은 시작점, corpus audit은 그 읽기 시점, runtime check는 별도 의존성/recorder 검사다. 반영 시작 시 다시 고정해야 한다.
