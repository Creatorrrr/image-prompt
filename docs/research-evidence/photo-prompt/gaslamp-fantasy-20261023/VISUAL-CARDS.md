# 시각 의미 카드

상위 장르에서 자동 활성화하지 않는다. `still`은 한 가시 상태의 실현, `proxy`는 비가시 의미의 일부만 보이는 저술 장면, `context`는 가시 후보를 만들지 않는 문맥이다. 출처가 구체 장면의 역사적 표준형을 인증하는 것은 아니다.
