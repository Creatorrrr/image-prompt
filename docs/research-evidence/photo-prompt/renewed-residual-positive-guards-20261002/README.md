# 남은 긍정 대안의 자기 제외 충돌 3곳

기준 커밋: `99ebda65bab0efbf6476ce222ab40391494dc25f`.

1,496개 프로필의 성분 대안·의역 9,989개를 검사하고 실제 소비자에서 확인한 3개 문자열만 교정했다.

- 유령 정체성 프로필의 한국어 긍정 성분이 홀로그램을 부정하면서도 같은 제외어에 걸리던 문제: 장면 기하, 생전 인물과 연결된 불가능한 현현과 국소 결과를 긍정적으로 설명
- 그랑 부부의 지역 형식 대안이 다른 의복 명칭을 부정하면서 그 제외어에 걸리던 문제: 선택한 지역 형식의 재단·레이어·장식을 유지하는 표현으로 교체
- 교체가 불가능한 생활 물품 수선의 완전한 긍정 의역이 장식적 손상을 부정하면서 그 제외어에 걸리던 문제: 계속된 관리라는 기존 성분 문구를 온전히 보존

제외어·수치 기준·성인 조건·다른 대안은 모두 그대로다. 유령의 물리적 고체성이나 의복의 보편적 분류를 새로 단정하지 않았고, 낡음만으로 빈곤을 추론하도록 넓히지 않았다. 독립 리뷰에서 수선 의역의 기존 관리 성분을 끊는 초안 표현을 바로잡아, 최종 세 긍정 묶음 모두 성분 매칭으로 통과한다.

## 무엇이 개선됐고 무엇이 그대로인가

데이터가 내보내는 긍정 문구가 스스로 제외되는 충돌을 없앤 것이다. 같은 사용자 질의의 검색 성능이 좋아졌다는 결과는 아니다.

실제 메타데이터 검증을 거친 전후 인덱스로 질의·맥락·성인 여부·필드를 고정한 115개를 재실행했다. 대상 자격·상태·매칭 근거는 전부 동일했다. 새 문구는 이전 인덱스에서도 이미 통과했고, 이전 문구를 사용자가 그대로 쓴 경우는 수정 후에도 거절된다. 사용자 문장의 부정 표현을 이해하지 못하는 일반 런타임 문제는 해결하지 않았다. 제외어 대조 84개도 모두 비활성 상태를 유지했다.

전체 점수는 코퍼스 통계 변화로 115개 모두 달라졌다. 후보 ID/순서는 111개에서 같고 부부 관련 대조 4개에서 하위 순위가 달라졌다. 3개는 말단 두 후보의 교환이고, 안쪽 레이어를 뺀 대조에서는 8위 pc_pc27_owner_relation이 y2kr_chainmail로 교체됐다. 네 경우 모두 부부 대상은 계속 없거나 비활성이었다. 이를 새로운 후보 품질 개선이나 전체 검색 무퇴보로 주장하지 않는다. [정확한 순위·점수와 고정 질의 결과](identical-query-results.md)를 제공한다.

## 검증과 제한

독립 실제 인덱스 검사 115개와 추가 고정 질의 쌍 대조, 사전·인덱스 검증이 통과했다. 관련 34개 테스트 중 33개 통과. 기존 픽셀 근거 테스트 1개는 PNG 3개가 현재 체크아웃에 없어 하위 사례 3개가 실패했다. 테스트와 해당 픽셀 고정 자료는 이전에 같은 실패를 재현한 기준과 바이트 단위로 동일하며, 현재 기준 Git에도 PNG가 없다. 테스트를 건너뛰거나 고치지 않았고, 기존 누락을 새 회귀 또는 영구 소실로 단정하지 않는다.

이번 단계는 실제 전체 레지스트리의 어휘 검색 검증이다. 질의 임베딩, 정상 공개 CLI 팩, 전체 구성 프롬프트, 생성 이미지의 품질 검증을 새로 수행한 단계가 아니다.

실제 벡터 3개를 갱신하고 1,493개를 보존했다. 성공 3회와 최초 실패·불확실 1회도 비용에서 빼지 않았다. 단계 보수 상한 $0.0065536, 프로젝트 누적 상한 $1.4188544 / 허용 $10이며 실제 청구 금액은 아니다. 수선 프로필은 앞서 교정한 기록이므로 고유 기록 수에 중복 계산하지 않는다.
