# 실제 이미지 검증 설계

실행 상태: NOT_RUN. 아래는 미래 실험 계획이다. 정지 이미지로 검증할 수 있는 선택된 실현만 검사한다.

각 사례는 독립적인 candidate-free baseline A, 현재 데이터의 B, 보강 데이터의 C로 비교한다. 동일 요청·해상도·도구·controls를 기록하되 각 arm의 source와 receipt는 분리한다. 도구가 공통 seed를 지원하지 않으면 지원한다고 가정하지 않고 `unsupported`로 남긴다. 현재 연구를 읽은 후 작성한 문장을 후보 독립 baseline이라고 부르지 않는다.

| 군 | 장면과 연결 카드 | 반드시 실제로 보일 것 | 실패 또는 미확정으로 남길 것 |
|---|---|---|---|

첫 배치 제안은 12군 × 3 arm = 36장이다. 모든 200개 개념의 이미지 검증은 아니다. 추가 자원이 있으면 다음 12군을 확장한다: 무안면/천 가림의 별도 2군, 실제 분신과 반사의 구분, 인공 하늘, 같은 지면의 거대 식물, 밑면이 보이는 부유 지형, 침수 복도, 물 빠진 풀, 읽히는 번호 반복, 광각과 심도의 분리, 재질/용도의 찻잔, 임상 시설 정상 대조군. 이 경우 추가 36장이고 누적 72장 제안이다.

평가자는 실제 저장 원본을 먼저 보고 각 gate를 `visible / partial / unobservable`로 기록한다. 설명이나 source card를 읽고 보이지 않는 것을 보인다고 처리하지 않는다. 필수 owner와 모든 연결이 보여야 전체 gate를 통과한다. 작은 글자·접속부는 원본 크기, 전체 상황과 주제는 thumbnail에서도 따로 확인한다. 가림·crop·너무 작은 대상은 필요한 판정에 `UNOBSERVABLE_NOT_PASS`이며 `partial_is_fail`을 유지한다.

별도 평가 축:

- instruction fidelity: 선택한 의미·요청 락·owner·물체 상태의 충족.
- situational legibility: 장르 라벨을 가렸을 때 공간·관계가 무엇으로 읽히는지.
- comfort / unease: 편안함과 불안함을 각각 기록. 하나를 다른 하나의 역점수로 계산하지 않는다.
- artistic preference: 구도·분위기·관심·전체 선호. 구조 검증 결과로 대체하지 않는다.
- requester acceptance: 사용자가 실제 판단하기 전에는 pending.

오디오 13개, sequence 10개, 감정·기억·동의·진단·원인·생사 같은 해석층에는 정지 사진 PASS를 만들지 않는다. 필요한 매체를 쓰지 못하면 미검증으로 남긴다. moderation/도구 오류가 발생한 arm도 성공 분모에서 조용히 빼지 않고 `blocked_unscored`로 별도 집계한다.
