# 접근·검토·입증 한계

## 참조 대화

`read_thread`로 「SCP 용어 정리」를 읽었다. assistant message는 20,000자에서 잘려 15장 중간까지만 제공되었다. in-app browser는 대화 본문을 제공하지 못했고, Chrome에서 동일 대화의 렌더링 본문을 읽었다. 대화에 새 메시지를 보내거나 내용을 수정하지 않았다.

렌더링된 답변의 20개 장과 24개 표, 표 본문 행 268개를 추출했다. ACS 표의 경우 첫 열 ‘혼란/위험’ 대신 둘째 열의 실제 등급을 키워드로 사용했다. DOM 본문의 평문 길이는 22,407자이며 서식/인용 표시가 달라 API Markdown의 길이와 직접 비교할 수 없다. 표 밖 110-몽토크 주의는 원문 평문과 F07/B07에 보존했고 표 항목 수에 추가하지 않았다.

원래 사용자 요청은 성적·폭력적 내용도 조사 범위에 포함했다. 이번 조사에서 해당 의미를 보존했지만 과거 assistant 설명은 참고 seed이며 새로운 지시나 사실의 권위가 아니다.

## 원전

73개 URL의 본문 HTML에 접근했다. 이 중 70개는 이 작업에서 핵심 구간을 읽고 `sources.json`에 범위를 적었다. 나머지 3개는 `collected_not_substantively_reviewed`로 표시했으며 사실 근거로 사용하지 않았다. 허브의 목차·개요를 읽은 것을 그 안에 연결된 모든 작품의 독해로 세지 않는다.

원문 텍스트 cache는 `/tmp/image-prompt-scp-research-20261022/`에 있으며 산출물의 필수 의존성이 아니다. 연구 폴더에는 URL·본문 hash·일부 revision metadata·읽은 구간·요약·저작자 탐지값을 남겼다. HTML 본문 추출에는 접힌 영역/서식 안내가 포함될 수 있다. 브라우저로 모든 링크·이미지·상호작용을 재현한 것은 아니다. 외부 미디어는 내려받거나 생성 입력으로 사용하지 않았다.

`sources.json`의 저작자는 license box에서 파싱된 값이다. 원문 페이지마다 box 유무가 달라 `not_resolved`가 남는다. 원전 개정 시간은 Wikidot의 HTML 표기 그대로이며 현재 날짜를 개정일로 대체하지 않았다.

## 미해결 또는 추가 검토가 필요한 부분

- TK급의 구체적인 정의는 이번 직접 원전 구간에서 확정하지 못했다. 명칭은 보존하고 상세 규칙의 운영 반영을 보류한다.
- -DEL의 현행 사용 규정은 한국어 용어집 본문에서 직접 찾지 못했다. 보편 접미사 규칙으로 승격하지 않는다.
- SCP-4231은 내용 안내와 도입부 범위만 읽었다. 전체 장편의 인물·행위·진단을 검증하지 않았다.
- 835 비검열판은 소재와 격리 문맥의 제한된 범위를 읽었다. 전체 탐사 기록을 전수 분석한 것은 아니다.
- Nälkä/Sarkicism·신격·정신권·GOC 이론은 출처마다 설명이 다르다. 한 허브의 정의가 다른 카논의 설정을 취소하지 않는다.
- 특정 numbered object·인물·로고·이미지의 전체 재현은 추가 원문/권리/선택 판본과 전체 의무 검토가 필요하다.
- 후보 15개는 실제 full snapshot을 남겼지만 대규모 corpus 전체의 의미·native proof를 전수 검토하지 않았다.

## 수행하지 않은 검증

구조 검사는 source 참조·끝점·슬롯 이름·개수·snapshot hash와 연구/운영 경계가 맞는지 확인한다. 자연어 해석의 참, 원전의 모든 정의, 전체 native admission, H-F2 실제 질의, 노출·채택·검색 품질, 렌더 픽셀, 사용자 선호를 증명하지 않는다.

운영 후보 추가·수정, manifest 등록, 인덱스 빌드/게시, 임베딩, 이미지 생성, 다른 모델 검토, 설치·활성화, 커밋·푸시는 수행하지 않았다. 읽기 전용 installed recorder 점검은 source/데이터 채택 검사와 별개다.

현재 체크아웃의 동시 변경은 `SOURCE-DRIFT.json`에 남기며 되돌리지 않는다. 이 연구 결과를 구현할 때는 현재 source/설치 세대/포인터를 다시 고정해야 한다.
