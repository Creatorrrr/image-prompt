# 픽셀 평가 계획 — NOT_RUN

아래는 최초 12사례 × 3 arm, 총 36장의 제안이다. 이번 연구에서는 이미지·임베딩·다른 모델 검토를 호출하지 않았다. case는 의미 단위이며 해당 번호/단체의 모든 설정을 재현하는 계약이 아니다.

| 사례 | 카드 | 핵심 가시 판정 | 실패·미판정의 구체 예 |
|---|---|---|---|
| P01 관찰 경계 | I01 | 같은 벽의 창, 밖의 사람, 안의 받침/사물 | 창의 인쇄·반사를 실물로 판정, 다른 벽/방의 경계를 합침 |
| P02 장갑 포트 | I03 | 두 장갑이 각각 다른 포트에 부착되고 시료는 안쪽 | 장갑 하나의 입구 가림, 시료가 밖에 있음 |
| P03 문장 가림 | I08 | 인쇄 줄의 일부만 막대가 덮고 줄 앞뒤가 남음 | 검은 테두리·빈 줄을 검열로 판정 |
| P04 방호복 연결 | M01 | 후드/면창/몸통/커프의 선택된 접속 | 후드가 몸통과 분리, 손이 다른 인물 소유 |
| P05 차폐된 도상 | C02 | 패널의 실제 도상 면이 불투명 판에 완전히 가림 | 머리 방향만으로 도상을 봤다고 판정 |
| P06 앰풀과 캡 | C05 | 봉합 목, 액면, 독립 캡/주사기 | 결정 스톰글라스 대체, 외형으로 약효 승인 |
| P07 계측 장치 | R01/R02 중 하나 | 선택한 기기와 실제 화면/배선 관계 | 빛나는 몸을 계측 화면과 혼동, SRA 효능 판정 |
| P08 문턱의 연속 | R03 | 문 네 테두리, 양쪽 공간과 문턱의 접속 | 벽 사진·거울을 통로로 판정 |
| P09 ARI 매체 | T04 | 전원·헤드셋·처리부와 배선, 선택했다면 화면 안 의사색 | 기기의 옆면 가림, 육안 장면에 오라를 투사 |
| P10 보철의 소유 | F02 | 같은 팔의 피부·커프·보철 양쪽 접점 | 별도 금속 장식, 다른 사람 팔로 연결 |
| P11 두 몸의 조직 다리 | B01 | 독립 몸 둘과 다리의 양끝 연속 | 한 끝점 가림·몸 겹침·끈 대체 |
| P12 매장과 무안 인물 | E08 | 진열대 깊이, 얼굴 특징 부재, 상·하의의 소유 | 초점 흐림을 무안으로 판정, 깊이로 무한성 승인 |

각 case는 실제 요청을 독립적으로 해석하고 baseline/core/controls를 후보 열람 전에 고정한다. A는 독립 장면, B는 기존 후보, C는 보강한 staging 후보다. 새 자료의 실제 노출·선택 ID와 선택 문구를 기록하며 공통 core와 사용자 제약을 유지한다. 비교를 위해 사용자 요구를 삭제하거나 다른 성적/폭력적 내용으로 바꾸지 않는다.

가능한 provider 설정은 함께 기록하되 고정할 수 없는 seed·모델 개정·서버 차이를 숨기지 않는다. 동일한 prompt hash는 동일 이미지나 동일 조건의 보장이 아니다. 원본 파일·해상도·SHA, provider/model/runtime, 최종 파라미터, returned/error 상태를 남긴다.

판정은 `visible / partial / unobservable / BLOCKED_UNSCORED / NOT_RUN`으로 나눈다. 필수 관계의 일부만 보이면 전체 PASS가 아니다. 개념이 정지 사진으로 검증 불가능하면 `UNOBSERVABLE_NOT_PASS`다. 정책 차단은 이미지 실패 점수나 성공률의 분모에 임의 합산하지 않고 별도 보고한다.

관계 충실도와 별도로 전체 장면의 상황 이해, 주제의 존재감, 위계, 과도한 소품 설명, 시선의 설득력, 미적 선호를 기술한다. 사용자 판단은 `not_yet_received`에서 시작한다. 36장은 최초 평가량이며 통계적 일반화나 모든 SCP 개체의 native qualification을 뜻하지 않는다. 추가 반복은 설명되지 않는 실패나 비교 변동이 있을 때만 정한다.
