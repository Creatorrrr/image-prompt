## Verify without retrieval

Use Python 3.12.14 (the experiment version), a checkout/worktree at the pinned commit, and this package. From any directory:

```sh
python3 -I -B -S /path/to/package/reproduce.py --repo /path/to/pinned-checkout --evidence /path/to/package
```

Default mode checks HEAD, all pinned source hashes, package hashes/bytes, JSON syntax, raw-request equality and compact totals. It imports no project modules and runs no retrieval/CLI. A source mismatch is a hard failure. The source checkout and package are read-only.

## File purposes

- `inputs/*/raw-request.txt`: exact synthetic request bytes, including newline
- `inputs/*/request_envelope.json`: frozen scope and request binding
- `inputs/*/authorial_core.json`: final authored scene, requester locks and camera declaration
- `inputs/*/creative_controls.json`: exact per-request saved controls, no overrides
- `inputs/*/embodiment_review.json`: required final non-person review input
- `prototype-extension.json`: exact two-row proposal, including whole relations and descriptive prerequisites
- `source-pin.json`: immutable source identity and rejection of changed executable/data inputs
- `provenance.json`: original/reconstructed/fresh distinctions and archive hashes
- `verdict.json`: compact membership results, meanings, causal finding and limits
- `expected-replay.json`: archived hashes for all 24 public surfaces and bindings
- `reproduce.py`: portable read-only verification and explicit optional replay
- `verification.json`: v2 replay result, immutable identities and preserved failure history
- `manifest.json`: SHA-256, byte count and purpose of each delivered file; excludes itself to avoid self-reference

Full preview/ablation dumps, runtime stores, historical copies, intermediates and internal coordination are excluded. No staging, commit or push is part of this package.
