arm-2은 도예 작업대 장면의 첫 native 생성 1장을 보존했습니다. 프롬프트·런타임 감사는 PASS, 엄격한 픽셀 종합은 FAIL입니다. PARTIAL을 PASS로 올리지 않았고 사용자 수용은 미수신입니다.

| 사전 키워드 | 판정 |
|---|---|
| Henley | PASS |
| raglan | PARTIAL |
| cable_knit | PASS |
| rib_knit | PASS |
| cargo_pocket | PARTIAL |
| drawstring | PARTIAL |
| half_tuck | PASS |
| layer_order | PASS |

라글란의 목-겨드랑이 연결선, 드로스트링의 두 출구, 카고 포켓의 확장 거싯이 충분히 구분되지 않았습니다. 네 opt-in 의복 게이트 중 2 PASS/2 PARTIAL, 신체·접촉 게이트 5/5 PASS입니다.

새 후보 노출은 정확히 14개(프로필 8, 슬롯 5, 묶음 1), 채택은 5개(묶음 1 및 opt-in 프로필 4)입니다. 초기 중간 보고의 15개를 목록 기준 14개로 정정했습니다.
