# 재시험 원인 분석과 보완

이번 검증은 등록, 검색 순위, 표본 노출, 의미 적합성, 최종 문구 기여, 실제 도구 입력, 원본 픽셀을 구분한다. `native chosen=0`은 곧바로 material inspiration=0을 뜻하지 않으며, 기존 초안에 이미 있던 특징은 새 데이터 전이로 세지 않는다.

## 확인한 원인

1. 이전 세 장면의 슬롯 검색에서는 신규 87CID가 rank-32 창에 없었다. 창에 있던 자료도 표본으로 전달되지 않을 수 있었다. B에 전달된 V060의 17층 컨테이너는 예비 바퀴 장면과 맞지 않아 적절하게 거절됐다. 검색 부재, 표본 누락, 의미상 거절을 한 원인으로 합치면 안 된다.
2. 최초 실제 주제 검색에는 컨셉 선정·첨부 사용·생성 등 실행 지시가 섞였다. 첫 수정 후에도 인용한 대화 제목의 ‘용어 조사’가 남아 조사 봉투·해안 조사·보험 조사 등의 의미로 검색됐다. 최종 입력은 실제 이전 사용자 원문의 정확한 `해병문학` 부분만 인용한다. 전체 원문·참조 의미·배제·초안·슬롯 질의는 보존한다. 단어를 자동 삭제하는 필터를 넣지 않았다.
3. 초기 데이터에는 세 관찰 구성을 풀어 쓴 영어 설명은 있었지만, 짧은 영어 사물명은 빠진 경우가 있었다. 예를 들어 모자의 패널·챙·머리 관계만으로는 자연스러운 군용 모자 질의와 충분히 연결되지 않았다. 87개 자료에 기존 관찰 계약을 가리키는 영어 명칭을 보강했다.
4. 노출된 자료도 항상 채택할 수 있는 것은 아니다. 연령 등 닫힌 차원, 기존 소유자·조건, 장면에 없는 공구, 완전한 복합 계약, 매체 차이 등을 검토해야 한다. 자격 표지 하나만으로 예술적 부적합을 선언하지도, 일부 속성만 가져와 복합 계약을 채택한 것처럼 말하지도 않는다.
5. 이전 픽셀 실패는 오른손/왼손 역할 반전, 깃발에서 바퀴로 이어지는 그림자의 불명확성, 물과 선체에 가려진 보트 지지면이었다. 보이는 물체 수만으로 연결·지지·전체 경로를 입증할 수 없었다.

## 적용한 변경

- 후보 87개에 정확한 영어 명칭을 추가했다. 기존 한영 시각 명제, 모든 구성·소유자·관계·혼동 경계·필수 픽셀 게이트·조건·효과·기존 출처를 보존했다. 진단 247개는 그대로이며 긍정 검색에 넣지 않았다.
- 시각 의미 자료에 인물 기준 좌우와 화면 위치 구분, 전체 연결의 동시 가시성, 지지면, 실제 그림자 수신면을 검토하는 안내를 추가했다. 안내는 자격 증명이나 게이트 완화가 아니다.
- 최신 스킬의 정확한 요청 구간 분리와 독립 감사자 투영을 실제 설치 런타임에서 검증했다. 스킬에 업무가 섞인 대화 제목에서도 정확한 주제 부분만 인용하도록 명시했다. 새 회귀 3개와 기존 범위·소유권 회귀 10개가 통과했다.
- 작업 소스의 인덱스를 별도로 재구축하고 120개 입력 파일이 그대로일 때만 활성화했다. 동시 변경을 감지한 첫 활성화는 중단했으며 타 작업의 소스를 덮어쓰지 않았다.

## 통제 비교

`retrieval-ablation.json`은 같은 전체 긍정 코퍼스·검색 구현·질의에서 87개 자료의 이름/검색 문서/실제 로컬 임베딩만 교체한 오프라인 비교다. 반사실 인덱스는 실제 설치 버전이라고 주장하지 않는다.

|질의 묶음|질의 수|신규 후보 출현 합계, top-8|신규 후보 출현 합계, top-32|
|---|---:|---:|---:|
|이전 실제 질의|12|0 → 7|4 → 18|
|이번 독립 슬롯·초안 질의|12|0 → 3|0 → 5|

이는 질의별 후보 출현 합계이며 독립 holdout 정확도나 채택 성공률이 아니다. 특정 자료를 찾는 개발 질의에서도 개선이 균일하지 않았다. 원래 낮은 6개 순위는 32→4, 41→38, 8→1, 10→1, 78→77, 427→13이었다. 새 자료라는 이유의 가산점·강제 선택·표본 반복은 없다.

## 독립성과 절차 경계

세 에이전트는 서로 다른 테스트 축에서 후보 접근 전에 무작위 컨셉, 완성 초안, 현재 기본 controls, 참조 범위, 픽셀 기준을 만들었다. 최초 공식 봉투는 dispatch 전에 발행했으나 참조 구간 누락·실행 모드·새 query-scope 지원을 바로잡은 후속 봉투는 dispatch 뒤 발행했다. 이 절차상 한계를 숨기지 않는다.

첫 설치 검색(v4)에서 제목의 ‘조사’ 오염을 확인해 이미지 호출 전 공식 입력을 다시 만들었다(v5). 최초 독립 초안·controls·기존 픽셀 기준·슬롯 질의 문자는 그대로 유지하고 요청/주제 문맥/계획 해시만 다시 바인딩했다. v4 자료와 검토는 보존하며 최종 선택은 v5 발급 자료에 한정한다. 따라서 v5를 새로운 눈가림 재저술 실험이라고 부르지 않는다. 새 run의 표본 seed는 관리 절차가 새로 발급하므로 두 발급 표본의 차이를 주제 인용 변경의 단독 효과라고 주장하지 않는다.

최종 이미지 평가는 `RESULTS.md` 및 원본 파일을 기준으로 기록한다. `partial_is_fail`, `UNOBSERVABLE_NOT_PASS`를 유지하고, 일부 일반 속성의 반영과 원래 카드 전체 자격을 구분한다.
