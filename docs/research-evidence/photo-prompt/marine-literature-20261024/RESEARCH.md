# 해병문학 시각 의미·후보 데이터 보강 연구

2026-10-24 KST. 이 패키지는 상세 연구와 반영 설계다. 후보 등록, 임베딩, 실제 검색, 실행본 설치, 이미지 생성은 후속 단계다.

## 조사 범위와 자료 계층

참조한 [원래 대화](https://chatgpt.com/c/6adb70c4-3054-83ee-9ae1-fa8c2adc2c4a)는 도구에서 답변 끝부분이 잘렸다. 로그인된 Chrome에서 사용자 메시지 하나와 답변 하나의 전체 본문을 읽고 표 23개·데이터 247행을 추출했다. 13절의 장면 조합 7행과 14절의 혼동 9행까지 포함한다. 나머지 231행도 복합 용어·같은 용어의 재등장을 포함하므로 ‘독립 단어 247개’로 부르지 않는다. 대화 원문·표·보이는 출처 주소를 함께 보존했다. 출처 묶음의 `+N`에 숨겨진 모든 링크까지 추출했다고 주장하지 않는다.

이전 답변은 연구 입력이며 독립적인 사실 증거가 아니다. 외부 출처 19개를 추가 확인 또는 시도했고, 그중 15개는 본문 또는 해당 부분을 읽었다. 팬아트 모음은 캡션만 확인했으며 이미지 링크는 열리지 않았다. 국방일보와 Lightroom Academy는 검색 추출만 확보했고 Tate는 403으로 확인하지 못했다. 이 차이는 [출처 장부](SOURCES.md)에 보존했다.

장르 형성·현실 관계는 [2022년 주간경향 보도](https://weekly.khan.co.kr/article/202204011420591), 남성성과 언어 분석은 [방혜린의 2022년 비평](https://withoutwar.org/?p=19020), 실제 창작 문법은 [2021년 비공식 집필 가이드](https://gall.dcinside.com/board/view/?id=marinecorps&no=214763)를 대조했다. 비평의 해석, 익명 이용자의 규칙, 현실 조직의 사실을 서로 대체하지 않는다.

## 핵심 결론

해병문학은 ‘군인+빨강+근육’이라는 묶음으로 충분히 표현되지 않는다. 반복 인물, 비공식 위계, 자기미화하는 말, 화면과 말의 불일치, 일상 물건의 기괴한 재명명이 함께 작동한다. 그중 정지 이미지가 직접 담는 것은 물체·몸·표면·관계·인쇄된 문자다. 위계의 정당성, 자발성, 폭력의 원인, 실제 소리, 이전 장면, 인간의 정체성은 별도의 맥락이다.

따라서 `입력 개념 → 문맥/판본 선택 → 선택형 시각 대안 → 소유자·부위 → 방향 관계 → 혼동 경계 → 관찰 게이트`를 데이터의 기본 사슬로 삼는다. 출처가 쓰는 별명과 연구자가 제안한 외형을 분리한다. 96개 카드의 구체적 화면은 연구자의 제안이며 정본 설정이나 열람한 출처 이미지의 복제본이 아니다.

## 1. 현실 복식과 밈 복식

[2017년 군사전문기자의 설명](https://v.daum.net/v/20170328031045087)은 팔각모·빨간 명찰·돌격형 두발·세무워커를 실제 상징으로 다룬다. 현재 규격의 완전한 고증은 별도 과제다. 팔각모는 단순 군모가 아니라 각진 모체와 짧은 챙의 형태로 정의한다. 단일 시점에서 보이지 않는 뒤쪽까지 여덟 각을 확인했다고 판정하지 않는다. 다른 군 조직의 유사 모자도 있어 모자 하나로 소속을 단정할 수 없다.

가슴의 붉은 이름표는 `착용자 → 상의 → 적색 천 패치 → 선택된 글자`로 모델링한다. 목줄 카드·계급장·금속 배지와 섞지 않는다. 맨가슴 위 패치 변형은 운반체가 피부이므로 옷 위 명찰과 별도 대안이다. 패치의 부착 방식은 확인되지 않았으며 상처나 침습적인 부착을 만들어내지 않는다.

세무워커는 이 연구에서 발목 높이·끈·매트한 짧은 결·두꺼운 밑창의 제안으로 좁혔다. 기존 코퍼스의 긴 스웨이드 패션 부츠는 소재 단어만 가깝다. 실제 보급품을 정확히 재현하려면 시대가 지정된 실물 사진과 사양이 필요하다.

최소 복장에 대해서는 비공식 가이드가 강한 규칙처럼 말하지만 이를 전 장르의 강제 프로필로 사용하지 않는다. 붉은 색, 삼각형, 사각형, 반바지형을 각각 선택한다. V008 삼각형과 V009 사각형을 합치거나 ‘해병문학’ 한 단어에서 맨상체를 강제하지 않는다. 성인 인물의 노출 상태와 성적 표현은 별개의 축이다.

## 2. 캐릭터 이름과 선택형 외형

황근출·황룡·박철곤·무모칠·톤톤정과 기능별 인물 18행은 판본이 필요한 인물 문맥으로 보존했다. [팬아트 모음의 캡션](https://gall.dcinside.com/board/view/?id=dcbest&no=25879)에서 황근출 얼굴의 비묘사 관습은 확인되지만 하나의 얼굴·체형·의복이 정본이라는 증거는 없다. 이 조사에서는 팬아트 이미지 픽셀을 읽지 못했으므로 모히칸·두건·붉은 변신·말 얼굴의 반복도를 실증한 것으로 보고하지 않는다.

각 외형에는 일반 형태 카드가 있다. 이름을 입력하면 먼저 판본/참조/명시 외형을 선택해야 한다. 모히칸은 중앙 능선과 짧은 옆면, 검은 두건은 천과 매듭, 모니터 머리는 모니터-목 관절-몸통 연결로 정의한다. 커다란 모니터를 손에 들고 있는 인물은 모니터 머리가 아니다.

과장 근육은 어깨·상완·흉곽·허리의 관계이고, 작은 머리는 같은 몸통에 붙은 머리의 비율이다. 가까운 손만 커지는 원근법은 별도 카드다. ‘보통 체형=정상인’, ‘큰 몸=가해자’, ‘기열=의학적 상태’, ‘작은 몸=아동’ 같은 추론은 하지 않는다. 황룡의 평범한 활동복·체형은 선택형 대비의 제안이다.

## 3. 포즈는 감정·서열과 독립된 기하 구조

차렷·경례·도열·팔짱·뒷짐·허리손·가슴 내밀기 등 24개 포즈 계열을 카드 V035–V058로 나눴다. 기본 구조는 같은 인물의 어깨-팔꿈치-손목-손, 골반-무릎-발, 지지면의 연결이다.

|항목|필수 관찰|핵심 혼동|
|---|---|---|
|경례|자기 어깨에서 이어진 팔, 모은 손가락, 자기 관자/이마 끝점, 선택된 손 방향|햇빛 가림·다른 사람 이마 접촉·특정 국가 규칙 자동 추가|
|팔짱|같은 몸통 앞의 전완 교차와 올바른 양팔 소유|두 사람의 팔짱·엉킨 손·방어적 성격 확정|
|뒷짐|몸통 뒤 팔의 연속과 실제 손 연결|정면 가림을 깍지의 증거로 처리|
|내려다보기|관찰자와 별도 대상, 두 얼굴의 상대 높이, 시선 방향|로우앵글 카메라와 인물의 시선을 동일시|
|문간 배치|문틀 안 인물과 뒤 통로의 겹침|실제 감금·위협 의도·다른 출구 부재 확정|
|엎드려뻗쳐|손바닥·발끝·바닥, 지지된 몸통|운동 포즈 자체를 가혹행위로 판정|
|도게자|무릎·손·낮춘 머리와 바닥 관계|원문의 성적 노출 변형과 일반 절 자세를 동일 재현으로 보고|
|역돌격|장애물과 주자의 분리, 몸과 앞다리의 방향|한 프레임으로 과거의 도열·실제 도주·용맹 주장 증명|

V048·V055–V057은 정지 순간의 이동 대리형이다. 실제 이동 방향·전후 관계를 요구하면 T001의 순서 있는 칸과 별도 검증으로 이동한다. 얼어붙은 자세·식은땀·굳은 입은 긴장 연출에 쓸 수 있으나 내면 감정이나 질환의 관찰 게이트는 아니다.

## 4. 공간·차량·소품

성채는 직사각형 컨테이너의 골판, 수평 이음새, 창/문 개구부, 위아래 관계로 구성한다. 17층 버전은 전체 입면과 17개 구분 층을 모두 보여야 한다. ‘17층’ 자막이나 아파트처럼 높은 실루엣만으로 통과시키지 않는다. 같은 장르의 다른 성채·실제 포항 거리·실제 군 시설에 이 구조를 주입하지 않는다.

생활관은 침상·관물함·통로의 배치다. 주계는 취사 준비부와 식사 구역의 관계다. ‘주계장’은 역할/공간 문맥을 다시 확인해야 하므로 원래 표의 뜻을 그대로 확정된 표준으로 승격하지 않았다. ‘화장실 3사로’는 세 번째 칸과 번호를 표현할 수 있어도 그곳에서의 부활을 보여주지는 못한다.

오도봉고는 붉은 구형 승합차라는 제안을 기본으로 하되 제작된 팬 판본과 연식은 미확정이다. [제조사 회고](https://www.hyundaimotorgroup.com/ko/story/CONT0000000000166733)는 봉고 트럭과 승합차의 도입 시기를 구분하는 데만 쓴다. 제조사 자료가 밈 차량의 색·개조·기능을 증명하는 것은 아니다. 열린 화물 적재함의 각개트럭은 닫힌 승객실의 승합차와 다르다. 무한 수용은 정지 이미지로 참을 증명할 수 없고, 외곽과 불가능한 내부 깊이의 대리 제안으로만 남긴다.

몽키스패너는 [제조사 제품군](https://www.bahco.com/int_en/products/wrenches/adjustable-wrenches.html)의 고정 턱·이동 턱·조절 나사·자루를 구분한다. 공구를 든 인물에 폭력을 자동 부여하지 않는다. 츄라이는 식판·식사·설거지의 다의성을 보존하고, 칸 나눈 식판 형태와 세척 행위를 분리한다. 체스터는 이 사용례에서 관물함이며 영문 인명·소파로 바꾸지 않는다. 맛동산은 원래 문맥과 강제 취식의 연결을 보존하되 현행 포장·모양을 새로 조사한 제품 후보로 부르지 않는다.

## 5. 성적·폭력적·배설 관련 연구 내용의 보존

원래 대화의 7-1 성적 은어 10행, 7-2 음식명 10행, 7-3 금기 소재 10행을 모두 원뜻과 함께 보존했다. 선정성·폭력성 때문에 용어를 삭제하거나 평범한 우애로 치환하지 않았다. 이들은 `sensitive_context_diagnostic`이며 긍정 시각 검색 문구와 분리한다. [전체 지도](KEYWORD-ATLAS.md)에서 원뜻을 확인할 수 있다.

- 전우애는 일반 우애·합의된 성적 관계·위력에 의한 성폭력이라는 문맥을 구분한다. 동성사회성과 성적 지향은 동치가 아니다. [2023년 축약 용어집](https://gall.dcinside.com/board/view/?id=marinecorps&no=307254)의 거친 등식을 보편 정의로 옮기지 않는다.
- 포신·포신주머니·전우애 구멍/포신거푸집·올챙이 크림은 각각 신체 부위·체액을 치환한 말이라는 문맥을 보존한다. 문자 그대로의 대포·부속 주머니·크림을 같은 의미의 시각 후보로 등록하지 않는다.
- 전우애인형·전우애인 형(刑)·포신 검술·해병세례는 신체 대상화·성적 가혹행위·형벌·강제 편입의 맥락을 서로 구분한다. 일반 인형·장난감·세례 의식은 그 원래 의미의 동의어가 아니다.
- 해병짜장은 배설물, 수육/탕수육은 인간을 식재료로 다루는 설정이라는 원뜻을 남긴다. 갈색 덩어리나 익힌 고기만으로 배설물·인육을 확정할 수 없다. 메뉴 이름도 실제 성분의 증거가 아니다.
- 해병맥주는 소변 풀이와 다른 체액을 지칭하는 변형을 버전별로 둔다. [2024년 용어집](https://gall.dcinside.com/board/view/?id=marinecorps&no=314237)은 한 사용례다. 젤리·햄버거·특식도 지칭 대상이 고정되어 있지 않다.
- 배설 유머와 배설물 성애, 식인 모티프와 화면의 고어, 신체 변형과 그 원인, 남성 임신이라는 서사와 배의 외형을 나눈다. 비인간 성적 금기·시신의 성적 대상화도 연구 분류로 보존한다. 노출·사체 여부·행위·동의·살아 있음은 서로 대신 증명하지 못한다.

V064 빈 방 문패와 V074 덮인 용기/메뉴 카드는 제한된 문맥 전달의 제안이다. 원래 설정을 시각적으로 재현했다는 후보가 아니며 이번 긍정 후보 초안 90개에서 제외했다. 민감한 원뜻을 이런 비노출 대안으로 덮어써서는 안 된다.

악기바리·기수열외 역시 단순 먹기·줄 밖에 서기의 동의어가 아니다. [국가인권위원회의 2011년 조사](https://www.humanrights.go.kr/base/board/read?boardManagementNo=24&boardNo=602340&menuLevel=3&menuNo=9&page=326&searchCategory=&searchType=&searchWord=)를 용어의 경계 근거로 삼되 현재 모든 장병이나 부대를 일반화하지 않는다. 가혹행위의 강제성을 이미지만으로 판정하는 절차는 만들지 않는다.

## 6. 구도·문자·음향·연속성

[Adobe의 원근 설명](https://www.adobe.com/creativecloud/photography/technique/perspective.html)에 따라 실제 신체 비례와 전경 확대를 구분했다. 로우앵글은 카메라가 위를 보는 구도, 아래를 보는 눈은 인물의 시선이다. 어두운 실루엣은 가려진 명찰·손·얼굴 관계의 통과 근거가 될 수 없다. 적색 물체 세 개의 반복은 국소색이며 전체 적색 조명이나 색보정과 다른 선택형이다.

[CLIP STUDIO의 공식 설명](https://help.clip-studio.com/en-us/manual_en/540_comic/Speed_lines_and_Focus_lines.htm)을 바탕으로 평행 속도선과 방사형 집중선을 구분했다. 효과선·눈물 과장·먹선·반응 컷은 만화 매체를 선택했을 때만 사용할 수 있다. 사진을 요청한 사용자에게 장르 분위기만으로 그래픽 효과를 삽입하지 않는다.

[말풍선 공식 튜토리얼](https://tips.clip-studio.com/en-us/articles/863)은 윤곽·채움·꼬리·글자를 구분하는 데 사용했다. 말풍선 꼬리가 누구를 향하는지, 자막이 장면 바깥인지, 표어가 실제 벽의 물건인지 소유자를 분리한다. ‘악’, ‘따흐흑’, 시동음·군가·추임새는 실제 소리를 정지 이미지로 검증할 수 없다. 글자를 선택하면 정확한 문자열과 배치만 검증한다.

드리프트·리스폰·회의 길이·앞뒤 모순은 순서 있는 서사다. T001–T004는 정지 이미지 후보에서 제외했다. 원래 답변의 7개 조합은 저자가 만든 예시이며, 그 7개를 검색될 때마다 강제 적용하는 장르 번들로 등록하지 않는다.

## 7. 기존 코퍼스 조사와 실제 공백의 범위

현재 manifest의 21,883개 후보 중 긍정 검색 대상은 20,750개였다. 첫 전체 content 문자열 탐색에는 부정 예시·claim limit도 섞였으므로 발견용 기록으로만 남겼다. 두 번째 조사는 현재 `photo_global_index.fields`와 `POSITIVE_KINDS`를 직접 사용했다. 실제 임베딩 검색이나 의미 유사도 평가는 수행하지 않았다. 각 모듈을 읽은 앞뒤 해시도 비교했으며 이 스캔 중에는 변경이 없었다.

|대조|판단|
|---|---|
|일반 경례|자기 손-이마·팔꿈치 소유가 있는 기존 후보를 재사용 검토. 손바닥 변형·조건·effects는 유지|
|일반 뒷짐|기존 팔의 뒤쪽 연속과 가림 한계 보존. 후면 시점은 검증 장면에서 명시|
|일반 로우앵글|장르 독립적으로 기존 후보 재사용 검토. 새 강한 관찰 계약이 이미 구현됐다는 뜻은 아님|
|팔짱|기존 전완/어깨 관계에서 손 끝점까지 강화하려면 refine 검토|
|위장무늬|국소 천 패턴은 재사용 가능성이 있지만 상의·바지 관계나 군인 subject와 동일하지 않음|

|승합차 검색|`shared vanishing`에 `red van` 부분문자열이 들어가 소실점 후보가 적중. 차량 아님|

15개 기존 레코드와 전체 bindings를 [대조 파일](existing-source-mapping.json)에 남겼다. 어휘 검색에서 해병 고유 묶음이 0건이라는 사실은 의미가 완전히 없다는 증명이 아니다. `new` 85건은 새 정의 제안의 잠정 분류이며 구현 전 의미 중복검토가 남는다. `reuse` 3건도 현재 검색·픽셀 합격의 뜻이 아니다.

## 8. 미해결과 다음 조사

인물별 모히칸·두건·기계 머리·붉은 괴물·말 얼굴은 원래 대화의 입력과 제안 수준이며, 식별 가능한 원작자/게시 시점의 팬아트 픽셀 자료를 추가 확보해야 한다. 현재 군복의 패턴·정확한 색·보급 전투화·명찰 고증은 해당 시대의 공식 자료가 필요하다. 오도봉고의 정확한 차종과 개조도도 판본을 골라야 한다. 맛동산 현행 포장, 주계장 용례, 소수점 기수·후달쓰·쓰바쓰 같은 세부 용어 역시 전체를 새로 검증했다고 표시하지 않았다.

이 과제들은 모호한 캐릭터·브랜드를 정본으로 고정하기 전에 해결한다. 일반 포즈와 물체 관계의 제안은 먼저 검토할 수 있다. 최종 반영 순서·검증·중단 기준은 [반영 계획](IMPLEMENTATION-PLAN.md), 이미지 단계는 [픽셀 계획](PIXEL-PLAN.md)에 구체화했다.
