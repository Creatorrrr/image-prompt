# 원본 픽셀 평가 계획

> 후속 실행: 아래는 최초 연구 시점의 계획이다. 실제 등록·검색·생성 결과와 남은 한계는 [반영 및 이미지 검증 결과](INTEGRATION-RESULTS.md)에 별도로 기록한다.

상태: 설계만 완료. 생성 0건·픽셀 판정 0건. 아래의 장면은 기존 결과가 아니다.

## 독립된 전체 장면 제안

- A: 성인 인물 한 명의 선택된 모자·상의 위 붉은 패치·매트한 끈 부츠. 적당히 밝은 3/4 시점으로 모체/챙·패치/천·끈/밑창을 함께 보인다. 한글 이름은 별도 텍스트 게이트를 둔다. 성격·군 소속은 주장하지 않는다.
- B: 서로 다른 성인 두 명과 닫힌 승합차. 한 명의 자기 팔짱 또는 명시된 경례, 다른 한 명의 독립 손·시선과 차량 운전대 접점을 선택한다. 두 가지 상호 배타 포즈를 한 인물에게 섞지 않는다. 같은 사람 손·팔·어깨와 다른 사람을 분리한다.
- C: 컨테이너 탑의 전체 입면, 침상/관물함의 별도 삽입 도면 또는 독립 장면, 선언된 표어판. 정확한 17층을 선택하면 바닥-지붕과 모든 층 경계를 한 이미지에 보이게 한다. 내부와 외부를 물리적으로 섞지 않으며 매체는 사전에 선택한다.

실행 시 이 세 제안 중 각 요청의 독립적 의미를 먼저 동결한 뒤 검색한다. 본 연구의 96개 카드를 모두 한 이미지에 요구하지 않는다. 일반 대조 장면과 실패 대조는 별도의 결과 파일을 둔다.

## 판정 기록

각 arm에 요청 원문, 독립 입력, 후보 검색 영수증, 실제 채택 CID/RID, 선택 realization, 전달 프롬프트, 도구 상태, 원본 파일과 해시를 보존한다. 게이트별로 원본 전체와 필요한 crop의 좌표·관찰·판정을 남긴다. crop만 맞고 전체 이미지에서 다른 사람에게 붙었다면 실패다.

`PASS`는 선택된 카드의 모든 필수 그룹·관계·조건이 한 arm에서 함께 관찰될 때만 쓴다. `PARTIAL`은 전체 불합격이다. 보이지 않는 연결점·문자·층은 `UNOBSERVABLE_NOT_PASS`다. 원본이 없으면 `BLOCKED_UNSCORED`이며 시도 횟수만 기록한다. 평가자가 원본을 보지 않았다면 `NOT_REVIEWED`다.

V064 문패·V074 덮인 용기는 내용을 드러내지 않는다. 그 이미지로 방 안의 행위·음식 성분을 통과시킬 수 없다. T001–T004의 서사 주장은 순서 있는 자료가 필요하며 단일 이미지 평가는 해당 주장에 `UNOBSERVABLE`을 남긴다. 소리·동의·실제 신분·심리·화학 성분·사회적 의도는 픽셀 점수에 끼워 넣지 않는다.

비용이나 차단 결과를 피하려고 의미를 바꾼 이미지를 원래 사례의 성공으로 대체하지 않는다. 변경된 시도는 새로운 arm과 새로운 요청 계약으로 기록한다. 최종 사용자의 수락은 기술 판정과 별개로 남긴다.
