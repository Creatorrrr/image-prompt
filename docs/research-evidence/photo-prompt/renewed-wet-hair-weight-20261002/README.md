# 젖은 머리의 수분에 의한 처짐 대안 보존

기준 커밋: `6c3296384dae4b01812b7c63f4f4f8f9d4ed3c31`. 정상 공개 BEFORE 입력은 그 이전 동일 사진 소스에서 동결됐으며, 현행 기준선 관측 정비는 사진 소스에 영향을 주지 않았다.

원래 정의는 방향성 있는 무게감 **또는** 국소 부착을 허용하고, 원래 패러프레이즈와 개념 용어도 무게감 있는 젖은 다발을 설명했다. 그러나 성분·필수 증거·구성·두 게이트는 얼굴·목·의복에 붙는 형태만 강제했다. 다섯 데이터 잎만 수정해 수분으로 젖은 다발이 아래로 처지는 기존 대안을 보존했다.

출처는 완전히 일치하지 않는다. 원래 후보의 설명과 기존 픽셀 사례는 부착형을 선택했고, 일부 조사 기록도 부착을 언급했다. 그것들은 유효한 더 좁은 선택이므로 후보·원본 fixture·조사 기록·기존 테스트를 바꾸지 않았다. 새 대안이 명시적인 사용자 부착 요구를 면제하지도 않는다. 일반적인 마른 머리의 중력·광택·젤만으로 대체할 수 없으며, 부피 감소·다발·수분 상태의 일치·광택 혼동 제어 등 다섯 필수 성분과 증거 길이를 유지했다.

## 실제 검증

비부착 수분 처짐과 기존 부착형, 마른 중력·광택·젤 음성 대조 등 다섯 입력을 정상 공개 CLI에 동일하게 재실행했다. 양성 두 팩은 팩 ID와 승인한 다섯 계약 잎만 변했고, 음성 세 팩은 전체 JSON이 동일했다. 다섯 팩의 후보 모음 144개가 내용·순서·개수까지 동일하다.

같은 명시적 증거에서 비부착형은 이전 실제 구성 감사의 weighted_adherence_phrase에서 거절됐고 수정 후 통과했다. 원래 부착형은 계속 통과한다. 전체 구성 감사 다섯 건을 독립적으로 재실행해 통과했고 원본 코어 문장을 보존했다. 각 결과의 비실패 자유 서술 경고 세 개는 증거에 남겼다.

독립 소비자 검사 42개, 새 회귀 3개·원래 머리 의미 9개·검색 13개로 총 25개 테스트, 사전·인덱스 검증이 통과했다. 원래 유닛 테스트의 합성 임베딩 대조는 테스트 내부의 모의 입력일 뿐이며 운영 인덱스나 실제 전후 결과를 대체하지 않았다. 현행 사진 경계의 엄격한 바이트 기준 검증도 그대로 통과했다.

실제 임베딩 한 번으로 대상 벡터 한 개를 갱신하고 1,495개 엔트리를 보존했다. 캐시·성공 기록·의미 해시·실제 로더를 독립 검증했다. 단계 보수 상한 $0.0016384, 프로젝트 누적 상한 $1.4237696 / 허용 $10이며 실제 청구 금액은 아니다.

이는 기존 대안을 텍스트 계약으로 표현할 수 있게 한 수정이다. 독립 작문자의 자발적 선택, 물리적인 젖음 판정, 실제 이미지·픽셀 품질 개선을 측정하지 않았다. 다섯 사례 외의 모든 검색 질의가 무변경이라고 주장하지 않는다. 전체 테스트의 기존 산출물 누락 제한은 [앞선 전체 실행 보고](../renewed-full-suite-baseline-20261002/README.md)에 남아 있다.
