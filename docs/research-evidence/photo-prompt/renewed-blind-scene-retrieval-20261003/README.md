# 독립 장면 12건으로 확인한 후보 조회의 도달 경로

기준 커밋: `6c2cc0f9311ee4c9c6a376781e3ea599d7bb6d14`. 런타임·라우팅·후보 데이터는 수정하지 않았다. 이 문서화는 데이터 개선 회차로 세지 않는다. 제공자 호출은 0이고 누적 보수 예산 상한은 $1.4270464로 유지된다.

## 방법과 입력 보정

저장소·후보·이전 결과를 보지 않은 별도 작성자가 조명, 카메라/초점, 재료/질감 각 네 건, 영어·한국어 각 여섯 건을 작성했다. 요청·정답 관계·비슷하지만 틀린 해석·독립 기본 프롬프트를 먼저 동결했다. 최초 해시: `a54e8488c07b343432907b31c5df2dccf17674b71fcba7dd3e8353d34be9ace1`.

조회 전에 스키마가 요구하는 단어 수와 긍정문 표현 때문에 주어 한 곳·장소 일곱 곳·기본문 세 절만 같은 뜻으로 보정했다. 원래 요청과 정답 기준은 그대로다. 실패 기록과 수정 목록을 보존했다. 첫 정상 CLI 열두 건은 전부 통과했다.

첫 기계적 입력은 요청이 특정한 카메라·조명·재료 속성을 충분히 잠그지 않는다는 한계를 발견했다. 후보를 보지 않은 원래 작성자가 같은 요청과 기본문만으로 부분 속성 앵커 30개를 작성했다. 이를 추가한 별도 입력도 열두 건 모두 통과했다. 기존 기본문·요청·설정·기존 앵커는 변경하지 않았다. 두 실험군과 그 이력을 모두 남긴다.

## 직접 확인한 네 가지

1. **질감/초점은 데이터가 있어도 예산에 밀린다.** 재료 사례009–012의 texture에는 실행 시 163개 항목, 적합 104개가 있다. 전체·슬롯 전용 조회도 각각 결과를 반환하지만 슬롯을 방문할 때 공유 후보 상한64가 이미 찼다. 가운데 향신료 병의 라벨만 선명하게 요청한007도 focus의 전용 조회 1위가 적절한 초점면 후보인데 같은 상한에 막힌다. 적란운 등의 다른 데이터 단어를 더 다듬어도 이 슬롯에 자리가 생기지는 않는다.

2. **표면 재료는 먼저 대상 범주에서 막힌다.** 사례009–012의 surface_material 실행 자료는 333개지만, 동결 코어의 대상은 generic으로 추론되어 슬롯의 object/food/plant/environment/sign 범주에 들지 않는다. 따라서 적합 항목이0이다. nonhuman은 동물 등도 포함할 수 있어 무조건 object로 바꾸거나 generic 전체를 허용하는 수정은 제안하지 않는다.

3. **조명 방향은 소유 필드 선택의 영향을 받는다.** 역광 물뿌리개001은 전체 조회에 후보12개가 있지만 슬롯 전용 질의는 setting의 `Garden table at sunrise`뿐이다. 전용 조회가0이라 이중 질의 조건에서 탈락한다. 실제 방향 근거는 기본문과 우선순위에 있다. 이 경우에는 상한만 늘려도 해결되지 않는다.

4. **기존 후보의 속성 범위 누락은 팩의 적합성 표기를 건너뛴다.** 속성 앵커를 추가한 뒤 12건 모두 후보 ID 집합은 같고, 22개 출현 항목이 ineligible로 바뀐다. 그러나 아래에서 올려다보는 장난감 기차006의 top-down/bird’s-eye 후보는 여전히 eligible이다. 해당 기존 행에는 affected_properties가 없으며, 현재 팩 생성 코드는 그 필드가 있을 때만 속성 검사를 호출한다. 순수 검사 함수에 같은 잠금과 누락/빈 효과를 직접 주면 거절된다. 이는 팩의 적합성 판정 경로의 누락이며, 최종 작성자가 반드시 잘못된 각도를 채택한다는 뜻은 아니다. Dutch/mirror 방향은 요청 밖 대안일 수 있지만 그 자체가 반드시 상향 시점과 모순되는 것으로 세지 않는다.

위 주요 여섯 사례(001,007,009–012)의 실제 조회 추적은 원본/속성 보정 입력에서 순위·점수·예산 상태까지 동일하다. 이 여섯 사례의64 상한 관찰을 모든 최종 팩이64개라는 주장으로 일반화하지 않는다. 다른 일부 팩은 더 적다.

## 관련도 관찰의 한계

표시 순서는 계약상 `seed_shuffled_non_preferential`이다. 원시 검색 순위가 아니므로 화면의 첫 후보를 검색1위로 해석하지 않는다. 최초 입력의 관련 슬롯군에서 표시된 후보67개를 별도로 검토했지만, 이것은 작은 탐색적 의미 검토이며 전체 검색 정확도 수치가 아니다. 미리 정한 세부 슬롯과, 그 슬롯이 비활성일 때 살핀 넓은 슬롯군도 구분해 기록했다.

표면 재료 슬롯이 없다고 기본 프롬프트에서 재료가 사라지는 것은 아니다. 기본문은 두 실험군 모두 그대로다. 후보는 선택 사항이며, 최종 프롬프트나 이미지를 생성·평가하지 않았다. 어휘 데이터 자체의 명확한 오류는 이12건에서 추가로 입증하지 못했다.

## 다음 작업의 경계

각 문제는 후보 단어 부족과 구별해야 한다. [후속 검증 사양](FOLLOWUP_SPEC.md)은 속성 검사 누락, 중요 슬롯의 예산, 대상 범주 전달, 슬롯 질의 근거를 별도로 다룬다. 단순 상한 확대·generic 일괄 허용·실패 문장용 동의어 추가는 하지 않는다. 별도 승인과 회귀 검증 없이 이 보고서가 런타임 수정 권한을 뜻하지 않는다.
