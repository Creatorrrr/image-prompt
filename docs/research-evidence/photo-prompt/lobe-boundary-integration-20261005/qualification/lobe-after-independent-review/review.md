# Independent paired lobed-opening after review

## Assessment

The nine-leaf DATA correction fixes the identified four-lobed self-rejection and makes the three-lobed rejection boundary explicit. Every public candidate ID set, intended meaning, owner, eligibility, component, evidence requirement and render gate is retained in the four paired natural cases. No candidate was added or removed. The exact original frozen case changes only `pack_id` and `provenance.tags_hash`.

**The planned candidate-order invariance hypothesis fails.** The stone, timber and painted cases reorder their `visual_concept_candidates.candidates` lists. This is an independently reproduced consequence of the unchanged runtime hashing each entire candidate record, including its changed rejection wording, for presentation order. It is not an observed candidate-set or meaning change. Other visual candidates retain their relative order, and all other public candidate-list orders are unchanged.

This supports the narrowly described semantic boundary correction with the presentation-order side effect disclosed. It does not support a claim that all public output changes are confined to strings and hashes at the same numeric JSON pointers, or that exact candidate order is preserved. If exact order preservation is an acceptance requirement, that requirement is unmet. No runtime change was made to hide or eliminate the effect.
