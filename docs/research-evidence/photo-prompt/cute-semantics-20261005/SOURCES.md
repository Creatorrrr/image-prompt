# 출처와 주장 범위

2026-10-05 KST 확인. 30건은 실험 논문, 공식 기술 설명, 사전, 창작자 본인의 설명·작업·상품 사례다. 각각의 근거 범위는 다르다. 본문 열람·검색 초록·검색 사전 항목의 확인 상태를 분리했다. 외형의 귀여움, 의도, 동의, 건강 상태를 보편적으로 판정하는 출처로 취급하지 않는다.

## S01

[Glocker et al. (2009), Baby Schema in Infant Faces](https://onlinelibrary.wiley.com/doi/10.1111/j.1439-0310.2008.01603.x)

- 유형: `peer_reviewed_experiment`
- 확인 상태: `SEARCH_ABSTRACT_VERIFIED`
- 뒷받침하는 범위: large-head/round-face/high-forehead/large-eye features and cuteness/caretaking ratings in manipulated infant photos
- 주장 한계: Adult photographic body, identity and age changes are not established by this study.
