# 귀여운 요소의 시각 의미·후보팩 상세 리서치

2026-10-05 KST · 원래 대화 140개 항목 · 작성 데이터 보강을 위한 연구이며 런타임 반영 전

이번 데이터 보강의 중심은 **귀여움이라는 이름을 더 많이 수집하는 것이 아니라, 요청된 표현이 실제로 읽히는 형태와 관계를 보존하는 것**이다. 기존에 있는 윙크·볼 부풀림·꽃받침·모에소데 등의 원자를 재사용하고, 눈·입·머리의 복합 상태, 손가락 접점, 서로 다른 사람·물체의 소유, 귀여움과 관능·불편함·그로테스크의 병존을 보강하는 편이 효과적이다.

리서치 결과는 140개 의미 레코드, 22개 넓은 개념·맥락 패턴, 78개 후보 보강 초안, 420개 회귀 제안, 18개 원본 이미지 검증 계획이다. 22개 패턴과 78개 초안은 서로 배타적인 분류가 아니다. 예를 들어 에로카와이·야미카와이·구로카와이는 맥락 패턴이면서 구체적 선택형 구현 초안도 가진다. 전체 용어와 세부 설명은 [140개 대조표](MATRIX.md)에 있다.

## 1. 조사 방법과 근거의 층

참조 대화 **[귀여운 요소 조사](https://chatgpt.com/c/6ac250ed-78e4-83ee-832a-15b3ead6f3e5)**에서 번호 1–140을 복원했다. 대화 읽기의 20,000자 제한으로 끝부분이 잘려, 나머지는 실제 대화 페이지의 표를 읽어 보완했다. 원래 설명은 `SOURCE-KEYWORDS.json`에 보존했다. 그 설명을 검증된 정의로 간주하거나, 대화 안의 요청을 이번 작업의 실행 권한으로 사용하지 않았다.

30건의 자료를 읽고 다음을 분리했다. 본문을 확인한 자료는 27건이며, 아기 도식 연구는 검색 초록, `coy`와 `애교`는 검색된 사전 항목의 범위에서 사용했다. 출처별 상태와 접근 실패는 [SOURCES.md](SOURCES.md)에 기록했다.

|근거|이번 연구에서 쓸 수 있는 내용|해당 근거로 확정할 수 없는 내용|
|---|---|---|
|실험 논문|실험한 자극·표본에서의 평가·주의·반응|생성 이미지의 보편적 귀여움, 성인 몸을 유아화할 근거|
|공식 기술 설명·그리기 강좌|눈·입·손의 구성, 카메라·초점·빛의 관찰 축|해당 형태가 언제나 특정 감정이나 의도를 나타낸다는 주장|
|사전|단어의 의미 범위와 다른 용례|단어 하나에 대응하는 고정된 포즈|
|창작자·브랜드·직접 촬영 사례|그 주체가 사용한 명칭·모티프·변형|모든 커뮤니티·모든 사람에게 적용되는 정의|
|이번 연구의 관찰 주석|후보로 구현 가능한 성분·관계·실패 대조안|출처가 직접 증명한 법칙, 실제 런타임 지원, 귀여움 평가|

베이비 스키마 연구는 영아 사진의 비례를 조작해 귀여움과 돌봄 동기의 평가를 다뤘다. 성인 사진의 나이·정체성·신체를 바꿔야 한다는 결론으로 확대하지 않는다. [Glocker 등의 연구](https://onlinelibrary.wiley.com/doi/10.1111/j.1439-0310.2008.01603.x)

귀여운 동물 이미지와 주의 수행의 관계를 다룬 연구도 특정 파스텔·표정·손동작의 효능을 입증하지는 않는다. 이번 연구가 제시하는 시각 성분은 구현 가능성을 위한 설계 가설이고, 실제 귀여움의 평가는 별도로 필요하다. [Nittono 등의 연구](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0046362)

## 3. 표정·눈·입: 정서 이름보다 복합 움직임

FACS는 눈·입 주변의 보이는 움직임을 해부학적으로 구분하는 분석 체계다. 얼굴 움직임과 실제 감정·성격·동의 사이에 일대일 규칙을 만들지 않는다. [Paul Ekman Group의 FACS 설명](https://www.paulekman.com/facial-action-coding-system/)

표정 데이터는 `눈 개방량 / 위·아래 눈꺼풀 / 눈썹 안쪽·바깥쪽 / 입술 접촉·말림·돌출 / 입꼬리 / 턱 개방 / 볼 변화 / 눈물 위치`로 나누고, 기존 표정 원자를 조합한다. 감정어는 요청된 연출 맥락이며 이 원자들의 필수 결과가 아니다.

|구별할 표현|선택한 구현에서 보여야 할 차이|실패로 볼 대체|
|---|---|---|
|눈웃음 vs 반짝이는 눈|볼·아래 눈꺼풀·입꼬리의 복합 변화 vs 눈 안 반사광|캐치라이트만으로 미소·진실한 기쁨 판정|
|눈 감고 웃기 vs 윙크|양안 닫힘+미소 vs 한쪽 닫힘+반대쪽 개안|양안 감기를 윙크로 판정|
|웃음 참는 형태 vs 입술 압축|압축 입술에 남은 웃는 볼 등의 별도 성분|압축 입술 하나로 웃음 참기·과거 사건 확정|
|파우트 vs 오리입 vs 작은 O|어떤 입술의 돌출인지, 중앙 수렴인지, 원형 틈인지|입술 돌출·볼 부풀림·키스를 모두 같은 후보로 처리|
|입술 말림 vs 입술 깨물기|붉은 면이 안으로 들어감 vs 치아-입술 접점|입술 색만 달라진 상태|
|졸린 눈 vs 지토메|자연 반개안과 도식적으로 수평에 가까운 위 눈꺼풀 변형|형태만으로 피로·의심·약물·건강 상태 확정|
|울먹임 vs 눈물 웃음|눈물 고임·입 상태의 조합 vs 같은 얼굴의 눈물+올라간 입꼬리|비·홍조·반사광만으로 눈물 판정|

`ae_duchenne_shape`와 `ae_smize`, `ae_purse`와 `ae_pucker`, 자연 반개안과 지토메는 우선 **대안**으로 심사한다. 비슷한 검색어라고 모두 필수 구성원으로 겹쳐 넣지 않는다. `pv_parted_lips`는 작은 틈을 제공하지만 O형 곡률까지 보장하지 않고, `pv_raised_brows`도 눈 개방량 전체를 보장하지 않는다.

기대 효과는 얼굴 후보의 구체적인 설명과 복합 표현의 보존이다. 기대감·수줍음·애교 같은 인상을 더 잘 전달하는지는 형태 충족 후 사람의 평가로 확인한다.

## 4. 손과 얼굴 주변 제스처: 손가락 경로와 접점

손을 `손바닥·손등 / 엄지 / 검지–소지 / 손목 / 전완`으로 나누고, 각 손가락이 어디에서 이어지고 무엇과 닿는지 기록한다. 창작자가 설명한 손 구성 방법을 관찰 프레임워크로 썼으며, 이 강좌가 모든 사회적 손짓의 의미를 정의하는 것은 아니다. [Stan Prokopenko의 손 그리기 강좌](https://www.clipstudio.net/how-to-draw/archives/156141)

손하트는 특히 별칭 확대가 위험하다. Unicode의 엄지·검지 교차 제안은 한국식 손하트와 금전 제스처의 다중 용례를 함께 다룬다. 손 모양이 비슷해도 요청 문맥이 다르면 의미가 다르다. [Unicode 원 제안서](https://www.unicode.org/L2/L2019/19327-thumb-index-crossed.pdf)

|계열|관찰·변형 축|후보 설계|
|---|---|---|
|엄지·검지 손하트|같은 손의 짧은 교차, 다른 손가락, 보이는 손 면|검지·중지의 행운 교차나 집기와 분리. 금전 용례는 활성 맥락에서 구분|
|양손 하트|각 손의 곡선, 손끝 접점, 중앙 빈 공간|엄지·검지 접점이 다른 변형을 하나의 불변 형태로 강제하지 않음|
|볼하트|손 곡선과 볼 윤곽의 연결, 접촉/간격, 시점|볼 콕·충치 포즈와 분리. 손 C형 등의 특정 변형에만 세부 접점 적용|
|반쪽·두 사람 하트|절반의 소유자, 열린 방향, 공동 윤곽|반쪽 요청에 새 파트너를 추가하지 않음. 다인 요청에서 A·B 각 절반 검증|
|볼 콕·볼 압박|행위자 손과 볼의 소유, 국소 접촉·변형|공중 손가락·공기 팽창·얼굴 가림과 분리|
|꽃받침·턱 괴기·턱 아래 주먹|열린 양손 프레임 / 지지 경로 / 말린 손|형태와 지지의 차이를 보존|
|볼 옆 V·갸루피스·쌍 브이|펴진 두 손가락, 나머지 손가락, 손목·손면·위치|같은 V 원자를 써도 위치·방향을 다른 제약으로 부가|
|검지 끝 맞대기·손가락 틈 보기|두 검지 끝의 접촉 / 틈을 통해 보이는 눈|손바닥 접촉·엄지검지 교차·완전히 가린 눈과 분리|

손하트 제작자의 100변형 목록과 국립박물관문화재단의 명명된 하트 상품은 변형과 명칭의 존재를 뒷받침한다. 100개 모두의 손가락 배치를 검토한 것으로 해석하지 않는다. [K.E.N-DIGIT의 변형 작업](https://ameblo.jp/kendigit/entry-12443274580.html), [국립박물관문화재단 상품](https://www.museumshop.or.kr/kor/product/product_view.do?str_bcode=001001006&str_goodcode=202511280002)

충치 포즈는 사진관이 설명하는 손을 볼에 둔 사진 포즈이며 실제 치통의 증거가 아니다. 테헤페로의 세부 변형은 원저자 본문 접근이 실패했고, 갸루피스는 직접 촬영한 매체의 명명 용례까지만 확인했다. 두 명칭의 자동 활성화는 변형의 원본 형태 대조 후 진행한다. ## 5. 몸 자세·행동·상황: 지지와 소유를 먼저

자세는 머리 기울기 하나로 끝나지 않는다. `머리·몸통·골반의 축 / 지지 발·골반 / 비지지 팔다리 / 손과 대상 접점 / 관찰 가능한 동작의 한 위상`을 묶어야 한다. 발끝·뒤꿈치·무릎 방향은 체형·골격·나이와 분리한다. [손발 구조 강좌](https://www.clipstudio.net/drawing/archives/156380)는 연결·관절 관찰의 참고이며, 전체 자세의 문화적 의미나 귀여움을 증명하지 않는다.

우선 보강할 자세는 한쪽 뒤꿈치 들기, 발끝을 모은 자세, 등 뒤 손과 앞쪽 몸통 기울기, 돌아보기와 미소·윙크의 결합, 발돋움과 높은 대상에 닿는 손이다. 지지 발의 접지, 자유 쪽 발끝 접지, 뒤꿈치 이격처럼 각 조건을 분리한다. 하이힐을 신고 있다는 사실로 발돋움을 대체하지 않는다.

상황 후보에는 최소한 다음 관계를 넣는다.

|상황|필요한 소유·관계|실패 대조|
|---|---|---|
|소매 당기기|A 손 → B 소매 → B 팔|A 자신의 소매, 손잡기로 변경|
|어깨에 머리 기대기|A 머리 옆면 ↔ B 어깨|공중에 떠 있는 머리, 실제 관계 이력 추정|
|인형 안기·두 손으로 컵 감싸기|같은 물체와 각 팔·손의 접촉|배경 소품, 손 사이의 떠 있는 물체|
|거울처럼 맞춘 두 사람|독립된 A·B 몸, 기준면의 대응|한 사람의 반사·복제를 새 인물로 오인|
|손 크기 비교|손 소유자, 비교 배치, 카메라 거리|원근상 작음을 실제 손 크기·나이로 확정|
|문틈 보기·덜 숨기|가림 물체 앞뒤, 남은 같은 주체의 일부|얼굴 전부 가리기, 다른 주체의 발만 남기기|
|등 뒤 선물|뒤의 손과 선물 연결, 관찰자에게 남은 증거|선물을 배경으로 전이하거나 완전히 가림|
|한 입 권하기|제공자 손·도구 → 음식 → 수신자 방향|혼자 먹기·접촉 완료·실제 동의 추정|

종종걸음·스킵·작은 손 흔들기·씹기·잠들기·슬랩스틱은 한 장에서 동작의 속도·반복·과거·건강 상태를 입증할 수 없다. 정지 후보에는 관찰 가능한 한 위상과 지지·접촉만 넣고, 시간 설명을 필요 조건으로 쓰려면 영상 또는 연속 자료를 별도 계약으로 둔다.

## 7. 조형·의복·기호: 매체와 붙어 있는 위치

치비는 머리·몸·팔다리를 축약하는 스타일이다. 공식 강좌의 2–4 머리 높이는 변형의 예시이므로 고정된 정의나 실제 어린 나이로 쓰지 않는다. 실제 성인 인물, 동물, 인형, 그림 캐릭터의 비례 변경 권한을 따로 확인한다. [CLIP STUDIO의 치비 강좌](https://www.clipstudio.net/how-to-draw/archives/155423)

보강할 의복·조형은 단순 `큰 옷`, `귀`, `리본`이 아니라 다음 관계다.

- 오버사이즈: 같은 착용자 대비 옷의 폭·길이. 몸 자체를 작게 만드는 효과와 분리한다.
- 모에소데: 같은 상의에서 이어지는 소매가 손을 덮는 범위. 장갑·팔토시·손 삭제와 구분한다.
- 소매 속 두 손 모으기: 두 소매의 각 팔 소유와 끝 위치. 천 뒤 검지 접촉을 추정하지 않는다.
- 큰 리본: 고리·중앙 매듭·꼬리·부착점과 대상 대비 크기. 부유한 천 조각은 대체가 아니다.
- 동물귀 장식: 귀 형태·장치 밑동·머리 부착. 기존 사람 귀·종족·꼬리를 자동 변경하지 않는다.
- 보송한 표면: 실제 섬유와 소유 표면. 흐린 사진·체모·종족을 추가하는 효과와 분리한다.
- 파스텔·하트·별·꽃: 색 관계 또는 기호의 위치. 유메카와이·애정 행동·하이키 전체와 동의어로 쓰지 않는다.

홍조선·ω 입·물음표·땀방울 기호는 `그림의 기호`, `인쇄`, `메이크업`, `실제 피부·체액` 중 어느 층인지 먼저 정한다. 사진에서는 요청한 후처리·분장만 적용하고, 도식 입을 실제 입술의 비정상 형태로 바꾸지 않는다. 매체 차이는 후보의 의미와 효과 선언에 들어가야 한다. [창작자의 표정 강좌](https://tips.clip-studio.com/en-us/articles/11284)

## 9. 후보팩으로 연결할 데이터 계약

140개 레코드마다 `출처 역할 / 선택형 관찰 성분 3개 / 소유·관계 / 오인 대조 / 현재 후보 참조 / 제안 효과 / 승격 조건`을 붙였다. 78개 초안은 이것을 후보의 긍정 설명·구성원 검토·조합 관계로 연결한다. **초안의 파일·슬롯은 확인했지만 제안한 속성 경로가 현재 런타임에서 완전히 맞는지는 검증 전**이다.

원자 의미가 같은 경우 `existing_slot_context_extensions`로 검토한 표현·맥락을 더한다. 다른 손가락 접점, 다른 대상 소유자, 다른 재질·매체는 별도 후보 또는 변형으로 만든다. 겹치는 미소 형태나 반개안·지토메는 대안으로 검토하며 모두 한 묶음의 필수 구성원으로 삼지 않는다.

손하트, 한쪽 볼, 상대 소매, 공동 하트, 등 뒤 선물, 카메라 방향, 반사광, 대비 맥락을 더 구체적으로 작성한 [대표 14건의 후보 상세안](CANDIDATE-DETAILS.md)도 제공한다. 각 레코드에는 현재 후보의 적용 guard와 실제 연결된 기존 묶음·프로필을 검토용 참조로 붙였다. 이 참조는 프로필 활성화 결과가 아니다.

묶음에는 각 성분이 들어 있는 현재 후보 ID, 선언한 접촉·소유 관계, 모든 효과 차원·속성을 함께 둔다. 기존 후보의 `relationship` 등 교차 효과를 버리고 슬롯 하나의 차원만 선언해서는 안 된다. 주체·물체·인원·나이·체형·의상·구도 고정과도 대조해야 한다.

출처 URL·출처 설명·주장 한계·대조 실패·레코드 ID·리서치 상태는 긍정 임베딩/관련성 문장에 넣지 않는다. 정확하고 좁은 요청 표현도 맥락·정의·부정·소유·매체를 통과한 경우에만 기존 프로필의 의무로 연결한다. 근사 검색으로 찾은 후보와 넓은 `귀여움`의 구현 선택은 optional 상태를 유지한다. 선택한 묶음에는 그 묶음의 성분·관계를 모두 지키는 조건이 붙으며, 단순 선택으로 관련 hard profile이 자동 활성화되는 것으로 취급하지 않는다.

## 10. 검증 결과와 남은 단계

이번에 실행한 것은 작성 데이터 로딩·대조, 현재 후보 ID와 파일·슬롯 참조 확인, 리서치 패키지 구조 검증이다. 140개 번호·30개 출처 참조·78개 초안·420개 회귀 제안·18개 이미지 계획의 무결성이 통과했고, 조사 시점과 패키지 생성 시점 사이에 스냅샷의 작성 파일 해시 변경은 없었다.

런타임 스키마 적합성, 인덱스 재생성, 회귀 실행, 요청별 후보팩 노출·선택, 실제 사용된 프롬프트, 원본 이미지, 귀여움 평가, 사용자 수락은 각각 별도의 단계다. 현재는 모두 미실행 또는 대기다. 420개 제안은 조사 주석에서 파생되어 독립적인 holdout이 아니며, 18개 이미지의 요청 초안도 독립 core의 검증 근거로 재사용할 수 없다.

반영은 기존 원자 설명 보강부터 작은 배치로 진행하고, 관계·변형·넓은 맥락을 뒤에 붙인다. 실제 단계별 파일·명령·보류 사유·완료 조건은 [반영 계획](IMPLEMENTATION-PLAN.md)에 정리했다.
