# 전체 키워드 경로

원 대화 표 622행과 표 밖 초야권 1항목. 개별 단어 수가 아니며 같은 단어의 중복·복수열 행을 유지했다. 34개 번호 장을 보존했고 마지막 외형 장에는 조합 예 8행이 포함된다.
