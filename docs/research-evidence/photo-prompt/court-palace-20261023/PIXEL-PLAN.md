# 실제 이미지 검증 계획

이번에는 이미지 생성·픽셀 검토를 실행하지 않았다. 아래는 후속 검증용 계획이다. 먼저 원전 검토와 source/native/실제 검색을 통과한 항목만 사용한다.

## 최초 비교: 8군 × baseline/보강 2팔 = 16장

| 군 | 고정할 요청 | 확인할 모든 관계 | 프레임/가림 조건 | 실패 예 |
|---|---|---|---|---|
| P01 | 성인 착용자의 당의, 측사면 | 긴 앞뒤 패널·옆트임·치마·소매 끝 거들지 | 손을 옆트임 앞에 두지 않음; 팔과 몸 사이 여유 | 긴 무용 한삼으로 바뀜, 트임 숨음 |
| P02 | 특정1922년 적의 구조의 성인 착용 | 꿩 문양·붉은 선·용보·폐슬/패옥 구별 | 전신+문양 확인용 해상도, 요청한 부속만 | 용만 반복, 꿩 미식별, 장식이 몸에 융합 |
| P03 | 건륭 조포 구조를 선택한 성인 | 별도 피령·우임·허리 아래 주름·마제수 | 양손과 허리 노출, 어깨깃이 몸판과 분리 | 소매가 조선 넓은 소매로 교체, 주름 없음 |
| P04 | 일본 궁정 겹옷의 성인 | 깃/소매 층·짧은 가라기누·모 | 후방 모를 볼 수 있는 공간; 실제 계절 배색 고증 선행 | 겉옷 바깥에 오비 강제, 모 누락,12겹 강요 |
| P05 |18세기 궁정복 구조 피팅 | 파니에의 좌우 지지·별도 스토머커·겉치마 경계 | 전면+측사면이 읽히는 구조 view; 몸/옷 carrier 분리 | 버슬로 전환, 가운 전체를 스토머커로 판정 |
| P06 | 프랑세즈의 뒤 주름 | 뒤 목점 시작·겹상자주름·밑단까지 연속 |3/4후면 전신; 의자/머리로 시작점을 가리지 않음 | 앞 장식만 화려, 주름 시작점 없음 |
| P07 | 근위가 관리하는 연속 방의 문턱 | 문축·근위·대기자·통과자·안쪽 방 | 문 너머 시야, 사람 발·문턱 깊이 확인 | 투시 파손, 인물 중복, 문밖/안 뒤바뀜 |
| P08 | 성인 착용자와 성인 수행자의 긴 트레인 | 어깨 부착·같은 천·수행자 손 지지·바닥 여유 | 천 경로 전체가 프레임에 남음 | 천이 분리됨, 손 주인 전환, 하중 없는 부유 |

모든 의복·인물의 역사적 신원은 포즈나 얼굴로 입증하지 않는다. 성인 조건을 쓴 창작 실현을 원래 아동 유물·어린 군주 사건의 직접 재현으로 보고하지 않는다. 숨은 받침옷을 확인해야 할 때는 전시·피팅 view를 택하고 일반 궁정 장면에 노출을 추가하지 않는다.

## 비교 통제와 증거

각 팔은 requester core·잠금·참조 범위·controls·크기·모델·전송 조건을 보존한다. baseline은 현재 source가 제공하는 대안을 사용하고, 보강팔은 실제로 자격을 얻은 후보만 사용한다. 신규 후보가 검색에 나타나지 않거나 선택되지 않았다면 그 팔을 신규 데이터의 이미지 증거로 세지 않는다. 아무 후보도 선택하지 않는 대안도 허용한다.

저장할 증거: frozen-core/controls hash, source와 role hash, 실제 검색 요청·응답·receipt, 선택/거절 ID, 채택한 문구의 literal prompt, generation request ID/상태, 반환 파일 hash·크기·포맷, gate별 관찰/가림/오류·전체 판정. 픽셀 관찰자는 image file을 실제로 열어 본다.

판정은 `PASS / FAIL / UNOBSERVABLE / BLOCKED_UNSCORED`로 나눈다. 필요한 관계가 가려지면 UNOBSERVABLE_NOT_PASS, 일부만 충족되면 partial_is_fail. 생성 실패·안전 차단에는 이미지 점수를 주지 않고 같은 프롬프트를 무변경 재시도하지 않는다. 실패한 지점의 원인을 확인한 뒤 승인된 범위에서 새 버전을 저술한다.

16장은 통계적 품질 개선을 입증하는 표본 수가 아니다. 관계 결함을 검출하는 최소 비교다. 데이터가 특정 포즈·한 구도에서만 작동한다면 view를 바꿔 별도 평가한다. 사진 품질·시대 고증·모든 구조 gate·사용자 선호는 별도 항목으로 남긴다.

## 후속 표적군

떨잠의 판·용수철·꽂이, 조주의 전후면 분기, 춘앵전의 자리·손목 천, 수방의 바늘-천 접촉, 편지 봉인의 닫힘 경계, 의장 박탈 흔적의 두 물건 대응을 후속으로 검토한다. 재배/사배·퇴장 방향·춤 순서·실제 떨림·소리는 영상/연속 프레임 없이는 통과시킬 수 없다.
