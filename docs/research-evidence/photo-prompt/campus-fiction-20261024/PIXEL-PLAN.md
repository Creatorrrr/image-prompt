# 이미지 검증 계획

아래는 실행하지 않은 비교 설계다. 각 사례에 동일한 requester core·필수 인원/물건 수·의상·장소·카메라 범위·금지 변형을 먼저 동결한다. A는 현재 source 기준, B는 심사 후 기존 후보 재사용/정제, C는 심사 후 신규 캠퍼스 후보를 포함하는 arm이다. 어떤 arm에 신규 CID가 실제 노출·선택되지 않았으면 그 arm은 신규 데이터 효과를 검증한 것이 아니다.

첫 12개 사례 × 3 arms = 36장 제안이다. 다중 seed·모델 간 일반화·통계적 인과를 증명하는 규모는 아니다. 비용·모델·도구·실행 수는 후속 이미지 실행 시 명시한다. 이번에 이미지 생성은 0장이다.

| 사례 | 의미 차이 | 반드시 보일 것 | 실패 예 |
|---|---|---|---|
| PX01 | 과잠 구조와 착용자 신원 분리 | 한 재킷의 몸판-배색 소매·골지·스냅 | 배색만 있고 스냅/소매 연결 없음, 학생 신원 자동 부여 |
| PX02 | 레터 스웨터/바시티 재킷 | 니트 풀오버와 가슴 패치 | 배색 재킷으로 치환 |
| PX03 | 작업용 닫힌 실험복 | 앞 잠금·눈 보호·장갑-소매 손목 경계 | 열린 가운, 손목 가림으로 미검증 |
| PX04 | 학위 가운/sub fusc | 가운 안쪽 정장 층·후드/모자의 구별 | sub fusc를 바깥 가운으로 통합 |
| PX05 | 공동 노트북 | 같은 단일 화면을 향한 두 눈/상체·노트북 하나 | 기기 둘, 화면 반대편 시선 |
| PX06 | 설계 크리틱 | 한 도면·모형 지지·A/B의 다른 손 | 도면 복제, 손의 주인 전환 |
| PX07 | 겉옷 걸쳐주기 | A 어깨 위 한 벌·B 손·A 팔은 소매 밖 | 두 재킷, B가 착용, A 자기 손으로 변환 |
| PX08 | 깍지 | 교대 손가락·두 엄지·두 손목과 팔 | 단순 손끝 접촉, 합쳐진 손·엄지 소실 |
| PX09 | 무릎베개/무릎 앉기 구별 | 지정한 A 머리 또는 골반의 B 허벅지 지지 | 다른 포즈로 치환, 몸통/다리 연결 파괴 |
| PX10 | 백허그 | 앞 A/뒤 B·B 양팔의 경로·최소 네 손 | 앞 포옹, 손·팔 귀속 불명 |
| PX11 | 벽 접촉/출입 통로 | A 손-벽·몸 사이 틈·B 옆 통로 | 통로 가림, 문 폭 점유로 바뀜 |
| PX12 | 스크린 안/밖 | 화면 내 별명/답글·방 안 실제 인물 한 명 | 계정 세 개를 실제 세 사람으로 생성 |

각 arm은 `request/core hash → source/index hash → 검색 query_scopes/top8 → 선택 CID/카드 → native owner/effects audit → compiled prompt → actual submitted prompt → 생성 receipt → 원본 이미지 hash → 전체 프레임/필요 crop → gate별 리뷰`를 보존한다. exact text가 필요한 별도 사례에서는 OCR/수동 판독을 구조 평가와 구별한다.

가시 계약은 전체 이미지와 필요 crop을 함께 보며 양 끝이 가려진 관계를 추정해 통과시키지 않는다. 크롭만 통과하고 전체 프레임에서 물체/인물 수·지지·거리·의상 층이 틀리면 전체 실패다. `partial_is_fail`, `UNOBSERVABLE_NOT_PASS`를 적용한다. 생성 차단은 `BLOCKED_UNSCORED`이며 픽셀 0장을 실패 이미지로 세거나 성공으로 보정하지 않는다.

동의·연애·신원·학적·평가권·기여·부정행위·원인·진단·소리·이전/이후 사실은 사진으로 통과시키지 않는다. 창작 인상과 사용자 선호는 구조 gate와 별도의 사용자 평가로 남긴다. 한 장의 성공은 모든 356용어·124카드·101초안을 자격 승인하지 않는다.
