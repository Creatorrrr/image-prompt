# 후속 데이터 반영 및 이미지 테스트

실제 반영·실행 결과는 **[통합 보고서](integration-evidence/RESULTS.md)**를 따른다. 최초 README/BASELINE/VALIDATION/리서치 checksum은 연구 시점의 기록으로 보존한다.

시각 의미 카드 124개·새 시각 후보 100개·문맥 진단 23개·선택적 연결 220개를 등록하고 실행 스냅샷을 설치했다. 기존 손깍지 후보 1개는 재사용했다. 의미 경계 검사 12개와 전체 현재 source/index 검증이 통과했다. 한영 개발 검색 274개를 실행했다.

독립 세 컨셉에서 첨부 이미지를 사용해 한 장씩 생성했다. 원본 픽셀 재검토 결과 도예는 간격 불명확, 천문 부스는 투사 경로 불일치로 부분 실패했고 가운 반납은 장면 gate가 통과했다. 새 CID의 실제 최종 채택은 0/3이므로 신규 source의 픽셀 기여는 미확립이다. 사용자 소유 anchor 범위와 실제 질의 구성의 방법상 한계도 별도 기록한다.

원본 이미지, 프롬프트, 실행 기록과 게이트별 판정은 통합 보고서 및 `integration-evidence/arms/`를 참조한다. 로컬 반영 및 테스트이며 commit/push는 수행하지 않았다.
