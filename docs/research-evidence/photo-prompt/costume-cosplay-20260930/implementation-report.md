# 코스튬·코스프레 조사 데이터 반영

## 반영 범위

2026-09-30 조사 결과의 42개 의상군을 **87개 독립 시각 의미 프로필**, **94개 슬롯 후보**, **27개 선택적 후보 조합**으로 런타임에 반영했다. 넓은 의상 이름으로 모든 구조를 강제하지 않고, 개별 부품의 실제 보이는 연결·겹침·접촉 관계를 활성화 단위로 삼았다.

- 의미 데이터: `skills/photo-prompt-image-generator/assets/photo_prompt_visual_obligations_costume_cosplay.json`
- 후보 데이터: `skills/photo-prompt-image-generator/assets/photo_prompt_costume_cosplay_extension.json`
- 출처·조사 범위·기존 데이터 재사용 기록: `docs/research-evidence/photo-prompt/extension-maintenance/photo_prompt_costume_cosplay_extension.json`
- 조사군과 런타임 프로필 매핑: [runtime-integration-map.json](runtime-integration-map.json)
- 상세 출처·행사/모델 사례: 기존 [research-report.md](research-report.md)와 [sources.json](sources.json)

후보는 `garment_detail`, `costume_style`, `wearable_accessory`, `prop`, `surface_material`, `hair_style`, `action`, `capture_context`, `location`의 9개 슬롯에 추가했다. 조합은 선택적이며, 부품별 요청 근거와 적용 범위를 따로 확인한다. 코스튬에서 실제 직업·나이·민족·성격·신체 특성을 추정하지 않는다. 특정 캐릭터의 공식 의상 버전이나 행사 전체의 착용 빈도 순위도 자동으로 확정하지 않는다.

## 연결 및 검증

기존 로더에 의미 확장 파일과 후보 확장 파일을 각각 등록하고, 필수 후보 확장 목록에 추가했다. 코스튬 전용 분기나 새 의미 해석기를 넣지 않았다. Gemini 검색 인덱스를 재생성해 전체 시각 프로필 1,075개 및 의미 검색 항목 9,744개를 확인했다.

신규 전용 검증 7개, 인접 실제 인덱스 바인딩 검증 1개, 인접 스키마 검증 2개, 병합 스키마 검사와 두 인덱스 검사가 통과했다. 다음 범위를 포함한다.

1. 정확한 부품 관계가 같은 의상군의 다른 부품을 강제하지 않는지.
2. 넓은 의상·역할·캐릭터 이름이 신규 세부 관계를 강제하지 않는지.
3. 부정 표현과 달라진 연결 대상이 같은 의미로 재사용되지 않는지.
4. 관계 근거가 없는 유사 벡터는 제외되고, 근거 있는 근사 검색도 선택적 후보로 남는지.
5. 27개 조합의 모든 참조·변경 범위·누락 구성원 조건이 유지되는지.
6. 출처 해시, 실제 로더 결과, 두 검색 인덱스가 연결되는지.
7. 병합 스키마가 유효하고, 선택적 검색 예문이 정확 활성화 문자열과 중복되지 않는지.

기존 시각 프로필 988개의 임베딩 입력과 벡터는 최종 인덱스에서도 동일하다. 이 작업의 생성기 변경은 확장 파일 이름 두 줄 등록이며, 기존 제어 테스트에는 수정하지 않았다. 작업 중 외부의 스킬·생성기·감사기 변경도 관찰돼 별도 사본과 해시를 보존했다. 전체 확장 회귀에는 전통 의상 라우팅 fixture의 6개 불일치가 남았고, 첫 사례만 변경 전 레지스트리로 같은 실패를 재현했다. 전체 회귀를 통과했다고 주장하지 않는다. 자세한 결과는 [runtime-validation.json](runtime-validation.json)에 기록한다.

## 독립 이미지 실험

실험 경로: `runs/costume-cosplay-20260930-independent/`.

서브에이전트 세 개는 서로의 입력·결과를 공유하지 않았다. 실제 사용자 원문과 첨부 사진의 해시를 고정하고, 후보 데이터 조회 전에 각자 무작위 선택·기본 프롬프트·핵심 의미를 작성했다. 이후 후보팩 하나를 사용하고 생성 전에 판정 기준을 확정해 네이티브 이미지 도구로 한 장씩 생성했다. 총 생성 3회, 재생성 0회다.

첨부 사진은 성인 가상 착용자의 얼굴과 머리 외형 참고로 사용한다. 신체 구조·의상·동작은 별도 작성하며, 사진 속 사람의 신원이나 전신 치수를 보존했다고 주장하지 않는다. 프롬프트 감사, 런타임 입력 감사, 실제 픽셀 판정을 분리한다. 필수 연결·접촉·가시성이 일부만 충족되거나 가려지면 실패로 판정한다.

| 컨셉 | 신규 후보 노출/채택 | 필수 픽셀 조건 | 관찰 |
|---|---:|---|---|
| 오로라 티하우스 서버 | 1/1 | 3/5 FAIL | 신규 허리띠·옆 매듭 확인, 앞치마 패널 일부 가림 |
| 달 기지 원자로 관리자 | 0/0 | 4/5 FAIL | 두 끈 중 한쪽 연결 끝 가림, 신규 데이터 영향 미검증 |
| 비 뒤의 여우 나루 안내자 | 4/2 | 4/4 PASS | 새 허리띠·꼬리 부착 관계 및 양손 접촉 확인 |

세 사례에서 신규 프로필은 0개 검색됐다. 프로필의 정확·근사·부정·소유자 검색 경로는 데이터 테스트로 검증했으며, 이 이미지들을 해당 경로의 픽셀 검증으로 간주하지 않는다.

픽셀 실험은 최초 반영 데이터 `integration-v1`을 사용했다. 이후 87개 선택적 검색 예문의 정확 문자열 중복을 수정하고 인덱스를 갱신했다(`integration-v2`). 필수 활성화·의미·픽셀 조건, 94개 후보 내용/ID, 27개 조합 내용/ID는 동일함을 대조했다. 최종 검색 예문 표면에 대한 이미지 실험은 재실행하지 않았다.

세 사례는 일부 데이터의 탐색 실험이며, 전체 항목의 픽셀 검증이나 변경 전후 개선률을 뜻하지 않는다. 원본 이미지, 실제 송신 프롬프트, 고정 테스트 조건, 판정과 실행 원장을 [종합 결과 보고서](/Users/chasoik/Projects/image-prompt/runs/costume-cosplay-20260930-independent/results-report.md)에 연결했다.
