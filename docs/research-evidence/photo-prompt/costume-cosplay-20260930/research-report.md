## 1. 조사 결과의 핵심

코스튬 데이터는 다음 여덟 축을 독립적으로 기록할 때 활용 범위가 넓어진다.

1. **출처:** 작품·캐릭터·의상 버전·재현 방식.
2. **역할:** 메이드·기사·마녀·아이돌·괴수 등.
3. **의복 구조:** 칼라·몸통·소매·앞치마·치마·겉층의 연결과 여밈.
4. **실루엣:** 길이·좌우 비대칭·옆/뒤 볼륨·조형 외피.
5. **표면:** 광택·투명도·파일·자수·전사·마모.
6. **부착물:** 가발·귀·뿔·꼬리·날개·모자·장갑·지지부.
7. **소품 관계:** 누구의 소품인지, 손잡이가 어디인지, 손이 실제로 닿는지.
8. **착용 상황과 상태:** 행사장·부스·무대·스튜디오·피팅·수선·회전·퀵체인지.

특히 **캐릭터 이름의 확대보다 의상 버전과 부품 관계의 확대**가 우선이다. 실제 제작 자료에는 비대칭 의복, 투명 꼬리 지지부, 천 관절층, 가발 뿌리, 지역 협업복, 무대 재해석이 구분되어 있다. 이를 한 의상 이름 안에 압축하면 후보를 조합할 때 소유자·부착·버전이 흐트러진다. [Kamui의 Yelan 제작 기록](https://www.kamuicosplay.com/project/yelan-genshin-impact/), [Kinpatsu의 K/DA Ahri 자료](https://kinpatsucosplay.com/product/kda-ahri-league-of-legends/), [NIKKE 교토 협업 보고](https://prtimes.jp/main/html/rd/p/000000139.000145037.html).

## 2. 근거를 읽는 방법

참조 대화는 조사 범위를 정하는 키워드 출발점으로 보존했다. 대화의 설명을 새 조사의 사실 근거로 그대로 채택하지 않았다.

공개 자료는 관찰 단위가 서로 다르다.

| 자료 | 확인할 수 있는 것 | 확인 범위 |
|---|---|---|
| 행사 코스프레 개더링 일정 | 행사에서 조직된 작품별 팬덤과 모임 | 예정된 모임; 착용 인원 미측정 |
| 주최측 수상 결과 | 출품 작품·캐릭터·팀·제작/연출 분야 | 선택된 대회 참가작 |
| 공식 부스·협업 보고 | 전문 모델의 배역·버전·협업 맥락 | 보고에 적힌 특정 출연 |
| 공식 출연 공지 | 예정 배역과 프로그램 | 실제 출연은 별도 확인 |
| 현장 기사·사진 모음 | 기자가 선택한 실제 착용 사례 | 표본 선택 기준과 전체 인원 부재 |
| 제작자 포트폴리오·튜토리얼 | 의복·가발·소품·소재·제작 방식 | 제작자가 선택해 공개한 작업 |
| 박물관·복식/공연 자료 | 의복 용어·역사적 구조·개별 소장품 | 특정 시대·지역·물건의 근거 |

예를 들어 Anime Expo의 개더링은 참가자가 조직하는 작품별 모임이다. 공식 프로그램에 이름이 있다는 사실과 코스튬을 많이 입었다는 사실은 다른 측정값이다. [Anime Expo 개더링 안내](https://help.anime-expo.org/support/solutions/folders/70000471472).

**이번 자료로 전 세계 또는 국내 행사 착용 빈도 순위를 산출할 수는 없다.** 따라서 뒤의 작품군은 자료에서 반복 등장하거나 구체적인 제작 사례를 확보한 조사 우선군이다. 팬 수·팔로워·좋아요·동인지 서클 수·사진 장수를 후보 가중치로 변환하지 않았다.

출처 확인 수준은 본문 확인 17건, 본문과 선택 사진 확인 3건, 검색 발췌 30건, 검색에 색인된 긴 게시글/기사 내용 3건이다. 검색 발췌 출처는 원문 전체와 사진까지 확인한 것으로 취급하지 않는다. 각 수준은 [sources.json](sources.json)에 남겼다.

## 3. 현재 데이터에서 보강할 위치

조사 시점의 기본 사전은 costume_style 159개, wardrobe_style 78개, garment_detail 92개, wearable_accessory 75개, prop 559개, surface_material 141개, hair_style 38개, action 516개다. 전체 태그 수를 코스튬 분야의 완성도로 해석하지 않았다. 파일 해시와 정확한 슬롯 수는 [coverage-audit.json](coverage-audit.json)에 기록했다.

이미 메이드·세일러 교복·학란·마법소녀·특촬·VTuber·동물 귀·역할 유니폼·판타지 갑옷·버니 등의 의상 후보가 존재한다. 기본 의상명을 대량으로 복제하기보다 다음 빈틈에 후보를 붙이는 편이 적절하다.

| 현재 출발점 | 보강할 관계 |
|---|---|
| 메이드 앞치마 | 가슴판/허리형 구분, 어깨끈과 가슴판의 연결, 드레스와 다른 밑단 |
| 집사·교복·장식 정복 | 앞뒤 길이, 칼라 종류, 라펠/조끼 층, 브레이드 끝점 |
| 캐릭터 코스프레 | 작품/캐릭터/버전 필드, 좌우 비대칭, 앞뒤 구성 차이 |
| 갑옷·특촬·로봇 | 겉판·천 관절·장갑 커프·헬멧 목 경계 |
| 동물 귀·꼬리·날개 | 머리띠·벨트·하네스에 속한 부착물, 뿌리와 끝의 관계 |
| 소품 검·활·지팡이 | 주인의 손과 손잡이 접촉, 손잡이와 본체의 연결 |
| 제작·수선 서브컬처 | 작업 과정과 실제 착용 상태를 각각 노출 |
| 역사·전통복식 | 기존 좁은 프로필 재사용, 현대 협업/무대 변형과 구분 |

서브컬처 확장에는 코스프레 제작·수선, 퍼슈트·마스코트 제작, 로리타 패션 코디 관련 후보가 있다. 이번 제안은 여기에 **완성 의상의 착용 구조**를 연결한다.

기존 간호·경찰·군사 임무와 실제 보호 갑옷 프로필의 소유 범위를 보존해야 한다. 코스튬 사진에서 의상 이름이 임무를 지정하도록 만들면 관련 소품·행동·장면까지 잘못 활성화될 수 있다. 이 부분은 조사 과정에서 확인한 현재 소스 계약에 근거한 통합 과제다.

이 표의 의복 요소는 **수집할 필드의 제안**이다. 같은 작품의 모든 캐릭터가 해당 요소를 착용한다는 뜻으로 데이터화하면 안 된다.

일본 C105의 선정 사진 기사도 NIKKE·원신·젠레스 존 제로·블루 아카이브·VTuber를 다룬다. 두 맥락에서 이름이 재등장하므로 조사 우선군으로 둘 수 있지만, 지역별 착용 순위까지 계산할 근거는 없다. C105의 행사 시점은 2024년 12월이고 기사는 2025년 1월 게시다. [INSIDE C105 기사](https://s.inside-games.jp/article/2025/01/02/162946.html?pickup-text-list=1).

### 4.2 제작·무대 대회가 드러내는 범위

WCC 2025의 공식 결과에는 Fire Emblem Engage, Witch Hat Atelier, Resident Evil Village, Godzilla, Elden Ring 등 서로 다른 외형 체계가 등장한다. 별도 제작·기술/기믹·무대 분야의 결과는 봉제 의상, 조형 외피와 퍼포먼스를 함께 수집해야 한다는 근거가 된다. [World Cosplay Championship 2025 결과](https://wcc.worldcosplaysummit.jp/history/2025/).

Comic-Con의 확인한 2025 결과에는 The Wiz와 Bumblebee가 있고, WonderCon·Dragon Con 자료에는 오리지널 Night Sisters, Super Sailor Jupiter, KPop Demon Hunters, Optimus Prime, Totoro, Medusa 등이 나온다. 공연 앙상블·마법소녀·기계 외피·괴수·신화·오리지널 디자인까지 포함할 필요가 있다. Comic-Con/WonderCon 페이지의 현재 머리말과 내부 수상 결과 연도가 달라 **내부에 명시된 2025 결과**로 기록했다. [Comic-Con](https://www.comic-con.org/cc/comic-con-international-2026-masquerade/), [WonderCon](https://www.comic-con.org/wc/things-to-do/masquerade/), [Dragon Con](https://dailydragon.dragoncon.org/2025/masquerade-winners-2025/).

Pyrkon은 Dragon Age: The Veilguard의 캐릭터 조합, CONvergence는 Rococo Hatsune Miku 재해석 사례를 제공한다. 작품 캐릭터 재현과 역사적 실루엣의 매시업을 별도 모드로 다룰 수 있다. [Pyrkon 결과](https://pyrkon.pl/en/the-winners-of-recent-editions-of-the-masquerade/), [CONvergence 2025](https://www.convergence-con.org/about/archive/2025-convention/2025-masquerade/).

## 5. 코스프레 모델·제작자의 사례

### 5.1 국내·일본 모델과 공식 협업

## 6. 원래 키워드의 넓은 범위를 유지하는 법

캐릭터 코스프레를 확장하면서도 공연·역사·지역·추상 의상의 범위를 유지해야 한다. V&A의 수집 범위는 연극·오페라·무용·대중음악·카바레·서커스까지 이어진다. FIT의 Uniformity는 군복·학교복·작업복·스포츠복과 패션 사이의 관계를 다룬다. [V&A Costume](https://www.vam.ac.uk/collections/costume), [FIT Uniformity](https://exhibitions.fitnyc.edu/uniformity/).

| 키워드 영역 | 이번 조사에서 구체화한 것 | 남겨 둔 세부 조사 |
|---|---|---|
| 역할 유니폼 | 앞치마·테일코트·칼라·견장·작업복·역사 간호복 인용 | 시대별 승무원, 다이너, 학술 가운 |
| 역사복식 | 기존 로브 등판·파니에·버슬 재사용, 드레이프 변형 | 토가, 중세 남성복, 일부 레트로 |
| 지역복식 | 한복/기모노와 무대·협업 해석 분리, 치파오·케바야 기존 관계 | 한푸·도포·아오자이·킬트의 좁은 변형 |
| 종교·의례 | 차수블의 별도 겉층·아플리케 사례 | 승복·혼례·상복의 지역/전통별 구조 |
| 판타지 | 모자·로브·갑옷·부착 귀·뿔·꼬리·날개·꼬리 치마 | 후광, 엘프 귀, 개별 비인간 신체 표현 |
| 호러 | 벨벳 겉층·가면·패치·헤짐과 수선 | 미라 붕대, 인형 분절, 특수분장 부착 |
| 무대 | 튀튀·팀 장식·할리퀸·피에로·깃털·회전·퀵체인지 | 플라멩코, 볼룸, 곡예복의 움직임 |
| 생물·괴수 | 귀꼬리 장식 / 전신 마스코트 / 큰 기계·생물 외피 | 곤충 더듬이와 다지 구조 |
| 추상·착용 조형물 | 신체 주위 외피와 팔다리의 분리 | 카드·체스·음식·건축 등 개별 도상 |
| 독립 미학 | 고딕·로리타·코르셋·란제리 영감과 역할/작품 분리 | 펑크·비주얼계·사이버의 개별 조합 |

각 남은 항목은 조사에서 누락된 결과를 감추는 대신 [keyword-alignment.json](keyword-alignment.json)에 상태와 함께 남겼다. 같은 넓은 키워드에 단일 좁은 변형을 강제로 배정하지 않는다.

지역복식의 근거도 해상도가 다르다. UNESCO의 케바야 자료는 여러 동남아 공동체의 앞이 열리는 상의와 기술·착용 맥락을, 싱가포르 Roots의 치파오 자료는 칼라·대각 여밈·매듭 단추를 다룬다. 카프탄 소장품은 완전한 착용 의상보다 남은 직물 조각의 근거에 가깝다. [UNESCO 케바야](https://ich.unesco.org/en/RL/kebaya-knowledge-skills-traditions-and-practices-02090), [Roots 치파오 제작](https://www.roots.gov.sg/ich-landing/ich/cheongsam-tailoring), [Met 카프탄 소장품](https://www.metmuseum.org/art/collection/search/454043).

고대 의상의 용어와 실제 증거에도 변형과 불확실성이 있다. 키톤·페플로스·히마티온을 하나의 “그리스 드레스”로 덮기보다 어깨 고정·천의 드레이프·허리 묶음을 선택 가능한 관계로 연구하는 편이 적절하다. 이번 CC41은 연구자가 작성한 재해석 변형이며 고대 복원의 인증이 아니다. [Met 고대 의복 에세이](https://www.metmuseum.org/pt/essays/the-chiton-peplos-and-himation-in-modern-dress).

## 7. 시각 의미를 작성하는 단위

데이터 구조는 **관찰 가능한 요소 → 소유자/관계 → 혼동 경계 → 필요한 시점 → 픽셀 판정**으로 작성했다.

| 예 | 선언할 관계 | 자주 생기는 혼동 | 확인할 시점 |
|---|---|---|---|
| 가슴판 앞치마 | 어깨끈이 가슴판에 연결, 허리띠가 드레스 밖, 별도 밑단 | 가슴판이 사라져 허리 앞치마가 됨 | 몸통과 치맛단이 있는 앞 3/4 |
| 꼬리 | 꼬리 뿌리가 착용자의 뒤 허리 벨트에 연결 | 배경 동물의 꼬리, 떠 있는 꼬리 | 뒤 3/4, 부착부 노출 |
| 날개 | 양쪽 뿌리가 동일한 등 하네스에 연결 | 배경 날개, 팔과 융합 | 후면 전신 |
| 소품 갑옷 | 패널 사이 천 관절, 패널 겹침, 국소 금속 같은 도색 | 피부와 융합, 관절을 가로막는 판 | 구부린 관절이 보이는 전신 |
| 가발 땋은 머리 | 뒤 머리의 묶음에서 시작, 교차가 끝 묶음까지 이어짐 | 몸과 분리된 장식 끈 | 뒤 머리와 전체 가닥 |
| 소품 접촉 | 지정된 장갑 손가락이 지정된 손잡이를 감쌈 | 손 근처에 떠 있음, 다른 사람의 소품 | 손/손잡이 원본 크기 |
| 자수/전사 | 실의 높이와 평평한 문양을 각 표면에 선언 | 모든 금색 문양을 같은 자수로 처리 | 원본 크기 근접 |
| 퀵체인지 | 손이 겉층 가장자리를 잡고 내부층이 열린 틈에서 보임 | 분할 합성 화면, 단순한 새 의상 | 한 프레임의 열림과 접촉 |

이 표는 생성·평가를 위한 **연구자의 조건부 설계**다. 작품명·마녀·천사·갑옷·한복 같은 넓은 이름이 모든 관계를 필수화하지 않는다.

예를 들어 CC18의 후보는 “뒤 허리 벨트에서 시작하는 꼬리”와 “치마에서 떨어져 곡선을 이루는 꼬리 끝”으로 분리된다. 후보를 검색했거나 선택했다는 사실만으로 하드 시각 계약이 활성화되지는 않는다. 원래 요청의 관계 근거와 소유자 결합이 필요하다.

### 중요한 혼동 경계

- **보디스/코르셋:** 보디스는 몸통 의복 부분이며 구조 코르셋을 자동 의미하지 않는다. 구조선·여밈·내부 지지는 각각 다르게 확인한다. [Theatrecrafts 용어](https://theatrecrafts.com/pages/home/topics/costume/glossary/), [FIT 란제리 전시](https://exhibitions.fitnyc.edu/exposed-lingerie-history/).
- **파니에/버슬:** 좌우 폭과 뒤쪽 볼륨을 방향 관계로 구분한다. 원본 이미지에서 드러나지 않는 지지체 재료는 확정하지 않는다. [FIT 파니에](https://fashionhistory.fitnyc.edu/panniers/), [FIT 버슬](https://fashionhistory.fitnyc.edu/bustle/).
- **전통복/현대 해석:** 한복의 넓은 전통과 짧은 무대복, 기모노와 게임 협업복을 별도 버전으로 둔다. [V&A 한복](https://www.vam.ac.uk/articles/hanbok-traditional-korean-dress), [V&A 기모노](https://www.vam.ac.uk/articles/kimono).
- **고딕/로리타/캐릭터 코스프레:** 미학·패션 코디·캐릭터 재현은 독립 축으로 저장한다. [FIT Gothic](https://www.fitnyc.edu/museum/exhibitions/gothic-dark-glamour.php).
- **귀꼬리/전신 수트:** 머리띠 귀·허리 꼬리와 얼굴을 덮는 마스코트 수트를 나눈다. 제작 귀와 꼬리는 해부학적 종족 표지가 아니다. [Kinpatsu 귀·꼬리](https://kinpatsucosplay.com/product/ears-and-tails-for-cosplay/).
- **광택/재료:** 도색한 폼의 금속 같은 외관과 실제 금속 성분·방호 성능을 분리한다. [Iden Versio 제작](https://www.kamuicosplay.com/project/idenversio/).
- **발광 외관/물리 작동:** 사진에서 빛나는 부위는 위치·범위로 평가한다. 실제 전원·배선·LED 작동은 제작 기록이나 별도 작동 증거가 필요하다. [Demonic Shield 제작](https://www.kamuicosplay.com/project/demonicshield/).
- **낡은 상태/전체 색보정:** 국소 헤짐·패치·수선 솔기를 선언한다. 의상 노화와 퀵체인지는 공연 제작에서도 독립 작업이다. [Theatrecrafts](https://theatrecrafts.com/pages/home/topics/costume/glossary/).

## 8. 후보팩 제안

94개 후보의 슬롯 분포는 garment_detail 35, costume_style 13, wearable_accessory 27, prop 4, surface_material 6, hair_style 2, action 3, capture_context 3, location 1이다.

조합은 모두 선택적이다. 각 팩에는 구성원 ID, 현재 후보의 선택적 앵커, 출처 레코드 해시, 동일 장면 관계, 최소 관찰 시점이 있다. 해시는 **작성한 출처 레코드의 해시**이며 웹 원문의 다운로드 해시라는 뜻은 아니다.

캐릭터명은 사례 데이터에 남겼다. 예를 들어 Jinx를 검색했다는 이유로 Arcane 의상과 LoL 소품이 한 공식 버전으로 합쳐지는 것을 막기 위해 각 자료의 버전을 별도로 유지한다.

조합의 사용자 결과 예시는 다음처럼 표현할 수 있다.

- 메이드: 검은 드레스 바깥의 흰 가슴판 앞치마, 가슴판으로 이어지는 어깨끈, 허리의 독립 매듭.
- 판타지 기사: 금속 같은 도색의 소품 갑옷, 구부린 관절에 남는 어두운 천, 별도 목 층.
- 동물 귀 캐릭터: 머리띠 귀와 뒤 허리 벨트 꼬리의 뿌리를 노출한 착용 사진.
- 한복풍 무대복: 짧은 상의와 별도 겹친 치마, 허리에 각각 부착된 늘어진 장식.

이는 출처 모델을 복제하는 지시가 아닌 연구자가 작성한 일반적인 의상 구성 예시다.

## 10. 통합 우선순위와 검증 설계

### 1단계: 범위와 버전

작품·캐릭터·버전·재현 방식과 출처 확인 수준을 사례 스키마에 유지한다. 정규화되지 않은 캐릭터 이름은 원문 표기를 보존한다. 공식 설정화·버전 자료가 확보되면 해당 레코드에 연결한다.

### 2단계: 구조와 소유자

앞치마, 칼라, 비대칭 패널, 천 관절, 귀꼬리 부착, 가발 뿌리, 소품 손잡이 관계를 먼저 통합할 후보로 제안한다. 요청에서 지원되는 좁은 관계만 하드 계약으로 컴파일한다. 의상 이름·검색 결과·팩 선택만으로는 필수 구조를 정하지 않는다.

### 3단계: 기존 프로필과 충돌 검사

역사·지역복식의 8개 프로필은 소스 해시와 ID로 재사용 연결했다. 간호·경찰·군사 임무, 보호 갑옷은 코스튬 범위와 별도로 확인한다. 유니폼·한복·기모노·치파오 등 넓은 이름이 좁은 역사 변형을 자동 활성화하는지 회귀 검증한다.

### 4단계: 후보 노출과 이미지 검증

27개 레시피를 런타임 번들로 변환하는 어댑터, 후보 메타데이터 검증, 영향받는 인덱스 갱신을 진행할 수 있다. 이후 24개 라우팅 항목과 8개 이미지 검증 장면으로 실제 계약을 확인한다.

| 이미지 장면 | 확인할 핵심 |
|---|---|
| RN01 가슴판 앞치마 | 끈/가슴판 연결, 허리띠 소유자, 별도 밑단 |
| RN02 비대칭 의상과 소품 | 양팔·패널 차이, 손가락/손잡이 실제 접촉 |
| RN03 갑옷과 헬멧 | 천 관절, 구부림 여유, 별도 목 층 |
| RN04 귀와 꼬리 | 동일 착용자, 부착부 노출, 끝의 독립 |
| RN05 한복풍 무대 변형 | 상의/치마 층, 노리개/리본 부착 |
| RN06 퀵체인지 | 손/겉층 접촉, 별도 내부층 |
| RN07 자수와 전사 | 실의 높이, 옆 문양의 평평함 |
| RN08 착용 조형물 | 외피와 팔다리, 착용 여유와 배경 구분 |

필수 관계가 가려지거나 일부만 충족되면 partial_is_fail 기준으로 실패다. 사진으로 증명할 계약을 설정하지 않은 숨은 물리 작동·재료는 UNSCORED로 둔다. 프롬프트와 런타임 통과, 픽셀 통과, 사용자 판단은 각각 별도로 기록한다.

이번에는 이 계획을 실행하지 않았다. 생성 이미지의 개선률을 측정하려면 따로 고정한 대조군과 비교군이 필요하다.
