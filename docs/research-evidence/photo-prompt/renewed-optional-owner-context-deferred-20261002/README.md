# 선택 후보의 대상 맥락 제한: DATA 수정 보류

조명 교정에서 관측한 무관한 선택 후보를 별도로 진단했다. 사람이 없는 무광 석고 장면에 앉은 몸·쿠션·옷의 지지 압축 후보가 등장한다. 필수 의무로 자동 승격되지는 않지만 채택하면 장면을 바꿀 위험이 있다.

현재 코드에서는 긍정 맥락 조건이 BM25F/임베딩 선택 검색에서 명시적으로 생략된다. 기존 성분 근거 요구를 켜면 이 오탐을 막을 수 있지만, 실제로 검색되는 독립 작성 섬유 정물과 자연스러운 착석·쿠션 장면도 함께 탈락했다. 벨루어를 직접 명명한 경우만 저장된 의역 덕분에 남는다. 성인 제한은 사람이 없는 정상 섬유 정물을 잘못 제외하며 쿠션 지지 관계 자체를 증명하지 못한다.

따라서 두 프로필의 플래그를 변경하거나 장면별 제외 문구를 누적하지 않았다. 별도 런타임/스키마 검토에서 선택 검색의 대상·맥락 적합성과 완성 형태의 근거 요구를 분리하고, 독립 자연어·한국어·복합 대상·비인간 접촉 대조를 검증하는 편이 적절하다. 이 보고서는 구현안이나 임계값을 승인·적용한 것이 아니다.

실제 코퍼스와 인덱스로 BM25F 진단 8개를 실행했다. 한국어 착석 양성은 현재도 상위 8개에 없으며 새 회귀로 계산하지 않았다. 새 공개 CLI 전후 평가, 임베딩 검색 실행, 이미지 검증은 하지 않았다. 저장소와 벡터 변경 및 유료 호출은 0회다.
