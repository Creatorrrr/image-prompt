# 필름·촬영 표현과 효과 소유자 DATA 정비

기준 커밋은 `9cc812523ca2ab0dd1301cbff11d3315dde1ac71`이다. 후보 54개와 영어 진단 검색문 32개를 먼저 고정했다. 최초 16개 수정 제안 중 3개는 검증 결과에 따라 철회했다. 최종적으로 13개만 수정하고 41개는 기준 상태 그대로 유지한다.

## 수용한 변경

- 필름·촬영 후보 7개: 잘린 숫자·일반 단어 별칭을 완전한 명칭으로 정리했다. Ektar, Velvia, SX70, Super8, Tri-X 등 의미 있는 축약 명칭은 보존했다
- 효과 소유자 6개: 원래 컴포넌트가 사진 영상면을 대상으로 하는데 넓은 제안 그룹이나 환경 표면 템플릿에서 복사된 소유자가 붙은 경우를 바로잡았다
- 일회용 카메라 표현은 영상면의 거친 입자와 가까운 물체의 정면 플래시 조명을 모두 유지한다. 단순히 영상면 효과로 축소하지 않았다
- 빗물이 유리 또는 렌즈에 있는 대안, 점광원 중심의 플레어, 화면 가장자리 빛샘, 기존 Portra·CineStill 정비는 그대로 유지했다

검색 로직·필터·스키마는 바꾸지 않았다. 소유자 변경은 기존 로더를 통해 scan-dust 번들 멤버 관계 한 곳에도 반영된다.

## 철회한 세 제안

HP5, Fujifilm Pro 400H, compact CCD의 별칭 변경은 수용하지 않았다. 원제안에서는 관련 대조 탐침이 dense 2→1, 5→4, 16→14위로 상승했다. 양성 검색 순위나 해당 lexical 탐침의 개선은 없었다. 원래 이미 선택 가능했던 후보라는 사실만으로 이 변화를 정당화하지 않았다.

HP5만 복원하는 안과 세 후보를 모두 복원하는 안을 기존 벡터로 비교했다. 세 후보의 원본 행과 벡터를 모두 유지하면 양성 순위와 다른 다섯 탐침의 개선은 그대로이며 세 역방향 변화가 전부 사라졌다. 추가 API 호출 없이 이 보수적인 안을 선택했다. 최초 고정 계획과 원제안 결과도 삭제하거나 고치지 않았다.

## 최종 고정 검색 결과

- Dense: 양성 16개 모두 전후 1위
- BM25F: 양성 15개는 1위, 광량 감소 한 개는 2위로 모두 기존 순위 유지
- Dense 대조 탐침: 5개 순위 하락, 11개 동일, 역방향 상승 0개
- BM25F 대조 탐침: 1개 순위 하락, 15개 동일

이 검색문은 영어로 작성한 후보 기반 진단이며 독립 holdout이나 한국어 검색 검증이 아니다. 특정 슬롯 안의 순위는 최종 채택이나 이미지 품질을 증명하지 않는다. 카메라·인화지가 장면에 등장하는 것과 특정 촬영 외관이 공존할 수 있으므로 탐침을 절대적인 배제 조건으로 만들지 않았다. 일부 탐침은 여전히 해당 후보를 상위에 노출한다.

## 인덱스·비용·검증

최종 사전 해시는 `56204620de3d806c38699af01264308354f988a699d141507c0f98c05c2bb35b`이다. 인덱스 10,174개 문서 중 13개는 새 벡터, 10,161개는 기준 벡터를 정확히 재사용한다.

실제 호출은 원제안 문서 16개와 검색문 32개, 총 48회였다. 모두 한 번씩 성공했고 자동 재시도는 없었다. 수용하지 않은 문서 벡터 3개도 비용·근거 기록에서 제거하지 않았다. 전송 문구 합계는 11,443 UTF-8바이트이며 추가 보수적 비용 상한은 $0.0786432, 기존 정비를 합친 추적 상한은 $0.9076736이다. 실제 청구액이나 별도 upstream 지출을 측정한 값은 아니다.

독립 읽기 전용 검토에서 원본 보존, 실제 인덱스, 벡터·호출 출처 및 고정 검색 결과를 확인했다. 원제안에서 DATA·촬영 97개와 효과·번들·시각 프로파일 40개 테스트가 통과했다. 세 행을 복원한 최종 상태에서도 같은 137개 테스트가 모두 통과했다. 완료 결과는 `validation.json`과 `*-accepted.log`에 기록했다. Dictionary 및 두 인덱스 검증도 통과했다. 전체 저장소 테스트나 새 이미지 생성·픽셀 평가는 수행하지 않았다.

## 재현과 근거

`replay_acceptance.py`는 API 없이 기준·원제안·수용 상태의 192개 결과 행과 현재 수용 인덱스를 검증한다. `--build`는 저장된 벡터만 사용해 수용 인덱스를 재구축한다. 기준 manifest가 참조하는 이전 shard 세대가 필요하다.

`dense/lexical-final.json`과 `*-proposal.json`은 최초 제안 결과이며, 실제 수용 결과는 `dense/lexical-accepted.json`이다. `acceptance-decisions.json`은 세 행을 유지한 이유와 최종 범위를 고정한다. `api-workload.json`의 최초 제안 통계는 실제 48회 호출 기록이며, 수용 인덱스 통계를 별도 필드로 구분했다.
