# 악기 정물·연주 범위 오류: 수정안 보류

이 단계는 **진단만 공개하며 운영 데이터는 변경하지 않았다**. 유료 호출도 없다.

## 확인한 실제 오류

사람·손 없이 놓인 미연주 트럼펫과 알토 색소폰 정물을 각각 정상 공개 CLI로 생성했다. 입력 코어는 사람과 손을 제외했지만, 후보팩의 필수 시각 계약은 입술·밸브 운지·악기 지지 손을 요구했다. 악기 형태와 연주 관계가 하나의 프로필에 묶인 범위 충돌이다. 실제 이미지를 생성한 결과는 아니다.

## 검토했지만 반영하지 않은 안

1. 형태 4성분과 연주 1성분을 별도 프로필로 분리: 단순 정물·명시적 단일 악기 연주에서는 올바르게 라우팅된다. 그러나 한 동사가 여러 악기에 걸리는 “playing a trumpet and a tenor saxophone”에서 두 번째 악기의 연주 요구를 놓친다. 일부 한국어 후치 부정도 기존 매처가 놓친다.
2. 기존 5성분 안에서 명시적 미연주/사람 없음 조건이면 연주 성분만 생략: 일반적인 연주와 단순 정물은 유지하지만, “Two adults playing a trumpet and a tenor saxophone, no people in the background”에서 두 번째 악기의 연주 성분을 잘못 생략한다. 문자열 매칭으로 전역 사람 부재와 배경 사람 부재를 구분할 수 없기 때문이다. 생성 코어가 미연주 속성을 잘못 붙일 때 요청의 연주 의미를 보존하는 데도 한계가 있다.

문구 예외나 악기 조합 별칭을 계속 늘려 고정 사례만 맞추는 방식은 선택하지 않았다. 기존 테스트를 수정해 이 회귀를 숨기지도 않았다. 두 대안 모두 운영 데이터·운영 인덱스로 만들지 않았으며 임베딩 API를 호출하지 않았다.

## 후속 방향

요청이 지정한 의미와 생성 코어가 고른 표현의 소유 관계를 확인하는 별도 런타임/의미 범위 작업이 먼저 필요하다. 이번 DATA 반복 작업에서 그 로직까지 확장하지 않는다. 이 문서는 모든 악기 정물이나 한국어 부정이 해결되었다는 뜻이 아니며, 확인한 오류도 아직 남아 있다.

앞서 게시한 [관악기 손 역할 교정](../renewed-instrument-hand-roles-20261002/README.md)은 별도 수정이며 그대로 유지된다.
