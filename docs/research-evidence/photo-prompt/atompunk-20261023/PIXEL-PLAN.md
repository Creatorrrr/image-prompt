# 원본 픽셀 비교 계획

상태: NOT_RUN. 이미지 호출 0회. 이번 요청은 상세 리서치와 반영 계획이며 이 문서는 후속 평가의 설계다.

## 첫 비교: 12사례 × 3 arms = 36장 제안

| 사례 | 대표 자료 | 구별할 핵심 관계 |
|---|---|---|
| Q01 | 구기 커피숍·투톤 가전 | 지붕 돌출과 지지선, 같은 가전의 두 색과 몰딩 |
| Q03 | 소비에트 영감 전시관·검출기 | 미국식 다이너 자동 혼입 방지, 프로브 케이블 양끝 |
| Q04 | 탐사 전원·핀 착륙선 | RTG 형태와 로켓 핀의 다른 소유자, 연결된 계측기 |
| Q05 | 안개상자·계측기 | 상자 안 응결 궤적과 화면 파형의 다른 매체 |
| Q06 | 수조의 청자색 빛 | 물 아래 발광과 같은 수면 반사, 주변 중성광 |
| Q07 | 닉시·천공카드 | 전극 깊이와 한 숫자의 발광, 실제 천공 |
| Q09 | 나비 지붕·카운터 | 낮은 중앙 골, 적층 단면과 테두리; 동시 가시 어려우면 장면 분할 |
| Q10 | 박람회 모형·모노레일 | 사람보다 작은 모형 도시, 한 빔을 걸쳐 탄 차량 |
| Q11 | 헬멧·월면 돔 | 동일 착용자 얼굴/목링/셸, 돔 안팎 |
| Q13 | 우주 시대 패션 | 직선 실루엣·패널·양쪽 부츠·의상과 신체의 구분 |
| Q17 | 민방위·광고 | 실물 비축물·침상과 인쇄 마스코트의 분리 |
| Q18 | 거대 곤충·폐박람회 | 세 마디·여섯 다리·더듬이·차량 대비 스케일 |

arm A는 후보와 연구 데이터를 보기 전에 독립 작성한 frozen baseline, B는 그 baseline에 현재 corpus를 사용하는 저술, C는 같은 baseline에 proposed corpus를 사용하는 저술이다. source의 효과 비교에서는 B/C의 code/runtime·요청·참조·통제값·출력 조건을 맞춘다. 새 데이터를 이미 본 agent가 그 표현을 A에 되삽입하지 않는다. 실제 이미지 요청 단계의 skill·precore·baseline binding 절차를 따른다.

장면 문구는 REALIZATIONS의 그대로를 독립 baseline으로 복사하지 않는다. 그 예시는 연구자가 후보 구조를 알고 저술한 조합이다. 실제 평가용 자연어 요청을 별도로 고정하고 독립 core를 작성해야 한다.

## 기록과 판정

각 arm은 request bytes·활성 span·core hash·settings snapshot·actual selected CID/RID/role·source/index/runtime SHA·모델·참조·정확한 전달 프롬프트·negative·반환 원본·tool outcome을 갖춘다. 이미지가 안 나오면 `BLOCKED_UNSCORED`로 남기고 픽셀 점수를 만들지 않는다. 생성 성공·prompt audit·native source qualification은 실제 시각 구현의 대체 증거가 아니다.

| 계층 | 기록할 내용 | 통과 조건 |
|---|---|---|
| source/contract | 선택한 전체 분기·조건·owner·effects·의무 | 현재 source와 일치하며 요청 의미/락을 보존 |
| 전달 | 실제 prompt·reference·model·출력 식별 | 검토한 버전이 실제 호출에 전달되었음 |
| component/relations | 각 요구의 visible/partial/unobservable/absent | 선택된 필수 성분과 관계가 한 결과에서 모두 보임 |
| 전체 장면 | 중심 사건·위계·깊이·관계 가독성·불필요한 시연감 | 체크리스트 나열 없이 요청 의미가 읽힘; 독립 판단 기록 |
| 사용자 | pending/accepted/rejected 및 이유 | 실제 사용자 판단을 받았을 때만 갱신 |

원본 크기에서 확인하고 필요하면 원본의 crop을 보조로 쓰되, 후보 이름·기술 해설로 보이지 않는 접점을 메우지 않는다. 모든 선택 의무를 한 이미지에서 확인해야 하며 arm 사이의 잘 나온 부위들을 합쳐 통과시키지 않는다. 핵심 연결이나 뒤 트임이 가려지면 `unobservable`, 몇 개 다리만 보이면 `partial`이고 **부분 통과는 전체 실패**다. 단, 실제 선택 source가 특정 수·부위를 요구하지 않았다면 연구 카드의 다른 분기 성분을 뒤늦게 강제하지 않는다.

Q09처럼 지붕 단면과 실내 적층 단면이 한 구도에서 읽히기 어렵다면 사용자 의미를 보존하는 열린 구도·위치·타이밍을 먼저 검토한다. 불가능한 단면을 억지로 도해로 바꾸지 않는다. 필요하면 연구 단계의 두 분리 사례로 재설계하고 같은 변경을 모든 arm에 적용한다.

기술 PASS는 전체 장면의 개선이나 사용자 수용과 별개다. blind review에서는 데이터/arm 이름을 가리고 상황의 읽힘·중요 관계·원치 않는 추가 요소를 평가한다. 단일 생성의 차이는 확률적 변동일 수 있으므로 인과적 우월성을 단정하지 않는다. 실패·근소한 차이는 실패 유형이 있는 사례에 한해 추가 반복한다.

## 확장

첫 비교 이후 Q02·Q08·Q12·Q14·Q15·Q16을 같은 3 arms로 추가하면 18장, 총 54장이다. 성인 핀업·공연 Q15/Q16도 연구 범위에 남아 있으나 항상 넣는 장르 의무가 아니며 실제 요청과 현재 통제값이 선택한다. 별도 성적 행위나 강압 장면을 이 평가에 만들지 않는다.

전체 36/54는 계획 수량이고 실행 실적이 아니다. 이미지 비용·모델 가용성·정책 outcome·참조 조건을 실제 평가 범위에서 고정한 뒤 실행한다. 필요한 형상을 숨기거나 기준을 낮춰 실패를 통과로 바꾸지 않는다.
