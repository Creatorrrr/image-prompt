# 접근·출처·판정의 한계

조사일 2026-10-23, Asia/Seoul.

- 참조 대화는 `read_thread`의 최대 20,000자 한계 때문에 11절 도중 잘렸다. 같은 URL의 로그인된 Chrome DOM/접근성 텍스트에서 표 15개를 직접 읽어 **용어 191행·작품 9행·조합 9행**, 마지막 로봇 반란과 검색 묶음 6개까지 확인했다. 최초 60,000자 요청은 인자 제한으로 거절되어 사용하지 않았고 20,000자 요청으로 수정했다.
- `SOURCES.tsv`의 53항목은 53개 전문을 모두 읽었다는 뜻이 아니다. 본문 발췌·초록·소장 metadata·권리자 synopsis·공식 사이트의 indexed excerpt를 구분했다. 52항목은 제한된 근거가 있고 S08은 본문을 확보하지 못한 접근 실패 기록이다. 검색 인덱스 발췌는 현재 본문 전체·판본 고증·이미지 픽셀의 대체물이 아니다.
- NRC의 Too Cheap to Meter 페이지 S03은 직접 열기에서 403이었다. 공식 검색 결과의 역사 글 존재와 제한된 발췌만 남겼다. 핵분열의 실제 달성 성능이나 원래 발언의 의도를 ‘오직 핵융합’으로 정정하지 않았다. 정밀한 인용사·원문 검토는 후속 항목이다.
- Smithsonian의 Project Orion 추진 시험체 페이지 S08도 403이었다. 원문 링크만 보존하고 정확한 추진판·완충 구조 판본을 승인하지 않았다. 원리 이름의 구분과 구체 유물 재구성의 근거는 다르다.
- Atomic Heart 공식 페이지는 JavaScript 안내만 반환했다. publisher Focus의 fictional 1955 소개로 설정 범위만 확인했다. 실제 소련의 기술·사회·건축을 입증하는 자료로 쓰지 않는다.
- 원 대화의 Fallout 근거는 fan mod 소개였다. 이를 시리즈 전체의 권위로 승격하지 않았고 S47의 공식 상품 설명은 복고 브랜드/핵전후 세계라는 좁은 연결만 뒷받침한다. 게임 본편의 장면·판본 연구는 후속이다.
- 원 대화의 Atomic Museum 현행 글은 문장 중 관련 없는 외부 링크를 포함했다. 그 외부 링크는 따르지 않았고 세부 수치·전시 서사를 핵심 근거로 사용하지 않았다. Miss Atomic Bomb은 UNLV 소장 목록과 지역 도서관 전시 설명으로 범위를 나눴다. UNLV metadata의 `approximately 1950-1959`와 1957 사진의 정확한 역사적 연대 증거를 혼합하지 않는다.
- NASA의 현재 프로그램 자료는 기술 원리·용어 구분에 사용했으며 현대 설비 외형을 1950s 실물의 고증으로 취급하지 않았다. 소련 자료 역시 1950s~1980s 엽서·생활 제품·1957~1966 전시 맥락이 서로 다르다.
- 구기·수조 발광·닉시·소장품 관련 페이지의 텍스트를 읽었다. 원격 이미지/영화/게임의 전체 픽셀을 수집·비교한 것은 아니다. 실제 유물의 색·치수·봉제·접합을 복원하는 `versioned` 카드는 후속 원본 검토가 필요하다. `proxy`는 외형 제안이며 실제 재료·작동·역사적 대표성을 승인하지 않는다.
- 불릿 브라는 Pitt Rivers 소장품 설명의 원형 봉제·원뿔형 컵, BDSM은 NCSF의 동의 개념, 지오데식 돔은 Fuller Institute의 삼각 구조를 추가 확인했다. Beehive의 원형 판본과 Tiki의 지역별 진품·전체 강연은 충분한 근거를 확보하지 못했다. 제한된 가시 실현 또는 문맥만 제안했다. 조사에서 삭제하지 않고, 직접 근거가 필요한 범위와 재개 조건을 표시했다.
- 초기 장르 선언의 ‘pre-digital’, 원문 ‘Giant Insects’ 예시의 거미, ‘Mini Dress / Shift Dress’의 묶음을 보편 사실·동의어·생물 분류로 자동 채택하지 않았다. 거미는 곤충이 아니며 미니는 길이, 시프트는 구조다.
- Docomomo의 Tiki 행사는 초기 열기에서 페이지 제목·일시·연사를 확인하고 공식 검색 발췌에서 문화적 차용의 주제를 읽었다. 후속 본문 find는 timeout이었다. 전체 강연이나 세부 주장을 읽었다고 계상하지 않았다.
- 방향 그래프·혼동 경계·18개 장면은 연구자가 저술한 제안이다. 출처가 그 장면의 필수성·표현 효과·후보 채택을 보증하지 않는다. 비평·의도·동의·정치·피해·진단·연속 작동·음향은 정지사진의 직접 판정 대상이 아니다.
- lexical audit은 `content.en/ko/aliases`를 지정한 문자 진단이며 정식 retrieval이 아니다. 0건이 의미 부재를, alias hit가 전체 source 적합성을 증명하지 않는다. 느슨한 이웃 탐색의 `monochrome` 오탐은 별도로 부적합 처리했다.
- source·index·installed pointer 등 기존 작업에 쓰지 않았다. `VALIDATION.json`의 기존 파일 대조가 조사 이후의 변경을 발견하면 baseline drift로 기록하고 이 연구가 만들었다고 자동 귀속하지 않는다. 동시 작업의 변경은 복구하거나 덮어쓰지 않는다.
- 이번 요청에서 임베딩 추론·이미지 생성·다른 모델 검토·운영 import·설치·커밋·푸시는 수행하지 않았다. 구조 검증 PASS는 의미 참·native source qualification·검색 노출·원본 픽셀·사용자 수용의 PASS가 아니다.
