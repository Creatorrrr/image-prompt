# 장식 의미 데이터와 샤딩된 main 통합

원격의 시각 프로필 벡터 샤딩 구조를 유지하면서 이번 조사에서 작성한 후보 66개, 프로필 66개, 선택적 후보 묶음 66개를 등록했다. 기존 후보 3개는 완전한 구성 관계의 동등 표현으로 보강했다. 기존 프로필 1,813개 및 해당 벡터는 모두 동일하며 로더·빌더·검색 정책은 원격 구현을 그대로 사용한다. 활성 시각 벡터는 16개 샤드, 과거 판본 보존을 포함한 실제 파일 수는 31개다. 재구성에서 추가 임베딩 요청은 0회였다.

기본 후보팩의 64개 슬롯 후보와 순서는 동일하다. 코어, 창작 설정, 구체화 계약, 부정문 및 공개/비공개 경계도 동일하다. 데이터 해시·검색 코퍼스 메타데이터·위치 후보 수 등 6개 값과 선택적인 설명/시각 개념 목록 2개만 변경됐다. 목록의 신규 노출 및 제거, 순서와 유지된 계약은 `REVIEWED-PACK-DELTA.json`에 명시했다. 기본 슬롯 후보 수와 위치 슬롯 전체 유효 코퍼스 크기는 구분한다.

V22는 이 검토된 변화만 허용한다. V1~V21의 판정 기록·팩·고정 입력·소스 증거는 덮어쓰지 않았다. `V21-PARENT-SOURCE.json`은 원격 소스 166개와 의존 파일 216개를 고정하며, 새 스냅샷은 9개이고 나머지 파일과 벡터는 기존 봉인된 자료를 재사용한다. 과거 검증기는 당시 소스에서 재현한다. 새 검증은 팩/코어/소유자/후보 순서/개인 라우팅/선택적 계약/벡터/소스의 임의 수정 및 재해시를 거부한다.

통합 관련 검사 134개와 실제 기본팩 생성은 통과했다. 전체 회귀는 1,662개를 모두 실행했고 4개 테스트의 13개 실패로 미통과다. 같은 실패를 원격 V21 소스에서 재현했다. 과거 전체 사전 비교에서 새 장식 확장만 제외한 후에도 남은 glass 후보 불일치는 원격의 동일한 기존 불일치다. 기대값이나 판정 기준은 수정하지 않았다. 세부 결과는 `FINAL-VALIDATION.json`, `FULL-SUITE-PARALLEL-RESULT.json`, `ORIGIN-PREEXISTING-FAILURES.json` 및 `HISTORICAL-SCOPE-AFTER-REPAIR.json`에 있다.

이번 통합에서는 이미지를 새로 생성하지 않았다. 앞선 3개 독립 에이전트의 원본 픽셀 검사와 부분 실패는 기존 로컬 증거 및 고정 워크트리에 남겨 두며, 저장 형식 변경이나 데이터 검사 통과를 픽셀 성공으로 간주하지 않는다. 사용자 판단은 아직 대기 상태다.

별도 작업의 지적 활동·포즈·연기 데이터 및 로컬 수정은 이 게시 범위에 포함하지 않았다. 기본 작업 디렉터리의 기존 변경은 별도 백업 후 최신 main에 다시 유지한다. 원격 검증 문서 커밋 c9075139도 일반 병합으로 함께 보존한다.
