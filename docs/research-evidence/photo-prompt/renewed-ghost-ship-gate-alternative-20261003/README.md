# 유령선의 국소 투명화 분기와 렌더 게이트 정렬 — DATA 26

같은 옛 작업 선박의 일부에만 유령성 단절이 나타나는 원래 프로필은 국소 투명화·부재·변위를 모두 허용합니다. 정의·구성요소·필수 증거에는 세 분기가 있었으나 렌더 게이트 한 문장에는 부재·변위만 남아 있었습니다. 그 문장에 원래 투명화 분기를 복구했습니다.

전체 배가 투명해지는 장면으로 확장하지 않았습니다. 같은 선박의 연속성, 상당한 불투명·고체·물과 상호작용하는 선체, 국소 연결 영역의 단절, 이전 작업 흔적, 현재 관찰 가능한 항적/수면/반사 등의 이상이라는 다섯 의무와 게이트를 유지했습니다. 초자연 현상이 실재한다는 근거를 추가한 변경도 아닙니다.

## 원문·검증

원래 legend source research와 현행 프로필의 명시적 대안을 확인했고 별도 검토가 승인했습니다. 실제 materializer에 한 문장만 전달되는 것을 확인했습니다. 원문을 본 뒤 작성한 인공 정규 사례이며, 자연 질의나 독립적인 초기 장면 다양성 실험이 아닙니다.

투명화·부재·변위 양성 세 사례와 완전히 불투명한 버려진 선박·완전히 투명한 선박 대조 두 사례를 동결했습니다. 5개 정상 공개 CLI 요청이 전후 성공합니다. 세 양성 팩은 해당 게이트 설명과 파생 pack ID만 바뀌고 두 음성 팩은 JSON 전체 동일합니다. 후보 ID·순서·개수와 core·선택 적합성·검색 결과를 유지합니다.

처음 구성에는 필수 runtime label이 빠져 세 양성이 실패했습니다. 원래 실패와 입력은 보존하고, 원래 요구된 label만 더한 별도 구성 집합을 다시 동결했습니다. 요청·core·선택·분기 증거·원래 게이트를 바꾸지 않았습니다. 이 수정 이력은 자료에 포함합니다.

## 인덱스·회귀·한계

실제 helper로 1,510개 프로필 벡터 텍스트·BM25F·벡터와 9,739개 일반 인덱스 문서를 비교했습니다. 검색 내용은 전부 동일하고 visual index의 registry fingerprint만 갱신했습니다. 외부 호출과 비용 증가는 0입니다.

새 회귀 3개를 포함해 legend·현행 경계 집중 테스트 27개와 사전 검증이 통과합니다. 전체 suite 통과나 CI 통과를 의미하지 않습니다.

이 수정은 원문과 렌더 지시의 모순을 줄입니다. 원래 어휘 감사가 투명화 사례를 거부했다거나 검색률·생성 픽셀 품질이 좋아졌다고 주장하지 않습니다. 실제 이미지는 생성하거나 검사하지 않았습니다.

고정된 수정 구성 20개의 전체 감사는 BEFORE/AFTER에서 완전히 같습니다. 완전한 장면 5개 통과, 필수 의무 하나씩을 생략한 15개 실패이며 증거·경고도 같습니다. 초기 label 누락을 포함한 원래 20개 결과 역시 동일하게 보존했습니다. 52개 원래 입력 해시를 검증했습니다. 따라서 자동 감사의 허용률 향상이 아니라 후속 렌더 지시의 일관성 정정으로 집계합니다.
