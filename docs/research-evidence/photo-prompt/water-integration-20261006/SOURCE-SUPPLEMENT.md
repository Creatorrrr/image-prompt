# 반영 시 추가 확인한 근거와 범위

기존 [45개 source registry](../water-semantics-20261006/SOURCES.md)를 유지했다. 추가 조회는 기존 연구의 빈칸을 확인하는 용도이며, 조회를 과학적 또는 픽셀 검증 PASS로 바꾸지 않는다.

- W108: [NOAA 2017 Dwarf Seahorse Status Review](https://www.fisheries.noaa.gov/s3/2025-11/2017dwarfseahorsestatusreviewfinal508.pdf), PDF 본문 접근. 꼬리는 지지물을 감아 붙잡는 구조다. 주둥이 길이와 체형은 종별로 다르며, 이 후보의 길어진 주둥이는 선택한 외형 변형이다. 모든 해마의 고정 치수로 사용하지 않는다.
- W111: [NOAA Channel Islands blacksmith 사진 설명](https://sanctuaries.noaa.gov/pgallery/pgchannel/living/living_25.html), 본문 접근. 개별 물고기들이 하나의 집단 배열을 이루는 관찰을 지지한다. 단일 이미지로 집단의 속도나 행동 동기를 측정하지 않는다.
- W172: [FAO AGROVOC abandoned, lost or discarded fishing gear](https://agrovoc.fao.org/browse/agrovoc/en/page/c_9d5917cc), 용어 본문 확인. 어구의 가닥·얽힘은 관찰 가능하지만 유실·폐기의 원인과 소유자의 의도는 픽셀만으로 확정하지 않는다. [캐나다 교육 자료](https://www.dfo-mpo.gc.ca/fisheries-peches/management-gestion/ghostgear-equipementfantome/educational-guide-pedagogique-eng.html)는 검색 발췌만 얻었으며 직접 열기는 실패했다.
- W159: [CottonWorks material library](https://cottonworks.com/product-innovation/material-library/?trk=test)와 [National Cotton Council 소비자 자료](https://www.cotton.org/pubs/cottoncounts/upload/Cotton-and-the-Consumer.pdf)는 검색 발췌를 확인했다. 이것을 수건과 몸의 접촉·겹침 자체를 실험 검증한 근거로 취급하지 않는다. W159의 접촉 구조는 선택한 시각적 실현이고, 흡수량·섬유 조성·성능 주장은 별도다.

30개 비가시적 context는 연구 정의로 유지했다. 45개 family는 서로 다른 의미/재료/경로를 하나의 필수 장면으로 활성화하지 않았다. 이번 live 반영은 검토된 117개의 관찰 가능한 관계에 한정한다. 단어 하나로 camera, 체형, 투명도, 인물 수, 원인 또는 고정 장면을 강제하지 않는다.
