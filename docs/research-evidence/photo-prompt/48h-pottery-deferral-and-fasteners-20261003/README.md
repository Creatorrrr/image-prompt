# 도예 작업 후보 보류와 의복 여밈 의미 점검

기준 소스: `9641e981b7bf7a57ba108a655546098b0b0006cd`

## 결과

**도예 물레 기벽 올리기 후보는 DEFER, 여밈 관련 기존 여섯 개념은 KEEP이다.** 이 문서는 조사·검증 증거만 추가한다. 실제 후보·프로필·인덱스·런타임을 변경하지 않았고, 새 DATA 개선 사이클로 세지 않는다. 임베딩 호출과 이미지 생성은 0건이다.

## 도예: 실제 의미 공백과 적용 가능성의 차이

기존 데이터에 도예가·도예 공방 등 관련 명사는 있지만, 한정된 어휘·의미 점검에서 젖은 점토의 물레 성형과 가죽 경도 단계의 굽 깎기를 구별하는 작업 후보는 찾지 못했다. 이 결과는 모든 기존 표현의 의미를 전수 검사한 부재 증명이 아니다. 여섯 관련 명사·작업 레코드와 두 마감재 대조를 직접 검토했다.

[The Crucible의 교육 자료](https://www.thecrucible.org/guides/ceramics/wheel-throwing/)는 젖은 점토 벽을 지지·가압하며 올리는 과정과 나중에 일부 건조된 기물을 다듬는 과정을 구별한다. [Lea Durie의 실제 작업 기법](https://ceramicartsnetwork.org/ceramics-monthly/ceramics-monthly-article/quick-tip-plant-pot-chuck)은 뒤집은 기물의 적절한 지지와 굽 깎기를 설명한다. 이를 근거로 일반 action 후보 한 개만 제안했으며, 왼손·오른손 지정, 회전 방향, 특정 장비 브랜드, 새로운 필수 프로필은 추가하지 않았다.

후보 작성자와 최초 독립 검토자는 평가 입력·검색문·결과를 보지 않았다. 독립 검토로 기존 물레와 작업물의 지지는 사전 조건이지 새로운 배경 변경이 아니라는 점을 확인해, V2에서 setting 효과만 제거했다. 실제로 추가하는 동작·자세·재료 변형의 효과는 유지했다. 그 두 가지 action/material 효과를 기존 어휘로 정직하게 표현할 때 광범위한 범위 선언이 필요하며, 이를 통과 목적으로 줄이지 않았다.

### 정상 경로와 정확한 중단 지점

- 앞선 두 단계별 도예 사례와 새 네 사례에서 정상 public CLI 후보팩과 변경 없는 초기 본문의 완전 감사를 확인했다. 후보 채택은 0건이므로 이것 자체를 개선으로 세지 않는다
- 새 네 사례는 원문을 보지 않은 작성자의 주제 지정 합성 입력이다. 다만 모두 이후 명시적 스키마 수리를 거쳤으므로 그대로 통과한 최초 입력이나 완전히 독립적인 자연 검색 표본이라고 주장하지 않는다
- 최종 네 코어·초기 후보팩·감사를 고정한 다음에만, 변경하지 않은 제안 V2의 실제 런타임 사전 조건 및 후속 속성 적용 가능성 검사를 수행했다
- 새 도예 양성 사례 둘은 일반 후보의 초기 사전 조건 검사를 통과했다. 그러나 최종 후보팩 단계에서 사용하는 별도의 속성 보호 판정은 여섯 코어 모두 거절했다. 젖은 점토 상태 등 요청자가 보호한 속성과 제안의 광범위한 효과가 겹쳤다
- 따라서 **이 고정 후보와 여섯 사례에서는 순위가 좋아져도 적용 가능한 후보가 될 수 없다**. 새 임베딩이나 after 인덱스를 만들기 전에 보류했다. 존재하지 않는 후보팩 멤버십을 만들거나 선택 감사가 통과했다고 주장하지 않았다
- 독립 검토자가 실제 함수, 소스·행·코어 해시, 119개 before 증거 파일, 최종 ceiling 증거, 기존 실제 멤버 7개의 비교 검사를 재확인했다

이 결과는 도예 데이터 전반이 불가능하거나 런타임이 잘못됐다는 증명이 아니다. 의미상 유용한 후보도 현재 적용 범위 표현과 특정 요청의 보호 조건 때문에 사용할 수 없다는 한정된 반례다. 단어를 늘리거나 관련 없는 별칭을 붙여 해결할 문제로 취급하지 않았다.

### 별도로 확인한 기존 검색 한계

두 기존 단계별 도예 코어에서 `ceramic_potter`는 동일한 `an adult potter` 집중 검색문의 1위였다. 한 사례에서는 전체 문맥 검색의 상위 24개 범위에 없어 최종 후보에서 빠졌고, 다른 사례에서는 그 범위의 24위에 들어 실제 노출됐다. 첫 사례의 최종 후보는 두 검색 범위에 모두 있던 공연자였다. 공방 명사 누락도 기존 범위·교집합 동작과 관련된다. 정확한 검색문·해시·순위·최종 출력은 증거에 보존했다. 이 현상은 새 도예 작업 의미의 부재와 별개이며, 이번 조사에서 검색 로직이나 기존 명사의 별칭은 바꾸지 않았다.

### 입력 수리와 검증 한계

원래 입력과 실패를 그대로 남겼다. `adult` 한 단어는 최소 두 내용어 규칙을 만족하지 않았고 `adult woman/man`을 고정하면 요청하지 않은 성별까지 묶이므로, 별도 V2에서 중립적인 `adult person`으로 바꿨다. 손·작업물 소유 관계의 성별 대명사도 중립화했다. 완성품 정물의 일괄 부정 문장은 현재 검사에서 거절돼, 동일한 완성품 전시 범위를 긍정 문장으로 표현하고 요청의 제작자·작업 과정 배제를 별도 제약에 유지했다. 가죽 작업 대조에는 요구된 물건과 두 손의 가시성을 중립적으로 재진술해, 특정 두 바늘 기법·색상·장비를 고정하지 않았다.

이 수리들은 after 결과나 제안 후보 문구에 맞춰 한 변경이 아니며, 후보 비교 전 V2로 고정했다. 그래도 최초 계획의 초기 본문 불변 조건에 대한 명시적 예외이므로 원문 작성과 스키마 적응의 독립성을 구분한다. 이미지·일반 모순 추론·보편적인 소유 관계 판별·자율적 후보 채택의 품질은 평가하지 않았다.

## 의복 여밈: 여섯 기존 개념 유지

기존에 다룬 랩·크바야·잠수복 여밈 및 CT055 끈 여밈은 제외했다. 새 표본은 CT049-v2 단추 커프스, CT052-v1/v2 노출·숨김 지퍼, CT053-v2 바지 앞트임, CT054-v2 토글, sff_pro_h10 스냅 쌍이다.

노출·숨김 지퍼는 장치의 가시성을, 단추 커프스와 끼워진 토글은 여밈 상태를 설명한다. 이 의미를 피부 노출이나 반드시 벌어진 옷으로 바꿔야 할 근거가 없었다. 바지 앞트임의 넓은 family owner 표현은 더 정확하게 쓸 여지가 있지만, 선택된 정의·근거·검증 게이트가 이미 바지로 한정되므로 실제 결함이 입증됐다고 취급하지 않았다. 이 작은 표본의 KEEP을 의복 데이터 전체 품질이나 검색 성능으로 일반화하지 않는다.

## 증거

`evidence.tar.gz`와 `evidence-manifest.json`에 한정된 소스 표본, 출처, 원래/수리된 입력과 실패, 제안 V1/V2, before 출력, 실제 적용 가능성 ceiling, 독립 검토, 여밈 의미 점검을 보존했다. 제안 행은 조사 자료일 뿐 production 데이터에 설치되지 않았다. 원격 CI 성공이나 전체 테스트 통과를 주장하는 문서가 아니다.
