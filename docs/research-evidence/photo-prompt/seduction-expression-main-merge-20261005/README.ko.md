# 대체 표현 통합 및 main 병합

원격 main `1e309bd845918c7d9d99e0e171170e429c9de361`의 의상·모션 그래픽·카메라 검증 변경과, 유혹적 표현 연구의 실제 형태·대체 표현 보강을 함께 유지했다. 로컬 main의 사용하지 않는 검색 샤드 정리 커밋도 병합 이력에 보존했다. 관련 없는 미커밋 작업은 이번 배포 범위에 넣지 않았다.

이번 데이터 반영은 기존 후보 88개에 영어·한국어 대체 표현 176개, 기존 시각 의미 프로필 14개에 대체 표현 142개를 더하고, 새 후보 15개와 프로필 13개를 추가한다. 접촉·손·머리카락·의복·시선 관계의 소유자와 실제 변경 범위는 10개 기존 후보에서 보완했다. 기존 정의·활성화 조건·증거 최소값·픽셀 판정 기준을 유지한다. 분위기나 동작 이름만으로 관찰되지 않는 형상을 강제하지 않는다.

`SOURCE-MERGE.json`은 작업 전 원본과 원격 데이터가 같은지 검사하고, 원격 런타임에 새 확장 파일 두 개만 등록했음을 기록한다. `UPSTREAM-PRESERVATION.json`은 이번 반영 대상 이외의 원격 JSON 73개와 기존 검증 파일 23개의 바이트 보존을 확인한다. 양쪽의 저작 데이터에서 검색 인덱스를 다시 만들었으며, 동일 ID·긍정 문장·공급자·모델·차원의 벡터만 재사용했다. `INDEX-REBUILD.json` 기준 후보 10,000개, 시각 의미 프로필 1,787개, 정확 조회 표현 4,167개이며 새 임베딩 호출은 0회다.

원격 V13 의상, V14 건축, V15 모션 검증 기록을 수정하지 않았다. 이전 작업의 독립된 V13 관측은 `parallel-local-seduction-v13.json`으로 보존했다. SHA로 검증한 원격 V15 원본 159개를 `V15-source-parent.zip`에 묶어 과거 검증을 그 당시 데이터로 재생한다. 새 데이터에 과거의 승인을 적용하지 않는다.

새 V16 후보팩은 V15의 후보 64개 전체와 순서, 코어·장면·설정·구성·네거티브·공개 경계가 같다. 실제 변경은 `tags_hash`, `slot_corpus_sha256`, `slot_ownership_sha256`, `core_retrieval.canonical_sha256`, `pack_id`의 다섯 바인딩뿐이다. `V16-FIVE-BINDING-PROOF.json`과 검증기의 고정 SHA가 원본 데이터·활성 샤드·후보팩·과거 증거를 묶는다. 후보·순서·장면·공개 범위를 바꾸고 해시만 다시 계산한 결과를 거부한다. 전체 검증 결과는 `full-regression/SUMMARY.json` 및 최종 배포 기록을 따른다.

원본 이미지 3개, 프롬프트, 독립된 코어, 선택된 후보와 픽셀 평가는 기존 연구 증거로 유지한다. 원본 픽셀 전체 장면 판정은 0/3, 세부 판정은 PASS 11 / FAIL 8 / UNOBSERVABLE 8이다. 이 병합에서는 이미지를 추가 생성하지 않았다. 회귀 테스트와 인덱스 검증이 이미지 성공이나 사용자 수락을 의미하지 않는다.

재현 가능한 원래 3개 테스트케이스 및 개선 계획은 `../seduction-expression-integration-20261005/IMPLEMENTATION-REPORT.ko.md`와 `qualification/TEST-CASE-SUITE.json`에 있다. 실제 프로필 노출·선택·필수 픽셀 의무 충족이 분리되어 있으며, 가려진 세부 요소를 통과로 추정하지 않는다.

전체 174개 모듈의 1,517개 테스트를 실행했다. 첫 전체 실행에서 저장소가 제외한 과거 검증 자료 누락으로 3개 모듈이 실패했다. 원본·기대 해시를 확인한 읽기 전용 자료 15개를 복원하고 해당 28개 테스트를 다시 실행했다. 통합 최종 결과는 1,517/1,517 PASS, 실패·오류·생략 0이다. 첫 실패와 복원 후 결과를 모두 보존했다. 이 검증 자료는 공개 DATA가 아니라 기존 로컬 테스트 의존성이다.

푸시 이후 기본 작업 폴더의 main 참조와 인덱스를 푸시한 커밋에 맞춘다. 관련 없는 미커밋 파일은 원래 바이트로 보존하며, 로컬에 남긴 데이터 초안의 검색 인덱스만 동일 문장 벡터로 재생성한다. 공개된 main 검증과 미커밋 초안 검증을 구별한다.
