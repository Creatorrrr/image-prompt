# 운영·재현 보존 정리 실행 증거

2026-10-19. 기준 계획: `docs/plans/photo-runtime-and-research-cleanup.md`.

`BASELINE.json.gz`는 정리 전 파일 내용·파일 식별자와 Git 상태,
`PROTECTED.json`은 보호 범위, `RUN-BINDINGS.json.gz`는 발견된 실행 참조를 기록한다.
원래 작업 파일과 다른 작업 트리는 수정하지 않는다. 참조가 불확실한 항목은 보류한다.
H 단독+F2 설치 선택과 기존 CURRENT는 바꾸지 않는다.

각 `STAGE*.json` 및 검증 기록은 해당 단계의 범위와 실제 실행 결과다.
계획 수행의 완료 여부와 실제 제거·보류 내역은 최종 `REPORT.md`에서 확인한다.
