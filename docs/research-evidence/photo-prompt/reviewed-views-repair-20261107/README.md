# 검토 뷰 버전 복원과 검색 정비

2026-11-07. 과거 기준 뷰의 해시 오류는 해시 계산 자체가 아니라 서로 다른 시점의 원본을 결합한 데 있었다. 기준본의 불일치 1,250개 뷰는 1,245개 후보에 연결되며, 이 후보의 기준 당시 버전은 Git `8558b28e35234aba85e236f6fa2245a41dc458f1`에서 모두 회수했고 각 당시 뷰의 출처 해시와 일치한다. 현재 후보와 비교하면 내용, 조건, 효과가 실제로 달라진 경우가 있어 과거 출처 해시만 현재 값으로 바꾸는 처리는 하지 않았다.

기존 기준 파일과 다섯 오버레이는 변경하지 않았다. 과거 뷰·오버레이가 참조하는 후보의 정확한 버전 차이를 압축해 보존하고, 모든 과거 오버레이 622개와 원본 보존 근거 467건을 과거 버전에 대해 재검증한다. 역사 재생 모드는 과거 뷰가 참조하는 후보를 복원하는 것이며 이후 추가된 무관한 후보까지 제외한 완전한 당시 코퍼스는 아니다.

현재 버전용 전환 기록은 직전 봉인 릴리스의 검토된 뷰를 기준으로 구판 뷰 1,250개를 명시적으로 교체하고 1,376개를 추가한다. 과거와 현재 뷰의 의미가 동등하다는 주장은 하지 않는다. 모든 교체는 과거 뷰 해시와 현재 후보의 해시·인용문을 각각 검증하고, 중복·누락·변조가 있으면 중단한다. 변형 기록은 `data/reviewed-views/06-current-rebase.json.gz`, 과거 후보 증거는 `06-historical-candidate-delta.json.gz`, 연결 정보는 `06-current-release.json`이다.

카메라 높이 후보 한 건은 이미 설치된 native 스냅샷에만 역할 검토 근거가 있었다. native 원본과 작업 원본의 차이가 그 근거 필드 하나뿐임을 고정된 증거로 대조한 뒤, 연구 뷰 준비에서는 작업 원본에 맞는 검색 전용 투영을 쓴다. 설치된 native 근거는 유지하며, 이 투영은 역할 권한을 만들지 않는다. 새 검색본을 조립할 때는 반대로 해당 한 뷰를 정확한 native 원본 해시에 연결하고, 나머지 원본과 동일함을 검사한다.

기본 `photo_prepare_reviewed_views.py`는 과거 후보 복원·오버레이 재생·현재 버전 전환을 순서대로 검증한다. `--release-mode historical`은 과거 뷰를 따로 재생한다. `photo_replay_reviewed_view_overlay.py`의 기본 등록 체인도 과거 후보를 자동 복원한다. 원본이나 전환의 해시가 달라지거나 과거·현재 내용이 충돌하면 실패한다.

`doll like makeup`의 대상 후보는 인형풍 화장으로 장식한 전시용 머리 사례다. 그 한정된 의미를 유지하면서 영문 검색 별칭 두 개를 추가했다. 조건·효과·시각 명제와 기존 native 자격은 변경하지 않았다. 인덱스와 검색 비교 결과는 설치 완료 후 기입한다. 검색 순위는 이미지 구현이나 사용자 만족의 증거가 아니다.

비활성 세대 `40ca5236a557a29fd14113fcf830a6a96f8a077f41ebd8c8283fb9d96a1a5a8f`, native `c23afd2de882fd075d91e1fec9bf96ed59ab823fd26efa414ac0a715a56f3be2`의 전체 봉인·비활성 설치를 검증했다. 기존 뷰 26,927개의 ID를 보존했고 그중 변경한 후보의 두 뷰는 새 원본 해시로 다시 결합했다. 색인 문서 하나만 갱신해 실제 문구 한 개를 재임베딩했다. 진단 후보 네 개는 양성 문서와 뷰에서 제외됐다.

개발자가 목표를 아는 동일 질의 비교에서 `doll like makeup`은 40위에서 4위로 개선됐다. 이전 비교 질의 9건의 목표 순위는 유지됐다. 추가 변형 `doll makeup display head`, `porcelain doll makeup on mannequin`, `인형풍 메이크업`, `인형 화장 전시 머리`는 각각 1·8·7·1위였다. 이는 소수의 저자 인지 검색 탐침이며 전역 품질 향상이나 이미지 품질을 입증하지 않는다. 소스 결합 축약 표시를 별도 검사해 원문의 한영 명제·조건·적용 계약이 보존되고 검색 별칭이 필수 의미에 포함되지 않음을 확인했다.

관련 자동 검사 34개 통과, 12개 스킵, 하위 검사 4개 통과. 표준 현재 준비 명령과 과거 모드, 단독 기본 오버레이 재생 명령도 실제 데이터에서 통과했다.

이후 같은 세대를 기본 검색 설정으로 활성화했고 설치 런타임의 의존성 및 recorder 점검을 통과했다. 설치된 기본 검색본에서 같은 질의를 직접 실행해 목표 후보 4위와 원본 의미·조건·계약의 보존을 다시 확인했다.

작업 도중 별도로 반영된 creative-controls 정의는 유지했다. 설치본과 정의 파일은 버전이 다르지만 동일한 resolver 코드로 새 정의의 고정 스냅샷을 검증하는 단위 확인은 통과했다. 전체 이미지 생성 흐름은 이번 작업에서 실행하지 않았다.
