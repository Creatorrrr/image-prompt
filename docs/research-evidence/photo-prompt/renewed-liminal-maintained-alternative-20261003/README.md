# Liminal 공간의 기존 유지·운영 단서 대안 복원

## 변경

`liminal_transition_use_gap`의 `maintained_cues_phrase.must_mention_any`에 이미 구성요소로 선언돼 있던 OR 문구 하나를 추가했다. 기존 AND 문구는 그대로 남겼다.

- 기존: `working lights clean surfaces furniture and route markers imply normal service`
- 추가: `working lights clean surfaces furniture signs or route markers imply normal use`

정의·구도·게이트·관련 후보는 정상 사용을 암시하는 유지된 단서의 대안을 허용한다. 그런데 근거 검사만 가구와 경로 표식 등을 함께 나열한 문구로 좁혀져 있었다. 두 문구 모두 최초 2026-09-01 소스에 있었음을 별도 검토에서 확인했다. 새로운 검색 별칭이나 장면 조건을 만든 것이 아니다.

통로/대기/서비스 전환 기능, 유지된 사용 단서, 기대되는 사용의 부재, 시간적 흔적, 해결되지 않은 경로라는 다섯 부분과 모든 렌더 게이트를 유지했다. 평범한 빈 방·폐허·정상적인 영업 종료만으로 해당 의미를 충족시키지 않는다.

## 실제 전후 결과

기준: `f4d3532dd295275f7d64d94d720e57ace509de36`. 원래 조사 기준 `b4acb411`과의 차이는 문서뿐이며 검사한 소스는 동일했다.

- 합성 V6 CLI 입력 6개가 전후 모두 유효
- 전체 구성 감사 17개를 각 단계에서 실행한 34개 결과가 모두 동결 기대값과 일치
- 기존 소스 OR 근거 1개만 실패→통과. 기존 AND 근거는 계속 통과
- 일반 빈 공간·폐허·영업 종료·활성 사용 대조군 4개는 변함없이 통과하며, liminal 필수/선택 프로필을 추가하지 않음
- 잘못된 근거/필수 요소 누락 10개와 자연스러운 비정형 문장 1개는 계속 거부
- 무관한 전체 후보팩 4개는 바이트까지 동일. 표적 후보팩 2개는 `pack_id`와 위 근거 배열만 변경
- 후보·검색·core/의도 잠금·소유권·선택·게이트·배제 조건 보존
- 입력 수정·검사 우회·관련 없는 전체 감사 실패 없음
- 새 회귀 검사 4개와 기존 imaginal/liminal 검사 18개 통과, 사전 메타데이터 검증 통과
- 1,507개 벡터·검색 문장·BM25F 모두 동일. 시각 색인은 `registry_sha256`만 갱신
- 제공자 호출 및 추가 비용 0

새 회귀 검사는 수정 전 기존 구성요소의 OR 문구에서 오류 1개를 재현했고, 나머지 3개는 통과했다. 수정 후에는 모두 통과한다.

## 범위

이는 소스를 읽고 작성한 합성 입력의 정해진 근거 문구 검증이다. 후보를 보지 않은 독립 초기 작성 실험이나 자연어 검색 성공률, 이미지 품질 검증이 아니다. 정해진 앵커가 없는 자연스러운 유지 단서 문장은 전후 모두 거부되는 기존 제약을 그대로 기록했다. 선택 후보를 채택하지 않았으며, 노출과 채택을 혼동하지 않는다.

함께 조사한 51개 프로필 중 49개는 유지했다. 특히 궁전/방어시설 34개는 원래 좁게 정의한 변형이므로, 하부 구조나 오목한 깊이 등의 증거를 임의로 완화하지 않았다. 수중 취락의 척도 표시는 독립 표식까지 허용한 것인지 잠수사/ROV가 사용하는 표식인지 출처가 모호해 보류했다.

전체 회귀 검사는 별도의 고정본 실행으로 관리한다. 이 결과를 최신 main 전체 통과로 표현하지 않는다.
