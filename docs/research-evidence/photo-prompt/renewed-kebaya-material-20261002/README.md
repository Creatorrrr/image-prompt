# 케바야의 기존 가벼운 직물 대안 보존

기준 게시 커밋: `7a98e2dcf18a9d60e3505b71e735b88543a99b24`. BEFORE 실행은 앞선 커밋에 검증된 랩스커트 수정이 적용된 작업 트리에서 기록했으며, 실제 원본·인덱스 해시는 이 기준 커밋과 일치한다.

이 프로필의 정의와 구성·직물 게이트는 고운 가벼운 천을 허용하지만 필수 소재 증거는 자수나 레이스만 받아들였다. 원래 성분의 긴 문구에도 가벼운 천이 들어 있었으나 실제 소비자는 문구 전체를 리터럴로 비교하므로 독립 대안을 표현하지 못했다.

성분 대안과 필수 소재 증거 배열 두 곳에 직조와 마감된 앞단이 보이는 가벼운 천 표현을 덧붙였다. 기존 영어·한국어 표현, 단추/케롱상 선택, 별도 하의와 경계, 지역별 차이, 다섯 게이트와 증거 필드별 4단어 기준을 보존했다. 총 다섯 성분 그룹 중 네 필수 그룹과 최소 네 그룹 기준도 그대로다. 선택적 지역 그룹으로 필수 구조를 대신할 수 없다.

## 실제 전후 결과

일반 가벼운 천·자수·레이스와 단추·케롱상 조합 여섯 건을 동일한 고정 입력으로 정상 공개 CLI에 전후 실행했다. 모든 생성은 성공했다. 수정 후 팩에서는 팩 ID와 두 승인 배열만 달라졌고, 각 팩의 후보 모음 30개 전체와 코어·나머지 필드는 동일했다.

같은 증거를 실제 이전 계약에 대입하면 가벼운 천 두 건은 소재 앵커 때문에만 거절됐고, 수정 후에는 여섯 건 모두 통과한다. 기존 자수/레이스와 양쪽 잠금 방식은 전후 모두 유효하다. 전체 구성 프롬프트 감사도 여섯 건 통과했고 독립 검토자가 모두 재실행했다. 원본 장면은 그대로 보존했으며, 각 감사의 자유 서술로 남은 의도에 관한 비실패 경고 세 개도 기록했다.

독립 소비자 검사 28개와 선택 그룹으로 필수 그룹을 대체하는 음성 대조 네 개가 재현됐다. 일반 천·잘못된 하의·빠진 잠금·누락된 필수 구조·제외 표현을 허용하지 않는다. 검증 로그와 실제 전체 팩 차이는 첨부 자료에 포함한다.

## 범위와 한계

현재 저장소가 정의한 ‘앞여밈 상의와 별도 랩 하의’ 프로필의 내부 계약을 맞춘 것이다. 모든 지역의 케바야가 동일한 직물이나 하의를 요구한다고 일반화하지 않는다. UNESCO 직접 페이지는 사람 확인을 요청해 전체 본문을 열람하지 못했고, 검색에 노출된 공식 기록의 자수가 흔하다는 설명만 확인했다. 정확한 수정 근거는 이미 작성된 저장소 정의·구성·게이트다.

실험은 고정된 합성 텍스트 사례와 명시적으로 작성한 증거의 수용성 검증이다. 독립 작문자가 자연스럽게 소재를 선택하는지, 실제 생성 이미지의 품질이 좋아졌는지는 측정하지 않았다. 여섯 사례의 후보가 같더라도 BM25F 전역 통계 변화로 다른 질의 순위가 바뀔 가능성까지 배제하지 않는다.

실제 벡터 한 개만 갱신하고 나머지 1,495개 엔트리를 보존했다. 저장된 실제 응답과 의미 해시·성공 기록의 일치, 모든 벡터를 이용한 전체 인덱스 재구성의 일치를 독립 확인했다. 성공 제공자 호출 한 번의 보수 상한은 $0.0016384, 프로젝트 누적 상한은 $1.4221312 / 허용 $10이다. 실제 청구 금액은 아니다.

새 회귀 3개, 기존 전통 의복 8개, 시각 의무 26개, 시각 프로필 검색 13개로 총 50개 테스트와 사전·인덱스 검증이 통과했다. 더 넓은 전체 테스트 실행은 별도로 진행 중이며 여기서 전체 통과를 주장하지 않는다.
