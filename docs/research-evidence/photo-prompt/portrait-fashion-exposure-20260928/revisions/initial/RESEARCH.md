# 인물 사진의 의상·노출·가림·실루엣: 시각 의미와 후보팩 강화 리서치

작성·확인일: 2026-09-28. 참조 대화: [인물 사진 연출 조사](chatgpt-conversation://6ab93bd5-30d8-83ee-b2b5-866e63d1cba8).

성인 인물의 패션·글래머 사진을 대상으로, 참조 대화의 용어를 관찰 가능한 관계와 재사용 가능한 후보로 분해했다. **노출량, 의복 핏, 소재, 행동, 얼굴의 가독성은 독립 축**이다. 같은 의상이 모든 인물·장면에서 같은 매력이나 SNS 반응을 만드는 것으로 간주하지 않는다. 이번 작업은 리서치와 데이터 통합이며 이미지 생성·픽셀 평가·사용자 미감 평가는 실시하지 않았다.

## 1. 조사 방법과 근거 수준

참조 대화 전체 한 턴을 읽고 키워드 범위를 복원했다. 그 대화의 캐시된 인용 번호는 원문 URL로 취급하지 않았다. 사전, 복식 박물관, 직물 용어집, 촬영 안내, 플랫폼 전망, 실제 브랜드 의상 설명을 다시 확인하고 기존 런타임 데이터와 대조했다. 확인한 18개 자료와 접근 실패 자료는 [sources.json](sources.json)에 구분해 기록했다. 아래 표의 57개 용어군·104개 표기 형태는 [keyword_catalog.json](keyword_catalog.json)에 원래 열의 의미를 보존해 구조화했다. 복합 착장 표현은 그 자체로 한 항목이며, 별칭 개수가 의미 데이터의 품질을 증명하지는 않는다.

다음 근거를 서로 대체하지 않는다.

| 근거 | 확인할 수 있는 것 | 확인할 수 없는 것 |
|---|---|---|
| 사전 | 용어의 지시 대상과 인접 개념의 차이 | 특정 포즈의 효과·매력·인기 |
| 박물관·용어집 | 의복과 직물의 구성·재단·역사 | 현재 SNS 점유율·개별 사진 반응 |
| 브랜드 의상 설명 | 특정 구조의 존재와 조합 사례 | 보편적인 핏·실제 착용자의 만족 |
| 촬영 전문가 안내 | 실무에서 사용하는 구도·초점·조명 원리 | 보편적 매력의 실험적 순위 |
| Pinterest 전망·패션 보도 | 검색 추세 또는 선택된 착장 사례 | SNS 전체 유행·2026년 9월 실시간 비율 |
| 이번에 설계한 컴포넌트 | 프롬프트·데이터가 보존해야 할 소유자와 관계 | 실제 이미지가 그 관계를 구현했는지 |

문헌에서 가져온 사실과 이 저장소를 위해 새로 설계한 게이트는 구분했다. `proposals.json`의 `evidence_level`은 외부 효과 검증이 아니라 `source_informed_design_not_external_validation`이다. 출처가 직접 확인하는 형태와 그 형태에 대해 설계한 관찰 조건을 나누었다.

## 2. 현재 유행에서 가져올 수 있는 범위

Pinterest의 2026 전망은 **Laced Up**과 **Vamp Romantic**을 구분한다. 전자는 레이스 디테일, 후자는 어두운 네일·로맨틱 고스 헤어·번진 콜 계열 눈화장을 포함한다. 공개 수치인 `lace belt +55%`, `dark romantic makeup +160%`는 해당 전망의 검색 근거다. 특정 노출 사진의 성과나 현재 모든 SNS에서의 인기 비율로 전환할 수 없다. [Pinterest 원자료](https://newsroom.pinterest.com/news/pinterest-predicts-nonconformity-self-preservation-and-escapism-drive-21-trends-for-2026/)

2026-08-05 Vogue 보도에는 브라와 일반 겉옷을 함께 사용하는 착장 사례가 있다. 여기서 후보로 추출할 수 있는 것은 **독립적인 이너·외층, 서로 다른 볼륨, 소재 대비, 레이어 교차**다. 유명인의 얼굴·의상 전체를 복제하거나, 사례 등장 횟수를 인기 순위로 해석하지 않았다. [Vogue 보도](https://www.vogue.com/article/the-bra-is-the-outfit)

따라서 유행명은 **탐색과 분위기 제안**에 사용하고, 실제 시각 계약은 그 사진에서 선택한 의상 구조와 관계로 작성한다. `Vamp Romantic`은 검은 레이스, 깊은 목선, 특정 시선, 노출량을 자동으로 요구하지 않는다.

## 3. 가슴골과 주변 개념의 구분

`cleavage`의 복식·신체 의미는 가슴 사이의 중앙 함몰부를 가리킨다. `décolletage`는 낮게 파인 목선과 의복의 영역이다. **낮은 목선은 중앙 골을 반드시 보여주지 않으며, 중앙 골이 보인다고 가슴 크기·핏·의복 종류가 결정되지 않는다.** [Merriam-Webster](https://www.merriam-webster.com/dictionary/cleavage), [Dictionary.com](https://www.dictionary.com/browse/decolletage)

| 개념 | 보이는 대상과 경계 | 혼동하기 쉬운 대체물 | 데이터 처리 |
|---|---|---|---|
| 가슴골 / cleavage | 네크라인 안 피부의 중앙 함몰부 | V자 목선, 쇄골 그림자, 직물 접힘, 가슴 크기 | 새 `pfe_cleavage` |
| 데콜타주 / décolletage | 목 아래·어깨·상부 가슴을 드러내는 목선 관계 | 가슴골만 남긴 크롭 | 기존 `decolletage_neckline_exposure` 재사용 |
| 플런징 V넥 / plunging V | 깊게 내려가는 V형 의복 경계 | 피부의 중앙 골 또는 V자 장식 프린트 | 의상 구조 탐색; cleavage 자동 승격 없음 |
| 스쿠프넥 / scoop | 둥글고 넓은 목선 | V넥, 넓은 쇄골 영역만 | 기존 목선 후보와 연계 |
| 스위트하트 / sweetheart | 상단의 두 곡선과 중앙 굴곡 | 중앙 피부 그림자 | 기존 의상 형태 재사용 |
| 사이드 영역 / side-chest exposure | 팔구멍·옆선과 인접한 측면 영역 | 중앙 골, 등 노출 | 연구상 위치 축; 신규 런타임 의미 미승격 |
| 밑단 인접 영역 / lower-chest edge | 상의 하단 경계와 인접한 하부 영역 | 중앙 골, crop top의 복부 띠 | 연구상 위치 축; 신규 런타임 의미 미승격 |
| 브라·브라렛 가장자리 | 별도로 구성된 이너의 천·솔기·끈 | 피부의 골, 한 의상에 붙은 장식 | 새 `pfe_neck_foundation` |

측면·하부 영역은 중앙 골과 다른 **위치 기술**이다. 대중적 별칭의 외부 정의나 선호도까지 이번 자료로 검증한 것은 아니므로 생성용 프로필·유행명으로 추가하지 않았다.

새 가슴골 관계는 세 가지를 같은 이미지에 요구한다: 중앙 피부 함몰부, 연속된 의복에 붙은 목선, 피부와 천·그림자의 구분. 특정 깊이·크기·대칭·가슴을 모으는 자세는 요구하지 않는다. 검은 선을 천에 그리거나 목선의 V자만 구현한 경우는 실패다.

## 4. 판치라·브라치라·부분 보임을 하나로 묶지 않는 방법

小学館 デジタル大辞泉의 `パンちら`는 치마 안의 속옷이 일부 보이는 상태를 뜻한다. KCI의 이노우에 쇼이치 글은 `panchira`, `munechira`, `brachira`를 서로 다른 보이는 대상으로 구분한다. 이 글의 문화 해석과 일화는 시대·문화에 대한 논의이며, 보편적인 선호도나 현시점 SNS 반응의 실험 증거로 쓰지 않는다. PDF 첫 페이지의 연도 표기는 Autumn 2015다. [대사전](https://kotobank.jp/word/ぱんちら-682325), [KCI 원문·영문 초록](https://www.kci.or.jp/articles/files/J_FT02_INOUE_Chirarism_EN.pdf)

| 개념 | 대상 | 경계 구조 | 단일 사진의 관찰 한계 |
|---|---|---|---|
| 판치라 / panchira / パンチラ | 치마 안 별도 속옷의 부분 | 바깥 치마 밑단이 이너의 상당 부분을 가림 | 실제 순간성·우연성·연출 여부는 확정 불가 |
| 브라치라 / brachira / ブラチラ | 별도 브라·브라렛의 일부 | 목선·외층이 이너 일부를 가림 | 끈만 보임과 목선 뒤 컵 가장자리는 별도 형태 |
| 무네치라 / munechira / 胸チラ | 가슴 주변 피부의 부분 보임 | 블라우스 등 의복의 열린 부분 | 이너 천이 보인 것과 구분; 새 hard 은어 없음 |
| 허리밴드 위 이너 / whale tail | 바지 허리선 위 끈·이너 경계 | 하의 위쪽의 두 경계 | 치마 밑단 아래 부분 보임과 다름 |
| 언더웨어의 겉옷화 | 외층과 함께 스타일링한 기반층 | 라펠·끈·여밈·밑단의 레이어 질서 | 속옷 단독·한 가닥 끈만으로 성립하지 않음 |
| 시어를 통한 레이어 보임 | 투과하는 직물 아래 이너 | 직조·솔기·투과·안감 | 바깥 밑단의 가림과 다른 광학 관계 |
| 속치마 밑단 / petticoat hem | 속치마의 밑단 | 바깥치마 아래 독립된 헴 | 브리프라고 자동 분류하지 않음 |
| 안전 쇼츠 / safety shorts | 다리통과 밑단이 있는 쇼츠 | 치마 뒤 쇼츠의 구성 | 브리프와 형태가 다름 |
| 겉옷 위 속옷선 / visible panty line | 덮인 천 표면의 솟은 선·압흔 | 천 표면의 형태 변화 | 속옷 천 자체가 보인다는 증거가 아님 |

부분 보임은 다음 축으로 저장하는 것이 좋다.

1. **대상**: 피부 / 이너 천 / 끈 / 안감 / 속치마 / 쇼츠.
2. **가림체**: 목선 / 치마 밑단 / 외층 라펠 / 바지 허리밴드 / 반투명 직물.
3. **경계 방향**: 위쪽·아래쪽·옆쪽·투과. 단순 노출 면적보다 관계를 먼저 지정한다.
4. **대상 식별 근거**: 솔기·가장자리·여밈·직조·독립된 밑단·레이어 순서.
5. **상태**: 고정된 부분 보임 / 동작으로 변한 경계. 변화가 핵심일 때만 인과를 추가한다.
6. **프레임과 인물**: 보이는 얼굴, 지지 상태, 의복 전체의 연결. 특정 카메라 높이는 자동으로 넣지 않는다.

`pfe_hem_foundation`은 명백한 성인의 **치마 밑단—별도 불투명 브리프—식별 가능한 천 경계**라는 좁은 관계다. 이너 식별에는 휘어진 다리 구멍의 가장자리와 그에 연결된 천 패널이 필요하다. 외층 아래 흰색 천 조각이나 솔기 하나만 보인 경우는 브리프·속치마·쇼츠를 구분하기에 부족하다. 단어 `판치라` 하나를 몰래 촬영한 시점, 치마를 들추는 동작, 특정 자세로 번역하지 않는다. 실제 촬영 동의·성인 여부의 사실 확인은 제작 맥락에서 별도로 다뤄야 하며, 카메라 응시나 피부 노출을 그 사실의 증거로 쓰지 않는다.

## 10. 회귀·검색·픽셀 검증의 구분

계약 검증은 다음 오류를 겨냥한다.

- 완전 관계와 부분 문장, 부정된 관계, 성인 맥락 없는 관계의 분리.
- 광물 cleavage, slit-scan, 시스루뱅처럼 같은 단어의 다른 뜻.
- 판치라와 허리밴드 끈·속치마·안전 쇼츠·시어 투과의 혼동.
- 가슴골과 데콜타주·깊은 V넥·큰 가슴·천 그림자의 혼동.
- embedding 점수가 높다는 이유로 필수 관계를 생성하는 오류.
- 선택형 묶음의 구성원 누락·잠긴 차원 변경·프로필 자동 승격.
- 연구 URL·출처·매력 주장·정체성 차원의 런타임 유입.
- 새 의미 데이터와 재생성한 색인의 해시·후보 수·임베딩 무결성.

최종 데이터에서 신규 집중 회귀 **9/9**, 이어서 선택한 관련 계약 검사 **48/48**이 통과했다. 사전 검증과 두 색인 검증도 통과했다. 시각 색인은 960→974개 프로필, 후보 의미 색인은 9,128→9,146개 항목이다. 기존 항목의 텍스트·벡터는 각각 전부 동일하며, 이전 HEAD가 참조하는 벡터 세대도 보존했다. 색인 생성이 바꾼 BM25F 통계는 새 자료를 포함한 전체 코퍼스의 재계산 결과다.

실제 Gemini 검색 벡터와 최종 색인을 사용한 고정 진단은 다음 결과를 냈다. 문장과 기대 대상은 [retrieval_probes.json](retrieval_probes.json)에 보존되어 있으며, 독립 holdout으로 주장하지 않는다.

| 진단 범위 | 관찰 결과 | 해석 한계 |
|---|---|---|
| 새 관계를 다르게 풀어 쓴 6개 문장 | 기대 프로필 6/6 검색 | 14개 전체의 재현율·상위 1위 정확도·이미지 성공률은 아님 |
| 광물 cleavage·slit-scan·시스루 앞머리·허리밴드 끈 | 신규 선택형 프로필 없음 | 이 네 고정 문장에 대한 결과 |
| 속치마·안전 쇼츠 | `pfe_hem_foundation` 등 선택형 검색 오탐이 남음 | 브리프의 천 식별과 완전 관계의 검토가 필요함 |
| 전체 12개 advisory 문장 | 신규 hard 활성화 0 | 선택형 검색의 완전한 분리 성공으로 해석하지 않음 |

처음 실행한 넓은 관련 회귀에서는 완료된 57개 메서드가 통과했고, 세 메서드에서 실패를 발견했다: 기존 SKILL 문구 4개, 명시적 후보 선택 목록 누락 1개, 기존 라우팅 8개 사례의 인접 후보 유입. 120개 과거 라우팅 사례를 반복 재계산하는 구간에서 그 실행을 중단했으므로 **전체 회귀 통과 결과가 아니다**. 미완료 메서드는 통과 수에 포함하지 않았다. 이후 아직 실행하지 않은 관련 계약 48개를 최종 데이터에서 별도로 완료했다.

발견한 세 종류의 실패는 작업 시작 HEAD `766c327d23d721bfc4bc459e4d596a4563fa7264`의 스크립트·변경된 자산을 별도 임시 디렉터리에서 재구성해 재현했다. 라우팅 8개는 기존 fixture에서 실패한 원래 행과 검사를 그대로 사용했다. 최종 데이터와 변경 전 데이터의 8개 실패 traceback은 모두 동일하며 새 `pfe_` 프로필은 차이에 들어 있지 않다. 기존 기대값·문구나 생성기 동작은 이 리서치에서 수정하지 않았다.

실제 이미지 검증은 후속의 독립 작업이다. 최소 비교 조건은 아래와 같다. 이 표는 **계획**이며 합격 결과가 아니다.
