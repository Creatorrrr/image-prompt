# 마운트 사진 슬라이드의 필름 두께 단독 증거 복구 — DATA 25

원문은 동일한 이미지 지지 필름의 가장자리 밀도 또는 두께를 허용합니다. 기존 OR 문장도 두께를 표현할 수 있었으나, 두께만 확정적으로 설명하는 `film edge thickness`는 구성요소·증거 앵커 배열에 없었습니다. 이 문자열을 정확히 두 배열의 끝에 추가했고 기존 두 항목과 순서를 보존했습니다.

투명한 사진 필름, 물리적 마운트, 이미지가 있는 필름을 통과하는 투과광, 마운트 개구부 안에 들어간 사진, 같은 필름의 가장자리 밀도/두께라는 5개 관계·게이트·증거 최소량은 유지됩니다. 카드보드 마운트·모니터 테두리·불투명 인화지의 두께는 대체 증거가 아닙니다. 별도의 유제 화학, 천공, 층 분리 의무를 추가하지 않았습니다.

## 검증 기준

고정 BEFORE는 `5bf8142304f484138474fff4af9b0660439fa331`이며 PR #3 런타임을 포함합니다. AFTER도 같은 런타임에서 비교합니다. 원문을 참고한 인공적 정규 계약 사례로, 실제 사용자의 자연 질의나 독립적으로 처음 작성한 장면의 검색률 실험은 아닙니다. 한국어 정확 요청에는 영어 증거를 사용합니다.

## 회귀 및 인덱스

새 회귀 4개는 실제 BEFORE에서 1실패·1오류를 재현했고 AFTER에서 모두 통과했습니다. 해당 변경·사진 시대·아세테이트·프로필 검색 29개 및 현행 출력 경계 15개, 합계 44개 집중 테스트와 사전 검증을 통과했습니다. 이전 V1–V5 역사 기준이나 현행 V6 기대를 수정하지 않았습니다. 이것은 전체 저장소 테스트 통과를 뜻하지 않습니다.

실제 Gemini embedding-2 응답으로 벡터 1개를 갱신했습니다. 다른 1,509개 프로필 항목은 텍스트와 벡터 모두 동일하고 3,667개 정확 조회 행도 동일합니다. BM25F 전역 통계와 해당 문서는 갱신되므로 모든 점수 불변을 주장하지 않습니다.

## 비용과 한계

승인 문맥 확인 전 차단되어 응답을 받지 못한 시도 1개와, 원래 승인 근거를 전달한 뒤 성공한 동일 재시도 1개를 각각 보수적으로 예약했습니다. 증가 추정은 $0.0032768입니다. 누적 요청 추정 $1.4368768 + 별도 과거 전송 재시도 불확실성 준비금 $5.7081856 = 계획 $7.1450624, 기존 $10 내 여유 $2.8549376입니다. 실제 청구액이나 독립적인 다른 작업의 계정 사용료가 아닙니다. 각 신규 SDK 호출의 전체 전송 시도 제한은 1입니다.

이 변경은 텍스트 계약에서 원래 허용된 분기를 직접 표현하는 문제를 해결합니다. 의미 앵커를 그대로 포함한 잘못된 소유관계 문장이 어휘 검사에서 통과할 수 있는 기존 한계를 해결하지 않습니다. 사진 생성·관찰, 필름 물성 판단, 픽셀 품질 향상은 검증하지 않았습니다.
