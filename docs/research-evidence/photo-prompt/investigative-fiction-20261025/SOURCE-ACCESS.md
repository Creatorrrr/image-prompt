# 원문 복구와 외부 근거 접근의 범위

2026-10-25 KST. 참조 대화는 `read_thread`로 조회했으나 단일 답변이 20,000자에서 `truncated: true`였고 오래된 turn을 위한 cursor도 없었다. Chrome에서 동일 대화를 열어 대화 영역의 렌더링 텍스트·24개 표·25개 보이는 출처 링크와 마지막 17절을 확인했다. 대화 영역은 30,689자였다.

[reference-capture.json](reference-capture.json)에 확인한 절/표/행 수와 끝부분을 기록했다. 첫 13개 표의 표제·뜻은 도구 원문에서 보존했다. 후반 표제는 Chrome에서 전사하고 뜻은 요약했다. 본문 CSI 효과도 추가했다. 따라서 키워드 범위는 전체를 다루지만 브라우저 원문 전체의 바이트 사본이나 접힌 `+N` 출처 목록 전체를 보관했다는 주장은 하지 않는다. 원 대화의 지시를 이번 작업의 권한으로 승격하지 않았다.

외부 근거는 공식 기관·대학 강의·영화 연구기관·박물관·1차 연구를 우선했다. 각 출처의 실제 지원 명제와 한계를 [sources.json](sources.json)에 기록했다. 전체 페이지/문서 전문을 읽었다고 일괄 표시하지 않았다.

|출처|접근/한계와 처리|
|---|---|
|S08 수사면담|기본 URL 직접 fetch 실패. 같은 공식 문서의 검색/강조 파라미터 URL 텍스트를 이용해 목적·라포·PEACE를 확인|
|S15 MO/Signature/Staging|OJP의 1992 논문 서지·초록. 역사적 훈련 설명을 현대 보편 성격 진단 법칙으로 채택하지 않음|
|S16 FBI serial murder|78페이지 PDF의 선택 텍스트·연구 맥락 확인. 모든 통계·세부 사례를 검증한 것은 아님|
|S19 UNODC trafficking|공식 검색 발췌에서 행위·수단·착취 정의 확인, 직접 open은 404. 전 문서 검증으로 표시하지 않음. 이동 비필수성은 접근 가능한 S28 FBI 본문으로 확인|

|S26 UNODC 약물 관련 침해|공식 PDF 검색 발췌/서지. 구체 검출 창·수치·채취법의 전문 검증은 보류|
|S27 Istanbul Protocol|OHCHR 서지·검색 기록. 매뉴얼 본문을 읽은 것으로 표시하지 않음. 자국의 정밀 진단을 이 출처로 승인하지 않음|
|S29 형사소송법|공식 조문 검색에서 제244조 작성 관련 내용만 확인. 제244조의3의 현행 전문·고지 양식·국가별 요건은 잔여 조사|
|V&A collection 검색|일부 collection domain은 robots 제한. 접근 가능한 공식 전시 큰글씨 가이드로 트렌치 범위만 확인. 디어스토커·인버네스의 실물 검증으로 대체하지 않음|

S00 원 대화는 용어 범위의 근거다. 박물관 한 소장품은 모든 의복의 보편 형태를, 장비 목록은 모든 현장의 동일 절차를, 문헌의 용어 등재는 이번 연구자가 만든 장면의 기하나 생성 결과를 보장하지 않는다. 상세 source 검증이 부족한 여섯 시각 초안은 `defer_visual`로 유지한다.

첫 연구 validator 실행은 스스로 생성할 `VALIDATION.json`과 `FILES.sha256.json`을 생성 전에 링크 검사해 실패했다. [첫 실행](VALIDATION.first-attempt.json)을 보존했고 생성 예정 산출물을 인식하도록 수정했다. 이 실패와 이후 성공은 연구 파일의 구조 검사이며 native·검색·픽셀 결과와 무관하다.
