별표 3쌍을 먼저 실행하고 입력·표본 노출·실제 채택·전송 receipt·저장 픽셀의 연결을 확인한다. 나머지 11쌍은 source/검색이 준비되고 비교가 유효할 때 확장한다. 시나리오마다 동일 requester 의미와 creativity, 모델·해상도·참조 입력을 유지한다. 모델이 seed 통제를 제공하면 같은 조건을 사용하며 제공하지 않으면 비결정성 한계를 보고한다.

평가자는 (1) 필수 의미·소유·연결, (2) 해부/물리적 개연성, (3) 필요한 관계의 투영 크기·초점·가림·대비, (4) 조사 상황과 목적의 판독, (5) 인물 존재감·시각적 위계·전반적 품질을 구분해 기록한다. 작은 글자의 철자 성공과 상황 이해도도 별도다. 양쪽에서 선택 source가 실제로 달라지지 않았으면 그 쌍은 데이터 효과의 인과 비교로 해석하지 않는다.

필수 끝점 중 하나라도 숨거나 너무 작으면 `UNOBSERVABLE_NOT_PASS`; partial은 전체 실패. 모델 거절/출력 미확보는 `BLOCKED_UNSCORED`. 실패 후 재생성은 새 시도로 기록하고 이전 실패를 삭제하지 않는다. 사용자 수용은 별도 미확인 상태다.

시신 절단·고문·성적 침해·미성년 착취·시체성애는 이번 기본 사진 비교 장면에 넣지 않았다. 원 개념·기존 source의 전체 뜻과 문맥 경계는 연구에서 유지하며, 봉투·모형·담요·분장 표본을 해당 행위의 동일 의미 성공으로 계산하지 않는다. 별도 명시적 평가가 필요한 의미와 매체/근거가 갖춰진 경우에만 독립 설계한다.
