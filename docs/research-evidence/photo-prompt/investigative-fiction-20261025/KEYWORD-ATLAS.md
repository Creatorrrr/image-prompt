# 수사물 전체 키워드 지도

표 1–22의 용어 320개 + 본문 CSI 효과 1개, 혼동 10개, 창작 조합 8개. 표제 전사와 설명 요약의 출처 상태를 JSON에 구분했다. 모든 항목의 독립 사전 검증 완료를 뜻하지 않는다. 카드는 선택적·인접 대안이지 동의어나 자동 활성화 규칙이 아니다.
