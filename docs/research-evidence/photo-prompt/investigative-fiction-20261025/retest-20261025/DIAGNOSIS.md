## 픽셀 실패와 설계 가설

- A는 A-17/9,800,000의 화면·명세서 일치가 선명했다. 연필 끝은 원으로 표시된
  행 위·왼쪽의 다른 영역에 닿았다. 텍스트에 정확한 접촉을 썼다는 사실이 픽셀
  접촉을 보장하지 않았다. 소유 팔, 실제 흑연 끝, 원 경계와 표면을 함께 보이게
  하는 위치·각도·가림을 재설계한다.
- B는 조사 동작과 별도 담당자의 양손-카트 접촉이 보였다. 두 절단 끝 사이의
  명확한 틈은 금속 걸쇠 부근에서 불확실했고 인물 발·상자 바닥 지지가 잘렸다.
  얼굴의 존재감, 작은 봉인, 네 발과 바퀴의 동시 관찰 요구가 경쟁했다는 것은
  합리적인 설계 가설이다. 두 끝과 배경 틈, 지지 경로를 프레임 내에서 구분한다.
- C는 사진을 이용한 탐문과 직원의 지도 응답이 보였다. 조사자의 눈은 지도
  대신 직원 얼굴을 향했고 사진/펜의 좌우 팔 역할이 반전됐다. 펜촉-종이 간격은
  보이지 않았고 손끝은 부두 표식이 아닌 다른 분기를 짚었다. 한 시점의 시선과
  손/도구/대상 관계를 정적으로 분명하게 설계한다.

이것은 한 장씩의 관찰에서 얻은 실패 위치와 설계 가설이다. 특정 프롬프트
단어나 자료 하나가 실패를 일으켰다는 인과 증명으로 기록하지 않는다.

## 변경과 검증 방식

18개 시각 대안은 이전 실패와 source 판단에서 작성했으며 새 arm의 baseline·
query 원문을 읽기 전에 `repair-cards.frozen.json`으로 고정했다. 3개 diagnostic과
39개 optional binding을 추가했고 기존 모든 후보·조건·효과·출처·binding은
보존했다. 새 일반 geometry 자료는 나이를 주장하지 않으며, 기존 adult 조건을
없애거나 reference에서 나이를 추론해 통과시키지 않는다.

서로 입력을 공유하지 않는 새 에이전트 3개가 이전 부모의 닫힌 retry projection만
받는다. 부모 후보·이전 프롬프트·다른 arm은 보지 않는다. 같은 컨셉·참조 appearance·
사건 의미·controls를 보존하고 지역적인 관계/구도 수정을 새 lineage-v2에 묶는다.
과거 실패 gate와 전체 판정 기준은 약화하지 않는다. 새 slot plan은 긍정 시각
목적만 담고 법적/서사적 한계는 별도 노트에 남긴다.

실제 반영은 다음 사슬로 확인한다: 반환 CID와 source hash → 전체 source 검토 →
선택 이유 → 독립 baseline에 없던 최종 literal 구절 → 실제 native 입력 hash →
저장 이미지 hash → 사전 source 관찰 기준과 기존 관계 gate. 기존 baseline에
이미 있는 사실, 검색 노출, 단순 keyword 일치는 신규 기여로 세지 않는다.
`inspiration_only`의 실제 일반 기여와 native 전체 계약 채택도 별도로 기록한다.
후자는 여전히 모든 조건·owner·효과·권한과 독립 native qualification을 요구한다.


## 재시험 중 발견한 별도의 실행 오류

B의 보존 appearance 사실은 `request`와 `reference`를 함께 출처로 삼았다.
기존 coordinator는 의미 항목과 reference가 정확히 같아도 해당 사실이 인용하는
이전 request hash까지 child에 그대로 요구하여 정상 재요청을 거부했다. 이것은
앞선 이미지 세 장의 관계 실패 원인으로 소급하지 않는 별도의 재시험 실행 오류다.
`prepare_retry_context.py` 한 곳에서 이미 검증된 parent/child request_text의 출처
재바인딩만 허용했다. 비요청 텍스트·참조 파일·의미 내용·owner·scope 상태는 계속
동일해야 한다. 관련 테스트 49개(그중 scope inventory 19개), 실제 B 보존 사실
5개 대조와 17개 authoring/control 해시를 유지한 fresh-run 복구가 통과했다.
실패한 run과 오류 기록은 보존했다.

## 설치 및 검색 검증
