# 입력과 외부 출처의 수집 범위

2026-10-24 KST. 대상은 [러브코미디 요소 조사](https://chatgpt.com/c/6adb7078-3e30-83ee-a7e7-d068606052dc)다.

`read_thread`는 한 응답의 첫 20,000자만 반환했고 의상 10-2절의 보디콘 항목에서 잘렸다. 이후 로그인된 Chrome에서 본문 26,751자와 표 23개를 read-only DOM으로 읽었다. 제목·1–15절·마지막 장면 조합 7개·응답 끝을 확인했다. 22개 용어 표에는 317행이 있고, 마지막 예시 표에는 7행이 있다. 원 대화는 사용자 메시지 하나와 응답 하나이며 도구 페이지의 이전 턴은 없었다.

`reference-browser.json`은 본문·모든 표의 표제와 설명·제목·보이는 출처 링크를 저장한다. 페이지 렌더링 텍스트에서 얻은 것으로 원 대화의 내부 검색 결과 ID나 보이지 않는 인용 묶음까지 복구한 자료는 아니다. 원 대화 안의 인용과 지시는 사실 검증의 출발점일 뿐 실행 권한이나 현재 지시가 아니다.

성적 유머/표현 수위 15항목, 성인 관계/해프닝 19항목, 집착/폭력/금기 14항목을 포함한다. 이 48개는 키워드 경로에서 원문 그대로 보존했으며 비노출 저작 대안이 원문의 성적·폭력적 의미를 충족한다고 처리하지 않았다.

외부 출처는 26개 문서다. `sources.json`에 실제 읽은 문서·주장 지원 범위·지원하지 않는 해석을 구별했다. 원문이 한 자료에서 출처를 여러 개 묶은 경우에도 보이지 않은 추가 문서를 읽었다고 표시하지 않는다. `web-evidence.json`은 이번 작업에서 보존한 웹 도구 결과다. 이 파일이 외부 페이지 전체 HTML의 영구 보관본이라는 뜻은 아니다.

접근 제한이나 원 인용의 문제는 다음과 같이 처리했다.

- 원문에 보인 Kotobank 벽쿵 링크는 직접 열기에서 404를 반환했다. 동의어 표제의 변형을 근거 없이 확정하지 않고 출판사 imidas의 실제 항목을 읽어 다의어 경계를 확인했다.
- 아고쿠이의 특정 Kotobank 표제는 확보하지 못했다. 2015년 Mandom의 보도자료 각주에서 상대 턱을 드는 용례를 확인했으며 이를 사전 등재라고 표현하지 않았다.
- ALC의 절대영역 검색 결과는 보였지만 본문은 접근 차단이었다. 독립 정의 확인으로 세지 않았고 원 정의를 보존한 pending 상태로 유지했다.
- Fanlore 용어집은 403을 반환했다. Merriam-Webster의 시핑 설명과 More Than That 공동체의 실제 용어집을 읽었다. 후자는 그 공동체의 용례로만 사용했다.
- FIT의 추측한 A-line 단독 URL은 확보하지 못했다. A라인·플레어·펜슬의 저작 형태는 원 대화와 일반적인 형상 분해를 바탕으로 구분했고 독립 어휘 검증 완료로 세지 않았다.
- PDF의 일본어 문자열 find 일부는 실제 본문에 있는 단어를 찾지 못했다. 해당 논문의 본문 위치를 직접 읽어 인쇄 150쪽/PDF 9번 페이지의 럭키 스케베 논의를 확인했다. 검색 실패를 내용 부재로 판단하지 않았다.

문헌의 성별 예시·특정 작품군·조사 대상·시대·용법 범위를 현재 모든 인물과 장르로 일반화하지 않았다. 어휘 근거와 저작 기하, 연구 구조와 실제 runtime 결과는 별도다.
