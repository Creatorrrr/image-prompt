# 실제 이미지 검증 설계

2026-10-24. 현재 **모두 NOT_RUN**. 다음은 반영 후 수행할 12개 사진 장면의 baseline/stage 비교안이다. 비교당 같은 실제 요청·독립 core·허용 효과·생성 환경을 사용한다. 각 카드 문구는 기대 증거의 설명이며 사용자 요구를 대신하지 않는다.

P01–P03의 3쌍을 먼저 수행하는 안이다. 비교 입력이나 receipt·픽셀 연결에 문제가 있으면 그 상태를 복구한 다음 추가 생성한다. 반복 횟수와 비용은 후속 실행의 실제 자원 범위 안에서 정하며 이번에는 이미지 도구를 호출하지 않았다.

평가 기록은 요청/envelope/core/source/index/실제 선택/prompt/transport/저장 이미지 해시를 연결한다. 각 필수 명제를 supported/failed/unobservable로 판정하고 전체 장면은 모든 필수 명제가 supported일 때만 PASS다. `partial_is_fail`, `UNOBSERVABLE_NOT_PASS`, `BLOCKED_UNSCORED`를 유지한다. 접점 확대에서만 보이고 전체 장면에서 소유자를 알 수 없는 경우를 완전 성공으로 승격하지 않는다.

로맨스·웃음의 전달은 기하 판정과 별도다. 장면 정보를 모르는 판독자에게 ‘무슨 일이 보이는가, 누가 무엇에 반응하는가’를 기술하게 하고 사용자 의도와 비교한다. 등장인물의 실제 진심·합의·과거를 픽셀 정답으로 채점하지 않는다. 사소한 소품 정확도와 전체 장면의 전달력을 합치지 않는다.

M01–M04의 만화 기호는 일러스트 경로의 source/binding이 준비된 경우에만 별도 4장면 비교를 설계한다. 사진 비교에 그 결과를 합산하지 않는다. 나체·성행위·비동의 성적 접촉의 생성 시나리오는 이 계획에 작성하지 않았다. 원 연구 용어와 실제 생성 범위는 별도다.
