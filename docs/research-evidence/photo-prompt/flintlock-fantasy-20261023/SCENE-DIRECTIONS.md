# 장르 조합을 실제 장면 관계로 옮기는 방향

원문 17절의 여덟 조합을 연구 방향으로 보존한다. 아래는 선택 가능한 장면 설계이며 요청자의 의도·소품·인물·시대·팔레트로 자동 고정하지 않는다. 서사 의미와 가시 배치를 구분하고, 실제 작성 때 같은 장면에 맞는 완전 후보만 선택한다. 이미 다른 장르에 있는 후보도 원문·조건·효과·자격을 다시 대조해야 한다.

| 원문 조합 | 장면 전체를 조직하는 관계 | 검토할 데이터 | 가시 증거의 한계 |
|---|---|---|---|
| Gothic Horror | 궁정 출입구의 오래된 가문 표상과 그 문 바깥에 붙는 새 인쇄물을 서로 마주 보게 배치한다. 읽는 사람의 손과 종이, 출입구 경계를 중심으로 잡는다. | G02, D05/D06, I07, 기존 gothic/유물의 실제 전체 source | 그림·문장·인쇄물만으로 혈통 권력·흡혈귀·혁명 성공을 확정하지 않음 |
| Cosmic Horror | 관측 장치·기록지·탄도 도식을 같은 작업 면의 읽을 수 있는 관계로 둔다. 관측자가 바라보는 대상과 도식의 표현 층을 분리한다. | A07, H03, I13/I21, 기존 천문·cosmic source | 도식/시선으로 실제 우주적 존재·관측 성공·광기를 증명하지 않음 |
| Medical Horror | 사람의 잔여 사지와 별도 의지·소켓·도구의 거리를 중심으로 장면을 만든다. 손의 주인과 신체/기구 경계를 먼저 정한다. | F07, H05, J14, I18, 감사된 의지 원문 | 상처·회복·감염·통증·기억·법적 신분은 독립 선언/근거 필요. 모형/분장/실제 몸을 혼합하지 않음 |
| Clockpunk | 인간과 자동기구의 공동 작업에서 감기/정비 도구가 어디에 닿고 누가 지지하는지를 구성의 중심에 둔다. | F01/F06, H08, I19/I21, 기존 clockpunk의 native 자격 source | 태엽·명령서로 의식·책임·복종·권리를 판정하지 않음 |
| Decadent Aesthetic | 궁정복의 수선·속치마·가구의 섬세한 경계와 문 너머 생활/보급 공간을 하나의 깊이 관계로 배치한다. | G06/G07/G09, J09/J13, I08/I17 | 사치 외형만으로 성적 관계·식민 수탈·부채의 인과를 증명하지 않음 |
| Political Thriller | 장부·봉인된 문서·신호 장치가 한 인계 동선에서 어떤 손과 표면을 점유하는지 정한다. 문구는 필요한 경우에만 고정한다. | G02/G04, E06, H04, I07/I08 | 문서가 실제 쿠데타·승인·공모·비밀 전달 완료를 증명하지 않음 |
| Cozy Fantasy | 여관 작업대의 수리/음식 인계를 중심으로 성인 인물의 손·도구·수납·출입 동선을 구성한다. 평온한 낮도 열어 둔다. | F03/F04, J13, I16/I21, 감사된 의지 원문 | 제복·의지에서 전쟁 피해 원인·퇴역 사실·트라우마를 자동 추론하지 않음 |
| Posthuman Fiction | 몸과 외부 부품의 소켓·분리·교체 경계를 중심으로, 계약 문서는 다른 표현 층으로 둔다. | H06/H07, I09/I18/I21, 기존 posthuman source | 신체 변화·계약서·해골만으로 시민권·노예 신분·사후 복무·의식/동의 확정 금지 |
