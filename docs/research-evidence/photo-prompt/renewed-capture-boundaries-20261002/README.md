# 촬영 효과 프로필의 자기 제외 문구 교정

기준 커밋: `ebd10bcb9bfd963d585cc4bdacf6e28cbe19940c`.

## 수정한 데이터

광각 근접 원근·패닝·후막 동조·네거티브 필·광학 디퓨전·혼합 광원 화이트밸런스·하이라이트 롤오프, 7개 프로필의 영어 경계 성분과 대응하는 영어 증거 앵커를 교정했다. 실제 변경은 14개 문자열이다.

이전 영어 문구는 “camera shake가 아닌 추적”처럼 자기 프로필의 제외어를 포함해, 작성된 성분을 모두 제공해도 스스로 검색 대상에서 빠졌다. 이제 실제로 보여야 할 물리적 관계를 긍정형으로 기술한다. 정의·exact 별칭·제외 규칙·필수 성분 수·대조 예시·대체 실패 조건·렌더 게이트·증거 최소 길이는 유지했다.

작동하던 한국어 성분 문구도 전부 유지했다. 처음 시도한 한국어 동시 교정은 기존 패닝 회귀 테스트에서 유효한 표현을 잃는 문제가 드러나 폐기했다. 기존 테스트의 입력이나 판정 기준을 바꾸지 않고 데이터 수정 범위를 줄여 해결했다.

의미 근거는 기존 [촬영 효과 연구](../capture-elements-visual-semantics-20260902/source-research.md)를 따른다. [Nikon 패닝 설명](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/10-tips-for-better-camera-panning), [Nikon 플래시 설명](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/flash-points-the-control-of-light), [Tiffen 디퓨전 안내](https://tiffen.com/pages/diffusion-guide)도 재확인했다.

## 결과와 해석 범위

- 영어 전체 성분을 연결한 자기 일관성 진단: 타깃 발견 0/7 → 7/7
- 기존 한국어 전체 성분 진단: 7/7 → 7/7 유지
- 수정 전후 각각 제외어 주입 56개, 필수 성분 누락 70개, 영어 별칭 부정 28개는 계속 차단
- exact 별칭 28개는 기존 활성화 유지
- 수정한 영어 증거 앵커 단독 최소 길이 감사: 1/7 → 7/7. 다른 성분의 앵커만 나열한 것은 완전한 장면 증거가 아니므로 전체 프롬프트 감사 통과로 해석하지 않음
- 사전 자료를 보지 않고 작성한 자연 장면 14개: 타깃 발견 0/14 → 0/14. 전체 반환 프로필 ID·순서는 같고 일부 점수만 변함

따라서 이 단계의 성과는 작성된 데이터의 자기 모순 제거와 기존 한국어 경로 보존이다. 자연어 검색 성능 향상·전체 부정문 처리 개선·이미지 품질 향상을 입증한 결과가 아니다. 자연 장면 평가는 완전한 생성 CLI와 정규화 코어를 거치지 않은 resolver 진단이며, 질의 임베딩과 이미지 생성은 수행하지 않았다.

## 검증과 비용

관련 테스트 40개(새 회귀 4개 포함), 전체 사전 메타데이터, 현재 시각 의미 인덱스 검증이 통과했다. 1,419개 프로필 중 7개만 새 텍스트·벡터를 적용했고 1,412개는 보존했다.

초기 21문자열 시험과 한국어 호환성 복구 후 갱신을 합쳐 이 단계 임베딩 성공 호출은 14회다. 이 단계 비용의 보수적 상한은 $0.0229376, 프로젝트 누적 상한은 $1.3729792 / 허용 $10이다. 실제 청구 금액이 아니며 폐기한 시험 비용도 포함한다.
