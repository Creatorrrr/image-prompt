# 아이돌물 시각 카드 초안

모든 카드는 연구용 선택 대안이다. 출처는 분야·기능 맥락을 뒷받침하며 아래 전체 장면은 작성자가 설계했다. 출처의 정확한 표본·모든 구조가 확인되었다는 뜻이 아니다. 실제 데이터 등록·native 자격·검색·이미지 검증은 실행하지 않았다.

## I001 거울 앞 위치 맞추기

퍼포머 세 명이 서로 다른 바닥 테이프 십자 위에 서서 벽 거울을 바라보고, 거울에는 같은 세 사람과 간격이 비친다.

Three performers stand on separate floor-tape crosses facing one wall mirror, which reflects the same three bodies and their spacing.

- 관찰: 실물 세 명과 거울상 구분 / 각 발과 별도 테이프 위치 / 일치하는 반사 배치
- 경계: 거울상은 추가 멤버가 아니며 연습 횟수는 보이지 않음
- 출처 맥락: S02, S06; 전체 장면은 저자 설계.
- 제안 슬롯: composition, location; 개별 역할 적합성 검토 전.
