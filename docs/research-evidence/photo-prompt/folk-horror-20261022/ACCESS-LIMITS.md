# 접근 범위와 남은 조사

## 참조 대화

`read_thread`의 20,000자 상한으로 답변이 115번 도중 잘렸다. IAB에서는 로그인 화면으로 이동했다. 로그인된 Chrome에서 지정한 원 대화를 읽어 150개 제목 전체, 115~150 설명, 작품·조합 예시, 출처 링크를 확인했다. 새 질의를 보내거나 원 대화를 수정하지 않았다. `seed-keywords.json`은 그 제목 목록이며 원문 전체의 보존본은 아니다.

## 외부 자료

43개 자료의 access 값은 `sources.json`에 있다. `body_read`와 발췌·해당 절·출판사 소개·검색 본문은 다른 증거 수준이다. S11·S24는 PDF 텍스트를 읽었고 원본 도판의 시각 검사는 하지 않았다. 외부 자료의 이미지를 내려받거나 이미지 데이터셋으로 등록하지 않았다. 이번 결과는 텍스트 기반 의미 연구이며 실물 픽셀 참조의 완전한 대체물이 아니다.

접근 실패도 다음과 같이 보존한다.

## 후속 원전 보강

150개 route는 모든 정의의 독립 검증을 뜻하지 않는다. 특히 X07~X15가 묶은 세부 개념의 사료, 지역별 연행, 계절, 역사적 주장에는 추가 개별 근거가 필요하다. 실제 자료 반영에서 broad context group의 출처만 달고 독립 사실 검증이 끝났다고 기록하지 않는다.

원전 후속 조사 우선순위는 (1) 한국 직능·제차·손님굿과 일본 대리물/부정 개념의 개별 항목, (2) 각 전승 존재의 지역 판본과 원주민 당사자 자료, (3) 희생·신체·성적 관습의 사료와 비판적 연구, (4) 실제 도판의 부착·재료·전체 구조 확인이다. 사료가 약한 항목도 목록에서 지우지 않고 `defer` 이유와 재개 조건을 남긴다.
