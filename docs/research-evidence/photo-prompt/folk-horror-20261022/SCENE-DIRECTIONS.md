# 원 대화의 여섯 조합을 장면으로 연결하기

각 장면은 저술한 방향 제안이다. 원 대화의 조합이 실제 관습의 증거이거나 자동 prompt preset인 것은 아니다. 독립 baseline을 동결한 뒤 호환되는 경우에만 후보로 비교한다.

| 원 조합 | 선택 가능한 한 장면 | 연결 카드 | 사진 밖에 남는 의미 |
|---|---|---|---|
| 흉작 + 의례 달력 + 조상의 빚 + 제물 선정 | 손상된 밭 옆 작업대에서 한 성인이 다른 성인이 든 상자의 제비를 뽑고 주민들은 그 손을 바라본다 | L12/R04/X04/X06 | 매년 반복, 생존 계약, 조상의 부채, 다음 희생자의 죽음 |
| 당산나무 + 금줄 + 동티 + 집단적 공모 | 보호 경계의 나무 곁에서 잘린 줄 한쪽을 든 성인이 있고 다른 주민은 마을 출구에 서 있다 | K01/K05/R02/X14 | 금기 위반과 재난의 인과, 주민의 계약과 공모. K01의 완전한 줄 branch를 훼손 상태에 그대로 적용하면 안 됨 |
| 성혼 + 족내혼 + 생식 강제 + 세습 저주 | 두 성인이 서로 떨어진 의자에 앉고 별도 관리자가 두 사람 앞에 계보 문서와 잠긴 문 열쇠를 둔 장면을 검토 | R10/X12/X13 | 혼인·족내혼·근친·성행위·임신·동의·강제의 사실은 각각 별도 근거. 신체 노출을 강요의 대용물로 쓰지 않음 |
| 문턱 + 환대의 함정 + 사역령 + 벽사 표식 | 그릇을 내미는 주인과 문설주의 작은 표식을 보되 고양이는 열린 책 곁의 독립 동물로 남긴다 | L03/R02/O11/O14 | 고양이의 사역 계약, 표식의 보호 능력, 손님이 떠나지 못하는 초자연 규칙 |
| 봉분 + 습지 시신 + 망자 귀환 방지 + 겹친 풍경 | 현대 공사 단면 아래 고분 구조가 드러나는 장면 또는 이탄층 손을 조사하는 장면 중 하나를 선택 | L07/L13/V01/X11 | 봉분과 습지를 무리하게 합치지 않음. 시신의 사인·동일인·귀환 방지 목적은 미입증 |
| 애니미즘 + 요리시로 + 순환 시간 + 이류혼인 | 의례 표식이 있는 나무 앞에서 두 성인이 나란히 서고 한 사람이 별개의 가죽을 든 장면을 검토 | J02/E02/X04/X07/X12 | 실제 신의 강림, 인간/비인간 변신, 혼인, 혈통 관리, 반복 시간. 요리시로와 셀키를 한 문화의 실제 의례로 기록하지 않음 |

장면을 풍부하게 만들 때 모든 카드의 요소를 합칠 필요는 없다. 역할·인물 수·부착물·공간을 추가할수록 보존해야 할 관계가 늘어난다. 원 요청의 핵심과 눈으로 읽을 수 있는 하나의 상황을 우선하고, 호환되지 않거나 장면을 약하게 하는 선택은 제외한다. 채택한 후보의 일부 의무를 임의로 지우는 방식으로 단순화하지 않는다.
