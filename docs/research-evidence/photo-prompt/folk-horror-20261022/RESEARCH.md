# 포크 호러 시각 의미·후보 데이터 보강 리서치

2026-10-22 / 연구와 반영 설계. 운영 데이터 등록·검색 실험·이미지 생성은 이번 범위에 포함하지 않았다.

## 결론과 조사 범위

가장 큰 공백은 ‘포크 호러다운 사물 목록’보다 **장소가 만드는 제한, 집단이 집행하는 규칙, 개인과 제물의 관계를 관측 가능한 장면으로 연결하는 자료**에 있다. 후보는 숲·안개·뿔·피를 자동 추가하는 장식 사전보다, 선택한 장면을 성립시키는 재료·배치·접점·역할·반응을 제공해야 한다.

참조 대화 [포크 호러 용어 조사](https://chatgpt.com/c/6ad9b8ff-0f90-83ee-8569-db8cbb39c657)의 150개 번호와 용어를 복원했다. 연결 도구는 20,000자에서 115번 중간을 잘랐으나 로그인된 Chrome의 원 대화에서 150개 제목 전체와 후반 설명을 확인했다. 원 대화는 조사 출발점이고 사실 검증의 최종 권위가 아니다. 43개 외부 자료의 실제 읽은 범위를 [출처 장부](SOURCES.tsv)에 구분했다. 모든 원전·책 전체를 읽거나 150개 용어를 개별 독립 검증한 결과는 아니다.

지금 필요한 반영 단위는 다음과 같다.

| 자료 | 필요한 정보 | 여기서 확보한 것 |
|---|---|---|
| 용어 경로 | 같은 단어의 가시·비가시·지역·시대·판본 의미 | 원 항목 150개 전수 경로, 한영 표현, 카드 연결 |
| 시각 의미 | 소유자·부분·부착·위치·방향·조건·혼동 | 70개 가시 실현 카드와 19개 문맥 경계 카드 |
| 후보 | 선택 가능한 완전한 장면/물체, 번역, 실현별 의무 | 한영 70개 연구 초안. CID/RID/native proof는 없음 |
| 근거 | 확인한 정의/물체와 저술한 장면의 분리 | 출처 43개, 읽은 범위와 주장 한계, 기존 레코드 스냅샷 |
| 검증 | 노출·선택·프롬프트·원본 픽셀·관객 평가 | 한영 평가 사례와 3 arm 이미지 비교 설계. 실행은 NOT_RUN |

숫자를 합산해 데이터가 그만큼 증가했다고 보지 않는다. 70개 초안은 같은 70개 가시 카드의 후보 표현이다. 신규 CID 수는 기존 완전 소스를 비교한 뒤 결정된다.

## 1. 장르의 단위를 관계로 바꾼다

Scovell의 BFI 설명은 풍경이 고립을 만들고 공동체의 신념이 폭력·소환 등의 사건으로 이어지는 연결에 초점을 둔다. 이는 출발점이며 모든 작품의 필수 도식은 아니다. Keetley의 연구는 영미 중심의 정의가 다른 지역의 역사를 모두 설명하지 못함을 드러낸다. 따라서 `folk horror` 하나를 전역 강제 profile로 만들지 않는다. [BFI](https://www.bfi.org.uk/features/where-begin-with-folk-horror), [Revenant](https://www.revenantjournal.com/contents/introduction-defining-folk-horror-2/)

예를 들어 ‘고립된 마을’은 안개 낀 숲 사진만으로 충분하지 않다. 사진에 어떤 제한을 보여줄지 먼저 결정한다. 잠긴 연결도로, 문을 가로막는 주민, 주인을 향한 환대와 뒤쪽 출구의 차단은 각각 다른 후보가 된다. ‘집단적 공모’도 나란히 선 주민의 얼굴로 입증되지 않는다. 같은 출구를 막는 역할 분담이나 같은 대상에 향한 동작을 가시 단서로 제안하고, 공모·동기는 서사 해석으로 남긴다.

| 개념 | 관측 가능한 저술 선택 | 단독으로 확정할 수 없는 의미 |
|---|---|---|
| 고립 | 도로-해안-섬 연결 중 일부가 물 아래 잠김 | 완전 탈출 불가, 밀물의 진행, 교통수단 부재 |
| 내부자/외부인 | 길 끝의 집단 원 밖에 한 인물 | 출신, 거주기간, 신앙, 실제 소속 |
| 환대의 함정 | 그릇을 내미는 주인과 출구를 막는 별도 인물 | 감금 의도, 손님의 동의, 마을 전체의 공모 |
| 희생자 선정 | 상자-선정 손-쪽지의 연결 | 희생·사망, 절차의 공정성, 결과의 필연성 |
| 반목가 | 아름다운 들판과 같은 화면의 출입 차단 | 관객이 느낄 두려움의 강도 |
| 유령론/기록물 공포 | 서로 다른 사진과 수첩에서 반복되는 표식 | 기록의 연대·진위·동일 인물·과거의 인과 |

위 장면은 연구자가 만든 후보 표현이다. 비평 자료가 이런 장면의 실제 관습을 보증하는 것은 아니다.

## 2. 풍경은 배경 명칭보다 실제 형태와 동선을 보강한다

L01~L14는 길·문턱·조수 통로·숲 경계·거석·봉분·우물·습지·작물·층위·도시 하부를 구분한다. holloway는 양옆 땅보다 낮은 노면이 핵심이며 단순 숲길과 다르다. 조수섬에서는 섬만 보여주는 대신 육지와 섬 사이의 통로를 읽히게 해야 한다. 거석 원·봉분·겹쳐진 옛 구조는 각각 독립 형태다. [National Trust 유적 기록](https://heritagerecords.nationaltrust.org.uk/HBSMR/MonRecord.aspx?skin=printerfriendly&uid=MNA141529), [English Heritage 풍경 연구](https://www.english-heritage.org.uk/learn/story-of-england/prehistory/landscape/)

`bog / fen / moor`는 한 원어 그룹에 묶였어도 후보에서는 나눈다. 이탄층의 절단면, 갈대와 얕은 물길, 낮은 식생의 열린 구릉은 다른 선택이다. 사진이 수문학적 분류를 확정하지 못한다는 한계도 남긴다. ‘질병에 걸린 작물’은 병명부터 붙이기보다 검게 처진 줄기와 옆의 녹색 작물을 비교해 손상 자체를 보인다. 원인·신의 분노·누군가의 책임은 별도 맥락이다.

### 재료에서 생기는 장면의 차이

짚은 곡식단·가면 의상·기둥 경계줄·버들가지 형상과 바꿔 쓰면 안 된다. 밀랍·천·뼈·나무·돌도 같은 ‘오래된 의례 물체’로 평탄화하지 않는다. F02처럼 어느 재료가 어느 틀에 봉합되고 어떤 흔적이 접합부에 남는지 연결한다. 표면의 낡음은 진품·고대·특정 민족의 증거가 아니다.

## 4. 한국 자료는 독립적인 구조와 지역 차이를 보존한다

한국형 포크 호러를 `shaman + horror`로 검색하는 방식만으로는 부족하다. K01~K09는 한국 자료가 설명하는 물체와 제차를 별도 연결로 저술했다.

| 카드 | 형태·관계 보강 | 한계 |
|---|---|---|
| K01 금줄 | 두 문기둥 사이의 왼 새끼줄, 같은 줄에 끼운 숯·솔가지 | 부착물은 지역별로 달라 선택한 조합만 의무화. 출산·성별 추정 금지 |
| K02 서낭당 | 길목의 누석단-신목-부착 천 | 당집·입석 등 다른 형태는 별도 branch. 도리이를 기본값으로 쓰지 않음 |
| K03 장승 | 얼굴이 같은 나무·돌 기둥에 새겨진 구조 | 쌍·명문·표정·악령성을 보편화하지 않음 |
| K04 솟대 | 장대 꼭대기에 고정된 새 형상 | 날아가는 생물 새와 구별. 새 종류·수·방향은 표본별 |
| K05 당산나무 | 나무와 주변 경계의 범위·줄 양끝 | 특정 마을의 실제 의례 재현은 별도 자료 필요 |
| K06 굿 | 연행자·악사·악기·제상의 소유와 향하는 방향 | 굿의 종류·지역 복식·퇴마·강신은 별도 정의 |
| K07 고풀이 | 긴 무명천의 매듭과 양손 접점 | 매듭의 가시 상태와 한의 실제 해소를 분리 |
| K08 씻김 | 옷을 감싼 돗자리와 위에 놓인 주발의 상징 구조 | 상징물을 실제 시신으로 바꾸지 않음. 제차 전체를 충족하는 후보는 아님 |
| K09 길닦음 | 상징물-긴 무명천-바닥의 관계 | 사후 세계·천도의 성공은 미입증 |

근거: [금줄](https://encykorea.aks.ac.kr/Article/E0008002), [서낭당](https://encykorea.aks.ac.kr/Article/E0027672), [장승](https://encykorea.aks.ac.kr/Article/E0048619), [솟대](https://encykorea.aks.ac.kr/Article/E0030608), [굿](https://encykorea.aks.ac.kr/Article/E0006765), [씻김굿](https://encykorea.aks.ac.kr/Article/E0034204).

무당/강신무/세습무, 신병/내림굿, 공수, 부정, 동티, 원혼/객귀, 손님신/손님굿은 삭제하지 않고 X14에 남겼다. 다만 개별 직능·신병·질병·말의 출처를 외형으로 판정하지 않는다. 이번에 각 세부 항목의 원문을 모두 독립 재확인한 것은 아니므로, 해당 직능을 직접 설명하거나 실제 지역 의례를 재현할 후보의 채택 전에 원전 보강이 필요하다.

## 5. 일본과 다른 문화권의 요소는 비교하되 합치지 않는다

시메나와와 한국 금줄은 둘 다 경계를 표시할 수 있어도 동일한 alias가 아니다. J01은 나무-짚줄-선택한 시데의 부착을 기록하고 K01은 그와 다른 재료 조건을 갖는다. 요리시로는 신령이 내리는 매개라는 기능이며 가타시로는 대리물이라는 다른 기능이다. 나무·종이·인형이라는 외관만으로 두 기능을 바꿀 수 없다. 내방신은 무서운 가면을 쓰더라도 환대·복·교육·공동체의 전승과 연결되며 악령의 습격으로 고정할 수 없다. [Kokugakuin 시메나와](https://d-museum.kokugakuin.ac.jp/eos/detail/?id=9616), [요리시로](https://d-museum.kokugakuin.ac.jp/eos/detail/?id=9657), [UNESCO 내방신](https://ich.unesco.org/en/RL/raiho-shin-ritual-visits-of-deities-in-masks-and-costumes-01271)

전승 존재의 강화는 외형을 하나씩 더 붙이는 과정이 아니다.

- **켈피:** 말형·인간형·복합형을 독립 판본으로 다룬다. E01의 말 갈기 수초는 자료의 인간형 단서를 옮겨 저술한 변주임을 표시했다. 전통 표준 외형이라고 등록하면 안 된다.
- **셀키:** 사람-별도 물범 가죽-다른 소유자의 도달 거리로 소유 관계를 설계한다. 변신의 전후나 강제 혼인은 맥락이다. 인어와 동의어로 처리하지 않는다.
- **라 요로나:** 실제 기록은 외형·행동·관계가 다양하다. E04는 한 연출이며 흰 드레스·두 아이·익사를 필수화하지 않는다.
- **아스왕/마나낭갈:** 포괄 범주와 분리 상체 유형을 나눈다. E05를 선택하면 상체·하체·분리 범위가 함께 보여야 하며 날개만으로 통과하지 않는다.
- **웬디고:** S24는 사슴뿔·사슴 머리의 현대 비원주민 매체 재구성을 전통의 보편 원형과 구분한다. 특정 원전을 지정하기 전에는 X18 경계 자료를 먼저 두고 기본 외형 신규 후보는 보류한다.
- **바바 야가·루살카·야마우바·밴시·와일드 헌트:** 원 대화 항목과 문맥 경로는 보존했다. 이번에 확보한 자료만으로 각 판본의 완전한 외형을 확정하지 않았다. 후속 원전·지역별 자료를 추가해 P1에서 분기한다.

## 6. 폭력·성·생식 요소는 의미를 유지하면서 증거를 세분화한다

원 항목 90~117을 모두 경로에 남겼다. 성인 나체는 실제 외형으로 표현할 수 있어 V07을 별도로 두었다. 성기 도상은 O18의 물체 외형이며 성행위와 다르다. 반면 생식 강제·성적 입문·족내혼·근친·초야권·성전 매춘·악마의 성적 방문은 정의·권력·관계·역사·판본의 문제를 함께 가진다. 이를 나체 하나나 특정 얼굴로 대체하지 않는다.

| 서로 분리할 축 | 기록 원칙 |
|---|---|
| 노출 / 성행위 / 의례 | 무엇이 보이는지, 어떤 행위인지, 왜 하는지를 각각 기록 |
| 외형 / 성인 여부 / 동의 / 강제 | requester의 명시 의미를 보존하되 픽셀만으로 전부 판정하지 않음 |
| 생식 / 임신 / 혈통 / 혼인 | 몸·가계·계약·사회 범주의 차이를 보존. 족내혼과 근친은 비동의어 |
| 붉은 액체 / 피 / 인간 피 / 특정인의 피 | 가시 색과 성분·종·소유자 증거를 분리 |
| 신체 훼손 / 살해 / 시신 처리 / 식인 | 신체의 상태, 사건, 처리 행위, 목적을 별도 명제로 기록 |
| 희생 / 희생양 / 기초 매장 / 귀환 방지 | 제물의 종교적 의미, 책임 전가, 건축 맥락, 사후 처리 목적을 구분 |
| 역사적 도상 / 박해 혐의 / 실제 관습 / 허구 | 문서의 주장 주체와 근거 수준을 기록하고 서로 승격하지 않음 |

습지 시신의 왕권·희생 연결은 전시에서도 이론으로 제시된다. Wharram Percy의 손상 흔적은 식인 가설과 대조되며, 모든 특이 매장에 동일 의미를 적용할 수 없다. 영광의 손도 독립된 초를 받치는 판본과 손가락 자체를 켜는 판본을 합치면 안 된다. [NMI 전시](https://source.museum.ie/en-IE/Museums/Archaeology/Exhibitions/Kingship-and-Sacrifice), [Historic England](https://historicengland.org.uk/whats-new/news/archaeological-evidence-living-dead-in-mediaeval-england/), [Whitby Museum](https://whitbymuseum.org.uk/hand-of-glory/)

초야권과 성전 매춘은 검토한 출판사 자료가 각각 통속적 제도상의 역사성을 비판한다. 이는 모든 시대의 성폭력·착취가 없었다는 주장이 아니다. 해당 저술과 반론의 세부 원전까지 조사한 것은 아니므로 후속 역사 설명에는 범위를 명시한다. [Chicago Press](https://press.uchicago.edu/ucp/books/book/chicago/L/bo3629910.html), [Cambridge Press](https://www.cambridge.org/core/books/myth-of-sacred-prostitution-in-antiquity/61198555C0E969D82AC0B8900F7D99E7)

향후 어떤 표현이 생성 도구에서 지원되지 않거나 제한되면 요청 의미·시도·응답을 별도로 기록한다. 관계를 임의로 바꾸고 원래 의미를 충족했다고 보고하지 않는다. 이번에는 생성 도구를 호출하지 않았다.

## 7. 충분한 강화의 기준

동의어 증가나 후보 수 증가만으로 완료라고 판단하지 않는다. 반영 시에는 다음이 모두 필요하다.

1. 150개 원 항목이 가시 후보·문맥·보류 중 어디로 가는지 누락 없이 연결된다.
2. 실물·판본·해석·창작을 구분하는 출처와 지역/시대가 필요한 단위에 남는다.
3. 선택한 실현의 한영 문장에 모든 소유·접점·수·물성이 보존된다.
4. 기존 CID/RID의 완전한 소스를 먼저 비교하고 reuse/refine/new/context/defer를 결정한다.
5. 선택하지 않은 모티프가 장르 이름으로 강제되지 않는다. 문화권·생사·동의·시간을 외형에서 발명하지 않는다.
6. 검색 노출과 소스 승인, 선택과 프롬프트, 생성과 원본 픽셀, 픽셀과 사용자 선호를 각각 평가한다.

이 연구 패키지는 1의 연결과 2~4를 수행할 수 있는 구체적인 초안·비교 자료를 제공한다. 실제 운영 채택·실행·이미지 품질은 [반영 계획](IMPLEMENTATION-PLAN.md)과 [픽셀 계획](PIXEL-PLAN.md)에 정의한 별도 증거가 필요하다.
