## 0. 기준선과 작업 공간

현재 작성 원본과 런타임의 세대를 각각 확인한다. 이번 조사 원본은 2026-10-09 03:48 KST 스냅샷이므로 구현 시 다시 확인해야 한다. 등록 원본의 해시, 기존 dirty/untracked 상태, 실제 수정할 경로를 기록하고 적절한 격리 작업 공간에서 진행한다.

산출물은 원본 지문, 기준 로더 결과, 기존 런타임 receipt, 보존 목록이다. 이 구현이 검토 범위만 수정하고 동시 작업의 변경을 기록·보존하면 종료한다.

## 1. 289개 행의 재사용·보강 판단

각 행의 검토 이웃을 실제 본문까지 읽고 소유자, 조건, 구성, 제외 범위, 선택 조건, 문장 효과를 비교한다. 같은 단어가 있다는 사실만으로 통합하지 않는다. 최대 12개 저장 이웃은 의미 순위가 아니라 긍정 표현 일치의 검토 단서다.

| 결정 | 적용 조건 | 남길 기록 |
|---|---|---|
| 재사용 | 같은 의복·구성·관계·조건·효과를 이미 표현 | 기존 후보·프로필 ID와 내용 해시 |
| 보강 | 의미는 맞지만 관찰 구성·관계·반례·검증 조건이 부족 | 기존 의도를 보존한 추가 요소와 출처 |
| 새 변형 | 소유자·패널 상태·연결·레이어·효과가 다름 | 기존 항목과 달라야 하는 점, 새 후보의 좁은 범위 |
| 요청 명세 | 성분·공정·숨은 상태처럼 정지 이미지로 입증 불가 | 요청 보존과 관찰 가능한 대체 속성의 분리 |
| 근거 보류 | 채택할 정의·변형의 독립 근거가 부족 | 추가 확인할 제작 자료 또는 제품 예 |

예를 들어 `sw_sweetheart`의 수영복 의미를 일반 블라우스에 별칭만 바꿔 적용하지 않는다. `clothing_ct064_v1/v2`의 평행 모음 봉제와 장식 스모킹은 분리한다. 스코트의 내부 쇼츠가 보이지 않는 출력은 내부 구성 확인으로 기록하지 않는다.

원문 기반 카드 14개는 실제 채택할 변형에 필요한 추가 근거를 이 단계에서 확보한다. 섬유 성분 4개·바이어스 컷·브라리스 6개는 요청 명세로 유지하며 직접 픽셀 의무를 만들지 않는다. 검토할 모든 행에 결정과 근거가 남으면 종료한다.

## 2. P0의 변형별 그래프와 관찰 조건 확정

카드 수준 그래프는 의미군의 설계도이므로 실제 선택 변형의 노드와 관계를 새로 확정한다. 대안을 동시에 활성화하지 않는다. `front_anchor_and_back_anchor` 같은 연구 표기를 실행 노드로 복사하지 않고 양쪽 끝점을 각각 실제 소유자에 묶는다.

| P0 묶음 | 우선 작업 | 종료 조건 |
|---|---|---|
| 목선·지지·암홀 | 스위트하트/스트랩리스, 레이서백/드롭 암홀, 깊이와 연결선 | 윗선·끈·암홀 끝점이 독립 선택되고 의복에 귀속 |
| 컵·가슴 아래 | 뷔스티에·언더버스트·컵·패딩·몰딩 | 내부 명세와 보이는 컵·봉제 경계가 분리 |
| 크롭·밑위·절개 | 밑단과 허리선, 실제 컷아웃, O링, 가림 상태 | 겹침·공백·안감·두 연결점의 차이가 명시 |
| 표면·장식 | 포인텔, 시어·처짐, 셔링, 러플/플라운스 | 조직의 구멍·이너·고정점·자유 가장자리 확인 가능 |
| 소품·레이어 | 신발 끈, 체인·하네스·가터, 보이는 속옷·열린 카디건 | 정확한 부착 소유자, 현재 상태, 층 순서 유지 |
| 명세 한계 | 섬유·공정·브라 미착용 | 관찰 불가능한 사실을 PASS 기준으로 사용하지 않음 |

각 후보 문장의 모든 절을 실제 허용 속성 경로에 대응시킨다. 이번 자료의 `wardrobe.*` 등 경로는 제안이므로 저장소의 실제 효과 범위·컴포넌트 계약을 확인한다. 신체 치수, 미선택 의복, 카메라·포즈·조명·배경은 요청 범위 밖의 변화가 없어야 한다.

## 3. 기존 도메인에 원본 반영

주 대상은 `clothing_structure`, `fashion_fit`, `textile_surface`, `ornament_structure`, `accessory_structure`, `color_relations`, `subculture_appearance`, `portrait_fashion_exposure`의 후보·프로필 원본 쌍이다. 16개 경로는 JSON 계획에 명시했다. y2k·palette_applications·sensual_fetish_fashion 등 관련 기존 항목도 함께 비교해 중복 신설을 피한다.

후보에는 실제 선택하는 변형의 문장·의미 단위·소유자·관계·좁은 효과 범위를 작성한다. 프로필에는 같은 변형의 구성 요소·관계·반례·명세 한계·관찰 조건과 컴포넌트 근거를 작성한다. 라벨·검색 노출만으로 프로필을 필수 활성화하지 않는다.

각 후보가 필요한 의무만 연결하고 기존 도메인과 코어 의도를 유지하면 종료한다. 계절별 원본 파일은 별도 구조 이득이 확인될 때만 검토하며 봄이라는 이유로 모든 의복을 복제하지 않는다.

## 4. 원본 검증과 파생 인덱스 재생성

공식 후보·프로필 로더와 관련 원본 검증을 실행한다. 실제 새 파일이 생겼다면 source manifest를 갱신하고, 같은 작성 세대로 semantic/BM25F 및 visual profile index를 재생성한다. 기존 authored variant를 통째로 덮어쓰거나 한쪽 인덱스를 다른 시점에서 가져오지 않는다.

임베딩은 텍스트·공급자·모델·차원이 모두 같을 때만 재사용한다. 원본·인덱스의 해시 대응과 기존 항목 보존이 확인되면 종료한다. 원본 통과와 인덱스 최신성은 각각 기록한다.

## 5. 검색·선택·구성 회귀

[regression-plan.json](/Users/chasoik/Projects/image-prompt/docs/research-evidence/photo-prompt/spring-fashion-20261009/regression-plan.json)의 최소 비교 66쌍을 실행 fixture로 옮긴다. 각 쌍에서 기대하는 긍정 의미, 배제할 가까운 의미, 소유자, 허용 효과를 먼저 정한다. 검색에 노출된 후보와 실제 선택된 후보의 receipt를 분리한다.

변경 반례 14개도 실행한다. 리본·구멍의 소유자 변경, 링 프린트, 사라진 스트랩 연결, 피부색 안감, 신체 치수 변경, 대안 전체 활성화, 부정 문맥 키워드, 선택 없는 의무, 숨은 미착용 추정, 수영복 소유자 재명명, 색명의 고정 RGB, 실패 후 기록 재사용을 구분한다.

필요한 후보가 선택되고 혼동 후보가 잘못 활성화되지 않으며 미선택 속성이 보존되면 종료한다. 검색 점수만 오르거나 라벨만 나오는 결과는 의미 통과로 표시하지 않는다.

## 6. 불변 런타임 세대와 관리 보고서

현재 저장소 게시 경로로 원본·파생 인덱스를 묶은 불변 런타임 세대를 만들고 해당 세대에서 데이터 관리 보고서를 생성한다. [관리 도구 계약](/Users/chasoik/Projects/image-prompt/tools/photo_data_maintenance/README.md)의 지문·세대·현재성 검사를 따른다.

원본·인덱스·런타임이 같은 세대를 가리키고 기존 봉인 기준선이 유지되면 종료한다. 관리 연결 보고서는 의미 선택이나 픽셀 결과를 증명하지 않으므로 별도 결과와 합쳐 쓰지 않는다.

## 7. 요청된 이미지 검증

이미지 검증이 요청되면 원문 코디 8개와 진단 4개, 총 12묶음을 준비한다. 대안 비교는 별도 요청으로 나누므로 실제 이미지 수는 선택한 비교 설계에 따라 정한다. 각 요청은 검색 전에 동결하며 후보 노출·선택·구성 감사·런타임·원본 이미지를 별도로 연결한다.

착용자·신체·미요청 의복·조명·카메라·포즈·배경을 통제한다. 양쪽 스트랩 끝점이나 암홀 측면이 필요한 구도는 동결 전에 요청에 명시한다. 원본 해상도에서 선택된 구성과 관계를 모두 확인하고 결과를 PASS, FAIL, UNOBSERVABLE, MODERATION_BLOCKED_UNSCORED로 남긴다.

필수 관계 일부만 만족한 결과는 FAIL이다. 가림은 미관찰이며 숨은 명세는 픽셀 채점에서 제외한다. 계획은 재생성을 자동 승인하지 않으며 실행 때 해당 workflow의 실제 요청·실패 분류·재시도 기록을 따른다.
