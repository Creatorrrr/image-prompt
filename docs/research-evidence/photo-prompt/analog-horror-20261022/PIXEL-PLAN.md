# 독립 이미지·픽셀 검증 계획

상태: **NOT_RUN**. 이 문서는 생성 요청이나 이미지 성공 결과가 아니다.

1차 설계는 아래 12개 장면 × 3 arms × 2회 = 최대 72장이다. 처음부터 모든 이미지를 생성하라는 실행 지시가 아니며, source 공백·검색 단계의 실패를 해결한 뒤 범위를 확정한다. 연구의 6개 보류 카드는 근거 검토 완료 전 채택하지 않는다.

|사례|장면의 고정 중심|필수 차이·관계|주요 실패|
|---|---|---|---|
|G1|평범한 방의 TV를 외부에서 촬영|유리·베젤과 화면 내부의 주사선 분리|방·인물 피부까지 주사선이 번짐|
|G2|같은 복도 기록 프레임의 기술 비교|tracking/dropout/head-switch를 각각 별도 subcase로 평가|세 결함의 위치·형태가 같아짐|
|G3|한 글자 또는 단순 경계의 신호 예|색 퍼짐/Y-C 위치 차이/dot pattern을 별도 subcase로 평가|그냥 흐림·임의 RGB 무지개|
|G4|직사각형 기록 화면의 문틀|내부 윤곽만 휘고 바깥 프레임 유지|실제 건축 자체가 휘어짐|
|G5|복도의 동일 윤곽 비교|수평 옅은 echo와 광원 잔광을 별도 subcase로 평가|렌즈 플레어·귀신·다중 인물로 치환|
|G6|같은 방을 기록한 고정 감시 시야|높은 모서리·주변 바닥·작은 성인; 범죄 추론 없음|로봇 세계·괴물·비동의 촬영 추가|
|G7|TV를 보는 성인의 거실|TV 내부 기록 공간과 실제 시청자 공간 분리|시청자가 영상 안으로 합쳐짐|
|G8|문 옆의 두 짧은 지침|같은 문에 대한 읽을 수 있는 반대 문구|가짜 글자·서로 다른 조건·새 괴물|
|G9|봉인된 매체와 기록 양식|번호 대응 또는 날짜 불일치 중 하나만 선택|진짜 수사·범죄·은폐 사실 자동 주장|
|G10|독자적인 마스코트의 점검구|외피-패널-기구 접점; 원작 캐릭터·시체 없음|일반 천 인형·내부 시체 자동 추가|
|G11|기존 유기 건축 source를 쓴 방|벽-막-능선 전체 연결과 독립 장면의 구도 보존|분리된 소품·포도덩굴·동일 후보 중복|
|G12|문서·신호 조사 책상|가림 문서/시간-주파수 도해/SSTV 배치를 각각 별도 subcase로 평가|가림=항밈, 그래프=SSTV, 실제 해독 성공 주장|

G2/G3/G5/G12의 subcase는 대체 비교다. 한 프롬프트에 모든 기술을 누적하지 않는다. 12개 대표 arm을 먼저 고정하고 확장 subcase는 실패 원인에 따라 별도 추가 계획으로 남긴다. 72장은 모든 subcase까지 검증한 수량이 아니다.

세 arm의 의미:

1. **Baseline:** 같은 시점의 원래 source/index, 같은 요청과 독립 core.
2. **Refine/reuse:** 기존 source와 discovery·owner·sense 보완만 채택. 새 유사 후보를 더하지 않은 비교.
3. **Minimal new:** 2번에 확인된 관계 공백의 최소 신규 source만 더함. 72개 초안 전체 추가가 아니다.

요청·core·선택 후 허용 변화·provider/model/settings·이미지 크기·반복 번호·모든 해시를 보존한다. provider가 seed를 제어하지 못하면 paired repeat이며 같은 난수의 인과 실험이라고 부르지 않는다. 전후 source 버전이 다른 결과를 같은 snapshot으로 묶지 않는다.

각 이미지의 검토:

- thumbnail: 중심 사건·공간·구도·시각적 긴장·보조 요소의 경쟁 여부.
- native: 모든 owner, 관계의 방향, carrier 범위, 필수 접점, 텍스트 판독, 인물·장치 중복/병합.
- 별도 주장 경계: 소리·동작 시간·동의·정체·의도·생사·원인·공식 설정을 외형으로 통과시키지 않음.
- 전체 판정: 선택된 필수 gate가 하나라도 partial/unobservable/failed면 complete가 아니다. `UNOBSERVABLE_NOT_PASS`, `partial_is_fail` 유지.
- 기록: source exposure, selection, prompt evidence, generation, technical pixels, artistic judgment, requester acceptance를 각각 남김. 사용자 판단은 미수신 상태에서 pending.

정확한 문자·시험표가 필요한 장면은 원본 생성물과 결정적인 그래픽 후처리를 분리한다. 합성한 문구와 위치는 눈으로 검토하고, OCR은 보조 수단으로만 쓴다. 후처리 결과로 원래 생성 픽셀 gate를 고쳐 쓰지 않는다.

제안하는 초기 채택 기준은 장르 주입·잘못된 owner·원작 혼입·비가시 의미의 성공 승격 0건이다. 기술 관계의 완전 통과 비율과 독립적인 미적 선호는 다른 표로 보고한다. 2회 반복은 안정성 탐색의 시작이지 통계적 우월성을 입증하는 표본 규모가 아니다.
