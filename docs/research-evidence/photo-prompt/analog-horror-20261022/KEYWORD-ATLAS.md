# 원 대화 200개 키워드의 처리 경로

원래 복합 항목의 번호를 보존했다. `mixed`는 부분별 관찰 가능성이 다르다는 뜻이다. 맥락만 남긴 용어도 누락된 것이 아니다.

독립 원전 정의를 200개 모두 검증한 것은 아니다. source_support가 개념군 문맥인 항목은 저술한 시각 proxy 또는 후속 조사 경로다.
