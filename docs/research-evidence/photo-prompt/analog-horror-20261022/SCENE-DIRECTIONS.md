# 원 대화의 8개 조합을 반영하는 방법

원 대화의 조합은 원작의 공식 장면이 아니라 그 대화에서 제안한 창작 예시다. 각 조합을 그대로 모든 장면의 필수 bundle로 만들지 않고, 기록 용도·제작 주체·조사자·관찰 가능한 불일치·남는 서사 의미를 연결한다. 아래 역시 저술한 설계이며 생성 결과는 아니다.

|원 조합|원래 서사에서 지킬 중심|선택 가능한 가시 실현|단독 이미지로 통과하지 않을 의미|
|---|---|---|---|
|PSA + False Safety Protocol + Mimic|주민 보호 안내를 따르는 행위가 모방 존재를 집 안에 들이는 조건이 됨|성인 주민이 현관 옆 TV의 짧은 출입 안내와 문밖의 닮은 인물을 비교. A040·A049·A055·A059 중 맞는 전체 관계 선택|안내의 의도·거짓·인물의 실제 정체·안내를 따른 뒤의 침입 사건|
|Nature Documentary + Ecological Invasion + Body Horror|교육물이 인간을 새로운 생물 생활사의 한 단계로 분류함|자연사 도판(A043)과 지역 도해(A070)가 같은 허구 생물 무늬를 공유. 필요할 때만 기존 생물/몸 접점 source를 결합|실제 인간의 숙주화·확산·생활사·변형 과정. 단순 촉수 추가로 대체하지 않음|
|Corporate Training Tape + Bureaucratic Horror + Body Imprisonment|실종은 퇴사로 기록되지만 시설 내부 응답이 계속 남음|성인 유지보수 담당자가 같은 장비 번호의 교육 도해(A041)·종결 접수 문서(A065)·점검창(A072)을 대조|실종·생존 의식·응답 음성·회사의 은폐·조종 의도. 모형이 보이는 것을 실제 감금 성공으로 세지 않음|
|Home Video + Voyeurism + Unreliable Archive|가족이 촬영했다고 믿은 영상의 촬영 위치와 제작 주체가 모순됨|성인 조사자가 같은 방의 홈비디오(A038)와 메타데이터/보관 표기(A050·A078)를 비교. 가린 관찰 시점(A067)은 필요할 때만 선택|혈연·촬영 동의·관음의 성적 동기·불가능한 카메라 이동·촬영자의 정체|
|Clinical Recording + Reproductive Coercion + Cover-up|치료라는 기록의 표면 아래 생식 선택 통제 제도가 드러남|옷을 입은 성인 환자의 중립 관찰 기록(A046), 명시된 정책 문서와 서로 다른 보관 표기(A050·A073)를 대조하는 장면|임신·피임 상태·동의·강압·의료 윤리·가해 주체. ACOG 원문 추가 확인 전 세부 정의 확정하지 않음|
|Children’s Programming + Dream Logic + Fourth-wall Break|녹화 당시의 대상이 아닌 현재 시청자의 기억에 맞춰 질문이 바뀜|성인 시청자가 보는 독자적 만화 교육 화면(A042·A049)에서 과거·현재 기록의 읽을 수 있는 짧은 문구 차이를 제시|기억 읽기·질문의 실제 변경·현재 관객 인식·꿈의 시간 논리. 실제 아동의 피해나 성적 의미는 추가하지 않음|
|Numbers Station + Antimemetic + Fragmented Narrative|받아 적을 수 있지만 해석 내용을 기억하지 못해 자기 경고를 반복 발견함|성인 조사자의 라디오·번호 메모·빈 기록 칸(A051)·가림 문서(A073). 소리는 별도 audio 경로에 보존|숫자 음성·망각·반복 발견·항밈적 원인·기억 상태. 메모를 지운 외형으로 효과를 통과하지 않음|
|Retrofuturism + Living Architecture + Corporate Horror|미래 주거 홍보의 자동 관리가 입주민을 생체 환경 일부로 유지함|같은 주거시설의 낙관적 광고 도판(A044)과 기존 벽-막-능선 전체 관계(A064)를 시설 시점에 맞춰 선택|건물의 실제 의식·거주자 생체 유지·기업의 목적·후에 드러나는 진실. 유기 건축을 새 중복 후보로 늘리지 않음|

모든 조합의 평가에서 장면의 중심 행동·기록의 용도·정보의 차이를 먼저 정한다. 3개 개념을 받았다고 무관한 소품 3개를 하나씩 추가하거나, 장면의 모든 평면에 동일 노이즈를 바르는 방식은 비교 대상으로 채택하지 않는다. 실제 생성 실험에서는 전체 장면의 서로 다른 구도를 비교하되 고정된 요청 의미는 보존한다.
