# 남은 연구와 검증의 정확한 범위

원문 392행의 추적·처리 경로는 완성했다. 모든 정의와 복합 용어의 의미 전체를 독립 검증한 것은 아니다. 원문 행 하나가 여러 기술/복식/장르를 포함하면 연결된 카드는 그중 한 실현이다. `whole_compound_term_covered`는 false로 유지했다.

| 항목 | 이번 확인 | 남은 작업 |
|---|---|---|
| 연주 접점 | Fender/Yamaha의 정의·교육 본문, IU의 피치카토 발췌, Roland의 모델 조건 | 실제 이미지/영상 표본에서 양끝 접점, 정확한 튜닝·운지·연속 동작 확인 |
| 복식·헤어 | NGV/FIT/V&A/Met의 문화·소장품·미학 문맥 | 배틀 재킷·불릿 벨트·크리퍼스·코르셋/뷔스티에·콥스 페인트 등의 개별 표본 세분화 |
| 소리·음악이론 | 제작·신호·재즈 용례와 비가시 경계 | 발성·이론 전체에 대한 교육·평가 문헌 검토. 정지 후보로 완전 대체하지 않음 |
| 장르·지역·시대 | 운동·씬·복식의 비동치와 일부 1차 문맥 | 각 장르의 독립 공연 아카이브와 지역·시대·편성 다양성 보강 |
| 성인 무대 | 원문 소재 보존, 복식·캠프·권력차의 문맥 | 누드·버레스크의 구체 공개 작품·공연자/기관 설명과 표본 확인 |
| 폭력·착취·건강 | 실제 폭력/쇼·군중 압박/모싱·동의/압박·소품/진단 분리 | 스토킹·의존·번아웃·목소리/청력/손 문제의 자료와 문맥·복수 장면 설계 |
| source 심사 | 음악 어휘 hit 90건의 전체 레코드 보존, 9건의 자세한 재사용 제안 | 나머지 hit의 전체 조건·realization·binding·native 근거 수동 심사 |
| 운영·검색·이미지 | 읽기 전용 recorder/의존성 확인, 연구 구조 validator | native 등록/자격·index/release·실제 질의·선택/전달·저장 픽셀·수용·발행 |

`remaining-research.json`의 Q01–Q12는 주제를 삭제하는 목록이 아니다. 불완전한 부분의 다음 근거와 검토 순서를 남겼다. 완성된 구성 요소가 있는 카드는 그 전체 명제를 기준으로 개별 반영을 심사할 수 있다. 연구 보류를 source 승인으로 바꾸거나 모든 주제에 하나의 자동 차단으로 적용하지 않는다.

공개 출처 52개 중 본문을 읽은 항목은 38개, 발췌를 읽은 항목은 14개다. 그중 GKIDS 한 항목은 직접 열기 실패 후 발행자 발췌를 사용했다. 실제 원격 이미지·영상·음악 청취는 수행하지 않았다. source register와 raw web evidence는 이 구분을 유지한다.
