# 습지와 사구의 기존 표면 대안 보존

적용 기준 커밋: `7bc6d8bc759f9c14da95afc8be54bca44caf3830`. 여섯 BEFORE 팩을 이 기준에서 재검증했고 이전 `cad6f905` 팩과 바이트까지 동일했다.

두 프로필의 세 데이터 잎만 수정했다. 습지의 정의·성분·증거는 얕은 고인 물 또는 포화된 땅을 허용했으나 구성과 토양 게이트는 물가를 강제했다. 구성과 토양 검토 문구를 기존 포화 지면 대안에 맞췄다. 사구는 정의·성분·증거·게이트에서 잔물결 또는 짧은 모래 도약 이동 흔적을 허용했으나 구성만 잔물결을 요구했으므로 그 한 문장을 맞췄다.

각 네 필수 성분, 다섯 게이트, 증거 요구·기하·거절 조건·활성화는 그대로다. 사용자가 물가나 잔물결을 구체적으로 선택한 후보는 그 더 좁은 선택을 보존하며, 이 일반 프로필 수정이 명시적 장면 요구를 무효화하지 않는다.

[EPA의 습지 설명](https://www.epa.gov/wetlands/what-wetland)은 표면 또는 그 근처의 포화 상태를 뒷받침한다. [NPS 사구 설명](https://www.nps.gov/subjects/geology/aeolian-landforms.htm)은 완만한 바람맞이 면·능선·급한 바람그늘 면을 뒷받침하지만, 세밀한 잔물결/도약 흔적의 대안 자체를 새로 독립 검증한 자료라고 과장하지 않는다. 그 대안의 직접 수정 근거는 이미 승인된 내부 조사·정의·성분·게이트다. 법적 습지 판정이나 물리량을 이미지에서 추론하지 않는다.

## 실제 결과

포화 지면/얕은 물, 이동 흔적/잔물결 네 양성과 장식 연못/대칭 모래더미 두 음성을 정상 공개 CLI에 전후 실행했다. 습지 팩은 승인 문구 두 곳과 팩 ID, 사구 팩은 구성 한 곳과 팩 ID만 바뀌었다. 모든 후보와 코어·기타 필드는 동일하고 음성 두 팩은 전체 동일하다.

같은 증거는 이전과 이후 실제 계약 모두에서 통과한다. **검색·활성화·증거 수용률 향상이 아니라 구성/검토 지시의 모순을 바로잡은 결과**다. 전체 구성 감사 여섯 건도 독립 재실행에서 통과했다. 원본 코어와 증거를 유지했고 각 감사의 비실패 자유 서술 경고 세 개를 공개했다. 첫 양성 초안은 필수 안전 런타임 명칭이 빠져 실패했으며, 그 실패를 보존하고 구성문에 해당 명칭만 추가한 후 재검증했다. 원본 입력이나 계약을 바꿔 실패를 없애지 않았다.

새 회귀 3개와 기존 자연환경 8개로 11개 테스트, 독립 활성화 대조 9개, 사전·인덱스 및 엄격한 현행 사진 바이트 기준 검증이 통과했다. 기존 좁은 물가/잔물결 후보도 독립 확인했다. 실제 이미지를 생성하거나 픽셀 품질 개선을 측정하지 않았다.
