# 여성 직업 제복 시각 의미 리서치

검토일: 2026-09-01

## 범위와 모델링 원칙

이 리서치에서 `여성 제복`은 하나의 고정 복장 유형이 아니다. `직무·기관 × 근무 상태 × 복장 구성요소 × 도구 × 작업-대상-결과`의 결합으로 모델링한다. `여성`, `woman`, `female`은 성인 착용자와 선택적 핏 변형을 지정할 수 있는 축일 뿐이며, 치마·구두·화장·몸매 강조를 자동으로 요구하지 않는다. 동일 직무의 성별 표기만 달라진 경우 역할 도구와 업무 절차는 바뀌지 않아야 한다.

제복을 픽셀에서 인정하려면 다음 네 층이 함께 읽혀야 한다.

1. 복장 시스템: 상·하의, 외피, 식별 표지, 보호구처럼 서로 맞물린 구성요소
2. 직무 도구: 무전기, 차트, SCBA 게이지, 리더기처럼 역할이 소유한 물체
3. 업무 동사: 확인, 대조, 통제, 회수, 인계처럼 정지화면에서 관찰 가능한 행동
4. 대상과 결과: 환자 식별표, 통제선, 출입문 상태, 구조선 장력처럼 행동이 무엇을 바꾸거나 확인하는지 보여 주는 증거

복장만 맞고 업무가 없거나, 업무 도구가 장식처럼 흩어져 있거나, 역할 분위기만 남은 이미지는 부분 성공이므로 실패로 판정한다.

## 우선순위별 계약

| 우선순위 | 역할 | 필수 시각 연쇄 | 주요 혼동 경계 |
|---|---|---|---|
| P0 | 임상 간호 | 스크럽·식별표 + 환자 식별 확인 + 활력 모니터 + 차트 인계 | 간호사 코스튬, 의사 가운, 병원 복도 인물 사진 |
| P0 | 경찰 공공안전 | 관할 비특정 근무복 + 무전 + 통제선 + 보행 흐름/사건 기록 | 페티시 경찰 코스튬, 민간 경비, 실재 기관 배지 복제 |
| P0 | 소방 대응 | 턴아웃 보호구 묶음 + SCBA + 압력계 확인 + 장비 점검표 | 헬멧만 든 초상, 패션 방화복, 화재 배경만 있는 장면 |
| P0 | 응급의료 수송 | 고가시성 근무복 + 들것/모니터 + 평가·고정 + 이송 준비 | 일반 간호 장면, 구급차 앞 포즈, 환자 고통의 과장 |
| P0 | 해양 안전·해경 | 부력 호환 복장 + 구조선·구명환 + 무전 + 회수 대상/장력 | 밧줄을 든 선원, 폭풍 분위기, 시장·항구 관광 사진 |
| P0 | 철도 기관사 | 운전실 근무복 + 제어기 위치 + 노선/신호 표시 + 교차 확인 | 객실 승무원, 운전실 배경 초상, 복도 인계 장면 |
| P0 | 플랫폼 발차 업무 | 플랫폼 근무복 + 출입문 간극 확인 + 무전/지시기 + 발차 신호 | 표를 건네는 작별 장면, 매표 업무, 기관사 운전실 |
| P0 | 민간 출입통제 보안 | 현장 식별 근무복 + 자격증명 + 리더기 + 출입 기록 + 게이트 상태 | 경찰 제복 모사, 정장 경호원, CCTV 모니터만 보는 장면 |
| P1 후보 | 전문 주방 | 위생 작업복 + 온도계 + 주문표 + 위생 스테이션 | 흰 조리복만 입은 인물, 음식 광고 정물 |
| P1 후보 | 우편 배달 | 역할별 지급 복장 + 스캐너 + 우편가방 + 배달 지점 | 낭만적 편지 전달, 일반 택배 상자, 브랜드·주소 노출 |
| P1 후보 | 호텔 프런트 | 예약 확인 + 객실 배정 + 무문자 키카드 발급; 복장은 선택적 | 럭셔리 글래머 화보, 컨시어지 코스튬, 접객 포즈만 있는 장면 |

P1의 복장은 직업 전체에 보편적이지 않으므로 정확한 역할·근무 맥락이 없는 일반 요청에서 하드 활성화하지 않는다. 특히 호텔 프런트 복장은 프리셋의 선택 슬롯이며 레시피가 강제하지 않는다.

## 활성화 경계

- `여성 제복`, `women's uniform`, `female uniform` 같은 포괄어는 어떤 직업 프로필도 자동 활성화하지 않는다.
- 정확한 직업 문구도 코스튬·코스프레·작별 화보 맥락이면 업무 프로필에서 제외한다.
- 검색 임베딩이나 BM25F 유사도는 후보 발견만 돕는다. 구성요소와 업무 연쇄가 없는 유사도 히트는 하드 계약이 아니다.
- 실재 경찰·소방·해경·철도 기관의 배지, 계급장, 로고, 노선 UI를 복제하지 않는다. 역할은 관할·브랜드 비특정의 식별 구조로 표현한다.
- 이미지 참조는 사용자가 제공한 성인 인물의 얼굴·헤어 같은 관찰 가능한 외형 앵커에만 사용한다. 신원, 국적, 민족, 직업, 건강, 매력도 또는 동일인 여부를 추론하지 않는다.

## 조합 및 촬영 규칙

- 얼굴 참조가 있더라도 머리 위주 초상으로 축소하지 않는다. 최소 상반신 또는 3/4 구도로 손, 도구, 대상, 복장 상부 구조가 함께 보여야 한다.
- 복잡한 배경은 직무 증거를 가리지 않는 보조 층이다. 배경 사건은 작업 동사의 원인이 될 수 있지만 제복 자체를 대체할 수 없다.
- 읽을 수 있는 개인정보, 실제 환자 정보, 주소, 자격증명 값, 열차 노선 문구, 호텔 예약정보는 생성하지 않는다. 화면과 문서는 무문자·비식별 상태로 둔다.
- 프레임 밖 도구, 가려진 손, 의미 없는 소품 나열, 분위기만 맞는 색상은 필수 게이트를 충족하지 못한다.

## 소스와 추출한 경계

- [NHS England uniforms and workwear guidance](https://www.england.nhs.uk/publication/uniforms-and-workwear-guidance-for-nhs-employers/): 임상 근무복, 식별, 감염관리의 결합과 지역별 변이.
- [Korean National Law Information Center police uniform interpretation](https://www.law.go.kr/expcInfoP.do?expcSeq=315651): 경찰 제복의 규제된 공적 역할 표지와 실재 표장 복제 회피.
- [OSHA 29 CFR 1910.156](https://www.osha.gov/laws-regs/regulations/standardnumber/1910/1910.156): 소방 보호구와 호흡보호 장비를 단일 구성 시스템으로 취급.
- [EMS.gov](https://www.ems.gov/becoming-an-ems-clinician/): 평가·안정화·수송의 직무 범위.
- [IMO life-saving appliances](https://www.imo.org/en/ourwork/safety/pages/lifesavingappliances-default.aspx): 구명 설비와 배치 관계.
- [RSSB RIS-3703-TOM](https://www.rssb.co.uk/standards-catalogue/CatalogueItem/ris-3703-tom-iss-6): 플랫폼-열차 접점, 출입문 확인, 발차 절차.
- [ORR driver controlled operation](https://www.orr.gov.uk/guidance-compliance/rail/health-safety/strategy/driver-controlled-operation-dco): 기관사의 통제된 운전실 작업 경계.
- [CISA physical security recommendations](https://www.cisa.gov/sites/default/files/documents/CatalogofRecommendationsVer7.pdf): 자격증명, 리더기, 기록, 게이트를 잇는 출입통제.
- [FDA Food Code](https://www.fda.gov/food/retail-food-protection/fda-food-code): 주방 위생·온도 확인과 복장 성능 주장의 한계.
- [USPS uniform program](https://about.usps.com/manuals/elm/html/elmc9_009.htm): 성별이 아닌 직무·배치에 따른 지급 복장.
- [BLS lodging managers](https://www.bls.gov/ooh/management/lodging-managers.htm): 호텔 역할은 서비스 업무로 정의되며 보편 제복은 아님.

## 검증 기준

패키지 검증, 프롬프트 검증, 생성 전달, 실제 픽셀, 사용자 판단을 별도로 기록한다. 필수 픽셀 게이트는 각 프로필의 다섯 `evidence_phrases`와 `gates`에 대응하며 하나라도 애매하거나 누락되면 해당 실험군은 실패다. 생성기가 프롬프트를 수락했거나 파일을 만들었다는 사실은 픽셀 성공으로 승격하지 않는다.
