# 호러·귀신·공포 요소 사전

공포를 구체적으로 표현하려면 **“무엇이 등장하는가”뿐 아니라 “어떤 일상의 규칙이 어긋나는가”**도 함께 정하는 것이 좋습니다. 유령을 직접 보여주는 대신, 거울 속 사람만 늦게 움직이게 하거나, 밝고 깨끗한 공간에서 사람의 흔적만 지우는 식입니다.

아래에서는 **장르·비평·민속 용어**와 **외형·공간·색채·소리의 묘사 키워드**를 나누었습니다. 민속적 존재는 전승과 창작 속 개념으로 설명하며, 뒤쪽의 팔레트와 장면 조합은 활용을 위해 제가 구성한 예시입니다.

## 2. 호러의 장르·형식·스타일

다음 분류는 서로 배타적이지 않습니다. 한 작품이 **고딕이면서 바디 호러이고, 동시에 에로틱 호러**일 수도 있습니다.

## 5. 출몰·저주·빙의·이상 현상에 관한 설정 키워드

## 7. 신체 훼손·부패·기생·변형의 요소

바디 호러의 중요한 축은 **상처의 양뿐 아니라 몸이 더 이상 자기 뜻대로 유지되지 않는다는 점**입니다. 아래 항목은 허구의 신체 표현을 구별하기 위한 어휘입니다. :chatgpt-content-reference{index="44"}

| 용어 | 뜻과 표현 방향 |
|---|---|
| **고어 — Gore** | 피, 심한 상처, 노출된 신체 조직을 직접적으로 보여주는 표현입니다. 공포 전체가 아니라 시각적 노출의 한 방식입니다. |
| **절단 — Dismemberment** | 신체 부분이 분리된 상태를 다룹니다. 훼손 장면 자체보다 남겨진 부분과 부재한 몸의 관계를 보여줄 수도 있습니다. |
| **참수 — Decapitation** | 머리와 몸의 분리입니다. 말하거나 바라보는 기능이 계속되는 불가능한 상태와 결합할 수 있습니다. |
| **박피 — Flaying** | 피부가 제거된 신체 표현입니다. 몸의 내부와 외부를 나누던 경계가 사라지는 이미지입니다. |
| **내장 노출 — Evisceration / Disembowelment** | 신체 내부의 장기가 외부에 드러난 상태입니다. 내부·외부의 전도가 중심이 됩니다. |
