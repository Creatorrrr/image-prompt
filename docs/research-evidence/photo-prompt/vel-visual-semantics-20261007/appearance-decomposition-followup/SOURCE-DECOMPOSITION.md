## 읽는 법

형태를 지칭하는 구절은 구체적인 선·면·색·재질·접촉으로, 분위기와 감정은 해당 문맥에서 관찰 가능한 단서로 풀었다. 아래 문장은 원문 인용이 아니라 재서술이다.

**문맥 결합** 36개 / **해석 예시** 32개 / **직접 분해** 128개 / **제외 조건** 20개 / **대상 조건** 1개

기존 217개 분석 항목을 같은 ID·분류·긍정/설명/부정 구분으로 재서술했다. 새로운 전체 세션 전수조사나 생성 효과 실험을 수행한 자료가 아니다.

외형 분해 문장은 원문 인용이 아니다. 형태·재질·빛·자세 등으로 구체화한 서술이며, 추상적인 인상·감정에는 한 가지 해석 예시를 제시했다.

직접 분해는 구절의 외형적 의미를 구체화한 것이며, 모든 세부가 원문에 그대로 적혀 있거나 실제 결과 이미지에서 확인되었다는 뜻은 아니다.

문맥 결합은 해당 표현만으로 부족한 부분을 같은 원자료의 의복·장면·제한 조건으로 보완한 것이다. 해석 예시는 유일한 시각적 정답이 아니다.

이번에는 텍스트와 사전을 변환했다. 결과 이미지들을 새로 대조하거나 동일 결과를 재현하는지 시험하지 않았다.

설명문에서 유래한 항목은 실제 생성 입력인지 미확인이라는 상태를 유지한다.

성인 패션의 관능성, 비성적 친밀감, 위협, 물리적 제압, 유혈을 서로 대체하지 않았다. 원문보다 노출·부상·행동을 늘리지 않는다.

미성년·연령 모호 자료의 갈등·액션은 비성적으로만 다룬다. 연령이 확인되지 않은 분위기 수식어는 확인된 의복 구조만 분해하며 새로운 성적 자세를 만들지 않는다.

부정 항목은 배제되는 장면의 묘사가 아니라 그 제한 아래 유지해야 할 외형으로 풀었다. 의복 가림, 비접촉, 유혈 금지 같은 조건은 그대로 남긴다.

지속 압력·동작 속도·실제 감정·법적 나이 등은 한 장의 외형만으로 확정할 수 없다. 해당 항목에는 한계와 남겨야 할 맥락을 표시했다.
