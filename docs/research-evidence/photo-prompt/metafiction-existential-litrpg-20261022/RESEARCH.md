# 메타픽션 × 실존공포 × LitRPG: 시각 의미·후보 데이터 보강 리서치

조사일: 2026-10-22, KST. 대상은 [메타픽션 실존공포 LitRPG 조사](https://chatgpt.com/c/6ad9bed0-44e4-83ee-805e-4134cdb987c7)의 130개 항목이다. 대화는 조사 출발점이며, 그 안의 정의·응용 예시·인용을 독립 검증된 사실로 간주하지 않았다. 이번 산출물은 연구와 반영 계획이다. 운영 데이터·검색 인덱스의 개선이 이미 적용됐다는 뜻이 아니다.

## 1. 보강의 핵심 결론

이 조합은 `떠 있는 파란 상태창 + 우울한 인물 + 글리치`만 추가해서는 충분히 표현되지 않는다. 필요한 단위는 **서로 다른 실재·표상·기록·규칙·행동 사이의 구체적인 관계**다. 특히 장면 안에서 누가 무엇을 만지고, 어떤 매체에 무엇이 표시되며, 실제 인물과 표시의 소유자가 어떻게 연결되는지를 분명히 해야 한다.

가장 우선할 데이터는 다음 여섯 관계군이다.

| 관계군 | 구체적으로 보강할 내용 | 먼저 연결할 카드 |
|---|---|---|
| 재현 경계 침범 | 인쇄된 공간과 실제 탁자를 잇는 연속 팔, 화면 안팎에 걸친 발, 종이·실물 경계 | A01, A08 |
| 재귀·전체와 부분의 대응 | 같은 방의 반복, 같은 목도리·파손 문을 가진 모형, 유한 반복 단계의 읽힘 | A03, A04, A07 |
| 기록의 불일치 | 같은 사건 기준점, 다른 인원 도식, 개정판 사이의 문/벽 차이, 삭제 표식 | B02, B03, B05, H04 |
| 닮음과 개체의 분리 | 두 개의 몸, 다른 손동작, 따로 존재하는 위치와 접지, 의수의 몸 접점 | C01, C05 |
| 규칙 표시와 행동의 분리 | HP 표시와 신체 모습, 하트 수치와 거리, 다른 버튼과 같은 빗장 | D02, D08, E02 |
| 세계 내부 구조의 국소 변화 | 한 면의 와이어프레임, 연속 바닥 기준선, 파일 손상과 구별되는 공간 귀속 | F03, F04, H05 |

전체 설계는 시각 카드 64개, 문맥 카드 10개, 원 용어 경로 130개, 외부 출처 40개다. 시각 카드의 근거 방식은 정지 형태 35개, 서사에 대한 단서/비유 28개, 명시 다중 패널 1개다. 문맥 카드는 긍정 시각 후보로 변환하지 않는다. 각 카드에는 원문 연결, 한영 문장, 소유자, 방향 관계, 혼동 경계, 주장 한계, 검토 항목이 있다. 개수는 연구의 구조를 나타내며 충분한 검색 성능이나 이미지 품질의 증거가 아니다.

## 2. 원 개념을 바르게 옮기기

### 메타픽션·메타서술·메탈렙시스·미장아빔

메타픽션은 허구성·구성됨에 대한 자기반영이고, 메타서술은 서술 과정에 대한 논평이다. 책, 키보드, 작가처럼 보이는 사람이 있다는 사실만으로 둘 중 하나가 성립하지 않는다. [Neumann·Nünning](https://www-archiv.fdm.uni-hamburg.de/lhn/node/50.html)

메탈렙시스에는 서술 층위의 경계가 필요하다. 보통의 문, VR 접속, 평행세계 이동을 모두 여기에 넣으면 개념이 무너진다. 수사적 경계 넘기와 층위 사이 상호 침투를 구별하고, 시각 후보는 그중 **책/화면의 매체 경계와 연속 몸의 접점** 같은 저술한 실현을 다룬다. [Pier, Metalepsis](https://www-archiv.fdm.uni-hamburg.de/lhn/node/51.html)

액자서사는 포함 관계이고, 미장아빔은 내부 요소와 전체 사이의 반영 관계다. 작은 그림 하나가 있다고 미장아빔으로 확정하지 않는다. 데이터에는 `contains`, `depicts`, `matches_arrangement`, `crosses_boundary`를 서로 다른 관계로 넣고, 유한 반복과 무한성도 분리한다. [Narrative Levels](https://www-archiv.fdm.uni-hamburg.de/lhn/node/32.html)

회화 자료는 이를 사진 장면으로 번역하는 데 도움이 된다. 마그리트의 1933년 《La condition humaine》에서는 풍경 정렬과 캔버스 옆면이 재현의 경계를 드러낸다. 에셔의 《Drawing Hands》에서는 종이·소매 선묘와 입체적으로 보이는 손의 접점이 중요하다. 두 작품은 선택한 기하 관계의 참고이며 작품 복제나 특정 외형의 의무를 뜻하지 않는다. [NGA](https://www.nga.gov/artworks/70170-la-condition-humaine), [Rijksmuseum](https://www.rijksmuseum.nl/en/collection/object/Drawing-Hands--650fda32c233fdf147430f0ee8127c0d)

### 신뢰할 수 없는 기록과 주변텍스트

신뢰 불가능성에는 보고의 오류뿐 아니라 해석·윤리 평가의 오류, 중요한 정보의 누락도 포함된다. 두 문서가 다르다고 어느 문서가 거짓인지 확정하지 않는다. 따라서 B03은 같은 지도와 인원 차이를, B05는 같은 균열과 문/벽 차이를 표현한다. `불일치가 보임`과 `시스템이 거짓말함`을 다른 필드에 둔다. [Unreliability](https://www-archiv.fdm.uni-hamburg.de/lhn/node/66.html)

파라텍스트는 작품을 제시하는 제목·서문·각주 등의 문제다. 상태창을 모두 파라텍스트로 분류하지 않는다. 책 속 문장, 화면 UI, 등장인물의 문서, 실제 작품의 장 제목은 소유 매체와 제시 층위가 다르다. B01/B07은 물리적 비유이고, 제목이 죽음을 지정한다는 설정은 별도의 서사 규칙이다. [Genette, Introduction](https://www.cambridge.org/core/books/abs/paratexts/introduction/CCD45FBCF44320953B670DFD2CE6E9A5)

초점화 역시 단순한 카메라 앵글이 아니다. 누구의 경험과 지식에 따라 정보가 제한되는지를 다루므로, 한 장면을 저각·후면으로 찍었다는 사실만으로 완전히 옮길 수 없다. 에르고딕 문학도 독자의 실제 조작이 필요한 형식과 관련되며 일반적인 읽기 전용 LitRPG와 자동 동치가 아니다. [Focalization](https://www-archiv.fdm.uni-hamburg.de/lhn/node/18.html), [Cybertext 출판사 소개](https://www.press.jhu.edu/books/title/1398/cybertext)

### 실존적 의미·자유·자기 형성

실존주의는 허무주의나 절망적 표정의 다른 이름이 아니다. 자유·책임·주어진 조건·자기 형성의 긴장이 중요하다. 카뮈의 부조리·반항도 단순한 비논리·기괴함과 구별한다. 카뮈가 실존주의라는 분류와 거리를 두었다는 점을 남긴다. C08/E08처럼 편지를 보관하거나 상대를 일으키는 장면은 가능한 표현이며, 행위의 진정성과 무보상성은 작품 규칙과 문맥에 의존한다. [Existentialism](https://plato.stanford.edu/entries/existentialism/), [Albert Camus](https://plato.stanford.edu/entries/camus/)

결정론·숙명론·양립가능론·자유의지 부재를 합치지 않는다. 같은 결말에 이르는 경로, 자기 손목에 연결된 실, 선택지를 벗어나는 동작은 각각 다른 시각 비유다. 코드가 있다는 이유로 자유가 없다고 확정하는 태그를 만들지 않는다. [Free Will](https://plato.stanford.edu/entries/freewill/)

## 3. 자아·복제·부활에 필요한 데이터 분해

다음 다섯 층을 분리해야 한다.

| 층 | 한 장에서 확인 가능한 것 | 그대로는 확인할 수 없는 것 |
|---|---|---|
| 외형 | 닮은 얼굴·옷·태그 | 원본·가족·복제 원인 |
| 개체 구별 | 다른 위치·다른 동작·두 몸의 경계 | 철학적 수적 동일성 |
| 물질적 연속 | 몸–소켓–의수의 실제 접속 | 교체 이력·인격의 지속 |
| 기억 표상 | 초상 토큰·사진·문서의 존재와 차이 | 실제 기억 내용·심리적 연속성 |
| 주관적 경험 | 자기 보고가 적힌 문서의 글자 자체 | 감각질·의식의 존재/부재 |

인격 분기와 심리적 연속성은 논쟁이 있는 문제다. 질적으로 같은 두 몸을 그렸다고 같은 한 사람이라는 결론을 내리지 않는다. 복원 칸·남은 물건·덮인 형상도 부활과 생사의 증거가 되지는 않는다. [Personal Identity](https://plato.stanford.edu/entries/identity-personal/)

철학적 좀비는 특히 중요하다. 물리적·행동적으로 인간과 구별되지 않는 존재를 상정하므로 공허한 눈, 썩은 피부, 반복 동작을 고유 외형으로 등록하면 다른 개념이 된다. 감각질·타인의 마음·유아론·부수현상론·시뮬레이션 가설은 K04에 보존한다. 발광 회로나 글리치가 이 문제들의 답을 증명하지 않는다. [Zombies](https://plato.stanford.edu/entries/zombies/), [Qualia](https://plato.stanford.edu/entries/qualia/), [Other Minds](https://plato.stanford.edu/entries/other-minds/), [Epiphenomenalism](https://plato.stanford.edu/entries/epiphenomenalism/), [Bostrom의 조건부 논증](https://simulation-argument.com/simulation.pdf)

이인감·비현실감은 주관적 경험과 현실 구조를 구별해야 한다. 거울 불일치를 허구적 표현으로 쓸 수는 있지만 임상 진단의 외형 표지로 삼지 않는다. 이 경험에서 현실검증력이 보존된다는 구분도 지우지 않는다. [Merck Manual](https://www.merckmanuals.com/professional/psychiatric-disorders/dissociative-disorders/depersonalization-derealization-disorder)

## 4. LitRPG를 UI 외형보다 넓게 다루기

출판사의 장르 정의와 성장형 판타지 제안은 수치·규칙·성장을 구별하는 근거다. 성장형 판타지는 숫자나 상태창이 없어도 성립할 수 있다. 종이 캐릭터 시트, 퀘스트 물증, 길드의 검사 절차, 연결된 능력 분기, 통행권 같은 물리적·사회적 구현도 후보가 될 수 있다. [Level Up Publishing](https://www.levelup.pub/what-is-litrpg), [Andrew Rowe](https://andrewkrowe.wordpress.com/2019/02/26/progression-fantasy-a-new-subgenre-concept/)

인터페이스에는 적어도 다음 정보를 따로 둔다. Fagerholt·Lorentzon의 논문에서 이야기와 공간의 구분을 확인했으며, 아래 필드명은 이 저장소용 연구 제안이다. [Beyond the HUD](https://odr.chalmers.se/items/d5fe6889-4cc6-49c2-ba56-0d759e2f37eb)

| 제안 필드 | 값의 예 | 판정 한계 |
|---|---|---|
| 매체 | 종이 / 물리 화면 / 공간 투영 / 독자에게만 보이는 오버레이 | 홀로그램처럼 보인다고 세계 내부 UI로 확정하지 않음 |
| 표시의 소유자 | 손목 장치 / 벽 패널 / 외부 관찰자 화면 | 숫자가 누구 상태인지 대상 연결이 필요 |
| 작중 가시성 | 명시됨 / 불명 / 독자 전용 | 인물이 바라본다는 사실만으로 완전 확정하지 않음 |
| 조작 관계 | 손–종이 / 손끝–버튼 / 케이블–화면 | 동작과 실제 시스템 결과를 구별 |
| 표시 내용 | HP / 하트 / 짧은 ID / 슬롯 / 분기 | 같은 숫자가 건강·욕망·동의·권리를 통합하지 않음 |
| 진실성 | 확인된 작중 규칙 / 의심 / 불명 | 표시 자체와 실제 상태를 구별 |

D02의 HP 100과 붕대는 시각적으로 병치되지만 HP가 상처·통증 총량을 뜻하지 않는 규칙에서는 모순이 아닐 수 있다. SAN도 현실 정신건강을 측정하는 보편 척도가 아니다. 숫자와 몸을 연결하는 데이터에는 반드시 **판본·규칙·해석의 범위**가 필요하다. [D&D 2024 Rules Glossary](https://www.dndbeyond.com/sources/dnd/br-2024/rules-glossary), [Chaosium의 SAN 설명](https://www.chaosium.com/blogfrom-the-qa-what-is-the-sanity-san-mechanic-in-call-of-cthulhu/)

리스폰, 세이브/로드, 시간 루프, NG+, 레트콘도 하나의 `reset`으로 뭉치지 않는다. 몸·소지품·기억·타인·공간·세계 규칙 중 무엇이 유지·복원·소실되는지 별도로 저술해야 한다. 공식 Minecraft 설명만으로도 리스폰과 이전 세이브 복원이 다름을 확인할 수 있지만, 그 게임의 규칙을 모든 소설에 일반화해서는 안 된다. F01은 다중 패널의 상태 비교이며 단일 프레임 시간 증거가 아니다. [Mojang](https://www.minecraft.net/en-us/article/spawning-and-dying)

## 5. 선택·권한·관객을 데이터로 옮기는 방법

게임에서의 에이전시는 원하는 행동과 시스템이 지원하는 행동의 관계다. 버튼 개수나 철학적 자유의지와 같지 않다. E01의 통로 합류, E02의 같은 빗장, E04의 패널 밀기는 가능한 표현이지만 게임의 실제 실행 결과가 필요하다. [Agency Reconsidered](https://dl.digra.org/index.php/dl/article/download/369/369/366)

규칙과 서사의 불협화음은 서로 충돌하는 규범을, 절차적 수사학은 규칙과 상호작용의 표현력을 다룬다. 따라서 살해에만 보상이 붙는다는 설정은 실제 규칙을 확인해야 하고, E07/H01의 보상 도상만으로 그 규칙을 입증해서는 안 된다. 블리드는 플레이어·캐릭터 사이 감정과 경험의 전이이며 혈액 연출이 아니다. [Clint Hocking](https://clicknothing.com/2007/10/07/ludonarrative-d/comment-page-1/), [Ian Bogost](https://www.bogost.com/books/persuasive-games), [Sarah Lynne Bowman](https://www.nordiclarp.org/2015/03/02/bleed-the-spillover-between-player-and-character/)

## 6. 폭력·욕망·대상화 항목의 보존

원 대화의 99–116을 빠뜨리지 않았다. 바디 호러·아브젝시옹·고어·에로틱 호러·대상화·도구화·대체 가능성·주체성 부정·신체 침해·정신 지배·조작된 욕망·생식 공포·노예계약·고문·인신공양·식인·비인간화·구경거리화·성적 강압을 원 항목 수준에서 추적할 수 있다.

신체의 변형과 통제 상실은 바디 호러의 중요한 범위다. 그러나 모든 바디 호러를 고어·성적 폭력·특정 질병으로 고정하지 않는다. 피부–소켓 연결, 구속의 양 끝, 손상과 표시의 병치처럼 가시 성분을 다루고, 고통의 양·의도·생사·반복·물질의 인체 유래는 별도로 남긴다. [BFI](https://www.bfi.org.uk/lists/10-great-body-horror-films)

대상화 역시 도구화·대체 가능성·자율성 부정·소유·경계 침해·주체성 부정으로 나뉜다. G03의 ITEM 표시는 사람을 상품 취급하는 서사의 단서일 수 있지만 권리·주체성·소유권의 실제 상실은 확정하지 않는다. D08에서는 **화면 수치 / 실제 감정 / 관계에 대한 동의 / 외부 조작**을 독립 층으로 보존한다. 높은 호감도·복종·성인 외형·표정은 동의를 채우는 값이 아니다. 성적 강압은 비선정적 문맥으로 남기며 자동 성적 시각 후보로 변환하지 않는다. [Objectification](https://plato.stanford.edu/entries/feminism-objectification/)

생식 공포의 문서·장치 표현도 임신·혈통·강제를 증명하지 않는다. 식인과 인신공양을 정체 불명 음식이나 제단만 보고 확정하지 않는다. `의미를 보존함`과 `외형으로 사건을 입증함`은 다른 작업이다. K06/K07은 이 간격을 보존하기 위한 데이터다.
