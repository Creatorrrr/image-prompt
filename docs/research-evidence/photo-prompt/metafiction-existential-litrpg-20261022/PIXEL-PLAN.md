# 실제 이미지 비교 계획 — NOT_RUN

이 조사에서는 이미지·임베딩·외부 모델 호출을 하지 않았다. 아래는 후속 구현의 비교 설계이며 예산 지출이나 세대 게시를 실행한 기록이 아니다.

## 첫 질문

관계가 분명한 새 데이터가 현재 데이터보다 의미에 맞는 후보의 **노출·채택**을 늘리고, 같은 요구를 이미지에 옮길 때 매체 경계·비교 대상·접속·짧은 표시가 더 온전하게 보이는가? 단지 수동으로 문장을 길게 넣은 효과나 원래 좋은 기존 후보의 효과일 가능성도 분리한다.

## 세 arms

| Arm | 고정할 것과 바꿀 것 | 확인할 주장 |
|---|---|---|
| A 현재 기준 | 같은 독립 요청/core/controls, 현재 승인된 소스와 검색 | 현재 가능한 결과 |
| B 보강 staged 데이터 | A와 같은 조건에서 검토된 source/index 차이만 적용 | 데이터 보강을 통한 실제 발견·채택·렌더 변화 |
| C 직접 선택 진단 | 같은 core에서 심사된 완전 문장을 수동 선택해 literal evidence 보존 | 검색과 별도로 그 관계를 표현할 수 있는지. 운영 검색 개선의 증거로 세지 않음 |

같은 seed가 지원되면 case별로 대응시키고, 지원되지 않으면 불가능하다고 기록한다. 임의로 seed 통제를 주장하지 않는다. 프롬프트·참조·비율·크기·모델·controls·샘플링 횟수·비용 한도를 사전 고정한다. 실패 후 성공 이미지만 골라 비교하지 않는다. 재시도 정책도 결과를 보기 전에 정한다.

## 첫 12개 사례

| 카드 | 필요한 원본 픽셀 증거 | 대표적 실패 |
|---|---|---|
| A01 | 인쇄된 방, 페이지 끝, 연속 팔, 실제 탁자 그림자 | 책 위 일반 손, 잘린 손목, 인쇄 그림자 |
| A03 | 방–그림–내부 그림의 유한 포함, 반복 의자/램프 | 거울, 서로 다른 방, 내부 그림이 읽히지 않음 |
| A04 | 실제 방과 모형, 같은 목도리, 같은 문 파손 | 무관한 모형, 얼굴만 같음 |
| B03 | 두 보고서의 같은 지도와 서로 다른 인원 | 다른 사건, 지도/개수 가림 |
| C01 | 별도 성인 둘, 닮은 얼굴/옷, 다른 손, 두 접지 | 거울, 잔상, 융합 몸, 손 증식 |
| C05 | 몸–소켓–붙은 의수, 탁자 위 분리 부품 | 의수 인접만, 접점/분리 부품 가림 |
| D02 | 손목 화면의 정확한 HP 100, 같은 사람의 붕대 | 수치가 깨짐, 타인 손, 통증/거짓으로 자동 판정 |
| D08 | 성인 둘, 하트 100, 거리·물러나는 몸·거둔 손 | 숫자만, 과도한 성적 연출, 감정/동의의 단정 |
| E01 | 서로 다른 두 입구와 같은 화면의 실제 합류점 | 입구만 보임, 연결 추측 |
| E02 | YES/NO, 두 드러난 막대, 같은 단일 빗장 | 가짜 글자, 엉킨 연결, 다른 두 빗장 |
| F03 | 같은 벽의 고체/메시 경계, 연속 바닥, 주변 정상성 | 사진 전체 파일 오류, 단순 철망 벽 |
| G02 | 같은 사람 손목 커프–체인–토큰–벽 홈 | 장신구, 끊긴 체인, 끝점 가림 |

12 × 3 = 36개의 개별 결과를 먼저 확보하도록 계획한다. 단일 결과는 사례 재현성의 충분한 증거가 아니다. 다만 첫 라운드에서 어떤 실패 유형을 해결할지 결정하는 데 사용할 수 있다. 중요한 채택에는 같은 조건의 독립 반복을 추가하고 실제 예산·목표를 실행 전에 정한다.

F01의 세 패널은 별도 실험이다. 시간 순서를 말하는 텍스트/레이아웃과 각 패널의 기준점을 평가하고, 한 프레임의 시간 루프 성공으로 계산하지 않는다. 나머지 P1/P2와 원전의 장면·장기 규칙·상호작용은 첫 36장 평가의 범위 밖이다.

## 판정 단위

원본을 확대해 각 owner의 부위·경계·접점·문자·개수·방향을 확인한다. 필요하면 보기용 crop을 쓰되 전체 원본도 함께 보존하고 native 픽셀을 합성/보정해 판정하지 않는다. 모든 필수 gate가 `visible`이어야 전체 사례가 통과한다. `partial`은 전체 실패, `unobservable`은 `UNOBSERVABLE_NOT_PASS`다. 문맥 주장에 대해서는 `NOT_A_PIXEL_CLAIM`을 사용한다.

기하·문자/가시성 판정과 표현 선호를 분리한다. 예술적 평가는 주제 전달의 명료함, 관계의 읽힘, 불필요한 UI/설명 과다, 상투적 글리치 의존, 장면의 자연스러움을 같은 기준으로 비교한다. 구조 통과가 공포감·미학·사용자 만족을 자동 증명하지 않는다.

보고에는 run receipt, 실제 노출 CID/RID, 채택 문장, 원본 경로/해시, 반환 여부, 관계별 판정, 전체 판정, 선호와 사용자 수용 상태를 남긴다. 새 데이터가 노출되지 않은 B 결과는 새 데이터의 효과 실험으로 해석하지 않는다.
