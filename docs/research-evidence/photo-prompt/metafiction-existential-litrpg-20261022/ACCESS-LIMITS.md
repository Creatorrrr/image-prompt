# 출처 접근과 증거의 한계

2026-10-22 KST 기준의 연구 기록이다.

## 참조 대화

`read_thread`로 원 요청과 답변을 읽었지만 긴 답변이 문자 제한에서 잘렸다. 사용자에게 참조된 대화의 로그인된 Chrome 렌더링을 읽어 130개의 번호·용어·정의 표, 여덟 참고 작품, 마지막 여섯 조합 방향을 복원했다. [reference-conversation.json](reference-conversation.json)은 그 대화의 표·본문·실제 링크를 보존한다. 대화에 붙은 인용의 숨겨진 추가 출처를 전부 펼치거나 원전 전체를 읽었다는 뜻은 아니다.

## 외부 조사

출처 40개는 [sources.json](sources.json)에 자료 종류·실제로 읽은 범위·확인 가능한 의미·주장 한계를 기록했다. source ID는 이번 연구 안의 지역 식별자다. 기존 다른 연구 폴더의 같은 S번호와 합치지 않는다.

- LHN·SEP에서는 개념 정의와 필요한 구분을 읽었다. 이 조사에서 130개의 개별 정의를 각각 독립 사전으로 인증한 것은 아니다.
- Cambridge의 《Paratexts》는 공개 Introduction 요약만 읽었다. JHU 《Cybertext》는 출판사 소개와 검색 본문을 확인했으며 책 전문은 읽지 않았다. JHU 페이지 상단에는 다른 추천 도서가 섞여 있어 검색에서 제목·저자·ISBN을 함께 확인했다.
- 《Agency Reconsidered》는 논문 초록과 정의 범위를, Bostrom 논문은 초록의 조건부 논증을 확인했다. 논증 전체의 철학적 타당성을 판정한 연구는 아니다.
- 《Beyond the HUD》는 Chalmers 메타데이터와 공식 PDF를 확인했다. 웹 도구의 PDF find가 실패·타임아웃을 보였지만 공개 PDF를 직접 받아 `pdftotext`로 작중 인지 가능성과 공간 표현에 관한 대목을 읽었다. 전문 PDF는 임시 폴더에서만 처리했다. [HUD-SOURCE-ACCESS.json](HUD-SOURCE-ACCESS.json)의 줄 위치는 추출 텍스트의 locator이며 책의 페이지 번호가 아니다.
- Escher in the Palace의 Drawing Hands/Print Gallery 상세 페이지는 웹 열기에서 접근 실패/서버 오류가 있었다. 검색 본문은 보였으며, 주요 형태 설명은 접근 가능한 Rijksmuseum Drawing Hands와 NGA Print Gallery 기록으로 확인했다.
- RAINN의 consent 페이지는 타임아웃으로 본문 확인에 실패했다. 출처 40개에 넣거나 읽은 자료로 세지 않았다. 동의·자율성 구분에는 원 대화와 실제 읽은 SEP 대상화 논의를 사용했다.
- 참고 소설·게임은 작가·출판사·제작사의 소개문을 확인했다. 소설 전문, 실제 플레이, 영상의 전후 장면을 검증하지 않았다. 작품 소개와 후보의 구체적 장면 제안을 구분했다.
- 박물관의 형태 설명과 작품 기록은 읽었지만 원작 이미지의 native 픽셀 검토나 재사용 권리 확인을 수행한 것은 아니다. 작품의 특정 인물·로고·복장을 복제한 후보로 만들지 않았다.

## 로컬 원문과 검증

고정 필드 어휘 감사는 의미 유사도 검색이 아니다. 첫 40개 표본과 추가 17개 이웃의 원문 스냅샷을 보존했지만 전체 후보를 native 승인한 것은 아니다. 표본의 지정 필드와 전체 해시를 남겨 다음 구현에서 다시 확인할 수 있게 했다. 상속된 nested 연구 주석·과거 이미지 승인·모든 바인딩의 적합성을 전부 검토하지 않았다.

동시 작업으로 소스·manifest·검색·코드가 바뀔 수 있다. 이 조사 폴더 밖 변화는 되돌리지 않았다. [VALIDATION.json](VALIDATION.json)의 변경 목록은 관찰된 해시 차이이며 다른 작업의 변경을 이 조사 성과로 계산하지 않는다. 구현 전에 최신 baseline을 다시 고정해야 한다.

가시 카드의 한영 문장은 이 연구에서 함께 저술하고 교차 읽은 초안이다. 독립 번역가 검토·실제 검색·native 이미지 검토·사용자 수용은 아직 없다. 관계 graph와 성분·관계별 검토 항목은 연구 명세이며 native 계약·하드 활성화·픽셀 성공의 증거가 아니다.
