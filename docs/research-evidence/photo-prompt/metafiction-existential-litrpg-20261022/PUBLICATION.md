# 메타픽션·실존공포·LitRPG Git 공개 범위

이 문서는 최신 원격 main을 pull하기 전, 분리한 범위 커밋의 검증 경계를 기록한다. 기존 통합 보고서와 체크섬은 당시 작업 폴더·설치 버전·이미지 실험의 원본 기록으로 유지했다. 최종 병합·푸시 SHA는 Git 이력 및 로컬 `generated/maintenance/metafiction-main-publication-20261022/`의 검증 기록과 구분한다.

## 포함한 변경

- 시각 후보 64개, 맥락 진단 10개, 기존 슬롯 연결 128개와 의미 레지스트리의 키워드 경로 130개.
- 별도 원문 모듈 2개를 기존 매니페스트에 추가하고, main의 기존 모듈과 원문·조건·효과·연결을 보존했다.
- 전용 의미 문서와 공용 문서의 해당 설명만 추가했다. main에 있던 folk-horror·liminal 등의 설명을 유지했다.
- 해당 원문 조합으로 다시 검증한 전체 검색 인덱스와 그 매니페스트가 가리키는 783개 물리 파일.
- 기존 리서치·검색·세 독립 이미지 테스트 기록. 원본 이미지와 참조 JPEG, 모델·캐시·생성 폴더는 Git에 추가하지 않았다. 기존 로컬 원본은 유지한다.

다른 주제의 미커밋 데이터와 스킬·검색 엔진 수정은 이 범위에 넣지 않았다. `retrieval-runtime.json`과 설치된 버전·native CURRENT는 변경하지 않는다.

## 원문과 검증

분리 기준 main은 `242e73c008885280fdabe28cf8889187d82f51f1`이다. 이 기준에 이번 주제만 추가한 사전은 후보 19,434개(양성 19,155개, 진단 279개), 연결 13,581개다. 앞선 이미지 실험의 혼합 작업 사전 19,801개/연결 14,246개와 다른 조합이며, 두 실험을 같은 소스 상태로 주장하지 않는다.

- 전체 소스·검색 인덱스 검증 및 최종 사전 검사: 통과, 오류 0개.
- 기존 literal/source-context/semantic-boundary/validation-context 회귀 테스트: 96개 통과.
- 기존 벡터 19,091개 재사용, 새 후보 벡터 64개 검증 캐시 적중, 새 임베딩 호출 0회.
- 메모리 사용량을 제한한 유지보수 해시 함수는 원래 canonical JSON 해시와 75개 입력에서 일치했다. 운영 코드와 임베딩 공간은 바꾸지 않았다.
- 역사적 리서치 체크섬 29개와 통합 기록 체크섬 36개 모두 일치한다.

## 이미지 증거의 경계

세 독립 에이전트가 각각 네이티브 1회 호출했다. 1번은 출력 안전 검사에서 차단되어 미평가이며, 2번과 3번은 핵심 주제 관계가 보이지만 지정된 팔·엄지의 좌우가 반전되어 전체 고정 기준은 부분 구현이다. 리뷰 기록의 유효성과 프롬프트 전달 감사 통과가 실패한 픽셀 게이트를 승인하지 않는다. 사용자 수락은 대기다.

신규 후보의 실제 영감은 3번 D01의 일반 종이 물성 보강에 한정됐다. 데이터 갱신의 인과적 품질 개선이나 native 원문 승인을 입증하지 않는다. [원래 통합 결과](INTEGRATION-RESULTS.md)와 [이번 범위 검증](PUBLICATION-CHECKS.json)을 함께 참고한다.
