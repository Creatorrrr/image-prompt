# 원 대화의 조합 방향과 구체적인 시각 설계

아래 첫 여섯 방향은 원 대화의 마지막 조합 표를 따른다. 뒤의 두 방향은 이번 연구에서 추가한 제안이다. 각 장면은 모든 개념을 한 화면에 넣기보다 서로 읽히는 관계 한두 개를 선택한다. 장르·기존 작품명이 자동 외형을 정하지 않는다.

| 방향 | 한 장에서 사용할 구체적인 관계 | 서사로 남겨야 할 것 | 후보 연결 |
|---|---|---|---|
| 작가에게 반항하는 NPC | 책 안팎의 연속 팔, 또는 선택 패널을 밀고 옆 틈으로 뻗는 손 | 반항이 예정됐는가, 인물이 허구성을 아는가, 누가 작가인가 | A01 또는 E04, K02/K09 |
| 부활할수록 자신을 잃는 주인공 | 두 복원 칸의 목도리 대응, 또는 비어 있는 초상 토큰 홈과 접촉 손 | 실제 부활, 같은 사람의 지속, 기억 손실, 죽음 횟수 | C02 또는 C06, K03/K08 |
| 공략 가능한 사랑의 공포 | 하트 수치와 떨어지는 거리·거둔 손의 병치 | 실제 감정, 외부 욕망 조작, 동의·비동의의 구분 | D08, K06 |
| 공포영화 배역에서 탈출하기 | 가슴 배지를 잡은 다른 손, 또는 막힌 계단과 봉인 문 | 배역의 강제, 예정된 죽음, 탈출 성공, 세계의 실제 고장 | H02 또는 F07, K08/K10 |
| 관객이 유지하는 잔혹한 세계 | 생활방–관찰창–관객, 또는 무대 위 눈 표식과 보상 토큰 | 시청률이 생존을 결정하는 규칙, 착취, 타인의 동의 | G05 또는 H01, K07/K10 |
| 성장 자체를 거부하는 모험 | 칼집의 칼을 바닥에 두고 상대 손을 잡기, 또는 보상판 아래 돌봄 동작 | 실제 무보상성, 성장 경쟁의 거부, 행위의 내적 진정성 | E08 또는 E07, K02/K10 |
| 기록을 통해 세계 개정을 추적함 — 추가 제안 | 같은 지도·다른 인원 기록, 또는 동일 균열의 문/벽이 다른 두 판본 | 어느 기록이 참인가, 과거가 바뀌었는가, 누가 기억하는가 | B03 또는 B05, K08/K09 |
| 읽히지 않는 영역과 마지막 페이지 — 추가 제안 | 같은 거리의 실물–선묘 경계, 또는 책 가장자리에서 끝나는 입체 거리 | 읽기의 인과, 엔딩 이후 존재·시간, 세계 소거의 진실 | H05 또는 H08, K04/K08 |

매체도 다양하게 설계한다. 종이·실물 소품의 스틸라이프, 인물 손동작 중심 근접 장면, 방 전체와 축소 모형의 대응, 현실적 세트의 선택적 비현실 관계, 짧은 UI 문자 비교를 각각 유지한다. 모든 제안을 푸른 홀로그램·검은 방·고어로 통일하지 않는다. 조명·렌즈·색·의복은 독립 요청과 장면에 맞춰 별도로 고른다.

원 대화의 창작명 14개는 다음처럼 연결했다.

| 원 ID / 창작명 | 선택 시각 제안 | 분리할 규칙 |

이 표는 원전에서 고유하게 정해진 도상의 목록이 아니다. 다른 문맥에서 같은 물건·배치를 사용하더라도 이 의미를 자동 부여하지 않는다.
