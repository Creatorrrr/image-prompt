# 오버헤드 사진의 가까운 손 또는 소품 대안 보존

기준 커밋: `326a9321c93d7fe5b484fb62fff6d3d393ed46c7`.

현재 정의·의역·공개 후보는 가까운 손 또는 소품을 허용하지만, 성분·증거·구성 지침·렌더 게이트는 소품만 요구했다. 소품 없는 가까운 손 장면에도 소품 증거가 필수로 추가되는 것을 정상 공개 CLI에서 확인했다.

프로필 1개의 네 데이터 경로만 맞췄다. 기존 소품의 영어·한국어 성분과 증거를 그대로 남기고 가까운 손을 대안으로 추가했다. 게이트 ID·개수·척도와 증거 13단어 기준은 유지했다. 역사적 연구 문서는 소품을 명시했으므로 모든 출처가 처음부터 손을 허용했다고 주장하지 않는다. 현재 정의와 공개 데이터의 명시적 대안을 판단 계약에 일치시킨 수정이다. 별도 얼굴 가림 프로필의 저자가 선택한 미완료 과제 조건은 건드리지 않았다.

## 전후 결과

가까운 빈손/소품 없는 장면과 가까운 소품 대조 2개를 동일한 원본 네 계약으로 정상 CLI에 실행했다. AFTER 둘 다 성공했다. 팩마다 팩 ID와 네 의도한 계약 경로만 달라졌다. 29개 후보 모음의 ID·순서·개수 및 후보 기록 전체는 동일했고 코어도 그대로다.

같은 손 증거는 수정 전 시각 증거 감사에서 소품 앵커가 없다는 이유로 실패했지만 수정 후 통과한다. 소품 증거는 전후 모두 통과한다. 최종 두 구성물은 실제 전체 구성 감사 CLI에서도 종료 코드 0, 실패 0이다. 본문은 원래 기준 문장을 그대로 포함하고 손 장면에 소품을 추가하지 않았다. 각 사례의 의도/자유 서술 커버리지 경고 3개는 비치명적이며 결과에 그대로 남겼다.

새 회귀 3개를 포함한 46개 테스트, 독립 소비자 검사 72개, 사전과 실제 인덱스 검증이 통과했다. 두 앵커 자체는 내용 단어 12개라 기존 최소 13개에 못 미친다. 기준을 낮추지 않고 구체적 장면을 포함한 20/21개 단어 증거를 검증했다.
