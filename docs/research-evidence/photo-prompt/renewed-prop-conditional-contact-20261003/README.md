# 할버드·석궁의 정물과 손 접촉 조건 분리

기준 커밋: `fb21b964f0f740e6cf846df89154e603a1280b00`. 두 물체 형태 프로필의 세 문구를 수정했다. 할버드 구성의 손 간격, 석궁 구성과 접촉 게이트의 손 지지를 사람이 물체를 들거나 지지할 때의 조건으로 명확하게 했다. 사람 없는 정물에 손을 추가하도록 강제하지 않는다.

원래 무기 시각 의미 명세는 형태를 독립적으로 다루며, 사람과 물체의 소유·접촉 검증은 사람이 실제로 상호작용할 때 적용한다. 대상 소품 후보도 사람/물체 양쪽 문맥을 지원한다. 따라서 이 수정은 새 장면 정책이 아니라 기존 범위를 되살린다. 다섯 형태 성분, 다섯 게이트의 ID/수/척도, 증거 요구, 활성화와 세부 물체 구조는 그대로다. 요청된 인물·손 배치와 접촉은 계속 지켜야 한다. 물체 제조나 조작 절차를 추가하지 않는다.

## 실제 검증

각 물체의 정물·사람이 든 장면 네 건과 도자기 음성 한 건을 동결한 출처 참고 진단으로 정상 CLI에 전후 실행했다. 모든 실행이 통과했고 전체 팩의 차이는 승인한 문구와 올바르게 재계산한 팩 ID뿐이다. 모든 후보 값·순서·수, 코어·원본 묘사·손 접촉·신체 사전 검증은 동일하며 도자기 팩은 바이트까지 같다. BEFORE는 이전 커밋에 적란운 수정만 있던 작업 트리에서 실행했으며 그 소스 해시가 새 기준 커밋과 같음을 확인했다.

최초 전체 구성 감사는 기존 최소 단어 수를 충족하지 않는 짧은 증거 문구 때문에 대상 네 건이 전후 동일하게 실패했다. 그 기록을 보존했다. 동결된 장면에 이미 존재하는 형태·배치 설명만 덧붙여 증거를 작성하고, 같은 수정된 증거를 전후 양쪽에 다시 적용했다. 원본 입력·코어나 계약을 느슨하게 바꾸지 않았다. 이 수정은 구성 지시의 충돌을 없애며 검색 순위나 감사 수용률 향상으로 주장하지 않는다.

새 회귀 3개와 기존 무기/물체 소유 테스트 11개, 사전 검증이 통과했다. 모든 1,496개 의미 텍스트·벡터·BM25F가 동일하여 레지스트리 해시만 갱신했다. 제공자 호출·추가 비용은 0, 프로젝트 누적 보수 상한은 $1.4237696이다. 이미지 생성 및 픽셀 품질은 측정하지 않았다. 기존 전체 테스트의 자료 누락 제한은 [전체 실행 보고](../renewed-full-suite-baseline-20261002/README.md)를 따른다.

최종 수정된 전체 구성 감사는 전후 각각 5/5로 통과했고 같은 세 커버리지 경고를 유지했다. [전체 증거](diagnostic-evidence.tar.gz), SHA-256 `b46d8836a41273066da9ce6516a1dd6a1707d56c6068e1db3dc5d563d5cd4eec`. 최초 실패, 작성 증거의 보정 근거, 전후 최종 결과 및 모든 팩 차이를 함께 제공한다.
