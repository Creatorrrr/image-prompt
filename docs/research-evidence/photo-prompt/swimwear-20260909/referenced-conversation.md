여성용 수영복은 실제로는 상당히 세분화되어 있습니다. 촬영·이미지 콘셉트용이라면 단순히 **“비키니 / 원피스 수영복”**이라고 쓰는 것보다, **실루엣 + 네크라인 + 스트랩/백 디자인 + 하의 컷 + 소재 + 디테일 + 시대/무드**를 조합하면 훨씬 정확한 결과를 만들 수 있습니다.

실제로 패션 분야에서도 bikini, one-piece뿐 아니라 string bikini, high-waisted brief, sporty tank, retro maillot, cutout bralette, halter, bandeau 등의 용어가 함께 쓰입니다. citeturn451053search3

## 1. 가장 기본적인 수영복 종류

### 원피스 계열

| 용어 | 의미 / 특징 |
|---|---|
| **One-piece swimsuit** | 가장 일반적인 일체형 수영복 |
| **Maillot** | 패션 분야에서 클래식 원피스 수영복을 지칭하는 표현 |
| **Plunge one-piece** | 앞쪽 V가 깊게 내려가는 형태 |
| **High-neck swimsuit** | 목 가까이까지 올라오는 형태 |
| **Scoop-neck swimsuit** | 둥근 U자 네크라인 |
| **Square-neck swimsuit** | 사각 네크라인 |
| **One-shoulder swimsuit** | 한쪽 어깨만 스트랩이 있는 비대칭형 |
| **Asymmetric swimsuit** | 좌우 구조가 다른 비대칭 디자인 |
| **Cut-out swimsuit** | 허리·복부·옆구리 등에 컷아웃이 있는 형태 |
| **Wrap-front swimsuit** | 랩 드레스처럼 앞판이 교차 |
| **Twist-front swimsuit** | 가슴 중앙을 꼬아 만든 디자인 |
| **Zip-front swimsuit** | 앞쪽에 지퍼가 있는 스포츠/서프 계열 |
| **Belted swimsuit** | 허리 벨트가 있는 레트로·리조트형 |
| **Long-sleeve swimsuit** | 긴소매가 붙은 원피스 |
| **Legsuit** | 하의가 짧은 팬츠처럼 내려오는 일체형 |
| **Swim dress** | 스커트나 미니드레스 형태가 결합된 수영복 |

실제 스포츠 수영복에서도 racerback, zipper, removable cups, underbust elastic 같은 요소가 함께 사용됩니다. citeturn451053search0turn451053search6

# 2. 비키니 / 투피스 상의 종류

### Bikini Top

**Triangle Bikini**
- 삼각형 컵
- 가장 전형적인 비키니 디자인

**String Bikini**
- 가느다란 끈을 사용하는 비키니
- 목·등·옆구리를 묶는 구조가 많음

**Bandeau Bikini**
- 어깨끈이 없는 튜브형
- `strapless bikini`라고도 표현

**Halter Bikini**
- 목 뒤에서 묶는 홀터넥

**Bralette Bikini**
- 브라렛처럼 편안하고 비교적 구조가 단순한 상의

**Balconette Bikini**
- 발코넷 브라 형태
- 수평적인 컵 라인과 구조적인 느낌

**Underwire Bikini**
- 와이어가 들어간 브라형 비키니

**Demi-cup Bikini**
- 컵 높이가 낮은 브라형 디자인

**Longline Bikini Top**
- 언더밴드가 아래쪽으로 길게 내려오는 스타일

**Crop-top Bikini**
- 크롭톱과 수영복의 중간 형태

**Tank Bikini / Sport Bikini Top**
- 스포츠 브라 또는 탱크톱과 비슷한 형태

**One-shoulder Bikini**
- 한쪽 어깨 스트랩

**Off-shoulder Bikini**
- 어깨선 아래쪽에 위치하는 디자인

**Ruffle Bikini Top**
- 프릴이 들어간 디자인

**Wrap Bikini Top**
- 몸통을 감아 묶는 랩 구조

# 4. 비키니 하의 컷

촬영 프롬프트에서는 **상의보다 하의 용어를 정확하게 지정하는 것이 전체 실루엣에 큰 영향을 줍니다.**

### 허리선

**High-waisted**
- 배꼽 근처까지 올라오는 하이웨이스트
- 레트로 이미지와 잘 어울림

**High-rise**
- 높은 밑위

**Mid-rise**
- 중간 밑위

**Low-rise**
- 골반 가까이 내려가는 낮은 밑위

### 다리선

**High-leg / High-cut**
- 다리 개구부가 골반 위쪽까지 올라감
- 다리가 길어 보이는 1980~90년대식 실루엣에 자주 사용

**Classic-cut**
- 일반적인 다리선

**Boyleg**
- 다리 시작 부분을 짧은 팬츠처럼 감싸는 형태

### 뒷면 커버리지

커버리지가 많은 쪽부터 대략

**Full coverage → Classic → Moderate → Cheeky → Brazilian → Thong**

순으로 생각할 수 있습니다.

그 밖에:

- **Hipster Bottom**
- **Boyshort Bottom**
- **Tie-side Bottom**
- **Side-string Bottom**
- **V-cut Bottom**
- **V-front Bottom**
- **Fold-over Waist Bottom**
- **Swim Skirt**
- **Skirted Bottom**

등이 있습니다.

실제 스포츠 수영복 제품에서도 `cheeky coverage` 같은 용어가 사용됩니다. citeturn451053search2

# 8. 소재

가장 전형적인 조합은:

### 기능성 소재

**Nylon / Polyamide**
- 부드럽고 신축성 있는 표면

**Polyester**
- 내구성이 좋고 스포츠 수영복에 많이 사용

**Elastane / Spandex / Lycra**
- 신축성을 제공

예를 들어 실제 제품은 `80% nylon + 20% elastane`, 또는 `83% polyester + 17% elastane` 같은 조합을 사용합니다. citeturn451053search0turn451053search6

### 촬영 시 질감을 만드는 소재 키워드

- **Ribbed** — 골지
- **Crinkle** — 주름진 입체 텍스처
- **Seersucker** — 요철감 있는 원단
- **Terry cloth** — 타월 같은 테리 소재
- **Jacquard** — 직조 패턴
- **Mesh**
- **Power mesh**
- **Crochet**
- **Lace overlay**
- **Satin-look**
- **Metallic fabric**
- **Lurex**
- **Glossy stretch fabric**
- **Matte technical fabric**
- **Neoprene**

단, crochet나 lace는 실제 물놀이용 기능성 수영복보다는 **패션 수영복·커버업**에 더 가까운 경우도 많습니다.

**[기본 형태] + [네크라인] + [등판] + [하의 컷] + [소재] + [디테일] + [무드]**

**1950s**
> ivory halter-neck retro maillot + sweetheart neckline + low back + softly ruched waist + subtle skirted hip + navy piping + French Riviera glamour

**1990s**
> minimal black one-piece + square neckline + thin straps + very low scoop back + high-leg cut + matte stretch fabric + clean 1990s editorial

**서핑**
> long-sleeve zip-front surf suit + high neck + color-block panels + technical matte fabric + athletic coastal styling

**현대 리조트**
> asymmetric one-shoulder swimsuit + waist cut-out + metallic ring detail + ribbed ivory fabric + minimalist Mediterranean resort aesthetic

**로맨틱**
> floral balconette bikini + high-waisted bottoms + ruffled shoulder straps + scalloped edges + tiny rose print + soft vintage resort mood
