# 첫 독립 테스트 이후의 보완 계획

현재 원본 3장과 동결 기준은 유지한다. 이 문서는 후속 계획이며 추가 이미지 생성은 실행하지 않았다.

## 1. 실제 팩 노출 공백

세 팩 모두 일반 슬롯 후보 64개를 소진했다. 슬롯 검색 코드는 core 슬롯을 우선하고, 후보 접근 전에 작성된 구체적 semantic assertion이 있으면 해당 관찰의 슬롯에 먼저 접근하게 한다. 현재 케이스에는 그 관찰 assertion이 없어서 support 슬롯인 hand_pose·contact_point가 팩에 들어오지 않았다. 시각 의미 후보도 기존 8개였고 새 자세 프로필은 직접 opt-in 후보로 나오지 않았다. 관련 프로필 ID가 번들의 advisory 연결에 존재하는 것은 직접 노출·채택과 구분한다.

다음 독립 사례는 후보 접근 전에 일반 지식으로 소유자·관절·접촉·지지·가시성의 구체적 관찰을 baseline과 core에 함께 기록하고 동결한다. 이 관찰은 **advisory**로 두며 사용자 요구나 잠금으로 승격하지 않는다. 기존 64개 상한, 사용자 잠금, 적용 범위, 후보 자율 채택은 유지한다. 좌면 손바닥 지지, 머리 위 둥근 팔, V 손가락 배열이 정상적인 관찰 우선 경로에서 실제 노출되는지 확인한다. 현재 팩에 ID를 끼워 넣거나 현재 core를 바꾼 뒤 최초 성공으로 재기록하지 않는다.

팩 판정 기준은 독립 관찰과 후보의 소유자·속성 범위 일치, 원래 기준의 보존, 실제 상세 view의 구성요소·효과 노출, 재계산 가능한 감사다. 시각 의미 프로필을 실제로 선택했다면 그 프로필의 모든 게이트를 해당 원본에서 평가한다. 새 34개 프로필 전체는 이번 결과로 이미지 자격을 얻지 않는다.

## 2. 픽셀 실패와 관찰 경계

| 경계 | 다음 장면에서 고정할 관찰 | 대조 오답 |
|---|---|---|
| 지지손 좌우 | anatomical left와 frame-right의 연결, 열린 손바닥·손목·좌면을 함께 노출 | 오른손 지지·왼손 지도 |
| 교차 정강이 소유권 | 두 발목 연결이 각각 보이는 변형과 카메라 위치 | 뒤쪽 발목이 반대 다리에 가림 |
| 발레 팔 | 연결된 둥근 overhead oval·부드러운 팔꿈치·손끝 간격 | 곧은 overhead V 또는 기도 손 |
| V 사인 | 왼손의 두 펼친 손가락과 접힌 약지/소지를 함께 노출 | 세 손가락 또는 평행 두 손가락 |
| demi-plié 깊이 | 얕은 굽힘과 작은 골반 하강을 사전 정의 | 깊은 squat에 가까운 굽힘 |
| second position 간격 | modest spacing을 사전 정의한 명시적 변형 | 일반적인 넓은 turnout 배열 |
| 복구된 전시판 | 전시판·연결된 지지 브래킷·완료 상태를 별도로 식별 가능하게 배치 | 일반적으로 온전한 신호 전시물 |

첫 후속 묶음은 이 7개 경계의 양성·반례 각 1개, 총 14개 독립 사례로 설계할 수 있다. 각 사례의 기준을 후보 접근 전에 고정하고, source·pack·positive/negative·실제 tool arguments·원본·판정을 각각 보존한다. 과거 원본의 서로 다른 성공 부분을 합쳐 한 장면 성공으로 집계하지 않는다.

modest spacing과 shallow bend에는 비교 가능한 관찰 경계를 새로 정한다. 프로젝트용 명시적 변형과 발레의 일반 용어를 분리하고, 의상·카메라·신체 외형에서 정확한 실제 관절 각도나 힘을 추론하지 않는다. 닫힌 violin case 같은 물체는 외형이 구분되는 사례로 바꾸거나 동결 기준의 주장 범위를 실제 보이는 물체로 한정한다. 복구 상태 역시 보이는 부품 배열을 판정하며 실제 과거 수리 이력을 증명한 것으로 해석하지 않는다.

## 3. 나머지 데이터

이번 4개 선택 후보 외의 154개 새 후보와 선택하지 않은 34개 프로필은 별도 렌더 자격이 없다. 원래 보류한 64개는 변형·동작 단계·개별 출처·참고 픽셀 검토를 완료한 뒤 독립 확장으로 승격한다. 데이터·팩·프롬프트·실제 픽셀의 결과를 각각 기록하고 `partial_is_fail`을 유지한다.
