후보 소스나 런타임을 바꾸지 않은 읽기 전용 조사다. 제공자 호출은0이며 데이터 개선 회차에 포함하지 않는다.

## 구도·시점: 141개 행 유지

shot_scale, subject_framing, body_framing, camera_height, camera_direction의141개 행을 원래 출처와 실제 의미 표면으로 검토했다. 세부 변형과 축이 다르다는 이유만으로 한영 의미가 뒤집혔다고 판단하지 않았다. three-quarter의 화면 범위/몸 방향과 몸의 대각선/카메라 롤은 원래 조사에서도 구분되어 있다. 새 수정 근거는 없었다.

## 아래에서 올려다보는 방향은 이미 존재한다

앞선 독립 기차 사례006에서 `worms_eye`는 실제 준비된 소비자 자료에 있고, 물체 장면에서도 적합하다. 의미 표면은 “worm’s-eye view from below”로 낮은 위치만이 아니라 상향 시점을 표현한다. 극저각 두 변형도 적합하지만 요청보다 과할 수 있다.

원래 코어·컨트롤·신체 검토·시드를 그대로 사용한 실행 경로를 재현했다. 전체 질의에서는 extreme_low_angle_under_subject가1위, extreme_low_hero_angle가2위, worms_eye가5위다. 하지만 슬롯 전용 질의는 bird’s-eye/Dutch/top-down/mirror 네 항목만 반환한다. 전체/전용 ID 교집합에서 상향 후보가 빠지며, 이 슬롯 처리 시 총량은0이므로 여기서는64 상한이 원인이 아니다. 새 동의어나 상향 후보를 추가할 근거가 없다. [상향 시점의 실제 경로](upward-view-production-trace.md)에 자세히 적었다.

초기 보조 검사는 load_json만 사용하여 적합 행35개를 셌지만, 실제 load_runtime_data는 품질 레이어 문맥 가드를 적용하여28개다. 그 차이는 검증 도구의 로더 누락이었으며 과거 런타임 변화나 중복 ID 때문이 아니다. 원래 검사·정정 근거와 실제 재현을 함께 보존했다.

## 광학 명칭: 유지

틸트/시프트 장비와 미니어처 초점 효과의 범위는 이미 나뉜다. 일반적인 건축 시프트, 장노출, 후막 동조, 다중 노출이 조사 대상의 더 좁은 강제 프로필을 잘못 켜는 결과는 나타나지 않았다. 정확한 좁은 관계 세 건은 활성화되고 계약이 그대로 투영되었다. 선택적 의미 검색 순위나 이미지 픽셀은 검증하지 않았다.
