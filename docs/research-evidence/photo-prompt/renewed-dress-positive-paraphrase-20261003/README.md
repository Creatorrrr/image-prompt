# 드레스 긍정 예시의 자기 배제 표현 정리

기준 커밋: `c37e21f696047f64649c412db0c7cf468e200da3`. 원피스 드레스의 상세 긍정 예시 한 문장 끝을 수정했다. 기존의 “바지통으로 나뉘지 않는다”는 표현은 부정하려는 `trouser legs`를 자체 문맥 배제 조건에 걸리게 했다. 같은 뜻을 “하나의 연속된 치마형 드레스 실루엣”이라는 긍정 기하로 표현했다. 허리 봉제·여러 패널·여밈·드레이프 허용과 모든 배제 조건은 그대로다.

원래 문장은 10월 2일 개념 카드의 상세 긍정 예시에서 온 것이다. 사전의 넓은 one-piece 뜻 중 드레스에 한정하는 경계는 프로젝트가 명시적으로 선택한 범위다. 역사적 조사 카드나 런타임 규칙은 수정하지 않았다.

## 의미와 실제 효과를 구분

이것은 **데이터의 긍정 예시 일관성 수정**이다. 새 문구는 기존 인덱스에서도 이미 수용되었고, 원래 부정문으로 작성한 동일 요청은 수정 후에도 배제된다. 따라서 이 변경이 사용자 자연어 재현율을 높였다고 주장하지 않는다.

별도 작성자가 원래 정의와 경계만 보고 만든 영·한 양성 및 인접 개념·간판·다중 소유자 음성을 포함해 동결 질의 열 건을 비교했다. 실제 레지스트리에 결합된 새 인덱스에서도 후보 ID·순서·순위·매치 근거·문맥 적합성·선택 가능 여부가 모두 같았다. 점수 일부의 통계적 변화는 전체 증거에 남겼다. 간판 예시는 불일치 진단 항목으로 기록되지만 선택 불가능하므로 오탐 수용으로 세지 않는다. 한국어 자연어 양성의 기존 문맥 불일치도 그대로여서 해결했다고 하지 않는다.

정상 CLI 다섯 전후 실행은 모두 통과했고 **전체 팩이 바이트까지 동일**하다. 이 중 원본/수정 예시 둘은 출처 참고 진단이며 나머지는 독립 작성 질의다. 이미지를 생성하지 않았고 픽셀 개선이나 쿼리 임베딩 검색 품질도 측정하지 않았다.

기존에 지적된 21개 성분 묶음은 현재 공통 문맥 검사에서 모두 통과한다. 새 정적 검사의 48개 단어 중복은 결함 48개가 아니다. 정의가 제외 개념을 설명하기 위해 그 단어를 포함하는 정상 사례가 많으므로 일괄 수정하지 않았다.

새 회귀 3개와 기존 의미 안내 5개로 테스트 8개, 사전 검증이 통과했다. 변경된 프로필 한 개만 실제 Gemini 벡터를 갱신하고 나머지 1,495개 인덱스 항목은 동일하게 유지했다. 실제 제공자 요청은 1회다. 앞선 SDK 누락으로 네트워크 전에 끝난 로컬 시도도 보수 상한에 포함했으며, 이번 증가 $0.0032768, 프로젝트 누적 상한 $1.4270464 / 허용 $10이다. 이는 청구액이 아니다. 전체 테스트의 이전 자료 누락 제한은 [전체 실행 보고](../renewed-full-suite-baseline-20261002/README.md)에 남아 있다.
