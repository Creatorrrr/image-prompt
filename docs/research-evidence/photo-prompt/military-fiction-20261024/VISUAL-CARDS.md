# 시각 의미와 후보 초안 104개

각 항목은 연구용 완결 시각 대안이다. 실제 후보 CID/RID, effects, intrinsic conditions, native proof는 아직 만들지 않았다. `suggested_slots`는 구현 때 현행 catalog와 대조할 제안이며 승인된 binding이 아니다. 각 출처는 한정된 용어 구분을 뒷받침하고 아래 구도·행동은 독립적으로 작성했다. 실제 도판·신체 모델·원문 전체 조건 검토는 다음 단계다.

## V01 · 생활관의 개인 구역

서로 마주 보는 침상 두 줄 사이에 통로가 있고 각 침상 머리맡에 별도 관물대와 접힌 담요가 놓인다.

Two rows of bunks face an open aisle, with a separate locker and folded blanket at each bunk's head.

- 관계: bunks → face → aisle; locker → beside → bunk
- 화면 확인: 침상 반복; 통로 연속; 개별 수납
- 구분·한계: 신병·선후임·특정 국가의 생활규정은 이 배치로 증명하지 않는다.
- 제안 role: location, spatial_depth / 출처: S03
