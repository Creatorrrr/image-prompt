# 제복·코스튬 대체 표현 반영과 독립 이미지 시험

2026-10-04. 연구 결과를 시각 의미와 후보 데이터에 반영하고, 독립 에이전트 3개가 첨부 사진을 사용해 실제 이미지를 시험했다. 새 의복 관계의 픽셀 검사는 6/6 통과했으며, 복합 컨셉의 일부 접촉·겹침·부츠 조건은 실패로 남았다.

## 반영 범위

기존 시각 의미 29개와 그에 대응하는 후보 29개를 보강하고, 근거를 확인한 관찰 가능한 관계 38개와 후보 38개를 추가했다. 시각 의미에 새로 추가한 한·영 완전 대체 표현은 266개다. 짧은 구성요소 표현도 보강했으며, 선택 가능한 묶음 3개를 추가했다. 변경한 authored 원본은 8개다.

| 대상 | 반영 |
|---|---|
| 기존 29개 의미 | 한·영 관계 문장과 짧은 표현 추가. 기존 ID, 정의, 활성화 조건, 속성 효과, 증거 최소치, native 검사 의무 유지 |
| 새 관계 38개 | 소유 의복, 층, 연결부, 여밈, 부피와 경계를 구성요소별로 정의 |
| 후보 67개 | 대체 표현·keywords·embedding text를 의미와 대응시킴. 새 후보에는 concept units, relations, 주체의 appearance 속성 효과 명시 |
| 묶음 3개 | 겉포와 안쪽 소매, 어깨에 걸친 코트와 안쪽 장식, 세일러 칼라와 가장자리 선. 선택적이며 각 구성요소 증거를 요구 |
| 파생 검색 데이터 | 의미 프로필 1,728개와 후보 항목 9,939개의 현재 인덱스 재생성. 임베딩 batch size 1, 호환 벡터 재사용, 기존 shard 세대 보존 |

145개 조사 키워드 중 92개는 하나 이상의 관계에 대응한다. 53개는 확인되지 않은 버전·규격 등의 근거를 더 확보해야 한다. **92개는 복식 전체의 정본 재현을 보증하는 수치가 아니다.** 이름 하나로 대안 버전들을 모두 필수화하지 않는다. [키워드별 대응](keyword-runtime-map-final.json)과 [전체 반영 목록](INTEGRATION-LEDGER.json)에 범위를 남겼다.

## 대체 표현의 의미와 경계

| 자연스러운 표현 예 | 필요한 관찰 | 혼동 방지 |
|---|---|---|
| 소매 없는 겉포 / 안쪽 소매가 진동으로 나옴 | 바깥옷의 무소매 구조와 그 진동을 통과하는 안쪽 소매 | 소매 있는 겉옷으로 대체하지 않음 |
| 포의 봉제된 허리선 / 그 선에서 내려오는 주름 | 상하부의 실제 봉제 연결과 그 연결에서 시작하는 주름 | 독립된 주름치마를 같은 구조로 보지 않음 |
| 어깨에 걸친 모피 테두리 코트 / 빈 소매 / 같은 코트 지지끈 | 한 착용자의 걸친 코트, 비어 늘어진 소매, 그 코트의 지지 관계 | 두 팔을 넣어 정상 착용한 코트를 대체 증거로 보지 않음 |
| 독립된 조끼 / 재킷에 붙은 모조 조끼 | 단독 조끼와 부착 앞판의 서로 다른 소유·연결 관계 | 두 형태를 합치지 않음 |
| 넓은 바지통 / 모여 좁아진 각각의 커프 | 두 바지통의 느슨한 부피와 각 바지통의 좁은 하부 경계 | 게이터나 한 덩어리 치마가 커프를 대신하지 않음 |
| 일체형 비행복 / 중앙 앞지퍼 | 같은 의복의 몸통→허리→바지 연결과 그 의복의 앞여밈 | 따로 입은 재킷과 바지를 일체복으로 보지 않음 |
| 직물 비행복 / 주머니 지퍼와 다른 앞지퍼 | 몸체의 여밈과 별도 주머니 경계 | 압력 헬멧과 목부 연결을 자동 추가하지 않음 |
| 넓은 세일러 칼라 / 가장자리를 따르는 평행 줄 | 칼라의 폭과 그 칼라 가장자리의 선 | 소매의 줄만으로 칼라 선을 충족하지 않음 |
| 회색 어깨 요크 / 검정 몸판 / 별도 색 있는 속깃 | 같은 착용자의 선택된 층과 배색 경계 | 시대별 대안 배색, 직급이나 직무를 추정하지 않음 |

긴 대체 문장뿐 아니라 구성요소별 짧은 표현을 추가했다. 대체 표현은 의미를 찾는 근거이며, 기존 exact activation으로 자동 승격하지 않았다. 에이전트가 선택한 의미는 전체 구성요소의 native 검사를 받아야 한다. 일부만 보이면 FAIL, 연결부가 가려지면 UNOBSERVABLE로 판정한다.

주아브의 넓은 바지통과 커프 모임은 [Met의 실제 복식 기록](https://www.metmuseum.org/art/collection/search/151912)에서 추가로 확인한 U10 관계다. 기존 조사에서 보류한 부분에 추가 확인을 했다는 이력은 [추가 근거](additional-source-verification.json)에 남겼다. 모든 주아브 복식에 같은 하부 형태를 강제하는 규칙은 아니다.

## 검색 누락과 수정

세 에이전트는 강화 데이터·이전 결과를 보지 않고 각각 컨셉과 기본 프롬프트를 먼저 동결했다. 최초 검색에서 A·C는 적합한 변경 의미를 선택하지 못했고, B는 의복 후보만 선택할 수 있었다. 이 초기 결과와 프롬프트를 보존했다.

짧은 대체 표현을 보강한 뒤에도 긴 복합 장면의 전체 유사도 상위 8개가 해당 관계를 밀어내는 현상을 확인했다. 그래서 source가 명시적으로 허용하고 **모든 구성요소가 원래의 동결 관찰에 존재하는 관계**를 별도 BM25F 경로로 검색하도록 공통 연결을 보완했다. 특정 제복명이나 테스트 ID를 라우팅하는 분기는 없다. 제외 조건·열린 차원·속성 잠금·성인 문맥·source opt-in을 유지하고, 결과는 optional이며 사용자 요구 ID를 만들지 않는다.

원래 컨셉을 재사용한 3개 진단 회귀와 구성요소 누락, opt-out, 잠금, 제외 조건을 포함한 13개 집중 검사가 통과했다. [검사 로그](tests-uniform-component-bridge.log), [공통 연결 변경](component-discovery-bridge.patch).

이 수정에는 최초 테스트 문구를 본 뒤 추가한 일반 대체 표현과 관계가 포함된다. 따라서 아래 결과는 **독립적으로 만든 고정 컨셉의 회귀 시험**이며, 보지 않은 새 문구에 대한 일반화 성공률은 아니다.

## 독립 이미지 시험

3개 에이전트의 사용자 원문 봉투, 기본 프롬프트, 코어, controls, review와 pack seed를 유지했다. 실제 컨셉 문장은 에이전트 선택이며 사용자 정의나 필수 assertion으로 바꾸지 않았다. 현재 데이터와 코드를 별도 스냅샷으로 동결해 각 에이전트가 사용했다. 첨부 사진은 얼굴과 짧은 단발의 시각 참조로 사용했다.

| Arm | 독립 랜덤 컨셉 | 채택한 새 시각 의미 |
|---|---|---|
| A | 역 수하물 홀의 주아브 복식, 붉은 sash를 정리하는 손동작, 사광과 찬 보조광 | 두 넓은 바지통과 각자의 모인 커프 |
| B | 비가 그친 격납고 유리 통로의 sage 비행복, 카트 위 흰 리넨을 집는 손, 직물·금속·젖은 유리 | 일체복의 허리 연결과 같은 의복 앞여밈 |
| C | 오래된 궤도 작업실의 ivory·rust-orange 복고 우주 작업복, 장갑 손의 레버 1/4 회전, amber·blue 조명 | 일체복의 허리 연결과 같은 의복 앞여밈 |

각 arm은 새 의미의 native gate 2개와 embodiment gate 5개, 총 7개의 실제 계약 gate를 생성 전에 동결했다. 최초 키워드 검사표 A 7개, B 5개, C 8개는 별도 보조 검사로 보존했다. [3개 테스트케이스와 실제 프롬프트](PROMPTS.md). 프롬프트 감사와 runtime 감사는 생성 입력 검증이며, 픽셀 통과와 구별한다.

Native 호출은 각 arm 2회씩 총 6회다. 첫 이미지와 한 번의 제한된 수정 이미지를 모두 원본 바이트와 해시로 보존하고, 에이전트별 검사 후 coordinator도 6개 원본을 원래 해상도에서 확인했다. 프롬프트·runtime 감사는 모두 통과했지만 아래 픽셀 결과와 구별한다.

| Arm | 새 관계 gate 첫→수정 | 실제 계약 gate 첫→수정 | 최초 키워드 검사 첫→수정 | 최종 전체 키워드 판정 |
|---|---:|---:|---:|---|
| A 주아브 | 1/2 → **2/2** | 3/7 → **5/7** | 4/7 → **3/7** | FAIL |
| B 비행복 | 1/2 → **2/2** | 6/7 → **7/7** | 4/5 → **5/5** | 고정 키워드·계약 범위 PASS |
| C 복고 우주 작업복 | 0/2 → **2/2** | 5/7 → **7/7** | 6/8 → **7/8** | FAIL |

새 관계의 필수 구성요소는 최종 **6/6**, 실제 계약 gate는 **19/21**, 최초 키워드 검사 전체는 **15/20** 통과했다. 판정은 한 이미지 안의 모든 구성요소를 요구하며 이미지 간에 성공한 부분을 모아 통과시키지 않았다. 완전한 복합 키워드 시험은 3개 arm 중 B 하나가 통과했다. [모든 원본·해시·분모를 포함한 판정](NATIVE-QUALIFICATION.json).

A의 수정 이미지에서 두 바지통과 각자의 좁은 붉은 커프는 흰 게이터와 구별되어 확인됐다. 오른팔도 올바른 방향으로 수정됐다. 그러나 sash tail이 wrap 안으로 들어가는 접촉은 손 뒤에 가려 contact·visibility 2개가 UNOBSERVABLE이다. 재킷이 sash 윗부분을 덮는 것은 FAIL, 독립 waistcoat의 접합과 게이터가 바지 끝을 감싸는 관계는 UNOBSERVABLE이다. 커프를 노출한 수정이 다른 복식 검사도 자동 해결한 것으로 판단하지 않았다.

B·C는 허리벨트의 앞 버클 사이를 열어 같은 천과 앞지퍼가 허리를 지나 바지 구간으로 이어지는 부분을 직접 확인했다. B는 원래 비행복 키워드 5개를 충족했다. 수정 프롬프트가 추가로 요청한 반대편 벨트 고리 지지의 일부는 팔 뒤에 있어 별도 fidelity 검사 3/4이며, 완전히 관찰했다고 주장하지 않는다. C는 ankle-high 부츠 조건을 충족하지 않아 최초 키워드 전체는 여전히 FAIL이다.

## 회귀 및 보존

전체 **1,393개 테스트를 빠짐없이 실행**했다. 처음 1,391개가 통과했고 2개에서 오류가 발견됐다. 현재 참조하는 외부 유지보수 기록 4개에 필수 `maintenance_only` 메타데이터를 추가하고, 과거 사전 비교 검사에는 해시로 고정한 정확한 추가분의 역투영만 넣었다. 기존 21개 keep 값과 모든 과거 기대값·질의·holdout은 그대로 유지했다.

수정 뒤 관련 6개 모듈의 **61개 검사를 다시 실행해 모두 통과**했다. 전체 1,393개 각각의 최신 결과가 PASS다. 수정 뒤 전체를 처음부터 다시 실행한 것으로 표현하지 않는다. [완료·재검사 결과](TEST-RESULTS.json).

유지보수 메타데이터 수정 전후 모든 runtime 후보 행·의미·활성화·속성·gate는 동일하며, 고정 입력으로 만든 현재 후보팩의 **전체 바이트도 동일**함을 검증했다. 인덱스 검사와 사전 검사도 통과했다. [메타데이터 보완](maintenance-seal-receipt.json), [후보팩 바이트 보존](maintenance-runtime-preservation.json), [최종 인덱스](index-receipt-final.json).

현재 후보팩의 데이터 변경은 새 V11 관찰로 기록했다. 기존 V1–V10 파일, 4개의 고정 입력, scene·composition contract, 공개 후보 64개 제한, negative bytes를 유지했다. V11을 읽는 추가 지원과 validator SHA 연결만 보완했다. [보존 검증](PHOTO-BOUNDARY-PRESERVATION-final.json).

원래 존재하던 다른 작업의 dirty·untracked 파일과 이전 shard 세대를 보존했다. 커밋·푸시는 수행하지 않았다. 결과는 이 스냅샷의 데이터·검색·입력·native 픽셀 범위에 관한 검증이며 사용자 최종 수용 여부는 별도다.
