# 범용 작성 지침 반영 및 독립 이미지 시험

사진 스킬의 Phase 1과 Phase 3에 특정 단어와 무관한 공통 작성·선택 지침을 반영했다. 대화 기록을 상속하지 않는 독립 에이전트 3개가 같은 첨부의 얼굴·머리만 참고해 각자 컨셉을 작성했고, 기본 이미지 도구 3회로 원본 이미지 3장을 반환받았다. 구성·런타임 감사는 모두 통과했다. 원본 픽셀의 세부 충족은 혼합 결과이며, 전체 DATA 구현이나 반복 편향 해소를 통과로 선언하지 않는다.

## 실제 반영

- 모든 요청에 공통으로 적용하며 단어·분위기 분류·언어·키워드 유무로 지침을 활성화하지 않는다. 전체 의미, 지정 조건, 열린 선택, 해결된 제어값으로 해석과 탐색을 조절한다.
- 주제·형태·순간·관계의 착상을 먼저 정하고 표현을 선택한다. 익숙한 첫 실현과 다른 실현을 같은 기준으로 비교하며 고정 대안 수·요소 메뉴·과거 작품 조회·반복 금지는 도입하지 않는다.
- 모든 창의성 수준에 작성자 판단을 유지한다. 숫자는 해석 거리와 탐색 깊이를 조절한다.
- 후보 단계에서도 초안과 후보를 같은 예술적 기준으로 평가한다. 최초 작성자 선택을 보호하지 않으며 열린 범위에서 교체·삭제·단순화할 수 있다. 사용자 조건과 채택한 계약은 보존한다.

수정 소스는 [SKILL.md](../../../../skills/photo-prompt-image-generator/SKILL.md) 하나이며 `.agents/skills/photo-prompt-image-generator`가 같은 파일을 가리킨다. 제어 정의·DATA·검색 코드·과거 시험 기준은 변경하지 않았다. 변경은 현재 로컬 작업 트리에 있다.

main `977a5d8680eabf24c6e19993340b4a72f884b24a`에 검토한 SKILL 변경만 더한 261개 runtime 파일을 고정했다. SKILL SHA-256은 `427349afef4cec8892e450b84e0feb0a20575bee01010eb12798a3920757c172`이다. 다른 작업의 미완료 DATA는 시험에 포함하지 않았다. ## 시험 방법

‘유혹적인’, ‘귀여운’, ‘지적인’은 실험자 배정 방향이다. 각 에이전트가 구체적인 장소·복장·행동·구도·빛을 결정했다. 사용자 원문을 새 장면문으로 바꾸거나 새 사용자 잠금으로 승격하지 않았다. 이전 작품·다른 arm·예상 답·복장 금지·상호 차이 강제는 제공하지 않았다.

독립 초안·코어·관찰축·신체 검토·장면 기준을 고정한 뒤 keyword/offline 후보팩 1개를 생성하고 전체 채택 계약을 검토했다. 기본 이미지 도구는 arm마다 1회이며 유료 임베딩·API 대체 생성·재생성은 0회다. 실제 참조의 신상은 추론하지 않고 성인 나이와 역할은 새로 작성했다.

저장 기본값 `creativity=1`, `sensual=1`, `fetish=0`, `surreal=0`을 사용했다. 이전 유혹 장면 시험의 `sensual=3`과 다르고 주제도 다르므로, 이번 차이를 지침만의 인과 효과로 해석할 수 없다. [고정 프로토콜](TEST-PROTOCOL.ko.md) · [독립 배정](AGENT-DISPATCH.json)

선택의 정확한 증거 문구가 최종 프롬프트에 있고 원래 초안에 없었던 문구임을 부모가 확인했다. 그러나 과일 건네기, 봉제 장난감, 돌봄의 손동작, 지도 비교, 참조 외형과 기본 복장은 초안에 이미 있었다. 이를 DATA가 새로 만든 장면으로 세지 않는다.

귀여움·지적 의미의 전용 시각 프로필은 해당 arm에 노출·선택되지 않아 그 주제 인상을 전용 의미 DATA의 효과로 계산하지 않는다. A의 건네기 프로필은 전체 관계가 픽셀에서 확인됐지만 표정 후보는 완전 구현되지 않았다. B의 출처 계약은 ‘접점 어두워짐 또는 압축’을 만족하지만 추가 압축 문구까지 모두 보인 것은 아니다. C의 직조·주름은 정성적으로 보이며 면 섬유의 실제 성분을 확인한 결과가 아니고 지적 분위기의 원인으로 확대하지 않는다.

앞서 강화한 유혹 연구의 27개 프로필·103개 후보 대상 집합에서는 C의 `pc_pc17_owner_relation` 1개가 노출됐지만 선택되지 않았다. 대상 프로필·후보 채택은 모두 0이다. 현재 DATA의 사용과 앞서 강화한 연구 항목의 검증을 구분한다. [부모 DATA 확인](PARENT-DATA-READBACK.json)

## 작성 절차와 반복

세 공개 작업 기록에는 첫 실현과 다른 실현의 비교, 현재 작품의 관계·순간에 따른 선택, 작성자 선택과 사용자 조건의 구분이 있다. A는 중립 카탈로그를 전체 착상 비교 기록보다 먼저 읽었다고 보고했으므로 theme-before-catalog 순서의 엄격한 준수 사례로 통과시키지 않는다. 편차를 사후 기록 수정으로 없애지 않았다.

A·B는 DATA 조회 전부터 오트밀색 니트를 선택했다. 전체 착상과 복장 구성은 다르지만 소재·배색 반복은 남았다. 이를 자동 실패나 니트 금지의 근거로 삼지 않으며, 반복 편향이 해소됐다는 근거로도 쓰지 않는다. 같은 열린 주제의 독립 반복, 정밀 요청, 비인물 주제, 지침에 없는 표현의 검증은 이번 세 사람 중심 사례 범위를 넘어선다.

## 검증과 한계

스킬 검증과 기존 작성 격리·소유권 테스트 18개가 통과했다. 부모 최종 artifact 확인 65개가 통과했으며 runtime 261개 파일, 초기 코어/CASE, 원본과 복사 이미지, 정확한 도구 프롬프트·참조·코어·팩 바인딩을 확인했다. 다른 작업의 변경 12개 파일도 그대로다. [부모 검증](PARENT-VERIFICATION.json) · [원본 픽셀 검토](PARENT-PIXEL-REVIEW.json) · [계약 테스트 로그](instruction-contract-tests.log)

이는 파일·바인딩의 증거이며 모든 파일 읽기 순서나 모델 내부 판단을 독립 계측한 증거가 아니다. 부모 검토는 주제를 알고 수행했다. 같은 제어값의 이전 스킬 대조 실행, DATA 없는 대조 이미지, 통계적 반복 표본, 사용자 선호 비교는 없다. 보편적 적용 설계는 반영했지만 모든 키워드에서 다양성이 개선됐다는 실증 결론은 아직 내리지 않는다.
