# AUTHORING-NOTES

## 사전 의미 해석 및 초기 착상

현재 사용자 문장은 이전 시험 방식의 재실행 요청이다. 같은 방식은 첨부를 활용해 독립적으로 복잡한 컨셉과 프롬프트를 작성하고 실제 이미지와 의미 DATA 적용을 평가하는 작업을 가리킨다. ‘지적인’은 조정자가 배정한 넓은 실험 방향이며, 사용자 소유의 장소·의상·행동 잠금이 아니다. 지능이나 성격을 얼굴에서 추정하지 않는다. 한 장에서 볼 수 있는 관찰, 비교, 검증의 관계를 작성자의 선택으로 표현한다.

직접 본 참조에서는 어두운 짧은 보브, 가는 앞머리, 부드러운 얼굴 윤곽, 짙은 갈색 눈과 자연스러운 입술 형태가 보인다. 원본의 나이, 신상, 지능, 직업은 판단하지 않는다. 새 피사체는 작성한 성인 설정이다.

첫 방향은 도서관에서 책을 읽는 정면 초상이다. 의미는 읽기 쉽지만 책이라는 표지에 의존하고, 인물과 자료 사이의 구체적인 판단 과정이 희박하다. 다른 방향은 빛나는 지도 작업대에서 종이 지도와 투명한 선 도면의 해안선을 맞추어 보는 자료 연구자다. 자료의 겹침, 손의 작은 이동, 시선의 끝점을 통해 비교하는 순간을 한 프레임에서 볼 수 있다. 얼굴의 매력은 편안한 입술과 가까운 심리적 거리로 은은하게 뒷받침하고, 의상을 특별한 성적 표지로 쓰지 않는다. 저장된 제어값에서 벗어나지 않는다.

이 작품의 방향은 후자를 택한다. 오래된 지도를 분석하는 29세 성인 지도 연구자의 옆쪽 초상. 장소, 나이, 직업, 천, 색, 동작, 프레이밍은 모두 작성자의 선택이다. 세밀한 인쇄선과 머리카락의 부드러운 선, 작업대의 조용한 발광을 연결한다. 주인공은 카메라에 설명하는 대신 자료를 살피며, 관객은 작업대 바로 건너편에서 생각이 물체의 관계로 드러나는 순간을 본다.

이 노트는 후보 DATA를 보기 전에 기록했다. 후보 도입으로 이미 있던 선 맞춤·시선·조명·성인 설정을 새 데이터 효과라고 계산하지 않는다.
