# 공통 작성 지침 반영 후 독립 시험

사용자는 특정 단어와 무관한 공통 작성 지침을 반영하고, 이전과 같은 독립 서브에이전트 시험을 요청했다. 사진 스킬의 Phase 1과 Phase 3만 수정한다. 저장 제어값·후보 데이터·시각 의미 데이터·검색 코드·역사적 시험 기준은 변경하지 않는다.

## 고정 실행 범위

- `SOURCE-FREEZE.json`의 커밋 파일과 검토한 새 `SKILL.md`만 별도 runtime에 고정한다. 다른 작업의 미완료 변경을 포함하지 않는다.
- 새로운 세 에이전트는 대화 기록을 상속하지 않는다. A는 유혹적인, B는 귀여운, C는 지적인 방향을 각각 실험자의 주제로 받는다. 장소·복장·행동·구도·빛 등 구체적인 실현은 각자 결정한다. 다른 arm이나 과거 작품과 달라야 한다는 규칙은 주지 않는다.
- 주제는 실험자 배정이며 사용자 소유 정의나 잠금 조건으로 승격하지 않는다. 부모가 원문 그대로 만든 요청 envelope와 현재 사용자 문맥만 전달한다. 에이전트가 새 요청문을 만들어 사용자 원문으로 바꾸지 않는다.
- 동일한 첨부 이미지의 눈에 보이는 얼굴·머리만 참고한다. 장면의 성인 나이와 역할은 새로 작성한 설정이며 원본 인물의 신상 추론이 아니다.
- 저장된 제어 기본값을 그대로 사용한다. 이전 시험의 실험자 설정 `sensual=3`과 이번 기본값 사용을 구분한다. 이전 결과와의 차이를 지침 수정만의 인과 효과로 주장하지 않는다.
- 각 arm은 독립 초안·코어·관찰축·신체 검토와 장면 판정 기준을 검색 전에 고정한다. 이후 실제 후보팩을 한 번 생성하고 필요한 전체 후보 계약을 읽어 최종 작성과 감사를 수행한다.
- 실제 이미지 생성은 기본 도구로 arm마다 한 번이다. API 대체 생성, 유료 임베딩, 결과를 본 뒤의 기준 변경이나 재생성은 하지 않는다. 생성 실패나 차단은 그대로 기록한다.

## 증거와 판정

1. 초기 작성: 허용 입력만 사용했는지, 착상과 선택이 실제로 기록됐는지, 열린 선택과 사용자 조건을 구분했는지 확인한다. 초기 작성자가 선택한 형태가 후속 DATA의 효과로 계산되지 않게 한다.
2. 시각 의미 데이터: 프로필의 노출·선택·출처·전체 구성요소와 관계·프롬프트 증거·적용한 픽셀 기준을 따로 기록한다. 슬롯 후보만 사용한 것은 시각 프로필 사용으로 계산하지 않는다.
3. 후보 데이터: 실제 노출과 채택·거절, 후보 ID와 출처, 초안 대비 변화와 선택 근거를 기록한다. 노출 또는 선택을 강제하지 않는다.
4. 실행 바인딩: 코어·팩·제어·첨부·최종 프롬프트·런타임의 정확한 해시와 감사 결과를 보존한다. 감사 통과는 텍스트와 바인딩 증거다.
5. 원본 픽셀: 이미지가 반환된 경우 실제 파일을 보고 모든 필수 요소와 관계를 확인한다. 일부 충족은 통과가 아니며 가림은 관찰 불가로 기록한다. 반환된 픽셀이 없으면 이미지 구현과 전체 인상을 미판정으로 남긴다.
6. 전체 인상: 반환 이미지의 주된 인상을 먼저 서술하고 고정한 착상과 비교한다. 기술적 충족·작품 전체의 평가·사용자 수락을 구분한다.

부모는 세 arm의 작업 기록과 원본 이미지를 별도로 검토한다. 세 사례는 다른 키워드에서도 공통 절차가 실행되는지 확인하는 시험이며, 모든 키워드에서의 성공이나 반복 감소의 통계적 증거가 아니다. DATA가 없는 대조 이미지도 생성하지 않으므로 DATA의 인과적 품질 개선을 주장하지 않는다. 인물 중심 세 사례로 비인물·정밀 요청·새로운 언어까지 실증했다고 보고하지 않는다.
