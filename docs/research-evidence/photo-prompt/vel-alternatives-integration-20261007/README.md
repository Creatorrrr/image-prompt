## 독립된 세 이미지 테스트

세 독립 서브에이전트는 동일한 실제 사용자 요청 envelope와 동일한 참조 사진만 공유한다. 각자 다른 무작위 시드로 네 개의 독립 컨셉 대안 중 하나를 골랐으며 다른 arm의 프롬프트·pack·이미지·리뷰를 보지 않았다. 연구/후보 데이터에 접근하기 전에 중립 절차로 기본 프롬프트와 core를 동결했다. 특정 컨셉·옷·소품 선택은 agent의 작성 선택이며 사용자 원문으로 재기록하지 않았다.

| Arm | 독립 컨셉 | 원문 키워드 시험 | 실제 보강 데이터의 추가 기여 |
|---|---|---|---|
| 1 | 폭풍 방벽 아래 조력 발전소 엔지니어 | 낡은 은/흑철, 물방울, 미래 갑옷 실루엣, 뻗은 팔, 차가운 반사, 진홍 기계 빛 | 머리와 눈이 서로 다른 기존 목표를 향하는 후보의 대체 표현을 채택 |
| 2 | 오페라 분장실에서 빌린 브로치를 돌려주는 감사의 순간 | 검정 광택 라텍스, 팔꿈치 위 장갑, 검정 초커와 큰 은색 O링, 봉헌 몸짓, 차가운 달빛/따뜻한 촛불 | 열린 고리의 실제 부착·구멍, 작은 입술 틈과 치아 가림 후보를 채택 |
| 3 | 비 오는 해안 정류장에서 젖은 승차권을 건지는 여행자 | 새틴, 원단 밀착, 물방울, 젖은 머리, 피부 하이라이트, 창 결로, 피부 질감 | 머리의 버스 방향과 눈의 승차권 방향을 분리하는 후보 대체 표현을 채택 |

각 arm은 최종 prompt와 runtime input을 audit하고 같은 원본 portrait를 실제 reference 입력으로 전달했다. 한 번의 native 호출 결과와 독립 ledger/manifest, 사전 선언한 testcase 및 최종 픽셀 판정을 보존한다. 이미 기본 프롬프트에 있었던 키워드는 데이터의 인과적 기여로 계산하지 않는다. 세 독립 시도는 적용·실현 가능성을 보는 작은 테스트이며 이전 데이터와 통제된 A/B 비교나 일반 성공률 측정이 아니다. 사용자 선호 판정은 직접 답변을 받기 전까지 미수집 상태다.

총 3회 호출에서 이미지 2장이 반환되고 1회는 출력 심사에서 차단되었다. 발전소는 부분 충족이며 정류장은 시선·결로·접촉 관계가 실패했다. 최종 이미지·프롬프트·픽셀 판정과 실패 경계는 [RESULTS.md](RESULTS.md)와 [TEST-RESULTS.json](TEST-RESULTS.json)에 기록했다.
