Six legacy ideas now have opt-in visible relations

The June preset branch contained useful interaction ideas inside fixed role and scene recipes. These six relations preserve the observable part without selecting a role, age, prop, emotion, supernatural cause or scene for the requester.

| Relation | Visible evidence | Claim boundary |
|---|---|---|
| Hand-cast shielding shadow | Existing lamp, intervening hand and localized shadow on the recipient's eyes | Does not establish goodness or supernatural protection |
| Cover handoff | Giver and recipient contacts joined by the same continuous fabric | Does not infer vulnerability, care status or a relationship label |
| Observer attention | One observer's gaze and body orientation toward the same visible event | Does not infer awe, empathy or agreement |
| Received-item material trace | Supported reachable item and a separately open declared carrier | Does not prove a prior rescue, crisis, miracle or giver identity |
| Shared document reference | Supported document, pointing fingertip and another participant's gaze at the same marked area | Does not prove testimony, truth, profession or agreement |
| Supported precision contact | Supported component, declared hand-held tool and connected working tip | Does not prove successful repair or calibration |

Each relation has one candidate, one authored visual profile and one optional bundle. All three component groups are required for descriptive discovery; approximate hits remain optional. Precise maintained labels have paired negation and exclusion coverage. Selection cannot override owner/property locks. Partial, occluded, disconnected or invented evidence cannot pass the declared native review gates.
