# 스포츠물 시각 의미·후보 데이터 보강 리서치

작성일: 2026-10-25, Asia/Seoul. 범위는 참조 대화의 스포츠물 용어를 시각 의미와 후보 데이터로 반영하기 위한 조사·설계다. 이번 산출물은 **리서치 및 후보 초안**이며 실행 코드, 운영 코퍼스, 인덱스에는 등록하지 않았다.

## 1. 결론과 산출물

스포츠물의 우선 보강 대상은 ‘열혈’, ‘운동선수’, ‘승부’의 동의어가 아니라 **종목, 선택한 동작 단계, 신체와 장비의 연결, 선수 간 역할, 지지면, 착용층, 관찰 가능성**이다. 같은 단어의 종목별 의미를 먼저 구분하고, 한 장에 보일 수 있는 구체적인 실현을 선택형 후보로 제공하는 편이 적절하다.

반면 언더독·재기·에이스·입스·반칙·KO·도핑·연애·동의·승부조작 같은 말은 장면의 해석과 서사를 결정하지만, 특정 자세나 소품 하나가 사실을 입증하지 않는다. 이 개념들도 조사 범위에 유지하면서, 정의와 혼동 방지 정보는 해석용으로, 현재 보이는 형태는 별도 후보로 다룬다.

| 산출물 | 수량과 의미 |
|---|---|
| 원문 복구 | 16개 절, 22개 표, 330개 데이터 행 |
| 종목별 기술 분해 | 복합 종목 설명 24행에서 콜론으로 구분된 70개 기술 항목을 보존. 유일 개념 수와는 다름 |
| 시각 의미 카드 | 102개. 카드마다 3개 관찰 요소, 소유자·관계, 선택 단계, 혼동 경계, 가시성 조건 |
| 후보·바인딩 초안 | 102개 후보 초안, 204개 선택형 슬롯 바인딩 초안. 운영 스키마 합격이나 등록을 의미하지 않음 |
| 출처 레코드 | 39개. 사용자 대화 1개와 외부 자료 38개. 직접 본문·검색 발췌·목록만 확인·접근 실패·과거 판본을 구별 |
| 기존 데이터 조사 | 최초 스포츠 어휘 검색 184개/21개 모듈. 추가 형태·의상 검색에서 209개 고유 후보를 검토 대상으로 확보 |
| 회귀 설계 | 의미·문맥·소유·가시성의 64개 사례. 실행 결과가 아닌 기대 동작 명세 |
| 후속 픽셀 평가 설계 | 위험이 다른 12개 독립 장면. 이미지 생성과 픽셀 평가는 미실행 |

숫자는 완성도의 점수가 아니다. 102개 카드 중 일부는 출처가 용어·구분만 뒷받침하고 자세·연출은 작성한 제안이며, 일부는 전문적인 형태 근거를 더 확보해야 한다. 각 카드의 `verification_scope`와 출처의 `supports`를 함께 확인해야 한다.

## 2. 원문을 어디까지 확인했는가

[참조 대화: 스포츠물 용어 정리](https://chatgpt.com/c/6adc0773-1cb0-83ee-b4b5-18e4481cde33)는 조회 도구에서 답변이 20,000자로 잘렸고 `truncated=true`였다. 로그인된 Chrome에서 사용자 메시지와 답변 끝부분까지 확인하고, 화면 DOM의 본문·제목·표를 저장했다. 표는 22개이며 헤더를 제외하면 330행이다. 마지막 표의 12개 창작 조합과 끝맺는 설명까지 포함한다.

원문 데이터는 [conversation.browser.txt](conversation.browser.txt), [conversation-tables.json](conversation-tables.json), [conversation.accessibility.txt](conversation.accessibility.txt)에 있다. 원문은 사실의 독립 검증 자료가 아니다. 원문에 달린 링크는 [conversation-reference-urls.json](conversation-reference-urls.json)에 별도로 보존했다.

분류 결과는 다음과 같다. 모든 행은 원래 설명을 보존하며 반영 경로를 갖는다.

| 반영 경로 | 행 | 처리 |
|---|---:|---|
| 문맥·정의 중심 | 150 | 시각 의무를 자동 생성하지 않음 |
| 문맥과 선택형 실현 | 20 | 원래 개념과 제안된 보이는 장면이 같다고 주장하지 않음 |
| 시각 카드 연결 | 79 | 종목·단계·소유·가시성을 만족하는 실현을 검토 |
| 표적 후속 조사 | 69 | 누락하지 않고 근거·구조·기존 후보 검토 과제를 지정 |
| 복합 창작 예시 | 12 | 여러 시간대·관계·의상을 한 프레임에 자동 묶지 않음 |

전체 경로는 [KEYWORD-COVERAGE.md](KEYWORD-COVERAGE.md), 기술 분해는 [technique-atoms.json](technique-atoms.json)에 있다. ‘축구’ 한 행에는 인스텝·바이시클·세이브가 함께 들어 있으므로, 330행을 330개 원자 개념이라고 부르지 않는다.

## 3. 출처를 통해 확정하거나 좁힌 핵심 경계

### 배구: 기술 형태, 수행 역할, 복장 표식을 분리

포어암 패스는 팔뚝 면의 기술 형태다. 서브를 받는 리시브와 공격을 수비하는 디그는 선행 플레이가 달라지는 상황·역할이다. 팔뚝 접촉 한 장면을 세 단어의 완전한 동의어로 저장하면, 들어온 공의 문맥을 잃는다. 카드 V01은 보이는 팔뚝 플랫폼을 제안하되 리시브·디그 결과를 자동 확정하지 않는다.

리베로의 대비색은 개인 저지의 색 태그가 아니라 **같은 팀 선수들의 저지와 비교하는 관계**다. 특정 색을 고정하거나 배번을 생략하지 않는다. 리베로와 주장은 배타적인 역할로 가정해서도 안 된다. [FIVB 2025–2028 규정의 19.2 및 팀 리더 항목](https://www.fivb.com/wp-content/uploads/2025/01/FIVB-Volleyball_Rules2025_2028-EN-v05.pdf)을 확인했다.

카드 V01–V05는 팔뚝·손끝·타격 손·블록 손의 서로 다른 접점과 네트 경계를 나눈다. 규정 자료는 역할·복장 경계를 뒷받침하며, 각 접점의 촬영 실현 전체가 규정 문구라는 의미는 아니다.

### 농구: 선택 직전, 스크린, 롤, 릴리스를 별도 순간으로 작성

트리플 스렛은 공을 잡고 선택 가능한 상태다. 슛·패스·드리블을 한 몸이 동시에 하는 그림이 아니다. 온볼 스크린은 볼 핸들러·스크리너·수비자의 관계가 있어야 한다. 롤 단계 한 장면으로 이전에 스크린이 있었던 전체 과정을 입증할 수는 없다.

점프슛은 공이 손끝을 떠난 순간, 레이업은 골대 근처의 선택한 릴리스, 덩크는 손·공·림의 높이 관계로 구체화했다. 지면에서 뜬 발, 손 소유, 공 하나의 위치를 기록한다. ‘버저비터’의 시간 조건이나 득점 성공은 별도 시간·결과 자료가 필요하다. [FIBA 용어집](https://assets.fiba.basketball/image/upload/documents-corporate-regional-offices-europe-programs-fiba-europe-coaching-certificate-fiba-europe-basketball-terminology.pdf)은 기술과 전술의 정의 근거다. 카드 B01–B06의 특정 구도는 작성한 제안이다.

### 수영: 준비·공중·수중을 한 후보에 혼합하지 않음

출발대 트랙 스타트(S01)는 발·손이 출발대에 닿는다. 공중 입수(S02)는 발이 출발대를 떠나고 손끝이 수면으로 향한다. 수중 스트림라인(S03)은 몸 전체와 정렬된 팔이 수면 아래에 있다. 접영 리커버리(S04)는 양팔이 수면 위로 돌아오는 구간이다. 앞의 세 상태를 한 몸의 동시 의무로 넣으면 모순이다.

[US Masters Swimming의 코칭 자료](https://www.usms.org/fitness-and-training/articles-and-videos/articles/five-key-elements-of-a-good-track-start?Oldid=3258)는 출발 지지와 단계 구분에 활용했다. [World Aquatics 현행 규정 목록](https://www.worldaquatics.com/rules/competition-regulations)에서 2026-02-18 판본 링크는 확인했지만 PDF 본문은 도구 오류로 확보하지 못했다. 따라서 이번 조사로 수영 자세·수영복의 세부 규정 적합성을 인증하지 않는다. 스트림라인·접영 카드는 형태 제안의 추가 근거 검토가 남아 있다.

### 계주: 배턴의 공유 접촉과 인계 완료를 분리

A04는 뒤 주자의 주는 손과 앞 주자의 받는 손이 **하나의 배턴의 서로 다른 부분**에 닿는 인계 중 순간이다. 각 손은 다른 사람의 팔로 이어져야 한다. 인계 완료 후에는 받는 사람의 손에만 배턴이 남는 다른 상태다. ‘앵커’라는 역할이 배턴 형태나 최고 속도를 증명하지 않는다.

[World Athletics 2026 기본 규정](https://worldathletics.org/download/download?filename=acdec6c6-1261-4c7f-96d2-92f712707e99.pdf&urlslug=Competition+and+Technical+Rules+%E2%80%93+2026+Edition)은 인계와 배턴 위치의 경계 근거다. [2026년 개정 목록](https://worldathletics.org/about-iaaf/documents/technical-information)도 확인했으므로, 후속 구현에서 구역 길이·실격 판정을 넣는다면 적용 대회와 최신 개정 본문을 다시 대조해야 한다. 이번 카드는 그 판정을 하지 않는다.

### 펜싱: 자세와 장비의 종별 차이

앙가르드(E01)와 런지(E02)는 준비와 도달 단계가 다르다. 같은 `lunge`라도 배드민턴 D01과 장비·발 역할·표적이 다르다. [British Fencing 용어집](https://www.britishfencing.com/glossary-of-terms/)을 의미 근거로 삼았다.

플뢰레 E03의 몸통 겉층과 사브르 E04의 손목까지 이어지는 소매 범위를 구분했다. 플라스트롱 M04는 보호 재킷 아래 별도 층이며, 닫힌 재킷에서는 내부를 확인할 수 없다. 라메가 반짝인다는 이유만으로 전도성·인증을 판정하지 않는다. [FIE 2026년 8월 Material Rules, m.25–34](https://static.fie.org/uploads/40/204156-book%20material%20August%202026%20ang.pdf)를 대조했다.

### 양궁: 활 유형과 손 접점이 함께 달라짐

리커브 R01은 활 손, 시위를 당기는 손, 팽팽한 시위, 화살의 받침·노크가 연결되어야 한다. 컴파운드 R02는 캠·케이블·릴리스 보조기와 D루프 연결을 별도로 다룬다. 기존 ‘화보용 시위 당기기’나 ‘느슨한 목제 훈련 활’을 경기용 풀드로로 재명명하지 않는다.

보호구 R03도 암가드는 활 쪽 팔뚝, 핑거탭은 당기는 손과 시위, 체스트가드는 의복과 시위 경로라는 소유 관계를 가진다. [World Archery 리커브](https://www.worldarchery.sport/sport/equipment/recurve), [컴파운드 설명](https://www.worldarchery.sport/sport/equipment/compound)을 확인했다. 파라 선수의 보조 장비와 기술 변형에 일반 형태를 강제하지 않는다.

### 체조·피겨·하키: 익숙한 단어의 다른 관절 구조

턱 G01은 엉덩이·무릎이 모두 접힌다. 파이크 G02는 엉덩이는 접히고 무릎은 펴진다. 레이아웃 G03은 길게 펴진 몸이다. [USA Gymnastics의 과거 텀블링 코드](https://members.usagym.org/PDFs/T%26T/Rules/devcop/2021/tu.pdf)는 형태 구분의 근거이며 모든 체조·다이빙 종목의 현행 각도·채점에 일반화하지 않는다.

피겨의 카멜·싯·비엘만은 지지 스케이트와 자유 다리의 위치가 다르다. 비엘만은 업라이트 계열이다. [ISU 현행 규정 페이지](https://www.isu.org/dc/figure-skating-rules/figure-skating-rule/handbooks-single-and-pair-skating)에서 2026-06-12 발효 규정을 열어 본문 p65의 분류를 확인했다. PDF의 검색 메타데이터 제목은 오래된 내용이 남아 있어 본문과 구분했다. 정지 실루엣만으로 회전수·레벨이나 스파이럴 활주와 회전을 확정하지 않는다.

하키 버터플라이 H01은 무릎 지지·바깥으로 벌어진 패드·빙면 위 스틱이다. 수영의 butterfly와 형태가 다르다. [Hockey Canada 코칭 자료](https://cdn.hockeycanada.ca/hockey-canada/Hockey-Programs/Players/Goaltending/Downloads/goaltending-butterfly-e.pdf)를 사용했다.

[UWW 유니폼 규정](https://cdn.uww.org/2026-01/uniform_regulations_jan2025_final.pdf), [Gymnastics NZ 복장 규정](https://www.gymnasticsnz.com/attire/), [USA Swimming의 수영복 실루엣 자료](https://www.usaswimming.org/docs/default-source/rules-regulations/tech-suit-restrictions/speedo-120220.pdf)를 추가 대조했다. 뉴질랜드 국내 규정은 FIG·다른 국가 규정과 구분하고, 2020년 수영복 자료는 형태 구분에만 사용한다.

[윔블던 2023 White Clothing 자료](https://www.wimbledon.com/pdf/4.%20Media%20Fact%20Sheet%20-%20White%20Clothing%20Rule%202023.pdf)는 거의 흰색인 복장과 여성의 어두운 이너 쇼츠 예외를 보여준다. 이를 모든 테니스의 일반 규정이나 현재 모든 대회에 대한 인증으로 바꾸지 않는다. [Met의 1893–98년 미국 체육복](https://www.metmuseum.org/art/collection/search/159463)은 역사적 블루머 형태의 근거이며 일본 후기 짧은 부르마와 시대·지역을 분리한다.

## 5. 체형·흔적·감정·관계의 해석 한계

‘애슬레틱 빌드’는 특정 종목의 단일 체형이 아니다. 어깨·몸통·팔·다리 비율을 사용자가 지정한 범위 안에서 다루고, 근육 윤곽과 실제 힘·지구력·체지방률을 동일시하지 않는다. 긴 리치도 화면 원근이나 포즈와 구분해 비교 조건을 명시해야 한다.

땀처럼 보이는 물방울, 젖은 머리, 어두워진 저지, 흙 얼룩, 초크처럼 보이는 가루는 표면 상태다. 물의 출처·운동량·피로도·질환·가난·경력·금지약물 여부를 증명하지 않는다. L07–L09는 흔적을 피부·원단·장비에 국소적으로 귀속한다. 미세 디테일을 요구한다면 촬영 크기와 가림 상태도 함께 설계한다.

피스트 펌프, 무릎 꿇기, 포효, 포옹, 주저앉기는 서로 다른 감정·결과 문맥에서 나타날 수 있다. 팔·손·무릎의 보이는 자세와 ‘승리’, ‘패배’, ‘두려움’, ‘인정’을 분리한다. 원진 L02, 하이파이브 L03, 작전판 L01 등은 관계의 현재 배열을 보여주는 제안이며 우정·리더십·실제 고용을 입증하지 않는다.

입스·초킹·슬럼프·번아웃은 단일 표정의 별칭이 아니다. 원문의 연구를 다시 확인한 [Clarke 외 논문](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2019.02784/full)은 골퍼·양궁 선수 155명의 자기보고 설문이다. 이 자료로 정지 사진의 진단·인과·전체 종목에 대한 일반화를 하지 않는다. 테이핑·보호대 역시 부상 이력이나 치료 효과의 증거가 아니다.

## 6. 성인·폭력·착취·부패 항목의 반영

원문의 성적·폭력적·조직적 소재를 누락하지 않았다. 다만 각 용어가 요구하는 증거의 종류가 다르다.

| 항목 | 보이는 자료로 작성할 수 있는 부분 | 별도 문맥·시간·판정이 필요한 부분 |
|---|---|---|
| 성인 스포츠 로맨스·BL·GL·시핑 | 명시된 인물 설정 안에서 두 사람의 거리·상호 시선·동작 | 연애·성적 지향·감정·동의·관계 변화 |
| 스포츠 에로티시즘·유니폼 페티시 | 사용자가 지정한 의상·빛·프레이밍·표면 상태 | 의복 자체가 성적 의도를 증명한다는 주장 |
| 팬서비스·메일 게이즈·성적 대상화 | 선택된 구도·부위 강조·편집 형태를 분석 | 촬영자 성별·인물의 실제 의도·단일 자세로 작품 전체 확정 |
| 탈의실·샤워실·의상 사고 | 공간, 의복 경계, 지정된 착용 상태 | 사생활 침해·실제 사고·의도적 연출·동의 |
| 러프·더티·보복·플래그런트 | 어느 몸이 어디에 닿는지, 경기장 경계·심판 개입 | 고의·보복·리그별 반칙 요건·최종 판정 |
| 다운·KO·TKO·닥터 스톱 | 내려간 몸, 심판·코너의 현재 동작 | 카운트·실신·경기 종료·종목별 결과 |
| 서브미션·탭아웃 | 어느 손이 상대 또는 바닥 어디에 닿는지 | 반복 탭·항복 의사·공식 결과 |
| 컷·출혈·타박 흔적 | 위치·표면 흔적·접촉·조명 | 원인·중증도·진단·선수 생명·가해자 |
| 도핑·TUE | 검체 용기·서식·검사실 관계 | 위반 사실·물질 성분·정당한 치료 면책 |
| 헤이징·학대·성희롱·강요 | 명시된 장면의 행위·거리·소유·대상 | 원치 않음·권력관계·의도·동의·조직 은폐 |
| 승부조작·탱킹·스포츠워싱 | 명시된 문서·장소·행위의 표면 | 고의적 조작·대가·평판 세탁·실제 범죄 |
| 케이페이브·워크·슈트·데스매치 | 프로모·링·퍼포머·도구의 배치 | 연출 여부·진정성·히든 합의·실제 사망 조건 |

[IOC Portrayal Guidelines](https://www.olympics.com/ioc/gender-equality/portrayal-guidelines)는 경기 수행과 외모 중심 재현을 구별하는 근거다. [IOC safeguarding 설명](https://www.olympics.com/ioc/news/ioc-publishes-new-consensus-statement-on-safeguarding-and-interpersonal-violence-in-sport)은 권력·조직 관계의 맥락을 보완한다. [WADA 2021 Code](https://www.wada-ama.org/sites/default/files/resources/files/2021_code.pdf)는 도핑·TUE의 정의 범위를 뒷받침한다. 어느 자료도 개별 사진 속 인물의 실제 상태를 판정하지 않는다.

성인 설정은 사용자·출처 문맥에서 확인해야 한다. 스포츠 브라·밀착복·땀·치마·피부 노출로 나이를 추정하지 않는다. 학원 스포츠 맥락을 성인 로맨스·핀업 후보에 자동 연결하지 않는다. 비평적·비시각 용어는 positive 시각 후보의 동의어 목록에 섞지 않는다.

## 7. 촬영·만화·영상은 지원하는 증거가 다름

패닝 X01은 피사체와 배경의 상대적인 선명도·흐름이다. [Canon 기술 설명](https://www.usa.canon.com/learning/training-articles/training-articles-list/how-do-i-get-a-panning-effect)을 참고했으며 특정 셔터속도를 모든 스포츠에 강제하지 않는다. 슬로모션 재생, 몽타주, 교차편집, 매치 컷, 시간 팽창, 소리 소거는 시간·패널·음향 구조가 필요하다.

만화 오라 X02는 일러스트를 명시한 경우의 그래픽 층 제안이다. 실제 동물, 실제 초능력, 사진의 필수 효과로 격상하지 않는다. 몸과 효과의 소유를 분리하며, 잔상으로 손발 수를 늘리지 않는다. POV M08도 목표·전경 도구·카메라 방향의 관계이며 실제 인물의 지각 경험을 입증하지 않는다.

## 8. 기존 코퍼스 조사 결과와 보강 우선순위

조사 시작 HEAD는 `85884333ca146a28bfa0c455fa1d9e64d5ee8099`였다. 작업 중 저장소는 다수의 기존 변경이 있는 상태였다. [existing-corpus-hits.json](existing-corpus-hits.json)의 184개는 태그·설명에 스포츠 어휘가 걸린 결과이므로, 스포츠 의미가 184개나 완전하다는 뜻이 아니다. 예컨대 공사장 fencing과 Streamline Moderne도 어휘 충돌로 검색될 수 있다.

[reuse-inventory.json](reuse-inventory.json)은 추가로 53개 의상·형태·장소 검색군을 조사하여 35개 군에서 고유 후보 209개의 검토 단서를 기록했다. 이 역시 어휘 조사이며 실제 검색기의 노출률·랭킹·선택·렌더 품질은 검증하지 않았다. 후보의 완전한 조건·효과·provenance를 읽은 뒤에만 재사용을 결정해야 한다.

| 결정 | 현재 확인한 사례 | 반영 원칙 |
|---|---|---|
| 그대로 재사용 검토 | 훈련 비브가 반소매 저지 위에 겹치고 소매·밑단이 드러나는 후보 | 기존 전체 proposition과 조건 보존 |
| 보완 실현 추가 | 빕 쇼츠의 상부 스트랩·패드 가시성, 짧은 sprint start 표현 | 가려진 내부까지 보인다고 요구하지 않음; 지지·단계 구체화 |
| 새 문맥으로 분리 | 기존 화보 양궁 자세와 경기 리커브 풀드로 | 기존 editorial 의미를 경기용으로 덮어쓰지 않음 |
| 진단 정보와 시각 실현 병존 | 보호대·테이핑이 부상 증거가 아니라는 기존 기록 | 진단용 기록을 양성 시각 후보로 승격하지 않음 |
| 일반 후보 재사용 후 전문 보강 | 저지·재킷·머리·피부·코트·메달 등 | 스포츠라는 이유로 동일 구조 중복 생성 금지 |

## 9. 이번 조사에서 확인한 한계

- 330행을 복구·분류했지만 모든 정의와 모든 전문 기술을 독립적으로 완전 검증한 것은 아니다. 특히 70개 기술 분해 중 대응 카드가 없는 항목은 별도로 남겨 두었다.

- ITTF Foundation 그립 교재는 검색 발췌가 확인되었으나 직접 열기는 404였다. 탁구 손가락 세부 정본 검토는 보류했다.
- ABC Regulatory Guidelines는 본문에 2005년 수정일이 표시되어 있다. 현재 모든 복싱·MMA 종료 규칙의 보편 근거로 쓰지 않는다. 프로레슬링 전문 사전 페이지도 확보하지 못해 해당 전문 정의는 확정 등록을 보류한다.
