P01은 우상과 부조를 대안으로 비교하는 판본 사례다. 하나의 요청에 두 대상을 모두 그리라는 뜻이 아니다. 동일 requester 대상이 유지되는 비교끼리만 A/B/C 차이를 계산하며, 우상 결과와 부조 결과를 동일 정답 이미지로 비교하지 않는다.
