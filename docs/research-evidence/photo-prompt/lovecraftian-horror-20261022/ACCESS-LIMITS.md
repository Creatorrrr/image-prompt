# 접근·근거·미해결 범위

## 참조 대화

`read_thread(turnLimit=10)`로 하나의 전체 대화 turn이 있다는 사실을 확인했으나 응답이 20,000자에서 잘렸다. 브라우저로 같은 conversation ID를 열고 렌더링된 본문·19개 표를 DOM에서 읽었다. [conversation-dom.json](conversation-dom.json)은 이 관찰의 text/tables를 보존한다. 이 파일의 `links`가 빈 배열이므로 원래 인용 링크 전체를 보존했다고 주장하지 않는다. 출처는 본문·사이트를 별도로 조사했다. 원 대화의 주장은 검증 전 연구 seed다.

185개 용어 행에 모두 route가 있지만 모든 단어·번역·이론·작품 설명을 독립적으로 원전 검증한 것은 아니다. 16개 용어 표와 3개 보조 표의 구분을 유지했다. 대화 밖의 원전·비평 자료로 보강한 카드에는 해당 source refs가 있다.

## 출처

45개 출처 가운데 S31 지정 Macmillan 페이지는 현재 책을 이용할 수 없다는 안내만 반환했다. 소설 내용의 근거로 사용하지 않았다. S32는 출판사 소개와 목차만 읽었으며 비평서 전문이나 각 장의 결론을 읽은 것이 아니다. S26은 편지를 소개한 아카이브 편집 설명을 확인했지만 원본 표식 도판을 확대·계측하지 않았다. 직접 요청과 웹 도구가 서로 다른 성공/403을 보인 출처는 `sources.json`에 수단별로 남겼다.

원전은 해당 묘사·이야기 장치의 근거다. 사진의 구도·가시 소유자·분기 표식·비교 실현·render gate는 저술한 제안이다. 작품에서 단어가 나온다는 사실이 후보 장면 전체의 정본 디자인을 보장하지 않는다. 판본 고정이 중요한 부분만 별도의 versioned 범위로 명명했다.

## 실행 증거

이번 작업은 연구 폴더 내부 파일만 작성했다. 코퍼스 접근은 읽기 전용이었다. 같은 checkout에서 다른 작업의 변경이 있었으므로 시작과 종료 source hash의 차이는 [SOURCE-DRIFT.json](SOURCE-DRIFT.json)에 기록한다. drift가 있어도 이 작업이 타 파일을 수정했다는 뜻이나 source 오류라는 뜻은 아니다. 다음 구현에서는 다시 기준을 잡아야 한다.

구조 검증·보존 해시·소스 직접 비교는 수행했지만 실제 retrieval/native execution/임베딩/API 이미지/픽셀/사용자 acceptance는 미실행이다. 구조 검사는 자연어 진실성·번역 완전성·원전 정본 도판·예술적 성공을 판정하지 않는다.

## 권리와 자료 사용

외부 출처는 정의·모티프·판본 경계의 근거로 사용했다. 사이트 삽화·책 표지·게임 도안의 사용 허가를 취득한 것은 아니며 해당 이미지를 다운로드하거나 reference pack으로 배포하지 않았다. 실제 이미지/도판을 후보 reference로 채택할 때에는 그 자산의 권리·조건을 별도 확인해야 한다. 이번 데이터의 구체 장면 문장은 프로젝트 저술 제안이다.
