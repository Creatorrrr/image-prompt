# 기존 데이터 대조와 반영 판단

자료는 현재 작업 소스에 대한 snapshot이다. manifest가 참조하는 전체 candidate/binding 모듈을 읽었고 exact-source·keyword 어휘 진단·원전 대조를 구분했다. 실제 검색이나 native qualification은 실행하지 않았다.

## 재사용 7개

R01 규모, R17 수중 매질, R18 블록 축조, R19 계단 전체 고리, R27 미고 부위 구조, R31 시연 장면, R33 균사체는 기존 의미·관계와 가깝다. 해당 CID의 전체 조건·효과·한영 문장·출처를 먼저 검토하고 중복 신규 CID를 만들지 않는다. `reuse`는 현 source가 이미 승인됐다는 뜻이 아니다.

## 정교화 28개

현재 정의가 핵심 관계를 포함해도 한국어가 제목·주의문 중심인 사례가 있다. C119/C120/C126/C169는 양 언어에서 같은 부위·재료·수량·접점이 보존되는지 검토해야 한다. C173/C174는 경계 또는 비교 관계의 양 끝을 완전히 서술해야 한다.

R09의 날짜 비교와 기존 C174의 도식 비교는 동일한 후보 문장이 아니다. 이 차이를 숨기지 않고 `refine`으로 분류했다. 재사용/정교화 판단은 최종 채택 때 exact source 기준으로 다시 확정한다.

R39의 케이블 2개와 장치 2개는 한 덩어리 `cords`/`devices` 관계 대신 각 연결의 소유를 보존한다. R40은 원전 금속 원통과 별개인 투명 뇌 용기 변형이다. R34는 비늘·주름·인쇄를 분리하고, R30은 무안면·가면·암부를 구분한다. R50은 원전 장신구의 외투 고정을 보존하는 방향으로 기존의 넓은 장신구 후보와 비교한다.

## 신규 제안 22개

신규는 이번 범위에서 exact equivalent를 직접 매핑하지 않았다는 연구 판단이다. 전체 코퍼스에 유사 장면이 없다는 결론은 아니다. 실제 채택 전 공통 검색 풀에서 다시 중복을 검토한다.

R06·R08·R10·R11의 매체 대응, R15·R16·R20·R21의 공간 접점, R23의 얕은 부조, R25의 국소 분기, R32의 분말 윤곽, R38의 돌봄, R41의 표본/도식 분리, R43의 유물 취급, R45의 체액 소유, R47의 서지 관계, R48·R49·R51의 물건 구조, R53의 발화 자세, R57의 휴면 같은 배치를 제안한다. R13의 아름다운 꿈 도시는 장르의 암흑 기본값을 피할 대안이다.

## 문맥 21개·보류 6개

장르·철학·신뢰할 수 없는 화자·심층 시간·의식·친족·동의·진단·냄새·소리는 형태 의무로 직접 변환하지 않는다. 보류는 정확한 원전·이론·판본 자료가 더 필요한 영역이며 [ACCESS-LIMITS.md](ACCESS-LIMITS.md)에 명시했다.

## 증거 파일을 읽는 방법

- [existing-source-mapping.json](existing-source-mapping.json): 80개 기존 의미 카드와 79개 직접 매핑 후보 snapshot. 모든 선택된 record·binding·해시를 보존했다. C028은 이번 card_id 직접 연결에서 CID를 찾지 못했다.
- [CORPUS-LEXICAL-AUDIT.json](CORPUS-LEXICAL-AUDIT.json): 지정 primary field의 casefold substring 진단. 후보별 점수·semantic fit·실제 검색 성능을 계산하지 않았다. alias 부재/문장 변형 때문에 0건이어도 의미 부재라고 할 수 없다.
- [BASELINE.json](BASELINE.json), [SOURCE-DRIFT.json](SOURCE-DRIFT.json): 시작 보호 파일과 후속 변경 관찰. 같은 checkout의 다른 작업을 되돌리지 않았으며 구현 전에는 새 기준을 잡아야 한다.

기존 레지스트리 180개 및 관계 변형 24개, 이번 의미 카드 84개, 후보 초안 57개를 합쳐 확대된 운영 데이터 수라고 보고해서는 안 된다. 조사·등록·qualification·검색·이미지·사용자 판단은 별개다.
