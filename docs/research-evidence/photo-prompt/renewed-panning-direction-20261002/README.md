# 패닝 프로필의 수평 전용 제약 교정

기준 커밋: `56fa035716021c9129e310141a8facb4c2162126`.

## 문제와 수정

방향을 한정하지 않은 패닝 프로필이 수직으로 내려오는 성인 다이버 요청에도 측면 추적과 수평 이동 벡터를 요구했다. [Nikon 패닝 가이드](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/10-tips-for-better-camera-panning)는 수평 이동뿐 아니라 다이빙대에서 내려오는 다이버의 수직 추적도 설명한다.

프로필 1개의 정의·구성 지침·의미 단서에서 측면 이동을 강제하던 부분을 제거했다. 방향 중립적인 영어/한국어 성분과 영어 증거 표현을 우선 배치하고, 기존 측면 이동 표현은 대안으로 그대로 남겼다. 일반 패닝 슬롯 2개·기존 의역·exact 별칭·제외어·필수 성분·증거 길이·5개 렌더 게이트·검색 코드는 유지했다. 일반적인 “panning”이나 “vertical panning”을 새 필수 활성화 별칭으로 추가하지 않았다.

## 실제 공개 CLI 전후 결과

영어 수직 다이버, 한국어 수직 다이버, 영어 측면 자전거 3개 사례를 정상 공개 CLI로 전후 실행했다. 4개 입력 계약의 바이트와 코어·컨트롤·신체 동작 검토는 그대로 유지했다. 전후 총 6회 모두 종료 코드 0이다.

두 수직 사례에서는 측면 추적을 강제하는 문장이 사라지고 방향 중립 증거가 먼저 나온다. 측면 자전거 사례는 기존 표현을 계속 쓸 수 있다. 다섯 필수 게이트와 제외 경계는 같다.

각 팩의 변경 경로는 정확히 6개다. 팩 ID, 해당 패닝 프로필의 의미 설명과 네 관련 계약 필드만 달라졌다. 슬롯·선택 시각 개념·의미 설명 후보·묶음·창의적 보강의 후보 ID·순서·개수에는 변화가 없었다. 늘어난 배열은 방향 성분 대안(2→4), 증거 대안(1→2)뿐이다. 이 세 사례에서 관측한 결과이며 전체 입력 공간의 동등성을 주장하지 않는다.

## 추가 검증과 한계

관련 테스트 28개(새 회귀 3개 포함), 기존 수평/새 방향 중립의 이중 언어 성분, 제외어·누락 성분·넓은 부정 대조, 전체 사전과 실제 인덱스 검증이 통과했다. 수정 벡터 1개 외 1,418개는 보존했다.

사례는 데이터를 알고 작성한 진단이며 독립 블라인드 평가가 아니다. 이미지 생성이나 픽셀 품질 측정은 하지 않았다. 실제 원근·회전 카메라의 곡선 광학 흐름 전체를 재설계한 것도 아니다. 기존의 방향성 배경 흐림·상대적으로 읽히는 피사체·보조 움직임이라는 좁은 패닝 의미를 유지하면서 강제 수평 방향만 제거했다.
