# Sensual 관련 용어·외형·연출 용어집

조사 기준일: 2026-11-07

## 읽는 방법

Sensual은 몸의 감각에서 오는 즐거움과 관능을 뜻한다. 성적 매력을 포함할 수 있지만 노출량이나 성행위의 유무만으로 정해지는 말은 아니다. 촉감이 떠오르는 재질, 빛, 목소리, 몸의 긴장과 이완, 시선과 거리도 관련 요소다. [S1]

이 용어집은 성인 대상의 패션·사진·미술·공연·성문화 맥락을 다룬다. 전문 용어, 일상적인 형용사, 촬영 지시용 묘사구를 함께 정리했다. 묘사구 전체가 국제적으로 통일된 포즈 이름이라는 뜻은 아니다. 분위기에 관한 설명은 흔히 쓰이는 해석이며, 표정·자세·의복만으로 실제 감정, 성적 취향 또는 동의를 판단할 수 없다.

## 1. 핵심 의미와 가까운 표현

| 용어 | 뜻과 구분 |
|---|---|
| Sensual · 감각적·관능적 | 신체 감각의 즐거움에 호소하는 성질. 음식·향·음악에도 쓰지만 인물 묘사에서는 성적인 함축이 생기기 쉽다. |
| Sensuous · 오감에 호소하는 | 촉감·색·소리 등 감각적 풍부함에 초점. sensual보다 미적 경험에 잘 쓰이지만 성적인 뜻이 완전히 배제되지는 않는다. |
| Sexual · 성적인 | 성, 성욕, 성행위와 관련됨을 나타내는 넓고 비교적 중립적인 말. 반드시 매력적이라는 뜻은 아니다. |
| Sexy · 성적 매력이 있는 | 성적 끌림을 준다는 일상적 표현. sensual보다 매력의 효과를 직접적으로 말한다. |
| Erotic · 에로틱한 | 성적 욕망·흥분을 드러내거나 불러일으키는 성질. 예술·문학·사진의 내용에도 쓰인다. |
| Sensory · 감각에 관한 | 시각·청각·촉각 등 감각 작용에 관한 중립적인 말. 즐거움이나 성적 매력은 자동으로 포함하지 않는다. |
| Sensuality · 관능성 | 감각적 쾌락에 대한 감수성이나 그러한 매력이 드러나는 성질. |
| Eroticism · 에로티시즘 | 성적 욕망을 암시·상징·서사·이미지로 표현하는 특성이나 미학. |
| Seductive · 유혹적인 | 상대를 끌어당기는 성질. 인물에서는 성적인 유혹을 뜻하기 쉽지만 제안·아이디어에도 쓴다. |
| Alluring · 매혹적인 | 아름다움이나 신비로움 때문에 마음이 끌리는 상태. 성적인 뜻은 필수가 아니다. |
| Enticing · 마음을 끄는 | 가까이 가거나 경험하고 싶은 욕구를 만드는 성질. 음식·향·옷에도 자연스럽다. |
| Sultry · 농밀하고 관능적인 | 사람·시선·목소리에 쓰이면 짙은 성적 매력을 암시한다. 날씨를 말할 때는 무덥고 후텁지근하다는 뜻이다. |
| Smoldering · 이글거리는 듯한 | 겉으로 크게 드러내지 않지만 강도가 느껴지는 시선·분위기. 욕망 외에 분노를 묘사하기도 한다. |
| Voluptuous · 풍만하고 관능적인 | 몸의 풍성한 곡선 또는 호화로운 감각적 즐거움을 가리킨다. 모든 관능적인 인물의 체형을 뜻하지 않는다. |
| Curvaceous · 굴곡이 뚜렷한 | 신체 곡선을 설명하는 말. 욕망이나 성적 행동에 관한 판단은 포함하지 않는다. |
| Intimate · 친밀한·사적인 | 가까운 관계와 개인적인 공간·거리의 느낌. 비성적인 친밀감에도 사용한다. |
| Romantic · 낭만적·연애적인 | 애정·이상화·정서적인 유대를 강조한다. 관능성과 겹칠 수 있으나 같은 뜻은 아니다. |
| Flirtatious · 추파를 보내는 듯한 | 호감을 장난스럽게 드러내는 말투·시선·행동의 분위기. |
| Coquettish · 교태 있는 | 짐짓 수줍거나 장난스러운 매력. 오래된 용례에서는 여성에게 주로 사용됐다. |
| Provocative · 도발적인 | 관심·욕망·논쟁 등 강한 반응을 유발하는 성질. 문맥에 따라 성적 의미가 아닐 수도 있다. |
| Risqué · 아슬아슬하게 외설적인 | 성적인 농담이나 표현이 점잖은 기준에서 다소 대담하다고 평가하는 말. |
| Suggestive · 암시적인 | 직접 보여 주기보다 어떤 의미를 떠올리게 하는 표현. 성적 암시라는 뜻으로 자주 쓰인다. |
| Lewd · 음란한 | 성적 표현이 노골적이거나 외설적이라고 평가하는 말. sensual보다 부정적인 판단이 강하다. |
| Raunchy · 노골적이고 거친 | 성적 농담·공연 등이 상스럽고 대담한 성격임을 나타낸다. 세련된 관능과는 어감이 다르다. |
| Luscious · 감미롭고 풍부한 | 맛·향의 풍부함을 나타내며, 문학적으로 색·질감·외모의 매력에도 쓰인다. |
| Carnal · 육체적 욕망의 | 정신적·정서적 측면보다 육체의 욕망을 강조하는 문학적 표현. |
| Lascivious · 음욕을 드러내는 | 욕망이 노골적으로 드러난다고 평가하는 말. 인물에게 쓰면 비난이나 불쾌함의 뉘앙스가 강할 수 있다. |

관련 의미의 구분: Cambridge Dictionary와 American Heritage Dictionary. [S1–S4]

## 2. 분위기·미학·장르

| 용어 | 뜻과 외형적 연결 |
|---|---|
| Languid · 나른한 | 움직임이 느리고 힘이 빠진 듯한 분위기. 이완된 손과 어깨 등으로 표현하지만 성적 흥분을 뜻하지는 않는다. |
| Ethereal · 가볍고 비현실적인 | 무게감이 적고 현실에서 벗어난 듯한 인상. 반투명 재질과 흐린 윤곽의 묘사에 쓸 수 있다. |
| Dreamy · 몽환적인 | 현실에서 살짝 떨어진 듯한 분위기. 흐릿한 배경·부드러운 초점과 연결하기 쉽다. |
| Sinuous · 물결처럼 굽이치는 | 몸·옷·선이 매끄러운 곡선으로 이어지는 성질. |
| Tactile · 촉각적인 | 보고도 표면의 감촉이 떠오르는 특성. 천의 결·주름·피부 질감과 관련된다. |
| Luxurious · 호화롭고 안락한 | 재료와 공간이 풍요로운 감각적 만족을 주는 분위기. |
| Opulent · 화려하고 풍성한 | 장식·색·재료를 넉넉하게 사용하는 호사스러운 양식. |
| Decadent · 퇴폐적인 | 과도한 향락·권태·사치가 연상되는 미학. 단순히 어두운 색을 뜻하지 않는다. |
| Understated sensuality · 절제된 관능 | 자극적인 요소를 적게 쓰고 선·질감·여백으로 감각성을 표현하는 묘사구. |
| Boudoir · 부두아르 | 사적인 방이나 드레싱 공간의 친밀감을 활용하는 사진 장르. 란제리가 흔하지만 필수 조건은 아니다. |
| Glamour · 글래머 | 인물의 매력·화려함·스타성을 강조하는 미학. 영어에서는 특정 가슴 크기나 체형을 뜻하지 않는다. |
| Old Hollywood glamour · 고전 할리우드 글래머 | 정교한 웨이브, 긴 드레스, 선명한 조명 등으로 표현하는 고전 영화 스타의 화려함. |

| Burlesque · 벌레스크 | 풍자·과장·희극적 공연의 전통. 현대의 일부 형태는 탈의와 관능적 무대 연출을 결합한다. |
| Cabaret · 카바레 | 노래·춤·코미디 등이 결합된 소규모 공연과 공연 공간. 성적인 공연만을 뜻하지 않는다. |
| Femme fatale · 팜 파탈 | 매력과 위험성을 함께 부여받은 여성 인물의 서사적 유형. 실제 여성의 성격 분류가 아니다. |

| Noir · 누아르 | 그림자·불안·도덕적 모호함을 강조하는 영화 및 시각 양식. sensual과 조합할 수 있지만 동의어는 아니다. |

## 3. 표정·시선

아래에서 bedroom eyes는 관용구이고, 상당수 항목은 얼굴의 상태를 설명하는 촬영 지시용 묘사구다. 같은 모양이 피로·슬픔·집중으로 읽힐 수도 있다. [S7]

| 용어 | 눈에 보이는 형태와 의미 |
|---|---|
| Direct gaze · 정면 응시 | 카메라나 상대를 똑바로 보는 시선. 주체성·친밀감·대결감 등으로 해석될 수 있다. |
| Averted gaze · 비껴간 시선 | 카메라 밖으로 시선을 돌린 상태. 사적인 순간이나 거리감을 표현할 때 쓴다. |
| Sideways glance · 곁눈질 | 얼굴의 방향과 다른 쪽으로 눈을 움직이는 표정. 호기심·경계·장난 등으로 해석 가능하다. |
| Over-the-shoulder glance · 어깨너머 시선 | 몸을 돌린 채 뒤로 얼굴을 향하는 구성. 목·어깨·등의 방향 차이가 생긴다. |
| Downcast eyes · 아래로 내린 눈 | 시선을 아래로 떨어뜨린 상태. 차분함·수줍음·사색 등을 표현한다. |
| Upward gaze · 올려다보는 시선 | 눈이 위쪽의 대상이나 카메라를 향하는 상태. 시선의 의미는 장면에 따라 달라진다. |
| Half-lidded eyes · 반쯤 뜬 눈 | 눈꺼풀이 내려와 눈의 일부를 덮는 상태. 나른함·피로·관능을 표현할 때 쓰인다. |
| Bedroom eyes · 관능적 눈빛 | 성적 관심을 암시한다고 여겨지는 눈빛을 뜻하는 관용구. 특정 눈 모양의 공식 명칭은 아니다. |
| Come-hither look · 유혹하는 듯한 시선 | 상대를 가까이 오게 하는 듯하다고 해석되는 표정. 직역하면 ‘이리 오라’는 느낌이다. |
| Soft gaze · 부드러운 시선 | 눈 주변의 긴장이 적고 응시가 날카롭지 않은 상태를 가리키는 묘사구. |
| Smoldering gaze · 강도를 억누른 시선 | 크게 표정을 움직이지 않으면서 짙은 감정이 느껴지도록 묘사하는 표현. |
| Closed eyes · 감은 눈 | 외부 대상과의 시선 연결을 끊은 모습. 휴식·몰입·감각의 집중 등 여러 의미가 가능하다. |
| Parted lips · 살짝 벌어진 입술 | 입술 사이에 틈이 있는 상태. 놀람·호흡·이완의 표현에도 해당한다. |
| Pursed lips · 오므린 입술 | 입술을 모아 앞으로 내밀거나 조인 모양. 입맞춤 외에 불만·생각의 표정일 수도 있다. |
| Pout · 뾰로통한 입 모양 | 입술을 내미는 표정. 장난·삐침·의도적인 매력 연출에 쓰인다. |
| Lip bite · 입술을 무는 표정 | 입술 일부를 가볍게 무는 모습. 긴장·머뭇거림·연기된 유혹 등 맥락이 다양하다. |
| Subtle smile · 옅은 미소 | 입꼬리의 움직임이 작고 치아 노출이 적은 웃음. |
| Smirk · 한쪽 입꼬리 미소 | 비대칭적인 미소. 자신감·장난·비꼼 등으로 해석될 수 있다. |
| Coy expression · 짐짓 수줍은 표정 | 시선을 피하거나 미소를 억제하는 등 속내를 다 보여 주지 않는 느낌의 표현. |
| Rapt / ecstatic expression · 몰입·도취된 표정 | 강한 감정이나 감각에 몰입한 표정. 음악·종교·공연에서도 쓰이며 성적인 뜻만 있는 것은 아니다. |

## 4. 포즈·손동작·움직임

Contrapposto는 미술사 용어다. 나머지 상당수는 몸의 배치·움직임을 직접 기술한 표현이며, 그 자체에 특정 성적 의미가 고정되어 있지 않다. [S8]

| 용어 | 형태와 구성상 특징 |
|---|---|
| Contrapposto · 콘트라포스토 | 한쪽 다리에 체중을 두어 골반과 어깨의 균형이 비대칭으로 잡히는 자세. |
| S-curve pose · S자 자세 | 머리·몸통·골반의 선이 연속된 S자처럼 보이도록 배치한 자세. |
| Weight shift / hip shift · 체중·골반 이동 | 한쪽으로 무게중심을 옮겨 정적인 정면 자세에 비대칭을 만드는 동작. |
| Three-quarter turn · 사선으로 돌린 몸 | 정면과 옆면 사이로 몸을 틀어 앞면과 옆면이 함께 보이게 한 자세. |
| Profile pose · 옆모습 자세 | 몸이나 얼굴을 측면으로 보여 실루엣을 강조하는 자세. |
| Torso twist · 몸통 비틀기 | 골반과 어깨의 방향에 차이를 주는 자세. 옷의 주름과 대각선이 생긴다. |
| Over-the-shoulder pose · 뒤돌아보기 | 등이나 옆면을 보여 주면서 머리를 뒤로 돌리는 자세. |
| Wall lean · 벽에 기대기 | 벽·기둥 등에 몸의 일부를 기대는 자세. 접촉점과 이완된 부분의 대비가 생긴다. |
| Forward lean · 앞으로 기울이기 | 몸통을 카메라나 상대 쪽으로 약간 기울이는 자세. 거리감이 가까워진다. |
| Back arch · 등·허리의 곡선 | 등을 펴거나 굽힘을 조절해 몸통의 곡선을 드러내는 표현. 과도한 젖힘을 뜻할 필요는 없다. |
| Reclining pose · 기대어 눕기 | 등받이·소파 등에 몸을 비스듬히 기댄 자세. 대각선 구도가 만들어진다. |
| Side-lying pose · 옆으로 눕기 | 옆구리 쪽을 바닥에 두는 자세. 몸·다리의 겹침을 표현하기 좋다. |
| Supine pose · 바로 눕기 | 등을 바닥에 대고 얼굴이 위를 향한 자세. |
| Prone pose · 엎드리기 | 몸의 앞면이 바닥을 향하는 자세. 상체를 지지하는 팔의 위치에 따라 형태가 달라진다. |
| Seated edge pose · 가장자리에 앉기 | 의자·벤치 가장자리에 앉아 몸과 다리의 선을 분리하는 자세. |
| Crossed legs · 다리 교차 | 한쪽 다리를 다른 다리 위로 포개거나 앞에서 교차하는 자세. |
| Crossed ankles · 발목 교차 | 무릎보다 아래에서 양쪽 발목을 교차한 배치. |
| Bent-knee pose · 무릎을 굽힌 자세 | 한쪽 또는 양쪽 무릎을 굽혀 직선적인 다리 배치에 변화를 주는 표현. |
| Kneeling · 무릎을 댄 자세 | 한쪽 또는 양쪽 무릎이 바닥에 닿은 자세. 기도·휴식·공연·복종 연출 등에 두루 쓰인다. |
| Chair straddle · 의자 걸터앉기 | 의자 좌판을 양다리 사이에 두고 앉는 자세. 의상의 형태와 카메라 각도에 따라 인상이 달라진다. |
| Arms overhead · 머리 위로 든 팔 | 양팔 또는 한쪽 팔을 위로 올린 배치. 몸의 세로선과 소매의 흐름이 강조된다. |
| Hand in hair · 머리에 둔 손 | 머리카락을 쓸어 올리거나 정리하는 순간을 표현하는 동작. |
| Hand at neck / collarbone · 목·쇄골 부근의 손 | 손으로 얼굴과 상체 사이에 시선이 머무를 지점을 만드는 배치. |
| Hand on waist / hip · 허리·골반 옆의 손 | 몸통과 팔 사이에 공간을 만들고 허리선을 구분하는 자세. |

| Self-embrace · 스스로 감싸 안기 | 팔로 자신의 몸이나 어깨를 감싸는 자세. 온기·보호·고독 등으로 해석된다. |
| Garment-adjusting gesture · 옷을 정리하는 동작 | 칼라·소매·장갑·라펠을 정돈하는 모습. 동작 중의 자연스러운 순간을 만든다. |
| Walking turn · 걸으며 돌아보기 | 이동 중 몸이나 얼굴만 뒤로 향하는 순간. 머리카락과 옷자락에 움직임이 생긴다. |
| Body isolation · 신체 분리 움직임 | 춤에서 어깨·흉곽·골반 등 특정 부위를 다른 부분과 분리해 움직이는 기법. |
| Body roll · 이어지는 몸통 움직임 | 상체의 굽힘과 펴짐이 순서대로 이어져 파동처럼 보이는 춤 동작. |

## 5. 신체 묘사·헤어·메이크업

아래는 외형을 구체적으로 적기 위한 말이다. 특정 체형·성별·피부색이 관능성의 조건이라는 뜻은 아니다. 메이크업의 질감 구분은 NARS·MAC의 공식 자료도 참고했다. [S9]

| 용어 | 뜻과 시각적 특징 |
|---|---|
| Silhouette · 실루엣 | 인물이나 의상의 외곽선. 몸에 밀착된 옷과 넓은 옷 모두 고유한 실루엣을 만든다. |
| Décolletage · 데콜테 | 낮은 네크라인으로 드러나는 목 아래·어깨·윗가슴 부위 또는 그 연출. 단순한 가슴골과는 범위가 다르다. |
| Cleavage · 가슴골 | 가슴 사이에 형성되는 골이나 옷 밖으로 보이는 해당 부분. |
| Collarbone · 쇄골 | 목과 어깨 아래를 가로지르는 뼈와 그 윤곽. |
| Nape · 목덜미 | 목의 뒤쪽. 올린 머리나 등이 열린 옷의 외형 설명에 유용하다. |
| Midriff · 복부 중간 부분 | 가슴 아래부터 허리 부근까지의 몸통 영역. 크롭트 상의의 노출 부위를 설명할 때 쓴다. |
| Natural skin texture · 자연스러운 피부결 | 모공·잔주름·미세한 색 차이 등이 남아 있는 표면 표현. |
| Dewy finish · 촉촉한 광 | 수분감이 있어 보이는 피부 표현. 번들거리는 기름막과 반드시 같은 뜻은 아니다. |
| Satin finish · 새틴 광 | 매트와 강한 광택 사이의 은은하고 매끄러운 윤기. |
| Matte finish · 무광 | 강한 반사가 적은 마감. 피부·입술·섬유 모두에 쓸 수 있다. |
| Glossy lips · 광택 있는 입술 | 표면에 반사광이 뚜렷하게 보이는 립 메이크업. |
| Blurred lips · 경계가 흐린 입술 | 입술 외곽선을 부드럽게 번지게 표현하는 방식. |
| Gradient lips · 그러데이션 입술 | 입술 안쪽과 바깥쪽의 색 농도를 달리하는 표현. |
| Smoky eyes · 스모키 아이 | 어두운 색을 눈 주변에 부드럽게 번지도록 연결해 깊이를 만드는 메이크업. |
| Smudged eyeliner · 번진 아이라인 | 선을 또렷하게 유지하지 않고 부드럽게 퍼뜨린 형태. 일부러 흐트러진 인상을 줄 수도 있다. |
| Winged eyeliner · 날개형 아이라인 | 눈 바깥쪽으로 선을 뻗어 끝을 올리거나 길게 만드는 형태. |
| Tightlining · 속눈썹 뿌리 채우기 | 속눈썹 사이와 뿌리 쪽을 채워 경계를 조밀하게 보이게 하는 방식. |

| Finger waves · 핑거 웨이브 | 머리 표면에 연속적인 S자 물결을 만드는 고전적인 스타일. |
| Face-framing strands · 얼굴 옆 머리 가닥 | 얼굴 외곽을 따라 내려와 윤곽을 감싸는 머리카락. |
| Stubble · 짧게 자란 수염 | 면도 뒤 남거나 짧게 정돈한 수염의 질감. 성인 남성적 스타일의 외형 묘사에 쓰인다. |

## 8. 브래지어·하의·노출 방식

## 12. 빛·구도·오감 연출

아래는 관능성 전용 기법이 아니라 어떤 인물·정물에도 사용할 수 있는 사진·미술·감각 묘사 용어다. 이미지의 분위기는 조합에 따라 달라진다. [S19–S21]

|---|---|

| Chiaroscuro · 명암법 | 밝고 어두운 부분의 관계로 입체감·드라마를 표현하는 미술 기법. |
| Tenebrism · 테네브리즘 | 큰 어둠 속에서 일부 형상을 강한 빛으로 부각하는 극적인 명암 표현. |

이미지·화보·캐릭터 설명에 재사용하려면 **분위기 → 표정·시선 → 포즈 → 의복 형태 → 파츠 → 소재 → 빛·구도**처럼 서로 다른 속성을 따로 지정하는 방식이 명확하다. 이는 이 용어집을 활용하기 위한 작성 제안이며 공식 분류법은 아니다.

| 구성 방향 | 단어 조합 예시 |
|---|---|
| 절제된 감각미 | understated sensuality + soft gaze + contrapposto + draped blouse + matte/satin contrast + window light |
| 고전적인 화려함 | Old Hollywood glamour + side glance + reclining pose + bias-cut gown + opera gloves + chiaroscuro |
| 사적이고 나른한 분위기 | intimate + languid + averted gaze + loose updo + camisole + robe + soft light |
| 구조적인 패션 | direct gaze + three-quarter turn + tailored jacket + corset + visible boning + hard light |
| 고딕 패션 | Gothic glamour + profile pose + velvet + lace trim + metal hardware + low-key lighting |
| 성별 표현을 혼합한 착장 | androgynous styling + open-collar shirt + tailored trousers + soft draping + subtle smile |

같은 ‘검은 옷’도 벨벳의 파일과 방향성 있는 명암, 새틴의 부드러운 광택, 라텍스의 표면 반사가 만드는 외형은 다르다. 따라서 추상적인 sensual 하나에 기대기보다 원하는 표면과 형태를 직접 적는 편이 재사용하기 쉽다.
