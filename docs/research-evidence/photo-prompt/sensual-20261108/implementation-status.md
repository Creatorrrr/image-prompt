# Sensual 데이터 반영 및 검증 기록

- 원문 기준: `docs/research-evidence/photo-prompt/sensual-20261108/term-inventory.csv` 323행. 병합 표현의 세부 sense는 아직 전수 분리되지 않았으며 사용자 제공 용어집은 독립 출처 검증을 대체하지 않는다.
- 의미 registry 323행, 연구 context view 323행, 신규 후보 20건, binding 20건, 한영 whole retrieval view 20건. 신규 후보에 연결되지 않은 원문 행 303개는 해결 완료가 아니다. 기존 후보 14건은 제한적 시각 예시로, 103행의 기존 별칭 170건은 검토 전 단서로 기록했다. 동일 의미·중복·조건의 전수 판정이 필요하다.
- 모든 맥락 뷰는 별도 읽기 전용 BM25F `photo_sensual_context_search.py`로 접근할 수 있다. 이 경로는 managed H-F2, embedding 또는 후보 승인과 별개이며 스킬의 managed retrieve에 자동 포함되지 않는다.
- 20개 신규 후보의 H-F2 세대 `bcad814ab72f13c3a281cdfa9c1abac757ec83a37db78c369497309b0d29a2c5` / native `a1cd87d683d3d277c056fc22ce22fb043246f3dcd89ec1711a25dee1e44fa826`. 이전 `d154b481617fee4e7caf9304a3bc5f972cde287d2ba7a45ac66be16da57531ec`; 별도 설치 및 활성화. 의존성·recorder 점검 통과는 검색 품질이나 이미지 품질을 입증하지 않는다.
- 사전 대상 알고 작성한 EN/KO 8개 검색 탐침: 새 예상 후보가 6개 질의 1위, 2개 5위. cowl 두 질의는 기존 소스가 1위. 고정 generation 경로·동일 쿼리 임베딩을 사용했으며 도중에 활성 설정은 이번 작업에서 바뀌었다. 자세한 source, rank, lane과 쿼리는 `probe-results.json`. 독립 holdout이나 관리형 표본 평가가 아니다.
- 독립 arm 세 개는 최신 generation에서 관리형 검색과 receipt audit에 성공했다. 거울 40회/고유 36, 무대 48회/고유 41은 이번 신규 CID 0개; 갤러리 40회/고유 38은 문틀 신규 CID가 2개 질의에 발행됐으나 독립 초안에 이미 같은 구도가 있어 채택·기여로 계산하지 않았다.
- 기본 sensual=1의 인간적 attraction/desire와 참조 인물의 미상 연령이 충돌해 세 managed run은 pack_bound에서 멈췄다. managed composition/audit/render는 수행하지 않았고 provider 호출도 없다. 임의 설정을 사용자 요청으로 오인하지 않았다.
- 세 개의 완전 비성적인 보조 image_gen 이미지는 독립적으로 1회씩 생성했고 managed 후보를 입력으로 사용하지 않았다. 갤러리 `generated/sensual-gallery-test-preparation-20261108/auxiliary-gallery.png`, 무대 `generated/sensual-stage-preparation-20261108/auxiliary/stage-fashion.png`, 거울 `generated/sensual-test-prep-20261108-mirror/auxiliary-image.png`. 문틀·측면·절제 색상, 핑거 웨이브·명암, 거울·드레이프 칼라는 각각 보인다. 잘림·프레임 한계가 있고 이미지 품질의 인과적 개선 증거가 아니다.
- 1~5, 6~11, 12~14절의 행별 소스·후보 대조 추가 감사를 수행했다. 위 이미지는 해당 감사 이후 데이터를 대상으로 재평가한 결과가 아니다.
- 추가 감사 중 cowl neckline의 신규 `cand_2cfe44bde20c53a28adc3cc4f119d6e0`와 기존 `cand_85caf55d82095691acf8f0d30875e4a8`은 표현이 겹친다. 기존 후보는 human 조건과 명시적 appearance/material 소유자 효과가 있으므로 완전 동일하다고 결론내리지 않았고, 별도 유지의 필요성은 미해결이다.
- 323행 전체의 1차 의미 대조가 `photo_sensual_research_context_views_20261108.json`의 `coverage_review`에 기록됐다. 1~5절 126행, 6~11절 120행, 12~14절 77행이며 총 165개 분리 검토 단위와 247개 후보 참조를 보존했다. 후보 참조는 유일 후보 수가 아니다. 각 ref에는 전체 원문 CID·RID·모듈·해시와 역할 바인딩 해시가 있고 검색 시 현재 작업 원본의 일치를 확인한다. 이것은 전체 의미·근거·검색·픽셀의 완성 판정이 아니다.
- 플런지 브라에서 단순 정확 문자열 검사 0건 이후 구조를 재검색해 낮은 중앙 연결부를 가진 기존 후보 두 개를 확인했다. HerRoom의 제한된 용어 설명에 근거하여 그중 하나에 플런지 스타일 검색 context view를 작성하고 후속 인덱스에 반영했다. 검색 뷰는 기존 후보 원문, 조건·효과, native qualification을 변경하지 않는다.
