# 검색·의미·픽셀 평가 계획

아래는 제안된 평가 설계다. 이번 작업에서 운영 검색이나 이미지를 실행하지 않았다. `evaluation-cases.json`의 48개는 실행 전 기대값이며, 결과가 아니다.

## 검색과 적용을 분리한 세 단계

1. 현재 활성 H-F2 release/generation, source manifest, 실제 실행 Python, model/vector space를 고정한다. 작업 소스와 설치된 release는 다른 대상이다. 코퍼스의 literal hit를 retrieval hit로 보고하지 않는다.
2. 개발용 12쌍의 양성/근접 음성 24개, 무키워드 양언어 6쌍 12개, 평범한 장면 6개, 비시각 문맥 6개를 같은 환경에서 평가한다. 모든 실제 query/CID/RID·표본 seed·출처 hash·전체 결과를 보존한다. 조정 후에는 별도 미사용 패러프레이즈와 새로운 장면으로 검증 세트를 작성하고 먼저 hash를 고정한다. 현재 공개된 개발 사례를 독립 holdout이라고 부르지 않는다.
3. 각 노출 후보를 문장 전체, 소유자, 관계 양끝, 조건, 변경 효과와 함께 판정한다. 자연 질의 결과의 노출·원문 호환·실제 선택·최종 prompt 반영을 각각 기록한다. 더 높은 rank나 더 많은 노출만으로 좋은 결과라고 하지 않는다.

개발 통과 제안: 각 양언어 의미 가족에서 호환되는 후보 1개 이상이 기본 검색 예산 안에 노출되고, 잘못된 대상·매체·추가 인물을 강제하는 후보의 채택은 0건이어야 한다. 평범한 장면에 LitRPG 의무나 상태창을 추가하는 결과도 0건이어야 한다. `@k`는 실제 활성 material-view의 반환 예산을 확인한 뒤 기록한다. 이 수치는 미리 주장한 성능이 아니라 후속 작업의 합격 목표다. 광범위 코퍼스 정밀도·재현율은 정답집과 충분한 샘플 없이 주장하지 않는다.

## 정지 이미지에서 확인할 것

| 축 | 합격에 필요한 증거 | 부족한 증거 |
|---|---|---|
| 소유자 | 창·인물·물건·부품이 각각 식별됨 | 머리 위 표식이 둘 중 누구 것인지 불명확 |
| 연결 | 시작점·끝점·그 사이 관계가 한 장에 함께 보임 | 선이 대상 근처에서 끝남, 손·물건이 겹쳐 끝점이 안 보임 |
| 공간 | 선택한 원근·앞뒤·가림 관계가 일관됨 | 반투명만 있고 깊이 판단 기준 없음 |
| 정보 | 자원·등급·옵션·시간 항목이 서로 구분됨 | 색만 다르고 의미 라벨 없음 |
| 문자 | 요청한 짧은 핵심 라벨·수가 사람이 읽을 만큼 정확함 | 비슷한 가짜 글자, OCR 결과만 맞음 |
| 비시각 주장 | `not_established`를 유지 | 수치·표정으로 동의·원인·영구성·신뢰성을 판정 |

`partial_is_fail`과 `UNOBSERVABLE_NOT_PASS`를 적용한다. 장식·국소 관계 하나의 합격을 전체 의미 합격으로 올리지 않는다. OCR은 보조 도구이며 실제 확대 픽셀 검토와 라벨의 대상 연결이 필요하다. 레이아웃 정확도와 실제 값의 진실성도 다른 축이다.

## 제안하는 후속 이미지 6개

| 사례 | 전체 상황과 기준 카드 | 함께 보여야 할 관계 | 주요 혼동 통제 |
|---|---|---|---|
| P1 | 길드 접수원이 카드와 물품을 대조한다. U03/Q01 | 손→카드 받침, 접수원→해당 행, 표식→소포 대응 | 카드와 공중창 혼합 금지; 퀘스트 완료를 자동 선언하지 않음 |
| P2 | 시전자와 아군이 서로 다른 위치에서 지원을 주고받는다. C02/C04 | 효과 시작점→손, 끝점→아군, 상태 아이콘→그 아군 | 빛의 색만으로 치료를 판정하지 않음 |
| P3 | 현재 자원과 배분 가능한 포인트를 따로 보여준다. I02/I04 | 각 라벨→막대, 포인트 총량→행별 선택 | HP·MP·SP 오독, 숫자·막대 비율 모순 |
| P4 | 제작자가 소켓에 들어간 보석을 감정한다. Q06/Q08 | 소켓→무기 부품, 테두리→보석 가림, 감정선→같은 무기 | 보석이 손·다른 무기에 귀속되는 오류 |
| P5 | 현재 생물과 진화 선택 화면을 한 장에 둔다. I07/H02 | 현재 표식→실제 몸, 분기→아직 선택되지 않은 도식 | 분기가 실제 복제 생물로 생성되는 오류 |
| P6 | 관계 수치를 확인하는 두 인물의 상황. R02/X09 | 표시값→정확한 인물, 실제 두 사람의 독립 자세 | 점수를 감정·복종·동의의 증거로 채점하지 않음 |

이 6개는 의미·표현 확인용 제안이다. 향상 효과를 주장하려면 같은 요청과 창작 제어를 고정한 baseline 및 강화본을 비교하고, 반환 이미지 식별자를 가린 평가를 추가해야 한다. 생성 성공률·미학 선호·의미 충족·사용자 승인은 별도로 보고한다. 프롬프트/구성 감사는 픽셀 증거가 아니다.

세계/시야 고정, 개폐, 쿨다운 감소, 레벨업, 반복 사망은 별도 연속 장면 평가다. 한 정지 이미지로 합격시킬 수 없다. 인물의 사적 인지·동의·기억·정체성은 영상만으로도 확정되지 않을 수 있으며 원전 규칙·명시 문맥을 함께 본다.
