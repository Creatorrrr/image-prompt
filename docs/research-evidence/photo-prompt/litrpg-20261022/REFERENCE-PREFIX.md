# LitRPG 용어·요소 사전과 상태창의 시각 표현

**LitRPG는 레벨·능력치·스킬·퀘스트 같은 RPG 규칙이 인물의 선택과 이야기의 결과에 직접 작용하는 장르**입니다. 인물이 자신의 능력을 확인하고, 규칙을 이해하며, 어떤 방식으로 성장할지 선택하는 과정 자체가 중요한 재미가 됩니다. 출판사와 독자 공동체마다 경계는 조금씩 다르지만, 명시적인 게임 규칙과 성장 구조를 중시한다는 공통점이 있습니다. :chatgpt-content-reference{index="0"}

아래에는 **장르·세계관, 능력치·전투·아이템, 서사 관습, 성인·폭력 소재, 상태창과 UI의 시각 표현**을 폭넓게 정리했습니다. 영문 검색어도 함께 붙였습니다.

용어의 성격은 서로 다릅니다. RPG에서 가져온 일반 용어, 웹소설 독자들이 사용하는 분류, 성인물·호러의 소재 태그가 함께 들어 있습니다. 특히 ‘부활을 이용한 고문’, ‘생식력 시스템’ 같은 항목은 **설정을 설명하는 표현**이며, 장르 전체가 공유하는 공식 전문용어는 아닙니다.

## 1. 장르와 하위 유형

먼저 **LitRPG, GameLit, Progression Fantasy**를 구별하면 나머지를 이해하기 쉽습니다. 성장 판타지라는 개념을 설명한 작가 Andrew Rowe도 LitRPG·GameLit·선협·소년 배틀물이 서로 겹치면서 각기 다른 범주라고 설명합니다. :chatgpt-content-reference{index="1"}

| 용어 | 설명 |
|---|---|
| **LitRPG — Literary Role-Playing Game** | RPG 규칙이 서사의 작동 원리가 되는 문학. 레벨, 경험치, 직업, 스킬, 아이템 등의 변화가 사건 해결 방식에 영향을 준다. |
| **GameLit — 게임 문학** | 게임 세계·게임적 논리·게임 구조를 사용하는 이야기의 넓은 분류. 상세한 능력치나 레벨업이 적은 작품까지 포함하는 용도로 많이 사용한다. |
| **Progression Fantasy — 성장 판타지** | 인물이 점점 더 강해지고 능숙해지는 과정을 중심에 놓는다. 수련·기술 습득·마법 연구만으로도 성립하며 상태창은 필수 요소가 아니다. |
| **System Fiction / 시스템물** | ‘시스템’이 인물에게 능력·임무·보상·제약을 제공하는 유형. 전투 외에도 요리, 사업, 연애, 육아 등이 시스템의 대상이 될 수 있다. |
| **Isekai — 이세계물** | 인물이 원래 살던 세계와 다른 세계로 이동하는 유형. 전이·소환·환생 등의 진입 방식이 있으며, 목적지에 RPG 규칙이 있는지는 별도 문제다. |
| **Portal Fantasy — 포털 판타지** | 문·통로·균열 등을 통해 다른 세계로 넘어가는 판타지. 이세계물과 많이 겹치지만 서구 판타지의 별도 분류 전통을 가진다. |
| **VRMMORPG** | 가상현실 다중접속 RPG에 접속하는 설정. 현실의 신체, 게임 아바타, 계정, 운영자, 게임 경제가 서로 얽힌다. |
| **Full Dive — 완전 몰입형 가상현실** | 감각과 신체 경험까지 가상 공간에 몰입하는 설정. 흔히 말하는 ‘완몰가’와 연결되는 개념이다. 작품 속 기술 수준은 현실의 VR과 구별해야 한다. |
| **Crunchy / Stat-heavy LitRPG** | 수치·계산·장비 옵션·스킬 상호작용을 자세하게 보여주는 유형. ‘잔혹하다’는 뜻이 아니라 규칙과 계산의 밀도가 높다는 뜻이다. |
| **Stat-light / Soft LitRPG** | 게임 규칙은 존재하지만 숫자와 계산의 노출을 줄이는 유형. 레벨·직업·스킬 획득만 간결하게 제시하기도 한다. |
| **Apocalypse LitRPG — 아포칼립스형** | 현실 세계에 시스템·몬스터·던전이 도입되며 사회와 생존 규칙이 바뀐다. 재난 생존과 게임식 성장이 결합한다. |
| **Dungeon Core — 던전 코어물** | 주인공이 던전의 핵이나 의식이 되어 방·함정·몬스터·자원 흐름을 관리한다. 던전을 공략하는 사람 대신 던전 자체가 성장 주체다. |
| **Monster Evolution — 몬스터 진화물** | 비인간 존재가 먹이·전투·조건 달성을 통해 진화한다. 종족 분기, 감각 변화, 생태적 지위가 중요한 성장 요소가 된다. |
| **Hunter / Gate Fantasy — 헌터물·게이트물** | 현대 사회에 차원문·던전·몬스터와 이를 상대하는 전문직이 등장한다. 헌터 등급만 있고 게임식 성장 규칙이 약한 작품도 있다. |
| **Tower Climbing — 탑등반물** | 층별 시험·보스·보상을 돌파하며 성장한다. 공간의 수직 구조가 이야기의 단계와 강함의 서열을 동시에 표현한다. |
| **Cultivation — 수련·경지 성장 체계** | 기·육체·영혼·도에 관한 수련으로 상위 경지에 도달한다. 선협과 LitRPG가 결합하면 경지·돌파 조건이 수치화되기도 한다. |
| **Deckbuilding LitRPG — 덱빌딩형** | 스킬·마법·권능을 카드로 획득하고 덱 구성, 손패, 드로, 조합으로 운용한다. 카드 수집과 전술 설계가 성장의 핵심이다. |
| **Crafting LitRPG — 제작 중심형** | 대장장이·연금술사·요리사 등의 숙련, 레시피, 제작 품질이 주요 성장 경로다. |
| **Base / Kingdom Building — 거점·왕국 건설형** | 개인뿐 아니라 건물·생산·인구·기술·군대를 성장시킨다. 개인 상태창과 영지 관리창이 함께 등장하기 좋다. |
| **Slice of Life / Cozy LitRPG — 일상형·코지형** | 생활·장사·농사·공동체에 시스템을 적용한다. ‘일상 중심’과 ‘온화한 분위기’는 별도 성질이라 모든 일상물이 코지는 아니다. |
| **Roguelike / Roguelite적 서사** | 죽음·초기화·반복 도전·무작위성·매회 다른 빌드가 중심이 되는 구조. 문학에서는 게임 장르보다 느슨하게 사용하는 경우가 많다. |

던전 코어의 실제 예로 출판사 Mountaindale Press는 《The Divine Dungeon》의 Cal을 던전을 확장하고 모험가를 유인하는 존재로 소개합니다. 이런 유형에서는 ‘내 캐릭터가 강해지는 것’이 ‘내가 곧 공간이며 그 공간이 성장하는 것’으로 확장됩니다. :chatgpt-content-reference{index="2"}

## 2. 시스템과 세계의 구조

| 용어 | 설명 |
|---|---|
| **The System — 시스템** | 능력치 산정, 스킬 부여, 퀘스트, 보상, 금지 규칙을 관장하는 작중 질서. 프로그램·신적 법칙·초월적 존재 등 정체는 다양하다. |
| **System Integration — 시스템 편입** | 개인·행성·문명이 시스템의 적용 대상이 되는 사건. 종족 판정, 튜토리얼, 새로운 생태계와 법칙의 도입이 뒤따를 수 있다. |
| **Awakening — 각성** | 시스템 접근권이나 초능력·직업이 처음 발현되는 사건. 한국 웹소설에서 특히 익숙한 관습이다. |
| **Tutorial — 튜토리얼** | 시스템 사용법을 배우는 구간. 독자에게 규칙을 알려주면서 인물에게는 시험·선별·생존 과제가 된다. |
| **Administrator — 관리자** | 규칙 변경, 권한 부여, 정보 열람 등 일반 인물에게 없는 접근권을 가진 존재. |
| **GM — Game Master** | 게임을 진행하거나 운영하는 존재. 실제 운영자일 수도 있고 세계 안의 신적 역할로 구현될 수도 있다. |
| **System AI — 시스템 인공지능** | 시스템을 운영하거나 인물과 대화하는 AI. 관리자와 동일한 권한을 갖는지는 작품마다 다르다. |
| **Player — 플레이어** | 게임·시스템에 참여하는 주체. 특별한 성장·부활·정보 접근 권한을 가진 계층을 의미하기도 한다. |
| **Avatar — 아바타** | 플레이어가 세계 안에서 사용하는 몸이나 표현체. 실제 신체와 외모·성별·종족·감각이 다를 수 있다. |
| **NPC — Non-Player Character** | 플레이어가 직접 조종하지 않는 인물. 작중에서 자아·감정·기억을 가지면 인격과 권리의 문제가 생긴다. |
| **Dungeon — 던전** | 위험과 보상이 집중된 탐험·공략 공간. 지하 미궁뿐 아니라 병원, 우주선, 도시, 꿈속 공간도 될 수 있다. |
| **Instance — 인스턴스** | 개인이나 파티별로 분리된 공간. 같은 장소에 들어가도 서로 다른 복제 공간을 경험하는 방식이다. |
| **Gate / Portal — 게이트·포털** | 서로 다른 공간을 잇는 출입구. 던전 그 자체와는 구별된다. |
| **Safe Zone — 안전 구역** | 전투·약탈·몬스터 출현 등 특정 위험이 제한되는 지역. 무엇으로부터 안전한지는 규칙으로 정해진다. |
| **Checkpoint — 체크포인트** | 진행 상태나 재시작 위치를 정하는 기준점. 저장·귀환·부활의 기준이 될 수 있다. |
| **World Boss — 월드 보스** | 공개된 세계에 등장해 여러 집단이 함께 상대하거나 경쟁적으로 공략하는 강적. |
| **Level Gating — 레벨에 따른 접근 제한** | 특정 레벨·등급·업적에 도달해야 지역이나 기능을 이용할 수 있는 구조. |
| **Patch / Rebalance — 패치·재조정** | 시스템 규칙이 변경되는 사건. 작중에서 발생하면 주민들이 자연법칙처럼 믿던 규칙이 바뀌는 재난이 될 수도 있다. |

**세계관에서 큰 차이를 만드는 질문은 “누구에게 시스템이 적용되는가?”입니다.** 주인공만 상태창을 보는 세계, 모든 사람이 같은 시스템을 쓰는 세계, 플레이어와 NPC의 권한이 다른 세계는 같은 ‘레벨업’이라는 말로도 매우 다른 이야기를 만듭니다.

## 3. 능력치·자원·등급

RPG마다 능력치 이름과 계산 방식은 다릅니다. 예를 들어 D&D의 공식 규칙은 능력치·숙련·HP·상태를 구분하며, HP가 0이 되었을 때의 결과도 별도 규칙으로 정합니다. 아래는 특정 게임의 공식을 그대로 적용한 정의가 아니라 여러 작품에서 공유하는 쓰임입니다. :chatgpt-content-reference{index="3"}

| 용어 | 설명 |
|---|---|
| **Level — 레벨** | 성장의 단계를 나타내는 값. 실제 전투력은 장비·상성·기술·직업 등에 따라 같은 레벨에서도 달라질 수 있다. |
| **XP / EXP — 경험치** | 행동의 성과를 성장에 환산한 누적값. 처치 외에 탐험·제작·발견·사회 활동에도 부여할 수 있다. |
| **Stat / Attribute — 스탯·기본 능력치** | 인물의 능력을 계산 가능한 항목으로 표현한 것. 기본 능력치와 그로부터 계산되는 파생 수치를 구분하기도 한다. |
| **STR / Strength — 힘** | 근력·물리적 출력·운반 능력·근접 공격 등에 연결된다. |
| **DEX / Dexterity — 기교·손재주** | 정밀 조작, 무기 취급, 제작, 손놀림 등에 연결된다. |
| **AGI / Agility — 민첩** | 이동·반응·몸놀림·회피 등에 연결된다. DEX와 합쳐 쓰는 시스템도 있다. |
| **CON / VIT / END** | 각각 체질·생명력·지구력 계열의 이름으로 쓰인다. 최대 HP, 질병 저항, 지속 활동 능력 등과 연결되지만 서로 완전한 동의어는 아니다. |
| **INT / Intelligence — 지능** | 학습·연산·마법 위력·마력량 등에 연결되는 추상 능력치. 현실의 IQ와 같은 척도는 아니다. |
| **WIS / Wisdom — 지혜·통찰** | 판단·인지·직관·영적 능력 등에 쓰인다. INT와 기능을 나누는 역할을 하기도 한다. |
| **PER / Perception — 지각** | 숨은 대상, 미세한 변화, 기척, 위험 등을 알아차리는 능력. |
| **CHA / Charisma — 매력·카리스마** | 설득·통솔·위압·존재감 등 사회적 영향력. 외모의 아름다움과 동일하지 않다. |
| **LUK / Luck — 행운** | 치명타·아이템 획득·우연·확률 판정에 영향을 주는 값. 인과관계에 간섭하는 능력으로 확장되기도 한다. |
| **HP / Hit Points·Health Points** | 피해를 감당하고 생존할 수 있는 여력을 표시한다. 실제 상처나 혈액량과 일대일 대응하는지는 설정에 달렸다. |
| **MP / Mana — 마력 자원** | 주문·마법·특수 능력에 소모되는 자원. 정신력이나 외부 에너지로 해석하기도 한다. |
| **Stamina — 스태미나** | 달리기·공격·방어 등 육체 행동을 지속하는 자원. HP와 분리하면 ‘멀쩡하지만 움직일 힘이 없는’ 상태를 만들 수 있다. |
| **SP** | 작품에 따라 **Stamina Points, Skill Points** 등 의미가 달라지는 약어. 반드시 해당 작품의 정의를 확인해야 한다. |
| **AP / Action Points — 행동력** | 일정 구간에서 수행할 수 있는 행동의 예산. 턴당 행동 횟수나 행동 비용을 제한하는 데 자주 쓰인다. |
| **Attack / Defense — 공격력·방어력** | 공격의 위력과 피해 대응력을 요약한 수치. 방어가 명중을 어렵게 하는지, 맞은 피해를 줄이는지는 별개다. |
| **Accuracy / Evasion — 명중·회피** | 공격이 대상에게 닿는지를 다룬다. 적중 후 피해량과 분리된 계산 단계가 될 수 있다. |

## 4. 직업·스킬·빌드와 성장 방식

| 용어 | 설명 |
|---|---|
| **Class / Job — 클래스·직업** | 사용할 능력과 성장 방향을 묶는 역할 체계. 전투 직업과 생활 직업을 따로 둘 수 있다. |
| **Subclass — 하위 직업** | 같은 직업 안에서 전문 분야를 선택하는 분화. |
| **Multiclass — 다중 직업** | 여러 직업의 능력을 병행하는 구조. 직업을 완전히 바꾸는 전직과 구분된다. |

| **Proficiency / Mastery — 숙련도·숙달** | 사용·훈련으로 높아지는 기술 운용 수준. 캐릭터 레벨과 스킬 수준을 분리한다. |
| **Skill Tree — 스킬 트리** | 기술의 선행 관계와 선택 경로를 연결한 구조. 실제 형태는 나무보다 복잡한 그래프일 수도 있다. |
| **Prerequisite / Unlock — 선행 조건·해금** | 능력치·기술·업적·사건 등의 조건을 충족해야 새 기능이 열리는 구조. |
| **Talent / Trait / Perk — 재능·특성·특전** | 선천적 자질, 고유 성질, 선택형 보너스 등을 나타내는 이름. 작품마다 용어 배분이 다르다. |
| **Skill Book / Skill Stone — 스킬북·스킬석** | 능력 획득을 물품화한 장치. 능력을 거래·약탈·상속할 수 있게 만든다. |

| **Build — 빌드** | 능력치·스킬·장비를 조합한 운용 설계. 같은 직업도 빌드에 따라 역할이 달라진다. |

| **Min-maxing — 극단적 최적화** | 중요하지 않은 요소를 줄이고 핵심 성능에 자원을 집중하는 방식. 반드시 버그 악용을 뜻하지는 않는다. |
| **Glass Cannon — 유리 대포** | 공격력은 높지만 방어·생존력이 약한 빌드. |
| **Respec — 재분배** | 이미 선택한 능력치·스킬을 되돌리고 빌드를 다시 구성하는 기능. 비용과 횟수 제한이 선택의 무게를 결정한다. |
| **Skill Copy / Theft / Absorption** | 타인의 기술을 복제·탈취·흡수하는 성장 방식. 원래 소유자가 능력을 잃는지 등에 따라 의미가 달라진다. |

| **Title / Achievement — 칭호·업적** | 칭호는 인물에게 붙는 명칭이나 자격, 업적은 특정 성취의 기록이다. 둘 다 능력이나 권한을 부여할 수 있다. |
