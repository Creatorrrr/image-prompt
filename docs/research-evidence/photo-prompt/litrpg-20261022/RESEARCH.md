# LitRPG 시각 의미·후보 데이터 강화 리서치

초기 조사일: 2026-10-22 KST. 대상은 [LitRPG 용어 조사 설명](https://chatgpt.com/c/6ada011f-1294-83ee-969f-be549a1046c2)의 전체 키워드와 `photo-prompt-image-generator` 데이터다. 이 문서는 운영 변경 이전의 리서치와 계획 기록이다. 이후 사용자 요청에 따른 실제 반영·검색·독립 이미지 실험은 [INTEGRATION-RESULTS.md](INTEGRATION-RESULTS.md)에 구분해 기록한다.

## 판단과 보강 방향

LitRPG를 시각 데이터로 다룰 때 핵심은 RPG 규칙이 **무엇을 측정하고, 누구에게 보이며, 어떤 선택과 결과를 연결하는가**다. 출판사 [Level Up](https://www.levelup.pub/what-is-litrpg)과 작가 [Andrew Rowe](https://andrewkrowe.wordpress.com/2019/02/26/progression-fantasy-a-new-subgenre-concept/)는 장르의 게임 규칙과 성장 구조를 설명하지만, 모든 작품에 같은 파란 창이나 수치 밀도를 요구하지 않는다. 작품 분류는 설명 맥락으로 보존하고 구체적인 창·손·물건·연결·표시값을 선택 가능한 실현으로 만든다.

현재 데이터의 보강 우선순위는 (1) 표시 매체와 인지·공간 축 분리, (2) 자원·성장·전투·경제의 정보 구분, (3) UI와 정확한 대상의 연결, (4) 규칙과 정지 이미지 증거의 한계다. 기존 메타픽션/실존 공포/LitRPG 모듈의 8개 D 실현은 좋은 비교점이지만, 일반 LitRPG 전체를 대표하기에는 다루는 상황이 제한적이다. 60개 새 초안은 전부 신규 등록하라는 할당량이 아니다. 기존 소스와 동치면 재사용하고, 필요한 차이만 독립 실현으로 검토한다.

참조 대화의 용어 255행과 작품·스타일·매체·설계 질문 42행을 297개 경로로 연결했다. 78개 의미 카드는 직접 보이는 관계 22개, 표시 내용 38개, 비시각 문맥 14개, 연속 증거 필요 4개로 구분했다. 60개 시각 후보 초안에는 영어·한국어 문장, 소유자, 관계, 조건, 혼동 경계와 제안 슬롯을 붙였다. [전체 용어 경로](KEYWORD-ATLAS.md), [카드](VISUAL-CARDS.md), [후보](CANDIDATE-ATLAS.md)를 각각 확인할 수 있다.

## 외형 다양성은 기능과 독립적으로 유지

참조 대화의 12개 표현 방식은 후보 선택의 외형 축으로 보존한다. 청색 패널·밝은 메뉴·레트로 창·아케이드 보상·SF HUD·종이/카드·피부 문자·장비 계기·감각형·손상 UI·생체형·관전 피드다. 특정 장르 단어가 특정 색·질감·창 개수를 자동으로 요구하게 만들지 않는다.

청색 패널은 원근과 가림, 밝은 메뉴는 목록과 선택 상태, 레트로 창은 글자 격자와 테두리, 아케이드는 큰 정보와 장면 반응, SF HUD는 조준·센서 대상, 종이/카드는 지지·두께·취급, 피부 문자는 신체 굴곡, 장비 계기는 부품 결합, 생체형은 막·접합의 소유 관계가 주요 비교점이다. 손상 UI는 오류·가림·잠금을 나누고, 관전 피드는 메시지·수신자·보상 항목을 나눈다. 감각형·등장 애니메이션·닫아도 재출현은 시간·문맥 증거가 필요한 쪽에 둔다. 이 세부 실현은 이번 연구의 설계 제안이며 특정 작품의 검증된 픽셀을 복제한 목록이 아니다.

## 성인·폭력·불쾌한 소재의 처리

원문 용어의 고문·절단·포식·사령술·강제 변형·부활 반복 가해·통증, 성인물·페티시·BDSM·비동의·성적 강요·노예제·생식 통제·NTR·금기 관계·촉수·방어구 파괴를 키워드 목록에 유지했다. 조사 분류는 생성 허가나 특정 묘사를 추가하라는 명령이 아니다.

각 항목을 관계 구성, 노출·행위의 상세함, 신체 변화, 통제 권한, 동의·강요의 문맥으로 나눈다. [Royal Road의 분리된 경고 축](https://www.royalroad.com/support/knowledgebase/114)은 이런 분리의 한 사례이며 통일된 장르 사전이나 현실 동의 판정 체계가 아니다. 목걸이·침묵·미소·높은 호감도·노출에서 동의를 추론하지 않고, 혈통 도식이나 신체 외형에서 임신·성적 이력·생식 강요를 확정하지 않는다. BL/GL·몸 교환·비인간 연애·하렘 자체를 성적 상세 묘사와 합치지 않는다.

고문 의도·통증·정신 안정·영혼·강제성·반복 이력은 X 카드 문맥으로, 변형의 연속 표면·부착체 접합·장비 파손·표시값은 H/R 카드의 선택적 시각 실현으로 구분했다. 비시각 의미를 지워서 평범한 소품으로 바꾸는 것도, 소품에서 그 의미를 자동 판정하는 것도 피한다.

## 현재 자료의 증거 수준

참조 대화의 20,000자 preview 뒤는 실제 브라우저의 전체 18개 표를 읽어 보완했다. 원문 전체 body는 보관하지 않았고 20,000자 prefix와 전체 행 라벨·행 수를 보관했다. 뒤쪽 라벨은 관찰된 DOM 추출에서 수동 전사했으므로 [reference-register.json](reference-register.json)의 획득 범위를 함께 본다.

코퍼스 audit은 지정 양성 문장 필드만 읽은 스냅샷이다. 연구 그래프는 native facts가 아니고 제안 슬롯은 qualification이 아니다. 키워드 경로가 있다고 검색·선택·픽셀 개선이 검증된 것도 아니다. 운영 데이터 편입, 인덱스 발행, 설치 활성화, 이미지 품질·사용자 승인은 모두 후속 단계로 남아 있다.
