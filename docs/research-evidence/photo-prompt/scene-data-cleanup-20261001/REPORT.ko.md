## 고정 평가와 솔직한 한계

수정 전에 32개 행과 42개 질의를 고정했다. 기준선은 원격 main 원본이 아니라 이전 23개 수정을 포함한 상태다. 전체 해당 슬롯에서 순위를 측정했으며 검토 대상 32개만으로 검색 공간을 제한하지 않았다.

- lexical 양성 32개: 1위 30/32 → 32/32. 2개 개선, 30개 동일
- 탐침 10개: 대상 순위 하락 7개, 동일 3개. 이들은 문맥 중첩과 유효한 대안도 포함하므로 10개 hard negative 통과로 해석하면 안 된다
- 빈 다이어리 대안은 1위를 유지했다. 군중 없는 공간과 한 명이 있는 공간의 중첩 탐침은 7위로 동일했다
- 검토 과정에서 일반적인 `blue hour` 검색이 사라지는 실제 부작용을 발견했다. 완전한 `blue hour after sunset` 별칭을 추가해 1위를 복구했다. 이 추가 진단은 고정 질의 집합과 별도로 기록했다
- 전경·중경·배경의 연속 공간, 일관된 가림 경계, 카페의 서비스 측 컵, 세탁기→손→바구니의 이동·지지 관계를 보존했다

질의는 현재 후보와 프리셋의 의미를 바탕으로 작성했다. 수정 전 고정 검증이지만 독립적인 일반화 holdout은 아니다. 이미지 생성·픽셀 검토는 하지 않았으며 시각적 품질 향상을 주장하지 않는다.

## 검증과 비용

- 최종 통합 회귀 테스트 102개 모두 통과 (163.315초)
- 새 정합성·기존 수정 보존 테스트 16개 통과
- 위 테스트와 기존 BM25F 테스트 합계 25개 통과
- aggregate dictionary metadata validator 통과
- 실제 dense 양성 32개: 기준선·최종 모두 32/32가 1위. 10개 탐침 중 대상 순위 하락 7개, 동일 3개
- 실제 semantic index: 9,754개 문서 검증 완료. 9,740개 벡터 재사용, 변경된 14개만 새로 계산
- 중간 1·2단계도 캐시된 실제 벡터로 평가했다. 검토 후 최종 3단계 상태가 실제 배포 후보 인덱스다
- 승인된 호출 상한: 14개 문서 + 42개 고정 질의 = 56회. 자동 재시도 없음
- Gemini Embedding 2 표준 텍스트 가격 $0.20/1M token, 입력 상한 8,192 token으로 보수적 추가 상한 $0.0917504. 이전 작업과 합한 보수적 상한 $0.6914048
- 현재 라운드 API 실행: 56회 성공, 재시도 0회. 위 금액은 보수적 상한이며 실제 청구액을 측정한 값이 아니다
- 복구된 이전 23개 수정 기준선은 기존 86개 통합 테스트를 모두 통과했다
- 이전 23개와 이번 14개는 겹치지 않아 기준 커밋 대비 총 37개 행이 수정된 상태다

가격과 입력 한도: [Google 공식 가격표](https://ai.google.dev/gemini-api/docs/pricing), [공식 embedding 문서](https://ai.google.dev/gemini-api/docs/embeddings)

초기 실행 환경에 체크아웃이 없어 기존 복구 파일과 해시가 검증된 공개 저장소 소스로 복구했다. 초기 테스트의 누락 fixture/인덱스 오류는 복구 과정의 불완전한 파일 상태였으며, 수정 자체의 회귀로 계수하지 않는다. 최초 로그도 보존하고 복구 후 결과를 별도로 기록했다.

커밋·push·PR·merge·배포는 수행하지 않았다. 원본 코드와 데이터를 변경하는 범위는 위에 한정되어 있다.
