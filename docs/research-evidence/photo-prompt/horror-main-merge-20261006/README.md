# 호러 데이터 main 통합

최신 원격 main을 pull한 별도 체크아웃에 호러 후보 155개, 시각 의미 프로필 155개, 선택형 묶음 11개를 통합했다. 기존 main의 물 관계 데이터와 실행 캐시 개선은 유지했다. 다른 작업의 미커밋 지적 활동 데이터와 데이터 품질 수정은 주 작업 폴더에 보존하며 이번 커밋에 포함하지 않는다.

## 양쪽 의도 보존

- 부모 main: `c72abf1d7f05895b7546b07bcab9f8f39dbd3173`.
- 기존 authored DATA는 바이트 그대로 유지했다. 등록에는 호러 소스 두 행만 추가했다.
- 기존 main 대비 후보 10,205 → 10,360, 시각 의미 프로필 2,038 → 2,193, 묶음 953 → 964.
- 두 검색 인덱스는 합쳐진 원본에서 다시 생성했다. 항목 ID, 전체 긍정 텍스트, 제공자·모델·768차원이 맞는 실제 벡터만 재사용했고 새 임베딩 호출은 0회다. 이전 샤드는 보존했다.
- V1–V30 후보팩과 매니페스트를 수정하지 않고 V31을 추가했다. 과거 실행을 재현하는 V30의 원본 소스·의존성 1,307개는 Git blob, SHA-256, 크기, 모드로 고정했다. 변한 파일은 별도 원본 경로에 보존하고 원래 구현에서 과거를 재현한다.

## 검색 변화와 검증

고정된 요청·코어·제어·신체 사전검토·작성 예산·부정문은 유지된다. 공개 후보 수는 64개다. 호러 데이터 확장으로 네 슬롯이 새로 노출되고, 기존 일곱 슬롯의 선택적 후보가 각각 한 개 줄었다. 별도 선택적 대립 후보도 달라졌다. 검색 해시·풀 크기 등을 포함한 전체 차이 41개를 고정했고, 그 외 의미·순서·본문·예산·원본 변경은 변조 검사에서 거부한다. 선택적 후보 노출 자체는 사용자 요구나 필수 표현의 생성이 아니다.

## 이미지 증거의 범위

원래 세 독립 에이전트의 원본 이미지·프롬프트·후보팩·감사·ledger를 보존했다. A/B 전체 기술 통과, C는 접합 주제 구현과 별개로 지지 접촉이 보이지 않아 전체 미통과라는 판단을 유지한다. 과거 이미지는 실제 생성에 사용한 `d947d6b6` 버전에 연결한다. 병합 중 이미지 생성 호출은 0회이고 새 V31에서 재렌더됐다고 주장하지 않는다. 사용자 미감 판단은 별도다.
