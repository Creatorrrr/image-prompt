# 유도선의 리듬 연결 대안을 렌더 판단 문구에 보존

기준 커밋: `1feea7ceb7ec55b34aaf0c521a0c56714dcfa2e7`.

유도선 프로필은 성분·증거·의역에서 연속된 선뿐 아니라 반복 정렬된 모서리의 리듬 연결도 허용한다. 그러나 두 필수 렌더 판단 문장은 물리적인 선과 눈에 보이는 연속성만 명시했다.

프로필 1개의 두 판단 설명만 맞췄다. 시작점은 물리 선 또는 정렬된 장면 모서리, 경로는 연속 또는 리듬 연결로 명시한다. 네 게이트의 ID·척도, 네 필수 성분, 지정된 대상에 도달하는 끝점, 증거 기준과 잘못된 대체물 거절은 그대로다. 일반 점무늬나 대상 없는 소실점까지 허용한 것이 아니다.

## 실제 결과와 한계

같은 주전자 주둥이에 도달하는 연속 난간과 반복 정렬 모서리 2개를 정상 공개 CLI로 전후 실행했다. 팩마다 두 설명과 파생 팩 ID의 3곳만 달라졌다. 각각 슬롯 후보 64개 전체와 시각 후보 3개/4개가 완전히 동일하다.

두 완전한 구성 프롬프트는 실제 전체 감사 CLI에서 종료 코드 0, 실패 0이다. 기존 본문·시작점·끝점과 반복 경로의 간격을 보존했다. 각 감사의 의도/자유 서술 커버리지 경고 3개는 그대로 공개했다. 같은 증거는 수정 전후의 시각 증거 감사에서 모두 통과한다. 따라서 이 교정은 렌더 판단 문구의 정합성이며, 이전에 이미지가 실제로 거절됐다거나 새 이미지 품질이 좋아졌다는 주장이 아니다.

새 회귀 3개를 포함한 37개 테스트와 독립 기존 구도 회귀 3개, 사전·실제 인덱스 검증이 통과했다. 처음 작성한 새 테스트가 게이트 수를 잘못 5개로 가정한 실패 기록도 남겼다. 실제 원본은 4개이며 테스트의 가정만 바로잡아 다시 실행했다. 데이터를 테스트에 맞춰 늘리거나 기존 테스트를 변경하지 않았다.

1,496개 프로필의 의미 텍스트·벡터·BM25F·조회 데이터는 모두 그대로다. 실제 캐시를 사용해 인덱스의 registry_sha256만 갱신했다. API 호출 0회, 이 단계 비용 0달러, 프로젝트 누적 보수 상한은 $1.4123008 / 허용 $10 그대로다.
