기존 결과는 3개 사례 중 전체 필수 조건을 통과한 사례가 0개였다. 실제 저장된 원본 두 장과 이미지가 반환되지 않은 차단 한 건을 구분해 분석했다. 프롬프트·런타임 감사 PASS는 픽셀 PASS를 대신하지 않는다.

| 사례 | 원본에서 확인한 실패 | 보완한 판단과 데이터 | 재시험에서 유지하는 필수 조건 |
|---|---|---|---|
| A: 외투·가방·버클 동작 | 외투 앞섶과 다리 주변의 틈은 보이지만 몸통 옆 외투 경계와 몸통 사이 틈은 팔·옷에 가려졌다. 두 가방 연결구는 통과했다. 두 발의 바닥 지지와 버클 혀가 하우징에 들어가는 손의 연결 상태도 요구와 달랐다. | 같은 소유자·몸통 옆 경계라는 의미를 더 명확히 하고, 다른 위치의 틈과 구별한다. 같은 가방의 두 연결구를 부분 연결 한 개나 전체 스트랩 경로와 구별한다. 동작 순간의 손→물체→접촉점을 하나의 상태로 계획한다. | 이전 두 시각 프로파일의 전체 계약과 신체 점검 5개를 그대로 승계한다. 이미 통과한 가방 연결구도 다시 확인한다. |

위 원본의 위치와 검증 해시는 [이전 픽셀 판정 원장](../wardrobe-keyword-integration-20261010/NATIVE-QUALIFICATION-LEDGER.json)에 보존되어 있다. 가림과 미세 질감 실패는 관찰된 결과다. 구도·거리·깊이·대비의 보완이 실패를 줄일 수 있다는 판단은 제작상의 가설이며, 실패한 모델 내부 원인이 확정됐다는 뜻은 아니다.

스킬에는 특정 장소·의상·포즈 정답을 넣지 않았다. 프리즈 전에는 의미를 담당하는 소유자, 양 끝, 상태를 함께 볼 수 있는지 계획하고, 채택 후에는 전체 계약이 한 사진에서 공존하는지 다시 판단하도록 보완했다. 필요한 연결을 숨기거나 필수 검증을 선택 항목으로 내리는 방식은 허용하지 않는다. 원본 해상도에서 구별되지 않는 미세 구조를 확대·보간으로 만들어 통과시킬 수도 없다.

데이터는 기존 관계 6개의 동의적 설명·혼동 경계를 보강했다. 기존 146개 시각 프로파일의 활성화와 필수 지시·증거·게이트는 보존했다. 리서치에서 기존 ID로 재사용한 카울 목선과 비숍 소매에는 각각 동일 의상의 부착 경계/손목 커프 관계를 별도 한정 프로파일·번들로 연결했다. 기존 후보 ID는 유지하고 해당 후보·프로파일의 소재 변형 영향 범위를 완성했다. 재사용한 다른 두 관계는 기존 계약이 이미 범위를 담당해 중복 생성하지 않았다.

리서치의 503개 표제어는 125개 집중 분석 카드와 연결되어 있다. 관찰 가능한 114개 카드의 150개 후보 초안 및 53개 명명 대안을 현재 후보·프로파일에 대조했다. 원문 불확실성, 미확인 대상, 선택 색상, 사적 감정 추정 등의 11개 카드는 근거 한계 기록으로 유지한다. 과거 조합 20개는 선택 가능한 분석 사례이며, 과거 제외 조건 23개는 해당 문맥에만 적용한다. 이 범위의 연결 누락은 해소했지만, 전체 과거 세션의 전수 확보나 503개 용어의 모든 보편 정의, 모든 대안의 픽셀 성공을 입증한 것은 아니다. [현재 리서치 반영 감사](RESEARCH-COVERAGE-AUDIT.json)가 개별 연결과 현재 해시를 기록한다.

네이티브 결과 기록 경로도 보완했다. 관리 워크플로가 기존 독립 실행 매니페스트의 사례 ID, 작업 디렉터리, 스킬 해시, 소스, 독립성 선언, 실제 누적 호출 수를 일반 기록기로 전달하도록 했다. 메타데이터 누락은 이미지 품질 실패의 원인과 별개다. 선언만으로 독립성을 입증하지 않으며, 각 에이전트의 입력 범위와 실제 프리즈·소스·참조·호출·원본 기록을 함께 유지한다.

이번에는 새 독립 에이전트 3개가 각자 작성한다. A/C는 공식 닫힌 재시도 문맥으로 이전 필수 계약을 승계하며, B는 기존 차단 프롬프트를 받지 않는 새 초기 컨셉이다. 세 사례 모두 동일 첨부 사진의 얼굴·머리 특징만 참조한다. 각 사례는 새 실제 이미지 호출을 최대 두 번까지 사용하며, 첫 이미지가 전체 필수 조건을 통과하면 종료한다. 한 번의 추가 호출은 실패한 조건의 범위 안에서만 보완하고 이전 통과 조건을 보존한다. 차단·불확실한 호출·원본 미확보는 자동 재호출 사유가 되지 않는다.

현재 채택한 일반 후보나 번들의 완전한 관계는 필수 게이트 외부의 보조 관찰로도 확인한다. 그중 미완성 관계가 있으면 사례 전체의 완전 반영을 주장하지 않는다. 이전 선택 사항이 현재 사례에서 달라진 경우 이를 공개하고 실제로 승계한 조건끼리만 비교한다. 프롬프트·런타임 계약, 원본 픽셀의 조건 충족, 전체 장면의 인상, 사용자 선호를 각각 기록한다. 이번 소수 사례로 스킬 수정의 인과 효과나 모든 후보의 성공률은 추정하지 않는다.
