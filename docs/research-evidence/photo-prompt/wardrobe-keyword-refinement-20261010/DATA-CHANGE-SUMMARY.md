이번 보완은 같은 화면에서 확인할 소유자·경계·끝점·상태를 명확히 한다. 기존 146개 관계의 활성화, 필수 문구·증거 필드·게이트와 거부 조건은 그대로 보존했다. 아래 여섯 관계는 발견용 설명, 유사 표현, 혼동 경계와 후보·번들 설명을 보강했다.

리서치 초안에서 기존 후보 ID를 재사용한 두 항목은 완전한 한정 관계 연결이 빠져 있었다. 카울 목선의 양쪽 부착 경계 사이에 늘어진 주름(WK024)과 같은 소매의 풍성한 하부가 손목의 좁은 커프로 모이는 관계(WK029)에 각각 프로파일과 번들을 추가했다. `clt_ct037_v1`, `clt_ct047_v1`의 후보 ID는 유지하고 소재 변형의 영향 범위만 완성했다. 기존 의상 프로파일 306개의 구성 요소와 활성화는 보존했고, 다른 후보 304개는 그대로다.

현재 의상 확장에는 프로파일·번들 각각 148개가 있다. 이번에 일반 후보 ID를 새로 만들지 않았다. 원래의 150개 초안은 이전에 통합한 후보 146개와 기존 후보 재사용 4개로 연결되며, 재사용한 나머지 두 항목은 기존 계약이 이미 필요한 관계를 담당한다.

503개 표제어와 125개 집중 분석 카드, 관찰 가능한 카드 114개, 후보 초안 150개 및 명명 대안 53개를 현재 소스와 대조했다. 11개 근거 한계 카드는 외부 주석으로 유지하고, 과거 조합 20개와 제외 조건 23개는 해당 문맥의 분석으로 유지한다. 이 정보는 전역 필수 조합이나 전역 제외 규칙으로 변환하지 않는다. 현재 연결 누락은 [반영 감사](RESEARCH-COVERAGE-AUDIT.json)에서 해소됐으나, 모든 후보의 픽셀 성공이나 전체 과거 세션의 전수 확보를 뜻하지 않는다.

생성용 시각 인덱스와 의미 인덱스를 다시 만들고 최종 런타임 세대를 발행했다. 시각 인덱스는 전체 프로파일 3,834개와 정확 용어 6,637개, 의미 인덱스는 전체 항목 12,079개를 포함한다. 의미 벡터는 적합성이 맞는 기존 항목을 재사용했다. 전체 항목 수를 신규 API 호출 수로 세지 않는다.

스킬은 프리즈 전에 소유자·양 끝·접촉 상태·상대 크기·깊이·대비가 한 장에서 공존하는지 계획하고, 채택 후에는 추가한 관계가 그 계획과 함께 성립하는지 확인하게 보완했다. 특정 포즈·렌즈·해상도를 전역 정답으로 고정하지 않는다. 필수 부분이 원본에서 가려지거나 구별되지 않으면 실패다. 보간 확대는 누락된 증거를 만들어 주지 않는다.

관리 네이티브 결과 기록은 독립 사례 ID, 스킬 해시, 소스, 작업 위치, 독립성 선언과 실제 누적 호출 수를 기존 매니페스트에 전달한다. 이것은 기록 보완이며 이미지 품질을 입증하는 점검과 별개다. [110개 집중 테스트와 최종 데이터 재검사](VALIDATION.json), [기존 계약 보존](INHERITED-CONTRACT-PRESERVATION.json), [행 보존](ROW-PRESERVATION.json)이 각각의 검증 범위를 기록한다.
