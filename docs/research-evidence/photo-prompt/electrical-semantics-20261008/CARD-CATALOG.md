# 전기 시각 의미 연구 카드

각 카드는 선택 가능한 관측 표현의 초안이다. 실제 의미가 요구하지 않는 세부를 hard duty로 만들지 않는다. `P2`와 family 카드는 추가 리서치·분해 후 채택한다.

## EL001 — 같은 두피에서 갈라져 뜨는 대전 머리카락

- 모드/우선순위: `direct` / `P0`; 원자화: `bounded_realization_proposal`
- 시각 표현: separate fine strands rise from one scalp; the raised strands spread apart above that same head; ordinary room light reveals the strand edges
- 관계: strands → grows_from → same_scalp; strands → spreads_apart → neighboring_strands
- 혼동 경계: 바람에 한쪽으로 쏠린 머리와 공중 번개
- 판정 한계: 모발 형태만으로 전하량·원인 확정 불가;대전 상황은 요청 문맥
- 반영 경로: `hair_style`; `enrich_or_narrow_sibling`
- 출처: [S07: UW Madison Van de Graaff](https://www.physics.wisc.edu/outreach/wonders-of-physics-outreach-fellows/activities/van-de-graaff-machine/)
