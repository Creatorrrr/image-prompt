# 전체 테스트 결과와 현행 사진 관측 기준 정비

검증 소스: `cad6f90549d9fd6348310a71a23025f003fd00d6`. 이 작업은 데이터 개선 회차가 아니라 검증 관측값의 정비다.

## 전체 실행 결과

원본 전체 테스트를 건너뛰지 않고 실행했다. **1,205개, 3,980.265초, 실패 10건·오류 4건, 종료 코드 1**이다. 하위 테스트를 포함한 실패 수이므로 이를 14개 실패 메서드라고 해석하지 않는다. 전체 통과나 시스템 전체의 무회귀를 주장하지 않는다.

- 한국 감성: 외부 참조 JPEG 하나가 없어 하위 검사 3건 실패
- 메이크업: 고정 코어 5개가 없어 검사 1건 실패, source_observation.json 부재로 오류 1건
- 빈곤 장면: 기존 최종 PNG 3개 부재로 하위 검사 3건 실패
- 희귀 사진: 원본 요청 JSON 부재로 하위 검사 3건 실패. 해당 사례의 envelope/core 6개 및 명시된 후보팩 3개가 현재 경로에 없음
- 서브컬처의 사진 경계 검증 3건: 현행 후보팩의 바이트 해시가 고정 관측과 달라 오류

한국 감성·메이크업·희귀 사진의 해당 메서드는 원본 소스·자산을 내보낸 `57e2973`과 최초 기준 `9594c556`에서도 같은 위치에서 실패했다. 기준선 **전체** 테스트를 재실행했다는 뜻은 아니다. 관련 테스트·fixture·추적된 참조 JSON의 해시는 동일하다. 누락 파일을 위조하거나 테스트를 건너뛰지 않았다. 원 작성자의 컴퓨터에서도 실패했다거나 파일이 영구 유실됐다고 추정하지 않는다. 빈곤 PNG는 앞선 별도 진단에서 재현된 제한이며, 이번 새 누락 자료 진단과 구분했다.

## 바이트 불일치의 실제 범위

첫 로컬 발생은 손 역할 데이터를 수정한 `ebd10bcb`다. 통과하던 `9594c556`과 실제 정상 공개 CLI 출력의 차이는 tags_hash, slot_corpus_sha256, 파생 코어 해시, pack_id 네 곳이다. 이는 **정확한 바이트 기준 테스트의 퇴보**이며, 이 사례에서 후보 내용의 의미 퇴보가 확인됐다는 뜻은 아니다.

upstream `0adb5f6e`도 자신이 기록한 새 관측과 이미 다르게 출력된다. 현재 출력은 통합 upstream `840d4b8f`와 바이트까지 동일하고 반복 실행도 동일했다. 기존 v5 핀과 정확히 일치하는 원본 팩을 복구해 대조하니, 네 파생 해시 외에 쿨데레 프로필의 interpreted_meaning 문구도 한 곳 달랐다. 이 다섯 번째 차이는 순수 upstream에 이미 있던 수정으로, 일반 의미와 선택된 성인 캐릭터 장면 구현을 구분한다. 이를 해시 변화로 감추거나 ‘모든 원래 의미가 동일’하다고 주장하지 않는다.

동결 코어, 공개 후보 64개 전체, 부정 프롬프트, 의미 성분, 안전·의도·적용 조건은 그대로였다. 기존 통합 upstream 이후 추가 의미 차이는 없었다. 두 독립 검토에서 원본 팩과 다섯 차이, upstream 출처, 파생 해시 재계산을 확인했다.

## 적용한 정비와 재검증

현행 `photo_regression_baseline_v5.json`의 **sha256와 pack_id 두 값만** 실제 재현값으로 갱신했다. 원래 v5 파일과 원래 고정 팩, 전후·upstream 전체 팩을 새 증거에 보존했다. v1–v4, 과거 관측 영수증, v5→v4 연결, 명령·후보 수·부정 프롬프트·런타임 검사·원본 테스트는 변경하지 않았다. 초기 진단의 네 필드 갱신 제안보다 독립 최종 검토를 좁혀 두 필드만 적용했다.

새 실제 팩 SHA-256: `878167e663d6d8a3ce33cde24c18c70ea350e3861a0f9580486ebc18b0e5f3bb`, pack_id: `e153ad2c064e14fb`.

수정 후 **원본 오류 테스트 3개 모두 통과**했다(50.432초). 새 공개 CLI 출력도 갱신한 핀과 같고 수정 전 실제 출력과도 바이트 동일하다. 초기 잘못된 클래스 경로 실행은 별도 로그로 보존했고, 정정된 실행에서 세 원본 테스트를 모두 실행했다. 전체 1,205개를 다시 돌려 통과했다고 주장하지 않으며, 누락 자료 검증 한계는 남아 있다.

제공자 호출·추가 비용은 없다. [전체 자료](diagnostic-evidence.tar.gz), SHA-256 `c5707e9505196b239071020757610606971d8bf3cd57e51d18f5cdf9e0c8fa00`. 완전한 공개 팩 바이트는 보존했고 작업공간·개인 다운로드 경로는 진단 텍스트에서 자리표시자로 치환했다. 원본·내보낸 자료 해시는 구분해 기록했다.
