# 중첩 별칭의 적용 범위: DATA 수정 보류

두 읽기 전용 검사에서 별칭의 발생 위치와 소유 대상을 구분해야 하는 런타임 문제를 확인했다. 데이터·벡터·검색 코드를 수정하지 않았다.

## 역삼각 체형의 자기 제외

1,496개 프로필의 선언된 exact_terms 3,609개 중 하나의 명백한 자기 충돌을 찾았다. inverted triangle body shape는 자신의 triangle body shape 제외어에 걸린다. 성인 맥락을 제공한 실제 소비자에서도 context_mismatch/request_exclusion이며, 다른 유효 별칭 adult inverted triangle figure는 필수 자격을 유지한다.

23개 사례와 세 인메모리 대조에서 제외어를 삭제하거나 더 좁은 문구로 바꾸면 유효 별칭이 살아나지만, 단독 triangle body shape도 역삼각 선택 후보가 되고 두 체형 명칭을 혼합한 요청이 필수 자격을 얻는다. 현재 성분 규칙은 정확 별칭이나 의미 검색의 이 변화를 방지하지 못한다. 따라서 인기 별칭을 지우거나 제외어를 임의로 줄이지 않았다.

## 같은 얼굴에 겹치는 서로 다른 비율

정확/용어집 조회 3,624개에는 정규화 후 같은 문자열의 중복이 없었다. 포함 관계의 별칭은 26개 프로필 쌍·30개 문구에서 여러 필수 결과를 만들지만 대부분 상호 보완적이다. 의상·갑옷·유령의 의심 사례도 실제 코어 맥락 조건을 적용하면 분리된다.

남은 사례는 long square face shape 및 대응하는 한국어/중국어 표현이다. 같은 얼굴에 길이와 폭이 비슷해야 한다는 정사각 계약과 길이가 확실히 더 길어야 한다는 직사각 계약이 함께 필수로 활성화된다. 각각의 의미는 타당하지만 중첩 문자열 매칭이 이를 함께 적용한다.

## 보류 이유

긴 유효 별칭 안에 포함된 짧은 문구와 독립적으로 언급된 반대 명칭을 구분해야 한다. 전역에서 가장 긴 문구 하나만 남기는 방식도 독립 명칭이나 서로 다른 소유 대상을 잃을 수 있다. 정상 단독 명칭을 삭제하거나 예외 문구 목록을 늘리는 DATA 수정은 하지 않았다. 후속 런타임 설계와 동일/별도 소유 대상 대조가 필요한 항목이다.

실제 resolver·성분·의무 투영의 진단이며 새로운 공개 CLI 전후 평가나 이미지 실패 증명이 아니다. 첫 검사는 진짜 BM25F 소비자를 포함하고, 두 번째 포함 관계 검사는 제공자 없이 exact-only 조회와 실제 맥락 투영을 사용했다. 유료 호출·가짜 벡터·저장소 수정은 0회다.
