# 독립 이미지 비교 계획 — NOT_RUN

아직 이미지 생성·픽셀 평가는 실행하지 않았다. 연구자의 정확한 카드 문장은 테스트 구도를 제안할 수 있지만 독립 authorial baseline의 입력이 될 수 없다. 비용·생성 도구·후속 범위가 정해졌을 때 아래 비교를 실행한다.

## 비교 설계

첫 12장면군×3 arm, 총 36장이다. 관계와 표현 강도가 서로 다른 군을 모두 한 평균으로 감추지 않는다.

- A: 요청과 중립 creative controls만 읽고 작성·봉인한 독립 baseline. candidate 접근 없음.
- B: 같은 baseline에서 기존 installed 세대의 후보를 선택한 결과.
- C: 같은 baseline에서 데이터만 보강한 staged 세대의 후보를 선택한 결과.

동일 요청·seed(도구가 지원하면)·모델 버전·해상도·reference·core·control을 유지하고 B/C 검색 세대만 바꾼다. 도구가 이미지 seed를 지원하지 않으면 그 불일치를 기록한다. 검색 평가 seed와 이미지 생성 seed를 혼동하지 않는다. 1회씩의 탐색 비교는 인과적·통계적 품질 향상을 증명하지 못하므로 차이가 불안정한 핵심 군만 후속 반복한다.

|군|필수 관찰|대표 실패|
|---|---|---|
|01 열쇠/거울|한 열쇠·다른 손의 소유자·실물/반사 대응|여분 손·두 열쇠·거울 속 새 사람|
|02 만찬|별도 좌석과 식기·은기 홈/돌출부·관찰자 시야|공석을 살해로 진단·소품 융합|
|03 수집/출입|자연물/제작물/도구의 구분·통행선|인물을 전시물로 변경·관계 없는 잡동사니|
|04 목격|보이는 단편과 실제 가림 범위|프레임 밖 행위를 보였다고 채점|
|05 저장/식사|닫힌 덮개·과일·용기·메뉴 매체|숨은 음식의 재료·식인 발명|
|06 전달/기록|한 가보·양손 접점·기명 표기|세 손·물건 복제·판독 불가 글을 읽음|
|07 무대|공연 경계·보철 이음선·실제 연기자 피부|무대만 보이고 보철 경계 없음|
|08 분리 결과|대응 신체 부분·양 끝점·간격·소유자|크롭/가림을 절단이라고 통과|
|09 피부/천|같은 몸의 피부 경계·별도 직물 소유자|천과 피부가 같은 층으로 융합|
|10 내부 구조|공동·내부 구조·선택된 연결 또는 분리|적출과 돌출 혼합·음식으로 대체|
|11 융합|구별되는 두 몸·공통 조직·정상적 소유자 추적|포옹만 있음·설명 못 하는 여분 사지|
|12 매체|선택한 조각/밀랍/정물 매체와 받침/패널|청동·밀랍이 실제 손상된 사람으로 변경|

군12는 한 프레임에서 충분히 읽힐 한두 매체만 요청한다. 모든 박물관 소품을 넣는 장식 밀도 시험으로 만들지 않는다. 08–11도 주관계가 크게 읽히도록 독립 구도를 정하며 접점을 숨겨 통과시키지 않는다.

## 채점과 증거

선택한 exact CID/RID·긍정 원문·실제 최종 프롬프트 인용 구간·생성 parameters·반환 이미지 경로/hash·generation·receipt를 보존한다. 최종 프롬프트가 요청과 gate를 언급했다고 픽셀 성공으로 판정하지 않는다.

관계별 `visible / partial / unobservable / contradicted`를 기록한다. 양 끝점·연속 경계가 필수인 관계는 일부만 보이면 완전 통과가 아니다. `UNOBSERVABLE_NOT_PASS`와 `partial_is_fail`을 유지한다. 결과를 다음 층으로 나눈다.

1. 입력/계약 fidelity: 요청 의미·고정 제약·선택 후보의 실제 의미가 유지됐는가.
2. 관계 fidelity: 물건 수·몸 소유자·매체·접점·연결/분리·현재 상태가 픽셀에 보이는가.
3. 장면 이해: 키워드 설명을 가린 상태에서 행동·시선·반응·사물이 같은 상황으로 읽히는가. 긴 서사 주장과 구별한다.
4. 미감: 초점 위계·인물의 존재감·색/재질·정보 밀도·장르 비중이 의도와 맞는가. gate fidelity와 따로 보고한다.
5. 사용자 선호/수용: 외부 평가자의 심사이며 agent가 대신 승인하지 않는다.

프록시만 보이는 장면에서 학대·성적 동의·가스라이팅·혈연·식인 재료·인피 진위·진단·관객 감정을 픽셀 통과로 판정하지 않는다. 해당 의미가 명시된 요청이면 텍스트/서사 fidelity에 보존됐는지를 별도로 확인한다. 소품이 그것의 완전한 대체는 아니다.

정책 차단은 `BLOCKED_UNSCORED`, 생성 오류는 `GENERATION_ERROR`, 픽셀이 반환되지 않으면 `NOT_OBSERVED`다. 이를 이미지 품질 실패·성공 점수에 합산하지 않는다. 차단을 통과시키려고 원래 요청을 몰래 다른 사건으로 바꿔 동등 arm으로 세지 않는다.

첫 36장 이후에는 원인별 오류를 분석하고 영향이 확인된 필수 군만 재시험한다. 전체 데이터·검색·픽셀·미감 중 어디까지 확인했는지 상태를 나눠 남긴다. 실패한 군의 데이터는 전체 평균이 좋아도 HOLD다.
