# 원 대화의 작품 조합 사례와 활용 범위

원 대화 15번째 범주의 13사례를 보존한 표다. 작품 원본·영상·스크린샷을 직접 감상하거나 시각 디자인을 검증한 목록이 아니다. 본문 소개를 확인한 작품도 공식 소개가 뒷받침하는 개념 범위만 사용한다. 아래 선택적 방향은 새 장면을 위한 연구자의 제안이며 원작 장면의 역설계가 아니다.

|작품|이번에 확인한 범위|데이터에 유용한 분리|선택적 방향과 남는 문맥|
|---|---|---|---|
|카구야 님은 고백받고 싶어|VIZ 공식 소개 S16|고백 경쟁과 실제 대화/전달 동작|A01·W07; 심리전·상호 감정은 C06|
|역시 내 청춘 러브코메디는 잘못됐다|TBS 공식 소개 S17|봉사부의 문제 접수·학교 관계·작품 속 프롬|R01·A10·R08; 인기·고립·관계 변화는 별도|
|빙과|참조 대화 S00; Lantis 페이지 이번 독립 확인 안 함|일상 수수께끼와 범죄/초자연의 구분을 검토할 후속 사례|S06·S10의 활동 단서 제안; 특정 사건과 의복은 채택 보류|
|블루 피리어드|원 대화; Kodansha 접근은 점검 페이지로 실패 S24|미술 작업·평가와 재능/입시 제도의 구분|S09·R05의 원작 없는 작업 제안; 원작 고증 근거로 쓰지 않음|
|약한영웅|참조 대화 S00; NAVER 원자료 이번 독립 확인 안 함|현재 갈등 동작과 학교 서열·전술 이력의 구분|H01·H02; 캐릭터·싸움 방식 원작 사실은 보류|
|여고괴담 시리즈|KOFIC 공식 검색 색인 S23; 본문 시간초과|학교 공간과 제도적 공포의 구분|S14·H05·H08의 독창적 장면; 실제 영화 장면 재현 근거 아님|
|해리 포터|공식 Hogwarts 항목 S18|마법 교육 공간과 판본별 고유 설정|F01·F06은 원작 없는 창작 학교; 고유 기숙사·캐릭터 자동 부여 금지|
|어떤 과학의 초전자포|참조 대화 S00; Seven Seas 시리즈 원자료 이번 독립 확인 안 함|교육도시·능력 등급·치안 권한을 별도 검토할 사례|F03·F08은 일반 창작 제안; 설정의 세부 채택은 보류|
|어서 오세요 실력지상주의 교실에|Seven Seas 공식 소개 S21|포인트·학급 경쟁이라는 특정 창작 제도|F04; 숫자 표시와 돈/권리/객관 능력을 분리|
|단간론파|Spike Chunsoft 공식 소개 S19|학교 봉쇄·수사·mock trial이라는 특정 게임 구조|F07·H04; 일반 학급회의와 구분하고 원작 외형을 강제하지 않음|
|지금 우리 학교는|Netflix 공식 발표 S20|학교 봉쇄와 좀비 위기의 창작 원인|H04의 현재 구조; 실제 감염·질병 진단과는 별도|
|헤더스|참조 대화 S00; BFI 원자료 이번 독립 확인 안 함|인기 집단과 블랙코미디·폭력의 서사 관계를 검토할 사례|R08의 현재 거리 표현; 인물 도덕·풍자 의도는 보류|
|비밀의 계절 / The Secret History|Penguin의 Dark Academia 해설 S22|교육기관·지식 추구·비밀의 서사, 소품 외형의 구분|S10의 독서 공간; 범죄·엘리트주의·도덕적 타락은 문맥|

원작명을 긍정 후보의 스타일 약어로 넣기보다 필요한 구체 활동·구조를 분리해 작성한다. 특정 작품 재현 요청에는 해당 매체·판본·장면의 별도 근거가 필요하다.
