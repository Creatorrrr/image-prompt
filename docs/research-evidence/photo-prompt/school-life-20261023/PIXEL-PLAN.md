# 원본 픽셀 비교 계획

상태: **NOT_RUN**. 이미지 호출·픽셀 리뷰·사용자 평가는 수행하지 않았다. 아래는 후속 통합의 첫 비교 실험 12사례 × 3 arms = 36장 제안이다.

## 공통 설계

- A: 후보를 보지 않고 독립적으로 해석해 고정한 requester meaning/core. 후보 보강 없음.
- B: 동일 core·잠금·controls에서 현재 corpus가 제공한 실제 적합 후보를 선택해 보강.
- C: 동일 core·잠금·controls에서 새 corpus가 제공한 실제 적합 후보를 선택해 보강.
- 연구의 관계 그래프를 원래 사용자가 요구한 의미처럼 A에 몰래 넣지 않는다. 아래 testcase에서 평가할 구조는 실험 requester brief에 사전 명시하고 그 범위에서 세 arm을 비교한다.
- source·CID/RID·role·전체 선택 의무·입력/최종 프롬프트·모델/설정·시각 gate를 생성 전에 고정한다. 가능한 동일 설정/seed 지원 여부를 기록하고 단일 stochastic 출력으로 인과 개선을 확정하지 않는다.
- 사람을 쓰는 실험은 인원·역할·연령을 미리 명확히 정한다. 비선정적인 성인 교육기관 또는 명시한 성인 재연 장면을 사용할 수 있으며, 그 결과를 실제 청소년 학교생활의 고증·연령 재현 증거로 확대하지 않는다. 학생 성적 묘사·피해 이미지·자해 실행은 실험하지 않는다.
- 전체 장면 하나에 진단에 필요한 접점이 충분히 크게 보여야 한다. 접점마다 별도 이미지나 crop이 좋아 보여도 전체 scene의 필수 동시 관계가 없으면 성공으로 합치지 않는다.

세일러 칼라 W01·블레이저 W03·결계 F05는 후속 추가 묶음이다. 첫 36장에 포함되었다고 세지 않는다. 이 계획을 실제 실행할 때는 각 requester brief의 인물 수와 owner inventory, 선택 뷰까지 먼저 고정한다.

## 판정과 기록

기술 gate는 필수 성분·같은 소유자·관계 양끝·지지·개수·매체 층위·뷰 가시성·잠금 보존이다. `PASS`, `FAIL`, `UNOBSERVABLE_NOT_PASS`, `BLOCKED_UNSCORED`, `NOT_RUN`을 구분한다. 조건 하나라도 필수인데 실패/가림이면 전체 성공은 아니다(`partial_is_fail`). 차단에는 반환 이미지가 없으며 픽셀 실패나 성공을 부여하지 않는다.

장면 품질은 별도로 가독성·시선 흐름·동작 자연스러움·공간 일관성·장식 과잉·요청 맥락 전달을 평가한다. 기술 접점을 확대해 전체 장면을 훼손한 경우를 시각 품질 개선으로 보고하지 않는다. 사용자 수용은 `not_yet_received`에서 시작해 별도로 기록한다.

각 이미지에 원본 파일과 SHA·해상도·provider/model·생성 시각·설정·arm·실제 선택 source/역할/의무·프롬프트·실패/차단 상태·원본 리뷰·필요 시 crop을 보존한다. crop은 원본 증거를 보조하며 별도 생성물이 아니다. 반복성·성격·지향·동의·질병·소리·시간 반복은 기술 gate에서 통과시킬 수 없다.

후속 C에서 새 후보의 실제 노출·선택이 없으면 해당 pair는 데이터 변화의 효과를 평가할 수 없다. 변화가 있더라도 12사례 각 한 번의 출력은 탐색적 비교다. 영향이 보인 family에만 동일 조건 추가 반복을 계획하고 전체 210개 용어의 검증으로 확대하지 않는다.
