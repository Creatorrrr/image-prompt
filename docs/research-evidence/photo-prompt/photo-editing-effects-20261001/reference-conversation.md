## 1. 사진 전체의 스타일·표현 방향

이 범주는 구체적인 슬라이더보다는 **사진을 어떤 방식으로 보여줄 것인가**에 가깝습니다.

| 용어 | 의미·표현 방향 |
|---|---|
| **Natural / 내추럴** | 색, 피부, 명암이 실제로 보았을 때와 크게 어긋나지 않는 자연스러운 표현. |
| **Clean edit / 클린 보정** | 눈에 띄는 효과보다 노출·색 균형·잡티 등을 정돈한 깔끔한 보정. |
| **Candid / 캔디드** | 의도적인 포즈보다 자연스러운 행동과 순간을 포착하는 접근. |
| **Snapshot / 스냅사진** | 일상에서 빠르게 찍은 듯한 즉흥적인 프레이밍과 현장감. |
| **Documentary / 다큐멘터리** | 사건, 사람, 장소를 기록하고 상황을 전달하는 접근. 특정 색감의 이름은 아님. |
| **Lifestyle / 라이프스타일** | 생활 공간과 행동 속에서 인물이나 제품을 보여주는 방식. 연출 촬영도 포함. |
| **Editorial / 에디토리얼** | 잡지·기사·기획의 이야기나 콘셉트를 전달하는 사진. |
| **Commercial / 커머셜** | 제품·서비스·브랜드의 판매와 홍보 목적에 맞춘 사진. |
| **Fine-art photography / 파인아트 사진** | 기록이나 상품 설명보다 작가의 표현과 해석을 중심에 둔 사진. |
| **Cinematic / 시네마틱** | 영화의 한 장면처럼 느껴지는 조명, 색 설계, 구도, 공간감. |
| **Painterly / 회화적** | 붓질이나 회화의 색면·명암·부드러운 형태를 연상시키는 표현. |
| **Surreal / 초현실적** | 현실에서 불가능하거나 낯선 관계를 만들어 꿈같은 장면을 구성. |
| **Abstract / 추상적** | 사물의 정체보다 형태, 선, 색, 질감, 반복을 강조. |

**에디토리얼·다큐멘터리·파인아트는 사진의 목적이나 접근 방식에 가까워서, 특정 필터 하나와 일대일로 대응하지 않습니다.** 반면 내추럴·클린·회화적 표현은 보정 결과를 설명하는 데도 사용됩니다. :chatgpt-content-reference{index="1"}

### 분위기를 묘사하는 표현

아래는 엄밀한 기능명보다 **원하는 인상을 전달하는 묘사어**로 읽는 편이 좋습니다.

| 용어 | 실무적으로 풀어 쓴 의미 |
|---|---|
| **Light and airy** | 밝고 가벼우며, 답답하지 않고 공기가 느껴지는 분위기. |
| **Dark and moody** | 어두운 톤과 그림자로 감정적이고 무게감 있는 분위기를 강조. |
| **Dreamy** | 부드러운 번짐이나 낮은 선명도 등으로 꿈속 같은 인상. |
| **Ethereal** | 가볍고 비현실적이며, 희미하게 빛나는 듯한 분위기. |
| **Nostalgic** | 과거의 기억이나 오래된 사진을 연상시키는 정서. |
| **Muted** | 색의 강도를 억제해 차분하게 만든 표현. |
| **Faded** | 시간이 지나 색과 대비가 옅어진 듯한 표현. |
| **Washed-out** | 색과 검정의 힘이 빠져 물에 씻긴 듯 희미한 표현. |
| **Matte look** | 검정이 깊게 내려가지 않고, 어두운 부분이 살짝 들린 듯한 톤. |
| **Gritty** | 거친 입자와 강한 질감, 불균일함을 살린 표현. |
| **Lo-fi** | 낮은 해상도나 노이즈, 불완전한 재현을 미감으로 사용하는 표현. |
| **Crisp** | 경계와 세부가 또렷하고 정돈된 인상. |
| **Glossy / Polished** | 매끈하고 정교하게 다듬어진 상업 화보 같은 인상. |
| **Raw / Unpolished** | 덜 다듬어진 현장감과 불완전함을 남기는 표현. 파일 형식인 RAW와는 별개. |

이런 표현은 하나의 정답이 없습니다. 예를 들어 `dreamy`는 부드러운 초점, 광채, 색감 등 서로 다른 방법으로 만들 수 있습니다. :chatgpt-content-reference{index="2"}

## 2. 밝기·명암·계조를 조절하는 용어

| 용어 | 무엇을 조절하는가 |
|---|---|
| **Exposure / 노출** | 이미지의 전반적인 밝기를 조절. |
| **Contrast / 대비** | 밝은 부분과 어두운 부분의 차이를 조절. |
| **Highlights / 하이라이트** | 밝은 영역의 표현을 조절. |
| **Shadows / 섀도** | 어두운 영역의 표현을 조절. |
| **Whites / 화이트** | 가장 밝은 쪽의 기준과 표현 범위를 조절. |
| **Blacks / 블랙** | 가장 어두운 쪽의 기준과 표현 범위를 조절. |
| **Levels / 레벨** | 검정점·흰색점·중간톤을 기준으로 명암 범위를 정리. |
| **Tone curve / 톤 커브** | 입력 밝기가 어떤 출력 밝기로 바뀔지 곡선으로 제어. |
| **S-curve / S자 커브** | 일반적으로 밝은 쪽을 올리고 어두운 쪽을 내려 대비를 강화하는 커브. |
| **Histogram / 히스토그램** | 이미지에 어떤 밝기의 픽셀이 얼마나 있는지 보여주는 분포도. |
| **Clipping / 클리핑** | 밝기나 색이 표현 한계에 도달해 서로 다른 값의 구분이 사라지는 현상. |
| **Highlight recovery / 하이라이트 복원** | 원본에 남아 있는 정보를 활용해 밝은 부분의 디테일을 되살리는 보정. |
| **Shadow recovery / 암부 복원** | 어두운 영역을 열어 남아 있는 디테일을 드러내는 보정. |

**Highlights와 Whites, Shadows와 Blacks는 같은 조절이 아닙니다.** 밝거나 어두운 영역 전반을 다루는 것과 양 끝의 기준을 다루는 것은 구분해야 합니다. 완전히 기록되지 않은 정보를 일반적인 노출 조절만으로 되살릴 수도 없습니다. :chatgpt-content-reference{index="3"}

### 명암 자체가 만드는 스타일

| 용어 | 눈에 보이는 특징 |
|---|---|
| **High-key / 하이키** | 밝은 톤이 화면의 큰 비중을 차지하는 구성. |
| **Low-key / 로키** | 어두운 톤이 큰 비중을 차지하고 일부 빛으로 형태를 드러내는 구성. |
| **Lifted blacks / 들린 검정** | 가장 어두운 부분을 완전한 검정보다 밝게 올린 표현. |
| **Crushed blacks / 뭉개진 암부** | 어두운 계조를 깊은 검정으로 몰아 디테일을 줄인 표현. |
| **Soft highlight roll-off** | 밝은 부분이 흰색으로 급격히 끊기지 않고 부드럽게 이어지는 표현. |
| **Tonal compression / 계조 압축** | 넓은 명암 차이를 더 좁은 범위 안에 담는 처리. |
| **Tone mapping / 톤 매핑** | 원본의 밝기 관계를 출력 가능한 밝기 범위로 재배치하는 처리. |

**하이키는 단순한 노출 과다, 로키는 단순한 노출 부족이 아닙니다.** 밝은 배경·어두운 배경, 조명, 피사체의 톤까지 포함한 의도적인 구성입니다. :chatgpt-content-reference{index="4"}

`HDR`도 구분해서 쓰는 것이 좋습니다. **HDR 병합**은 서로 다른 노출을 결합하는 과정, **HDR 출력**은 실제로 확장된 밝기 범위를 표시하는 것, **HDR풍 룩**은 강한 톤 매핑과 국부 대비를 연상시키는 스타일 표현입니다. HDR 자체가 과도한 채도나 선명도를 뜻하지는 않습니다. :chatgpt-content-reference{index="5"}

## 3. 색 보정의 기본 용어

| 용어 | 의미 |
|---|---|
| **White balance / 화이트 밸런스** | 흰색·회색 같은 중립색이 어떤 색으로 보일지 기준을 맞추는 조절. |
| **Temperature / 색온도 조절** | 편집에서 전체 색을 따뜻한 쪽이나 차가운 쪽으로 이동. |
| **Tint / 틴트** | 주로 초록과 마젠타 방향의 색 균형을 조절. |
| **Hue / 색상** | 빨강·노랑·초록처럼 색의 종류를 나타내는 속성. |
| **Saturation / 채도** | 색이 얼마나 강하고 선명하게 느껴지는지 조절. |
| **Vibrance / 생동감** | 대체로 채도가 낮은 색을 더 보강하고, 이미 강한 색은 상대적으로 덜 변화시키는 조절. |
| **Luminance / 휘도·밝기** | 특정 색이나 영역이 얼마나 밝게 보이는지 조절. |
| **HSL adjustment** | 색상·채도·밝기를 색상군별로 나누어 조절하는 방식. |
| **Color balance / 색 균형** | 색 성분의 비중을 조절해 전체 또는 특정 밝기 영역의 색을 바꿈. |
| **Color cast / 색 편향·색조 끼임** | 사진 전체나 일부에 초록빛·푸른빛 등 특정 색이 덮인 현상. |

Adobe 계열의 `Vibrance`는 피부색과 이미 채도가 높은 색의 과도한 변화를 줄이는 방향으로 작동하지만, 모든 프로그램이 같은 알고리즘을 사용하는 것은 아닙니다. :chatgpt-content-reference{index="6"}

### 색감과 컬러 그레이딩

| 용어 | 의미·표현 |

| **Teal and orange / 청록·주황 배색** | 청록 계열과 주황 계열의 대비를 중심으로 구성한 색감. |

| **Earthy tones / 어시 톤** | 흙·모래·나무·식물을 연상시키는 갈색·베이지·올리브 계열의 구성. |
| **Monochrome / 모노크롬** | 하나의 색 계열과 그 밝기 차이로 표현. 반드시 흑백만 뜻하지는 않음. |
| **Sepia / 세피아** | 갈색 계열로 통일한 단색조 표현. |
| **Duotone / 듀오톤** | 두 색을 중심으로 계조를 표현하는 방식. 인쇄에서는 두 잉크를 사용하는 의미도 있음. |
| **Gradient map / 그레이디언트 맵** | 이미지의 밝기 단계에 지정한 그라데이션의 색을 대응시킴. |
| **Color splash / 선택적 탈색** | 대부분을 흑백으로 바꾸고 일부 대상이나 색만 남기는 표현. |

색 교정과 그레이딩은 도구가 겹칠 수 있지만 목적이 다릅니다. 또 **Color splash와 Photoshop의 `Selective Color` 기능은 다른 개념**입니다. 후자는 특정 색상군의 성분을 조절하는 기능입니다. :chatgpt-content-reference{index="7"}

## 4. 조명 스타일과 관련된 용어

이 용어들은 원래 촬영 현장의 빛을 설명하지만, 리라이팅이나 이미지 생성에서도 중요한 표현입니다.

| 용어 | 눈에 보이는 특징 |
|---|---|
| **Soft light / 부드러운 빛** | 그림자 경계가 완만하고 명암이 부드럽게 이어짐. |
| **Hard light / 단단한 빛** | 그림자 경계가 날카롭고 형태와 질감이 강하게 드러남. |
| **Diffused light / 확산광** | 빛이 확산 재료 등을 거치며 퍼져 들어오는 조명. |
| **Direct flash / 직광 플래시** | 플래시를 직접 피사체에 비추는 방식. 강한 반사와 또렷한 그림자를 만들 수 있음. |
| **Bounce light / 반사광** | 벽·천장·반사판 등에 빛을 반사시켜 비추는 방식. |
| **Backlighting / 역광** | 피사체 뒤쪽에서 빛이 들어오는 배치. |
| **Side lighting / 측광** | 옆에서 빛이 들어와 얼굴이나 물체의 굴곡을 강조. |
| **Top lighting / 상부 조명** | 위쪽에서 내려오는 빛으로 눈썹·코·턱 아래에 그림자가 생김. |
| **Underlighting / 하부 조명** | 아래에서 올라오는 빛. 익숙한 얼굴의 명암 관계를 뒤집는 효과. |
| **Rembrandt lighting / 렘브란트 조명** | 어두운 쪽 뺨에 작은 삼각형의 빛이 남는 인물 조명. |
| **Silhouette / 실루엣** | 피사체 내부의 디테일보다는 어두운 외곽 형태를 중심으로 표현. |

**부드러운 빛과 흐릿한 초점은 다릅니다.** 피부의 그림자는 부드럽지만 눈과 머리카락은 선명한 사진도 가능합니다. :chatgpt-content-reference{index="8"}

## 5. 빛 번짐·렌즈·광학 효과

“빛이 번진다”는 표현을 세분화할 때 가장 유용한 용어들입니다.

| 용어 | 의미·보이는 결과 |
|---|---|
| **Bloom / 블룸** | 밝은 광원이나 하이라이트가 주변으로 부드럽게 퍼져 보이는 효과. |
| **Glow / 글로우** | 발광감·광채·부드러운 빛 번짐을 넓게 지칭하는 표현. |
| **Halation / 할레이션** | 필름 내부의 빛 반사 등에 의해 밝은 경계 주변에 생기는 번짐. 컬러 필름풍에서는 붉거나 주황색인 경우가 많음. |
| **Lens flare / 렌즈 플레어** | 강한 빛이 렌즈 내부에서 반사·산란하며 생기는 빛무리나 대비 저하. |
| **Veiling flare / 베일링 플레어** | 화면 위에 얇은 빛의 막이 덮인 듯 검정이 들리고 대비가 낮아지는 현상. |
| **Ghosting / 고스트** | 광학 문맥에서는 광원과 별개 위치에 나타나는 원·다각형 등의 유령상. |
| **Light leak / 빛샘** | 의도하지 않은 빛이 들어온 듯 프레임 일부에 밝은 띠나 색 얼룩이 생기는 표현. |
| **Starburst / 스타버스트** | 작은 밝은 광원에서 별 모양의 광선이 뻗는 표현. |
| **Anamorphic flare / 아나모픽 플레어** | 아나모픽 렌즈를 연상시키는 길고 수평적인 빛줄기 표현. |
| **Vignette / 비네트** | 화면 가장자리가 중앙보다 어두워지거나 밝아지는 효과. |
| **Chromatic aberration / 색수차** | 대비가 강한 경계에 색 테두리나 색 분리가 나타나는 광학적 오차. |
| **Diffusion-filter look / 확산 필터 룩** | 선명함을 어느 정도 유지하면서 밝은 부분의 번짐과 부드러운 대비를 더한 표현. |

특히 **Bloom은 밝은 부분의 확산, Halation은 필름 특유의 경계 번짐, Flare는 렌즈에 들어온 빛의 반사·산란 현상**이라는 차이가 있습니다. 이들은 한 사진에 동시에 나타날 수 있습니다. :chatgpt-content-reference{index="9"}

비네트는 밝기 분포의 효과이고, 색수차는 색 성분의 어긋남입니다. 둘 다 렌즈의 불완전함을 제거하는 보정 대상이 되기도 하고, 의도적으로 더하는 스타일 요소가 되기도 합니다. :chatgpt-content-reference{index="10"}

## 6. 초점·심도·블러

| 용어 | 의미 |
|---|---|
| **Depth of field / 피사계 심도** | 사진에서 선명하게 보이는 거리 범위. |
| **Shallow depth of field / 얕은 심도** | 초점이 맞은 좁은 거리 범위만 선명하고 앞뒤는 흐려지는 표현. |
| **Deep focus / 깊은 초점** | 가까운 곳부터 먼 곳까지 넓은 범위가 선명한 표현. |
| **Defocus / 디포커스** | 초점이 맞지 않아 생기는 흐림. |
| **Bokeh / 보케** | 초점 밖 영역이 흐려지는 모양과 질적 특성. 동그란 빛망울만 뜻하지 않음. |
| **Selective focus / 선택적 초점** | 특정 대상이나 부분만 선명하게 보여 시선을 유도. |
| **Soft focus / 소프트 포커스** | 부드러운 번짐을 더해 윤곽과 피부를 유연하게 표현. |
| **Gaussian blur / 가우시안 블러** | 주변 픽셀을 가중 평균하는 방식의 흐림 처리. |
| **Lens blur / 렌즈 블러** | 광학적인 초점 흐림과 조리개 형태 등을 모사하는 블러. |
| **Tilt-shift miniature effect** | 일부 띠 모양 영역만 선명하게 남겨 실제 풍경을 미니어처처럼 보이게 하는 효과. |
| **Orton effect / 오턴 효과** | 선명한 이미지와 흐린 이미지를 겹쳐 부드러운 광채와 회화적인 느낌을 만드는 기법. |

**Bokeh는 흐림의 ‘모양과 성질’, Blur는 흐림 자체를 가리키는 더 넓은 말**입니다. 또한 디지털 미니어처 효과는 실제 틸트·시프트 렌즈가 할 수 있는 모든 기능과 같은 것은 아닙니다. :chatgpt-content-reference{index="11"}

### 움직임·시간을 표현하는 용어

| 용어 | 의미·보이는 결과 |
|---|---|
| **Motion blur / 모션 블러** | 피사체나 카메라의 움직임이 방향성 있는 흐림으로 기록된 표현. |
| **Long exposure / 장노출** | 긴 시간 동안 빛을 기록해 움직임과 시간의 누적을 보여주는 촬영. |
| **Light trails / 빛 궤적** | 차량·손전등 등의 이동이 연속적인 빛줄기로 남는 표현. |
| **Panning / 패닝** | 움직이는 피사체를 따라 카메라를 움직여 배경이 흐르도록 표현. |

| **Spin blur / 회전 블러** | 바퀴처럼 회전하는 움직임을 모사하는 흐림. |
| **Slow-sync flash / 슬로싱크 플래시** | 비교적 긴 노출로 주변광과 움직임을 기록하면서 플래시로 피사체의 한순간을 더하는 방식. |
| **Shutter drag / 셔터 드래그** | 플래시와 함께 셔터를 길게 열어 주변광이나 움직임을 강조하는 표현. |

이 범주에는 **촬영 기법과 편집 효과가 섞여 있습니다.** 결과가 비슷해도 실제 시간과 움직임을 기록한 것인지, 후처리로 만들어낸 것인지는 구분할 수 있습니다. :chatgpt-content-reference{index="12"}

## 7. 필름·아날로그·카메라 매체의 인상을 나타내는 용어

**필름 그레인과 디지털 노이즈는 원인이 다릅니다.** 또한 노이즈·먼지·스크래치 같은 결함도 제거 대상인 동시에 의도적인 스타일 요소로 사용될 수 있습니다. :chatgpt-content-reference{index="16"}

## 10. 프레이밍·기하 보정·형태 변형
