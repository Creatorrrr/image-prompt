# 검색·의미 회귀 평가 계획

모든 사례는 NOT_RUN이다. [evaluation-cases.json](evaluation-cases.json)이 기대 의미·금지 추론까지 포함하는 정본이며 TSV는 질의 목록이다.

| 분할 | 사례 | 한영 질의 | 목적 |
|---|---:|---:|---|
| source_literal_smoke | 138 | 276 | 원문 발견·ID/소스 연결의 기본 확인. 의미 검색 성능 평가로 사용하지 않음 |
| natural_regression | 24 | 48 | 다른 문장으로 손/장치/의복/반사 관계를 질의 |
| boundary | 20 | 40 | 포즈-카메라, 자기-상대, 리그-방호, 직물-섬유, 화면-실물 등의 혼동 |
| ordinary_control | 12 | 24 | financial asset, 동물 mole, book cover, wispy, 일반 통근·파티·여행 등의 문맥 오염 |
| nonvisual_control | 12 | 24 | 성적 유인·동의·고문·암살·실종 등 비가시 서사를 자동 외형으로 바꾸는지 확인 |

독립적인 외부 작성 holdout은 PENDING이다. 자연어 회귀 사례도 카드 작성자가 작성했으므로 성능 추정의 독립 표본으로 부르지 않는다. 구현자가 기존 holdout을 변경해야 한다면 기존 버전을 보존하고 별도 버전으로 동결한다.

각 질의를 기존 설치본과 신규 staging에 실행하고 실제 source/realization ID를 연결한다. 추상적인 연구 카드 ID가 top8에 있다는 식으로 보고하지 않는다. 같은 의미를 가진 기존 소스와 신규 대안은 모두 허용 목표로 사전 판정한다.

저장할 것: query 원문·언어·topic/baseline/slot 구분, core/locks 및 config hash, source/index/generation identity, BM25F/embedding/RRF의 실제 순위·score, source 조건/전체 효과, candidate 제시·선택·기각 이유. 설치본에 없는 연구 데이터를 이용한 수동 정답 주입은 금지한다.

사전 목표는 자연어 핵심 24사례에서 한영 각각 적합한 완전 실현의 top8 노출 ≥ 85%다. 24개 중 어느 언어에서 몇 개가 통과했는지 분모와 함께 보고하고 baseline 대비 차이를 별도로 적는다. 이 수치는 제안 목표이며 관찰 결과가 아니다.

경계/대조에서는 요청하지 않은 소유자 이동, 무기·성적 의미·비가시 효능의 **hard activation 0건**을 목표로 한다. 같은 장갑이나 코트가 일반 요청에 검색되는 것은 오탐으로 바로 세지 않는다. 소스의 전체 뜻과 채택 결과를 검토한다. 거짓으로 ‘무흔적’, ‘혼인’, ‘방탄’, ‘이중간첩’이 확정되면 실패다.

주요 회귀 쌍:

- 돌아보는 배우 / 다른 어깨 뒤의 카메라 / 허벅지까지의 초상 크롭.
- 귀에 착용한 장치 접촉 / 귀 옆에 든 수화기 / 입 옆으로 이어진 마이크 붐.
- 자기 커프 / 상대 타이 / 피팅 작업의 전제.
- 손에서 손으로 전달 / 아직 닿지 않은 빈틈 / 사람이 없는 보관 / 여러 시점의 회수.
- 실크 섬유 / 새틴형 광택 / PVC·라텍스의 화학 성분.
- 마감된 트임 / 찢긴 천 / 망사 패널 / 열린 개구.
- 수납 패널 / 판 수납 외피 / 숨은 판 / 실제 방호 성능.
- 반지 착용 / 혼인, 수갑 연결 / 고문, 사진 제시 / 협박·진위.

기존 source 조건을 만족하지 못한 실패를 검색 순위 조정으로 덮지 않는다. 선택한 대안의 각 효과가 잠긴 요청을 침해하면 retrieval 성공과 무관하게 adoption 실패로 기록한다.
