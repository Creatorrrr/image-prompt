# 저장 이미지 검증 계획

현재 생성 0장, 호출 0회, 전 사례 NOT_RUN. 사용자 요청은 리서치와 반영 계획이므로 실제 생성은 이 단계의 완료 조건이 아니다.

초기 비교는 12개 장면 × baseline/stage 2조건 = 24장으로 제안한다. 추가 반복은 실패 유형과 질문이 생겼을 때 별도로 설계한다. 사후에 성공할 때까지 반복한 결과를 최초 결과로 바꾸지 않는다.

| 장면 | 같이 보여야 하는 핵심 | 실패 예 |
|---|---|---|
| 두 사람의 봉투 직접 전달 | 독립 두 손, 같은 봉투 양 끝 | 손의 소유자 합침, 봉투 둘 |
| 아직 닿지 않은 전달 | 소유자의 쥔 손, 상대 빈손, 물리적 틈 | 전달이 이미 끝남 |
| 착용 이어피스 접촉 | 같은 몸의 귀·장치·손끝 | 전화기나 귀 긁기로 대체 |
| 수화기 청취 | 같은 사람 귀/입, 수화기 양 끝, 손 | 얼굴을 관통하는 기기 |
| 거울로 뒤의 사람 관찰 | 실물·거울 테두리·반사상·시선 | 반사상이 별도 실물로 증식 |
| 자기 커프 정리 | 서로 다른 두 손, 같은 착용자의 반대 커프 | 타인의 소매 또는 세 손 |
| 상대 타이 정리 | 행위자 손과 타인 매듭/칼라 | 자기 타이로 바뀜 |
| 부축 | 어깨에 놓인 팔, 옆몸 받침, 지지 | 접점 없는 포옹, 떠 있는 몸 |
| 트렌치 부품 | 선택한 견장·플랩·벨트 고리 경로 | 조각만 보이고 연결이 없음 |
| 스타킹 스트랩 | 허리-스트랩-클립-스타킹, 동일 착용자 | 떠 있는 클립, 레이어 소유자 전환 |
| 망사와 개구 | 미세 조직, 의복과 양 끝 솔기 | 망사가 사라지고 피부가 됨 |
| 수갑 연결 | 성인 한 명의 두 손목, 수갑, 사슬 양 끝 | 손목 밖 고리, 연결 없는 사슬 |

각 요청에서 실제 필요한 의미만 core/lock으로 고정하고 후보가 제안한 장면의 우연한 색·장소·손잡이를 requester-owned 제약으로 격상하지 않는다. baseline/stage는 같은 요청과 창작 제어값을 사용한다. 후보 사용이 필요한 차이는 selection/comparison에 기록한다. 모델·종횡비·참조·지원되는 seed 등 실제 파라미터를 기록하고 통제 불가능한 항목을 표시한다.

평가는 (1) requester 의미 (2) 선택한 전체 후보 관계 (3) 읽히는 장면/시각적 위계를 분리한다. 핵심 접점은 저장된 원본 크기에서 전부 관찰되어야 한다. 확대 크롭은 확인 보조물이며 원본에서 보이지 않던 구조를 만들어내지 않는다. thumbnail에서 주 사건을 읽을 수 있는지도 별도 기록한다.

부분 충족은 partial_is_fail, 작거나 가려져 판단 불가한 핵심은 UNOBSERVABLE_NOT_PASS다. moderation/provider block은 BLOCKED_UNSCORED이며 품질 0점 이미지가 아니다. 패드 암호 보안, 방탄 성능, 동의, 배신, 녹음된 말, 이후 탈출 성공 같은 비가시 주장은 pixel gate에 넣지 않는다.

정확한 F-21·Steineck·스파이크·미세 점·판독 문서 등 10개 detail/specimen 항목은 우선 도판과 투영 계획을 검토한 뒤 별도 시험으로 추가한다. 확대 삽입을 사용하는 장면은 단일 촬영 공간과 확대 매체의 경계를 명시한다. 단일 사진으로 여러 시점을 증명하는 평가를 만들지 않는다.

각 조건의 prompt hash, 실제 전달 요청, reference hash, provider 결과·실패, 저장 파일 hash/형식/크기, 원본 pixel 판정, 누락 gate, 사용자 수용을 함께 보존한다. 프롬프트 audit PASS나 한 장면의 국소 성공을 전체 데이터의 이미지 qualification으로 부르지 않는다.
