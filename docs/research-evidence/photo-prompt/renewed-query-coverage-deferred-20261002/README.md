# 자연어 성분 검색과 스캐너 슬롯 수정 보류

## 얕은 심도: 높은 원시 순위가 실제 후보로 이어지지 않음

기준 `dbfd897ce20b5c7c21456af2234ec140e42676a9`에서 독립 작성한 완전한 자연어 양성 네 건(영어 2, 한국어 1, 혼합 1)을 검증했다. 실제 레지스트리에 묶인 인덱스를 사용하는 전체 소비자에서 필터 전 BM25F 대상 순위는 **5·1·3·1**이지만, 다섯 문장 단위 필수 성분 게이트를 통과하지 못해 대상 후보는 **0/4**다. 쿼리 벡터는 제공하지 않았으므로 임베딩 검색 품질을 측정한 결과가 아니다. 이 성분 게이트는 벡터 점수 계산 전에도 적용된다.

기존 의미에서 도출한 짧은 관계 단서 15개를 먼저 고정하고 별도 작성된 입력에 적용한 메모리 내 어휘 전용 시험도 **0/4**였다. 단서를 그대로 쓴 점검 문장은 후보가 됐지만, 같은 단서가 박물관 설명판의 글이고 실제 장면은 모두 선명해야 하는 음성 사례까지 받아들였다. 독립 음성 다섯 건과 성분 누락·제외·부정 점검은 계속 거절됐어도, 이것만으로 소유 대상 판정이 보존됐다고 할 수 없다. 테스트 문장을 추가하는 식으로 조정하지 않고 수정안을 보류했다.

동일한 온실 질의를 수정 없는 정상 공개 CLI에도 실행했다. 종료 코드 0이지만 전체 팩에서 대상 ID가 한 번도 나오지 않아 실제 선택 후보에도 없음을 확인했다. 원본 요청을 보존했고 작성 코어의 일반적인 부정 명령만 같은 의미의 양성 표현으로 작성했다. 후보나 ID를 입력에 주입하지 않았다.

제안 시험의 벡터는 생성하지 않았다. 실제 빌더에 벡터를 주지 않아 빈 벡터를 가진 어휘 전용 자료를 만들었고, 기본 차원 메타데이터가 768로 남는다는 사실도 원본 보고서에 명시했다. 이를 실제 새 운영 인덱스나 임베딩 개선으로 취급하지 않는다. 기존 캡처 테스트 8개가 통과해도 이 네 자연어 사례의 재현율을 보증하지 않는다.

이 결과는 **시도한 짧은 단서 수정의 기각**이지 모든 데이터 전용 방법이 불가능하다는 증명은 아니다. 자연어 관계·대상·부정 범위를 보존하는 별도 설계 없이는 단어를 늘리는 것만으로 검색 이득을 주장하기 어렵다.

## 스캐너 시점: 원래 의도 불명확

scanner_platen_topdown 행에서 광학 스캐너의 아래쪽 센서 시점과 외부 카메라의 상단 촬영을 혼동할 가능성을 조사했다. 하지만 원래 preset은 일반 렌즈와 top_down 구도도 선택해 외부 촬영 미학일 수 있었다. 출처만으로 시점을 뒤집을 근거가 충분하지 않아 보류했다. 같은 질의 여섯 건의 실제 전체 후보 수용 ID는 같고, 장치 시점 행은 최종 64개 팩에 들어오지 않아 내부 순위 개선만으로 사용자 이득을 주장하지 않았다.

두 진단 모두 저장소 데이터·런타임을 바꾸지 않았고 제공자 호출·비용은 0이다. [전체 증거](diagnostic-evidence.tar.gz), SHA-256 `0f094283e75f09a32eead859803b438ef86d530af0dc64ca2705803137c0e394`. 동결 제안/독립 질의·실제 기준 인덱스 결과·어휘 전용 시험·정상 공개 팩을 구분해 포함한다. 실행 환경 경로는 자리표시자로 치환했고 내보낸 파일 해시는 별도로 기록했다.
