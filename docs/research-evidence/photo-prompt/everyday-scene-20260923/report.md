# 일상 장면 시각 의미·후보팩 데이터 보강 연구

후속 운영 데이터 반영과 3개 이미지 실험 결과는 [구현·검증 보고서](implementation-report.md)에 기록한다. 아래의 `연구 단계`와 `미실행` 표기는 이 보고서를 작성한 시점의 상태다.

조사 기준: 2026-09-23. 원자료는 ChatGPT 대화 **「일상 요소 조사」** (`6ab366b2-2858-83ee-a2f6-d1abee5ac437`)의 장소·행동·배경·소품 등 20개 범주다. 대화는 조사 범위를 정하는 **비검증 입력**이며, 그 안의 `:chatgpt-content-reference` 표시는 이 연구의 출처로 취급하지 않았다. 외부 1차 자료와 현재 저장소 데이터를 별도로 확인했다.

핵심 결론은 단어 사전을 크게 늘리는 것보다 **장소의 기능 → 사람이 그곳에서 하는 일 → 손·몸·도구·대상 사이의 관계 → 직전/직후를 암시하는 물체 상태**를 한 후보 단위로 묶는 편이 검증 가능하다는 것이다. `ordinary`, `candid`, `lived-in`, `mid-action`은 방향을 잡는 표현이지만 그 자체로 장면의 시각적 증거가 아니다. 이 결론은 데이터 설계 판단이며, 새 후보가 이미지 품질을 높인다는 실험 결과는 아니다.

산출물은 이 문서, [구조화 후보 20개](candidate-bundles.json), [경계·평가 명세](evaluation-cases.jsonl)다. 모두 **연구 단계**다. 운영 레지스트리·인덱스·후보팩 생성기의 데이터는 수정하지 않았고, 새 후보 노출·선택·렌더 성공은 아직 평가되지 않았다.

기준 체크아웃은 `e8dce9c6d8a3b930309c88b397dc81839296275f`다. 주요 원천 파일의 SHA-256은 `photo_prompt_tags.json`=`68be45078ded5eab669292f1597944427371c5460a33bf988bf4bc44a06281b9`, `photo_prompt_visual_obligations.json`=`a878e059c8a67329bbbbe01da8f37a42e517aceb90970f9a25ff68fa4fb07ca8`, 현실적 배경 확장=`d014e3b3b692cb312e978ba79c50b1258a257715fcb5ed115f20389d90689520`, 실사 요소 확장=`baa8c742cb4f5f41bf9b3da058314b5ef5ed8b8aa5d67200f1f9253c3940d48c`다. 이후 운영 파일이 바뀌면 아래 개수와 재사용 ID를 다시 확인해야 한다.

## 2. 현재 저장소와 중복 경계

2026-09-23 읽기 전용 점검에서 `photo_prompt_tags.json`은 575개 프리셋과 111개 슬롯을 갖고 있었다. `action` 516개, `location` 576개, `prop` 559개에 비해 `situation_context`는 38개다. 수량 차이는 곧 결함률이 아니다. 다만 단일 행동·장소·소품 후보보다 **이 셋의 맞물림**을 명시하는 데이터가 드물 수 있다는 조사 신호다.

이미 `daily_routine_photodump`, `commute_transit_candid`, `lived_in_room_reset`, `local_shop_bts_documentary`, `cafe_window_35mm_candid`, `grocery_run_two_baskets_candid` 같은 프리셋이 있다. 이들은 폭넓은 아이디어 경로이며, 모든 필터 조합의 시간·장소·행동·소품 양립을 자동으로 입증하지 않는다. 예를 들어 `grocery_run_two_baskets_candid` 필터에는 식료품 통로와 `walking_rain` 행동이 함께 있다. 필터의 동시 존재는 실제 후보팩에서 그 조합이 선택되었다는 증거가 아니지만, **장면 단위 양립성 검사**가 필요한 구체 사례다.

재사용할 좁은 계약도 이미 있다.

| 현재 프로필 | 재사용 범위 | 이번 제안에서 비어 있는 부분 |
|---|---|---|
| `pr_environmental_portrait_subject_place` | 인물·장소 설비·행동의 연결과 환경 가독성 | 대기→수령, 입장→퇴장 같은 장면의 **단계** |
| `pr_observed_action_trace` | 행동 주체·대상·접촉 경로·즉각적 결과 | 비교·교환·대기처럼 결과가 작거나 두 사람의 역할이 다른 사건의 구체 조건 |
| `rb_use_trace_affordance` | 사용 물체·작업면·손 닿는 범위·통로 | 특정 생활 사건의 **주체와 흔적의 동일성** |
| `rb_spatial_density_variation` | 작업 영역의 물체 밀도와 빈 통로 | 깨끗하고 정돈된 일상에서 물체 수를 늘리지 않는 선택 |
| `rb_clean_space_plausibility` | 청결한 공간의 접속·지지·재질 | 청소/정리 행동의 진행 단계와 결과 |
| `rb_foreground_occlusion`, `pr_casual_crop_subject_legibility` | 일관된 가림·크롭과 핵심 행동 가독성 | 모든 일상 장면에 우연한 가림을 기본으로 넣지 않는 조건 |
| `rb_local_motion_blur` | 실제 움직이는 부위에만 짧은 흐림 | 움직임이 없는 대기·휴식 장면을 선명하게 남기는 조건 |

특히 `pr_observed_action_trace`와 `rb_use_trace_affordance`를 새 이름으로 복제하지 않는다. 신규 hard 프로필 검토 대상은 기존 계약으로 표현할 수 없는 **서비스 동선, 비교 결정, 독립적인 배경 활동, 공유 물체를 통한 상호 반응** 같은 관계에 한정한다. 대부분의 예시는 기존 프로필과 새로운 **선택형 장면 묶음**으로 시작할 수 있다.

## 3. 참조 대화의 20개 범주를 데이터로 바꾸는 방법

| 대화의 요소 | 데이터 역할 | 픽셀에서 확인할 것 | 흔한 오인 |
|---|---|---|---|
| 장소·배경 | 기능을 가진 setting | 출입/주문/대기/작업의 설비와 동선 | 간판이나 장소 이름만 보임 |
| 행동·중간 순간·작은 사건 | 사건의 동사와 단계 | 손/몸의 대상, 접촉 또는 이동 경로, 상태 단서 | `mid-action`만 적고 정지 포즈 |
| 소품·생활 흔적·질감 | 대상·도구·결과 | 같은 인물/작업에 귀속된 물체 상태와 지지면 | 무작위 컵·얼룩·쓰레기 삽입 |
| 주변 사람·관계 | 별도 행위자 또는 수신자 | 각자의 목적, 동선, 시선/교환/반응 | 무관한 군중을 배경 장식으로 복제 |
| 시간·날씨·조명 | 사건의 조건 | 행동과 연결된 해·비·젖음·실내외 광역 | 밤이라는 말만 있고 낮 광질, 비가 없는데 젖은 우산 |
| 반사·가림·움직임·구도 | 선택형 촬영 표현 | 원본 물체·반사면·가림 기하·움직이는 부위 | 전역 블러·무작위 기울기·핵심 손 가림 |
| 자세·표정·`candid` | 시각적 관찰 스타일 | 작업에 맞는 몸의 하중·주의 방향·작은 반응 | 실제 비연출·심리 상태·사생활을 픽셀로 인증 |

대화의 최종 “장소+존재 이유+행동+중간 순간+흔적+주변 사람+배경+조명+구도” 공식은 **필수 항목 아홉 개**가 아니다. 요구된 장면에서 필요한 관계만 골라야 한다. 혼자 있는 사람, 정돈된 집, 맑은 날, 깨끗한 병원, 의도된 스튜디오 라이프스타일 사진도 유효하다. `clutter`, `rain`, `background people`, `tilt`, `grain`, `motion blur`는 각각 조건부 선택이다.

### 후보 데이터의 최소 단위

후보는 `setting_function`, `actor`, `action_phase`, `target_or_tool`, `visible_state`, `relation`, `optional_context`, `confusion_boundary`, `locked_dimensions`, `source_scope`를 갖는 **사건 관계**여야 한다. 한 장에서 보이지 않는 “버스가 늦었다”, “퇴근 후 피곤하다”, “생각에 잠겼다”는 원인/심리 확정 대신, 화면에 보이는 대기 위치·가방·정류장·휴대폰 확인처럼 관찰 가능한 기술로 바꾼다. 버스 지연이나 퇴근을 사실로 단정하려면 해당 정보가 요청 또는 별도 스토리 맥락에 있어야 한다.

선택 시 다음 조건을 순서대로 적용한다.

1. 요청자가 지정한 인물 수·관계·장소·행동·의상·시간·날씨·프레이밍을 먼저 동결한다. broad `everyday`만으로 hard 시각 의무를 만들지 않는다.
2. 후보의 장소 기능과 행동 단계가 사용자 의미에 맞고, 요구되는 차원이 실제로 열려 있을 때만 묶음을 노출한다.
3. 묶음 안에서는 `actor → action → target → resulting state`가 같은 사건·공간에 속해야 한다. 물체를 추가하려면 위치·지지·접촉·사용 목적을 함께 확인한다.
4. 기존 프로필이 관계를 정확히 덮으면 그 ID를 재사용한다. v6 관계형 후보를 선택하면 선택한 후보의 관계·구성요소 증거를 최종 프롬프트에 연결해야 한다. 함께 적힌 기존 `profile_id`가 자동으로 hard 권한을 얻지는 않는다. 요청 자체가 좁은 시각 의무를 분명히 정의한 경우의 hard 경로와, 선택형 후보의 opt-in 의무를 구분한다. 검색 hit나 유사도만으로 어느 쪽도 승격하지 않는다.
5. `candid`, `documentary`, `unaware of camera`는 픽셀에서 확인 가능한 관찰 거리/표정/행동으로 풀되 실제 촬영 이력·동의·인지 여부를 주장하지 않는다.

### 네 가지 자세한 차이

**카페 대기.** `woman in a cafe`는 장소만 지정한다. `woman waiting for coffee`도 컵을 이미 들고 마시는 이미지와 충돌할 수 있다. 픽업 지점에서 컵이 준비되거나 건네지기 전 단계, 인물이 그 지점을 향해 서 있는 상태, 다른 고객이 별도 동선을 쓰는 정도가 보이면 사건이 읽힌다. 실제 주문 완료 여부는 인쇄 영수증이나 화면 글자 없이 완전히 증명하기 어렵다. 따라서 “주문 후”는 장면 해석이며 픽셀 게이트는 **픽업 전 대기 구조**로 제한한다.

**장보기 비교.** `browsing shelves`와 `comparing two products`는 다르다. 비교를 요청받았다면 비슷한 두 상품이 동시에 보이고 손/시선이 그 사이를 오가며, 같은 종류의 구매 결정을 하고 있음을 알 수 있어야 한다. 정확한 가격 우열이나 예산 고민은 작은 숫자/글자 없이 판정하지 않는다. 기존 소품 슬롯 두 개만 선택해서는 관계가 보장되지 않는다.

**비 온 뒤 진입.** `wet pavement`, `umbrella`, `mixed light`를 서로 독립적으로 더하면 실내에서 마른 우산을 펴거나 바깥만 젖은 장면이 될 수 있다. 문턱의 실내외 위치와 젖은 우산의 물방울, 접는 손, 바깥 젖은 바닥을 서로 연결한다. 혼합광은 이 장면의 필요조건이 아니다.

**정돈된 일상.** `lived-in`을 쓰레기·마모·빈곤의 유의어로 만들지 않는다. 접힌 천을 보관하는 손, 비워진 작업면과 남은 작은 작업 영역, 막힘 없는 동선만으로도 현재 사용 중인 깨끗한 집을 표현할 수 있다. `rb_clean_space_plausibility`와 `rb_spatial_density_variation`을 재사용하고 표면 오염은 선택하지 않는다.

## 5. 데이터·후보팩 반영 순서

1. **재사용 우선:** 20개 묶음의 `existing_profile_ids`를 현재 레지스트리의 실제 ID와 다시 대조한다. `pr_observed_action_trace`, `rb_use_trace_affordance`, `rb_clean_space_plausibility` 등을 중복 작성하지 않는다.
2. **관계형 후보 추가:** 장소/행동/소품을 독립 슬롯에서 하나씩 뽑는 대신, 위 20개를 잠금 차원과 물리적 전제조건을 가진 선택형 scene bundle로 변환한다. 예시의 성별·나이·도시·카메라·날씨는 자동 기본값으로 만들지 않는다.
3. **좁은 시각 프로필 후보:** `ed_cafe_pickup_wait`, `ed_market_compare`, `ed_subway_exit`, `ed_shared_phone`, `ed_independent_bystander`처럼 기존 네 성분 관계로 다루기 어려운 의미만 별도 프로필 필요성을 검토한다. 정적 한 장에서 입증할 수 없는 동기·전후 사건은 hard gate에 넣지 않는다.
4. **자료 경로 확인:** 신규 asset이 실제 `photo_prompt_tags.json` 확장/로더에 연결되는지, 인덱스 원천 해시가 갱신되는지, v6 후보팩의 공개 후보 ID가 노출되는지 각각 확인한다. 소스 파일에 있다는 사실과 공개 후보팩 노출은 별개다.
5. **채택과 픽셀 별도 판정:** 독립 코어 → 후보팩 → 선택 → 합성 프롬프트 감사 → 정확한 이미지 요청 → 축소/원본 픽셀 → 사용자 판단의 결과를 분리한다. 후보가 노출되었다고 선택되거나 구현되었다고 보고하지 않는다.

`evaluation-cases.jsonl`의 24개 사례는 broad 요청, 부정·잠금, 장면 전환, 사람 수, 소품/행동의 오인, 깨끗한 일상, 촬영 진정성 경계를 다룬다. 이는 **예상 판정 명세**이며 테스트 실행 결과가 아니다.

## 6. 검증 설계와 합격 기준

| 단계 | 확인할 증거 | 현재 상태 |
|---|---|
| 연구 데이터 | 출처 URL·지원 범위·기존 ID 대조·중복 ID 없음 | 구조 검증 수행 |
| 검색·노출 | exact/embedding 분리, 부정/맥락, 공개 후보팩 ID, 슬롯·차원 조건 | 미실행 |
| 채택·프롬프트 | 최종 선택 이유, `source_intent_lock_sha256`, 같은 사건의 역할/상태 표현, 감사 결과 | 미실행 |
| 픽셀 | 같은 이미지의 같은 사건에서 필수 관계 모두 관찰; 축소 화면은 사건/장소, 원본은 접촉/상태 | 미실행 |
| 품질 효과 | 고정된 요청군·모델·크기·참조에서 기존 데이터 대 신규 묶음의 블라인드 비교 | 미실행 |
| 사용자 의도 | 별도의 직접 선호·의미 적합성 판단 | 대기 |

초기 파일럿은 **10개 상황군 × 3조건 × 3반복 = 90장**을 제안한다. 상황군은 깨끗한 집, 사용 중인 주방, 카페 픽업, 마트 비교, 대중교통 문턱, 비 온 뒤 진입, 공공 서비스 대기, 작업장, 두 사람의 화면 공유, 주변인의 독립 과업이다. 세 조건은 A=현재 데이터, B=`ordinary/candid/lived-in` 같은 일반 라벨 추가, C=관계형 후보 선택이다. 모델·버전·종횡비·주요 인물/의상·요청 의미를 고정하고 B/C의 프롬프트 길이·객체 수를 기록한다. 시드를 고정할 수 없는 생성기는 같은 난수 조건이라고 주장하지 않는다. 90장은 파일럿 설계 수이지 충분한 통계 검정력이나 실제 생성 수가 아니다.

픽셀 리뷰는 사전에 후보별 3~4개 조건을 동결한다. 한 이미지에서 필수 성분 하나라도 빠지거나 다른 물체·사람·장소로 대체되면 `partial_is_fail`이다. 뷰포트에 보이지 않는 증거는 추정하지 않고 `UNSCORED` 또는 해당 hard 게이트의 실패 사유로 기록한다. 프롬프트·감사 PASS와 픽셀 PASS를 합치지 않는다. 깨끗한 일상, 혼자 있는 일상, 맑은 날의 일상은 별도 holdout으로 두어 무분별한 어수선함·군중·비 추가를 잡는다.

## 남는 한계

시간사용 통계는 **무엇을 하는지**의 분류이며 **어떤 장면이 가장 자연스럽게 보이는지**의 순위가 아니다. Places·imSitu·Visual Genome은 인식/주석 연구이지 생성 프롬프트의 최적 조합 실험이 아니다. Ego4D·EPIC-KITCHENS는 비디오와 1인칭 시점이 많아 제3자 시점 단일 사진의 가독성으로 곧바로 옮길 수 없다. 이 연구의 20개 장면은 출처에서 발췌한 사진 분포가 아니라 그 자료의 표현 원리를 이용해 작성한 **검증 전 후보**다.

대화의 “중간 순간이 더 자연스럽다”, “조금 어수선하면 현실적이다”, “주변 사람이 있으면 스냅 같다”는 취향 가설은 이 단계에서 일반 법칙으로 확정하지 않았다. 실제 효과는 위의 대조 실험과 사용자의 직접 판정이 있어야 말할 수 있다.
