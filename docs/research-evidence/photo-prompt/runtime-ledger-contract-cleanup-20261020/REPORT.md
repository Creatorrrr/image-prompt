# 실행 장부 계약 정비 및 소규모 정리 검증

신규 버전 지정 기록을 실제 `photo-candidate-pack/v10`에 맞췄다. 워크플로와 기록기가 같은 상수를 사용하며, CLI뿐 아니라 직접 호출도 구버전 기록과 장부·독립 manifest 간 버전 불일치를 거부한다. 버전을 지정하지 않은 일반 기록은 그대로 허용한다.

공개 스키마는 과거 v2–v6에 v9와 v10을 추가했다. 기존 장부 행과 manifest를 다시 쓰지 않으며, 독립 manifest 자체의 wire 버전은 v2를 유지한다. 설치된 봉인 실행본은 수정하거나 재발행하지 않았다. 그 실행본이 쓰는 과거 버전도 새 공개 스키마로 읽을 수 있다.

소규모 정리는 빈 게이트 목록과 도달 불가 분기 제거, 미사용 튜플 바인딩 3개 명시, 실제 검증 조건과 어긋난 구버전 안내 4곳 수정에 한정했다. 검사 호출, `representative_eligible` 반환 필드와 기본 판정은 유지했다. 후보 원문·태그·검색 문서·인덱스·worker·Ruff 설정은 수정하지 않았다.

## 검증

- 작업본과 커밋 예정 소스에서 각각 회귀 검사 116개 통과. 원본 대조군은 각각 112개 통과하며 신규 검사 4개가 추가됐다. 렌더 검토 통합 검사는 변경 전·후 모두 팩 생성 중 600초 한도를 초과하여 미완료로 기록했다. 해당 정리는 전체 모듈 AST를 비교해 허용한 단순화·안내 문자열 외 문법과 검증 호출이 동일함을 확인했다.
- 실제 CLI의 성공·차단·오류 기록 3종을 Draft7 전체 스키마로 검증했다. 과거 6개 버전 읽기와 기존 바이트를 유지한 신규 기록 추가, 구버전·미지 버전의 쓰기 전 거부, manifest 버전 불일치 거부를 확인했다. 새 기록기에 옛 enum을 조합하면 세 상태 모두 새 회귀 검사가 실패한다.
- 정리 전·후 판정 96개 조합과 게이트 목록 64개 조합이 같았다. 튜플 정리는 변수 이름 외 AST와 검증 호출이 동일하다.
- 현재 선택된 H+F2 세대의 `texture` 목표로 정상 진입점의 조회·view·compose 감사·전달을 임시 저장소에서 변경 전후 실행했다. 발급된 벡터를 재사용했으며 상위 8개와 전체 순서 해시가 같았다. 공통 풀 18,180 CID / 18,182 RID 및 목표당 BM25F 1회·로컬 cosine 검색 1회를 유지했다.
- 별도의 과거 발급 `composition`·`lighting` 실행은 전체 점수·후보 순서와 H/native receipt·composed 감사를 재현했다. 원래 봉인 native 세대 863개 member와 실행 감사도 통과했다. 봉인 아카이브는 이전·최신 전체 순서 각 225개와 검사 17개를 재현했고 기존 HOLD 판정을 유지했다. 전체 과거 실행을 새로 전수 재현한 결과는 아니다.
- 실제 체크아웃에 반영한 후 장부 관련 검사 33개와 정상 H+F2 경로를 다시 통과했다. HEAD에 이번 변경만 합친 소스는 Ruff를 통과한다. 기존 미커밋 `prompt_generator.py`의 `source_key` F841은 보존했다.

## 보존 및 범위

원래 보호 목록 172,071개 경로와 CURRENT 168개를 비교했다. 기존 tracked 미커밋 diff, 다른 worktree와 선택된 세대는 보존했다. 병행 P0 연구가 모델 파일 12개에 추가한 하드링크는 내용·inode·mode가 같은 것을 확인하여 양쪽 모두 보존하고 예외로 별도 기록했다. 추가 untracked 작업도 이번 커밋에 포함하지 않았다.

최초 빈 임시 저장소에서는 변경 전후 모두 같은 상태 조회 오류가 있었다. 실제 설치 저장소를 읽되 원본 쓰기·네트워크·소스 fallback·torch 읽기를 차단하는 설정으로 바로잡은 후 전부 통과했다. 설치본/봉인 실행 검사의 첫 180/240초 초과는 통과로 처리하지 않았고, 같은 검증을 600초 한도에서 재실행하여 통과했다.

Gemini·새 임베딩 추론·이미지 API 호출 및 CURRENT 변경은 0회다. 실제 이미지 픽셀 품질 개선이나 봉인 설치본의 신규 기록기 배포는 이번 검증 범위에 포함하지 않는다. 이번 변경만 로컬 커밋하며 푸시는 수행하지 않는다.

상세 수치와 파일 해시는 [VALIDATION.json](VALIDATION.json)에 저장했다.
