# 모션 데이터와 최신 main 통합 근거

최신 main `6b1862aa4ac91a70834fdfdcbb1905a41e73dafe`에 이 작업의 모션 데이터만 더했다. 데이터 커밋은 `cfc8156d0b85cc433bd54744224add76e444ec95`이다. 기존 카메라·보컬로이드·교복·고궁 데이터와 관련 처리 로직을 유지했다.

- 시각 의미 46개, 선택 가능한 후보 46개와 번들 46개를 추가했다. 기존 의미 10개의 대체 표현과 후보 검색어도 보강했다. 새 대체 표현은 총 296개다.
- 최신 원본을 합친 뒤 의미 인덱스 9,985개와 시각 프로필 1,774개/검색어 4,141개를 재구성했다. 모델·차원·입력 문자열이 정확히 같은 기존 벡터만 재사용했고, 새 임베딩 호출은 0회다.
- 생성기 변경은 일반 데이터 레지스트리의 두 줄이다. 다른 main 처리 로직과 기존 v14 검증 함수는 동일하다.
- v1–v14의 기존 기준·팩·증거 33개는 해시를 보존했다. 로컬 연구 당시의 별도 v12를 최신 main의 v12–v14 위에 덮지 않았다.

후보 재생에는 실제 변경이 있다. 같은 입력과 시드에서 선택 가능한 평면 아트워크 번들이 하나 추가됐고, 구성 후보 하나가 평면 아트워크 후보로 바뀌었다. 구성 풀은 276→315, 소품 풀은 98→102이고 RGB 설명에 대체 표현 두 개가 더해졌다. 다른 선택 후보 객체와 기존 번들의 상대 순서는 유지됐으며, 공개 후보 수는 양쪽 모두 64개다. 요청의 의미·핵심·제어·구도·부정 프롬프트·개인 정보 경계는 보존됐다.

이를 변경 없는 전환으로 분류하지 않는다. v15의 `optional_inventory_transition`은 정확한 원본·샤드·팩·차이·데이터 커밋·부모 커밋을 고정 증거에 결합한다. 후보 순서나 필수 의무를 바꾸고 체크섬만 갱신하는 행위도 거부한다. v14의 기존 모든 부정 검증은 고정된 부모 원본에서 계속 실행하고, 현재 v15는 별도 검증한다.

`V14-source-parent.zip`은 v14 과거 테스트 재생용 원본이다. 정상 프롬프트 생성과 후보 검색에서 읽지 않는다. 현재 데이터에 과거 기준을 억지로 맞추지 않기 위해 분리했다.

이전 독립 에이전트의 이미지 세 장은 원래의 런타임·참조·프롬프트·픽셀 해시와 FAIL 판정을 유지한다. 모양 목표는 9/12개만 통과했고 전체 이미지 합격은 0/3개다. 이번 통합에서는 새 이미지를 생성하지 않았다. 데이터 검증 통과는 전체 46개 의미의 이미지 합격 또는 사용자 수용을 뜻하지 않는다.

원래 작업 트리의 미커밋/미추적 파일 1,265개는 먼저 백업했고 대조 결과 모두 동일하다. 최신 main 통합과 검증은 독립 작업 트리에서 수행했다.

검증: 전체 172개 모듈의 고유 테스트 1,495개를 모두 실행했고 최종 실패·오류·건너뜀은 0개다. 과거 이미지 입력 누락이 있던 13개 테스트 모듈은 SHA가 같은 원본을 연결한 뒤 모두 통과했다. 최초 실패 기록과 재실행 기록을 함께 보존한다. 실제 기본 생성기 실행으로 v15 팩 해시와 후보 ID도 확인했으며, 사전·시각 인덱스 검사와 변경 공백 검사를 통과했다.
