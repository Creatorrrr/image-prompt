core baseline and original fixture bytes while setting open_dimensions to [] and
omitting the optional camera review. Existing normalization accepts it. The new

## Recommendation

**Keep PR 5 draft and unmerged.** Scoped new-author queries have demonstrated
semantic routing value, but the new mode's zero-open compatibility gap remains.
The fresh legacy holdout still demonstrates no recall gain (0/8 before/after),
with unchanged 8/8 negative abstention. Broad legacy generalization, increased
eligible retrieval, adoption quality or rendering improvement are not established.
The source-grounding failure is an unchanged initial authoring-contract failure;
it should not be silently repaired or used to justify weakening the guard.

Before publication, address the independently reproduced new-mode compatibility
gap, or explicitly restrict the workflow to cores whose camera domain is declared,
without adding requester locks/edit permissions to pass. The prior runtime freeze
has been respected. Parent must decide the next scope and publication window.

exact source/DATA snapshots, historical missing-artifact failures and the three
