# 종교·신화 도상 대체 표현의 운영 반영

2026-10-03. 기준 HEAD `900848816f88a494e5bf16ea475a25074d584911`. [원 연구](../religion-myth-iconography-20261003/RESEARCH.md)의 140개 연구 단위를 현재 core-driven 후보팩 계약으로 번역했다. 연구 JSON을 런타임 입력으로 직접 연결하지 않았다.

## 반영 범위

| 변경 | 수량 | 실제 효과 |
|---|---:|---|
| 기존 시각 의미 소유자 보강 | 12 | 신화 10종, 그리핀, 무카르나스의 완전한 한국어·영어 대체 표현 24개를 추가했다. |
| 기존 구성요소 대체 증거 | 55 | 기존 신화·그리핀의 필수 그룹마다 같은 역할·소유·관계를 보존하는 영어 문장을 추가했다. 기존 exact 활성화와 픽셀 게이트는 유지했다. |
| 신규 출처 범위 프로파일 | 54 | 두광·복식·공간·합성체 등 선택된 변형의 구성요소 157개, 대체 표현 281개, 소유 관계와 ALL_OF 검증을 등록했다. |
| 신규 구도 후보 / 선택 묶음 | 80 / 80 | 코어가 이미 정한 몸·물건·사건을 읽히게 배치하는 `image_plane.layout` 후보다. 새로운 신·팔·지물·행위를 만들 권한은 없다. |
| 기존 슬롯 후보 대체 표현 보강 | 64 | 신화 후보 60개, 그리핀 2개, 무카르나스 2개를 원래 슬롯의 의미에 맞게 보강했다. |
| 추가 확인이 필요한 선택 후보 | 26 | 별도 hard 프로파일을 만들지 않았다. 표본·판본이 선택된 코어에서만 관계를 읽히게 하는 후보로 남겼다. |

탑·수인·다팔 도상·성인 지물·탈리트·테필린·미흐라브/민바르·도교 자수·산신도·도리이·합성 생물 등은 [매핑과 출처](MAINTENANCE.json)에서 각각 원 연구 단위와 연결된다. `ri_*` 확장은 완전한 변형을 명시한 긴 표현만 exact 의무로 인정한다. 이름 단독, 의미 검색 적중, 다른 후보의 설명은 특정 변형의 자동 의무가 아니다.

## 소유권과 혼동 경계

그리핀의 독수리 앞부분–사자 뒷부분, 무카르나스의 입체 오목 셀, 이집트의 심장–깃털 계량은 기존 프로파일을 재사용한다. 새로운 동의어가 기존 필수 그룹을 축약하거나 다른 변형으로 교체하지 않는다. 마아트 소형상과 단독 깃털은 다른 변형으로 유지하며, 원래의 심장–깃털 그룹을 몰래 넓히지 않았다.

새 구도 후보는 frozen subject/setting/event에 도상 또는 특징적인 가시 구조가 있을 때만 적합하다. `human`, `body`, `head`, `portrait` 같은 일반 단어가 미노타우로스나 신격 후보를 노출시키던 문제를 실제 기존 뷰티 인물 사진 회귀 사례로 확인하고 수정했다. 조건은 authored 후보 데이터에 있으며 생성기에 주제별 조건문을 추가하지 않았다. 생성기 변경은 새 확장 파일 2개의 로더 등록이다.

새 프로파일 54개는 `semantic_discovery_requires_component_evidence=true`를 사용한다. 일상 찻잔 요청에 다팔 도상이 섞이던 첫 통합 상태를 보존한 뒤 수정했다. 좁은 의미의 한국어·영어 발견 표현 113개와 몸 접합의 관찰 문장 6개는 위 281개에 포함된다. 이는 전체 구성요소를 입증하는 hard 증거가 아니라 선택적 발견을 돕는 표현이다. 짧은 이름·가까운 임베딩만으로 의무가 생기지 않으며, 선택 시 기존 ALL_OF 전체를 검증한다.

실제 runtime 프로파일 확인은 주로 코어의 해석과 baseline 본문을 사용한다. subject에만 있는 표현은 그 확인 단계에 충분하지 않을 수 있었다. 세이렌의 인간 목–새 몸통 연결과 키마이라의 같은 등–염소 목 연결을 설명하는 대체 문장을 보강하고, 동결된 본문으로 두 프로파일이 선택 후보에 다시 노출되는 것을 확인했다. 이 과정에서 코어와 최초 이미지 호출의 프롬프트는 바꾸지 않았다.

`prop` 슬롯의 허용 차원은 계속 빈 목록이다. 지물·성물 연구 초안 27건은 물건의 실제 owner/target/property 계약을 정의할 때까지 보류한다. 맥락·서사 중심 30건도 연구 전용이다. 추가 확인 후보 26건은 실제 박물관 도판을 검증했다는 뜻이 아니며, 각 기록의 출처 접근 상태와 후속 확인 항목을 보존했다.

## 실제 데이터와 검증

운영 로드 결과 슬롯 112개·후보 9,783개·시각 의미 프로파일 1,564개다. Gemini `gemini-embedding-2` 768차원 인덱스를 재생성했다. 기존 프로파일 중 표현을 바꾼 12개와 새 54개만 새 벡터를 쓰며, 나머지 기존 1,498개 벡터는 그대로 재사용했다. 의미 후보 인덱스는 9,819개 문서다. 새 manifest와 현재 소스의 해시를 검증했고 기존 추적 shard 파일은 보존했다.

최종 집중 검증은 긴 요청 표현의 활성화, 일반 이름·부정·advisory의 비활성화, 구성요소 하나 누락 시 실패, 한국어 대체 표현, 기존 소유자 유지, prop 권한, ordinary portrait의 비노출, 강제로 유사한 벡터를 넣은 찻잔의 비노출, baseline 접합 대체 문장의 선택적 발견, 기존 64개 후보의 다른 필드 보존을 확인했다. 검증의 정확한 테스트 ID와 결과는 `final-verification-*.json`에 기록한다. 전체 분할 회귀 및 실제 3개 이미지 결과는 [RESULTS.md](RESULTS.md)와 arm별 결과에 기록한다.

이웃 일러스트레이션 검사에는 현재 사진 팩의 고정 해시가 있어 이번 후보 표현·코퍼스 변경으로 3개 회귀 오류가 발생했다. 통합 전 소스·인덱스의 격리 재실행은 기존 v5 바이트 해시와 정확히 일치했다. 최종 찻잔 팩은 core·필수 의미·negative·선택 묶음·품질·안전·optional 시각 프로파일 ID를 유지하며, subject 선택 후보 순위와 코퍼스 바인딩이 달라졌다. 현재 기준을 `photo_regression_baseline_v6.json`으로 추가했고 v1–v5는 바이트 불변으로 남겼다. validator의 버전 계보 검사는 늘렸으며, 기존 현재 universal v2 메타데이터에는 새 validator 파일 해시 한 필드만 갱신했다. 오라클·holdout·과거 픽셀 실패 기록은 변경하지 않았다.

첨부 인물 사진은 가상 성인 주인공의 눈·얼굴·머리 등 보이는 외형의 참고다. 신원·신앙·실제 나이·신체 유사성은 평가하지 않는다. 각 에이전트가 같은 사용자 원문을 유지하면서 별도 envelope/core와 무작위 선택 컨셉을 작성하고, 실제 후보 노출·채택, 프롬프트 감사, native 이미지 픽셀을 따로 확인한다. 평가 기준은 전체 구성요소와 소유·연결 관계이며 `partial_is_fail=true`, 필수 가림은 `UNOBSERVABLE`이다.

데이터 검증·검색 노출·프롬프트·생성 이미지·사용자 선호는 서로 다른 증거다. 세 생성 사례가 모두 성공해도 54개 프로파일 또는 80개 후보 전체의 이미지 성공률을 확정할 수 없다.

이번 실제 테스트에서는 세 컨셉 모두 최종 FAIL이었다. 각 독립 에이전트의 최초 1회 생성과 1회 수정, 총 6개 native 원본을 보존했다. 생성 당시 통합 데이터는 `native-generation-source-snapshot`에 따로 보존했으며, 최종 데이터의 같은 동결 코어 재검색은 `qualification/FINAL-SOURCE-REPLAY.json`에 기록했다. 최종 소스 재검색 PASS가 이전 이미지의 픽셀 FAIL을 바꾸지 않는다.
