# 첩보물 전체 대화 보강 연구

크롬 로그인 세션에서 두 사용자 메시지와 두 답변의 본문 전체 52,155자를 읽었다. 표 35개, 데이터 500행을 검증했다. 기존 340행에 누락 160행을 더했다. 500은 단일 용어 480개, 혼동 구분 8행, 창작 조합 12행의 합이며 모두 시각 후보라는 뜻이 아니다.

추가 범위는 정치·기관 관계 13, 성·친밀감·착취 17, 심문·고문·구금·암살 22, 심리·윤리 12, 서사 장치 18, 공간·소품 17, 기관명 16, 혼동 구분 8, 사건 흔적 13, 촬영 12, 창작 조합 12행이다. 헤어 20항목은 기존 340행에 이미 포함됐다. 과거 접근 제한 보고는 과거 증거로 보존한다.

## 시각 의미를 강화한 방식

42개 완결된 한영 대안은 각 소유자·부위, 방향 있는 관계, 함께 보여야 하는 접점, 혼동 경계와 주장 한계를 갖는다. 의상은 마모와 정상 천의 경계, 구김의 능선과 골, 커프에 이어진 낱실, 젖고 마른 천과 방울을 구분한다. 비·밤샘·전투·도주라는 원인은 표면으로 확정하지 않는다. 상해 분장은 인조 피부 표본으로, 혈흔은 화학적 확인 없는 적갈색 천 얼룩으로 한정한다.

촬영은 프레임·카메라·빛의 관계다. 카우보이 숏은 머리부터 허벅지 중간, OTS는 전경 어깨와 다른 인물, 더치 앵글은 환경 축과 화면 축의 기울기를 본다. 고개 기울임은 카메라 회전이 아니다. 전경 가림은 앞 물체가 뒤 인물의 경계를 실제로 겹쳐야 한다. 림은 외곽과 배경이 분리되어야 하며 로키는 단순 노출 부족으로 통과하지 않는다.

문서·사진·모니터는 물리 매체, 매체에 묘사된 인물, 실제 관찰자·공간을 분리한다. 콘택트시트의 사진 격자는 실제 창 너머 안뜰과 다른 소유자다. 인쇄물 둘의 대응 자국은 비교 가능한 표면일 뿐 실제 시간 순서나 동일인 증명이 아니다. 특정 역사적 마이크로도트·위장 무기·암호기의 정확한 구조·기능은 표본 검토 없이 시각 후보로 승격하지 않는다.

누락된 160행은 원래 정의와 문맥을 diagnostic으로 보존하여 긍정 시각 검색에서 제외했다. 시각 대안이 연결된 행에도 원래 개념 전체와 대안의 좁은 범위가 구분된다. 성폭력·착취·강요·동의·성적 지향, PTSD·도덕적 손상, 기관 소속·충성·기밀·협박·강제실종을 외형으로 자동 활성화하지 않는다. 12개 창작 조합은 예시로 보존하며 장르별 강제 프로필이나 묶음으로 설치하지 않는다.

기존 미연결 외형 65행도 후보 탐색 기록을 남겼다. 전경 손과 폴더 소유, 뒤로 깍지 낀 손과 두 사람 포옹, 가방과 곤충 알 무더기처럼 어휘가 겹치는 이웃을 자동 재사용하지 않는다. 기존 조건·효과·분장 레이어·성인 조건·문맥 가드를 제거하지 않았고, 65행은 해결된 것으로 재표시하지 않았다.

## 1차 출처와 적용 한계

각 출처는 해당 개념군의 의미나 경계를 지원한다. 새 42개 장면의 구체적 구성과 픽셀 게이트는 연구자가 작성한 제안이며 출처 이미지의 검증된 복제가 아니다. 기관명·역사 명칭은 참조 대화의 문맥으로 보존하며 현행 조직 권한을 모두 새로 조사했다는 주장은 하지 않는다.

- [F01 Warner Bros Studio Tour: Costume Distressing](https://www.wbstudiotour.co.uk/es/schools/resource-hub/costume-distressing/): 제작진이 의상을 낡거나 사건 흔적처럼 보이게 처리한다. 보이는 표면은 실제 사건의 증거와 구분한다.
- [F02 ScreenSkills: Standby costume assistant](https://www.screenskills.com/skills-checklists/scripted-film-and-tv/costume-department/standby-costume-assistant-skills/): 의상 상태·변화·손상을 기록하며 연속성을 관리한다. 두 사진의 일치는 실제 시간 순서나 동일인 증명과 다르다.
- [F03 Adobe: Cowboy shot](https://www.adobe.com/creativecloud/video/production/cinematography/camera-shots-and-angles/cowboy-shot.html): 머리부터 허벅지 중간까지의 프레이밍. 배우의 자세나 무기 소유를 필수조건으로 만들지 않는다.
- [F04 Adobe: Over-the-shoulder shot](https://www.adobe.com/creativecloud/video/production/cinematography/camera-shots-and-angles/over-the-shoulder-shot.html): 가까운 인물의 어깨·머리 일부 너머 별도 인물을 담는 카메라 관계. 배우 혼자 뒤돌아보는 자세와 구분한다.
- [F05 ScreenSkills: Hair and make-up artist](https://www.screenskills.com/skills-checklists/scripted-film-and-tv/hair-make-up-and-prosthetics-department/hair-and-make-up-artist-skills/): 현대·시대극 헤어와 메이크업·가발·상해 분장·보철 제작이 역할에 포함된다. 분장 표면과 실제 상해를 구분한다.
- [F06 ICRC: Torture and other forms of ill-treatment definitions](https://www.icrc.org/en/document/torture-and-other-forms-ill-treatment-definitions-used-icrc): 고통의 강도·목적 등 비시각 조건이 중요하다. 눈에 보이는 멍이나 구금 포즈만으로 고문을 확정하지 않는다.
- [F07 US VA: Moral injury and PTSD](https://www.ptsd.va.gov/understand/related/moral_injury_ptsd.asp): 도덕적 손상과 PTSD는 동일하지 않으며 표정이나 어두운 연출만으로 진단할 수 없다.
- [F08 CIA Museum: Disguise kit](https://www.cia.gov/legacy/museum/artifact/disguise-kit/): 위장 도구와 이를 사용하는 사람의 실제 임무·신분은 별개다. 모든 정보기관 직원에게 같은 외형을 부여하지 않는다.
- [F09 FBI: Sextortion](https://www.fbi.gov/how-we-can-help-you/common-frauds-and-scams/sextortion/sextortion): 협박·강요 관계가 핵심인 맥락이며 노출·매력·친밀한 거리 자체가 착취·동의 여부를 입증하지 않는다.
- [F10 US National Archives: The Lavender Scare](https://www.archives.gov/publications/prologue/2016/summer/lavender.html): 역사적 차별과 입증되지 않은 취약성 추정의 맥락을 보존한다. 옷이나 몸짓으로 성적 지향·협박 가능성을 추정하지 않는다.
- [F11 UN: Convention on enforced disappearance](https://mandates.un.org/mandate/A/RES/61/177?subject=Disappearance+of+Persons): 국가 관여·자유 박탈·은폐와 같은 조건은 빈방이나 부재한 인물만으로 확인되지 않는다.

## 반영과 검증 계획

1. 이전 패키지·이미지·실패 기록을 그대로 보존하고 새 모듈 두 개와 의미 sidecar를 추가한다.
2. 설치된 최신 기준선의 모든 후보·조건·효과·바인딩·카탈로그·정책·커널을 유지한 채 새 자료만 봉인한다. 기존 벡터는 텍스트·레시피·모델 바인딩이 같은 경우만 재사용하고 새 긍정 대안은 실제 로컬 임베딩을 생성한다.
3. 한영 원문 검색, 자연어 재표현, 표면/의도 혼동과 일반 대조 질의를 실제 두 검색 lane으로 실행한다. 검색 노출은 채택 승인과 분리한다.
4. 세 독립 초안의 무작위 전체 장면을 봉인한 뒤 후보를 검색한다. 각 에이전트는 원본 인물 사진을 실제 첨부하고 native 생성 1회로 서로 다른 구도를 만든다.
5. 실제 프롬프트에 쓰인 후보/영감/미채택을 분리하고 원본 생성 파일을 직접 검사한다. 부분 성공이나 가려진 필수 접점은 전체 통과로 계산하지 않는다. 사용자 수용은 별도 미확인으로 남긴다.
