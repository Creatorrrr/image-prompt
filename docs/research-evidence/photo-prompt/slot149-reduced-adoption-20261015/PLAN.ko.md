# 149개 슬롯 축소 적용

사용자가 승인한 범위: 전수 검토 없이 149개 슬롯을 실제 운영에 적용한다. 애매한 연결은 보류한다. Gemini를 호출하지 않고 기존 로컬 임베딩만 사용한다. 각 단계의 구현·검증 후 해당 경로만 커밋한다. 이번 요청은 push를 포함하지 않는다.

1. 변경 항목만 다루는 명시적 적용 계약과 보류 연결의 실행 차단을 구현·검증한다. 기존 전수 native 심사 도구와 원문·조건·권한 검증은 유지한다.
2. 기존139/최종149의 차이와 제한된 대표 후보를 직접 검토하고 적용 manifest를 확정한다. 104개 동일 명세의 기존 관계는 승계한다. 35개 변경 명세의 연결은 명시적으로 유지 또는 보류한다. 후보 본문이나 참조를 전수 수정하지 않는다.
3. 확정된 변경만 격리된 원본에 적용해 전체 ID·참조·중복·조건·종류·출처 보존을 검증한다. 미수용 연구 보정은 가져오지 않는다. 기존 123개 연구 판정은 재사용 가능한 정확한 변경만 선택하고 나머지는 연구 상태를 유지한다.
4. 검증한 원본을 운영 assets에 반영하고 BM25F·동일 로컬 벡터 공간의 새 인덱스를 만든다. 입력·모델·recipe가 동일한 벡터만 재사용하고 전체 파생 closure를 검증한다.
5. 새 실행 세대를 실제 활성화하고149슬롯 독립 검색·receipt 재생·필요 shard 적재를 검증한다. 결과와 보류·생략 범위를 기록한다.

영향 분석은 자동 검사다. 직접 의미 검토는 변경 슬롯별 대표 기존 관계 최대1개, 신규 슬롯별 대표 후보 최대1개로 제한한다. 추가 후보 탐색이나1,000개 표본 평가로 확대하지 않는다. 대표가 없거나 실제 효과가 맞지 않으면 보류한다. 관계 검토 상태는 native 의미 자격을 부여하지 않는다. 슬롯 검색 대상은 공통 positive 후보 전체이며 태그는 검색 공간을 분할하지 않는다.

변경된 관계가 다른 후보에서 참조되면 삭제 대신 `_slot_binding_review.deferred`에 보관해 참조를 유지하고 해당 역할의 제시·채택을 차단한다. 동일 후보의 다른 역할과 공통 데이터풀 검색은 유지한다. 기존 정책 키·본문·조건·효과·출처는 변경하지 않는다.
