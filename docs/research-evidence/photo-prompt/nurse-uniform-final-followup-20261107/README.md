## 검증과 한계

선택 후보는 요청의 의도·범위에 맞을 때만 검토하는 독립적인 한 가지 시각 실현이며 출처 자체가 후보의 전체 형태나 native 채택을 승인하지 않는다. 기존 후보 재사용은 일부 의미의 연결이고 완전 동등성은 보장하지 않는다. 특히 정지 이미지에서 움직임의 전후, 실제 의도·감정·연령·동의·직업이나 보이지 않는 재료는 확정하지 않는다. 코스프레와 실제 간호복도 구분한다.

자동 검사: 관련 테스트 22개 통과, 12개 스킵, 하위 검사 4개 통과. 인덱스는 이전 봉인 뷰 26,877개와 새 뷰 50개를 결합하고 임베딩·전체 검증·설치한 다음 기본 설정으로 활성화했다. 이미지 생성과 픽셀 검증은 수행하지 않았다.

기존 `photo_prepare_reviewed_views.py` 기본 준비 절차는 오래된 기준 뷰 25,551개 중 1,250개가 현재 후보와 해시가 달라 실패했다. 직전 봉인 릴리스에는 이 기준 뷰 ID가 모두 포함되어 있으나 그중 1,251개 뷰의 내용이 과거 기준과 다르다. 현재 봉인 릴리스를 새 기준으로 검증한 병합은 통과했지만 과거 오버레이의 전체 재생은 바뀐 후보 해시 때문에 통과하지 않았다. 이력의 의미 동등성을 추정하거나 과거 기준을 덮어쓰지 않고, 직전 릴리스의 검토 뷰 26,877개를 그대로 유지하는 범위에서 새 뷰를 결합했다. 구체적인 수치와 재현 결과는 `legacy-replay-audit.json`에 있다.
