- 참조 대화 연결 도구는 20,000자에서 잘렸다. 동일 대화를 Chrome에서 실제 열고 16개 용어 표의 291행, 9개 작품 표, 끝의 인과 조합 3개를 확인했다. 원 대화에서 문장을 생성하거나 메시지를 보내지 않았다.
- 원문 전체의 독립 사전 검증이 아니다. 키워드 목록은 원 대화에서 복원했고, 45개 출처는 개념군·중요 구분·작품 맥락을 지원한다. 정확한 장면 기하·문구·owner graph는 연구자가 저술했다.
- 41개 본문 확인은 논문·원전 전체를 통독했다는 뜻이 아니다. NASA 연구 논문은 해당 구간, Project Hephaistos는 도입/모델, 작가 인터뷰는 해당 응답, 출판사는 줄거리, A Memory Called Empire는 공개 1장을 읽었다.
- T07 ESO는 검색 발췌만 확보했고 영상 프레임을 보지 않았다. T08 본문은 별도로 읽어 Dyson 군집의 일반 개념을 지지했다. 두 증거를 합쳐 ESO 영상 픽셀을 검증했다고 하지 않는다.
- M07 Nature는 인증 리디렉션, PMC는 browser check, M08 CHOP는 403, M10 concordance는 502였다. M08/M10은 검색 발췌 기록이며 운영 승격 근거가 아니다.
- NASA SP-413은 작은 메타데이터를 찾았지만 큰 PDF 전문은 읽지 않았다. 대체로 T05 개념 미술과 T06 작은 기술 논문의 해당 구간을 사용했다. 26MB ADG Picard 수상 PDF는 fetch 용량 한계가 있었고 M02 작은 제작자 기록/M03 참여 디자이너의 본문을 대신 읽었다. 처음 추정한 StarWars kitbashing URL은 열리지 않아 근거에서 제외했다.
- 모든 갤러리·영화 프레임·표지·소설/만화 전문을 조사하지 않았다. 공식 사이트의 텍스트 설명과 직접 픽셀/영상 검토는 다른 증거다. 외부 이미지 다운로드도 하지 않았다.
- Ringworld 상세, coilgun 대조, glassing 작품별 범위, ectogenesis 과학 의미는 V21/V25/V31/V42에 채택 보류를 기록했다. 그 밖의 과학/철학/디자인 용어 전체의 개별 정의 원전은 후속 작업이다.
- 기존 코퍼스 진단은 긍정 필드의 고정 어휘와 일부 구조 이웃을 읽었다. 실제 BM25F/hybrid 질의·query embedding·순위·노출·native qualification을 실행하지 않았다. 의미 부재나 검색 성능을 입증하지 않는다.
- 시작/종료 관측 사이 HEAD가 `be52bda6`에서 `9b654b63`으로 달라졌고 보호 파일 15,714개 중 `references/maintenance.md` 하나가 바뀌었다. 이 연구가 쓴 경로는 신규 연구 폴더뿐이다. 동시 변경을 되돌리거나 연구 성과에 합산하지 않았고, 후속 구현 시 최신 기준을 다시 고정하도록 계획했다.
