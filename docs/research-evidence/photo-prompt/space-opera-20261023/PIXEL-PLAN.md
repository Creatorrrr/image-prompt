# 픽셀 검증 제안 — NOT_RUN

현재 이미지 생성 0회다. 이 문서는 후속 반영 시의 비교 계획이며 비용 지출을 실행하지 않는다. 기본 12장면×3 arms=36장, 채택 여부가 불확실한 경우에만 같은 계약의 확인 반복 최대 36장을 제안한다. 장면마다 무작정 반복해 우연히 통과한 것만 남기지 않는다.

|장면|필수 가시 gate|금지할 과잉 결론|
|---|---|---|
|화물선 관문 협상|토큰 소유·허가 대상·관문 개구부·대기선과 순찰함 구분|독점·불법·통행 결과|
|이온선 정비|전력 배열·본체·짐벌 추진기 구분|거대 불꽃·FTL·실제 추력|
|태양돛|얇은 반사막·붐·중앙 본체의 연속 관계|태양전지·바람·실제 가속|
|토러스/실린더 대조|서로 다른 축·빈 공간·연속 내면과 인물 지지|실제 중력·거주 적합성|
|다이슨 군집|분리된 수집체·틈·항성과의 상대 관계|실제 발견·수집률·고체 껍질|
|EVA|같은 작업자 하네스·줄 양 끝·선체 고정점·레일 접촉|잘린 끝 연결 승인·수중 장비 전용|
|에어록/방열|별도 해치 둘·전이실·패널과 배관·단열재|압력 전이/열 성능 성공|
|비인간형 외교|별도 몸·닿는 사지·공용 물건·환경 경계|최초·지능·동의·생화학|
|android/cyborg|각각 기계 내부/피부 접점·동일 착용자|악의·성적 서비스·시민권|
|함선 지성의 권리 논쟁|사람·인터페이스·문서·권한표의 별도 소유|같은 의식·판결·소유 정당성|
|성인 공동생활/복식|명시 성인 메타데이터·개별 몸·의복·실내·별도 압력복|혈연·하렘·성노동·동의·진공 방호|
|사용 흔적과 승무원 수리|마모 부위·교체판·패널 지지·손/공구 소유|낡음이 쇠락·유사가족·트라우마를 입증|

세 arms는 A=변경 전 코퍼스, B=문맥/혼동 경계 보완만, C=B+검토된 완전 후보다. source/index ID와 실제 노출·선택·prompt를 저장해 선언한 차이가 정말 구현됐는지 먼저 확인한다. 같은 요청 원문·앵커·참조·모델·크기·controls를 사용하고 seed 고정 지원 여부는 실제 도구 기능으로 확인한다. 지원하지 않는 재현성을 약속하지 않는다.

본 평가 전에 각 장면의 완전 명제와 gates를 고정한다. `exposure → eligibility → chosen CID/RID → literal prompt evidence → generation artifact → saved original pixels`를 잇는다. 노출 자체가 실패한 arm은 이미지 의미 비교에서 별도 실행 실패로 처리한다. 여러 요소가 바뀐 B/C 차이는 결합 효과이며 각 구성요소의 독립 인과 증거가 아니다.

픽셀 판정은 `visible / partial / unobservable`로 하고 필수 관계의 일부만 보이면 완료 PASS를 주지 않는다. 가림·역투영·부착점 누락·다른 소유자로의 전이는 각각 구체 위치를 남긴다. 개별 카드의 모든 문장을 다 넣기보다 선택된 전체 명제에 맞는 필수 관계를 검토한다. 의식·동의·혈연·진단·원인·권리·정확한 수치·전체 피해는 픽셀 gate로 만들지 않는다.

객관 관계 구현과 예술성/전체 구성의 선호는 별도 평가다. 작품별 지식이 픽셀 판정을 대신하지 않게 원 요청과 gates를 먼저 보고, 가능하면 arm 정보를 가린 후 평가한다. 독립 검토자가 없으면 순차 자기 검토라고 명시한다. 사용자 수용은 응답이 오기 전 `pending`이다.

생성 차단은 이미지가 없는 결과이며 gate 점수가 아니다. 같은 차단 입력을 그대로 재시도하지 않는다. 실패·불충분·미실행·실제 픽셀을 모두 남기며 요청의 고정 요구를 성공 기준에 맞춰 조용히 완화하지 않는다.
