# 두 번째 참고 이미지: 독립 3개 장면 재검증

## 입력과 절차

새 참고 JPEG의 SHA-256은 `437ae5cc9e99efc573060eb248ac21873f5ff81c36347e10efc5fcb6234d6a0e`이다. 각 arm은 동일한 [원문 요청과 참고 파일 기록](reference_manifest.json)을 받고 별도의 난수 시드, 코어, 후보팩, 프롬프트, 생성 이미지, 원장을 사용했다. 참고 사진은 보이는 성인 얼굴과 머리 형태의 연속성에만 사용했다. 신원, 생체정보, 보호 특성, 실제 직업은 추론하지 않았다.

각 에이전트는 코어와 신체 검토를 후보 데이터 조회 전에 작성했다. 이후 v6 후보팩을 생성하고, [사전 테스트케이스](test_cases.json)의 장면 소유자와 구성요소를 이미지 생성 전에 정했다. 합성 감사와 정확한 런타임 요청 감사가 통과한 후 참고 JPEG를 실제 이미지 입력으로 첨부해 arm당 1회 생성했다. 판정은 저장된 원본 1024×1536 이미지 한 장의 선언된 소유자에서 모든 구성요소를 확인하는 `partial_is_fail` 규칙을 적용했다.

이번에는 [소스 스냅샷](source_snapshot.json)의 코드·데이터·인덱스를 실험 중 바꾸지 않았다. 앞선 실험의 프롬프트, 팩, 이미지는 새 arm의 입력으로 사용하지 않았다.

- A: 환경 인물·장소 관계와 작동 행동의 가시적 결과는 통과했다. 빨간 선택기의 밝은 띠가 손가락 접촉에 따른 작은 마모인지 원본 크기에서도 분리되지 않아 표면 흔적 관계가 실패했다. [이미지](arm_a/generated_images/radio-telescope-control-power-test/native_render.png), [픽셀 판정](arm_a/native_pixel_review.json).
- B: 세탁소 환경과 스카프를 꺼내며 떨어지는 물방울은 통과했다. 금속의 분홍색 자국은 받치는 왼손의 접촉 위치와 떨어져 있고 작은 손마모로 읽히지 않는다. 신체 지지 및 왼손 접촉 게이트도 일부 실패했다. [이미지](arm_b/native_image.png), [픽셀 판정](arm_b/native_pixel_review.json).
- C: 선택된 환경 인물·장소 프로필과 일반적인 마커 행동 관계는 통과했다. 유리의 닦인 흔적은 희미한 국소 자국보다 넓고 밝다. 새 흰 페인트의 젖은 돌출 가장자리도 원본 크기에서 확인되지 않았다. [이미지](arm_c/native_render.png), [픽셀 판정](arm_c/native_pixel_review.json).

세 이미지의 합성·런타임 감사는 각각 **3/3 통과**했다. 새 `pr_*` 목표 관계는 **6/9 완성**, 공개 후보팩 노출은 **2/9**, 실제 선택은 **1/9**다. 핵심 장면과 선언한 모든 목표 관계를 함께 통과한 이미지는 **0/3**이다. 소스·인덱스에 있는 관계가 공개 후보팩에 없더라도 사전 정의한 외부 픽셀 목표로는 평가했다. 그러므로 이미지에서 통과한 관계를 후보팩의 효과로 귀속할 수 없다. [자동 해시·구조 검증](verification.json)과 [종합 판정](adjudication.json)에 각 범위를 분리했다.

## 독립성과 판정 차이

C가 처음 무작위로 고른 천문 장비 장면은 A와 넓은 주제가 겹쳐 이미지 생성 전에 폐기했다. C는 그 코어의 해시와 교체 사유를 [무작위 선택 기록](arm_c/randomization.json)에 남겼다. 첫 팩은 생성됐으나 열람하거나 최종 코어에 사용하지 않았다고 기록했다. A는 최초 평가 계약에 기존 `rb_*` 관계만 있어, 이미지 생성 전에 이번 확장의 `pr_*` 관계 3개를 추가했다. A의 코어와 공개 후보팩은 유지했다. 따라서 C는 완전한 첫 추첨 사례가 아니고, A의 목표 목록도 최초 계약 그대로가 아니다.

조정자의 이미지 사전 판정과 arm 판정이 다른 부분은 [종합 판정](adjudication.json)에 그대로 보존했다. A 선택기의 밝은 띠는 마모로 단정할 수 없어 실패로 처리했다. C는 마커가 `TODAY`의 마지막 획에 닿는지, 별도 밑줄에 닿는지 판독이 갈렸지만 표면 흔적 실패만으로도 장면 전체가 실패한다. 기술 감사는 기록의 형식과 해시를 확인할 뿐 픽셀의 진실이나 사용자 선호를 증명하지 않는다. 사용자 직접 평가는 아직 없다.
