# 셀카 포즈 변경의 main 병합 기록

셀카 후보 104개, 시각 프로필 101개, 거울 소유·반사 프로필 1개의 수정만 기존 main 원본에 적용했다. 다른 미커밋 작업은 게시 범위에서 제외했다. 작성 원본을 먼저 보존하고 호환되는 벡터로 인덱스와 BM25F를 재생성했다.

기존 세 native 실험의 프롬프트·코어·receipt·생성 이미지·픽셀 판정을 변경 없이 보존했다. 최초 참조 JPEG, 실행 lock, 로컬 복구 ZIP은 원래 작업공간에 보존하며 이 커밋에서는 제외했다. 제외 항목은 EVIDENCE-COPY.json에 기록했다. 이미지 생성 당시 원본과 최신 main 병합 데이터의 증명 범위를 혼동하지 않는다.

이 문서는 첫 범위 커밋의 기록이다. 원격 main pull, 병합 검증 및 push 결과는 후속 병합 기록에 추가한다. 이전 이미지 검증은 부분 성공이며 신규 시각 프로필의 직접 채택은 0개다. 전체 테스트의 변경 전 실패 22개 모듈은 기존 보고서에 보존되어 있다.
