# 셀카 포즈 데이터와 원격 main 병합

셀카 후보 104개와 시각 프로필 101개, 기존 거울 관계 프로필 1개의 수정을 원격 main의 일식 수관 투영 데이터와 함께 보존했다. 원본 데이터는 양쪽 커밋과 바이트가 같고, 생성된 의미 인덱스의 충돌은 두 원본을 합친 코퍼스로 재생성해 해결했다.

- 셀카 범위 커밋: `eaeb821f20979e1d1c9e146a178bf4181849e7f3`
- pull로 확인한 원격 main: `74c4a77839d66832d58f9a59f71ba408ac415e2e`
- 다른 기존 프로필 332개와 기존 등록 항목의 의미를 보존했다.
- 다른 작업의 미커밋 소스는 원격 게시 범위에서 제외했다.
- 의미 인덱스 11,067개, 시각 프로필 2,820개를 구성했다. 동일 ID·전체 텍스트·provider/model/dimensions의 벡터만 재사용했고 임베딩 호출은 0회였다. BM25F와 메타데이터는 합쳐진 원본에서 다시 계산했다.

관련 테스트 39개, 전체 사전 검증, 시각 인덱스 deep check를 통과했다. 최초 범위 커밋 전 관련 테스트 21개도 통과했다. 전체 테스트는 이 병합에서 다시 실행하지 않았다. 이전 전체 실행의 22개 변경 전 실패와 이미지 검증의 부분 실패는 기존 기록을 보존했다.

[원본 의도 보존](MERGE-INTENT-VERIFICATION.json), [인덱스 재생성](MERGED-INDEX-REBUILD.json), [39개 테스트](merged-focused-tests.log), [원격 pull](pull.log)에 근거를 기록했다.

기존 세 native 실험의 프롬프트·코어·receipt·이미지·픽셀 판정 797개 복사 파일을 원본 해시로 대조했다. 이 병합에서 새 이미지를 생성하지 않았으며, 이전 이미지의 세대와 최신 main의 데이터 세대를 동일하게 취급하지 않는다. 최초 참조 JPEG, 실행 lock, 로컬 복구 ZIP은 원래 작업공간에 남겨 두었다. [기존 실험 보고서](../selfie-pose-integration-20261008/README.md), [복사와 제외 목록](EVIDENCE-COPY.json).

원래 main에는 작업 시작 시 Git에 보이는 수정·미추적 일반 파일 9,295개가 있었다. 추적 수정 14개와 활성 벡터를 별도 백업했고 모든 관찰 파일의 해시를 기록했다. 원격 푸시와 로컬 main 동기화 후의 실제 SHA 및 보존 확인은 별도 완료 기록으로 남긴다. 기록을 위해 과거 실험·프롬프트·판정 파일을 변경하지 않는다.
