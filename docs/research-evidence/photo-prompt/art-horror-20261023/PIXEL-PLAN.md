# 검색·선택·픽셀·미적 판단의 분리 평가

이 문서는 **미실행 계획**이다. 원 대화의 여섯 조합을 포함해 작성한 합성 테스트 주제이며 실제 사용자의 이미지 요청·개인 참조·requester-owned lock이 아니다. 이미지/API 호출을 수행하지 않았다.

## 첫 평가 장면군 8개

|군|합성 요청의 중심 의미|관련 카드|동시에 보여야 할 관계|별도로 남길 해석|
|---|---|---|---|---|
|1. 낯익은 거울|실제 편 손과 주먹 모양으로 어긋난 반사|V01|실제 오른손·같은 손의 반사·거울 테두리·신체 연결|지연·분신의 정체·공포 경험|
|2. 몸과 인공 표면|생체 같은 막이 특정 외피 테두리에 이어짐|V07, V12, V43|외피·막·안팎·부착/파단 경계의 매체 구별|감염·고통·자해·인간 피부의 정체|
|3. 비체적 물질과 설치|피부 같은 직물·기계·액체·받이의 설치|V10, V35, V54|직물/금속/관/받이의 서로 다른 주인·지지/연결|소리·냄새·실제 생명·관객 감각|
|4. 실제 방과 작품|실제 방·그림/모형의 대응과 한 차이|V19, V20, V61|서로 다른 매체 경계·대응하는 창/가구·차이의 정확한 소유자|예언·저주·현실 변화의 원인|
|5. 대낮의 타블로|밝은 공간의 성인 집단과 의례처럼 정돈된 배치|V13, V29, V33|인원·무대/통로·방향·현재 접근 경계|혈연·동의·희생·행렬의 시간|
|6. 성물과 손상|성유물함/성화와 내용물/표지의 층위|V25, V28, V30|용기와 파편·그림 속 손과 실제 손·조각 파손의 재료|유골 진위·기적·모독 의도·실제 인체 손상|
|7. 가정의 공백|같은 식탁에서 한 자리의 공백과 문 너머 미확정|V49, V56, V59|정확한 자리 수·점유 상태·문턱·암부의 판독 불가|사별·실종·시간 변화·정신 상태|
|8. 전시와 관객|작품·관람자·라벨·결제 매체가 따로 존재|V53, V62, V63, V64|각 매체·시선·관객/무대 경계·행위의 실제 접촉|거래 완료·공모·강박·저주 인과|

성적·폭력적 소재는 평가 명세에서 삭제하지 않는다. 다른 소재로 자동 대체하여 의미를 충족했다고 판단하지 않는다. 정지 이미지에서 검증할 수 없는 조건은 문맥 평가로 남기고, 후속 구체 요청의 콘텐츠 범위와 도구 요구에 맞게 개별 테스트를 작성한다.

## 비교 설계

1. 각 주제에 대해 현재 대화·일반 지식·필요한 공개 개념 연구로 독립적인 장면을 저술한다. 연구 카드의 정답 문장을 복사한 결과를 자연스러운 창작 품질의 증거로 쓰지 않는다.
2. 실제 요청이 주어졌을 때의 request envelope, creative controls, authorial core를 먼저 동결한다. 위 합성 테스트 명세를 인간 사용자의 지시라고 위장하지 않는다.
3. A는 기존 데이터 노출, B는 기존 데이터와 검토된 보강 데이터 노출로 실행한다. 같은 core·관계 의미·controls·모델·출력 설정을 유지한다. seed가 지원되면 기록하고, 지원되지 않으면 같은 난수 조건이라고 주장하지 않는다.
4. 새 source가 노출되었는지와 실제 선택되었는지를 기록한다. B에서도 선택을 강제하지 않는다. 양쪽이 모두 같은 후보를 쓰거나 새 후보를 모두 거절하면 그것 역시 유효한 관찰이다.
5. 첫 계획 예산은 8개 장면군 × 2조건 × 2반복 = 최대 32개 결과다. 구체적인 모델·비용·도구 예산은 후속 생성 작업에서 확정한다. 이 수는 이번에 생성한 이미지 수가 아니다.
6. A/B를 가린 상태에서 의미 충족과 미적 선호를 별도 기록한다. 작은 표본으로 보강 데이터의 보편적 인과 효과를 단정하지 않는다.

## 기록할 증거

|층위|기록|성공이라고 할 수 있는 범위|
|---|---|---|
|연구|출처·카드·초안·정의 한계|검토 가능한 의미 명세 존재|
|source|CID/RID·원문·조건·field/role 증거|해당 선택의 원문 검토|
|index/search|해시·recipe·vector·receipt·rank|실제 조건에서의 검색 노출|
|선택|selected/rejected CID와 이유|실제 후보 채택 또는 거절|
|프롬프트|확정 core·최종 문장·literal evidence|의미가 프롬프트에 보존됨|
|전송/저장|도구 입력·결과 상태·파일 해시|실제 요청 및 저장 파일 존재|
|픽셀|각 관계 양끝점과 경계의 관찰|해당 가시 조건 충족|
|미적 판단|주인공 존재감·구도·관계·감각적 일관성|평가자가 관찰한 작품의 장단점|
|사용자 수용|사용자가 직접 밝힌 판단|사용자 수용 여부|

가림·작은 투영 크기·저대비 때문에 필요한 관계가 읽히지 않으면 `UNOBSERVABLE_NOT_PASS`다. 옆에 있는 두 물체만으로 접촉·융합·내부 보관이 통과하지 않는다. 전체 장면의 모든 hard 조건이 충족되어야 전체 통과이며 `partial_is_fail`을 유지한다.

출력 차단은 `BLOCKED_UNSCORED`로 보존한다. 이미지가 없으므로 픽셀 합격/불합격을 부여하지 않는다. 불완전한 전송·저장·관찰은 해당 증거층의 미확인으로 남긴다.

## 미적 질문

관계의 정확성 외에, 키워드 설명 없이도 장면의 중심 관계가 읽히는지, 대상이 체크리스트를 시연하는 듯 보이지 않는지, 불안과 아름다움의 관계가 전체 구성에서 작동하는지, 과도한 디테일이 시선을 분산시키는지 평가한다. 조용한 장면과 과잉된 장면을 모두 허용하며 저채도·어둠·고어의 양을 Art Horror의 점수로 쓰지 않는다.

이 평가는 현재 `NOT_RUN`이다. 연구 무결성 검사를 통과해도 이미지 품질이나 사용자 수용을 통과한 것이 아니다.
