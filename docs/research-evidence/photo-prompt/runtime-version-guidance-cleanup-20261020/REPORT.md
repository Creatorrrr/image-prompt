# 구버전 안내 문구 정비 검증

현행 스킬·가이드와 실행 코드의 안내·오류 문구 12개 파일을 정비했다. 현재 팩은 `photo-candidate-pack/v10`으로 안내하고, 별도 버전이 있는 render request와 native generation에는 잘못 붙어 있던 v9 표시를 제거했다. generator 머리말도 공통 후보 풀과 다대다 슬롯 태그, 관리형 진입점에 맞췄다.

실제 generator 입력 별칭 `v9`는 그대로다. 기본 상수, 함수 기본값과 허용값을 수정하지 않았으며 `v9`와 전체 계약명 `photo-candidate-pack/v10`은 모두 같은 V10 계약을 반환한다. 축약형 `v10`과 `v8`은 계속 거부한다. 입력 별칭과 직렬화된 팩 버전을 구별하는 설명을 composition 가이드에 추가했다. 과거 직렬화 표면·장부 읽기와 구 V9 팩 거부에 관한 설명, 원래 봉인된 실행 코드와 기록은 유지했다.

## 검증

- 변경 전후 작업본, HEAD 및 이번 변경만 합친 커밋 예정본 네 경우에서 각각 기존 회귀 검사 116개와 실제 generator의 별칭 허용·거부 4종을 통과했다. 다섯 변경 모듈이 해당 검증 소스에서 로드되는 것도 확인했다.
- Python AST를 비교하여 허용한 진단 문자열·docstring 외의 기본값, 호출, 조건, 바인딩, f-string 표현식이 동일함을 확인했다. 주석 외 실행 구조 변경은 없다. 미커밋 변경이 있는 두 파일의 원래 추가·삭제 바이트도 HEAD/작업본 간에 그대로 보존했다.
- 현재 선택된 H 단독+F2 세대의 `texture` 목표로 정상 관리형 진입점의 view·retrieve·view·compose-audit·deliver 다섯 명령을 변경 예정 소스와 실제 반영 소스에서 통과했다. 발급된 질의 벡터를 재사용했고 상위 8개 및 전체 후보 순서 해시가 원본과 같았다. 공통 풀 전체 18,180 CID / 18,182 RID, 슬롯당 BM25F 1회·로컬 cosine 검색 1회를 유지했다.
- 별도의 과거 `composition`·`lighting` 실행에서 전체 점수·순서 및 H/native receipt·composed 감사를 재현했다. 원래 봉인 native 세대의 863개 member와 실행 감사, 아카이브의 이전·최신 전체 순서 각 225개와 검사 17개도 통과했다. 과거 품질 HOLD는 그대로다. 원래 native 팩으로부터 파생한 공개 view는 변경 전후 바이트가 같았다. 전체 과거 실행을 전수 재현했다는 뜻은 아니다.
- 실제 체크아웃 반영 후 관련 검사 33개와 별칭 4종도 다시 통과했다. 커밋 예정 소스는 Ruff를 통과한다. 기존 미커밋 작업의 `source_key` F841 한 건은 대조군에서도 같으며 이번에 수정하지 않았다.

## 보존 및 범위

보호 목록 193,691개 경로와 CURRENT 168개를 변경 전·반영 후 비교했다. 허용한 12개 파일의 안내 문구 외 내용·권한·inode·hardlink 수를 보존했고, 기존 미커밋 내용, 다른 worktree의 HEAD·index 및 추적 중 미커밋 diff를 유지했다. 병행 작업이 추가한 untracked 파일은 이번 변경에 포함하지 않았다.

후보·태그·검색 문서·인덱스·선택 설정 및 봉인 설치본은 수정하거나 재발행하지 않았다. Gemini·새 임베딩 추론·이미지 API 호출과 CURRENT 변경은 0회다. 검증은 네트워크와 원본 저장소 쓰기를 차단한 임시 복제본에서 수행했으며, 실제 이미지 픽셀 품질 평가는 포함하지 않는다. 이번 변경만 로컬 커밋하고 푸시하지 않는다.

파일 해시, 검증 소스와 실제 별칭 결과는 [VALIDATION.json](VALIDATION.json)에 저장했다.
