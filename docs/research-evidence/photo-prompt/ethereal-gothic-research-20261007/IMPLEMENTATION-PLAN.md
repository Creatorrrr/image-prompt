완료 증거: 실제 팩과 노출·채택·거절·문구 변화 및 기존 회귀 결과. 이 단계의 PASS와 이미지 픽셀 PASS는 다른 판정이다.

## 단계 6. 원본 픽셀의 경계 검증

[픽셀 6그룹](/Users/chasoik/Projects/image-prompt/docs/research-evidence/photo-prompt/ethereal-gothic-research-20261007/EVALUATION-PLAN.json)을 우선적인 탐색 진단으로 사용한다. 초기 제안 한도는 그룹당 두 이미지, 총 최대 12회다. 이는 계획이며 현재 이미지 실행이나 비용을 허가하는 설정이 아니다. 한 그룹에 여러 반대 개념이 있으면 처음에는 한 가지 대조만 선택하고 미검증 개념을 남긴다.

### 실행 전 실험 기록

| 필드 | 필수 내용 |
|---|---|
| 가설 | 어떤 새 저작 의미가 어떤 관찰 경계를 개선할 것으로 보는지 |
| 경쟁 설명 | 기본 프롬프트 자체, 다른 후보, 우연한 샘플이 같은 결과를 만든 가능성 |
| 대조 | 실제 기준/후보 DATA·선택·프롬프트의 차이; 바뀌지 않아야 할 코어·물리/카메라/참조 |
| 예측·판정 | 지정 소유자별 전체 component gate와 해당 hard negative |
| 유효성 | 버전·내용 해시·core·owner·실제 선택·추가 문구·원본 이미지 연결 |
| 자원 | 승인된 호출 한도·이미 사용한 시도·추가 실행의 구별 질문 |
| 상태 | not_run/running/completed/aborted, valid/invalid, supported/refuted/inconclusive, adopt/reject/defer |

같은 코어에서 보완 효과를 비교하려면 실제 최종 문구와 작동 경로에 원래 합의한 차이가 있어야 한다. 비교하려는 형태가 달라진 경우 각 변형의 요청·코어·팩을 다시 만든다. 최종 문장만 바꾸고 같은 고정 실험이라고 주장하지 않는다.

모든 채택 구성요소와 방향 관계를 원본 이미지의 지정 소유자에서 확인한다. 얼굴·눈·미세 레이스는 원본 크기, 중앙축·여백·꽃 배치는 전체 구도에서 확인한다. 다른 꽃의 맞는 수량, 다른 창의 모양, 다른 물체의 질감은 대체 증거가 아니다. 가림·부분 충족은 전체 qualification을 통과시키지 않는다.

기본 프롬프트에 이미 있던 요소나 선택하지 않은 후보의 성공은 새 데이터 효과로 계산하지 않는다. 탐색 몇 장은 범용 성능·미적 수용의 증거가 아니다. 실패를 보존하고 바뀐 가설·입력 없이 반복하지 않는다. 실행 오류·moderation block·원본 없음은 pixel PASS나 가설의 과학적 반증으로 바꾸지 않는다.

완료 증거: 요청·코어·팩·선택·감사·원본·gate별 평가와 원장. 사용자 미적 수용은 별도 상태로 남긴다.

## 후속 데이터 반영의 최종 기준

1. 필요한 P0 관계가 현재 저작 원본에 실제로 반영되고, 재사용·보강·새 sibling의 의미와 기존 ID 보존 근거가 있다.
2. 새로운 후보와 프로필의 소유·부착·가림·초점·표면/영상면 경계 및 명시적 참조가 유효하다. 문맥·보류를 필수 계약으로 승격하지 않는다.
3. 파생 인덱스가 현재 원본과 결합 검사를 통과하며, 비용·재사용·호환성 및 과거 증거 보존이 기록된다.
4. 한·영 직접/간접·부정·반대 형태·재정의·소유 경계에서 실제 후보 노출·채택·프롬프트 변화와 필요한 회귀가 원래 기준으로 판정된다.
5. 채택한 P0 의미의 원본 픽셀 gate가 모두 충족되거나, 미달 항목을 partial/not qualified로 명확히 남긴다. 일부 이미지 성공으로 전체 데이터의 모든 변형을 qualified로 만들지 않는다.
6. 원형의 물리·카메라·피부·의상 가림·인물 수·정서 해석 범위를 보존하고 무관한 작업·기준 바이트를 훼손하지 않는다.
7. 저작 데이터, 조회, 선택, 프롬프트 감사, 원본 픽셀과 사용자 수용을 분리해 보고한다.
8. 계획 수량·출처 수·테스트 수가 실제 개선 증거를 대신하지 않으며 원래 실패/미확정/미실행 결과를 유지한다.

현재 상태는 리서치·계획·연구 초안까지다. 위 구현/조회/픽셀 기준은 미실행이며 이번 연구 구조 검증으로 충족됐다고 표시하지 않는다.
