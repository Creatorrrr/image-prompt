# 추가 조사에서 유지·보류한 데이터 경계

이 보고는 데이터 변경 회차에 포함하지 않는다. 저장소 소스 변경과 제공자 호출은 없으며, 조사 결과를 재사용할 수 있도록 남긴 문서다.

## 인물 존재와 소품 관계: 유지

1,496개 프로필을 실제 로더로 컴파일하고 여섯 대상 계약을 실제 소비자로 확인했다. 인스턴트 사진 카드의 한쪽 모서리 잡기와 제품 강조 장면의 인물 제스처는 원래 후보가 명시한 범위다. 공유 그림자와 착용 갑옷 역시 인물 관계가 본래 개념에 들어 있다. 리볼버의 손 문구는 가리지 않도록 하는 지침이고 손을 증거로 강제하지 않으며, 박격포는 이미 손을 조건부로 표현한다. 일반적인 물체 이름처럼 보인다는 이유만으로 관계를 제거하지 않았다.

## 직물·재료·레이어: 유지

44개 작성 프로필을 검토했다. 실제 계약의 원시 증거 앵커 69개 중 64개가 바로 통과하며, 새틴 다섯 앵커는 기존 최소 단어 수에 맞는 같은 성분 설명을 덧붙이면 통과한다. 이는 데이터 오류나 최소 기준을 낮출 이유가 아니다. 관련 없는 음성 53개는 모두 거절되었다.

몸에 맞는 스트레치 데님, 부드러운 드레이프의 새틴, 별도 안감이 있는 투명 직물, 독립된 드레스 위 메시 레이어는 각각 원래 후보에서 선택한 좁은 변형이다. 특히 이 프로필들의 실제 활성화 문장은 그 세부 관계를 포함하므로 이름만 보고 모든 데님·새틴·메시 의상으로 확대하지 않았다. 일반적인 투명 의류 프로필은 이미 피부·아래 의상·배경이라는 소유 대상 대안을 보존한다. 직물의 섬유 함유율이나 성능을 사진으로 인증했다고 주장하지 않는다.

## 블러셔의 도달 불가능한 예시: 수정 보류

광대에서 관자놀이로 이어지는 블러셔 프로필의 짧은 세 번째 예시는 자체 배제어 `contour stripe`를 포함한다. 단순히 긍정문으로 바꾸면 네 성분을 갖추지 않은 짧은 구절이 의역 예시 우회 경로로 수용될 수 있으므로 그런 수정은 기각했다.

삭제안도 별도로 동결해 기존 실제 인덱스와 벡터 없는 어휘 진단을 비교했다. 16건 모두 후보 ID 집합과 선택 가능 여부는 같지만, 원래 배제된 문장에서는 공간 그라데이션과 물결 곡선 후보의 1·2위가 바뀐다. 새 부적절한 후보 노출은 입증되지 않았다. 독립 질의 열 건은 안정적이지만 자연어 양성 세 건과 올바른 소유 관계 양성 한 건은 양쪽 모두 대상 블러셔를 찾지 못한다. 재현율 개선 없이 죽은 예시를 정리하는 이득만 있으므로 구현·유료 벡터 갱신을 보류했다. 기존 영어/한국어 예시도 문자 그대로 네 성분을 모두 담지는 않으며, 그 의역 경로는 이번 조사에서 바꾸지 않았다.

세 조사 모두 구성된 이미지의 품질을 측정하지 않았다. 컴파일 통과는 전체 의미 정확성이나 픽셀 품질 보증이 아니다. 채택하지 않은 삭제/재작성 제안, 독립 질의, 전체 비교와 유지 근거를 [증거 묶음](diagnostic-evidence.tar.gz)에 남긴다. SHA-256: `75044e83ee0bf30326a8be1dd6283eefc754a7f3e495491533b938e09975b1af`.
