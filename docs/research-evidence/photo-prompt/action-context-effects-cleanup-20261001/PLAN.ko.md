# 행동 → 상황·관계·맥락 → 새 편집 효과 DATA 정비

기준 커밋은 `558e5cbfe0e1139f620c1322b943c5624dbb486f`이며, 시작 시 origin/main을 다시 fetch해 같은 커밋임을 확인했다. 작업 브랜치는 `data-action-context-effects-20261001`이다.

1. 실제 원문·프리셋·관계 소유자·컴포넌트를 읽고 행동 24개, 상황·관계·맥락 16개, 새 편집 효과 12개를 선정한다
2. 수정 전에 52개 원본 상태, 유지/수정 판단, 양성 18개와 대조 탐침 14개를 함께 고정한다. `frozen-sha256.txt`가 그 기록을 고정한다
3. 행동 2개 → 관계·맥락 5개 → 편집 효과 소유자 9개 순으로 실제 불일치만 고친다. 각 단계의 사전 해시·변경 전후 필드·BM25F 결과를 따로 기록한다
4. 동일한 32개 쿼리로 변경 전후 dense를 비교한다. 바뀐 직렬화 문서 16개만 새 벡터를 만들고 나머지 9,871개는 재사용한다
5. 독립 읽기 전용 검토, 기존 정비 회귀·편집 효과·속성 잠금·검색 검사를 통과시킨 뒤 복구 가능한 결과를 저장한다

범위 밖: 검색 알고리즘, 스키마, hard filter, 프로파일 활성화, 속성 잠금 정책, 가중치, 태그, 기존 시각 레지스트리와 시각 프로파일 인덱스. 기존 37개 정비와 관련 없는 원본을 그대로 보존한다. 정당한 왕실·감금·아파트·반려동물·의상/동작 조합·촬영 특수성을 일반화하지 않는다.

기준 aggregate validator의 22개 오류는 새 편집 프로파일 메타데이터와 이전 validator 사이의 기존 불일치다. 이를 없애려고 유효한 discovery/affected-property 필드를 삭제하거나 validator를 느슨하게 바꾸지 않는다.

Gemini는 새 문서 16개와 고정 검색문 32개, 최대 48회로 제한한다. 재시도는 자동 실행하지 않는다. 최대 입력 8,192토큰과 $0.20/백만 토큰을 모두 적용한 추가 상한은 $0.0786432, 기존 프로젝트 누적 보수적 상한은 $0.770048이다. 실제 청구액과 구별한다.

이 쿼리는 실제 후보에서 작성한 진단문이며 독립 holdout이 아니다. 대조 탐침에는 유효한 대안도 있다. 순위가 낮아지지 않은 결과와 역방향 변화도 그대로 기록한다. 이미지 생성·픽셀 품질 평가·게시·푸시·PR·병합은 포함하지 않는다.
