# 행동·상황/관계·새 편집 효과 DATA 정비 결과

## 결과

계획한 세 단계를 완료했다. 실제 후보 52개를 검토해 근거가 확인된 16개만 수정했고 36개는 유지했다. 기준은 main `558e5cbfe0e1139f620c1322b943c5624dbb486f`이며, 작업 브랜치는 `data-action-context-effects-20261001`이다.

- 행동: 24개 점검, 2개 수정. 긍정 검색문에 섞인 ‘셀피 자세를 대체’라는 과거 편집 지시와 직접 전면 카메라 셀피라는 비교 표현을 제거했다
- 상황·관계·맥락: 16개 점검, 5개 수정. 한국어 원문에 있던 우산을 상대 쪽으로 기울이는 방향과 말없이 마주 앉는 관계를 영어에 복원했다. 출근 러시·막차 대기·빗속 산책의 조각 별칭을 완전한 표현으로 바꿨다
- 새 편집 효과: 12개 점검, 9개 수정. 넓은 제안 그룹에서 복사된 효과 소유자를 실제 후보의 범위와 맞췄다. 예를 들어 피사계 심도와 무관한 흐림은 이미지 평면, 수채화·목탄·연필·시아노타입은 사진 속 종이, 종이 찢김은 그 종이의 가장자리에 귀속된다

왕실·감금·밝은 아파트·반려동물 클로즈업·프라이버시·의상 동작 등 근거 있는 특수성은 보존했다. 도서관 책장 넘기기의 무릎/테이블 지지 대안과 버스 문 쪽으로 움직이거나 준비하는 단계도 원문 컴포넌트를 확인해 유지했다.

기존에 게시된 37개 수정, 9,145개 슬롯 항목의 ID와 순서, 프리셋, 가중치·태그·속성 잠금·discovery 설정을 보존했다. 수정된 효과 관계는 기존 로더에 의해 번들 4개의 멤버 관계에도 그대로 반영된다. 검색 로직·스키마·hard filter·시각 프로파일은 변경하지 않았다.

## 고정 검색 비교

수정 전에 원본 52개와 검색문 32개를 SHA-256으로 고정했다. 양성 18개와 대조 탐침 14개를 동일한 슬롯 전체 후보에서 비교했다.

- Dense: 양성 18개 모두 전후 1위 유지
- BM25F: 양성 14/18개가 전후 1위이며, 18개 모두 기존 순위 유지
- Dense 탐침: 3개 순위 하락, 10개 동일, 1개 역방향 변화
- BM25F 탐침: 2개 순위 하락, 12개 동일

예시:

- ‘selfie posture with an outstretched smartphone’의 정중한 직립 후보: BM25F 1→182위, dense 13→101위
- 직접 전면 카메라 셀피 검색의 거울 셀피 후보: BM25F 1→2위, dense 3→4위
- 낮에 지나가는 화물열차 검색의 막차 대기 후보: dense 1→2위
- 역방향 결과: ‘a quiet morning at home’에서 출근 러시 후보가 dense 8→5위로 올라갔다

마지막 결과를 숨기거나 검색문·필터를 바꾸지 않았다. 조각 별칭을 정리해도 기존 일반 키워드와 의미적 겹침은 남는다. 편집 효과 소유자 수정도 해당 탐침들의 순위를 일괄 변화시키지는 않았다.

이 검색문은 실제 후보를 보고 작성한 진단문이며 독립 holdout이 아니다. 일부 탐침은 유효한 대안 장면이다. 슬롯 안의 순위 비교는 다른 슬롯 후보와의 우열, 최종 후보 팩의 채택 여부, 전체 검색 품질이나 이미지 품질 향상을 입증하지 않는다.

## 실제 인덱스와 비용

최종 사전/인덱스 해시는 `ba7c89b746cca5cfabce69c3204fd830d8f7aacc60d0e473f7b0174cb4e199db`이다.

- 실제 파일 기반 인덱스 9,887개 문서와 BM25F·메타데이터·shard checksum 검증 통과
- 변경 문서 16개만 새 벡터를 만들고, 나머지 9,871개는 텍스트와 벡터를 정확히 재사용
- `gemini-embedding-2`, 768차원. 새 문서 16개 + 검색문 32개 = 실제 요청 48회, 모두 한 번씩 성공
- 자동 재시도 0회. 이전 shard 세대 보존. 성공 벡터와 요청별 해시 기록 저장
- 추가 보수적 비용 상한 $0.0786432, 프로젝트 누적 보수적 상한 $0.770048. 실제 청구액은 측정하지 않았다

상한은 공식 [입력 한도](https://ai.google.dev/gemini-api/docs/embeddings) 8,192토큰과 [텍스트 가격](https://ai.google.dev/gemini-api/docs/pricing) $0.20/백만 토큰을 매 요청에 적용한 값이다. 이번 실제 입력은 총 12,220 UTF-8바이트로, 상한과 실사용량은 구별한다.

## 검증과 한계

독립 읽기 전용 검토에서 원본·보존 범위·수정 근거·실제 인덱스·48개 요청/캐시 대응이 확인됐다. 기준, 1·2·3단계, 최종 상태의 32개 검색문을 각각 다시 계산해 dense/BM25F 순위·상위 5개·점수·후보 수가 모두 일치했다.

새 DATA 계약 테스트, 기존 정비 회귀, 일상 장면, BM25F, positive retrieval, 편집 효과, candidate semantics, visual profile retrieval을 검증했다. 총 107개 관련 테스트가 통과했다(67개 + 40개, 새 계약 테스트 8개 포함). 실행 결과는 `validation.json` 및 로그에 기록한다. 인덱스를 갱신하기 전 중간 실행에서 발생한 stale-index 오류도 `pre-index-cleanup-regressions.log`에 남기고, 갱신 후 다시 검증했다.

Aggregate dictionary validator는 전후 동일한 22개 오류를 보고한다. 새 편집 프로파일의 유효한 `core_assertion_discovery`, `affected_dimensions`, `affected_properties`를 이전 validator가 허용하지 않는 기존 문제다. 로그는 바이트 단위로 동일하다. 유효한 메타데이터를 삭제하거나 validator를 수정하지 않았으며, aggregate 통과로 표시하지 않는다.

전체 저장소 테스트, 이미지 생성, 픽셀 검토는 수행하지 않았다. 게시·푸시·PR·병합도 수행하지 않았다.
