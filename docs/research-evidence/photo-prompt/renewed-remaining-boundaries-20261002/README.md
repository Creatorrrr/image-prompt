# 남은 긍정 성분과 제외 경계의 자기 충돌 교정

기준 커밋: `57e29730f0b5c2df336fd1e9dd58374b2025ee03`.

## 변경

거울 셀피, 오버헤드 소셜 사진, 얼굴 가림 무드 사진, 눈밑·상부 볼 블러시, 광대·관자 블러시, 포토부스 4컷, 교체를 미룬 수선의 7개 프로필에서 긍정 성분과 증거 문장에 포함된 자기 제외어를 제거했다. 14개 원본 문자열만 바꾸며 수선 프로필의 파생 투영을 포함하면 컴파일 결과는 16곳이다. 거울 셀피에 얼굴 가림을 새 필수 조건으로 만들지 않았고, 무드 사진의 고개 돌림도 보존했다. 한국어, 정의, 제외어, 필수 성분, 증거 길이, 렌더 게이트, 검색 로직은 유지했다.

## 측정 결과

- 원본 성분을 조합한 영어 진단 0/7→7/7, 기존 한국어 6/6 유지
- 전체 1,419개 프로필의 첫 영어 성분을 조합한 자기 제외 충돌: 이번 작업 전 7개→0개. 이번 24시간 작업의 첫 기준에서는 21개였다. 이는 제한된 데이터 일관성 검사이며 자연어 검색 정확도가 아니다
- 제외어 66개, 성분 누락 61개, 단일 성분 61개, 부정 별칭 68개에서 대상 프로필 활성화 0 유지. 실제 성인 맥락을 적용한 별칭 34개 결과 유지
- 기존 의역 20개 중 17개 활성화 유지. 성분 문자열과 글자가 다르다는 이유만으로 유효한 의역을 불완전하다고 재분류하지 않았다
- 별도로 작성한 장면 14개는 대상 검색 0→0, 모든 후보 ID와 순서 유지. 일부 장면은 프로필의 구체적 필수 조건을 충족하지 않아 이 수치를 독립 정답률로 볼 수 없다
- 같은 입력의 주변 선택 후보에서 2건의 컷오프 교체가 있었다. 단일 성분 사례의 필름 그레인, 부정 별칭 사례의 소유 관계 후보가 새로 들어왔다. 자세한 전후 ID·순위·점수는 자료에 기록했다. 전체 검색 무퇴보를 주장하지 않는다
- 경계 증거 자체의 감사 통과 4/7→7/7. 다른 짧은 증거 단서만으로 전체 프로필 감사가 통과한다는 의미는 아니다

## 테스트와 기존 근거 누락

확장 69개 테스트 중 68개 통과. 기존 픽셀 근거 검사 1개에서 PNG 3개가 없어 하위 사례 3개가 실패했다. 별도의 수정 전 Git 스냅샷에서도 동일 실패를 재현했다. 파일은 기준 커밋에도 포함되어 있지 않았다. 실패를 건너뛰거나 테스트를 수정하지 않았다. 로그 두 개를 함께 제공한다. 새 회귀 테스트 4개와 이전 경계 테스트를 합친 16개는 통과했다. 사전 메타데이터와 실제 인덱스 검증도 통과했다.

벡터 7개를 새 텍스트로 갱신하고 나머지 1,412개는 그대로 보존했다. 이 단계 성공 임베딩 7회, 보수적 비용 상한 $0.0114688. 프로젝트 누적 상한 $1.3975552 / 허용 $10이며 실제 청구 금액은 아니다.

정상 공개 CLI·최종 구성 프롬프트·이미지 생성 품질의 개선은 이 단계에서 측정하지 않았다. 진단의 전후 입력이 달라지는 원본 성분 조합과 고정 입력 대조를 분리해 기록했다.
