# 스페이스 호러 데이터 반영 및 독립 이미지 테스트

이 문서는 2026-10-22에 시작한 조사·구현 작업의 후속 실행 기록이다. 원본 리서치 40개 파일은 변경하지 않았다. 이미지 테스트와 직접 픽셀 검토 결과를 아래에 기록했다.

## 반영한 데이터

- 시각 의미 카드 64개, 문맥 구분 20개, 원 대화의 키워드 경로 200개.
- 새 선택형 시각 후보 53개, 수정 없이 참조한 기존 후보 5개.
- 양성 후보 검색에서 제외한 진단·문맥 기록 26개: 보류 카드 6개와 문맥 기록 20개.
- 새 선택형 바인딩 146개. 기존 후보, 조건, 효과, 카탈로그와 정책을 유지했다.
- 각 카드에 관찰 가능한 구성 요소, 소유자, 방향 관계, 가까운 혼동, 출처 범위와 한계, 후보 매핑을 유지했다.

관련 소스는 `skills/photo-prompt-image-generator/assets/photo_space_horror_semantics_20261022.json`, `photo_candidate_space_horror_20261022.json`, `photo_candidate_space_horror_bindings_20261022.json`과 `references/space-horror-semantics.md`이다. 연구 관계 그래프와 출처는 검토 자료이며 native 사실·채택 권한으로 승격하지 않았다.

## 설치 및 검증

이번 이미지 테스트에 고정한 H-F2 generation: `c34c69bb6a031f2938987cc687a51481e01d24710e7ba06f5e05f4130a91f849`. Native generation: `f764682eefe81421e209e28d5dddfeb63981a25834c73799790f44a09fcff431`.

기존 설치본의 후보 19,879개를 보존하고 79개 기록을 추가했다. 운영 양성 후보는 19,551개, 실현 문서는 19,553개다. 기존 문서 벡터 19,500개를 그대로 재사용했고 새 문서 벡터 53개를 로컬 모델에서 계산했다. 진단 26개는 양성 검색 대상에 포함하지 않았다. 공식 설치기를 비활성 설치→검증→활성화 순서로 사용했고 native CURRENT는 변경하지 않았다.

최신 canonical SKILL 및 최근 변경 계약을 확인했다. 설치본의 canonical V4 데이터 처리와 호환되는 구현을 유지하고 누락된 capability-clause 변경만 명시적으로 추가했다. 무차별 코드 복사 시 V3/V4 비호환을 발견해 해당 비활성 시도는 폐기했으며 검증을 우회하지 않았다. `latest-reviewed-delta-resolved.json`, `execution-notes.json`과 검증 보고서가 근거다.

- 주제 문맥·네거티브 정책 회귀 13개, capability-clause 회귀 3개 통과.
- 한·영 직접 작성 개발 질의 16/16에서 목표 후보가 상위 10개에 노출.
- 일반 사진 대조 질의 4개에서 새 후보의 상위 10개 노출 0개. 별도 혼동 경계 질의 4개도 기록.
- 설치본의 실제 `h-f2-v2` recorder, NumPy 및 버전 파생 검사 통과.
- 기존 연구 파일 40/40의 해시 보존, 새 소스 구조·진단 제외·바인딩 불변식 통과.

검색 수치는 직접 작성한 개발 점검이며 독립 holdout이나 이전 버전 대비 개선율이 아니다. 검색 노출은 호환성, 프롬프트 사용, 실제 픽셀 성공을 각각 입증하지 않는다. 전체 64개 카드의 픽셀 검증도 아니다.

대용량 사설 빌드 산출물은 `build-cache-relocation.json`에 기록한 작업 전용 캐시에 보존했다. 검토용 문서에는 입력·변환 코드·출력 해시와 seals를 남겼다. 운영 설치본은 연구/빌드 경로에 의존하지 않는다.

## 독립 테스트 설계

사용자가 요청한 세 서브에이전트를 `fork_turns=none`으로 분리했다. 각자 일반 지식과 참조 외형, 최신 SKILL/허용된 중립 precore만으로 컨셉을 무작위 선택하고 기본 프롬프트·테스트케이스를 확정했다. 후보나 조사 결과는 고정 이후에만 보았다. 다른 arm의 프롬프트나 결과는 공유하지 않았다. 파일 시스템은 같은 checkout이며 독립성 선언을 물리적 접근 통제 증명으로 해석하지 않는다.

참조 사진은 외형 안내로만 사용하며 실제 신원·나이·전기를 추정하지 않는다. 저장된 기본 제어값은 sensual=1, fetish=0, creativity=1, surreal=0이며 agent가 고른 장면·소품·행위는 requester lock이 아니다.

### 후속 검증 계획

1. A의 수면·팬 겹침을 줄여 팬-줄기-고정점-바닥을 같은 시야에서 추적하는 구도로 재검증한다. 손의 좌우는 각 팔의 어깨부터 접점까지 분리해 판정한다.
2. B는 막 전체 경계와 미봉합 틈의 가독성을 우선 확보하고, 흐름의 시작점과 열린 bay 쪽 도착점을 분리해 검증한다. 보기 좋은 누출 연출을 압력 방향의 증거로 인정하지 않는다.
3. C는 난간을 잡는 손과 조작부에 접근하는 손의 역할을 나누고, 실제 빈 간격이 보이는 구도로 접촉/비접촉을 검증한다. 표적이 일상적인 마네킹으로만 읽히는 한계도 별도 판단한다.
4. 신규 후보의 효과를 검증하려면 같은 requester 의미·참조·제어값 아래에서 baseline과 실제 호환되는 후보 기반 대안을 대응 비교한다. 후보의 전체 의미를 보존하고 채택은 선택으로 유지한다. 지금 결과에서 강제 채택이나 개선율을 만들어 내지 않는다.

위 재생성·대응 비교는 이번 3회 호출 이후 실행하지 않은 후속 계획이다. 이번 이미지의 실패를 연구 카드나 후보 자체의 실패로 자동 승격하지 않았고, 임의의 native qualification도 추가하지 않았다.
