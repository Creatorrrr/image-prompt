ReactorPrompt 패션 후보·의미 데이터와 검색·선택 지침을 발행한다. 원격 main의 기존 모듈과 코드를 보존하고 패션 후보/바인딩 4개 모듈을 추가했다. 검색 인덱스는 합쳐진 원본에 맞춰 다시 검증한다.

최신 결과는 [creativity=2 재시험](retest-creativity2-20261026/RESULTS.md)과 [기계 판독 결과](retest-creativity2-20261026/FINAL.json)에 있다. 같은 사진, 독립 Luna max 저자3명, 각1회 이미지 호출을 검증했다. 신규 코호트의 크림색 하이넥 니트/별도 남색 코트1건은 프롬프트와 픽셀에 반영됐다. 별도로 보강한8개는 검색 창1건·실제 표본0건·직접 기여0건이다. 부분 충족과 관찰 불가능을 통과로 바꾸지 않았다.

최초34개 후보와 확장2430개 후보의 원본,2,556개 용어의 최종 CSV/압축 JSON, 해시가 일치하는 생성 이미지3장, 실제 호출·비교·픽셀 기록을 함께 보존했다. 기존 RESULTS.md/EXPANSION-RESULTS.md는 당시 상태를 설명하는 역사적 기록이다. 원본 사진과 원문 수집 corpus는 로컬에 유지한다. 보고서의 절대 경로는 원래 실행 위치의 provenance이고, 이 폴더의 사본은 publication-evidence/source-scope.json이 원본 SHA와 대응시킨다.

세 지침 파일은 작업 전/후 차이만 main에3-way 병합했다. 다른 미발행 코드와 런타임 선택 설정은 포함하지 않았다. 시험에 사용한 sealed e8d4/7c878 버전과 발행 저장소의 기존 기본 런타임은 별개다. source/index 발행이 새 default runtime 설치나 native 후보 일괄 승인, 사용자 수용을 뜻하지 않는다.
