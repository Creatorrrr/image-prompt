# 8개 후보의 검색 누락과 이번 보완

8개 후보는 누락된 색인이 아니다. 실제 설치·선택된 e8d4f903… 색인에 8개 모두와 각 5개 alias가 존재한다. 직전 재시험 42개 질의를 동일 색인의 전체 후보 순위로 확인했을 때, 후보별 최고 순위는 368, 416, 583, 1860, 2212, 1111, 1345, 1026위였다. 따라서 기존 creativity=1의 상위 32개는 물론 creativity=2의 상위 96개에도 들지 못했다. 표본 추출 이전의 순위 문제와 표본에 나온 후보의 선택 문제를 구분해야 한다.

기존 질의는 의상 관련 역할을 지정하면서도 기본안의 실제 의상명·소재·형태 정보를 지우고 넓은 읽힘/분위기 질문으로 추상화했다. A안의 셔츠·민소매 의상, B안의 재킷·치마, C안의 구체적 코트·직물 정보가 충분히 전달되지 않았다. 추가 alias만으로 이 정보 손실과 전체 24,076 CID 후보군의 경쟁을 상쇄하지 못했다. 전체 순위 범위는 368–2,212위이고, 개별 후보에 지정된 역할 질의만 집계한 범위 368–9,714위와 다르다.

동일한 엔진과 저장 벡터에서 기본안에 근거한 구체 질의 9개를 진단한 결과, 회색 헤링본 코트 후보 한 개가 66위 및 교차 역할 92위에 들어왔다. 다른 7개는 여전히 96위 밖이었다. 이 진단 질의는 조사자가 alias를 이미 본 뒤 작성했으므로 독립 시험의 성과로 세지 않는다. 표본 채택·프롬프트 반영·이미지 구현의 증거도 아니다. 세 신규 저자에게 이 후보의 ID나 묘사를 전달하지 않았다.

선택 단계에서도 기본안의 에이전트 선택을 요청자 요구로 오인하는 문제가 있었다. 예를 들어 required owner/presence 증거를 `The human subject stands` 전체로 묶으면 요청자가 지정하지 않은 서 있는 자세까지 사실상 보존 조건이 된다. 이런 행은 새로 동결하기 전에 최소 식별 구절로 작성하고, 진짜 요청 행동·관계는 별도 근거로 완전하게 보존하도록 안내를 보완했다. 이미 동결한 행은 수정하지 않고 새 core를 만들어 원본을 보존했다.

이번 변경은 다음 세 지침 파일에 한정한 문서 변경이다.

- `SKILL.md`: 자기 기본안의 역할에 맞는 실제 의상·소재·관계 정보를 검색 질의에 유지한다. 편집 가능한 정보라는 이유로 검색에서 삭제하지 않는다. 필수 식별 증거와 선택적 연출도 구분한다.
- `references/composition-contract.md`: creativity 2–3에서 요청자가 정하지 않은 옷·색·장면이 다르다는 이유만으로 후보를 부적합으로 판정하지 않는다. 양립 가능한 교체·재구성을 완전한 대안 사진으로 구체화해 비교한다. 진짜 출처 조건과 보호된 요구는 그대로 지킨다.
- `precore/photo_semantic_witnesses.md`: owner/role/category/presence의 최소 식별 증거, 완전한 요청 원문 provenance, 별도로 보호할 실제 사실·관계를 분리한다. 동결 증거를 사후 축소하지 않는다.

두 변경 묶음은 독립 검토를 통과했다. 설치된 검색·생성 런타임 코드·후보 레코드·색인·점수식·추출 알고리즘·후보 조건은 이번에 바꾸지 않았다. 별도의 시험용 근거 대조 helper는 추가했다. 과거 8개 alias 보강을 또 다른 후보 추가로 세지 않는다.

새 질의의 사전 기술 검토에서는 추가 한계도 확인했다. 비유적 `connected`와 `hand`를 신체 연결로, 배경의 `water`와 옷의 `silhouette`/`contour`를 물로 된 형체로 해석하는 오분류가 있었다. 전자는 실제 손끝과 옷깃 천의 접촉으로 명확히 썼다. 후자는 owner를 명시해도 오분류가 남아, 구성 역할에 필요한 원경의 부두·항구 전망으로 맥락을 간결하게 썼다. 기본안과 보호 조건은 그대로이며, 중간 질의도 보존했다. 이는 이번 저술·검토 절차의 보완이다. 설치된 파서의 일반적인 owner 해석 결함까지 고친 것으로 주장하지 않는다.

재시험은 같은 사진의 동일 SHA-256, 독립 gpt-6-luna/max 저자 3명, creativity=2로 수행한다. 세 기본안과 모든 질의를 검색 전에 확정하고, 기존 상위 96개/질의별 최대 12개 정책과 최초 seed를 그대로 사용한다. 실제 후보 노출, 출처 전체 조건, 기본안 대비 새 literal 구절, 실제 저장 이미지의 관찰 가능한 단서를 별도로 평가한다. 특정 후보 채택·표본 재추첨·이전 이미지 모방은 요구하지 않는다.

실제 재시험 검색은 26개 질의·312개 표본 발생 건으로 완료됐다. 신규 코호트는 상위 창에 67종(중복149건), 실제 표본에 17종(중복19건)이 들어왔다. 별도 8개 중 갈색 스웨이드 로퍼가 C안 footwear의 발급된 창에서 25번째였으나 최초 표본에 선택되지는 않았다. 나머지 7개도 표본에 없었다. 따라서 이 8개의 이미지 기여를 이번 표본에서 주장할 수 없다. 전체 신규 코호트의 프롬프트·픽셀 기여는 최종 결과에서 따로 집계한다.

출처 검토의 페이지 누락도 검사했다. C안이 처음에 마지막40/104종만 집계한 것을 root가 발견하여 첫 페이지64종을 같은 바인딩에서 읽게 했다. 별도 검색 없이 저장된 source-view 페이지의 CID/RID/hash 및 질의 tuple을 발급 표본과 대조했다. 최종 저장 범위는 A83종/96건, B88종/96건, C104종/120건으로 모두 일치한다. 이 검사는 검토에 필요한 원문 범위가 갖춰졌다는 증거이며 저자의 이해나 채택 자격 자체를 자동 증명하지는 않는다. 보완 helper와 경미한 절차 편차는 photo-runs의 SOURCE-VIEW-COVERAGE.json 및 PROCESS-DEVIATIONS.json에 남겼다.

생성 전 실제 선택 기록 검토에서는 C안이 서로 다른 신발 출처에 같은 판단 문구를 재사용하며 불투명 타이츠·페이턴트 로퍼와 검정 정장 구두에 반투명/하이힐 속성을 섞은 것도 발견했다. 또 패딩 숄더 블레이저·하트형 네크라인·비닐 쇼츠의 전체 효과가 없는 다른 대안을 근거로 비교 완료라고 쓴 행이 있었다. 같은 저자가 실제 5개 출처의 전체 효과를 구현한 A7–A11을 추가하고 원문에 맞는 비교 이유로 교정했다. 원본과 교정 후 기록을 모두 보존했고 root가 내용을 대조했다. 발급·선택 행의 개수 일치만으로 의미 검토가 충분하다고 보지 않았으며, 이 교정은 특정 후보 채택을 강제하지 않았다.

이번에는 기본안·질의·creativity가 함께 달라지고 이전 기본안의 대조 이미지를 새로 생성하지 않는다. 따라서 실제 반영 여부는 검증할 수 있지만 변경 하나의 인과 효과나 이미지 품질 향상을 분리해서 입증할 수 없다. 8개가 모두 상위권에 오르게 됐다는 주장도 실제 결과 없이 할 수 없다. 재시험 최종 수치는 photo-runs의 RESULTS.md/FINAL.json에 별도로 기록한다.
