# 신규 패션 후보 기여 0건 분석 및 보완 범위

이전 3개 생성에서 신규 코호트는 160개 반환 occurrence 중 7회(5개 CID) 노출됐으나 최종 기여가 없었다. 6회는 일반 topic 검색, 1회만 소재 역할 검색이었다. 검색에서 완전히 누락된 결과가 아니다. 노출된 원문은 아동복 모티프 분기, 두 인물의 교복, 특정 의상에 맞춘 장식, 의상-액세서리 같은 착용자 관계, 착용자 어깨를 덮는 니트/울 대안 등 실제 장면의 대상·인원·조건과 맞지 않았다.

case B는 사용자가 정하지 않은 의상/소재/상황까지 닫고 framing만 열었다. 또한 random/different 컨셉 선택 지시가 visual topic query에 포함됐다. 이 두 항목은 검색·선택 과정의 실제 보완 대상이다. H-F2 검색은 전체 positive pool, 두 lane과 기존 rank-window sampler를 유지한다. 특정 CID 우대나 seed 반복은 원인 근거가 없다.

모든 2,430개가 EN/KO 본문을 이미 보유한다. 번역 부재가 아닌 자연 검색 표현과 실제 의상 역할 표현을 보강한다. 원문에만 있고 현재 카드에 없는 인접 세부를 별칭으로 추가하지 않으며 조건/소유자/효과/승인 상태를 보존한다. 신규 중복 카드는 추가하지 않는다.

검색 노출, 일반적 authorial inspiration, native 계약 채택, 제출 문구의 신규 변화, 저장 이미지의 실제 관찰을 별도로 검증한다. native 승인 부재 하나만으로 일반적 영감 0건까지 설명하지 않는다. 반대로 검색 노출만으로 신규 데이터가 이미지에 반영됐다고 보고하지 않는다.
