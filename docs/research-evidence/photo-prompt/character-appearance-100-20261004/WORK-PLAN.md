# 캐릭터 외형 100개 추가 조사와 반영

- 기존 37개와 다른 캐릭터 100개를 공식 출처의 특정 도판 버전으로 식별한다.
- 홀로라이브, 길티기어 스트라이브, 철권 8, 포켓몬, 귀멸의 칼날에서 각 20개를 조사한다.
- 캐릭터마다 도판 바이트 해시와 외형 요소, 연결 관계, 혼동 경계, 미확인 구조를 기록한다.
- 기존 의미는 동일 owner의 긍정 대체 표현으로 보강하고, 신규 관계는 현재 runtime 스키마의 profile로 추가한다.
- 캐릭터 고유명은 출처와 사례 식별에만 사용하며 새 인물의 외형을 자동 변경하는 activation으로 쓰지 않는다.
- 연구 기록과 런타임 profile 사이를 각 요소 단위로 연결하고 100개 전체의 반영 여부를 점검한다.
- 시각 의미 인덱스를 갱신하고 기존 definition, activation, property effect, render gate의 보존을 검증한다.
- 데이터 검증, 실제 인덱스 검색 점검, 전체 unittest discovery를 실행한다. 이미지 생성 평가와 이번 데이터 검증은 별도 근거다.
