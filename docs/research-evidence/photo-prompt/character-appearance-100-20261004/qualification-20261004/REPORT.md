# 캐릭터 외형 데이터 반영 후 독립 이미지 재검증

같은 첨부 사진으로 독립 서브에이전트 3개가 서로 다른 난수 시드와 복잡한 사진 컨셉을 정했다. 후보팩·프롬프트·픽셀 기준을 고정한 뒤 내장 image_gen 도구로 각 1장, 총 3장을 생성했다. 재시도와 CLI/API 대체는 없었다. 생성된 원본 파일과 실제 실행 프롬프트·참조 입력·해시·원장을 보존했다.

**외형 항목만 모두 만족한 장면은 1/3개다. 전체 장면 조건과 이번 시각 의미 통합의 후보 노출·선택까지 통과한 장면은 0/3개다.** 조정자 교차 평가에서 외형 항목은 총 14/20개가 통과했다. 부분 구현과 필요한 부분의 가림을 통과로 집계하지 않았다. 사용자 선호와 수락은 아직 확인하지 않았다.

현재 레지스트리 1,671개와 정확 조회 표현 3,935개의 인덱스 바인딩은 유효했다. 고정한 원본 데이터·인덱스·생성기·설정·중립 카탈로그 36개 파일은 실행 전후 동일했다. 각 실행의 원본 요청, 코어, 기준, 실제 도구 인수, 런타임 문자열, 참조 해시, 출력 해시, 원장·매니페스트 연결 등 23개 검사도 모두 통과했다. 프롬프트·실행 요청 검증은 3/3 통과했지만 이것을 픽셀 통과로 해석하지 않았다.

**후보 노출 결과**

세 후보팩은 각각 기존 시각 의미 후보 8개를 노출했다. 그 목록은 이번 신규 49개·기존 보강 61개와 교집합이 없었으며 시각 의미 선택도 세 실행 모두 0개였다. 일반 후보에서는 세 번째 실행의 연결된 팔·여백 포즈 1개만 선택됐다. 이 일반 후보는 이번 외형 100개 통합의 선택 증거가 아니다.

| 실행 | 독립 프롬프트와 연결되는 이번 의미 | 실제 의미 후보 노출 / 선택 |
|---|---|---|
| 1 | ca_compact_bob, ca_blunt_fringe, ca_spectacle_frame | 0/3 · 0/3 |
| 2 | ca_compact_bob, sca_x15, y2kr_visible_layers | 0/3 · 0/3 |

첫 실행의 clothing_ct108_v2 귀걸이 연결은 스터드 연결부가 처방되지 않은 부분 대응이다. 완전한 원본 프로필 평가 분모에 포함하지 않았다. 세 번째 실행의 전체 110개 목록과 교집합이 없다는 것은 110개 각각에 대한 검색 재현율 시험 결과가 아니다. 하단 얼굴 감김을 어깨 천으로, 손목 커프를 위팔 커프로 대체하지 않았다.

별도 어휘 진단에서 첫 두 코어의 관련 표현 6개는 현재 구성 요소 매처와 일치하지 않았고, 같은 프로필의 등록 정의는 모두 일치했다. 이는 실제 자연 문장과 등록된 대체 표현 사이의 누락을 보여준다. 이 진단은 고정한 baseline만 검사했으며 전체 검색 점수·후보 상한의 인과관계를 재현한 결과는 아니다. 새 의미가 이미지에 등장하더라도 후보 노출·선택이 없었으므로 통합 데이터가 그 픽셀을 만들었다는 효과는 입증하지 못했다.

**평가자 차이와 판정 경계**

첫 실행의 작성자는 단발의 명시적 blunt-cut 변형이 부족해 실패로 보고 베레모 형태는 통과로 봤다. 조정자는 등록된 compact-bob 구성 관계를 통과로 보고, 완전한 베레모 윗선이 잘린 것을 실패로 봤다. 두 평가 모두 2/7이며 각 항목의 차이를 그대로 보존했다. 오른쪽 귀 부위의 가림은 조정자 기록에서 UNOBSERVABLE이다. 이를 귀 장식의 실제 부재로 진단하거나 통과로 추정하지 않는다.

일반 신체·가시성 게이트는 작성자 평가 4/5 · 5/5 · 4/5, 조정자 초기 원본 평가 5/5 · 5/5 · 5/5다. 첫 실행에서 지정 귀·머리 가시성을 신체 투영의 필수 부분으로 포함할지, 세 번째 실행에서 비행동 손의 잘린 손끝을 가시성 실패로 볼지에 차이가 있다. 고정한 최종 embodiment 리뷰에는 첫 실행의 전체 머리·오른쪽 귀, 세 번째 실행의 양손 가시성이 명시돼 있다. 최종 수락에는 보수적으로 두 평가가 모두 통과한 항목만 인정하며, 이 차이를 이용해 전체 성공을 선언하지 않는다. 외형·전체 장면·통합 데이터의 비통과 결론은 어느 평가에서도 같다.

**절차 기록**

각 실행은 다른 실행의 프롬프트·팩·이미지를 입력으로 사용하지 않았다. 1·2번은 개발자 지침에 따른 운영 MEMORY.md 검색을 코어 고정 전에 실행해 엄격한 pre-core 허용목록만의 입력이었다고 주장하지 않는다. 예전 장면 프롬프트·팩·원본 이미지나 현재 다른 실행은 읽지 않았다고 기록했다. 3번은 메모리 파일 조회를 하지 않았다. 자동 제공된 개발자 메모리 요약은 존재했다.

리뷰 저장 과정에서 조정자와 작성자 리뷰의 파일명이 겹쳐 별도 경로로 분리했다. 1번 작성자 리뷰는 원래 바이트를 그대로 복원했다. 3번은 남아 있던 실행 코드·기본 리뷰·결과에서 원래 판정과 근거를 복구했으며 원래 정확한 리뷰 시각과 JSON 바이트는 확인되지 않아 복구 기록에 명시했다. 기준·코어·팩·프롬프트·이미지·원장은 바꾸지 않았다. 작성자 리뷰는 각 self_pixel_review.json, 교차 리뷰는 각 independent_pixel_review.json과 coordinator-native-inspection/에 따로 저장돼 있다.

**결과에 따른 후속 반영 계획**

1. 관련 5개 고유 의미(ca_compact_bob, ca_blunt_fringe, ca_spectacle_frame, sca_x15, y2kr_visible_layers)에 이번 고정 프롬프트의 자연 문장을 별도 홀드아웃으로 남긴다. 소유자와 모든 구성 관계를 보존하는 한영 대체 표현을 보강하고, 부분 표현을 완전한 증거로 승격시키지 않는다.
2. 실제 코어→선택 가능한 후보 노출까지 평가하는 회귀 사례를 추가한다. 레지스트리·벡터 등록 성공과 실제 후보 노출·선택을 각각 검증한다. 연구 캐릭터 이름만으로 외형을 활성화하지 않는다.
3. 다음 생성 시험 전에 blunt bob 변형과 compact bob 관계, 완전한 모자 외곽, 해부학적 좌우, 실제로 볼 수 있는 손 접촉, 버클 핀·고리 경로를 각기 명확한 기준으로 분리한다. 가려진 접촉을 같은 프레임에서 증명할 수 있는지 사전에 점검한다.
4. 다음 실행은 작성자·교차 평가 경로를 처음부터 분리하고, 운영 메모리의 조회 범위를 기록한다. 이번 실패 이미지는 보존한다. 이 요청에서는 고정한 데이터를 수정하거나 다시 생성하지 않았다.
