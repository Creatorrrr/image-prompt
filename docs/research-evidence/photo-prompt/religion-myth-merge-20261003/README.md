# 종교·신화 데이터와 원격 검색 개선의 통합

원격 검색·슬롯 배분 개선과 로컬 종교·신화 의미 대체 표현을 함께 유지했다. 로컬 부모와 원격 부모 및 정확한 소스 SHA는 SOURCE-BINDING.json에 기록했다.

- 원격: 대상별 독립 근거 검색, 주 대상의 선택적 유형 전달, 슬롯별 공정 배분, 기존 property 권한 검사, 식물·액체·격자 그림자·단일 식사 배분 및 아세테이트 도상 대체 표현.
- 로컬: 의미 프로파일 54개와 기존 12개 보강, 선택적 구도 80개와 기존 후보 64개 보강, 의미 구성요소 확인 조건, 6개 native 원본과 엄격한 0/3 통과 판정.
- 생성기 병합 결과는 원격 코드에 로컬 확장 로더 2줄을 추가한 형태다. 파생 시각 인덱스는 양쪽의 호환 벡터를 재사용해 다시 생성했다. 의미 인덱스 9,819개는 소스 메타데이터 검증을 통과했다.
- 같은 이름의 두 v6 사진 기준을 각각 그대로 보존했다. 원격 v6는 기존 경로, 로컬 v6는 photo_regression_baseline_v6_religion_iconography.json이다. 현재 통합 결과는 v7이다. v7은 양쪽 기록의 해시, 4개 동결 입력, 장면·창작·구현 계약, 후보 상한 64개와 기존 negative를 고정한다. 과거 v6 관찰 테스트는 명시적 v6 진단 모드로 원래 관찰 데이터를 검사한다.
- current universal v2 메타데이터는 최종 validator SHA 한 필드만 갱신했다. 과거 오라클과 holdout, 픽셀 실패 라벨은 바꾸지 않았다.
- 머지된 코드에서 세 동결 컨셉의 기존 채택 의미 모두 노출된다. MERGED-RETRIEVAL.json은 실제 재검색 결과이며, 새 이미지 성공을 뜻하지 않는다.

집중 검사 38개는 통과했다. 첫 병합 소스 ba0f45c1에 대한 전체 모듈 격리 검사로 147개 모듈, 1,305개 테스트를 빠짐없이 실행했다. 첫 실행에서 후보 순서에 의존하던 테스트 하나가 실패했다. 의도한 묶음을 고유 ID로 선택하도록 고친 뒤 해당 모듈 13개를 다시 실행해 모두 통과했다. 원래 실패 기록을 full-suite/summary.json에 보존했고, 재검사와 ID별 최종 결과는 VERIFICATION.json에 기록했다. 의미 구성요소·관계·full view·감사·변조 차단 조건을 유지했다.

검사 실행자는 데이터와 코드의 시작 해시를 기록하고 provider 키를 빈 값으로 고정했다. verify_merge.py가 모든 모듈과 재검사의 코드 23개 및 데이터 79개 해시를 첫 병합 소스와 대조했다. 양쪽 authored 파일과 두 v6의 원본 바이트 및 universal v2의 validator SHA 외 불변성도 확인했다. 이 기록은 첫 병합 소스에 대한 검증이며, 이후 원격 추가 변경의 재병합은 별도 후속 증거로 남긴다.

원래 통합 증거의 boundary-replay-preintegration 격리 체크아웃과 중간 인덱스 세대는 로컬 진단 자료로 남겼다. 해당 절대 경로 심볼릭 링크는 커밋에 넣지 않았다. 원본 의미 데이터 스냅샷, 최초/최종 후보팩, 생성 원본과 해시 및 검증 로그는 앞선 로컬 부모 커밋에 보존되어 있다. 다른 작업의 slang-visual-semantics와 subculture-appearance 자료는 변경하거나 커밋하지 않았다.
