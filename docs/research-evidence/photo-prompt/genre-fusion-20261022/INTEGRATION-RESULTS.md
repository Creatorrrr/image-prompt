# 장르 조합 데이터 반영 및 독립 생성 실험

2026-10-22. Dying Earth × New Weird × Cozy Fantasy × Cosmic Horror.

연구 초안을 실제 시각 의미 registry·후보 corpus·작업용 인덱스·설치용 검색 세대에 반영했다. 새 자료는 선택 가능한 구체적 장면이며 장르명을 입력했다는 이유로 자동 적용되지 않는다. 출처의 개념 설명과 새로 저술한 물건·구도·관계의 제안을 구분한다.

## 실행·검색 검증

기존 설치 엔진 코드와 임베딩 공간을 보존했다. 기존 RID 벡터 18,947개를 바이트 단위로 재사용하고 새 긍정 문서 84개를 로컬 임베딩했다. 전체 BM25F 통계를 새 corpus로 재계산했으며, 새로운 source/index closure를 검증한 뒤 기본 설정을 교체했다. native `CURRENT.json`은 쓰지 않았다.

- Native generation: `96233daebb54195a59878d6df5ece6af64cdde3cf6b43f074a06c2953094b3e4`
- 보존한 엔진 코드 SHA-256: `96b67dedcfea019115cd46c6542287d7102e46cd12a486f1e817d79f3c634d0e`
- 최신 작업 스킬 SHA-256: `7fe5b6cfc2da6e65dd9b9dc999e46d70a1fac7dce8c47157e53c1cba43b00f35`

작업용 dictionary/index 검증과 설치 검증, 활성화 후 runtime 확인이 통과했다. 관련 경계·문맥·원문·whole-scene·sampling 회귀 테스트는 97개 통과했다. 실행 로그와 검증 JSON은 [integration-evidence](integration-evidence/)에 있다.

[68개 한영 사례](EVALUATION-CASES.tsv)를 각각 두 언어로 실행하여 136개 질의, 반영 전후 272회 검색을 수행했다. 개발 질의 64개 모두 목표 CID가 상위 8개 안에 노출됐다. 이 목표들은 새 CID이며 반영 전 세대에는 없다. 저술한 개발 세트이므로 독립 holdout, 일반 사용자 검색 개선율 또는 생성 품질의 인과 증거는 아니다. 관리형 run에서의 slot projection·표본 노출과도 구분한다.

경계·일반·비가시 대조 72개 질의 중 41개(경계 22, 일반 14, 비가시 5)에 새 후보가 상위 8개 안에 노출됐다. 58개 질의–새 후보 쌍의 실제 긍정 원문과 의미 차이를 [control-exposure-review.json](integration-evidence/control-exposure-review.json)에 기록했다. 다른 컵과 같은 컵, 선물함과 추모함, 조명받은 버섯과 빛을 흘리는 버섯 등의 차이를 검색 유사성만으로 승인하지 않는다. 이 대조군에서는 강제 채택이나 이미지 생성을 실행하지 않았으므로 대조군의 downstream 통과율을 주장하지 않는다.

## 독립 생성 실험

사용자가 요청한 세 개의 독립 서브에이전트가 서로의 프롬프트를 공유하지 않고 난수 seed·선택 메뉴·결과를 기록했다. 각자 최신 스킬을 읽고, 후보 자료를 보기 전에 컨셉·기준 프롬프트·판정 기준을 고정했다. 에이전트가 정한 구체적 소품과 관계는 실험자의 설계로 기록했으며 사용자 요청의 hard lock으로 바꾸지 않았다.

첨부 JPEG의 실제 파일을 각 생성 호출의 reference로 사용한다. 용도는 보이는 얼굴·머리 모양의 외형 안내이며 실제 인물의 정체·나이·생애에 관한 추론이나 보장은 아니다. 기준 파일 SHA-256은 `06d6c6feeed0d2397ec9562d46113cd221ac54a0e190295f0aa7f7868c22ece7`이다. 각 arm은 내장 이미지 도구를 정확히 한 번 호출하고 재시도하지 않는다.

내장 이미지 도구를 arm마다 한 번씩 호출해 세 장 모두 반환받았다. 실제 reference 해시·최신 스킬 해시·독립 manifest·native plan·ledger를 대조했으며, 원본과 전달 이미지의 해시가 일치했다. 각 보고서에 지정된 파일 55개의 실제 해시도 확인했다. 재생성·fallback은 0회다. 정확한 이미지·프롬프트·review·ledger 경로와 해시는 [IMAGE-TEST-RESULTS.json](IMAGE-TEST-RESULTS.json), 프리뷰와 판정은 [IMAGE-TEST-REPORT.md](IMAGE-TEST-REPORT.md)에 있다.

세 arm 합계 18개 실제 질의에서 136회 후보 occurrence, 중복을 합친 CID 112개를 검토했다. 이번 신규 96 CID와 교집합은 고유 CID 4개였다. 각 질의는 같은 19,029개 전체 긍정 후보에 BM25F와 로컬 cosine을 각각 한 번 실행하고 scope·표본 추출을 거쳤다. C의 `space_condition`은 저술한 "not an empty scenic ruin"을 부정 범위로 읽은 뒤 양성 변경이 없다는 해석으로 노출이 0개였다. 결과가 없다고 검색 자체가 생략된 것은 아니다. 표본을 다시 뽑지 않았다.

원래 사전 기준의 완전 통과는 **0/3**이다. 게이트 개수는 품질 점수가 아니다. A는 환대·고갈된 수로·reference 외형이 강하지만 나무→산호의 연속 경계, 물의 거의 소진, 동일한 두 그릇 사이 증기 방향과 내부 깊이가 불충분하다. B는 낯선 막을 돌보는 생활과 거대한 외부 생태가 보이지만 좌우 팔의 역할, 건조부/습윤부 대비, 작은 생물의 전체 이동 경로와 외부 생물에 대한 같은 뿌리의 접합이 불명확하다. C는 유기적 시설과 거주 생활·수리·눈이 하나의 공간에 잘 통합되지만 홍채의 역전 폐허·반대 방향 그림자, 압축 상태·각 램프까지의 공급 말단이 충분히 드러나지 않는다.

코디네이터도 원본 세 장을 직접 열어 별도 검토했다. A의 초기 5/6, C의 초기 7/8은 별개 검토자와 끝점·가시성 근거를 대조해 각각 3/6, 6/8로 보수적으로 정정했다. 초기 기록과 정정 이유를 모두 보존했다. B는 두 검토자가 3/7로 일치했다. 구성·런타임 감사 통과, 유효한 실패 기록, 일반 embodiment 통과 여부와 위 주제 실험의 결과를 섞지 않았다. C는 일반 embodiment 5개 통과여도 주제 실험은 미통과다. A·B는 일반 embodiment에도 부분 미충족이 있다.

두 가지 운영 이력도 보존했다. B는 검색 전 슬롯 준비 범위 오류 때문에 같은 frozen core·baseline·사전 testcase를 새 managed run에 재바인딩했다. 유효 control 값·정의는 같고 seed/digest만 달라졌으며, 새 blind arm으로 세지 않았다. C가 D16을 이번 신규 자료로 분류한 것은 실제 CID→모듈 대조에서 오류로 확인했다. 그 후보는 기존 `photo_candidate_dark_fantasy_grimdark_20261022.json` 소속이다. 신규 노출 1→0, 신규 영감 1→0으로 정정하고 기존 자료 영감 1로 분리했다. [정정 증거](image-tests/arm-c-source-classification-correction/correction-receipt.json)에는 변경 전 보고서와 보호 파일 해시가 남아 있다. 이미지·프롬프트·core·ledger는 바꾸지 않았다.

따라서 이번 실험은 장르 주제의 가시적 표현과 새 자료의 실제 검색 노출·검토를 보여준다. 새 후보의 완전한 의미를 채택한 사례는 없으므로 새 자료 전체의 픽셀 자격이나 품질 개선의 인과 증거로 해석할 수 없다. A의 새 자료 영감 역시 완전한 G01 원문의 terrace/cup/ribbed-mass 관계를 구현한 것은 아니다. 사용자의 미적 판단은 pending이다.

## 관찰에 따른 후속 검증 계획

1. 새 후보의 효과 검증은 실제 신규 CID 목록과 전체 source 의미를 먼저 대조하는 별도 제한 실험으로 진행한다. 이번 세 장과 baseline 이미지를 비교한 실험을 혼동하지 않는다. 후보 채택을 강제하거나 작은 단편만 잘라 채택 실적으로 세지 않는다.
2. A 유형은 카운터 한 곳의 목재–산호 변환 경계와 인간 그릇–연속 증기–다른 그릇의 양 끝점을 동시에 보이게 하는 프레이밍을 검증한다. 남은 물의 외형을 마지막 식수라는 서사 사실과 분리한다.
3. B 유형은 두 팔의 역할·지지·막의 젖은 곳/마른 곳을 먼저 읽히게 하고, 실내–창 경계–외부 몸까지 같은 뿌리의 접합이 가려지지 않는 구도로 전체 연결을 검사한다.
4. C 유형은 한 개의 공급 램프와 출구 말단을 가깝게 두어 전체 경로를 노출하고, 막의 압축 지점과 반대 방향 그림자를 각각 비교 가능한 배경 면에 드러내는 실험을 분리한다. 눈·폐허·그림자를 한 소품의 존재만으로 통과시키지 않는다.
5. 부정 문구에 의한 slot scope 축소는 별도 준비/질의 회귀 대상으로 남긴다. 현재 실행을 수정하거나 재검색해 결과를 바꾸지 않는다.

## 증거 범위

`VALIDATION.json`은 선행 리서치 시점의 구조 검증 기록이다. 그 안의 NOT_RUN은 당시 상태로 보존한다. 당시 README와 checksum은 integration-evidence의 `research-stage-README.md`, `research-stage-SHA256SUMS`로도 보관했다. 후속 반영·실행·보존 검증은 별도의 integration 증거를 따른다. 선행 12군×3 arm 비교 제안 36장과 이번 독립 생성 세 장은 다른 실험이다.

커밋·푸시는 요청 범위에 포함되지 않는다. 사용자의 미적 평가와 기준 이미지 대비 선호도 판단은 아직 받지 않았다.
