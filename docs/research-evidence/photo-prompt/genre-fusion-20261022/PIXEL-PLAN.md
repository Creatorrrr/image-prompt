# 실제 이미지 비교 계획

상태: **NOT_RUN**. 이미지·임베딩·검색 호출 0회. 아래는 제안한 실험 범위이며 실행·비용 승인 결과가 아니다.

첫 단계는 12개 의미군 × 3개 독립 arm = 36장이다. 각 군에서 A는 기존 세대 재료, B는 신규 staged 세대 재료, C는 후보를 모두 거절한 독립 baseline을 사용한다. 같은 실제 requester envelope·creative controls·의미 lock·사전에 저술한 평가 기준을 공유한다. 기준 baseline은 후보·본 연구의 실현안을 보기 전에 독립 저술하고 freeze해야 한다. 이 연구 문구를 복사해 독립 baseline이라고 기록하지 않는다. A/B가 같은 baseline이나 동일한 후보를 선택해도 억지로 차이를 만들지 않는다.

이미지 도구가 seed를 노출하면 동일 조건의 paired 비교를 하고, 노출하지 않으면 그 한계를 명시한다. source 선택과 후보 거절 이유를 기록하고 최종 prompt·transport·exact CID/RID/source hash·generation·receipt·반환 파일 hash를 묶는다. 첫 36장은 진단용 개발 비교이며 통계적 유의성·확정 품질 향상 증거가 아니다. 정식 개선 주장이 필요하면 사전에 고정한 독립 holdout·반복 수를 별도로 설계한다.

|군|카드|같이 보여야 할 증거|주요 실패/비가시 경계|
|---|---|---|---|
|P01 환대 전달|D01|제공자 손–동일 그릇–수신자 손/부속지|다른 그릇, 떠 있는 그릇, 피부 융합; 동의·안심은 확정 불가|
|P02 이종 식탁|D02/D03|같은 식탁·각 식기의 다른 형태·동일 컵 접촉|음식 호환·로맨스 강제; 컵 수·손 소유자 오류|
|P03 생활 수선|D06|착용자 소매·천의 찢어짐·패치·돕는 손|상처 봉합으로 변형, 다른 소매, 가려진 접점|
|P04 시설 보수|E01|동일 배관·이음 틈·클램프 양 끝 접점|다른 관, 가린 끝, 수리 성공을 prompt만으로 PASS|

|P06 탈피 돌봄|C03/C04|몸과 분리된 속 빈 외피·등 틈·패드 쟁반·받치는 손|시체·옷 혼동, 붙은 피부 당김, 외피가 새 몸으로 합쳐짐|

|P08 생태와 시설|C01/C02|호스와 가지줄의 분리 또는 밝은 갓과 수광면|시설을 신체로 합침, 전역 색보정만 있음; 생물학적 인과는 불가|
|P09 배급의 현재 순간|A03/E03|계량 도구·재료·수신 통 또는 표·저울·음식|calibration 오탐, 표의 판독 불가; 공정성·빈곤 판정 금지|
|P10 낯선 도시 노동|E04/E08|창구의 두 참여자·서류 또는 운송체–틀–상자–끈|시민권·자발성 단정, 화물의 장기화|

각 군의 복수 카드는 선택 가능한 대안이다. 한 프레임에 모든 대안을 합치지 않는다. 특히 P06/P08/P10은 각 arm에서 같은 하나의 구체 관계를 선택해 공정하게 비교한다. 선택 관계가 달라졌다면 관계 충실도 비교가 아닌 다른 장면의 미학 비교로 명시한다.

## 판정 기록

각 요구 관계를 `visible / partial / unobservable / contradicted`로 기록한다. 필수 양 끝과 연결이 드러나고 소유자를 구분할 때만 visible이다. 모든 필수 관계가 visible인 경우에만 그 실현안의 완전 관계 gate가 통과한다. 가린 손·희미한 글자·프레임 밖 접속은 `UNOBSERVABLE_NOT_PASS`; 단순 부분 충족은 `partial_is_fail`로 남긴다. 관계 수·문구 길이·컴파일 성공이 픽셀을 대체하지 않는다.

관계 충실도와 별도로 다음을 이미지에 근거해 서술한다: 중심 행동이 읽히는지, 그 필요와 상황이 이해되는지, 정보량·시각 위계·몸의 접촉이 장면을 돕는지, Cozy 관계가 주변 괴이함에 묻히는지, 낯섦이 자동 악의·고어로 바뀌는지. 네 장르의 표식이 모두 보이는지를 점수화하지 않는다. 시대·권리·동의·기억·실제 감정·효능은 사진만으로 PASS하지 않는다.

출력 정책 차단·도구 오류·결과 파일 없음은 `BLOCKED_UNSCORED`로 기록한다. 이미지가 없는 arm을 시각 실패나 성공으로 계산하지 않는다. 원래 의미를 다른 장면으로 바꾸거나 추가 호출해 차단을 숨기지 않는다. 추가 생성은 새 실험 범위에 따르며, 첫 비교에서 실패한 관계·단어가 무엇인지 먼저 남긴다.

사용자 선호·수용 판단은 `not_yet_received`에서 시작한다. 블라인드 A/B/C 순서로 전체 이미지 선호와 관계 충실도를 구분해 물을 수 있다. 사용자 판단이 없는데 승인·품질 향상을 확정하지 않는다. 실제 결과가 나와야 시행 여부와 사진을 저장한 위치를 추가한다.
