# 관악기 손 역할 데이터 교정

기준 커밋: `9594c5567973832d9f3daf7acb3f72beaddd086d`. 2026-10-02 재개한 24시간 작업의 첫 단계다.

## 반영 범위

- 공통 관악기 자세 1행: “양손으로 키나 밸브 조작”이라는 잘못된 일반화를 각 손의 악기별 연주·지지 역할로 교정
- 트럼펫 동작 1행: 공개 후보 문구에 왼손 지지·오른손 밸브 운지를 명시하고, 세 밸브를 동시에 누르는 듯한 표현을 음에 맞는 조합으로 교정
- ID·태그·가중치·별칭·키워드와 검색 로직은 그대로 유지
- 트럼펫 시각 의미 프로필은 이미 올바른 손 역할을 담고 있어 수정하지 않음

근거: [Yamaha 연주 자세](https://www.yamaha.com/en/musical_instrument_guide/trumpet/play/), [Yamaha 튜닝 슬라이드 설명](https://www.yamaha.com/en/musical_instrument_guide/trumpet/mechanism/mechanism002.html), [Yamaha 트럼펫 안내서](https://usa.yamaha.com/files/download/brochure/2/2133632/W215R18_trumpets.pdf). 왼손은 지지를 맡지만 튜닝 슬라이드를 조정할 수도 있으므로, 수동적인 역할만 수행한다고 제한하지 않았다.

## 실제 소비 경로 검증

트럼펫·색소폰·클라리넷·트롬본·호른의 완전한 v3 입력을 정규화한 뒤 실제 `retrieve_core_slots`와 `audit_core_retrieval`을 실행했다. 5개 장면 × 수정 전후 2회 = 10회 검색 감사가 통과했다. 원문과 장면 코어를 수정하지 않고, 1위 공통 포즈의 공개 문구에서 손 역할 오류가 제거됨을 확인했다. 트럼펫의 동작 후보도 1위를 유지한다.

이 입력들은 후보를 이미 알고 설계한 진단용 장면이다. 독립적인 블라인드 평가나 전체 CLI·최종 조합·이미지 생성 시험으로 해석하면 안 된다.

## 남은 변화와 한계

전체 85개 반환 슬롯 중 84개의 후보 순서는 같다. 트롬본의 `camera_direction`에서는 기존 네 후보를 그대로 유지하지만 1·2위가 교환된다. 전역 BM25F 문서 빈도의 미세한 변화가 근소한 점수 차이를 뒤집고 RRF 순서를 바꾼 결과다. 화면 표시용 셔플이 아니다.

상공 시점 후보는 원래 2위였고 수정 후 1위가 된다. 실제 코어와 자동 선택은 바뀌지 않으며 모든 후보는 선택 사항이다. 그러나 이후 작성자가 이 후보를 채택할 가능성까지 같다고 입증하지 않았으므로, 제안 순위의 잔여 위험으로 기록한다. [점수·원인 상세](rank-diagnosis.md)에 원시 점수와 통계 대조를 남겼다. 순위를 맞추기 위한 동의어 조정은 하지 않았다.

클라리넷·트롬본·호른에서 다른 악기의 동작 후보가 함께 나오는 기존 문제는 이 두 행 교정으로 해결되지 않는다. 검색 전체가 퇴보 없이 개선되었다거나 렌더 품질이 좋아졌다고 주장하지 않는다.
