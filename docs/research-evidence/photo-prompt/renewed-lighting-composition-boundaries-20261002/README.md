# 조명·구도 경계와 불완전한 의역 예시 교정

기준 커밋: `a21a08cb6e95fda0dd8f430fe68481878e5ea581`. 루프 조명·스플릿 조명·로우키·삼분할·비대칭 균형·네거티브 스페이스·단일 패턴 이탈, 7개 프로필을 수정했다.

## 변경

자체 제외어를 포함한 영어 경계 성분 7개와 대응하는 증거 앵커 7개를 긍정형 물리 관계로 바꿨다. 검토 중 드러난 과도한 제약도 피했다. 로우키에 표면 질감을 강제하지 않고, 삼분할에 배경 풍경을 요구하지 않으며, 네거티브 스페이스 전체에 질감이 균일해야 한다거나 패턴의 모든 속성이 같아야 한다는 조건을 추가하지 않았다. [Adobe 구도 안내](https://www.adobe.com/creativecloud/photography/technique/composition.html)와 [네거티브 스페이스 설명](https://www.adobe.com/creativecloud/photography/type/negative-space-photography.html)을 참고했다. 구도는 보편적 미적 정답으로 취급하지 않는다.

추가로 조명 3개 프로필의 의역 예시 9개를 교정했다. 기존 예시는 각 성분 한 줄을 그대로 복사해, 전체 관계가 불완전해도 의역으로 인정되는 문제가 있었다. 이제 각 문장이 해당 조명의 완전한 관계를 담는다.

최종 변경은 **23개 문자열, 7개 프로필**이다. 한국어 표현·활성화 규칙·제외어·필수 성분·최소 길이·정의·대조 예시·렌더 게이트와 검색 코드는 유지했다.

## 검증 결과

- 영어 전체 성분 진단: 0/7 → 7/7 선택 후보 발견
- 기존 한국어 성분 진단: 4/4 유지. 나머지 조명 3개에는 기존 한국어 성분 묶음이 없으며 이번에 추가하지 않음
- 필수 성분 누락 47개 중 선택 후보 발견: 3 → 0. 경계 문구만 고쳤던 중간안에서는 15개였으므로 그대로 게시하지 않음
- 기존 단일 성분 의역 9개: 9 → 0. 새로운 완전한 의역 9개: 0 → 9 선택 후보이며 필수 활성화 아님
- 성분 맥락에 제외어를 넣은 47개와 새 의역에 제외어를 넣은 45개는 차단 유지
- exact 별칭 28개와 영어 별칭 부정 28개는 기존 판정 유지
- 경계 앵커 단독 감사: 6/7 → 7/7. 전체 앵커만 나열한 감사는 4/7로 동일하며, 실제 장면별 증거가 더 필요함

위는 작성된 데이터의 관계·경계 검증이다. 일반 자연어 의미 이해 성능으로 환산하지 않았다.

## 독립 장면과 남은 변화

사전 자료 없이 작성한 14개 자연 장면을 실제 성인 문맥 판정과 resolver에 넣었다. 목표 프로필 발견은 0/14 → 0/14로 그대로다. 부정 장면에 새로운 프로필 ID나 필수 활성화가 생기지는 않았다.

양성 장면 두 개에는 낮은 순위 변화가 있다. 삼분할 부표 장면의 8위가 인물이 물건을 건네는 관계에서 표면 사용 흔적 관계로 바뀌었고, 비대칭 정물 장면의 7·8위가 시각적 병치와 비대칭 상의 사이에서 교환됐다. 원인 대조 실험은 기존 후보 문서가 아니라 전체 BM25F 통계 변화임을 확인했다. [점수·원인 자료](combined-rank-change-causes.json)를 보존했다. 이를 목표 검색 향상이나 후속 조합 동일성으로 주장하지 않는다.

자연 장면 시험은 완전한 생성 CLI·정규화 코어·이미지 생성 시험이 아니다. 임베딩 질의를 호출하지 않았고 렌더 품질도 측정하지 않았다.

## 통합 검증·비용

관련 테스트 73개(새 회귀 5개 포함), 사전 전체 메타데이터, 실제 시각 의미 인덱스 검증이 통과했다. 기존 테스트와 기존 고정 입력은 변경하지 않았다. 7개 프로필 벡터를 갱신하고 1,412개는 보존했다.

이 단계 임베딩 성공 7회, 보수적 비용 상한 $0.0114688. 프로젝트 누적 상한은 $1.384448 / 허용 $10이며 실제 청구 금액은 아니다.
