# Boundary, threshold, breakthrough, and transition visual semantics

Date: 2026-09-01  
Status: implemented data design; rendered qualification is recorded separately.

## Research question

The source keyword inventory mixes limits, thresholds, extremes, breakthroughs, awakenings, release, overload, transition, transcendence, ascension, singularity, absolutes, infinity, and evolution. The useful visual unit is not the broad label. It is a falsifiable event relation that can survive a complex photograph:

```text
before state -> constraint or threshold -> trigger or accumulation
-> crossing, rupture, release, transition, or failure -> localized consequence
```

The same subject or material system must remain continuous whenever the claim depends on transformation rather than replacement.

## Implemented P0 contracts

| Profile | Primary observable proposition | Nearest rejected substitutes |
|---|---|---|
| `critical_threshold_pretransition_accumulation` | an intact bounded system, accumulating driver, owned threshold reference, localized precursor, and remaining margin coexist before transition | suspense, gauge alone, peak, aura, post-rupture aftermath |
| `barrier_breakthrough_causal_event` | a resisting finite barrier, aligned force, contact rupture, fresh aperture crossing, and localized displacement share one contact-to-passage axis | open-air explosion, preexisting doorway, fog beam, rubble only, victory pose |
| `dormant_capacity_limiter_release` | one source owns a functional limiter, disengagement action, released output path, and local old-bound consequence | sleep awakening, glow alone, ordinary unlocking, costume swap, external power donor |
| `technical_overload_progressive_failure` | a rated system receives sustained excess load, fails locally, propagates through dependencies, and trips protection or loses function | short circuit alone, external impact, isolated spark, one broken part, collapse aftermath |
| `phase_transition_nucleation_growth` | one specimen contains a driving gradient, parent phase, multiple new-phase nuclei, and an advancing coexistence interface | color lighting, smoke, unrelated materials, completed product, fantasy transformation |
| `irreversible_threshold_crossing_consequence` | one subject crosses a concrete one-way threshold while the return path becomes unavailable and a downstream condition begins | ordinary doorway, reversible portal, sign alone, already-beyond pose, black-hole icon |

Each profile has five component groups, five literal prompt evidence fields, five thumbnail/native render gates, and at least five false substitutes. Missing or ambiguous evidence is a full profile failure under `partial_is_fail`.

## Candidate-pack design

`photo_prompt_boundary_transition_extension.json` provides six coherent clusters across the ordinary `aesthetic_trend`, `subject`, `action`, `location`, `prop`, and `composition` slots. Each cluster binds exactly one hard profile and six optional candidates. Candidate order is not preference, and approximate retrieval cannot create hard duties.

The six candidate clusters are:

1. pretransition critical accumulation;
2. physical barrier breakthrough;
3. dormant-capacity limiter release;
4. rated-system progressive overload;
5. nucleation-and-growth phase transition;
6. irreversible threshold crossing.

## Advisory-only boundary

The following remain advisory unless the requester supplies an observable definition:

- generic limit, threshold, extreme, peak, ultimate, absolute, and infinity;
- breakthrough without a physical versus figurative sense;
- awakening without sleep, awareness, revival, or limiter-release context;
- transcendence, self-overcoming, enlightenment, and sublime without externalized comparison evidence;
- ascension and apotheosis without source-bound movement, status, or mortal-to-divine evidence;
- singularity without mathematical, technological, or black-hole context;
- evolution when used for one individual's instant transformation rather than population change across generations;
- nirvana, moksha, liberation, and cultivation realms without a source-specific cultural or genre contract.

## Reference-image boundary

A portrait is scoped to visible adult appearance only. It may support face shape, eye spacing, adult impression, hair, wardrobe, and framing. It cannot establish identity, protected traits, health, attractiveness, personality, occupation, awakening, power, transcendence, or narrative status. Pixel review reports visible appearance continuity rather than biometric same-person verification.
