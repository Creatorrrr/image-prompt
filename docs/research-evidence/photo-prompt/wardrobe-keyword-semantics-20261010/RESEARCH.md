## 3. 시각 의미의 기본 단위

의미 데이터는 다음 순서로 읽을 수 있어야 한다.

**문맥상 의미 → 무엇의 속성인가 → 지금 보이는 부위 → 부위·객체 사이의 방향 있는 관계 → 대체하면 다른 의미가 되는 경계 → 보여야 하는 증거 → 보이지 않는 속성의 한계.**

예를 들어 `one sculptural red bow`는 붉다는 색 정보만으로 충분하지 않다. 하나의 매듭인지, 두 꼬리가 그 매듭에 속하는지, 어느 의상·어느 부위에 붙는지, 단순 부착인지 봉제선과 연결되는지까지 나누어야 한다. 색·크기·장소를 바꾸는 열린 선택과 매듭 하나라는 지정은 서로 다른 속성이다.

| 저장해야 하는 축 | 예시 | 피해야 하는 손실 |
|---|---|---|
| 소유자 | `wearer_A → garment_A → sleeve_A → cuff_A` | 다른 사람·다른 옷의 커프스를 증거로 쓰기 |
| 유형과 상태 | 착용 블라우스 / 옆에 놓인 블레이저 | 같은 의상 목록에 모두 착용으로 합치기 |
| 형상 | 사각 목선 / 둥근 목선 / 닫힌 키홀 | 이름만 같고 경계가 다른 형태 |
| 지지·고정 | 체인 양끝 / 위팔 밴드 / 가방 스트랩 | 한쪽 끝이 떠 있거나 다른 부품에 붙기 |
| 지역 속성 | 몸판은 불투명, 소매는 시어 | 소재 하나를 전신에 적용 |
| 수량과 위치 | 한 장의 붉은 면, 한쪽 리본 | 빨간 소품을 여러 군데 추가 |
| 현재 변화 | 손 접촉 부근의 밑단 아래 당김 | 반대 방향 움직임이나 공중 손동작 |
| 관찰 범위 | 접합점이 보임 / 발은 프레임 밖 | 보이지 않는 부위를 통과 처리 |
| 출처와 확실성 | 명시 / 설명 / 허용 후보 / 추정 | 추정 소재를 실제 물성으로 승격 |

## 4. 의상·목선·소매·실루엣 조사

상의는 `의상 유형`, `기장`, `소매`, `핏`, `레이어 역할`로 분해한다. 베이비 티의 baby는 의상명에서 해석하며 인물의 연령 근거로 사용하지 않는다. 반도 몸판과 오프숄더 소매는 서로 다른 구조이므로 하나의 스트랩리스라는 라벨에 뭉개지지 않게 한다.

K002의 `pale-blue button-down shirt`는 우선 정규화 검토가 필요하다. 일반적인 앞단추 셔츠 설명과 칼라 끝에 버튼이 달린 버튼다운 구조는 다르다. 원자료 설명이 앞여밈만 확인하므로 칼라 버튼을 새로 추가할 근거는 없다. `original_keyword_en`을 보존하고 `normalized_front_button_shirt`, `collar_point_fastening: unspecified`, `normalization_review`를 별도 관리하는 편이 정확하다. | 데님 | 바탕, 국소 밝은 접힘 무늬, 주머니·스티치 | 페이딩과 실제 사용 연수 분리 | WK054 |
| 아일릿·레이스·튤 | 바탕 원단의 구멍 / 독립 열린 무늬 / 반복 네팅 | 서로 다른 경계·바탕을 보존 | WK049, WK056 |
| 자수·아플리케·프린트 | 실 경로 / 위로 솟는 부착물 / 바탕의 색 무늬 | 무늬 이름이 같아도 기법·부피는 다름 | WK060, WK062 |
| 수선·변색·마모 | 국소 수선 다리, 닳은 가장자리, 어두운 금속 영역 | 빈곤·애착·과거 사건은 단정하지 않음 | WK065, WK072, WK100 |

오간자의 비침과 비교적 빳빳한 마감은 독립해 관리해야 한다. 이를 시폰과 동일한 처짐으로 단정하지 않고, 선택한 원단 외형과 해당 부위의 형태를 관찰한다. [MFA CAMEO의 오간자 설명](https://cameo.mfa.org/wiki/Organza). 파유의 가로 리브는 세로 골지 니트와 구별한다. [퀘벡 공식 용어사전](https://vitrinelinguistique.oqlf.gouv.qc.ca/fiche-gdt/fiche/8395270/faille).

직조된 무늬·크레이프의 미세 요철·파일 구조는 다른 표면 축이다. [CottonWorks의 복합 직조 설명](https://cottonworks.com/learning-hub/weaving/complex-woven-fabric-designs/), [벨벳 설명](https://cottonworks.com/encyclopedia-item/velvet/). 니트는 조직·실·섬유 조합에 따라 처짐이 달라지므로 ‘니트’ 하나로 물성값을 고정하지 않는다. [니트 구조 설명](https://cottonworks.com/learning-hub/knitting/single-and-double-knits/).

브로더리 앙글레는 바탕 원단의 구멍을 잘라 가장자리를 감싸는 자수이다. 흰 점 프린트나 바탕이 없는 레이스로 바꾸면 의미가 달라진다. [V&A의 자수 기법 설명](https://www.vam.ac.uk/articles/embroidery-styles-an-illustrated-guide). 데님 위스커·페이딩은 가공으로도 생기므로 실제 사용 기간의 증거가 아니다. [데님 마감 설명](https://cottonworks.com/learning-hub/denim/denim-finishing/).

## 6. 색상과 장식의 귀속

색 정보는 `owner`, `region`, `hue_family`, `lightness/chroma_language`, `role`, `count`, `placement`, `source_light_or_surface`, `option_group`, `certainty`로 분해한다. 모든 색명에 임의 HEX를 붙이는 것보다 부위와 역할을 먼저 고정하는 것이 원자료에 충실하다.

| 사례 | 유지해야 하는 구조 | 흔한 잘못된 변환 |
|---|---|---|
| 검정·스칼렛 쿠튀르 | 한 장의 붉은 면, 시작점, 길이, 다른 부위 반복 제한 | 빨간 신발·머리리본·배경을 추가 |
| 아이보리·래커레드 리본 | 한쪽 한 개 매듭, 두 꼬리, 실제 봉제선 접합 | 리본 두 꼬리를 두 개 장식으로 셈 |
| 옥스블러드 파이핑 | 좁은 패널 경계선 | 몸판 전체를 옥스블러드로 칠함 |
| 화이트–핑크 그라데이션 | 동일 원단 영역의 변화 축 | 전역 조명 필터로 대체 |
| 수영복 다섯 후보색 | 하나의 선택 그룹 | 다섯색이 동시에 들어간 배색 |
| 블랙실버 + 흰 배경 | 옷의 색 범위와 배경의 색 범위 | 흰색을 의상에 추가 |
| 톤온톤 검정 | 같은 색 계열 안의 재질·반사·요철 차이 | 다른 색을 넣어 대비를 대신 만듦 |
| 크림과 어두운 금속 | 천과 부속의 독립된 소유자·접합 | 배경 검정으로 국소 금속 대신 구현 |

`lacquer red`는 이 원자료에서 색 이름이다. 원단이 실크 파유 또는 새틴이라는 정보와 충돌시키지 않는다. `moon jade`, `moon gray`, `indie pink`, `deep aubergine sheen`도 재료·표준 좌표·전체 배색을 자동 결정하지 않는다. 원문 표현을 보존하면서 색 영역과 확실성을 분리한다.

표면색·조명색·화이트밸런스는 따로 관리한다. 조명이 따뜻해서 아이보리가 주황빛으로 보이는 것과 실제 주황 배색을 구분한다. 웜 전경과 쿨 배경은 객체별 빛의 관계이지 반드시 두 색 의상이라는 뜻이 아니다. [Nikon의 플래시·화이트밸런스 설명](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/flash-points-the-control-of-light), [전경·배경 색조 사례](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/using-white-balance-and-lighting-for-a-cool-tone).

## 7. 액세서리·전통복식·콘셉트의 경계

액세서리는 이름보다 ‘어디에 무엇으로 붙는가’를 보강한다. 체인은 양끝의 고정점과 처짐을 갖고, 가방은 손잡이·스트랩과 몸체가 같은 객체에 연결된다. 귀걸이 비대칭은 같은 착용자의 두 귀에서 비교해야 한다. 메리제인의 발등 스트랩과 샌들의 발목 스트랩은 같은 끈으로 뭉개지지 않는다. 타비풍 부츠의 앞코 갈림도 색 줄무늬와 분리한다. [Met의 타비 영감 부츠 기록](https://www.metmuseum.org/art/collection/search/834967).

한복은 저고리·깃·고름·도련·치마의 독립 부위를 유지한다. 미니 치마라는 지정이 저고리 크롭을 허용하지 않는다. ‘정상 저고리 길이’는 해당 요청과 참조의 의미이며 모든 시대에 공통인 고정 길이가 아니다. [국립민속박물관의 한복 설명](https://folkency.nfm.go.kr/en/topic/detail/7251), [치마·저고리와 고름 설명](https://www.nfm.go.kr/k-box/ui/hanbok/female?lang=en).

기모노풍 의상은 랩 몸판과 오비의 관계를 보존하되 원자료의 미니 변형을 역사적 기모노와 분리한다. 실제 전통 형태의 겹침 방향을 사용할 때는 착용자 좌우를 기준으로 한다. [V&A의 기모노 설명](https://www.vam.ac.uk/articles/kimono). 한푸 영감 판타지·홀터 치파오 재해석·데님 한복을 하나의 ‘동양풍 의상’으로 합치면 각각의 선·여밈·길이 의도가 소실된다. 이번 조사에서는 특정 한푸 시대형·치파오 계보·해군 계급 고증을 충분히 확인하지 못했으므로 이를 검증 완료로 기록하지 않았다.

고딕·다크 아카데미아·코티지·프린세스·미래 화보·해적·코스튬은 넓은 의미와 선택적 실현 사례를 함께 보관한다. 연구자 고딕을 교복으로 바꾸거나 고딕 테일러링을 무조건 큰 종형 치마로 바꾸지 않는다. ‘로리타’는 여기서 복식 스타일 맥락이며 실제 인물 연령을 뜻하지 않는다. 성인 화보가 명시된 원자료는 그 문맥을 보존하고, 설명문에 없는 실제 연령은 새로 확인했다고 주장하지 않는다.

20개 조합은 과거 사례를 구조적으로 분석한 참고 자료이다. 특정 스타일명이 등장했다고 조합의 의상·소품·색·장소를 전부 활성화하지 않는다. 선택된 관계·변형만 실제 요청과 양립하는 열린 범위에서 사용한다.

## 8. 의상과 행동·장소·촬영의 연결

| 상황 | 같은 프레임에서 필요한 연결 | 해석 한계 |
|---|---|---|
| 팔을 올린 베이비 티 | 같은 팔–암홀–국소 당김–주름 | 힘의 수치·이전 움직임 순서 미확정 |
| 피팅룸 밑단 아래 당김 | 손가락 접촉–같은 밑단–아래 방향의 국소 변화 | 수줍음·실제 연령·성적 의도 단정 금지 |
| 걸으며 안감 노출 | 손·옆 패널–현재 열린 틈–같은 치마 안감 | 시간 전체·의도 미확정 |
| 트레이 전달 | 주는 사람의 손–하나의 트레이–받는 사람의 손 | 한 사람 네 손이나 복장 교환으로 대체 불가 |
| 사탕 하나 건넴 | 손–포장 사탕 하나–그릇–수신 방향 | 요청되지 않은 수신자 생성은 별도 효과 |
| 양말 정리 | 같은 사람의 손가락–자기 양말 가장자리 | 공중 제스처만으로 접촉 확인 불가 |
| 천의 바람 반응 | 안정된 고정점–자유 끝–양립하는 현재 편향 | 재료별 반응 차이를 허용; 풍속 확정 불가 |
| 젖음 | 물 접촉–국소 명도·방울–유지되는 가림 범위 | 젖음은 투명화의 동의어가 아님 |
| 해체 파편 | 원래 의상의 색·번호·무늬–같은 재료 조각–끝단 | 자동 노출 확대·다른 재료 파편 도입 금지 |

접촉·부착·충돌·지지면을 나누는 관점은 물리적으로 가능한 상태를 검토하는 데 도움이 된다. 그러나 이번 관계 문장이 물리 솔버로 검증되었다는 뜻은 아니다. [Pixar의 변형 시뮬레이션 자료](https://graphics.pixar.com/library/DynamicDeformablesSiggraph2020/paper.pdf). 젖은 거친 표면의 어두워짐은 광학적으로 가능한 현상이나, 원단 전체의 투명화나 젖은 원인·시간은 별도 주장이다. [관련 광학 논문 초록](https://opg.optica.org/ao/abstract.cfm?uri=ao-27-7-1278).

촬영 태그도 실제 관찰 범위로 풀어야 한다. 전신은 신발·트레인에 도움이 될 수 있지만 작은 파이핑·접합점을 자동으로 읽히게 하지는 않는다. 상체 크롭이면 신발 상태는 관찰 불가로 남긴다. 50mm·85mm라는 태그는 거리·센서·크롭·원근의 독립된 정보를 대체하지 않는다. [Nikon의 인물 촬영 설명](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/quick-tips-for-taking-better-portraits).

## 9. 반영 우선순위와 남은 판단

125개 카드의 연구 우선순위는 P0 53개, P1 71개, P2 1개이다. 이는 출현 빈도나 선호도 기반 점수와 다르다. P0는 잘못 합치면 의미가 바뀌는 소유자·상태·극성·수량·부분 속성·가시성 경계에 집중한다. P1은 유형·표면·장식·장소의 조합 폭과 정밀도를 높인다. P2는 원자료 고증이 검증되지 않은 제복 주석을 별도 관리한다.

실제 첫 반영은 P0 전부를 한 번에 넣기보다 16개 카드의 제한된 관계부터 진행한다. [반영 계획](IMPLEMENTATION-PLAN.md)에는 정확한 카드 ID, 기존 항목의 재사용, 원본 파일, 인덱스 재생성, 48개 회귀 시나리오와 8개 이미지 비교 계획을 지정했다.

남은 판단은 ① 후보별 기존 의미와의 동등성, ② 선택 변형의 실제 관계 끝점, ③ 모든 부수 효과와 소유자, ④ 한복·치파오·한푸·제복의 개별 고증 범위, ⑤ 실제 조회·선택·최종 프롬프트·생성 이미지에서의 효과이다. 503개 키워드 모두 카드에 연결되어도 이 판단까지 모두 완료되었다는 뜻은 아니다.

현재 런타임 원본·인덱스·스킬 로직을 변경하지 않았고, 임베딩·이미지 API 호출, 생성 이미지, 커밋·푸시는 없다. 연구 산출물과 실제 반영·검증 상태는 분리해 기록한다.
