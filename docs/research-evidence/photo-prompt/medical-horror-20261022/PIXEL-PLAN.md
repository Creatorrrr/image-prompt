# 원본 이미지 비교 계획

이번에는 이미지 생성·임베딩·외부 모델 평가를 호출하지 않았다. 아래는 후속 구현 후의 제안 범위다.

## 비교 설계

필수 12사례 × A 후보 없는 독립 core / B 현행 후보 / C 승인한 보강 후보 = 초기 36개 arm을 계획한다. provider가 seed·설정을 지원하면 동일하게 고정하고, 지원하지 않으면 비결정성을 기록한다. 한 번씩의 생성은 표현 가능성의 예비 확인이며 성공률의 통계적 증거가 아니다.

원문 의미·인물 수·성인/모형 조건·노출·매체·구도·창의성 controls를 동일하게 유지한다. B에서 적합한 후보가 없으면 무리하게 대체하지 않고 `NO_ELIGIBLE_CANDIDATE`로 기록한다. C에서 새 데이터 노출·선택이 없으면 데이터 효과를 주장하지 않는다. 기존 적합 후보를 reuse한 경우도 신규 후보 효과로 세지 않는다.

모든 필수 gate가 같은 arm에서 통과해야 한다. 서로 다른 이미지의 부분 성공을 합치지 않는다. occluded/too small/ambiguous는 `UNOBSERVABLE_NOT_PASS`, 부분 일치는 `partial_is_fail`이다. 원본 파일·크기·hash·생성 설정·선택 CID/RID·실제 prompt·gate별 근거를 남긴다.

## 독립된 판정 열

1. 원본 생성 여부: `RENDERED / NO_PIXELS / NOT_RUN`.
2. 후보 실제 노출·선택 여부와 원문 의미 운반.
3. 가시 물체·수·접점·위치·문자·매체의 물리적 준수.
4. 의료적 문맥의 일관성. 스틸로 진단·동의·기능을 증명하지 않는다.
5. 의료 호러로 읽힘과 장면의 긴장·서사적 이해 가능성.
6. 조형·구도·조명·독창성 등 작품성 및 사용자 수락.

3번 PASS가 5·6번 PASS는 아니다. 의료 기구가 정확해도 단순 병원 사진일 수 있고, 공포스러운 이미지여도 연결 구조가 틀릴 수 있다. 두 평가를 모두 보존한다. 제공자 차단·도구 미지원은 픽셀 실패로 채점하지 않으며 `NO_PIXELS`와 이유를 남긴다. 차단된 사례를 다른 모티프로 몰래 바꾸거나 반복 호출하여 성공으로 대체하지 않는다.

추가 비가시 대조는 마취 중 각성·폐쇄증후군/혼수·동의/강제·감염/집락·키메라/복제·프리온/패혈증·세포 불멸성과 개인 의식·음향이다. 이 의미를 원본 픽셀로 증명했다고 채점하는 경로 자체가 없는지 검사한다. 이번 12사례는 64개 초안 전체의 이미지 승인이나 사용자의 선호 확인을 대신하지 않는다.
