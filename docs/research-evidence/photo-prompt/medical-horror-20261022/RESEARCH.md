# 메디컬 호러 시각 의미·후보 데이터 심화 리서치

2026-10-22 KST. 원 대화 **메디컬 호러 용어 정리**의 181개 용어를 보존하고, 이를 실제로 그릴 수 있는 요소와 장면 밖의 주장으로 나누었다. 결과는 가시 실현 64개, 문맥·혼동 경계 22개, 한영 후보 초안 64개다. 이 수량은 연구 산출물 수이며 운영 후보·검색 성능·이미지 품질의 개선 실적이 아니다.

핵심 보강 방향은 의료 명사의 수보다 **몸·도구·기록·공간 사이의 관계를 더 정확히 표현하는 것**이다. 같은 흰 가운·병상·봉합선도 소유자, 접점, 가려진 범위, 표기, 시점에 따라 전혀 다른 의미가 된다. 메디컬 호러를 특정 색·피·상처의 자동 패키지로 만들면 임상적 공포와 제도적 공포를 놓치고 기존 바디 호러와 중복된다.

## 1. 조사 범위와 근거 수준

연결 도구의 응답은 정확히 20,000자에서 11번 구역 중간에 잘렸다. 로그인된 Chrome에서 원문 DOM의 용어 표 13개, 작품 11개, 조합 7개, 역사 사례 4개까지 확인했다. 원 대화는 용어 조사 대상이며 그 안의 인용 표시를 재검증 없이 사실 근거로 사용하지 않았다. [전체 대응표](KEYWORD-ATLAS.md)에 181개 항목을 빠짐없이 연결했다.

[출처 목록](SOURCES.tsv)은 51개다. 공공기관·의료기관·박물관·전문직 단체·논문/책 발행처·제작사/배급사/영화제의 자료를 사용했다. 책 전체를 읽은 항목은 없으며, 논문·책의 공개 초록과 출판사 설명만 확인한 항목은 그 범위로 표시했다. 구체적 장면·기하·소유 관계는 이번에 저술한 제안이다. 출처가 그 장면을 직접 관찰했거나 임상적으로 검증했다는 뜻이 아니다. [접근 한계](ACCESS-LIMITS.md)를 함께 읽는다.

작품 11개는 원 대화의 참고 목록으로 보존했다. 직접 재확인한 작품별 자료와 미검증 작품을 구분했다. `American Mary`, `Re-Animator`는 이번에 별도 작품 원문을 확인하지 않았으며 전체 작품의 원본 프레임 분석도 수행하지 않았다. 작품은 특정 연출 가능성의 사례이며 유행 빈도·장르의 필수 형태·실제 의료의 증거가 아니다.

## 2. 장르를 의료적 관계로 해체하기

의료 고딕 연구는 의료 음모·실험, 정신의료기관, 전염을 교차 영역으로 다룬다. 이식 고딕의 공개 장 요약은 《Coma》 등에서 병원·기업 이익·조직 거래의 관계를 논의한다. 여기서 필요한 데이터는 ‘고딕한 병원’ 하나보다 **누가 몸을 볼 수 있고, 옮길 수 있고, 이름 붙이고, 기록하며, 출구를 통제하는가**를 저술할 수 있는 별도 요소다. [의료 고딕 초록](https://academic.oup.com/edinburgh-scholarship-online/book/56658/chapter-abstract/453346976), [이식 고딕 장 요약](https://www.cambridge.org/core/books/abs/transplantation-gothic/bioemporium-corporate-medical-horror-in-late-twentiethcentury-american-transfer-fiction/6395F77E3425618EEC30E7AF532C276D).

치과 호러는 치과적 폭력뿐 아니라 치아 소실·부식과 관련된 연구 용례가 있다. Gynaehorror는 생식 신체의 재현을 분석하는 비평 범주다. 둘 모두 하나의 고정 구도나 ‘여성·임신·치료가 본질적으로 공포스럽다’는 명제가 아니다. 임상 장면의 위협은 요청이 지정한 관계에서 구성해야 한다. [치과 호러 논문 초록](https://intellectdiscover.com/content/journals/10.1386/host_00077_1), [Gynaehorror 출판사 설명](https://www.routledge.com/Women-Monstrosity-and-Horror-Film-Gynaehorror-1st-Edition/Harrington/p/book/9781315546568?PageSpeed=noscript).

| 의미 축 | 직접 다룰 수 있는 재료 | 별도 문맥으로 남길 것 |
|---|---|---|
| 외과적 | 도구 끝, 조직 가장자리, 수술포, 봉합 경로 | 통증·의식·동의·처치 목적 |
| 임상적 | 정렬, 장비 분리, 밝기, 이름 대신 보이는 코드 | 냉담함·인간성 상실·관객의 공포 |
| 제도적 | 문·가림막·창구·기록·닿지 않는 호출기 | 적법한 권한·강제입원·은폐·퇴원 거부 |
| 생식·신체권 | 검사 공간의 시야 경계, 서류, 보호 가림 | 강제 임신·불임화·성징 변경의 이력·선택권 |
| 이식·생명공학 | 표본 용기, 배양 스케일, 가상 이음선 | 세포 기원·유전·기증자·면역 반응·기억 |
| 감염 | 외부 막·용기 경계·시료 취급의 배치 | 미생물·전파 경로·감염·질환·의료관련성 |

## 3. 공간: 무균·격리·감금의 외형을 합치지 않는다

**음압 격리실과 양압 보호환경은 반대 방향의 압력 관계를 갖는다.** 문·유리·전실 자체는 두 기능을 구별하는 충분한 증거가 아니다. A03은 문 두 개와 전실의 연결, A04/A05는 서로 반대 방향인 ‘도식의 화살표’를 다룬다. 도식이 보인다고 실제 공기가 흐르거나 건축 기준을 통과했다고 판정하지 않는다. 최신 건축 설계 지침을 제공하려는 조사도 아니다. [CDC의 압력 관계 설명](https://www.cdc.gov/infection-control/hcp/environmental-control/air.html).

병상·장비의 분리(A02), 닫힌 영안실 구획(A07), 환자 운반 침대의 누운 시점(A09), 해부극장의 중앙대와 관람석(A10)은 서로 다른 공간 문법이다. 영안실 서랍이 닫혀 있으면 시신·내용물은 보이지 않는다. 천장 구도가 있어도 이동·혼수는 입증되지 않는다. [Boerhaave의 해부극장 재현](https://www.rijksmuseumboerhaave.nl/en/our-worlds/anatomical-theatre)은 관람 구조의 참고이며 현대 수술실의 보편형이 아니다.

A11은 밝고 정돈된 공간의 작은 배치 불일치로 임상적 긴장을 제안한다. A12는 벗겨진 도장·녹빛 얼룩·물의 반사를 저술한다. ‘깨끗함=실제 무균’, ‘쇠락=감염·방치’로 승격하지 않는다. 요양시설 A06의 긴 창가 회랑은 창작 제안이며 특정 시대·국가의 결핵요양소를 사실적으로 재현하려면 별도 사진·설계 자료가 필요하다.

## 4. 기구: 명사보다 연결 경로를 보강한다

도관·배액관·주입관·호흡 회로를 `tube` 하나로 합치면 모양은 그럴듯해도 의미는 실패한다. 다음 관계를 한 화면에서 확인할 수 있게 한다.

| 실현 | 필수 관계 | 혼동하면 실패하는 것 |
|---|---|---|
| D04 배액 | 신체의 보이는 삽입부 → 연속 관 → 외부 수집 벌브 | 주입 주머니·펌프·호흡 장치에 연결 |
| D05 주입 | 주머니 → 펌프를 지나는 관 → 팔의 외부 연결부 | 배액 벌브·관의 중간 단절·허공 종단 |
| D06 구강 호흡 경로 | 입의 고정 튜브 → 외부 커넥터 → 회로 → 별도 장치 | 코 산소관·마스크·목 경로와 혼합 |
| D07 마스크 경로 | 코·입을 덮는 마스크 → 커넥터 → 회로 | 이를 기관삽관이라고 명명 |
| D08 목 경로 | 목 앞 고정판·목끈 → 외부 연결부 → 회로 | 온전한 피부 관통·구강 튜브와 혼합 |
| D01 수술포 | 얼굴과 작업 구역 사이 불투명 장벽 | 가려진 수술을 보였다고 판정 |
| D02 견인기 | 기구의 두 끝과 조직의 양 가장자리 접촉 | 공중 기구·단순 장식·끝점 가림 |
| D03 검경 | 특정 유형의 두 날·경첩·손잡이·나사 | 모든 검경·견인기의 보편 형태로 일반화 |

배액의 외부 구조는 MSK, 주입펌프는 FDA, 환기 경로는 NHLBI 자료와 대조했다. 외부 연결이 맞아도 내부 위치·유량·호흡 작동·투여 성분이 증명되지는 않는다. [MSK 배액관 설명](https://www.mskcc.org/cancer-care/patient-education/caring-your-jackson-pratt-drain), [FDA 주입펌프 설명](https://www.fda.gov/medical-devices/infusion-pumps/what-infusion-pump), [NHLBI 인공호흡기 설명](https://www.nhlbi.nih.gov/health/ventilator).

검경은 Science Museum의 특정 Cusco형 유물 기록을 근거로 범위를 제한했다. 진료 부위의 노출이나 사용 장면을 자동 추가하지 않는다. 표본병 D12는 투명 벽·액면·내용의 위치, 슬라이드 D13은 절편·유리·커버글라스의 층을 다룬다. [검경 개별 유물](https://collection.sciencemuseumgroup.org.uk/objects/co93477/vaginal-speculum-vaginal-speculum), [NCI 생검 정의](https://www.cancer.gov/publications/dictionaries/cancer-terms/def/biopsy).

## 5. 상처: 위치·층·연결·시간을 구별한다

W01 창상 열개의 대리형은 남은 봉합과 중앙의 틈이다. ‘이전에 닫혔다 다시 열렸다’는 시간 이력은 스틸만으로 확인되지 않는다. W02는 가상 해부 모형의 내부 조직이 개구부를 통해 피부면 밖으로 연속 돌출하는 구조다. 안쪽에 조직이 보이는 것과 밖으로 돌출하는 것은 별개다. [Cleveland Clinic의 창상 열개 설명](https://my.clevelandclinic.org/health/diseases/wound-dehiscence), [ACS의 수술 후 합병증 교육자료](https://www.facs.org/media/iccbhdga/postoperative_care.pdf).

W03 누공은 두 끝을 잇는 통로이므로 하나의 구멍과 구별한다. 피부 사진에서 안 보이는 경로를 투시했다고 판정하지 않고 명시적 단면 모형으로 제한한다. W04 탈출은 기존 통로를 통한 위치 관계의 일반 도식으로만 제안했으며 부위별 임상 정확성은 P2 추가 조사 대상이다. [NCI 누공 정의](https://www.cancer.gov/publications/dictionaries/cancer-terms/def/fistula).

W05는 피부층과 하부층의 분리다. 박리 손상에는 피부가 열리지 않은 형태도 있어 모든 경우를 열린 상처로 고정할 수 없다. W06의 어둡고 건조한 패치는 괴사·괴저의 대리 외형일 뿐 진단이 아니다. 허혈의 혈액 공급과 저산소의 산소 공급도 구별한다. [NHS 폐쇄형 손상 교육자료](https://www.rightdecisions.scot.nhs.uk/media/jujp5l25/hand-injuries-dec-24.pdf), [NCI 괴사](https://www.cancer.gov/publications/dictionaries/cancer-terms/def/necrosis), [허혈](https://www.cancer.gov/publications/dictionaries/cancer-terms/def/ischemia), [저산소](https://www.cancer.gov/publications/dictionaries/cancer-terms/def/hypoxia).

궤양의 표면 결손(W07), 농양을 설명하는 공동·액체 모형(W08), 흉터·주름(W10), 신체 끝과 분리 의수(W11)를 따로 저술했다. 노란 액체·흉터·사지 부재로 감염·구축 기능장애·환상지통을 진단하지 않는다. 기형종의 여러 조직형은 작은 인간·태아·의식체가 아니다. W09도 명백한 가상 표본 모형으로 한정한다. [NCI 궤양](https://www.cancer.gov/publications/dictionaries/cancer-terms/def/ulcer), [농양](https://www.cancer.gov/publications/dictionaries/cancer-terms/def/abscess), [기형종](https://www.cancer.gov/publications/dictionaries/cancer-terms/def/teratoma).

## 6. 의식·통증·감각: 얼굴·눈·기계가 진단을 대신하지 못한다

전신·국소·부위마취와 진정은 다르다. 특히 의식이 유지되는 국소·부위마취 장면을 ‘마취 실패’로 바꾸면 의미가 틀어진다. E11의 열린 눈과 수술포는 가시 관계이며, 우발적 각성·통증·회상·마취 종류의 증거가 아니다. 의식·통증·움직임·기억을 별도 축으로 다루고 약리 세부는 전문 자료를 추가 검토한다. [NIGMS 마취 설명](https://www.nigms.nih.gov/education/fact-sheets/Pages/anesthesia), [ASA 각성 안내](https://www.asahq.org/~/media/sites/asahq/files/public/resources/patient-brochures/asa_awareness-anesthesia_final.pdf?la=en).

혼수는 깊은 무의식 상태지만 혼수·폐쇄증후군·뇌사 판정 전체를 같은 병상 외형으로 합칠 수 없다. 이번에 혼수의 공개 정의를 확인했으며 나머지 두 상태의 전문 판정 기준을 승인했다고 주장하지 않는다. 공포증·망상·섬망·환상지통의 상세 임상 정의도 후속 전문 확인 대상으로 명시했다. [MedlinePlus 혼수](https://medlineplus.gov/coma.html).

노시보는 기대와 증상 사이의 인과를 포함하므로 괴로운 표정이나 약병 하나로 판정할 수 없다. 현대 ECT도 마취·근육이완 아래 시행하는 치료로 설명된다. 전극·움직임 제한·전기를 모두 처벌용 고문이나 역사적 로보토미와 같은 것으로 취급하지 않는다. D18은 외부 전극과 장치의 도식만 제안한다. [NCI 노시보](https://www.cancer.gov/publications/dictionaries/cancer-terms/def/nocebo-effect), [NIMH ECT 설명](https://www.nimh.nih.gov/health/topics/brain-stimulation-therapies/brain-stimulation-therapies).

## 7. 감염·이식·유전: 보이는 표면과 기전을 분리한다

오염·집락화·감염·의료관련성은 같은 명제가 아니다. L04의 막이 보여도 미생물 공동체나 감염은 입증되지 않는다. 프리온은 단백질 접힘 이상과 관련되며 바이러스·세균·기생충 형상으로 자동 바꾸지 않는다. 패혈증도 단순한 피의 변색으로 표현·진단할 수 없다. [CDC 의료관련감염](https://www.cdc.gov/healthcare-associated-infections/about/index.html), [프리온](https://www.cdc.gov/prions/about/), [WHO 패혈증](https://www.who.int/news-room/fact-sheets/detail/sepsis).

이식 거부반응은 면역 과정이며 인공재료의 이물반응과 구별한다. 이종이식은 수혜자에게 동물 귀·주둥이·발굽이 생긴다는 뜻이 아니다. W12의 이음선과 L09의 시료 표기는 대리형이며 이식·유전적 기원·기억 전이를 증명하지 않는다. [이식 거부반응](https://medlineplus.gov/ency/article/000815.htm), [FDA 이종이식](https://www.fda.gov/vaccines-blood-biologics/xenotransplantation), [NCI 키메라 현상](https://www.cancer.gov/publications/dictionaries/cancer-terms/def/chimerism).

L01의 작은 배양 구조와 눈금은 오가노이드의 크기·용기 관계를 정교하게 하기 위한 제안이다. 완전한 장기·소형 사람·의식체로 확대하지 않는다. 인공자궁 관련 2023년 FDA 회의 요약은 극조산 출생 이후 발달 지원 목적을 다루며, 2026년 전체 승인 현황이나 완전 체외임신 공장의 실용화를 입증하지 않는다. L07은 빈 허구 챔버로 분리했다. [NCI 오가노이드](https://www.cancer.gov/publications/dictionaries/cancer-terms/def/organoid), [FDA 당시 회의 요약](https://www.fda.gov/media/172441/download).

## 8. 동의·생식·성·폭력 관련 용어의 보존과 경계

원 대화의 강제 임신·임신 종결·불임화, 산과적 폭력, 비동의 민감부위 검사, 의료 관계의 성적 경계 침해, 관음, 의료 페티시즘, 합의된 성인 역할극, 강제 노출·성징 변경, 거세·성기 훼손, 수술적 에로티시즘, 시체성애를 목록에서 삭제하지 않았다. 다만 이 명칭들은 서로 다른 사건·취향·권한·동의 이력을 가리킨다. 외형이 비슷하다는 이유로 하나의 긍정 시각 후보로 합치지 않는다.

동의는 서명만의 문제가 아니고 정보·이해·자발성의 과정이다. 영국 GMC의 민감부위 진찰 지침은 설명·중단 요청·동의·사생활 보호를 명시한다. E03·E07은 서류의 가림과 공간의 시야 경계만 표현한다. WHO의 불임화 성명도 당사자의 자유롭고 충분한 동의를 중심에 둔다. 사진으로 생식능력·처치 이력·동의·강제를 확정하지 않는다. [벨몬트 보고서](https://www.hhs.gov/ohrp/regulations-and-policy/belmont-report/read-the-belmont-report/index.html), [GMC 지침](https://www.gmc-uk.org/professional-standards/the-professional-standards/intimate-examinations-and-chaperones/intimate-examinations-and-chaperones), [WHO 성명](https://www.who.int/publications/i/item/9789241507325).

의료복·장갑·성인이라는 설정은 성적 취향·동의·장애를 증명하지 않는다. E08의 성인 연기자와 소품 진료실도 실제 치료 관계와 분리한다. APA의 DSM-5 안내자료는 비전형적 관심과 장애를 구별하지만, 이를 현재 진단 기준 전체로 사용하지 않았다. 수술·욕망의 연결은 《Crimes of the Future》의 특정 허구 맥락에서 확인한 사례다. [APA 안내자료](https://www.psychiatry.org/File%20Library/Psychiatrists/Practice/DSM/APA_DSM-5-Paraphilic-Disorders.pdf), [BFI 작품 논의](https://www.bfi.org.uk/sight-and-sound/reviews/crimes-future-darkly-funny-world-organ-ised-crime).

## 9. 역사·작품을 사용할 때 생기는 잘못된 추론

터스키기 연구의 문제는 충분한 동의와 제공 가능한 치료의 부재이며 참가자를 고의 감염시킨 연구로 재서술하지 않는다. HeLa의 1951년 비동의 채취와 2013년 가족과의 합의는 NIH 공식 검색 본문에서 재확인했다. 세포의 배양 지속성을 원래 인물의 의식 지속으로 바꾸는 것은 허구적 가정이다. 우생학의 행정·통계적 언어도 과학적 인간 가치의 사실로 승격하지 않는다. [CDC 터스키기 FAQ](https://www.cdc.gov/tuskegee/about/), [NIH-Lacks 합의 설명](https://grants.nih.gov/policy-and-compliance/policy-topics/sharing-policies/dms/privacy/nih-lacks-family-agreement), [NHGRI 우생학 설명](https://www.genome.gov/about-genomics/fact-sheets/Eugenics-and-Scientific-Racism).

RCS의 기록은 1811–12년 런던의 해부용 시신 거래를 다룬다. `resurrectionist`를 부활 능력으로 읽거나 이를 모든 시대의 병원 운영으로 일반화하지 않는다. [RCS 기록 소개](https://www.rcseng.ac.uk/library-and-publications/library/blog/diary-of-a-resurrectionist/).

《Eyes Without a Face》의 성형수술과 얼굴, 《Dead Ringers》의 쌍둥이 산부인과 의사, 《Antiviral》의 질병 상품화, 《Jane Doe》의 외부·내부 불일치, 《The Substance》의 미의 규범을 서로 다른 창작 축으로 사용한다. 이 작품 설명은 정확한 소품 외형이나 개별 프레임의 증거를 대신하지 않는다. [Criterion](https://www.criterion.com/films/950-eyes-without-a-face), [Dead Ringers 에세이](https://www.criterion.com/current/posts/31), [Sitges 시놉시스](https://sitgesfilmfestival.com/en/film/2012/antiviral), [British Council](https://filmsandfestivals.britishcouncil.org/projects/the-autopsy-of-jane-doe), [제작사 설명](https://www.workingtitlefilms.com/film/the-substance/).

## 10. 반영할 데이터의 단위와 남은 조사

가시 카드는 `명시한 대상 → 부분·상태 → 방향 관계 → 혼동 경계 → 주장 한계 → 원본 이미지 gate`로 작성했다. 단면 모형·허구·스튜디오라는 모드는 원문 의미의 일부다. 태그나 번역에서 삭제하면 임상적 사실 또는 실제 사건으로 변질된다. 단서·대리형은 사용 가능한 창작 후보이지만 대리하는 진단·동의·시간·소리를 입증하지 않는다.

우선순위는 P0 공간·기구·외부 연결, P1 상처의 구조·표본·몸과 장치, P2 역사·생식·유전·비평의 문맥과 추가 전문 확인이다. P2에 둔 용어가 덜 중요하다는 뜻은 아니다. 관측만으로 판정할 수 없는 의미를 정확히 보존하려는 순서다.

추가 확인 대상은 폐쇄증후군·뇌사 전문 판정 기준, 공포증·망상·섬망·환상지통의 임상 정의, 위축·부위별 탈출, 이물반응과 조직공학의 세부, 의료 가스라이팅·제도적 배신·이중 충성의 개별 원전, 시체 약재·역사적 정신외과의 시대별 자료, 개별 요양시설 도면·사진이다. NCI의 atrophy/prolapse 직접 주소는 이 도구에서 실패했고 NHS의 옛 뇌사 페이지는 제거된 페이지로 연결됐다. 이들을 접근 성공한 출처 수에 포함하지 않았다.

이번 결과로 다음 구현을 시작할 수 있지만 카드별 기존 소스 비교·native 의미 승인·실제 검색·이미지 표현은 별도로 수행해야 한다. 구체적인 파일·우선순위·통과 기준은 [반영 계획](IMPLEMENTATION-PLAN.md), 핵심 이미지 비교는 [픽셀 검증 계획](PIXEL-PLAN.md)에 정리했다.
