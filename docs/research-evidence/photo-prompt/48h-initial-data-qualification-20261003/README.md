## 후보를 보지 않고 작성한 새 장면

독립 작성자는 허용된 pre-core 스킬·설정·중립 카탈로그만 사용했다. 코어 작성 전 조정자가 원문 그대로 요청 봉투를 동결했다. 실제 사용자의 요청 로그가 아닌 합성 평가 입력이며 `requesting_user`는 프로토콜상의 시뮬레이션 값이다.

8개 개념 장면을 영어·한국어로 각각 작성한 **16개 입력**이다. 번역 쌍을 독립 사례 16개로 계산하지 않는다. 동물 5개, 살아 있는 식물 1개, 도자기 물체 대조 1개, 사람·개 혼합 주체 대조 1개다.

- 원본 그대로 public CLI 실행: **14/16 성공**
- 혼합 주체의 두 번역 입력은 setting 최소 내용 단어 수 조건으로 동일하게 실패했다. 원본·실패 로그를 보존했으며 이 장면의 소비 경로를 검증했다고 주장하지 않는다
- 살아 있는 비인간 6개 장면의 번역 쌍에서 action 후보 노출 26개를 관찰했다. 이 중 20개는 이미 human 태그가 있다
- action은 이 코어에서 열린 차원이 아니다. 26개 모두 일반 후보 경로의 eligible 상태와 해석 헬퍼 허용을 재현했다. event와 action은 별개 허용 문자열이며 동일한 검색 필드를 사용한다고 자동으로 같은 차원은 되지 않는다
- 그러나 action 변경을 명시한 전체 감사는 차원 잠금으로 거부했다. 실제 철도 문장을 추가하고 물리 검토의 미해결 상태를 정직하게 제출한 대조도 embodiment 검사에서 거부됐다
- 전체 감사가 통과한 잘못된 선택 표시는 **고슴도치 원문을 전혀 바꾸지 않고** 지하철 후보가 이미 실현됐다고 기록한 메타데이터 불일치다. 잘못된 새 장면이나 픽셀이 전체 검증을 통과했다는 증거가 아니다

사람 태그·필터를 기계적으로 추가하는 수정은 채택하지 않았다. 혼합/사람 양성 대조가 입증되지 않았고, 부차적인 사람 행동까지 제거할 수 있다. 원본 코어·기대값·런타임을 바꾸지 않았다.

## 새 주제: 덩굴손과 지지물 — 보류

[Gerbode 등의 원 논문](https://doi.org/10.1126/science.1223304)과 [Passiflora caerulea 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC10558631/)를 근거로 식물-덩굴손-별도 지지물의 부착 관계를 조사했다. 줄기 전체의 휘감기, 접착판, 공중 나선, 장식 끈을 같은 것으로 취급하지 않았다. 지지물 윤곽도 실제 가림을 허용하도록 초안을 점검했다.

소규모 새 선택형 프로필은 기존 스키마로 표현할 수 있지만, 현재 채택할 근거가 부족하다.

- 개발용 소비 경로 검사 19/21, 범위 검사 4/4 통과
- 별도 끈이 지지물을 감는 혼합 주체, 접촉 없이 지지물 주변에 뜬 고리라는 음성 대조 2개를 선택형 후보로 잘못 제시
- 제안 작성자가 보지 않은 기존 독립 식물 장면의 EN/KO 원문·기본 프롬프트 4개에서는 구성요소 일치 **0/4**. 최종 초안에서도 동일
- 이 4개는 **한 개념 장면의 두 번역·두 텍스트 표면**이며 독립 장면 4개가 아니다
- 실제 벡터 갱신·수정 DATA의 전체 CLI·새 이미지 검증은 하지 않았다. 비용을 쓰거나 런타임 예외를 추가해 억지로 통과시키지 않았다
