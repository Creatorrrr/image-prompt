# 셀카 포즈 시각 의미·후보 데이터 보강 리서치

2026-10-08 KST · 연구와 반영 설계 · 운영 데이터 등록 전

‘셀카 포즈 조사’의 **18개 분류·180개 번호 행과 첫 답변의 20개 요약 검색행**을 조사 범위로 삼았다. 180개 행을 각각 연구 카드로 보존하고, 소유 대상별 시각·촬영 구성요소 540개, 후보 79개와 시각 프로필 79개의 초안으로 정리했다. 79쌍은 확정 신규 항목 수가 아니다. 기존 원본과의 의미 동등성·변형 분리·활성화 조건 검토를 거쳐 신규 등록, 기존 ID 보강, 조합, 보류 중 하나를 선택해야 한다.

핵심 보강 대상은 셀카라는 이름 자체보다 **누가 어떤 손으로 촬영하고, 나머지 손이 어디에 닿으며, 얼굴과 기기가 어떤 경로로 보이고, 어떤 구성요소가 실제 화면 안에 남는지**다. 같은 ‘반쪽 얼굴’이라도 손 가림, 폰 가림, 프레임 밖 크롭, 조명으로 어두워진 반쪽은 다른 시각 관계다. 이런 차이를 원본 의미·후보·검증까지 연결해야 검색 결과가 실제 형상화에 도움을 준다.

## 조사 범위와 증거

원 대화의 `read_thread` 결과는 한 메시지 18,000자에서 잘려 180개 후반 항목을 모두 담지 못했다. 브라우저에서 해당 대화의 전체 표를 읽어 1–180의 연속 번호, 분류 이름, 설명과 20개 요약 검색행을 확인했다. `original-keywords.json`은 표제어·분류·번호를 보존한 전사본이다. `source-conversation-cache.json`은 잘린 캐시이며 전체 원문 저장본으로 부르지 않는다. 연구용 관찰 문장은 `seed-research.tsv`에 별도 저작했다. [사용자 지정 대화](https://chatgpt.com/c/6ac663d1-765c-83ee-b316-9e5c0d03db8c)

출처는 26건이다. 외부 본문을 확인한 18건, 검색 발췌 1건, 페이지 범위 확인 1건, 표제 확인 후 본문 시간 초과 3건, 접근 실패 1건, 원 대화에만 있는 게시물 링크 1건, 사용자 지정 대화 1건을 구분했다. 외부 출처는 촬영 원리 또는 특정 이름의 용법을 지지한다. 180개의 모든 관찰 문장·접촉 관계·게이트가 각 기사에 존재한다는 뜻은 아니다. 이 부분은 자료를 바탕으로 만든 연구 설계다.

현재 작업 소스는 authored JSON 104개 파일을 읽고 지문을 기록했다. 여기에서 뽑은 후보·프로필 행에는 여러 파일의 중복·부분 정의가 포함될 수 있다. 이 행 수를 실제 loader가 내보내는 활성 후보 수나 검색 정확도로 해석하지 않는다. 등록·검색·선택·생성에 대한 실행 증거는 이번 연구에 포함하지 않았다.

## 현재 데이터와 연결하는 방식

104개 연구 단위에 대해 기존 원본의 119개 참조를 확인했다. 이 참조에는 같은 ID를 여러 카드에서 사용하는 경우가 있다. ‘119개의 신규 후보’나 ‘119개의 동등 형태’를 뜻하지 않는다. 특히 `pv_arms_behind_head`의 양팔을 원문 126의 한 팔에 그대로 적용하거나, `pv_ankle_cross_seated`의 좌면 지지를 원문 103의 서 있는 발목 교차로 가져오면 자세가 바뀐다. 이런 사례는 부분 성분 검토 또는 새 변형으로 처리한다.

현재 `mirror_selfie_reflection_device_topology`는 물리 거울, 쥔 폰, 시선·가림의 일관성을 이미 다루지만 한 명의 분명한 성인을 전제한다. 범용 셀카 구조로 사용할 때 그 연령·인물 수·대명사 전제를 다른 요청에 전파해서는 안 된다. 이를 바꾸는 작업은 기존 exact activation과 과거 사례를 함께 검토해야 하므로 이번 연구에서 원본을 직접 변경하지 않았다.

초안의 반영 판단은 기존 성분 조합 81개, 신규/특수화 초안 75개, 고양이 하트 외형 초안과 이름 보류 1개, 낮은 무릎 앉기 재사용과 밤비 이름 보류 1개, literal 연구 후 원본 대조 대상 22개다. 메이크업 135를 립·브러시·퍼프로, 책 가림 133을 한 손·두 손 그립으로 분리하면서 후보·프로필 초안은 각각 79개가 됐다. 22개도 연구 카드의 의미·관찰·혼동 경계는 작성됐으며 런타임 ID 채택 판단이 남아 있는 상태다.

프로필 초안은 후보 초안과 같은 성분을 쓰되, 실제 렌즈 높이처럼 화면 밖 원인을 요구하는 부분은 투영 일관성의 관찰로 구분했다. ‘카메라가 실제로 바닥에 놓였음’이라는 실행 조건과 ‘낮은 시점에서 인물과 수직선이 위로 전개됨’이라는 이미지 증거를 같은 통과 주장으로 합치지 않는다. 양손·다인·가림·접촉·작은 손가락 형태에도 필요한 프레임을 명시했다.

## 성인 패션·반항·액션의 범위

원문의 성인 패션·부두아·뒤태·리클라인·입술 물기와 중지·록·복서 가드·전경 주먹·빌런 응시를 연구 범위에 유지했다. 구체적인 의상, 몸의 지지, 손 위치, 표정, 크롭을 분해했다. 예를 들어 뒤태 중심이라는 belfie 용법이 특정 노출·체형·한 가지 자세를 뜻하는 것은 아니다. 가드나 빈손 총 모양 또한 실제 타격·총격·부상의 필수 조건이 아니다. [SELF의 기존 belfie 용례](https://www.self.com/story/lea-michele-jlo-selfie)

성적 분위기·역할·감정은 요청 문맥으로 남기고, 구조 데이터가 이를 모든 자세에 자동 붙이지 않도록 계획했다. 원문의 성인 패션 맥락을 지우는 것과 모든 셀카에 성인·노출 조건을 추가하는 것은 모두 부정확하다. 실제 prompt 작성 단계의 연령 문구는 당시 유효한 creative control과 요청·계약에 따라 결정해야 한다.
