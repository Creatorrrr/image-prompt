# 적란운 모루 꼭대기의 기존 줄무늬 대안 보존

기준 커밋은 `ef0ea3f6a396d06bad42b92bfe7915f71089a5a5`다. 적란운 프로필의 구성 지시에서 `flattened fibrous anvil`을 `flattened fibrous or striated anvil`로 맞췄다. 성분·증거·게이트와 승인된 WMO 조사 추상화에 이미 있는 대안을 한 곳에서 누락한 문제다. 실제 구름 물리를 새로 검증했다는 뜻은 아니다.

어두운 낮은 밑면, 연결된 대류 탑, 모루 꼭대기, 강수 기둥의 네 필수 성분과 다섯 게이트를 그대로 보존했다. 섬유상 모루를 구체적으로 요구하는 기존 일곱 후보와 명시적 사용자 요구도 변경하지 않았다. 강수/virga 표현은 별도 결함 근거가 부족해 유지했다.

## 확인 결과와 한계

출처를 참고해 동결한 진단 입력 여섯 건을 정상 공개 CLI에 전후 실행했다. 섬유상·줄무늬·명시적 섬유상 세 양성은 대상 구성 문장과 파생 팩 ID만 변경되며 코어·후보는 동일하다. 광범위한 구름, 밑면 누락, 강수 기둥 누락 세 음성은 전체 팩이 바이트까지 같다. 필수 성분 누락 음성에는 정확 활성화 별칭을 넣지 않았으므로, 명시적으로 활성화한 계약의 성분을 생략해도 된다는 뜻이 아니다.

전후 총 12건의 전체 구성 감사가 같은 구성문과 증거로 통과했고 각 감사의 자유 서술/의도 커버리지 경고 세 개도 동일하다. 증거에는 기존의 선택지를 나열한 리터럴과 실제 선택한 줄무늬 분기가 함께 있으므로, 줄무늬만 쓴 자연어 증거 수용률 개선으로 해석하지 않는다. 후보는 실제 선택하지 않은 진단이며 독립 창작 평가나 이미지 품질 평가도 아니다.

새 회귀 2개, 기존 자연환경 8개, 사전 검증이 통과했다. 전체 1,496개 벡터·의미 텍스트·BM25F는 동일하고 파생 인덱스의 레지스트리 해시만 갱신했다. 제공자 호출과 추가 비용은 0, 프로젝트 누적 보수 상한은 $1.4237696이다. 실제 청구액 및 별도 작업 비용은 포함하지 않는다. 기존 전체 테스트의 자료 누락 한계는 [전체 실행 보고](../renewed-full-suite-baseline-20261002/README.md)에 남아 있다.
