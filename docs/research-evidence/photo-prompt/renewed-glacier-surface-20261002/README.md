# 빙하 표면의 기존 방향성 대안 보존

기준 커밋: `dbfd897ce20b5c7c21456af2234ec140e42676a9`.

빙하 프로필의 구성 지시 한 문장을 정의·성분·증거·게이트에 이미 존재하는 대안과 맞췄다. 기존 구성은 균열이 있는 얼음을 일괄 요구했지만, 나머지 계약은 크레바스, 흐름 띠 또는 잔해 줄무늬로 나타나는 방향성 표면을 허용한다. 연속 얼음, U자 계곡, 빙퇴석 접촉, 말단 융빙수와 넓은 시점은 보존했다.

여섯 기존 크레바스 전용 후보는 모두 그대로다. 사용자가 크레바스를 명시하거나 해당 후보를 선택하면 그 구체적인 요구를 계속 지켜야 한다. 잔해 줄무늬가 독립적으로 필요한 측면 빙퇴석 접촉을 대체하지 않는다. 유속·질량수지 추론도 허용하지 않는다.

## 검증

정상 CLI 여섯 전후 사례 중 세 양성은 구성 문장과 파생 팩 ID만 변경되었다. 세 음성 팩은 바이트까지 동일하며, 모든 코어와 후보는 보존되었다. 같은 구성문과 증거로 전후 감사가 모두 통과하므로 검색이나 증거 수용률 개선이라고 주장하지 않는다.

독립 재실행한 전체 구성 감사 여섯 건이 통과했다. 각 감사에는 기존 자유 서술/의도 커버리지 경고 세 개가 남는다. 새 회귀 테스트 2개와 기존 자연환경 테스트 8개가 통과했으며, 사전·현행 사진 기준도 검증했다. 재개 시 승인 변경과 여섯 전후 팩을 다시 검사하고 새 회귀 2개를 재실행했다.

전체 1,496개 프로필의 벡터·의미 텍스트·BM25F 데이터가 동일하며 인덱스 레지스트리 해시만 갱신했다. API 호출과 추가 비용은 0이다. 프로젝트 누적 보수 상한은 $1.4237696으로 실제 청구액이 아니다. 이미지 생성이나 픽셀 개선을 검증하지 않았다. 전체 테스트의 기존 자료 누락 한계는 [전체 실행 보고](../renewed-full-suite-baseline-20261002/README.md)에 남긴다.
