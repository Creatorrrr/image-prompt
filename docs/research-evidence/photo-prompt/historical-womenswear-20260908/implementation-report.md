## 독립 실험 절차

독립 서브에이전트 3개가 각각 유럽·한국·중국 복식 계열 안에서 장소, 행동, 소재, 보조 요소를 무작위로 뽑았다. 사용자 요청 원문을 해시로 고정하고, 각 에이전트가 로컬 연구·후보 데이터를 보기 전에 기본 프롬프트와 테스트 판정 조건을 확정했다. 선택한 상황은 에이전트가 만든 테스트임을 기록했으며 사용자 발화로 재분류하지 않았다.

이후 실제 v6 의미 검색 후보팩을 만들고, 고정한 의도와 일치하는 후보만 선택했다. 프롬프트 및 런타임 검사 후 제공된 초상 이미지를 참조하여 내장 이미지 도구로 각 1장씩 생성했다. 총 3회 호출, 재시도 0회다. 각 에이전트는 다른 에이전트의 프롬프트나 출력을 받지 않았다. 루트는 전달된 세 이미지를 직접 확인하고 고정한 판정 조건과 대조했다.

참조 범위는 사진에서 보이는 성인 외관이다. 동일 인물 여부나 신원·민감 속성을 검증한 실험이 아니다. 부분 충족은 전체 통과로 세지 않았다. 사용자 판단은 아직 받지 않았다.
