## 데이터 분류에서 바로잡아야 할 열 가지 문제

1. **시대·미학과 의복 구조를 분리한다.** Medieval, Renaissance, Baroque, Rococo, Victorian, Edwardian은 넓은 문맥이다. ‘Victorian gothic dress’에 크리놀린·버슬·기고 소매·모든 검은 옷을 한꺼번에 결합하면 서로 다른 시기의 구조가 섞인다. 19세기의 변화는 허리선, 치마 부피의 위치, 소매 부피를 나눠 표현할 수 있다. [Met 19세기 실루엣](https://www.metmuseum.org/pt/essays/nineteenth-century-silhouette-and-support).

2. **키르틀과 코트아르디를 전 시대의 완전 동의어로 만들지 않는다.** 지역별 명칭이 겹쳐도 시대에 따라 의복 범위가 달라진다. 특히 16세기 자료의 kirtle은 앞선 세기의 긴 드레스와 같은 뜻으로 항상 쓰이지 않는다. `regional_term`, `dated_sense`, `chosen_variant`를 연구 단계에서 구별한다. [FIT 1430년대](https://fashionhistory.fitnyc.edu/1430-1439/), [FIT 1540년대](https://fashionhistory.fitnyc.edu/1540-1549/).

3. **에냉의 현대 통칭과 역사 명칭을 함께 보관한다.** FIT의 관련 연구는 원뿔형 머리장식에 turret 등의 명칭을 쓰고 hennin의 역사적 적용을 문제 삼는다. 이것을 근거로 현대 사용자의 ‘에냉’을 삭제하는 것도 좋지 않다. 검색어는 보존하되 원뿔형·절두형·쌍뿔형을 뜻풀이 단계에서 구분하고, 이번 초안은 원뿔과 베일의 결합에 한정한다. [FIT 1450년대](https://fashionhistory.fitnyc.edu/1450-1459/).

4. **등판 재단과 치마 걷어 올림을 독립 축으로 둔다.** Met 1976.146a, b는 제목이 앙글레즈이고 설명은 폴로네즈식 드레이핑이다. 이 한 사례만으로 모든 polonaise라는 용어를 드레이핑으로 환원하지는 않는다. 다만 `back_construction`과 `skirt_draping`을 상호 배타적인 enum 하나로 저장하면 이 실례를 표현할 수 없다는 점은 분명하다. [Met 해당 소장품](https://www.metmuseum.org/art/collection/search/84611).

5. **파딩게일·파니에·크리놀린·버슬을 ‘큰 치마’로 합치지 않는다.** 원뿔, 엉덩이 둘레의 바퀴형 펼침, 좌우 확장, 고리 케이지, 후방 집중 부피는 다른 공간 구조다. 원래 지지물의 명칭과 입은 옷의 외곽선도 구별한다. [Royal Collection Trust 발췌](https://media.rct.uk/sites/default/files/Look%20inside_3.pdf), [Met 파니에 설명](https://www.metmuseum.org/pt/perspectives/costume-art-corset-drapery-body), [Met 크리놀린 실물](https://www.metmuseum.org/art/collection/search/82072).

6. **크리놀린은 다의어다.** 직물·뻣뻣한 페티코트·고리 케이지를 가리키는 용례가 연결되어 있다. ‘크리놀린 원단’을 케이지 지지 구조로 자동 해석하면 안 된다. 초기 원형에 가까운 부피와 뒤쪽으로 옮겨 간 변형도 함께 기록한다. [V&A 속옷과 구조물](https://www.vam.ac.uk/articles/corsets-crinolines-and-bustles-fashionable-victorian-underwear).

7. **겹옷의 빈틈은 맨살과 다르다.** 가무라의 끈 연결부, 튜더 소매의 열린 이음, 포어파트, 옆이 열린 조르네아는 아래 옷을 드러내는 관계를 포함한다. 현대 cutout으로 일괄 번역하지 않는다. 속층이 가려진 경우에는 눈에 보이지 않는 부분을 증거로 요구하지 않는다. [National Gallery 가무라](https://www.nationalgallery.org.uk/paintings/style-of-domenico-ghirlandaio-costanza-caetani), [FIT 조르네아](https://fashionhistory.fitnyc.edu/1490-1499/), [FIT 튜더복](https://fashionhistory.fitnyc.edu/1530-1539/).

8. **티 가운은 하나의 코르셋 규칙이 아니다.** Met은 어떤 티 가운을 코르셋 없이 입을 수 있는 옷으로 설명하고, 다른 실물에는 코르셋을 느슨하게 했을 가능성을 제시한다. ‘tea gown → 코르셋 없음’이라는 보이지 않는 필수 조건을 만들지 않는다. 실내 접객이라는 용도도 구조와 별개다. [Met 1890년 티 가운](https://www.metmuseum.org/art/collection/search/81518), [Met 1875–80년 티 가운](https://www.metmuseum.org/art/collection/search/158839).

9. **날짜 하나를 고증 정답으로 쓰지 않는다.** Met의 1851년 웨딩드레스 기록은 치마의 시대적 불일치를 스스로 설명하며 개조 여부도 확정하지 않는다. `제작 연대`, `개조 연대`, `묘사 연대`, `양식 추정`, `불확실성`을 나눠야 한다. 연대의 교집합은 검색 보조·검토 신호이지 모든 혼합을 자동 배제하는 근거가 아니다. [Met 연대가 불확실한 웨딩드레스](https://www.metmuseum.org/art/collection/search/159435).

10. **마네킹·회화·판화를 실제 착용의 동일한 증거로 취급하지 않는다.** NMS 만투아 전시에는 복제 지지물과 스토머커가 포함된다. 회화는 재단 내부를 증명하지 못하고, 사건 시점의 실제 옷이 아니라 화가 시대의 옷을 그릴 수도 있다. 패션 판화는 유행을 제시하는 출판물이다. [NMS 전시 구성](https://www.nms.ac.uk/discover-catalogue/luxury-in-fashion-the-18th-century-court-mantua), [Getty 중세 패션 전시](https://www.getty.edu/art/exhibitions/fashion/index.html), [V&A 패션 판화](https://www.vam.ac.uk/articles/the-art-of-fashion-plates-a-hidden-history-of-three-pioneering-women).

## 권장 시각 의미 축

아래는 **연구용 분해 축**이다. 새로운 런타임 필드를 이 이름 그대로 추가하라는 뜻은 아니다. 지원되는 기존 슬롯과 구성요소 계약에 투영하되, 인용·연대·논쟁 사항은 연구 근거 파일에 둔다.

| 연구 축 | 기록할 내용 | 실패하기 쉬운 대체 표현 |
|---|---|---|
| 층위 | underdress → overdress, undersleeve → outer sleeve, support → skirt | ‘화려한 중세 드레스’ |
| 몸판의 맞음 | 직선/원추형/몸에 맞음/느슨함; 재단이 어느 옷에 속하는가 | 실제 신체 치수나 체형으로 치환 |
| 허리 위치 | 가슴 바로 아래, 높은 벨트, 자연 허리 부근, 아래로 긴 몸판 | 모든 high-waist를 Empire로 판정 |
| 부피 방향 | 좌우, 전둘레, 후방; 돌출이 시작되는 높이 | ‘풍성한 치마’만 |
| 등판 연결 | 등목에서 자유롭게 하강, 허리에 맞게 형성, 별도 덧패널 | 앞면의 장식량으로 구분 |
| 치마 드레이핑 | 앞 열림, 들어 올린 위치, 드러나는 별도 페티코트 | 뒤에 천이 있으면 모두 bustle |
| 소매 | 부피 최대 위치, 중간 조임, 끝단 폭, 안소매와의 관계 | puff sleeve 한 태그 |
| 목선과 목 덮개 | 옷의 절개선, 그 안의 별도 천, 독립 칼라 | partlet·ruff·neckline의 합병 |
| 머리장식 | 지지 형태, 머리에 앉는 위치, 베일의 연결 | 티아라·마녀 모자 대체 |
| 재질 거동 | 주름의 깊이, 접힌 천의 두께, 표면 조직과 광택 | 광택만 보고 섬유·가격 확정 |
| 착용·관찰 모드 | 입은 가운 / 지지물 전시 / 보존 상세 / 구조 설명용 복제 | 불투명 가운을 통해 속 구조를 보이게 함 |
| 증거 가시성 | 보임 / 부분 가림 / 화면 밖 / 텍스트 근거만 | 안 보이는 것을 통과 처리 |

색·보석·궁정 배경·인물의 외모를 구조의 필수 조건으로 삼지 않는다. 검은 옷을 빈곤, 흰 옷을 순결, 옷의 풍성함을 임신, 코르셋 외관을 건강 상태로 번역하지 않는다. 역사적 문화·소장품 분류를 현대 인물의 국적·계층·정체성 추정으로 사용하지 않는다.

## 후보팩으로 옮기는 설계

한 번들에는 재사용할 수 있는 소수의 구성요소를 묶는다. 프랑세즈의 경우 ‘상자주름의 시작점’과 ‘허리에서 고정되지 않고 이어지는 하강’이 한 조형 의미를 만든다. 튜더 전면 변형은 ‘포어파트가 드러나는 앞트임’, ‘겉 커프스와 안소매’, ‘네모 목선 몸판’으로 나눌 수 있다. 색·배경·촬영 장르를 이 번들의 숨은 필수 구성원으로 추가하지 않는다.

권장 이행 순서는 다음과 같다.

1. 참조 대화의 정확한 키워드·정의·제외 사항을 확보하고 잠정 목록과 `동일 / 추가 / 범위 밖 / 다의어 / 근거 부족`으로 대조한다. 현재 초안의 `reference_conversation_alignment`는 모두 `pending`이다.
2. 각 항목이 의복 전체, 부위, 지지물, 착장 방식, 시대·미학, 현대 재해석 중 무엇인지 판정한다. 같은 철자라고 같은 ID에 합치지 않는다.
3. 현재 슬롯의 동일 의미가 있으면 보강하고, 필요한 경우에만 새 슬롯 엔트리를 만든다. 연구용 74개 단위가 곧 새 런타임 엔트리 74개라는 뜻은 아니다.
4. 구성요소를 지원되는 `concept_units` 및 관계로 표현하고, `candidate_ids`와 실제 `candidate_slots`를 연결한다. 관계 객체는 현재 스키마에 맞는지 별도로 확인한다.
5. 필수 시각 프로파일이 필요한 좁은 변형만 저작한다. ‘중세’, ‘빅토리안’, ‘가무라’ 등 넓은 표현에 선택한 한 표본의 모든 조건을 걸지 않는다. 사용자가 처음부터 정한 의미와 frozen core가 우선이다.
6. 외부 출처·연대·논쟁·출처 수준은 `docs/research-evidence/photo-prompt/`에 유지한다. 확장에는 현재 지원하는 `maintenance_ref`로 연구 기록을 연결하고, 검색용 긍정 문장에 거절 사례·원문 출처·연구 진행 상태를 섞지 않는다.
7. 확장 로딩과 번들 컴파일, 원본 해시, 실제 후보 노출을 확인한 뒤 의미·프로파일 인덱스를 갱신한다. 등록 건수 증가만으로 성공을 선언하지 않는다.

`reject_substitutes`와 혼동 경계는 판정·검색 구별을 위한 자료다. 이를 통째로 이미지 생성의 부정 프롬프트에 삽입하지 않는다. 잘못된 의미의 강제 억제 대신 올바른 층위와 구조를 긍정 문장으로 전달한다.

## 검증은 무엇을 입증해야 하는가

**첫째, 뜻이 보존되는가.** 원문에 사용자가 정한 정의가 있으면 통칭·사전·후보팩보다 우선한다. ‘현대 재해석’ 요청에 역사 실물을 강제하지 않고, 역사 재현 요청에 로코코펑크의 해체·비대칭을 자동 추가하지 않는지 시험한다.

**둘째, 후보가 실제로 전달되는가.** 원문 의미를 먼저 독립적으로 작성한 core로 v6 팩을 만들고, 선택 가능한 번들 및 멤버가 의도한 슬롯에 노출되는지 확인한다. exact routing, approximate retrieval, optional candidate exposure를 별도 기록한다. 같은 후보가 레지스트리에 있다는 사실만으로 이 단계가 통과되지 않는다.

**셋째, 보이지 않는 조건을 요구하지 않는가.** 뒤를 보지 못하는 정면 이미지에 프랑세즈 등 주름 PASS를 주지 않는다. 동시에 한 장에 완전한 정면·완전한 후면을 요구하지도 않는다. 원래 요청의 구도를 보존하고, 진단 목적의 별도 케이스에서 필요한 시점을 확보한다. 지지물 내부 구조는 전시·구조 설명 모드에서만 평가한다.

**넷째, 생성 결과에서 관계가 남는가.** 대표 비교는 프랑세즈/앙글레즈, 원뿔/바퀴 파딩게일, 파니에/크리놀린/버슬, 기고/파고다/비라고, 스펜서/펠리스, 가무라/조르네아 겹침이다. 설명 글자를 숨긴 상태에서 관련 부위와 전체 실루엣을 함께 판정한다. 다르게 보이는 색·보석·배경만으로 정답을 맞히게 하지 않는다.

후속 이미지 평가는 각 케이스의 원 요청, frozen core, 팩, 최종 프롬프트, 생성 설정, 반환 이미지, 시도 수를 보존해야 한다. A/B 비교를 하려면 같은 요청·모델·규격과 사전 확정한 시도 수를 사용하고 성공 이미지 선별을 금한다. 통과하지 않은 조건, 가려진 조건, 미생성 결과는 각각 남긴다. 패키지/라우팅/프롬프트/이미지 반환/픽셀/사용자 판단을 하나의 PASS로 압축하지 않는다.

## 우선순위와 충분성 기준

우선순위는 원문 키워드가 도착하면 조정한다. 현재는 의미 오류의 영향이 크고 비교가 명확한 **등판 3개 축, 지지 실루엣 4개 축, 튜더 겹소매·포어파트, 가무라 소매 연결, 엠파이어 허리선**부터 검증하는 것이 적절하다. 이후 머리장식·소매 변형·외투, 마지막으로 출처가 부족한 하위형을 보강한다. 숫자를 채우기 위한 유사 후보 증식은 하지 않는다.

이 분야의 데이터가 충분히 강화됐다는 판정에는 최소한 다음 증거가 필요하다.

- 원문 키워드 전부의 대응표와 범위 밖·보류 이유가 있다.
- 채택할 각 하위형에 형태 근거, 날짜·지역 범위, 가까운 혼동 사례가 있다.
- 실물·회화·판화·현대 복제·전시 보조물을 구분한다.
- 선택적 번들 노출과 필수 의무의 독립성이 실제 v6 팩에서 확인된다.
- 정의를 구분하는 양성·음성 및 교차 조합 케이스가 통과한다.
- 대표 생성 이미지에서 핵심 관계를 읽을 수 있고, 확인할 수 없는 조건을 통과 처리하지 않는다.

현재는 **출처 조사와 설계 초안까지**다. 원문 대조, 런타임 반영, 인덱스 갱신, 실제 후보팩 노출, 생성 이미지 검증, 사용자 수용은 완료되지 않았다.

## 조사 종료 지점과 후속 조사

검색은 박물관의 실물·전시·교육자료와 저자 있는 복식사 해설을 우선했다. 첫 조사에서 중세·르네상스, 18세기 가운, 19세기 실루엣을 나누고, 다음 조사에서는 다의어와 상충 사례를 확인했다. 구체적으로 kirtle의 시대별 뜻, hennin 명칭, 앙글레즈와 폴로네즈의 교차, tea gown의 코르셋 설명, 1851년 소장품 연대 문제를 추가 대조했다. 판매 페이지·소셜 게시물·검색된 영화 이미지는 채택 근거로 사용하지 않았다. FIT의 일부 오래된 개요가 Wikipedia를 그대로 인용하는 사례는 해당 주장 근거에서 제외했다.

잠정 36개 항목의 데이터 설계에 필요한 주요 차이와 반례를 확보한 시점에 광범위한 검색을 멈췄다. 다음 자료 수집은 원문 키워드 대조에서 드러난 빈칸을 대상으로 한다. 블리오 원문, 사이드리스 쉬르코 재단·도상, 후드의 원본 초상, 지역 일상복, 기존 목록 밖의 세계 복식이 그 후보이며, 후자를 이미 조사한 것처럼 채워 넣지 않았다.
