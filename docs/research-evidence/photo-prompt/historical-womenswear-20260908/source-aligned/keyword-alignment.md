## 표 밖의 범위·주의점

- P01 (60–64행): **hennin / conical headdress** — 검색 별칭 hennin 유지; 원뿔과 베일의 형태·시대는 별도 판정.
- P02 (260–262행): **lens / full-length / three-quarter rear** — 렌즈·조리개는 시작값. 요구 특징을 보이는 시점과 해상도를 확보.
- P03 (268–280행): **four example prompts** — 4개 예시는 창작 레시피. 프랑세즈 등 주름 판정에는 후면이 필요.
- P04 (286–288행): **Pre-Raphaelite-inspired medieval romance** — 19세기 중세 재해석과 실제 중세 표본을 구분.
- P05 (290–292행): **fitted gown / stays / corset** — 서로 다른 시대와 구성. 불투명 옷 내부를 픽셀 의무로 요구하지 않음.
- P06 (294–296행): **court / everyday / social roles** — 서사의 역할과 보이는 옷을 구별. 사진에서 신분·직업을 추정하지 않음.
- P07 (298–300행): **daguerreotype / modern recreation** — 의복 시대와 촬영 공정 독립. 중세 당시 실제 사진이라는 주장을 생성하지 않음.
