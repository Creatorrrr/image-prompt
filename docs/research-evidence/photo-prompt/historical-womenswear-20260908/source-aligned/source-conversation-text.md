## 2. 중세 여성복 콘셉트에 관련된 단어

### 의복과 실루엣

| 용어 | 의미·형태 | 촬영에서 강조할 부분 |
|---|---|---|
| **커틀 — Kirtle / Cotte** | 여성의 기본적인 긴 가운. 시대에 따라 헐렁하거나 몸에 맞는 형태가 있으며, 속옷 위에 입음 | 허리에서 밑단으로 이어지는 선, 걸을 때 생기는 주름 |
| **코트아르디 — Cotehardie / Côte-hardie** | 중세 후기의 몸에 밀착되는 가운을 지칭하는 데 쓰이는 명칭 | 몸통의 피팅, 긴 소매, 끈 여밈, 상체와 넓은 치맛자락의 대비 |
| **슈미즈 — Chemise / Smock** | 피부에 가까이 입는 기본 속옷층 | 목이나 소매 틈에서 보이는 속천, 옷의 겹침 |
| **우플랑드 — Houppelande** | 원단을 풍성하게 사용한 겉가운 | 바닥에 고이는 옷자락, 깊은 주름, 큰 소매 |
| **맨틀·클로크 — Mantle / Cloak** | 몸을 감싸는 망토류 | 어깨에서 내려오는 큰 면, 바람에 움직이는 외곽선 |
| **봄바르드 소매 — Bombard sleeves** | 어깨 쪽은 좁고 아래로 갈수록 크게 벌어지는 깔때기형 소매 | 손동작에 따라 달라지는 소매의 공간감 |

### 로코코와 18세기
