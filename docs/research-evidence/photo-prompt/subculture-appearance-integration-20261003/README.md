# 서브컬처 외형 대체 표현 반영과 독립 이미지 시험

조사 결과를 실제 시각 의미 레지스트리와 후보 사전에 반영했다. 시각 의미 프로필 46개를 추가하고 기존 36개를 보강했으며, 후보 45개를 추가하고 기존 35개의 대체 표현을 보강했다. 독립 에이전트 3개가 서로의 입력을 읽지 않고 복잡한 장면을 작성한 뒤 첨부 얼굴 사진을 사용해 각각 이미지를 1회 생성했다.

외형 키워드의 실제 픽셀은 12개 중 11개가 통과했다. 온실의 히메컷은 실패했다. 관측소의 네 외형 관계는 통과했지만, 가려진 눈의 좌우가 동결 프롬프트와 반대였다. 이 때문에 외형 관계별 all-of는 2/3이고, 장면 배치와 좌우까지 포함한 전체 컨셉 실현은 1/3이다. 실패한 최초 이미지를 보존했다.

새 프로필의 전체 관계 대체 표현은 122개, 구성요소 대체 표현은 244개다. 기존 프로필에는 전체 관계 대체 표현 72개, 기존 후보에는 대체 표현 71개를 추가했다. 새 후보에는 검색용 표제·표기 변형 92개를 넣었다. 이 숫자들은 용도가 다른 집계이며 고유 표현 총수로 합산하지 않는다. [집계 원본](ALTERNATIVE-STATS.json)을 보존했다.

중점은 이름을 늘리는 것과 함께 같은 외형을 여러 방식으로 설명하도록 만드는 것이었다. 예를 들어 트윈 드릴은 양쪽 머리 덩어리의 반복 나선과 끝으로 갈수록 좁아지는 관계로, 머리 나선의 리본은 머리와 구별되는 별도 띠의 감김으로 보강했다. 한 눈·양 눈 가림, 옆·안쪽·뿌리에서 끝으로 바뀌는 머리 색, 눈꼬리 방향과 눈꺼풀 열림, 홍채 전체·부분·중심 색 분할도 별도 관계로 구분했다.

의복에서는 몸통과 분리된 소매와 드러난 팔 간격, 장갑과 소매, 손등까지 이어지는 건틀릿과 팔뚝 판금, 속치마와 겉치마의 층, 가장자리를 따라가는 파이핑과 넓은 줄무늬, 귀 머리띠와 해부학적 귀를 구분했다. 기존 히메컷·양갈래·신체 형태·열린 메시·가터 연결·시어 층 등의 구성요소에도 한국어와 영어 대체 표현을 추가했다.

기존 36개 프로필의 정의, exact 활성화, owner, 게이트 ID·개수·최소 증거, property effects는 보존했다. 머리 스타일은 `hair.style.*`, 머리 색은 `hair.color.*`의 기존 property 체계를 사용한다. 의복 색·손등 덮임 같은 변화도 기존 property lock을 우회하지 못하도록 확인했다. 새로운 주제별 생성 분기는 추가하지 않고 공통 로더에 두 extension을 등록했다.

[원 조사](../subculture-appearance-20261003/README.md)의 187개 연구 단위는 [반영 연결표](DISPOSITION-BRIDGE.json)로 추적한다. 기존 단위 중 새 관계 채택 44개, 기존 local owner의 부분 보강 34개, 자동 런타임 승격을 하지 않은 109개다. 여기에 F05의 부분·중심 홍채 색 차이 두 관계를 명시적으로 분리했다. 연구 JSON의 스키마와 runtime eligibility를 직접 바꾸지 않았다. 넓은 캐릭터 레시피, 신체·종족 전환, 매체 변경, owner가 불명확하거나 지원되는 dimension scope가 없는 항목은 자동 활성화하지 않는다.

## 세 독립 시험

각 에이전트는 사전 허용 자료와 실제 사용자 요청만으로 컨셉·기준·core를 먼저 동결했다. 이후 동일한 반영 데이터의 해시를 확인하고 후보팩 하나를 읽어 최종 프롬프트와 도구 입력을 감사했다. 에이전트가 고른 키워드는 에이전트 작성 의미로 기록했으며 사용자 원문 정의로 만들지 않았다. 참고 사진은 보이는 얼굴 외형에만 사용하고, 가상의 성인 인물을 작성했다. native `image_gen`을 사용했고 CLI/API 대체 경로는 사용하지 않았다.

| --- | --- | ---: | ---: | --- |
| 해저 유리 공연장의 첫 음 직전 | 트윈 드릴, 나선을 감싼 리본, 분리 소매, 코랄 파이핑 | 4/4 | 4/4 PASS | 추가 실패 없음 |

원본 이미지·프롬프트 해시는 [artifact 기록](QUALIFICATION-ARTIFACT-HASHES.json), root의 원본 픽셀 재검토는 [통합 평가](ROOT-PIXEL-REVIEW.json)에 있다. 첨부 참고 사진도 [원본 바이트](reference/input-portrait.jpg)와 해시를 보존했다.

세 arm의 구성·런타임 감사와 신체·접촉 게이트 5개는 각각 기술 통과했다. 이것이 외형 실패나 좌우·배치 편차를 상쇄하지 않는다. 관측소의 가려진 눈은 참고 사진과 비교할 수 없어 UNOBSERVABLE로 남겼다. 사용자 취향과 수락은 미확인이다.

후보 노출과 선택은 총 5/12이며, 목표 optional visual profile은 세 arm 모두 미노출이었다. 따라서 외형 픽셀 11/12 통과를 이번 데이터의 검색·채택 효과로 환산하지 않는다. 해당 관계가 처음부터 동결 프롬프트에 들어 있었고, 반영 전후를 통제한 이미지 비교도 수행하지 않았다. 일반 후보의 실제 노출·선택은 해저 4개, 온실의 페티코트 1개에서 확인했다.

후속 읽기 진단에서는 별도의 자연어 12문장으로 현재 BM25F 사전을 조회했다. 목표 후보는 상위 5개 안에 7개, 상위 20개 안에 8개가 나타났다. 히메컷·레이스업·한 눈 가림·열린 메시의 한국어 문장은 상위 20개에 목표 후보가 없었다. 이 결과는 [읽기 진단](READ-ONLY-RETRIEVAL-DIAGNOSTIC.json)에 보존했다. 이미지 생성 뒤 작성한 진단이며, 통합 후보팩의 필터·slot 배분·채택이나 독립 holdout 성적과 같은 것으로 취급하지 않는다. 현재 데이터나 시험 기준을 이 12문장에 맞춰 다시 작성하지 않았다.

## 검증과 다음 보강 항목

시각 의미 인덱스는 변경된 82개 프로필을 실제로 재임베딩했고, 후보 인덱스는 동일 텍스트와 벡터 공간 항목만 재사용해 재생성했다. 사전 메타데이터 검사, 인덱스 검사, 실제 `load_runtime_data` 로딩을 통과했다. 구성요소 누락, 오인 관계, 사용자·에이전트 출처, 부정·제외 범위, property lock, 기존 owner 보존을 회귀 시험한다.

최종 전체 unittest discovery 1362개는 실패·오류·skip 없이 모두 통과했다. 후속 범위 검사 36개도 통과했다. [검증 기록](TEST-RESULTS.json)에 전체 집계를 보존했다. 초기 회귀 실행에서 드러난 외부 유지보수 참조, 과거 후보 비교용 overlay 제외 목록, 현재 사진 후보팩 기준과 validator 바이트 참조는 수정했다. 사진 기준 V1–V8과 네 동결 입력은 보존하고, 현재 관찰만 V9으로 연결했다. [이력 보존 기록](boundary-preservation/)에 변경 전 자료를 보관했다. 이미지 시험에서 확인한 FAIL은 자동 테스트 통과와 별도로 유지한다.

이번 결과로 남은 우선순위는 다음과 같다.

1. **후보 노출 누락 분석:** arm별 동결 query·slot 배분·상한 64개 안의 경쟁 후보를 추적한다. 미노출 7개를 이미지를 본 뒤 의무 후보로 넣거나 사용자 정의로 바꾸지 않는다. 새로운 한국어·영어 설명 holdout으로 owner별 발견률과 혼동 후보 순위를 측정한다.
2. **대체 표현의 검색 효력 검증:** 이번 프롬프트를 학습 문장으로 재사용하지 않은 최소쌍을 작성한다. 한 눈/양 눈, 머리 리본/염색, 손등/팔뚝, 열린 메시/인쇄 격자가 구분되는지 검증하고, 모든 구성요소가 있는 표현만 채택 가능하도록 유지한다.
3. **히메컷과 좌우 후속 시험:** 처음 실패한 이미지·프롬프트·기준을 유지한 별도 후속 run에서 짧은 옆 패널의 끝 위치와 긴 뒷머리 단차, 인물 기준 좌우를 각각 독립 게이트로 관측한다. 기존 11개 PASS와 장면·접촉 조건도 함께 검사한다.
4. **데이터 효과의 통제 비교:** 동일한 새 core와 참고 입력으로 반영 전·후 후보 노출 및 최종 프롬프트 차이를 먼저 비교하고, 변경이 확인된 경우에 이미지 시험을 연결한다. 검색·작성·원본 픽셀·사용자 수락을 별도 결과로 기록한다.

이 항목들은 이번 실패를 통과로 재표기하기 위한 작업이 아니라 다음 보강과 검증의 범위다. 이번 반영과 세 최초 생성 결과는 이 문서의 연결 자료에 고정되어 있다.
