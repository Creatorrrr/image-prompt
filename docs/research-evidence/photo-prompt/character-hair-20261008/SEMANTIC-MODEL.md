# 헤어 의미를 관찰 가능한 구조로 저장하는 설계

작성일: 2026-10-08, Asia/Seoul. 상태: 연구·반영 설계. 이 문서는 런타임 스키마 변경이나 데이터 채택 완료를 뜻하지 않는다.

## 판단

454개 명칭을 각각 하나의 스타일 프로필로 만들면 중복, 잘못된 배타성, 시술 원인 추정, 동명이의어 충돌을 늘린다. 의미 정의는 관찰 축과 관계로 분해하고, 이름·언어·시대·플랫폼은 그 정의로 들어가는 검색 표면으로 관리하는 편이 타당하다. 시각 의미 프로필은 무엇을 보여야 같은 의미인지를 설명하고, 슬롯 후보는 그 의미의 가능한 표현을 제안한다. 양쪽을 일대일로 합치지 않는다.

원본 용어집의 `H001–H454`는 입력 추적 ID다. 이 ID 자체는 새 프로필 ID, 후보 ID, hard activation 근거가 아니다. `R01–R48`은 창작 조합안으로만 유지한다.

## 관계의 최소 단위

예를 들어 안쪽 청록 피카부 컬러는 `검정·청록 머리`보다 다음의 관계로 설명해야 한다.

1. 같은 인물의 겉 모발층이 기본색을 유지한다.
2. 아래·안쪽 모발층이 다른 색을 가진다.
3. 겉층이 안층을 일부 가리고, 열린 틈에서 안쪽 색이 드러난다.
4. 드러난 색 가닥은 해당 모발층을 따라 연속된다.

관계 방향은 `outer layer → occludes → inner layer`, `inner layer → has color → teal`, `inner strand → continues through → revealed gap`으로 보존한다. 주변 청록 조명이나 청록 리본은 같은 결과를 증명하지 않는다. 안층이 완전히 가려진 사진은 색의 부재도 성공도 입증하지 못한다.

분석용 owner는 `subject.hair`로 쓸 수 있지만 런타임 속성 효과는 현재 계약에 맞춰 `dimension: appearance`, `target: main_subject`, `property: hair.color.inner_layer`처럼 옮긴다. 속성명이 기존 lock과 같은 계층을 사용해야 한다. `hair.color` 또는 `hair`가 잠겨 있으면 자식 속성 변경으로 우회할 수 없다. 조명 차원의 효과라고 이름만 바꿔 모발색 잠금을 우회하지 않는다. 같은 원리는 다른 인물, 앞머리, 뿌리 높이와 장식에 적용한다.

## 의미 카드, 후보, 번들의 분담

**의미 카드**는 정의, 출처가 지지하는 범위, 최소 시각 서명, 오인 경계, 관찰에 필요한 영역을 보관한다. **후보**는 한 실현안의 긍정적인 문구와 속성 효과를 담는다. **번들**은 여러 후보가 같은 모발 소유자와 배치에 속하는지 연결한다. **프로필**은 명시적으로 요청되거나 선택된 의미의 증거와 검증 조건을 담는다.

블런트 보브 후보에 검정색·완벽주의·성별·나이를 자동으로 넣지 않는다. 얼굴 옆 성긴 가닥과 뒤쪽 블런트 외곽은 서로 다른 부위에 적용할 수 있다. 한국 통칭, 문화적 이름, 화보 제목은 가능한 실현안의 군을 알려줄 수 있으나 같은 구조 하나를 항상 강제하지 않는다.

하나의 원본 용어가 여러 카드에 연결될 수 있다. 반대로 69개 색 이름·다색 배치 계열은 공통 색 축과 위치 구조를 재사용할 수 있다. 프로필 수나 후보 수의 증가는 충분성 기준이 아니다. 필요한 차이와 관계가 빠짐없이 표현되는지가 기준이다.

## 현재 데이터에서 먼저 검토할 점

현재 working checkout의 raw authored rows는 hair_style 105개, hair_color 27개다. 이 132개 중 concept_units 78개, relations 47개, affected_properties 40개다. 나머지가 모두 오류라는 뜻은 아니다. 기존 단순 후보와 속성별 선택을 지원하는 구조 후보가 섞여 있다는 뜻이다. 전체 source row 수와 생성 인덱스/runtime의 상태는 별도 검증 대상이다.

기본 레지스트리의 전용 헤어 프로필 7개 외에 subculture appearance/Y2K/캐릭터 외형 프로필도 있다. 따라서 7개만 검색한 뒤 기존 의미가 없다고 결론내리면 안 된다. `KEYWORD-CROSSWALK.json`은 전체 등록 원본의 이름·alias·긍정 문구를 대조한 참고 자료다.

가장 먼저 검토할 경계는 wet-look이다. 현행 `wet_damp_clumped_hair_state.activation.exact_terms`에는 `wet-look hair`와 `wet look hair`가 들어 있지만, 정의·증거는 실제 수분에 일치하는 상태를 요구한다. 젤로 연출한 wet look과 실제 물에 젖은 상태를 분리하는 수정이 필요하다. 이는 현재 소스에서 발견한 의미 충돌이며 이번 연구에서 live activation이나 렌더를 실행한 결과는 아니다. 이미 보존된 실제 젖음의 비부착 처짐 대안은 유지한다.

발레아주도 시술 명칭과 대표 외형을 분리해 검토한다. 현행 프로필은 darker roots, irregular ribbons, base continuity, 옴브레와 구별되는 배치를 요구한다. 이 구조 자체는 유용하지만 모든 balayage 결과의 보편적 정의로 만들기 어렵다. 대표 구조는 좁은 이름의 optional 프로필로 보존하고, 시술·색 경사·가닥 폭·뿌리 상태는 함께 존재할 수 있는 축으로 검토한다. 정확한 alias 정비는 동결된 기존 요청과 역사적 재생 범위를 조사한 뒤 한다.

## 관찰성·출처 상태

출처 신뢰와 이미지 관찰성을 한 점수로 합치지 않는다. 출처에는 direct body, 공식 wiki API, 검색에 남은 과거 본문, 접근 실패를 구분한다. 시각 항목에는 다음을 따로 기록한다.

- 특정 뷰에서 확인 가능: 두피 뿌리, 길이 단차, 색 면 경계 등.
- 설명이 있으면 관찰 가능한 외형: 임상/시술/설치 용어의 결과 투영.
- 정지 이미지로 원인을 확정할 수 없음: 자연색/염색, natural/faux locs, 자연 곱슬/펌, wet look/실제 수분의 원인 등.
- 시간적 증거가 필요: 부유·감정에 따른 변화·독립 움직임. 한 프레임은 선택된 자세·접촉·높이 관계만 확인한다.
- 비시각 주제: trichophilia 같은 관심 개념. 특정 머리·성격의 증거로 쓰지 않는다.

국소 흰 모발의 임상 명칭은 임상 정의를 설명할 수 있지만 이미지로 진단하지 않는다. 혈흔·진흙·불에 그을린 끝도 실제 물질이나 사건의 원인은 문맥에 의존한다. 이를 조사에서 제외하지 않고 state/context와 소유자를 분리한다.

## 렌더 판정 설계

프로필마다 필요한 최소 관계를 기준으로 gate를 만든다. 모든 프로필을 관례적인 다섯 그룹으로 늘리지 않는다. collective duty가 있으면 현행 authored-components/v2의 obligation이 여러 구성요소와 증거를 함께 묶도록 한다. discovery threshold를 통과했다고 선택된 obligation의 gate가 줄어들지 않는다.

정면만으로 뒤통수 stack이나 목덜미 undercut을 볼 수 없고, 뒤쪽만으로 앞머리 길이를 판단할 수 없다. 한 장에서 필수 관계를 볼 수 있는 카메라·머리 상태를 실현해야 한다. 사진의 목적을 해치며 모든 부위를 억지로 노출시키는 기본 구도를 만들지는 않는다. 필요한 관계가 숨으면 해당 관찰은 `UNOBSERVABLE_NOT_PASS`로 둔다. 실제 품질의 all-of 판정에서는 한 필수 관계의 실패를 다른 예쁜 요소나 일부 성공으로 상쇄하지 않는다.

## 물리·문화 자료의 사용 범위

Marschner 등의 측정 연구와 PBRT 설명은 모발 반사가 광원·시점·가닥 방향·흡수와 함께 달라지는 근거를 제공한다. 이를 근거로 염색 가닥의 색, 광택, 역광 잔가닥을 분리한다. 이 자료가 생성 모델의 정확도나 한 사진의 실제 색을 검증한 것은 아니다. [Marschner et al.](https://graphics.stanford.edu/papers/hair/), [PBRT 4판 9.9](https://www.pbr-book.org/4ed/Reflection_Models/Scattering_from_Hair).

젖은 머리의 모세관적 응집 연구는 유연한 lamellae 모형의 실험이다. 가닥 뭉침의 물리적 개연성을 참고할 수 있지만, 광택이나 뭉침만으로 실제 물의 존재를 판별하는 이미지 분류 규칙을 제공하지 않는다. [Bico et al., 2004](https://pubmed.ncbi.nlm.nih.gov/15592402/).

한국민족문화대백과사전의 댕기·상투 설명은 장식의 재료/접합과 정수리 묶음의 구조를 분리할 근거다. 색·문양·시대·용도의 차이도 있으므로 역사물의 신분·혼인 상태를 헤어 실루엣 하나로 확정하는 규칙으로 쓰지 않는다. [댕기](https://encykorea.aks.ac.kr/Article/E0015303), [상투](https://encykorea.aks.ac.kr/Article/E0027380).

## 자료 충분성의 기준

이번 연구의 충분성은 다음 네 층으로 판단한다. 454개 입력 용어 전부에 조사/반영 disposition이 있고, 중요한 구조·오인 경계에는 직접 출처가 있으며, 후보·프로필·번들 연결의 구현 경로가 현재 계약과 맞고, 아직 실행하지 않은 검증이 계획에서 분명한지 확인한다. 454개 모두가 표준 명칭이거나 454개 정의를 독립 검증했다고 주장하지 않는다. 실제 인덱스 통합과 후보 노출·선택·이미지 품질 개선은 이후 각각 직접 증거가 필요하다.
