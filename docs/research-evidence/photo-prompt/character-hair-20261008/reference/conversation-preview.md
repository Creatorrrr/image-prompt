# 1. 헤어스타일을 구성하는 기본 요소

스타일명을 하나 고르는 것보다 **길이 → 외곽 형태 → 앞머리 → 가르마 → 질감 → 묶음 → 색 배치 → 현재 상태**를 나누어 지정하면 원하는 외형을 더 명확하게 설명할 수 있습니다.

| 용어·영문 | 설명 |
|---|---|
| 귀 길이 — Ear-length | 머리끝이 귓바퀴나 귓불 부근에 도달한다. |

이 표의 길이 표현은 **신체 위치를 이용한 묘사 기준**입니다. 플랫폼의 `short hair`, `long hair` 태그는 경계가 다를 수 있으므로, 정확한 길이가 중요하면 신체 위치를 함께 적는 편을 권합니다.
