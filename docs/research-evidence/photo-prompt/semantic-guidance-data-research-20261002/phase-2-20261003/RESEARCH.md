# 시각 의미 데이터 상세 조사: 문맥 의미와 용어 없는 형상 표현

조사 범위는 기존 12개 개념군, 15개 시각 프로필과 연결된 쿨데레 의미 그래프 레코드이다. 두 목표를 기준으로 원어 자료, 제작 도면, 광학 제조사 설명, 현재 데이터의 증거 조건을 대조했다. 런타임·스킬 로직·프로덕션 데이터·인덱스는 수정하지 않았다. 파일별 변경 문장과 순서는 [반영 계획](INTEGRATION-PLAN.md), [15개 프로필 변경 초안](profile-change-plan.json), [캐릭터 의미 범위 초안](character-scope-plan.json)에 있다.

핵심 판단은 **동의어보다 문맥별 의미 범위와 관찰 가능한 관계를 보강하고, 재서술 예문과 증거 조건을 함께 맞추는 것**이다. 이름을 없앴다는 이유로 원래 의복·아래층·부착점·행동을 다른 대상으로 바꾸면 의미 보존으로 인정할 수 없다. 허용되는 장면을 중립적인 구조 언어로 정확하게 기술하는 것이 조사 범위다. 안전장치 회피용 대체어 목록이나 차단 통과 보장은 만들지 않는다.

## 현재 데이터와 조사 표본

현재 작업 파일을 실제 로더로 읽었을 때 **1,496개 시각 프로필**이 있다. 앞선 1차 조사 스냅샷의 1,419개보다 77개 많다. 이번 스냅샷은 같은 Git HEAD에서도 작업 중인 파일 내용이 달라질 수 있음을 반영해 원문 해시를 함께 저장했다. 의미 데이터 전체 크기, 사용 요청의 빈도, 서로 다른 어휘 의미 수를 같은 숫자로 취급하지 않는다.

| 현재 설정·분포 | 확인한 수 | 해석 범위 |
|---|---:|---|
| 시각 프로필 | 1,496 | 로더가 읽은 authored profile 수 |
| `definition_with_optional_label` | 1,256 | 이름을 선택적으로 쓸 수 있는 설정 |
| `label_plus_definition` | 200 | 이름과 설명을 함께 쓰는 설정 |

61개만 문맥 구분 필드를 갖는다고 나머지가 전부 모호하다는 뜻은 아니다. 41개의 금지 라벨 설정은 실제 모델 차단 이력이 아니다. 범주별 수가 많다는 것은 개념·언어·변형이 충분히 덮였다는 증거도 아니다. 의복·형태 관계의 비중이 큰 분포이므로, 다음 확장에서는 한 개념의 변형 수보다 **한 단어가 다른 문맥에서 뜻하는 대상과 가까운 혼동 개념**을 함께 점검하는 편이 두 목표에 더 직접적이다.

이번 15개는 목적에 맞춰 선택한 심층 조사 표본이며 무작위 표본이 아니다. 전체 1,496개의 결함률을 추정하지 않았다. [현재 분포](current-distribution.json), [스냅샷](current-snapshot.json), [1차 조사 이후 차이](baseline-drift.json)에 계산 기준이 있다.

### 원어 자료에서 새로 확인한 점

국립국어원 표제어를 사이트 검색으로 직접 읽어 드레스 기본 뜻과 수영복 복합어 용례를 동시에 확인했다. 따라서 `원피스`라는 한국어 토큰 하나로 드레스 구조를 확정하는 데이터는 부족하다. [한국어기초사전 원피스](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=26721)

저자 공개 자료 PDF 2쪽의 외면·내면 도식과 각주, FLIGHT 공식 PDF 3쪽의 용어 설명을 렌더링해 읽었다. 이 자료들은 차분한 외면과 특정 상대를 향한 감정의 관계를 지지한다. **실용적 도움이라는 현재 데이터 조건은 프로젝트가 선택한 관찰 연출**이라는 판단이다. 특정 작품의 성별·학교·머리색·옷은 성인 사진 데이터의 공통 요구로 가져오지 않는다. [冨樫純一 자료](https://www2.ic.daito.ac.jp/jtogashi/articles/togashi2009a.pdf), [FLIGHT 공식 자료](https://www.flight.co.jp/uploaded_files/c_news/106_detail.pdf)

Vogue 도면은 중앙 앞판에 놓이는 고리 부분과 대응 돌기 부분의 결합을 보여 준다. Simplicity 앞뒤 도식은 장식 리본 유무와 길이가 달라도 한쪽 어깨 연결을 유지한다. 숨은 제작 과정과 사진에서 보이는 구조를 구분할 수 있는 직접적인 보강 근거다. [V1876 제작 도면](https://s3.eu-west-1.wasabisys.com/sewdirect/V1876_francais_english_ins.pdf), [S3165 원숄더 도식](https://www.sewdirect.com/product/simplicity-s3165/)

제조사 자료는 튤 제품의 조직·무게·마감 변형과 스플릿/스폿 초점 관계의 차이를 설명한다. 튤의 모든 셀 모양을 고정하거나 두 초점 영역만으로 실제 장비 사용을 확정할 수는 없다. [Heathcoat 제품군](https://www.heathcoat.co.uk/new-colours-for-flare-free-tulle/), [Schneider-Kreuznach Diopters](https://schneiderkreuznach.com/en/cine-optics/filters/cine-filters/diopters)

Dehancer 문서는 디지털 할레이션 시뮬레이션의 국소 확산·2차 확산·색상과 블룸 공존을 구분한다. 실제 필름의 보편적 물리 정의에는 앞선 Kodak 근거를 사용하며, 디지털 제품 문서를 그 정의로 대신하지 않는다. Profoto의 실제 작업 설명은 얼굴과 카메라의 관계로 브로드/쇼트를 설명한다. [Dehancer Halation](https://www.dehancer.com/learn/article/halation), [Profoto 조명 설명](https://www.profoto.com/lv/en/still-photography/profoto-stories/character-portraits-with-john-russo-and-profoto-d2)

## 목표 2: 용어 이름을 빼도 같은 형상을 남기는 데이터

이 목표에 유효한 데이터 단위는 `원래 의미 → 문맥과 대상 → 필수 관계 → 허용 변형 → 자연스러운 구조 문장 → 가까운 대체 오류 → 확인할 픽셀`이다. 단어를 덜 민감한 이름으로 바꾸는 것만으로는 부족하다. 단어별 모델 차단 여부는 현재 관찰하지 않았으며 아래 사례를 차단되는 단어 목록으로 제시하지 않는다.

| 기존 용어가 가리키는 선택 구조 | 이름 없이 쓰는 문장 초안 | 보존해야 하는 것 |
|---|---|---|
| 목선 카울 드레이프 | `the garment opening at the neck hangs in loose folds of the same continuous fabric` | 목 개구부와 같은 천의 연결, 느슨하게 매달리는 접힘 |
| 미세 튤 메시 | `fine threads form an evenly spaced network of actual open cells in the garment fabric` | 가는 실, 간격, 실제 열린 셀, 의복의 소유권 |
| 버스크 잠금 앞판 | `a fitted paneled bodice has two center-front edges joined by a vertical row of metal loops engaging matching studs` | 두 앞판 경계와 세로 대응, 고리·돌기의 맞물림 |
| 섬유층 뒤 신체가 부분적으로 읽히는 원단 투과 | `underlying body contours remain partly visible beneath the readable garment fibers` | 투과하는 원단과 그 뒤 신체의 구분, 요청한 피복 범위 |

의복이나 기능의 이름은 검색용 원어·별칭·출처 메타데이터에는 남길 수 있다. 출력 문장에서 이름을 생략하는 선택과 데이터베이스에서 용어 자체를 삭제하는 것은 다른 작업이다. `definition_with_optional_label`을 모두 `definition_only`로 바꾸거나 모든 원래 이름을 금지하는 일은 이번 반영 초안에 포함하지 않았다. 특정 요청에서 이름을 생략하려면 기존 출력 모드와 요청의 선택이 맞아야 하며, 구조 데이터만으로 전역 출력 정책이 바뀌지는 않는다.

### 예문만 추가하면 남는 실제 문제

카울·메시·앞판 잠금의 세 clothing 프로필은 `authored_components`의 증거 문자열에도 원래 용어가 들어 있다. 예문을 중립화해도 현재 리터럴 검사는 원래 문자열 중 하나를 포함해야 한다. 새 자연어 구조 문장을 같은 컴포넌트의 `evidence_terms`에 함께 추가하고, 정의·명령·판정 설명도 그 구조를 쓰도록 맞추어야 한다. 컴포넌트 수·필수 필드·게이트 ID·최소 단어 수는 유지한다.

시어 프로필에는 더 직접적인 충돌이 있다. 1차 조사 이후 예문과 후보 용어에 원단 뒤 신체가 추가됐지만, `layer_contrast_phrase`는 여전히 불투명 아래층 또는 단단한 원단 대비를 요구한다. 투과 판정 설명 역시 불투명 아래층·배경을 중심으로 기술돼 있다. **신체를 불투명 덮개로 바꿔 통과시키는 것이 아니라, 실제 요청된 아래층을 허용하도록 데이터 조건을 정렬**하는 초안을 작성했다. 기존 불투명 아래 의복 변형도 남긴다.

로컬의 실제 `validate_visual_intent_binding`으로 5개 문장을 검사했다. 현재 조건은 5개 모두 리터럴 앵커 부재로 거절했고, 변경 초안은 메모리 안에서 모두 받아들였다. 일반적인 장식 문장 3개는 변경 후에도 거절됐다. 이는 **문자열 증거 조건의 개선 가능성**을 확인한 결과이며, 의미 정확도 100%나 생성 성공률을 뜻하지 않는다. [검증 상세](validation-results.json)

## 실제 반영 시 고려할 기존 경계

현재 스킬은 요청 해석과 코어를 고정한 뒤 로컬 데이터를 검색한다. 강화된 데이터가 이미 잘못 고정된 최초 해석을 자동으로 되돌릴 수 있다고 약속할 수 없다. 이번 변경은 검색 가능한 문맥 설명, 후보의 의미, 출력에 쓰는 구조 문장, 증거 조건을 개선한다. 최초 의미 해석 문제는 별도로 기록해야 한다. 데이터를 코어 앞에 먼저 읽게 하는 로직 변경은 제안하지 않는다.

근사 검색은 후보 안내이며 정확 별칭·명시적 요청·선택 조건과 같은 효력이 아니다. 새 예문을 그대로 exact alias나 hard activation으로 올리지 않는다. 긴 자연어 설명을 추가할 때 긍정적인 구조 문장은 검색 입력에 넣고, 혼동 예·출처·한계·검증 설명은 검색의 긍정 증거로 넣지 않는다. 실제 코드의 필드 허용 목록을 확인해 반영 경로를 구분했다.

## 이어서 확보할 자료의 우선순위

1. **문맥 최소쌍:** 동일 단어의 대상만 바뀌는 한국어·영어 요청, 원어 복합어, 번역했을 때 뜻이 달라지는 요청. 기본 뜻과 특정 시각 프로필의 적용 범위를 서로 다른 정답으로 기록한다.
2. **연결·층·방향이 바뀌는 반례:** 같은 의복/별도 물건, 실제 구멍/인쇄, 원단 투과/투명 신체, 하나의 어깨/갈라진 끈, 얼굴 상대 기하/고정 좌우. 기존 자료의 단순 동의어보다 우선한다.
3. **허용 변형의 직접 자료:** 카울의 직립 니트와 늘어진 드레이프, 앞판 잠금이 다른 코르셋, 여러 메시 조직, 같은 할레이션과 블룸 공존. 변형을 한 all-of 목록에 합치지 않는다.
4. **중립 문장과 원래 형상의 대응 자료:** 같은 대상을 앞·뒤·세부에서 보여 주는 원본 도식 또는 사용 허가된 사진. 저작권·관찰 위치·작성자의 판단과 보이지 않는 내부 구조를 분리해 기록한다.
5. **모델별 실제 오류 자료:** 허용된 장면에 대해 같은 요청·코어·설정을 고정하고 의미 오류, 형태 손실, 차단, 픽셀 미달을 각각 기록한다. 차단 이유를 특정 단어 때문이라고 추정하거나 우회 재시도로 통과율을 높이지 않는다.

새 자료를 모을 때는 용어 수를 목표로 삼기 전에 기존 요청에서 확인된 혼동, 의미 변형, 출력 손실을 기준으로 우선순위를 정한다. 현재 새 개발용 자료는 **14개 최소쌍, 한국어·영어 56개 문장**이다. 독립 평가 세트가 아니며 검색기·LLM에 아직 실행하지 않았다. [개발 최소쌍](semantic-minimal-pairs.jsonl)

## 확인 범위

현재 스킬·테스트·1차 조사 파일 **677개 해시가 모두 유지**됐다. 프로필 변경 초안 15개를 메모리에서 컴파일했고, 캐릭터 그래프 변경 초안은 기존 스키마 검사를 통과했다. 기존 증거 필드 60개와 게이트 60개의 이름·검토 해상도·필수 그룹 수를 유지했다. 이 검증은 데이터의 내부 일관성에 한정된다. 독립 언어 검토, 근사 검색 성능, 전체 프롬프트 통합, 이미지 생성·안전성·픽셀·사용자 수용성은 미검증이다.

이번 추가·재확인 출처 9개는 [출처와 접근 증거](source-evidence.json)에 위치·읽은 범위·확정할 수 없는 내용을 기록했다. 저자와 FLIGHT PDF의 미독 상태를 본문/페이지 읽기로 보강했으며, 의복 도식 2개도 직접 관찰했다. 그림과 PDF 원문 전체는 연구 산출물에 복제하지 않았다. [관찰 기록](reference-observations.json)
