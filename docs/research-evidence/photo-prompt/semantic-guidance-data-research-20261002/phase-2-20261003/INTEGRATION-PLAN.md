# 시각 의미 데이터 반영 계획

목표는 문맥상 올바른 의미와 용어 이름을 생략해도 남는 형상 관계를 강화하는 것이다. **기존 15개 시각 프로필과 1개 캐릭터 의미 레코드의 데이터 변경**을 우선한다. 스킬 로직·검색 순서·코어 고정 규칙·런타임 스키마·전역 라벨 정책을 변경하지 않는다. 모든 변경은 현재 작업 파일 해시에 맞춘 검토 초안이며 아직 반영하지 않았다.

권장 순서는 **A 의미 범위·예문 → B 중립 구조와 증거 조건 정렬 → C 캐릭터 의미 범위 정렬 → D 독립 검증과 파생 인덱스 확인**이다. 특히 B는 예문만 먼저 반영하면 출력 문장이 증거 검사에서 거절될 수 있으므로 각 프로필의 의미·컴포넌트·증거·판정을 한 묶음으로 반영한다.

## 반영 전 기준

- 실제 로더 기준 1,496개 프로필, 기준 HEAD `0ed2267b91e73f4b4d1493d095287e7795ebf805`.
- 1차 조사 당시 1,419개와 다르며, 대상 15개 중 `sheer_garment_optical_layering`의 예문·후보 용어가 변경됐다.
- 다른 작업의 수정·미추적 자산과 테스트가 있다. 현재 파일을 통째로 옛 버전으로 덮거나 `git reset`으로 복구하지 않는다.
- 구현 시에는 그 시점의 파일 해시와 레코드 해시를 다시 확인하고, 작업 중 변경을 보존하는 격리된 체크아웃에서 검토된 필드만 수정한다. 다른 작업의 미추적 자산을 누락하지 않는다.
- [프로필 초안](profile-change-plan.json)은 각 연산의 `before` 값과 기준 파일·레코드 해시를 담는다. 실제 파일을 수정하는 적용 스크립트는 제공하지 않았다.

일부 일반 개념을 현재의 좁은 프로필이 다루지 않는다는 사실은 이 단계에서 명확히 기록한다. 다른 변형을 표현할 필요가 있으면 새 의미/연출 레코드가 필요한지 판단하며 기존 필수 조건을 느슨하게 풀어 합치지 않는다.

## B. 중립 구조와 증거 조건: 4개 프로필

### B1. `clothing_ct037_v1`, `clothing_ct090_v2`, `clothing_ct023_v2`

현재 컴포넌트 증거 문장에 원래 용어가 포함돼 있다. 라벨 없는 자연어 문장을 생성해도 정확한 증거 앵커가 없으면 거절된다. 다음을 같은 원문 컴포넌트에서 함께 수정한다.

1. `semantics.definition`을 같은 구조의 자연어 문장으로 기술한다.
2. `semantics.paraphrase_examples`에 한국어·영어 구조 문장을 추가한다.
3. `semantics.visual_components`와 `authored_components.components[].match_terms`에 같은 관계를 추가한다.
4. `authored_components.components[].evidence_terms`에 완전한 중립 영어 문장을 대안으로 추가한다. 기존 이름 있는 문장도 호환 대안으로 남긴다.
5. 해당 컴포넌트의 `instruction`, `render_gate.description`을 소유자·경계·연결 기준으로 맞춘다.

앵커는 `folds`나 `mesh` 같은 짧은 일반어로 줄이지 않는다. 대안 문자열은 같은 전체 관계를 표현해야 한다. **동일 컴포넌트 안의 문장 대안(any-of)을 늘리는 것이지, 서로 다른 필수 컴포넌트(all-of)를 선택 사항으로 바꾸는 것이 아니다.** 컴포넌트 수, 필수 필드, 최소 단어 수, 게이트 ID와 검토 해상도는 유지한다.

`authored_components`가 원문 소유자이므로 컴파일 결과인 `component_semantics`, `evidence_requirements`, `composition_instruction`, `render_gates`를 별도로 모순되게 수작업 수정하지 않는다. 현재 컴파일러의 투영을 사용한다. 기존 정확 별칭·하드 활성 조건·출력 모드는 유지한다. 중립 요청만 들어온 경우 근사 후보 발견과 명시적인 선택을 기존 규칙대로 구분한다.

완료 기준은 이름 없는 문장이 기존과 같은 의복의 연결 관계를 보존하고 로컬 증거 검사에서 받아들여지며, 일반 장식·별도 물건·인쇄 대체가 통과하지 않는 것이다. 최종 이미지에서는 연결과 실제 입체/열린 구조가 요구된 해상도에서 확인돼야 한다.

### B2. `sheer_garment_optical_layering`

현재 예문에는 섬유층 뒤 신체가 있지만 `layer_contrast_phrase`에는 불투명 아래층 중심의 앵커만 있다. 다음 필드를 한 번에 정렬한다.

- `semantics.definition`: 원단과 **요청한 실제 아래 표면**의 투과 관계로 기술한다.
- `composition_instruction`: 신체·아래 의복·배경 중 요청된 소유자와 피복 범위를 유지한다.
- `evidence_requirements.translucent_textile_phrase.must_mention_any`: 원단 이름 없이도 섬유층 투과를 기술하는 문장 대안을 추가한다.
- `evidence_requirements.layer_contrast_phrase.must_mention_any`: 아래 신체, 아래 의복, 배경을 각각 명시한 대안을 추가한다. 불투명 아래 의복의 기존 대안은 남긴다.
- `vo_sheer_transmission_relationship`의 설명: 투과하는 섬유층과 아래 대상의 구분을 평가한다. 원하지 않은 불투명 덮개로 대체하지 않는다.
- `activation.context_disambiguation.any_terms`: 섬유층과 아래 신체의 관계를 모두 담은 좁은 문장 2개만 추가한다. `body` 등 포괄어를 단독 활성 조건으로 넣지 않는다.

신체 자체가 투명해지거나 의복이 사라지는 오류는 계속 대체 실패다. 기존 성인·콘텐츠 제약, 요청한 피복 범위와 실제 아래층은 유지한다. 이 데이터가 모든 장면을 허용하거나 특정 모델 차단을 해제하는 기능을 제공한다고 주장하지 않는다.

## C. 쿨데레 의미 범위: 1개 프로필과 1개 그래프 레코드

두 데이터가 서로 다른 정의를 내리지 않도록 같은 변경 묶음에서 처리한다.

| 원문 | 변경 | 유지 |
|---|---|---|
| `kuudere_composed_warmth_relation` | 일반 의미와 현재 선택한 성인 도움 장면을 `semantics.definition`과 `claim_limits`에서 구분 | 기존 8개 증거 필드·게이트·성인 조건·같은 상대의 행동과 결과 |
| `photo_prompt_character_moe_extension.json`의 `concept_profiles[id=kuudere]` | `definition`, `en`, `ko`, `ja`에 일반 의미와 선택한 관찰 방식의 범위를 같은 방식으로 명시 | 별칭, 의미 축, 배제 축, 관계, 증거 역할, 선택 노드, 적용 조건 |

그래프 스키마에는 `claim_limits` 같은 새 필드를 임의로 추가할 수 없음을 확인했다. 새 원어 출처와 해석 한계는 연구 근거 파일에 저장하고 기존 허용 필드로 표현한다. 범위 설명이 검색 입력에 들어가는 영향을 확인한다.

이 변경은 모든 쿨데레 장면을 현재의 실용적 도움 계약으로 수용하는 변경이 아니다. 도움 행동 없이 관계적 온기를 드러내는 장면도 일반 용례에 맞을 수 있다. 그런 장면을 런타임에서 지원하려면 원어 사례와 성인 장면을 더 모아 **다른 관찰 방식의 데이터 레코드**를 별도로 설계해야 한다. 기존 게이트를 단순 삭제하는 방식은 권장하지 않는다.

- 반례·한계·출처·증거 검사 지침은 시각 프로필 벡터의 긍정 입력이 아니다. 다만 전체 레지스트리 해시에 포함돼 원문이 바뀌면 인덱스 연결 해시도 다시 만들어야 한다.
- 정의·예문·컴포넌트 문장이 바뀐 프로필은 입력 텍스트가 바뀌므로 해당 벡터를 다시 만든다. 텍스트와 공급자·모델·차원이 완전히 같은 벡터만 재사용한다.
- 그래프의 의미 정의·언어 라벨 변경은 사전 의미 인덱스의 입력에 영향을 준다. 두 인덱스를 혼동하지 않는다.

## D. 검증과 채택 기준

### D1. 데이터·증거 계약

이번에 이미 확인한 것은 변경 초안 15개의 메모리 컴파일, 그래프 스키마, 이름 없는 문장 5개의 기존 거절/초안 수용, 일반 문장 3개의 거절, 원문 677개 보존이다. 실제 반영 후에는 사전 전체 검증, 레지스트리·인덱스 해시 일치, 컴포넌트 투영과 기존 테스트를 확인한다.

현재 저장소에 있는 관련 테스트를 변경 면에 맞춰 실행한다. 일부 테스트의 기대 문자열을 변경해야 한다면 필수 구조와 실패 반례를 유지한 변경인지 함께 검토한다.

```sh
.venv/bin/python -m pytest -q \
  tests/test_photo_visual_obligations.py \
  tests/test_photo_visual_profile_retrieval.py \
  tests/test_photo_clothing_terminology_semantics.py \
  tests/test_photo_portrait_fashion_exposure.py
```

캐릭터 그래프·프롬프트 통합 변경은 실제 관련 테스트 위치를 확인해 더한다. 다른 작업의 현재 실패를 이번 변경의 실패나 성공으로 합산하지 않는다. 신규 의미·관계의 누락/대체를 검출하는 필요한 회귀 검사만 추가하며 문장 그대로를 복제한 형식 테스트로 품질을 주장하지 않는다.

특히 다음 경계를 확인한다.

1. 중립 앵커가 실제 같은 관계를 담는지, 일반 단어만으로 통과하도록 약해지지 않았는지.
2. 필수 그룹 하나를 빼거나 소유자를 바꾸면 실패하는지.
3. 정확 요청·긍정 예문·가까운 문맥 반례에서 자동 활성과 근사 후보가 구분되는지.
4. 실제 선택된 evidence phrase가 출력 문장에 리터럴로 결합되고 감사되는지.
5. 검토된 긍정 프롬프트가 바뀌면 기존 검토 결과를 재사용하지 않는지.
6. 기존 frozen holdout은 보존하고 이번 개발 최소쌍을 그 세트에 정답 누출시키지 않는지.

### D2. 문맥 의미의 독립 평가 계획

다음 수는 **실행할 평가 설계**이며 현재 조사에서 관측한 데이터량이나 정확도가 아니다.

- 12개 개념군 × 4개 요청 유형 = **48개 새 문맥 사례**를 만들고 한국어·영어 번역쌍으로 작성한다. 총 96개 언어 요청이다.
- 각 군은 기본 긍정, 용어 없는 구조 긍정, 가까운 관계 반례, 다른 문맥/허용 변형의 4종을 포함한다.
- 일반 어휘 뜻, 현재 선택 프로필의 적용 여부, 필수 형상, 허용 변형을 각각 주석으로 작성한다. 특히 쿨데레의 일반 용례와 실용적 도움 프로필 여부는 서로 다른 정답이다.
- 이번 초안과 1차 조사 예문을 복사하지 않고 별도 작성자가 만들거나, 작성자를 분리한 사람 검토를 거친다. 일본어 용례는 쿨데레·闇堕ち 관련 사례에 원어 검토를 추가한다.
- 조건과 버전을 고정해 현재 데이터와 강화 데이터를 비교한다. 의미 선택 정답률, 후보 recall, 인접 문맥의 오활성, 구조 누락을 따로 보고한다.

표본에서 의미 혼동이나 인접 문맥 오활성이 하나라도 발견되면 원인 사례를 해결하거나 해당 변경을 보류한다. 정답률 하나로 의미 범위 축소나 형상 누락을 감추지 않는다. 48개는 출발점이며 대규모 성능 개선이나 LLM의 전반적 지식을 추정할 통계 근거로 쓰지 않는다.

현재 로직은 코어를 먼저 고정하므로 강화 데이터가 최초 해석 오류를 복구한다고 평가하면 안 된다. 운영 흐름에서는 고정된 코어 아래의 후보·선택·출력 정확도를 측정하고, 별도 데이터 기반 의미 판별 실험은 운영 흐름의 성능과 구분한다.

### D3. 형상 보존의 생성 평가 계획

이미지 생성은 별도로 요청된 실행 단계에서 진행한다. 현재 계획 작성에는 생성 호출이 없다. 허용되는 장면의 중립적 기술과 형상 대응을 확인한다.

- 12개 개념군에서 요청과 코어가 고정된 장면 1개씩 선택한다.
- 원래 명칭을 포함한 설명, 현 데이터의 설명, 강화 데이터의 중립 구조 설명의 **3개 조건 × 12개 장면 = 36회 단발 생성**을 초기 탐색 설계로 둔다.
- 같은 모델·버전·설정·요청 조건을 고정하고 참조 이미지가 있다면 같은 참조를 쓴다. 모델이 seed를 보장하지 않으면 쌍 비교의 한계로 기록한다.
- 각 조건의 문자열·해시·시도·산출물·차단 결과를 보관한다. 차단 시 성공 문구를 찾기 위한 우회 재시도를 하지 않는다.
- 독립 검토자가 용어 이름보다 소유자·부착점·연속 경계·실제 셀·층·초점·밝기 관계를 평가한다. 네이티브와 썸네일 기준은 기존 게이트를 따른다.
- `PASS`, `FAIL`, `PARTIAL`, `BLOCKED`를 분리한다. 부분 충족은 성공이 아니다. 차단은 형상 품질을 관찰하지 못한 상태다.
- 실제 아래 신체를 불투명 의복으로 바꾸거나, 같은 천을 별도 스카프로 바꾸면 의도 보존 실패다. 사용자 수용성은 기술적 게이트와 별도로 기록한다.

36회 결과는 초기 탐색이며 유의미한 개선율을 보장하는 표본 수가 아니다. 관측 결과를 본 뒤 효과 크기와 분산에 따라 다음 표본을 정한다. 재시도 성공률이나 통과한 조건만 골라 성공률을 높이지 않는다.

## 채택·보류·복구 단위

채택 단위는 개념/관계 데이터와 그에 맞는 파생 인덱스다. 모든 항목을 한 번에 넣지 않고 A, B, C 묶음별로 검토 결과를 기록한다. 원문 근거 부족, 의미 범위 변화, 가까운 반례 오활성, 필수 관계 누락이 남으면 해당 레코드만 보류한다.

복구 시에는 이번 변경 필드와 그 변경에 맞는 인덱스 상태를 함께 되돌린다. 현재 다른 작업의 전체 파일이나 샤드를 옛 조사 버전으로 교체하지 않는다. 같은 텍스트가 아닌 벡터를 가져오거나 원문 해시가 다른 인덱스를 유효하다고 취급하지 않는다.

최종 반영 보고에는 변경한 레코드·필드, 사용한 원어 근거, 검증 결과, 미실행 단계, 데이터/인덱스 해시와 의미·픽셀의 한계를 남긴다. 이번 계획의 완료는 조사와 검토 초안 완성이며 프로덕션 반영 또는 모델 개선 완료를 뜻하지 않는다.
