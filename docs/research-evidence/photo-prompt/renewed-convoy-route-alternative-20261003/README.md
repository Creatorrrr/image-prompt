# 표국 출발 장면의 운송 수단별 경로 증거 정렬 — DATA 27

표국이 봉인된 화물을 호위하며 마당에서 문을 지나 길로 출발하는 원문은 수레 또는 짐을 실은 동물 등의 일관된 운송 단위를 허용합니다. 그러나 경로 구성요소·증거 배열에는 바퀴·발굽·손잡이가 함께 존재하는 문장만 있었습니다. 원래 조사 문서에도 이 모순이 있어 단순한 옮겨 적기 오류라고 할 수 없습니다. 정의의 운송 대안, 원자료의 특정 차량으로 한정하지 않는 설명, 이미 중립적인 경로 게이트를 근거로 내부 불일치를 조정했습니다.

두 배열 끝에 같은 영어 문장, 'transport contact points and body orientations continue from yard through gate onto one readable road'를 추가했습니다. 기존 영어·한국어 문장, 최소 단어 수, 표국 출발지·화물 소유·호위 분포·연속 경로·단순 상인 행렬과의 구별이라는 다섯 의무와 게이트를 보존했습니다. 별도의 수레 전용 후보는 바꾸지 않았습니다. 한국어 증거 결합 개선으로 확대 해석하지 않습니다.

## 동결 사례와 실패 이력

독립 검토가 정확한 두 배열 추가를 승인했습니다. 실제 V6 요청 6개를 동결했고 요청·core·후보 선택을 바꾸지 않았습니다. 처음 구성은 원래 앵커의 최소 내용 단어 수와 필수 runtime label을 충족하지 못했습니다. 그 실패를 남기고 같은 의미의 구체적 설명과 기존 label만 추가한 별도 구성 14개를 다시 동결했습니다.

수정된 BEFORE에서 완전한 짐노새·손수레·한국어 정확 요청(영어 증거) 세 사례는 경로 앵커 하나에서만 실패합니다. 기존 노새 수레 장면은 통과하고, 일반 상인은 대상 계약 없이 통과합니다. 구성요소-only 입력은 대상이 없으므로 그 통과를 대상 계약 통과로 세지 않습니다. 다섯 의무 누락과 세 잘못된 경로 대조는 모두 거부됩니다.

원문을 본 뒤 작성한 인공 정규 계약 검증입니다. 실제 사용자의 자연 질의, 독립 초기 장면 다양성, 전체 검색 정확도, 픽셀 품질을 측정한 실험이 아닙니다. 별도 유령선 게이트 변경과의 동시성은 기록하고 저장된 BEFORE 팩과 변하지 않은 표국 프로필로 비교했습니다.

## 인덱스·비용

실제 Gemini embedding-2 벡터 1개 갱신, 다른 1,509개 프로필 텍스트·벡터와 3,667개 정확 조회 행은 동일합니다. 일반 9,739개 인덱스 문서는 바뀌지 않았습니다. 해당 BM25F 문서와 전역 통계는 갱신되므로 점수 불변을 주장하지 않습니다.

추가 요청 예약 $0.0016384, 누적 요청 추정 $1.4385152 + 별도 과거 전송 재시도 준비금 $5.7081856 = 계획 $7.1467008, $10 내 여유 $2.8532992입니다. 실제 청구액이나 독립적인 다른 작업의 계정 사용료가 아닙니다. 신규 SDK 호출의 전체 전송 시도 제한은 1입니다.

## AFTER와 보존된 경계

같은 6개 공개 CLI 입력을 다시 실행했습니다. 주된 정확 요청 3개는 누락 경로 앵커 실패에서 통과로 바뀌며 기존 수레·일반 상인 대조는 유지됩니다. 8개 의무/경로 음성 대조는 계속 거부됩니다. 원래 core·몸체 검토·슬롯 검색·슬롯 ID와 표시 순서 및 공통 후보 내용은 같습니다. 유령선 동시 변경으로 인한 팩 차이는 없습니다.

구성요소 입력은 AFTER에서 표국 후보가 실제 적합 후보로 노출됩니다. 그 고정 구성은 BEFORE에 대상이 없었기 때문에 원래 증거/label의 불완전함이 AFTER에서 드러납니다. 이 실패를 수정해서 전후 통과로 세지 않았습니다. 별도로 동결한 AFTER-only의 완전한 opt-in 구성은 통과했고, 이 결과는 짝 비교 향상으로 집계하지 않았습니다.

이 새 후보가 제한된 선택 목록의 두 번째 자리에 들어오면서 이전에 적합하다고 표시되던 `rb_support_compression` 및 그 설명이 빠집니다. 이 후보의 필수 관계는 부드러운 쿠션 위의 앉은 몸·국소 눌림·앉은 접촉부 옷 주름인데, 고정 입력은 네 성인 모두 두 발로 길 위에 서 있고 쿠션/좌석이 없습니다. 따라서 이 사례에서 그 후보를 선택하면 원래 요청에 없는 앉은 관계를 도입합니다. 이 교체를 숨기거나 일반적 정확도 향상으로 확대하지 않습니다.

새 테스트 초안 하나는 부분 binding 입력을 허용하는 기존 `normalize_visual_intent`에 모든 필드 누락 거부를 잘못 기대했습니다. 초기 실패 로그/초안은 보존했고, 그 새 테스트만 실제 구성요소 matcher가 각 필수 관계 누락을 거부하는지 검사하도록 정정했습니다. 런타임·원문·기존 테스트는 바꾸지 않았으며 전체 구성 감사의 8개 음성 대조도 유지합니다.
