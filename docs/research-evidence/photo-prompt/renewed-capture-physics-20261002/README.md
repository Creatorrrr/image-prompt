# 센서 움직임과 스플릿 디옵터의 강제 조건 교정

기준 커밋: `904b5893c94e2d59d646e977c8400e270635a568`.

## 실제 문제

롤링셔터 프로필은 고정 카메라 앞의 움직이는 물체에도 배경 수직선이 기울도록 요구하고, 카메라가 움직이는 정지 장면에도 별도로 움직이는 피사체를 요구했다. 각 형태의 카메라에 대한 상대 움직임을 기준으로 설명·증거·렌더 게이트를 정리했다. 별도 배경 물체를 추가할 필요도 없다. [Basler의 전자 셔터 설명](https://docs.baslerweb.com/electronic-shutter-types#rolling-shutter)은 시간차를 둔 행 노출과 빠른 물체 또는 카메라 움직임의 관계를 설명한다. 고정 카메라에서 정지 배경이 안정적으로 남는다는 판단은 이 모델의 기하학적 해석이다.

스플릿 디옵터는 기존 정의에서 허용하던 부드러운 광학 전이와 중간 심도 띠의 대안을 관련 필드에도 일관되게 적용했다. 중간 깊이 물체를 새로 넣도록 강제하지 않는다. 가까운/먼 두 초점 영역과 장면의 연속성은 유지한다.

## 호환성과 검증

최초 제안의 기존 영어·한국어 성분 및 증거 표현 손실을 독립 리뷰에서 발견했다. 기존의 유효한 복합 움직임과 중간 띠 표현을 대안으로 보존한 수정안을 적용했다. 별칭·제외어·필수 그룹·증거 길이·게이트 ID와 척도를 바꾸지 않았다.

정상 공개 CLI로 원본 입력 24개를 고정한 6개 사례를 전후 실행했다. 고정 카메라, 카메라 스윕, 복합 움직임 각 사례는 정확히 12개 경로, 스플릿 광학 전이와 중간 띠 사례는 각각 6개 경로만 달라졌다. 변화는 팩 ID와 해당 프로필 설명·증거 계약에 한정됐다. 일반 모션 대조는 완전히 동일했고 모든 사례의 후보 ID·순서·개수는 유지됐다.

실제 팩과 전체 v6 구성 계약을 사용한 완성 프롬프트 감사 7개도 통과했다. 별도 배경 없는 단일 물체, 서로 다른 상대 속도, 기존 복합 움직임과 중간 띠 표현을 포함한다. 증거 필드나 필요한 문장을 제거하면 실패한다.

다만 물리적으로 모순된 문장을 추가해도 어휘 기반 감사가 통과하는 한계가 재현됐다. 이 작업은 조건을 올바르게 표현하도록 데이터를 교정한 것이며, 물리를 자동 판정하는 기능을 만든 것이 아니다. 이미지 생성·픽셀 품질을 평가하지 않았다.

## 의역 보완과 최신 main 통합

독립 리뷰에서 새 의역 2개가 중요한 조건을 생략한 채 선택 후보가 되는 것을 발견했다. 실제 행 노출 시차, 상대 움직임, 선명한 국소 세부와 대체 효과와의 구별을 포함하도록 완성했다. 불완전한 두 문장의 선택 활성화는 없어지고 완성한 문장은 선택 후보로 유지된다. 정확 별칭의 필수 활성화와 다섯 게이트는 그대로다. 최종 6개 팩은 이 보완 전과 동일했다.

검증 중 upstream `840d4b8f0dbcb977b3d02b5dbcce38894bcd0ec4`가 추가되어 병합했다. 새로운 신체 형태 데이터와 visual_priorities 기반 선택 발견 로직을 모두 유지했다. 스플릿 디옵터의 upstream 의역·대조·한계 설명과 이번 교정은 같은 프로필의 서로 다른 경로를 수정했으며, 정확한 3방향 구조 병합으로 양쪽을 보존했다. 대상 외 프로필과 모든 다른 upstream 파일도 보존했다.

확대된 1,496개 프로필의 진짜 인덱스로 새 upstream 단독 대조를 만들고 같은 입력을 재실행했다. 7개 사례 모두 후보 ID·순서·개수 차이가 없으며 대상 계약·설명 경로만 달라졌다. 예전 코퍼스와 비교하면 주변 조명·플랫폼·시각 후보 및 묶음이 달라지는 사례가 있으나, 이 차이는 새 upstream 단독에서도 재현되어 이번 광학 데이터 효과와 분리했다. 같은 프롬프트 본문과 시각 증거로 7개 전체 구성 감사가 다시 통과했다. 변경된 선택 후보에 대한 거절 결정과 팩·검색 해시만 새 팩에 맞춰 갱신했다.

최종 인덱스에서 upstream의 1,494개 항목은 그대로 보존했다. 롤링셔터 벡터는 이번 작업의 유효한 캐시를 재사용하고, upstream 설명이 결합된 스플릿 텍스트만 추가 임베딩했다. 이 단계는 수정 과정과 병합을 포함해 성공 호출 4회, 최종 변경 프로필은 2개다. 비용 보수 상한 $0.0065536, 프로젝트 누적 $1.4041088 / 허용 $10이며 실제 청구 금액이 아니다.

기존 코퍼스 회귀 55개와 최종 인덱스·사전 검증이 통과했다. 확대 코퍼스의 11개 모듈에서 회귀 테스트 94개가 통과했다. 이 기록은 기존에 누락된 과거 PNG 문제를 해결했다거나 전체 저장소·픽셀 테스트를 통과했다는 뜻이 아니다.
