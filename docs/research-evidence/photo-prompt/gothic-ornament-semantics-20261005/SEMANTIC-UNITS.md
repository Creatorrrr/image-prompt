# 용어별 시각 의미와 혼동 경계

**RESEARCH_DRAFT_NOT_RUNTIME_SCHEMA**. 124개는 도구로 복원한 참조 대화의 용어다. GX01–GX20은 이번 연구의 보조 관계이며 원문 용어로 세지 않는다. 가시 구성은 출처를 바탕으로 연구자가 만든 선택형이다. 조합/양식의 목록 전체는 필수 조건이 아니다. 제작 과정·역사·정체성과 픽셀로 확인할 외형을 구분한다.
