# 궁전·성곽 프로필의 한국어 관계 조건 정렬

## 결론과 한계

세 기존 프로필의 한국어 정확 일치 문구가 선택된 영어 변형보다 넓어, 요청하지 않은 재료·계단 형태·잔해를 필수 조건으로 가져오는 문제를 수정했다. `pf_window_seat`, `pf_double_helix`, `pf_roofless_ruin`의 `activation.exact_terms[1]`만 바꿨다. 프로필·개념 추가, 일반 후보 수정, 검색 런타임 변경은 없다.

**명시적 손실:** 의미가 충분한 기존 한국어 표현 세 사례도 수정 후 자동 프로필 활성화와 총 아홉 렌더 검증 게이트를 잃는다. 일반 본문 근거 검사는 이 자동 이미지 검증 범위를 대체하지 않는다. 의미 기반 재현율 향상을 입증한 수정이 아니라, 조건이 불완전한 정확 일치 별칭에서 잘못된 필수 조건을 가져오지 않도록 한 보수적 수정이다.

**적용 범위:** 조사자가 원문을 보고 만든 제한된 유지보수 사례와 주제가 지정된 합성 대조군이다. 실제 사용자의 자연 검색 분포, 생성 이미지 품질, 모든 부정·소유 관계 추론에 대한 성능 수치가 아니다. 별도로 진행 중인 카메라 런타임 PR5는 이 변경에 포함하지 않는다.

## 변경 근거

- 창가 좌석: 기존 한국어 표현은 같은 깊은 창 오목부가 원목인 장면도 허용하지만, 영어 선택 변형은 같은 오목부의 조적 벽을 요구했다. 붙박이 좌석, 같은 좌석 공간과 창 측벽의 연결, 좌석 면 바깥쪽 개구부를 명시했다
- 이중 나선계단: 기존 표현은 하나의 빈 중심부 양옆의 두 직선 계단도 허용했다. 같은 빈 중심부 둘레를 감는 두 나선형 계단과 각각 분리된 연속 동선·추적 가능성을 명시했다
- 지붕 없는 폐허: 기존 표현은 바닥의 잔해를 치운 장면도 허용했다. 같은 옛 방의 열린 하늘·바닥을 둘러싼 벽과 창, 파손된 상부 구조 아래의 국소적 조적 잔해를 명시하고 구조적 파손과 이끼의 구별도 유지했다

여섯 프로필을 한정 조사했으며 `pf_motte_bailey`는 KEEP, `pf_gate_sequence`와 `pf_garden_grotto`는 증거 부족으로 DEFER했다. 포트컬리스의 앞선 수정은 재계상하지 않았다. 원래 영어 의미·구성 요소·렌더 게이트, 일반 후보와 역사적 조사 자료는 그대로다.

## 검증 결과

기준 커밋은 `ca0f6d80c85e2538883da9a5a0e01818dfe7df0c`다. 요청·초기 본문·코어·제약을 먼저 고정하고 같은 런타임으로 전후를 비교했다.

| 주 검증군 | 사례 수 | 전 / 후 구성 감사 통과 |
|---|---:|---:|
| 기존 한국어 별칭과 양립하는 반례 | 3 | 0 / 3 |
| 완전한 영어 선택 변형 | 3 | 3 / 3 |
| 영어 동등 반례 | 3 | 3 / 3 |
| 수정된 한국어 정식 표현 | 3 | 3 / 3 |
| 모든 의미가 명시된 기존 한국어 표현 | 3 | 3 / 3, 자동 게이트 9개 손실 |
| 원문을 보지 않은 작성자의 주제 지정 대조군 | 3 | 3 / 3 |
| 합계 | 18 | 15 / 18 |

- 격리 검증의 36개 public builder/감사 실행을 실제 설치 상태에서도 재실행했다. 모든 후보팩·구성·감사 객체가 대응하는 검증 객체와 정확히 같았다. CLI 실행과 함수 수준 public 실행은 증거에서 구별한다
- 18쌍 모두 일반 슬롯·번들, 코어·제약·일반 의무, 긍정·부정 본문이 그대로다. 후보를 채택한 결과는 아니다
- 선택 후보 변화는 6사례에 한정된다. 해당 개념의 선택/필수 지위 변화 외에 정식 나선계단 사례에는 `rb_restrained_processing`, 정식 폐허 사례에는 `pf_keep_ward`가 선택 제안으로 들어왔다. 둘 다 채택하지 않았다
- 실제 본문을 바꾸는 10개 반사실 대조는 현재 본문 근거 검사에서 거절됐다. 메타데이터만 어긋난 실패와 구분했다. 근거 문장을 남겨 둔 모순 덧붙이기나 일반적인 의미 모순 판별을 입증하지 않는다
- 문구 일부 생략, 재료·경로·잔해의 소유 관계, 일반 명칭 검사는 전체 인덱스를 사용하는 helper 검증이다. 추가 public 입력 실행이나 이미지 검증으로 세지 않았다
- 독립 검토자가 36개 감사 결과, 대표 6개 after 후보팩, 전체 인덱스를 재현하고 손실 조건을 포함해 승인했다
- 설치 후 13개 테스트 모듈의 133개 메서드와 사전 검증이 통과했다. 추가된 6개 메서드는 수정 전 9개 assertion/subtest 실패를 보였다. 전체 프로젝트 회귀가 모두 통과했다고 주장하지 않는다

## 인덱스·비용·기존 경계

전체 1,622개 시각 의미 엔트리의 임베딩 텍스트와 벡터는 동일하다. 실제 production builder가 기존 캐시만 재사용해 변경된 정확 검색·BM25F·레지스트리 해시를 재생성했고 오래된 인덱스는 거절됐다. 일반 의미 인덱스와 9,876개 일반 엔트리는 변경하지 않았다. 임베딩 요청과 신규 벡터, 이미지 생성은 각각 0건이다.

고정 찻잔 경계 입력의 출력 SHA-256은 `6c097471705589a4db45daf5aa164017f2c7b512dcaab880e9e58bb3882f5589`로 직전 포트컬리스 수정 때와 동일하다. 이전 목덜미·직물 메타데이터 수정으로 생긴 불변 v9 바이트 기준 실패는 여전히 별도 알려진 상태이며 이 수정에서 기준을 바꾸거나 무시하지 않았다.

## 보존한 시행착오

초기 제안 V1과 V2를 분리 보존했다. 초기 V1 canonical 입력과 네 과거 실행은 주 18사례 분모에서 제외했다. 독립 검토로 모든 영어 관계를 명시한 V2를 고정한 뒤 평가했다. 새 주 검증 결과를 본 뒤 대조군 의미를 고치지 않았다.

초기 633줄 테스트 초안은 프로필 전체와 알려진 재현율 손실을 영구 고정할 위험이 있어 보존만 했다. 설치된 190줄 테스트는 관련 별칭·구성 요소·경계만 확인하며 향후 정당한 동의 표현 추가나 기존 표현의 재현율 개선을 막지 않는다.

설치 검증 도구의 첫 문법 오류, 외부 테스트 실행 경로 오류, wrapper의 0개 테스트 실행은 원문 로그와 함께 남겼다. 수정된 도구로 실제 검증을 완료했으며 이 세 실행은 제품 회귀나 통과 테스트로 세지 않았다.

## 재현 자료

함께 제공한 `evidence.tar.gz`에는 원문 표본, 고정 입력·해시, V1/V2 제안, 인덱스 영수증, 전후 후보팩·감사, helper 검증 범위, 독립 검토, 실제 설치 영수증과 테스트 로그를 포함한다. 데이터 중 일부 절대 경로는 당시 재현 환경 위치이며 외부 서비스나 사용자 비밀 정보가 아니다. `evidence-manifest.json`에서 파일별 해시를 확인할 수 있다.
