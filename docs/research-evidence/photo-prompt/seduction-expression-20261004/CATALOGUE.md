- 유형: `contextual_interpretation`. 아래 형태는 선택 예시이며 공동 필수가 아니다.
- 형태: 해석어: 끌어당기거나 유혹하는 인상 / 선택 예시: 대상이 분명한 시선 또는 억제된 입꼬리 변화 / 전체 요청의 장소·행동·관계를 먼저 확정.
- 소유·관계: 주체의 눈→이미 요청된 대상 / 상대가 없으면 카메라 또는 화면 밖 대상으로 바인딩.
- 혼동 경계: 반드시 반쯤 감은 눈·벌린 입·노출을 뜻하지 않음 / 인물의 욕망이나 상대의 동의를 판정하지 않음.

- 기존 후보: `expression.ae_sultry_variant`, `expression.ae_smolder_attraction`.
- 기존 프로필: `playful_flirtation_interaction`.
- 반영안: 기존 성인·끌림 문맥 후보의 다양한 대안을 보강하고 단독 라벨의 하드 활성화는 금지.
- 근거: [D01: Merriam-Webster: seductive](https://www.merriam-webster.com/dictionary/seductive), [R03: Barrett et al. (2019), Emotional Expressions Reconsidered](https://pmc.ncbi.nlm.nih.gov/articles/PMC6640856/).

### 012. 주도적·압도적인 — Commanding

### 013. 팜파탈 — Femme fatale

## 15–30. 눈·시선

### 015. 직접 응시 — Direct gaze

- 유형: `observable_configuration`. 요청한 형태만 의무로 평가한다.
- 형태: 양눈의 시선 축이 카메라 렌즈 방향으로 수렴 / 얼굴 방향은 정면/비스듬함 중 요청대로 유지.
- 소유·관계: 주체 양눈→camera lens / 고개 방향과 눈 방향은 독립.
- 혼동 경계: 정면 얼굴과 직접 시선은 다름 / 영상 통화 화면을 봄과 렌즈를 봄은 다름.
- 관찰 조건: 두 눈이 보이고 렌즈 방향 시선이 읽혀야 함;반사 속 응시는 별도 좌표로 검사.
- 기존 후보: `gaze_engagement.pv_gaze_direct`.
- 기존 프로필: 라벨만으로 신규 하드 프로필을 만들지 않음.
- 반영안: 시선 목표와 머리 방향의 독립성을 보강.
- 근거: [P02: Canon: Posing Tips for Successful Portraits](https://www.usa.canon.com/learning/training-articles/training-articles-list/posing-tips-for-successful-portraits), [R03: Barrett et al. (2019), Emotional Expressions Reconsidered](https://pmc.ncbi.nlm.nih.gov/articles/PMC6640856/).

### 016. 곁눈질 — Sidelong glance

- 유형: `observable_configuration`. 요청한 형태만 의무로 평가한다.
- 형태: 눈이 머리의 정면 축에 대해 한쪽으로 이동 / 머리 방향은 고정 또는 별도 기재 / 흰자 노출은 보이는 만큼만 기술.
- 소유·관계: actor eyes→lateral target / actor-left/right와 image-left/right 분리.
- 혼동 경계: side-eye의 판단/불신 감정은 필수 아님 / 머리 전체를 돌린 것과 눈만 옆으로 둔 것 구분.
- 관찰 조건: 얼굴과 양눈 방향이 읽히는 크롭;가려진 눈은 추정하지 않음.

- 기존 프로필: 라벨만으로 신규 하드 프로필을 만들지 않음.
- 반영안: 기존 후보에 머리/눈 기준축과 반사 좌표 경계 보강.
- 근거: [R02: Paul Ekman Group: Facial Action Coding System](https://www.paulekman.com/facial-action-coding-system/), [R03: Barrett et al. (2019), Emotional Expressions Reconsidered](https://pmc.ncbi.nlm.nih.gov/articles/PMC6640856/).

### 017. 내려다보는 시선 — Downcast gaze

- 유형: `observable_configuration`. 요청한 형태만 의무로 평가한다.
- 형태: 시선이 카메라 수평선보다 아래 대상에 향함 / 턱은 내려가거나 그대로일 수 있음 / 윗눈꺼풀/홍채 가시성은 현재 상태만 기록.
- 소유·관계: 주체 눈→아래쪽 기존 목표 / 목/턱 자세와 독립.
- 혼동 경계: downcast=슬픔·복종이 아님 / chin tuck와 동일시하지 않음.
- 관찰 조건: 동공과 얼굴 기준축 또는 명시된 아래 대상이 확인되어야 함.
- 기존 후보: `gaze_engagement.pv_gaze_down`, `gaze_engagement.ae_downcast`.
- 기존 프로필: 라벨만으로 신규 하드 프로필을 만들지 않음.
- 반영안: 감정 라벨과 아래 시선 형태의 분리를 강화.
- 근거: [R02: Paul Ekman Group: Facial Action Coding System](https://www.paulekman.com/facial-action-coding-system/), [R03: Barrett et al. (2019), Emotional Expressions Reconsidered](https://pmc.ncbi.nlm.nih.gov/articles/PMC6640856/).

### 018. 턱을 내리고 올려다보기 — Looking up through the lashes

- 소유·관계: 같은 주체의 head pitch와 eye direction이 반대 / 속눈썹→같은 눈.

- 관찰 조건: 얼굴 가까운 크롭에서 속눈썹/눈/턱의 관계가 모두 식별되어야 함.

### 019. 반쯤 감은 눈 — Half-lidded eyes

- 유형: `observable_configuration`. 요청한 형태만 의무로 평가한다.
- 형태: 양눈 또는 지정 눈의 눈 틈이 일부 좁아짐 / 윗눈꺼풀 하강형은 선택된 세부 변형 / 넓은 half-lidded 의미는 위/아래 기여를 확정하지 않음.
- 소유·관계: 눈꺼풀→같은 주체 홍채/눈 틈.
- 혼동 경계: 눈을 완전히 감음과 구분 / squinch의 아래 눈꺼풀 중심 형태를 덮어쓰지 않음.
- 관찰 조건: 열린 눈 틈과 눈꺼풀 경계 확인;윗/아랫눈꺼풀 구분이 안 되면 좁은 하위 변형은 미관찰.
- 기존 후보: `expression.pv_half_lidded`.
- 기존 프로필: 라벨만으로 신규 하드 프로필을 만들지 않음.
- 반영안: 범용 후보 유지 및 윗눈꺼풀 중심 하위 후보 제안.
- 근거: [P01: Peter Hurley: The Squinch](https://peterhurley.com/blog/squinch-single-easiest-tip-looking-confident-photos), [R02: Paul Ekman Group: Facial Action Coding System](https://www.paulekman.com/facial-action-coding-system/).

### 020. 스퀸치 — Squinch

- 유형: `observable_configuration`. 요청한 형태만 의무로 평가한다.
- 형태: 아랫눈꺼풀 경계가 홍채 쪽으로 올라 좁힌 눈 틈 / 양눈은 열려 있음 / 윗눈꺼풀은 상대적으로 덜 내려온 구성.
- 소유·관계: 같은 주체의 lower/upper eyelid를 분리.

- 관찰 조건: 원본 가까운 얼굴에서 아래 경계와 열린 눈 확인;단일 사진으로 실제 움직임/유지 시간을 증명하지 않음.

- 기존 프로필: `ae_profile_squinch`.
- 반영안: 기존 후보/프로필을 좁은 혼동 경계와 가시성 기준으로 보강.

### 023. 한쪽 눈썹 올리기 — Single eyebrow raise

- 소유·관계: same actor left/right brow / 눈썹과 눈의 소유 일치.

- 반영안: 머리 기준 좌우 높이와 화면 기준 높이의 혼동 검사 추가.

### 024. 짧게 눈썹 들기 — Brief eyebrow raise

- 유형: `temporal_or_state`. 요청한 형태만 의무로 평가한다.
- 형태: 현재 프레임에서 눈썹이 올라간 상태 / 짧게 올렸다 내리는 시작/끝과 지속은 연속 프레임 필요 / 한쪽/양쪽은 요청대로 분리.
- 소유·관계: 주체 brow→same face / 시간축 t0/t1/t2 별도.
- 혼동 경계: single eyebrow raise와 brief duration은 다른 축 / 정지 한 장으로 순간성을 판정하지 않음.
- 관찰 조건: 정지: 올라간 눈썹만 검사;시간 요구: 중립→상승→복귀 프레임 필요.
- 기존 후보: `expression.pv_raised_brows`, `expression.ae_single_brow`.
- 기존 프로필: 라벨만으로 신규 하드 프로필을 만들지 않음.
- 반영안: 상태 후보 재사용하고 시간 요구는 별도 미검증으로 기록.
- 근거: [R02: Paul Ekman Group: Facial Action Coding System](https://www.paulekman.com/facial-action-coding-system/), [R03: Barrett et al. (2019), Emotional Expressions Reconsidered](https://pmc.ncbi.nlm.nih.gov/articles/PMC6640856/).

### 025. 눈이 먼저 움직이는 고개 돌림 — Eyes-leading turn

- 유형: `temporal_or_state`. 요청한 형태만 의무로 평가한다.
- 형태: 눈 방향이 먼저 바뀌는 프레임 / 뒤에 머리가 같은 목표로 회전하는 프레임 / 현재 한 장에서는 눈/머리 방향 차이만 보임.
- 소유·관계: same actor eyes t1→target / head t2→same target.
- 혼동 경계: 역방향 전환·머리만 회전·순서를 알 수 없는 시선과 구분.
- 관찰 조건: 정지: 눈/머리 차이 상태만;전체 요구: 순서가 보이는 연속 장면.
- 기존 후보: `gaze_target.head_eye_counterorientation_relation`, `body_orientation.pv_head_turn`.
- 기존 프로필: 라벨만으로 신규 하드 프로필을 만들지 않음.
- 반영안: 시간 순서와 정지 대체의 실패 경계를 보강.
- 근거: [R02: Paul Ekman Group: Facial Action Coding System](https://www.paulekman.com/facial-action-coding-system/), [R03: Barrett et al. (2019), Emotional Expressions Reconsidered](https://pmc.ncbi.nlm.nih.gov/articles/PMC6640856/).

### 026. 시선 회피 후 재접촉 — Look away and return

- 유형: `temporal_or_state`. 요청한 형태만 의무로 평가한다.
- 형태: 목표를 봄→시선을 뗌→같은 목표를 다시 봄 / 동일 인물/목표의 연속성이 필요 / 현재 사진은 세 단계 중 하나뿐.
- 소유·관계: actor identity t0..t2 / target identity continuity.
- 혼동 경계: 단순 시선 회피·다른 대상 보기·눈 감기와 구분.
- 관찰 조건: 세 단계 시간 증거 없이 전체 요구 PASS 불가;사진 상태는 직접 또는 비직접 시선만 검사.
- 기존 후보: `gaze_engagement.pv_gaze_direct`, `gaze_engagement.pv_gaze_offcamera`, `gaze_engagement.returned_gaze_mid_partial_turn`.
- 기존 프로필: 라벨만으로 신규 하드 프로필을 만들지 않음.
- 반영안: 기존 미완료 돌아보기 후보를 재사용하며 시간 완료 주장은 금지.
- 근거: [R03: Barrett et al. (2019), Emotional Expressions Reconsidered](https://pmc.ncbi.nlm.nih.gov/articles/PMC6640856/).

### 027. 머무는 시선 — Lingering gaze

- 유형: `temporal_or_state`. 요청한 형태만 의무로 평가한다.
- 형태: 같은 목표를 향한 시선 유지 / 지속 시간이 요구의 핵심 / 깜박임/머리 움직임과 구분해서 기록.
- 소유·관계: actor gaze→same target across time.
- 혼동 경계: 직접 응시 한 장=lingering의 증거 아님 / 강렬함·집착을 자동 추정하지 않음.
- 관찰 조건: 정지: 현재 eyeline만;시간: 목표 유지 구간 필요.
- 기존 후보: `gaze_engagement.pv_gaze_direct`.
- 기존 프로필: 라벨만으로 신규 하드 프로필을 만들지 않음.
- 반영안: 정지 이미지에서 지속성 하드 게이트를 만들지 않음.
- 근거: [R03: Barrett et al. (2019), Emotional Expressions Reconsidered](https://pmc.ncbi.nlm.nih.gov/articles/PMC6640856/).

### 028. 눈에서 입가로 이동하는 시선 — Eye-to-lip glance

- 유형: `temporal_or_state`. 요청한 형태만 의무로 평가한다.
- 형태: 상대 눈을 보는 상태와 상대 입을 보는 상태가 순서대로 구분 / 시선 출발점은 주체의 눈 / 입은 이미 존재하는 상대 소유.
- 소유·관계: actor eyes→partner eyes t0→same partner lips t1.
- 혼동 경계: 자기 입·카메라·불특정 두 번째 인물과 구분 / 입맞춤·동의·욕망을 자동 추가하지 않음.
- 관찰 조건: 정지: 상대 입 방향 상태만;두 얼굴 또는 목표 위치가 식별되어야 함;순서는 연속 증거 필요.
- 기존 후보: 직접 재사용 ID를 아직 확정하지 않음.
- 기존 프로필: 라벨만으로 신규 하드 프로필을 만들지 않음.
- 반영안: 대상 입 방향 상태 후보를 조건부 제안하고 actor/partner 바인딩을 선행.
- 근거: [R03: Barrett et al. (2019), Emotional Expressions Reconsidered](https://pmc.ncbi.nlm.nih.gov/articles/PMC6640856/).

### 029. 눈을 감은 표정 — Eyes-closed expression

- 반영안: 닫힘과 가려짐을 분리한 게이트 보강.
- 근거: [R02: Paul Ekman Group: Facial Action Coding System](https://www.paulekman.com/facial-action-coding-system/), [R03: Barrett et al. (2019), Emotional Expressions Reconsidered](https://pmc.ncbi.nlm.nih.gov/articles/PMC6640856/).

- 반영안: 기존 펜던트가 있을 때만 가능한 접촉 후보 초안 제안.

### 081. 손가락으로 부르기 — Beckoning gesture

- 유형: `temporal_or_state`. 요청한 형태만 의무로 평가한다.
- 형태: 손바닥 방향과 한 손가락/여러 손가락의 굽힌 현재 상태 / 대상은 카메라 또는 기존 인물 / 다가오라는 반복 굽힘은 시간 증거 필요.
- 소유·관계: actor finger flexion→hand plane / gesture direction→bound target.
- 혼동 경계: 손가락 지시·주먹·임의 오므림과 구분 / 정지 상태만으로 초대 의도를 확정하지 않음.
- 관찰 조건: 정지: 굽힌 손가락/손바닥 방향 확인;전체 손짓: 굽힘 반복의 프레임 증거 필요.
- 기존 후보: 직접 재사용 ID를 아직 확정하지 않음.
- 기존 프로필: 라벨만으로 신규 하드 프로필을 만들지 않음.
- 반영안: 정지 손 상태 후보를 제안하고 beckon 전체 의미는 문맥/시간으로 분리.
- 근거: [P03: Neil van Niekerk: Tips on posing hands](https://neilvn.com/tangents/tips-on-posing-hands/), [R03: Barrett et al. (2019), Emotional Expressions Reconsidered](https://pmc.ncbi.nlm.nih.gov/articles/PMC6640856/).

### 082. 렌즈 쪽으로 손 뻗기 — Reaching toward camera

- 반영안: 기존 OTS 소유 프로필을 중심으로 재사용하고 포즈50 교차 회귀 추가.

### 109. 소프트 라이트 — Soft light

### 112. 키아로스쿠로·명암 대비 — Chiaroscuro

### 120. 부분만 드러내는 조명 — Selective illumination
