# 조명과 수광 재질의 구분

기준 커밋: `6adabfe4cf9255733686d61c5bff3288a7ef8138`.

## 문제와 교정

하드·소프트 조명 프로필이 빛의 크기·그림자 성질과 광택 재질을 혼동하고 있었다. 마른 석고와 무광 종이를 요청해도 반짝이는 정반사 증거가 필수였고, 재질에 맞는 확산 반사 증거는 감사에서 거절됐다.

두 프로필에 수광 재질을 보존하는 대안을 추가했다. 무광은 확산 명암을 유지하고, 실제 재질과 관찰 방향에서 정반사가 보이는 경우만 광원·거칠기·기하에 따른 광택 응답을 설명한다. 광택 소품을 추가하거나 무광 표면을 유약 처리한 것으로 바꾸지 않는다. 기존 광택 증거, 그림자 요건, 다섯 게이트와 길이 기준은 유지했다.

[PBRT의 재질 설명](https://www.pbr-book.org/3ed-2018/Materials/Material_Interface_and_Implementations)은 확산·광택 응답과 표면 거칠기를 구분한다. [broncolor의 조명 설명](https://broncolor.swiss/news/hard-soft-and-diffused-light-what-is-the-difference)은 광원의 크기·거리와 그림자 경계를 설명한다. 광택 수광면은 하드·소프트 조명의 필수 조건이 아니다.

독립 리뷰에서 의미상 조건이 빠진 기존 의역 6개도 확인했다. 예를 들어 물체와 그림자의 모양이 대응한다는 문장만으로는 하드 조명의 경계·방향·재질·노출 관계를 정하지 못한다. 이런 짧은 의역의 선택 활성화는 제거하고 완성된 광택/무광 관계를 보존했다. 단순히 정규 성분 문자열과 글자가 다르다는 이유로 의역을 배제한 것이 아니다. 불완전한 문구에 대한 재현율은 의도적으로 낮아진다.

## 실제 공개 CLI와 구성 감사

영어·한국어 무광 4개, 광택 2개, 일반 대조 2개의 고정 원본 입력으로 정상 CLI를 전후 실행했다. 8개 AFTER 모두 성공했고 코어와 슬롯 객체 전체가 동일했다. 일반 대조 팩은 완전히 동일하며 필수 조명 의무도 없다.

6개 활성 사례의 완전한 증거와 코어·의도·신체 동작 바인딩, 선택 후보에 대한 명시적 결정으로 8개 전체 구성 감사가 통과했다. 석고·종이는 그대로 무광이고 광택 대조는 기존 유약을 유지한다. 증거 필드나 본문 문장을 지운 60개 변형은 거절됐다. 이미지 생성·픽셀 검증은 하지 않았다.

## 주변 선택 후보 변화

무광 소프트 조명 영어 사례에서 무관한 선택 후보 1개가 교체됐다. 벨루어는 BM25F 8위/128.270476041874→10위/125.301511993474, 쿠션 지지·압축은 9위/127.738935810214→8위/127.778074503079로 이동했다. 후보 제한 8개의 경계를 넘은 결과다.

이 장면에는 사람·성인·옷·쿠션이 없고 두 후보 모두 성분 근거가 없다. 두 프로필과 문서는 변경되지 않았으며, diffuse 문서 빈도 7→9와 정규화 통계 변화가 순위에 영향을 주었다. 실제 실행에서 임베딩 검색은 평가되지 않았다. 새 필수 의무·게이트·슬롯 채택은 없고 해당 장면의 유일한 필수 프로필은 소프트 조명이다.

새 선택 후보를 채택하면 부적절한 사람·쿠션 내용이 유입될 위험은 남는다. 기존 벨루어 역시 부적절했지만 새 후보를 개선이라고 주장하지 않는다. 이 변경을 숨기거나 문구를 조정해 우연한 근접 순위를 보존하지 않았다. [정확한 원인과 위험](collateral-risk.md)을 별도로 기록했다. 전체 구성 감사에서는 관련 없는 선택 후보를 채택하지 않았다.
