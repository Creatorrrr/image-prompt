전체 후보의 무손실 편집 정본과 출처 기반 보강 계약을 만들고, Luna max로

A/B/C 모두 29/29, 지원 목표 7/7이었다. 이는 같은 판정을 재사용한 보조
결과이며, 새 요청에 대한 독립 일반화 평가나 모든 반환 결과의 적합 판정은 아니다.
미판정 결과와 창작 소재로 쓰일 수 있는 다른 후보에는 감점을 주지 않았다.

## 검색과 평가 검증

각 조건은 18,180 positive CID / 18,182 actual RID 전체에서 경쟁했다.
BM25F의 전역 DF·길이 통계를 매번 전체 풀로 계산했다. 기존 D 문서와 단서
순서를 정확한 prefix로 보존하고 새 설명을 덧붙였다. 원문 삭제나 슬롯별
후보 제한, 재검색, reranker를 넣지 않았다.

각 조건의 75개 목표는 BM25F 75회와 local cosine 75회를 수행했다.
즉 목표당 각 lane 1회이며 RRF10/CID 중복 제거/top8도 동일하다.
기존 H query와 로컬 모델 공간을 고정했고 변경된 C 문서 41개만 로컬에서
새로 임베딩했다. Gemini 호출은 없다. 실행 시 OS sandbox에서 네트워크와
과거 연구 checkout 접근을 차단했다.

기존 671건 판정의 명시적 적합 126개 goal/CID/RID 연결과 40개 지원 목표를
분모로 고정했다. 출처 연결 682건(정확 인용 605, 부분 인용 77)을 확인했다.
다른 RID의 적합 판정이나 미판정 목표를 임의로 포함하지 않았다.

전체 순위 225개를 저장된 BM25F/cosine 점수에서 독립 재계산했다.
모델·운영 cache 없이 재생하는 `audit_saved.py`에서도 top8, 주 평가 및 보조
평가가 일치했다. 점수 archive는 A/C를 보관하고 byte가 같은 B는 A를 공유한다.
관련 단위·workflow·precore·권한 전달 회귀 테스트 **72개가 통과**했다.

## 결과가 의미하는 것

B의 문서 변경 수는 0이다. 이번 대상의 기존 시각적 사실은 이미 D/F2의
다른 단서로 보존되어 있어 중복 제거 후 추가할 텍스트가 없었다.
따라서 이 B 대조는 새로운 구조 변경의 효과를 입증한 실험이 아니다.

C는 실제 문서 41개를 바꿨으며, 이 대상에 연결된 기존 적합 판정은 30/126건이다.
유지 38건, 파일럿 밖 55건, 보류 2건, 의미 편집 필요 1건은 설명을 보강하지 않았다.
이번 결과로 전체 데이터 개선에 효과가 전혀 없다고 결론 내릴 수는 없지만,
이 보강·컴파일 방식으로 전수 작업을 확대할 근거도 확보하지 못했다.

회수 이득 4건은 모두 보강 문서였다. 손실 중 1건은 보강 문서의 cosine 순위가
1위에서 28위로 내려가 RRF 2위→52위가 됐다. 이 후보의 BM25F 순위는 오히려
529위→225위로 올랐다. 원문을 보존해 설명을 추가해도 임베딩의 강조점은
달라질 수 있다는 실제 사례다. 나머지 손실 3건은 수정하지 않은 문서이며,
cosine 값은 같아도 다른 후보와 전역 통계·순위 경쟁을 거쳐 top8 밖으로 밀렸다.
정확한 후보별 점수·순위 변화는 `DIAGNOSIS.json`에 기록했다.

설명의 출처와 사람이 읽는 의미는 정리했지만, 이를 그대로 검색 문서에
덧붙이는 방식의 순이득은 확인하지 못했다. 현재 결과는 전수 이관의 성공이나
새 운영 검색의 품질 향상을 의미하지 않는다.
