# 구조 개선과 main 통합

최신 main baa876d8의 삼엽·사엽 혼동 경계 수정과 구조 개선을 함께 반영한다. 기존 프로필 의미, 활성화 조건, 증거 요건, 이미지 판정 기준과 후보 데이터는 그대로 유지한다.

- 429개 기존 평면 프로필을 묶음 의무를 표현하는 authored_components v2로 변환하고, 55개 프로필의 중복 파생 필드를 제거했다.
- 게시된 main의 후보 확장 52개와 시각 의미 확장 34개를 단일 등록표로 관리한다. 기존 로딩 순서와 필수 후보 파일 50개를 유지한다.
- 작업 시작 시 로컬에 있던 미게시 지적 활동 자료와 기타 연구 변경은 게시 범위에서 제외하고 백업·보존한다. 상위 qualification.json은 이 자료가 포함된 최초 작업 단계의 기록이며, main 통합 결과는 이 폴더의 기록을 기준으로 확인한다.
- main의 1,879개 프로필을 모두 비교했다. authored_components 작성 메타데이터만 제외한 컴파일 결과와 전체 후보 딕셔너리는 변경 전후 동일하다.
- 10,082개 의미 색인 항목과 시각 프로필 색인의 검색 텍스트, 벡터, BM25F, 정확 조회를 유지한다. 시각 색인은 레지스트리 결합 해시만 갱신했으며, 추가 임베딩 호출은 없다.

## 과거 경계와 현재 경계

V1–V23의 기존 증거, 기준 후보팩과 원본 소스는 보존한다. V23 재현용 V23-PARENT-SOURCE.json은 main 커밋의 Git blob, 파일 길이와 SHA-256으로 574개 입력을 고정한다. 이 중 16개만 새 스냅샷으로 저장하고, 나머지는 이미 봉인된 이전 소스와 기존 불변 자료를 참조한다. 복원은 Git·네트워크·현재 데이터 대체 없이 수행하며, 원래 V23 검증기와 지원 모듈을 사용한다.

새 V24 경계는 작성 구조와 등록표 변경을 별도로 검증한다. 실제 생성한 V24 후보팩은 V23 후보팩과 바이트 단위로 동일하다. 후보 ID·순서·본문, 코어, 제어값, 구성, 부정 프롬프트와 공개 출처 정보도 동일하다. 현재 검증기는 V24를 기본으로 선택하고, V23의 기존 검증과 변형 거부 테스트는 원래 봉인된 입력으로 재현한다.

V24-STRUCTURE-BINDING-PROOF.json은 원본 소스 변경 13개와 신규 소스 2개, 전체 데이터 파일 목록, 활성·보존 벡터 샤드를 고정한다. 공통 장면 기준 파일은 검증기 해시 한 곳만 갱신했다. 새 이미지 생성이나 이미지 품질 재판정은 수행하지 않았다.

## 검증

사전 확인한 main 원본에서도 기존 캐릭터 의미 비교, 직물 자료 출처 해시, 형제 스킬의 importlib 금지 검사가 실패했다. 리미널 과거 후보 목록의 glass_near_contact_reflected_fringes 불일치도 원래 main 코드와 데이터에서 재현했다. 이 네 불일치의 기대값은 이번 구조 변경으로 수정하지 않는다. 전체 회귀 결과와 변경 전 재현 로그는 VALIDATION.json과 logs/에 기록한다.

전체 1,705개 테스트 중 1,701개 통과, 기존 불일치 4개가 남았다. 별도 체크아웃에 없던 과거 입력 15개는 원본 및 고정된 해시를 검증해 읽기용으로 복원했으며, 관련 테스트 기대값은 변경하지 않았다.
