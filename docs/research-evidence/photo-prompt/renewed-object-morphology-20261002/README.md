# 물체 형태와 사람·방향의 소유 관계 교정

기준 커밋: `2549f45230fe37dbc4224929b0d661ceac8004cc`.

## 문제와 수정

레이피어와 컴파운드 보우의 일반 명칭을 요청하면 형태 프로필이 필수로 활성화된다. 기존 데이터는 사람이 없는 정물에도 손을 요구했고, 수평 제품 사진에도 활을 수직으로 제시하도록 요구했다. 독립 작성한 입력을 정상 공개 CLI로 실행하여 원본 코어는 그대로인데 이 필수 계약이 추가되는 것을 확인했다.

두 프로필의 형태 의무를 물체 자체에 귀속시켰다. 가드는 손잡이 주위 구조, 그립은 중앙 구조의 일부로 설명하며 사람의 존재와 사진 방향은 요청대로 유지한다. 일반 명칭의 활성화, 다섯 형태 게이트, 제외어, 증거 길이는 유지했다. 별도의 정물 예외 문구나 부정 처리 로직은 추가하지 않았다.

독립 리뷰에서 발견한 호환성 손실도 수정했다. 기존 영어·한국어 손 접촉 성분과 증거를 유효한 대안으로 남겼고, 수직 배치도 선택 가능한 예시로 보존했다. [Met의 물체 기록](https://www.metmuseum.org/art/collection/search/24677)과 [World Archery의 장비 설명](https://www.worldarchery.sport/sport/equipment)은 형태의 근거이며 사진에 손이나 특정 방향이 필수라는 근거가 아니다. 작동·조작·제작 방법을 추가한 작업은 아니다.

## 실제 전후 결과

사람 없는 정물 2개와 성인이 들고 있는 장면 2개를 동일한 원본 계약으로 정상 공개 CLI에 전후 실행했다. 4개 AFTER 모두 성공했고, 모든 후보 ID·순서·개수, 슬롯 객체 전체, 코어가 동일했다. 변화는 팩 ID, 대상 의미 설명과 형태 계약에 한정됐다. 레이피어 사례마다 11개, 활 사례마다 5개 경로/배열 길이 차이를 기록했다.

정물에는 손·수직 방향의 강제가 사라졌고, 손에 든 장면의 명시적 접촉은 유지됐다. 최종 본문을 임의 생성해 비교한 것이 아니라 실제 후보팩 계약을 비교한 결과다.

4개 완전한 증거 묶음이 실제 시각 의무 감사 함수를 통과했고, 필드 또는 필요한 본문 문장을 지운 40개 변형은 거절됐다. 손에 든 레이피어는 이전 손 접촉 증거, 정물은 새 중립 증거를 각각 사용했다. 원본 코어의 본문을 그대로 보존했다. 이 결과는 전체 구성 프롬프트 감사나 생성 이미지 평가가 아니다.

## 검증과 한계

새 회귀 3개를 포함한 15개 테스트, 독립 계약 검사 74개, 사전·실제 인덱스 검증이 통과했다. 수정 벡터 2개 외 1,494개는 그대로 보존했다. 앵커 자체가 기존 길이 기준보다 짧을 수 있어 구체적 장면 단어를 포함한 증거를 검증했으며 기준을 낮추지 않았다.

손에 든 입력의 최초 설정 필드가 최소 단어 수를 충족하지 못해, 의도를 바꾸지 않는 설정 문구만 보완한 원본 계약을 전후 고정했다. 최초 입력과 실패 기록, 수정 근거를 함께 보존했다. 이 네 진단이 전체 입력 공간의 무퇴보나 픽셀 품질 개선을 증명하지 않는다.
