## 양쪽 의도와 인덱스

- DATA 연장분의 고유 53개 레코드(51개 프로필·2개 슬롯 행)가 배열과 대안 표현까지 완전히 같습니다
- 해당 프로필의 전체 인덱스 항목·BM25F 문서·exact alias 행과 두 슬롯의 인덱스 항목도 같습니다
- 독립 upstream은 프로필 12개를 추가하고 기존 19개의 검색용 문장을 바꿨습니다. 일반 검색 항목은 12개 추가·22개 텍스트 변경입니다. 변경된 모든 텍스트는 기존과 다른 벡터를 갖고 있으며 바뀐 텍스트에 이전 벡터가 재사용된 사례는 없습니다
- 현재 1,576개 시각 프로필, 9,831개 일반 검색 항목, 16개 shard의 source binding·현재 텍스트·해시·BM25F·모델/차원 및 유한 768차원 벡터 검사가 통과했습니다
- 전체 벡터 수치만으로 제공자 출처를 재구성하는 증거는 아닙니다. 이 검증에 provider 호출은 없습니다

별도 upstream의 항목과 비용은 이번 DATA loop의 29개 cycle·56회 편집·53개 고유 대상에 합산하지 않습니다.

## 테스트 범위

10개 관련 모듈의 **63개 메서드가 모두 통과**했습니다. DATA25–29, 기존 경계 회귀, 카메라 owner, 새 은어 대안·경계 이력이 포함됩니다. 실제 기본 V8 경계 재조회도 통과했습니다. 실행 전후 506개 소스 해시와 HEAD는 같았고 이전 fcb 검증 증거도 보존됐습니다. 새로운 전체 suite 실행은 아닙니다.

은어 upstream은 자신의 worktree에서 원래 ignored 자산을 복원한 뒤 최종 선택 결과 1,354개 테스트가 모두 통과했다고 보고했습니다. 이번 dot 작업 폴더에는 그 목록의 24개 경로가 모두 없습니다. 따라서 그 통과 결과를 현재 작업 폴더의 전체 suite 결과로 옮기지 않습니다. 이전 고정 소스의 누락 자산 실패 로그도 유효한 당시 기록으로 유지합니다.

기존 backlog의 “원본 자산 복구”는 프로젝트 전체에서 아직 복구하지 못했다는 뜻으로 읽으면 안 됩니다. 원본 자산은 다른 worktree에서 확인됐으며, 이 환경에서의 재현·전달은 별도 과제로 남습니다. 원본을 추측해 새 이미지나 JSON으로 대체하지 않았습니다.

PR4의 새로운 V2 양성 0/6과 음성 abstention 8/8, 별도 은어 native 장면의 1 PASS / 2 FAIL도 그대로입니다. 관련 unit test 통과가 이 실패들을 해결했다는 뜻은 아닙니다.
