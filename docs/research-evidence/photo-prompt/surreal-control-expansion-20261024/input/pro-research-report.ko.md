# 사진 프롬프트 시스템 surreal 보강 리서치와 후보 초안

작성일: 2026-10-24 (한국 시간)  
문서 상태: 1차 자료 리서치와 저술 초안. 기존 원본 대조 및 생성 이미지 검증은 미완료.

## 1. 판단 요약과 조사 범위

**지금 가장 유효한 보강 방향은 일상 사물의 관계를 명확히 저술하고, 그 관계가 사진에서 맡는 역할을 비교할 수 있게 만드는 것이다.** 새로운 기계·생물·상징 소품을 계속 늘리는 방식은 우선하지 않는다. 다만 이것은 제공된 범위 설명과 외부 근거를 바탕으로 한 보강 제안이며, 기존 데이터의 실제 결손을 확정한 결과가 아니다.

### 1.1 원본 자료 확인의 한계

이번 대화에서 언급한 시각 후보 72개, 진단·맥락 기록 16개, 키워드 경로 182개의 원본 첨부를 확인하지 못했다. 관련 파일을 찾아보았으나 이번 범위와 일치하는 원본을 식별하지 못했으며, 과거 자료를 이번 첨부로 대체하지 않았다.

실제로 검토한 기존 자료는 **사용자 메시지에 적힌 설정 정의·집계·12개 관계군 목록**이다. 따라서 다음 판단을 엄격히 구분한다.

| 판단 대상 | 이번에 가능한 판단 | 아직 할 수 없는 판단 |
| --- | --- | --- |
| 주제적 범위 | 규모, 반사, 시간, 돌봄 등이 분류명에 존재함 | 각 관계가 사진에서 충분히 구현되도록 저술되어 있는지 |
| 편중 | 장치·신체를 명시한 분류군이 있음 | 기술 의존 후보의 실제 비율, 강도별 분포 |
| 일상성과 정서 | 친밀성·돌봄·일상이 이미 표제에 있음 | 온화함·유머·약한 초현실의 실제 부족 |
| 중복 | 기존 관계군과의 개념적 근접성 | 특정 후보 ID와의 중복, 첨부 밖 전체 코퍼스 중복 |
| 강도 | 0~3의 저술 의미와 비교 가설 작성 | 실제 이미지에서의 단계 분리 성능 |

원본 항목 열람 수는 시각 후보 0개, 진단 기록 0개, 경로 0개다. 사용자 제공 집계 72·16·182와 이 열람 수를 혼동하지 않는다. **현재 확정할 수 있는 실제 공백은 자료 접근의 공백이며, 코퍼스 내용의 실제 공백은 미확정이다.**

### 1.2 이번 산출물

- 조건부 시각 후보 초안 10개. 그중 도로 표시의 박리(C07)는 정상 현상과의 구분이 약해 보류 상태로 남긴다.
- 원리를 추가하는 용도와 구분한 진단·대조 기록 3개.
- 동일 주제를 유지하는 surreal 0·1·2·3 비교군 4개.
- 원본 대조 방법, 출처별 근거 범위, 생성 이미지 검증 계획.

후보 개수는 생산 목표나 충족 지표가 아니다. 기존 자료에서 같은 관계와 증거 구조가 확인되면 신규 항목 대신 재사용하거나 정제한다.

## 2. 설정의 의미를 데이터와 평가에 보존하기

### 2.1 0은 현실성을 강제하는 값이 아니다

| 설정 | 에이전트의 저술 지침 | 잘못된 구현 예 |
| --- | --- | --- |
| 0 | 추가 초현실 처리를 하지 않는다. 사용자 지정 판타지·불가능 요소는 유지한다. | 사용자가 요청한 용을 지우거나 장난감으로 바꿈 |
| 1 | 판독 가능한 관계가 주제를 돕는 보조 요소로 작용한다. | 관계가 전혀 안 보이는 것을 은근함으로 간주 |
| 2 | 관계가 사진의 분명한 특징으로 읽힌다. | 장식이 많다는 이유만으로 2로 판정 |
| 3 | 관계가 사진의 주된 인상과 방향을 이끈다. | 소품·이상현상 개수를 늘리거나 원래 행동을 지움 |

설정값은 이미지 생성 모델의 고유 파라미터가 아니라 에이전트의 창작 지침이다. 같은 관계가 배치, 정상 세계와의 대비, 시선의 흐름, 장면의 의미적 중심성에 따라 1·2·3의 역할을 맡을 수 있다.

사용자가 처음부터 불가능한 존재를 요구했다면 0의 사진도 매우 초현실적으로 보일 수 있다. 따라서 **설정 준수와 사진 전체의 비현실감은 별도 평가 항목**이다. 원래 요청이 이미 초현실적 주제를 지배하도록 정했다면 단계 사이의 총인상 차이가 작아도 그것만으로 실패가 아니다.

### 2.2 세 가지를 하나로 합치지 않기

1. **보이는 관계:** 무엇이 무엇과 어떻게 연결·대응·접촉하는가.
2. **현실에서의 구현 가능성:** 실제 소품·설치·촬영으로 만들 수 있는가.
3. **관객에게 읽히는 역할과 정서:** 관계가 보조·명시적·지배적이며, 서정적·유머러스한가.

Madoz의 일상 사물 사진을 설명한 Reina Sofía 자료는 발견한 사물, 조작한 사물, 제작한 사물을 모두 다루며 형식적·상징적 유비를 설명한다. 실제 제작 가능한 관계도 이번 설정의 연구 대상이라는 근거다. 다만 작가를 역사적 초현실주의의 자유연상으로 단순 환원하지 않는다. [S01](https://www.museoreinasofia.es/en/exhibition/madoz-objetos-1990-1999/)

Smilde의 Nimbus는 수초간 존재한 현상이 사진으로 남는 작업이고, Erlich의 가나자와 수영장은 유리 위 얕은 물과 아래 빈 공간으로 제작된다. 이들은 초현실적 인상과 물리적 제작 가능성을 분리할 실제 사례다. 이번 후보의 정확한 구성이나 생성 성공을 입증하는 자료는 아니다. [S06](https://www.berndnaut.nl/works/nimbus/), [S13](https://www.kanazawa21.jp/data_list.php?d=7&g=30&lng=e)

이 보고서의 ‘기술 장치 없이 성립’은 **기계·케이블·인공 신체가 화면의 의미를 이해하는 데 필요하지 않다**는 뜻이다. 참고 작품의 제작 공정에 어떤 도구도 사용되지 않았다는 뜻이 아니다.

## 3. 기존 범위의 잠정 평가

### 3.1 다섯 관점을 관계와 효과의 두 층으로 정리

공간·크기·인과·재질은 대체로 관계를 만드는 방식이고, 분위기는 여러 관계와 촬영 조건에서 생기는 효과다. 다음처럼 나누면 ‘서정적’이라는 단어 하나를 독립 시각 원리로 세는 오류를 줄일 수 있다. 기존 12개 분류군을 폐기하는 제안은 아니다. 기존 분류군 위에 교차 태그를 추가하는 방식이다.

| 관계 축 | 단어를 넘어 확인할 내용 | 연결되는 기존 분류군 | 현재 판단 |
| --- | --- | --- | --- |
| 맥락·용도·행위 역할 | 물체가 원래 누구를 위해, 어디서, 어떻게 쓰이는지의 전환 | 사물 전이·병치, 친밀성·돌봄, 포스트휴먼 일상 | 분류상 접점은 있음. 비기술적 단순 관계의 밀도는 미확인 |
| 공간·경계·포함 | 안/밖, 연결/단절, 표면/공간의 경계와 통로 | 유기적 건축, 규모·포함 세계, 재귀 | 공간 관련 표제는 있음. 정상적 건축의 규칙만 바꾸는 사례는 미확인 |
| 상대적 크기 | 동일 공간·깊이의 대상 사이 비례 | 규모·포함 세계 | 새 공백으로 선언할 이유 없음. 사용 행동·현실 기준·약한 역할 여부를 대조 |
| 지지·중력·인과 기대 | 접촉점, 지지면, 처짐, 분리된 위치 | 사물 전이, 재귀·시간 등과 접할 수 있음 | 독립 축이 표제에서 불명확. 단정 가능한 인과와 정지 상태를 구분해 감사 |
| 반사·그림자·대응 | 무엇의 반사인지, 어느 속성만 어긋나는지 | 이중 이미지·지각 불일치 | 표제에 명시됨. 정상 대응을 함께 보여 주는 설계 여부가 중요 |
| 재질·형태·사용감 | 표면 정체성과 눌림·접힘·사용 기대의 충돌 | 사물 전이, 신체·장치, 복합 생물, 신체 경계 | 재질 변형의 존재는 미확인. 신체 외 일상 사물의 물성 관계를 확인 |
| 상태·시간·환경 조건 | 서로 다른 상태가 한 프레임에서 대응하는 방식 | 재귀·시간, 이중 이미지, 인접 드림코어 | 시간의 서사와 관찰 가능한 동시 상태가 구분되는지 확인 |

효과·조건 층에는 일상성, 서정성, 온화함, 유머, 경이, 불안, 공포, 기술 장치의 의미적 필요성, 사람/사물/자연/건축, 관계의 저술 역할을 별도로 기록한다. 공포와 온화함은 강도의 다른 이름이 아니다.

### 3.2 12개 관계군별로 이미 인정할 범위와 확인할 공백

아래 표의 ‘이미 인정’은 분류명에서 확인한 범위다. 실제 사례의 충분성 판정이 아니다.

| 기존 관계군 | 이미 인정할 주제적 범위 | 원본에서 확인할 핵심 질문 |
| --- | --- | --- |
| 사물의 전이와 병치 | 일상 사물과 맥락 전환의 입구가 있음 | 단순 사물 나열인지, 사용·소유·접촉의 관계까지 저술되어 있는가 |
| 이중 이미지와 지각 불일치 | 반사·대응·다르게 읽힘을 다룰 가능성이 명시됨 | 원본과 대응상의 동일성을 한 장에서 연결할 수 있는가 |
| 신체와 장치의 접합 | 신체·장치 관계가 명시됨 | 접합부의 가시성은 있는가. 이것이 비기술적 후보를 대체하고 있지는 않은가 |
| 외부 인지·기억 구조 | 인지·기억의 외부화가 포함됨 | ‘기억한다’ 같은 설명이 없을 때도 구체 관계가 읽히는가 |
| 유기적 건축 | 건축의 생물적·유기적 변형이 포함됨 | 형태는 평범하되 공간 규칙만 다른 표현도 있는가 |
| 의례와 기계 | 의례와 기계의 결합이 포함됨 | 장치 없이 행동의 수신자·용도만 바꾸는 표현과 구분되는가 |
| 규모와 포함 세계 | 크기·세계의 포함을 이미 다룸 | 거대/미니어처 단어를 넘어 동일 깊이의 기준과 사용 행동이 있는가 |
| 재귀와 시간의 흔적 | 반복·흔적·시간 연상이 이미 포함됨 | 과거/미래/역행이라는 서사를 정지 이미지의 증거로 과장하지 않는가 |
| 복합 생물 | 생물의 결합을 이미 다룸 | 자연물이 변형되지 않고 관계만 달라지는 사례도 있는가 |
| 신체 경계 | 몸의 안팎·연속/분리를 다룰 수 있음 | 비신체 사물의 재질·경계 전환과 어떤 차이가 있는가 |
| 친밀성과 돌봄 | 온화함과 관계적 표현의 입구가 이미 있음 | 기계·생물의 돌봄만 있는가, 비의인화 사물의 역할 전환도 있는가 |
| 포스트휴먼 일상 | 일상 행동이라는 맥락이 이미 포함됨 | 일상의 낯섦이 포스트휴먼 외형 없이도 성립하는가 |

이 목록만으로 ‘일상이 없다’, ‘온화한 표현이 없다’, ‘기술 의존이 과반이다’라고 결론 내릴 수 없다. 특히 친밀성과 돌봄, 포스트휴먼 일상이라는 표제는 그 가설에 대한 반대 증거가 될 수 있다. 다만 실제 수록 방식은 확인해야 한다.

### 3.3 단어가 있는 것과 사용할 수 있는 관계가 있는 것

강도 0~3과 혼동되지 않도록 증거 상태를 문자로 구분한다.

| 코드 | 확보한 내용 | 예 |
| --- | --- | --- |
| L | 관련 키워드 | ‘거울’, ‘기억’, ‘dreamlike’ |
| R | 대상과 관계 | ‘실제 화분은 앙상하지만 같은 화분의 반사에는 꽃이 있다’ |
| E | 한 프레임 증거 설계 | 실제 가지·반사 가지의 분기 대응, 거울 테두리, 정상 반사되는 찻잔을 함께 보임 |
| V | 실제 생성·평가 결과 | 관찰자가 설명 없이 관계를 읽었고, 의도한 저술 역할도 확인됨 |

이번 후보는 **E 수준의 설계 초안**이다. 이미지가 생성되거나 검증되었다는 뜻은 아니다. 실제 코퍼스에서는 L/R/E/V를 각각 어떤 증거로 부여했는지 남겨야 한다.

182개 키워드 경로는 탐색 경로 수이지 독립적인 시각 원리 수가 아니다. 72개 후보가 12군에 균등하게 분포한다고 가정할 수도 없다. 같은 반사 불일치를 여러 이름과 소품으로 반복했다면 관계의 다양성은 그보다 적을 수 있다.

### 3.4 원본을 받았을 때 실제 공백을 확정하는 방법

1. 파일명·버전·해시와 대조 범위를 고정한다. 인접 리미널·드림코어 자료의 포함 범위를 명시한다.
2. 72개 후보를 모두 읽고, 안정적인 ID를 유지한 채 ‘대상—관계—현실 기준—필수 증거’로 정규화한다.
3. 16개 진단 기록이 오류·관찰 한계·강도 경계를 이미 다루는지 읽는다.
4. 182개 경로를 실제 후보 ID에 연결한다. 여러 경로가 같은 관계를 가리키면 독립 커버리지로 중복 계산하지 않는다.

## 4. 외부 근거에서 얻은 설계 판단

**[확인 사실]** Magritte의 Empire of Light에 대한 Peggy Guggenheim 설명은 낮 하늘과 밤 거리의 단일 결합 외에 다른 환상적 요소가 없다고 명시한다. **[해석]** 따라서 강한 초현실성이 많은 이상현상을 필요로 한다는 가정은 적절하지 않다. 작품의 실재는 설계 선례이며, 이번 0~3 평가척도의 실증 검증은 아니다. [S07](https://www.guggenheim-venice.it/en/art/works/empire-of-light/)

**[확인 사실]** Boijmans의 La reproduction interdite 연구 설명은 인물의 잘못된 반사와 책의 정상 반사를 함께 지적한다. **[해석]** 정상적인 대응을 남겨 두면 선택한 관계가 어디에서 어긋나는지 설계하기 쉽다. 모든 후보에 대조 소품을 의무적으로 더할 필요는 없으며, 이미 존재하는 문틀·가구·손·표면이 기준이 될 수 있다. [S02](https://www.boijmans.nl/en/collection/artworks/4232/la-reproduction-interdite)

### C01. 같은 화분의 다른 상태: 선택적 반사 불일치

**처리:** 기존 원리 정제 우선 / **순서:** 우선 시범 검토  
**축:** 공간·지각 대응, 대상의 동일성과 상태  
**적용 영역:** 사물, 자연, 일상 실내  
**예상 정서(미검증):** 서정성, 온화한 낯섦, 기대

**일반화한 시각 원리 — 해석**

반사면의 대부분은 정상적인 대상 대응을 유지하되, 선택된 대상의 상태만 바꾼다. 정상적으로 반사되는 주변 사물이 불일치를 판독하는 내부 기준이 된다.

**독자적으로 저술한 장면 — 한국어**

아침 햇빛이 드는 평범한 현관 선반에 가지가 거의 앙상한 작은 화분과 흰 찻잔이 놓여 있다. 바로 뒤의 벽거울에는 선반과 찻잔이 정확히 반사되지만, 같은 화분의 동일한 가지에는 작은 흰 꽃이 피어 있다. 실제 가지와 거울 속 가지의 굽은 형태와 갈라지는 위치가 서로 대응한다. 거울 테두리와 실제 화분의 전체가 함께 보인다.

**Independently authored scene — English**

On an ordinary entryway shelf in morning light stand a small, nearly bare potted branch and a white teacup. The wall mirror directly behind them reflects the shelf and cup accurately, but the same branch in the same pot carries small white blossoms in its reflection. The bends and branching points correspond clearly between the real branch and its reflected counterpart. Both the mirror frame and the entire real pot remain visible.

**일상적 기대에서 벗어나는 지점**

동일한 현재의 대상을 반사하는 거울에서는 가지의 개화 상태도 일치할 것이라는 기대가 선택적으로 어긋난다. 위반은 꽃이라는 소품 자체가 아니라 동일 대상으로 읽히는 실제상과 반사상 사이의 상태 대응에 있다.

**현실 기준**

- 정상적인 거울 테두리와 현관 선반
- 동일한 형태와 위치로 반사되는 찻잔
- 실제상과 반사상에서 대응하는 화분 모양 및 가지 분기 구조

**필요한 관계**

| --- | --- |
| 대상 | 선반 위 실제 화분과 가지 흰 찻잔 선반 뒤 벽거울 화분·가지·찻잔의 반사상 |
| 소유·동일성 | 거울 속 꽃은 실제 화분과 대응하는 반사 가지에 붙어 있으며 별도 화분이나 거울 표면 장식에 속하지 않는다. |
| 배치 | 실제 화분과 찻잔은 동일 선반 위에 놓이고 거울은 그 바로 뒤에 있다. 실제 가지와 반사 가지가 한 프레임에서 비교 가능한 간격으로 보인다. |

- 정상적으로 반사되는 찻잔
- 거울 테두리와 실제 선반

**정상 현상·장식·착시·오류와의 혼동**

- 거울처럼 보이는 창 뒤의 별도 화분
- 그림이나 화면을 거울로 오인하는 경우
- 거울 표면에 붙인 꽃 장식
- 대상 동일성이 무너진 반사 생성 오류

**정지 이미지에서 확인할 수 있는 것**

- 정상 반사 대조항과 가지 대응이 불일치를 의도된 관계로 읽게 하는지

**정지 이미지에서 확인할 수 없는 것**

- 거울이 과거 또는 미래를 보여 주는지
- 두 상태 사이에 실제 시간차가 있는지
- 화분이 실제로 개화하거나 회복하는 과정
- 장면이 관찰자에게 희망이나 그리움을 반드시 일으키는지

**기존 범위와의 중복·차이·보완 가치 — 원본 대조 전**

가까운 분류군: 이중 이미지와 지각 불일치, 재귀와 시간의 흔적.

기존 반사 불일치 후보가 있다면 새 원리라고 보기 어렵다. 이 제안의 보완 가치는 기술장치나 신체 변형 없이 자연물의 상태 한 가지만 바꾸고, 정상 반사 대조항과 대상 동일성의 증거를 구체화하는 데 있다. 시간 서사를 주장하지 않는 점도 정제 요소다.

반영 규칙: 원본에 선택적 반사 불일치와 정상 대조항이 모두 있으면 해당 후보의 일상·온화한 변형으로 재사용한다. 반사 키워드만 있거나 동일 대상의 증거가 없으면 그 기록을 정제한다. 원리 자체가 없을 때에만 신규 후보로 추가한다.

[S02 — René Magritte — La reproduction interdite, 1937](https://www.boijmans.nl/en/collection/artworks/4232/la-reproduction-interdite)

| 접촉 | 뺨이 베개의 완만한 오목한 부위에 닿는다. 베개 아래쪽은 침대 표면에 놓인다. |
| 상태 | 베개는 돌처럼 거친 표면과 두께를 보인다. 접촉 부위는 부드럽게 눌린 형태로 보이며 가장자리는 접혀 있다. 신체는 정상적인 형태이고 다치거나 눌려 변형되지 않는다. |
| 경계 | 뺨과 베개의 경계가 선명하다. 광물 표면이 접촉 부위와 접힌 가장자리에서도 같은 대상의 표면으로 이어진다. |

**한 프레임의 핵심 증거**

- 베개의 거친 광물 표면
- 뺨과 맞닿은 오목한 형태
- 부드럽게 접힌 가장자리
- 정상적인 침구와 인물

**정상 현상·장식·착시·오류와의 혼동**

- 돌무늬가 인쇄된 천 베개
- 발포체나 고무로 만든 소품
- 미리 사람 머리 모양으로 조각한 돌
- 재질이 일관되지 않게 생성된 오류
- 인물이 닿지 않아 변형과 사용 관계를 연결할 수 없는 구도

**정지 이미지에서 확인할 수 있는 것**

- 돌처럼 읽히는 표면과 부드러움으로 읽히는 형태가 함께 보이는지
- 뺨의 접촉과 오목한 부분이 일관되게 대응하는지
- 신체를 변형하지 않고 물건 쪽 관계에만 낯섦이 집중되는지

**정지 이미지에서 확인할 수 없는 것**

- 베개의 실제 경도나 재료
- 머리의 무게가 실제로 베개를 변형시켰는지
- 접촉 전후의 변화
- 편안함·온도·촉감을 실제로 느끼는지

**기존 범위와의 중복·차이·보완 가치 — 원본 대조 전**

가까운 분류군: 사물의 전이와 병치, 신체 경계, 친밀성과 돌봄.

기존 자료에 비정상 재질 후보가 있다면 원리 중복 가능성이 높다. 이 제안은 신체 접합이나 생체 개조 없이 평범한 사용 관계에 재질·형태 기대의 충돌을 집중하고, 무늬 장식과 구분할 관찰 증거를 제공한다.

반영 규칙: 원본에 동일한 재질·물성 충돌과 사용 증거가 있으면 장면 변형으로 재사용한다. 재질 이름만 있고 접촉·상태 관계가 없으면 해당 기록을 정제한다. 재질 축에 이 원리가 없을 때에만 신규 추가한다.

**출처가 실제로 뒷받침하는 내용**


[S03 — Meret Oppenheim — Object, Paris, 1936](https://www.moma.org/collection/works/80997)

- 확인 사실: MoMA는 Meret Oppenheim의 Object(Paris, 1936)를 털로 덮은 찻잔·받침·숟가락으로 기록하며, 촉각적 매력과 마시는 용도 사이의 충돌을 설명한다.
- 일반화·해석: 물체의 익숙한 사용 기대와 부여된 재질의 감각적 기대를 충돌시키는 일반 원리로 확장했다.
- 뒷받침하지 않는 것: 출처는 화강암 베개나 변형되는 돌의 존재, 이 장면의 정확한 형태, 실제 물성 또는 이미지 생성 성능을 뒷받침하지 않는다. 베개 장면과 접촉 형태는 독자적으로 저술했다.


### C03. 빈 의자를 무릎에 앉혀 돌보기

**처리:** 기존 원리 정제 우선 / **순서:** 우선 시범 검토  
**축:** 행동·의미, 분위기  
**적용 영역:** 인물, 사물  
**예상 정서(미검증):** 온화함, 담담한 유머, 친밀함, 조용한 낯섦

**일반화한 시각 원리 — 해석**

사물을 사용하는 행동 대신 보살피는 행동을 부여하여, 몸의 변형이나 사물의 얼굴 없이 행위의 수신자와 사회적 역할을 바꾼다.

**독자적으로 저술한 장면 — 한국어**

햇볕이 드는 평범한 거실. 소파에 앉은 성인이 작은 빈 나무 의자를 무릎 위에 앉히고, 한 손으로 의자 등받이를 조심스럽게 감싸며 다른 손으로 좌판 아래를 받친다. 의자의 네 다리와 비어 있는 좌판이 모두 보인다. 인물은 과장된 표정 없이 의자를 내려다본다. 자연스러운 피부와 목재 질감, 담담한 생활 사진의 구도.

**Independently authored scene — English**

In an ordinary sunlit living room, an adult seated on a sofa holds a small, empty wooden chair on their lap, gently cradling its back with one hand and supporting the underside of its seat with the other. All four chair legs and the empty seat remain visible. The person looks down at the chair without an exaggerated expression. Natural skin and wood textures, composed with the quiet restraint of an everyday domestic portrait.

**일상적 기대에서 벗어나는 지점**

사람이 의자에 앉거나 의자를 옮기는 통상적 관계가, 사람이 의자를 자기 무릎에 앉혀 보살피는 관계로 바뀐다. 물리적으로 불가능한 장면은 아니며, 초현실성은 행동의 사회적 의미가 대상과 어긋나는 데서 발생한다.

**현실 기준**

- 성인의 자연스러운 신체와 생활복
- 목재 의자의 알아볼 수 있는 구조
- 소파에 체중을 실은 정상적인 앉은 자세
- 일관된 중력과 실내 햇빛
- 돌봄 자세를 판독할 수 있는 손과 시선

**필요한 관계**

| 항목 | 조건 |
| --- | --- |
| 대상 | 성인 한 명 몸통이나 얼굴이 없는 작은 목재 의자 한 개 성인이 앉아 있는 일반 소파 |
| 소유·동일성 | 두 손과 시선은 같은 성인에게 속한다. 작은 의자의 등받이·좌판·네 다리는 한 물체의 구조다. 의자 좌판에는 별도의 사람·동물·인형이 없다. |
| 배치 | 작은 의자는 성인의 무릎 위에 놓인다. 좌판의 빈 공간이 카메라를 향해 드러난다. 인물의 얼굴과 의자 사이를 손이나 다른 물체가 완전히 가리지 않는다. |
| 접촉 | 성인의 한 손이 의자 등받이를 감싼다. 다른 손이 좌판 아래를 받친다. 의자와 성인의 무릎이 닿아 정상적으로 지지된다. |
| 상태 | 의자는 비어 있고 정상적인 목재 상태다. 인물은 의자를 옮기느라 힘주는 작업 자세보다 정적인 돌봄 자세를 취한다. 의자 자체의 생명이나 움직임은 설정하지 않는다. |
| 경계 | 인물의 몸과 의자의 목재 경계는 분명하다. 손가락이 목재에 융합되거나 의자 다리가 인물의 다리로 이어지지 않는다. |

**한 프레임의 핵심 증거**

- 성인이 소파에 앉아 있다는 정상적 신체 지지
- 무릎 위 의자의 비어 있는 좌판
- 의자 전체가 하나의 물체임을 보여 주는 등받이와 다리
- 부축하는 두 손과 의자를 향하는 시선

**정상 현상·장식·착시·오류와의 혼동**

- 이사나 수리 중 의자를 잠시 들어 둔 모습으로 읽힐 수 있다.
- 가구 광고나 단순한 장난 포즈로 읽힐 수 있다.
- 의자 크기가 지나치게 작으면 장난감을 든 평범한 장면으로 읽힐 수 있다.
- 좌판이 가려지면 실제 아이나 동물을 안은 장면으로 오해할 수 있다.
- 손·의자 다리의 비정상적 결합은 의도한 역할 전환 대신 생성 오류를 강조할 수 있다.

**정지 이미지에서 확인할 수 있는 것**

- 성인·의자·소파의 배치와 접촉
- 비어 있는 좌판
- 돌봄을 연상시키는 손의 위치와 시선
- 사물이 사람의 무릎에 놓인 역할 전환

**정지 이미지에서 확인할 수 없는 것**

- 의자가 실제로 살아 있거나 감정을 느낀다는 주장
- 인물이 실제로 애착을 느끼거나 의자를 달래고 있다는 내적 상태
- 이 자세 이전과 이후의 행동
- 온화함이나 유머가 모든 관객에게 같은 정도로 전달된다는 주장

**기존 범위와의 중복·차이·보완 가치 — 원본 대조 전**

가까운 분류군: 친밀성과 돌봄, 포스트휴먼 일상, 사물의 전이와 병치.

제공된 관계군 이름만 보면 돌봄군과 중복 가능성이 높다. 보완 가치는 기계·케이블·인공 신체나 사물의 얼굴을 시각적 의미에 사용하지 않고, 정상적인 인물과 물체의 취급 관계만 바꾼다는 데 있다. 실제 제작에 도구가 쓰이지 않았다는 주장은 아니다.

반영 규칙: 기존에 비생물 사물을 생명체처럼 돌보는 장면과 손·시선·빈자리 증거가 있으면 그 후보를 재사용한다. 같은 원리는 있으나 기술적 외형이나 의인화에 의존한다면 비기술적 변형으로 정제한다. 원본 확인 전 별도의 완전 신규 원리로 세지 않는다.

**출처가 실제로 뒷받침하는 내용**


[S04 — One Minute Sculptures](https://www.erwinwurm.com/artworks/one-minute-sculptures)

- 확인 사실: Wurm 공식 One Minute Sculptures 설명은 단순 소품과 자세 지시를 통해 참여자와 사물 사이에 어색하거나 역설적인 관계를 만든다고 명시한다.
- 일반화·해석: 외형을 기괴하게 바꾸지 않아도 몸과 물체의 사용 관계만으로 일상적 기대를 바꿀 수 있다는 일반 원리로 해석했다.
- 뒷받침하지 않는 것: 빈 의자를 무릎에 앉혀 돌보는 이 장면이 Wurm의 특정 작품이라는 주장, 이 장면의 정서나 surreal 강도가 검증되었다는 주장.


[S05 — Erwin Wurm: One Minute Sculptures, 2016 전시](https://www.makcenter.org/exhibitions/erwin-wurm-one-minute-sculptures)

- 확인 사실: MAK Center의 Wurm 전시 설명은 일상 물체의 바뀐 용도, 균형 잡기, 가벼운 몸의 변형, 맥락과 지각을 다룬다.
- 일반화·해석: 행동의 용도 전환과 일상적인 환경이 함께 있을 때 생기는 의미의 어긋남을 후보 저술에 적용했다.
- 뒷받침하지 않는 것: 제안한 돌봄 동작의 정확한 형태, 의자의 생명, 관객이 느낄 온화함이나 유머의 정도.


### C04. 안쪽 손잡이로 드는 찻잔

**처리:** 미수록일 때 신규 검토 / **순서:** 우선 시범 검토  
**축:** 공간·경계, 행동·의미  
**적용 영역:** 사물, 인물  
**예상 정서(미검증):** 일상적인 낯섦, 담담한 유머, 작은 기능적 모순

**일반화한 시각 원리 — 해석**

사물의 익숙한 형태를 유지하면서 사용을 가능하게 하는 부분의 안팎 위치를 바꾸고, 그 부분을 실제로 사용하는 자세를 보여 준다.

**독자적으로 저술한 장면 — 한국어**

아침 식탁의 빈 흰 도자기 찻잔. 바깥 벽에는 손잡이가 없고, 완전한 고리 모양의 손잡이 하나가 잔 안쪽 벽에 두 군데로 붙어 있다. 성인이 잔 안쪽 고리에 검지를 걸어 잔을 조금 들어 올린다. 매끈한 바깥 벽, 안쪽 손잡이의 두 접합점, 손가락의 접촉을 함께 볼 수 있는 높은 사선 구도. 나머지 형태와 도자기 유약은 평범하고 자연스럽다.

**Independently authored scene — English**

An empty white porcelain teacup is held just above a breakfast table. Its outer wall has no handle; a complete loop-shaped handle is attached at two points to the inside wall instead. An adult hooks one index finger through the inner loop to lift the cup. A high oblique view shows the smooth exterior, both attachment points of the internal handle, and the finger's contact. The rest of the cup's shape and glazed ceramic surface look entirely ordinary.

**일상적 기대에서 벗어나는 지점**

찻잔을 알아보게 하는 일반적인 비례·재질은 유지되지만, 통상 외부에 있는 손잡이가 내부에 있고 손도 잔 안으로 들어가야 한다. 실제 제작이 가능한 물체이므로 물리적 불가능성보다 사용 기대와 안팎 구분의 충돌을 다룬다.

**현실 기준**

- 일반 찻잔의 크기와 윤곽
- 일관된 흰 도자기 유약과 벽 두께
- 정상적인 손가락 해부학
- 식탁과 컵 바닥 사이의 작은 간격
- 손잡이의 기능을 읽게 하는 실제 사용 동작

**필요한 관계**

| 항목 | 조건 |
| --- | --- |
| 대상 | 빈 도자기 찻잔 한 개 찻잔에 일체로 부착된 내부 손잡이 한 개 성인의 한 손 평범한 식탁 |
| 소유·동일성 | 손잡이는 다른 물체가 아니라 해당 찻잔의 내벽에 속한다. 검지는 성인의 한 손에 정상적으로 이어진다. |
| 배치 | 손잡이는 잔의 내부 공간 안에 있다. 찻잔은 식탁 위에서 약간 들려 있다. 카메라 높이는 잔의 안쪽과 바깥쪽을 동시에 보여 준다. |
| 접촉 | 고리 손잡이의 두 끝이 같은 잔의 내벽에 부착된다. 검지가 고리의 빈 공간을 통과해 손잡이를 건다. |
| 상태 | 잔은 비어 있다. 외부에는 다른 손잡이가 없다. 손잡이는 완결된 고리이며 깨지거나 녹아 있지 않다. 음료의 온도나 열에 대한 설명은 필요하지 않다. |
| 경계 | 손가락·고리·컵 내벽 사이의 틈이 구분된다. 내부 손잡이가 컵 벽을 관통해 외부로 나가지 않는다. 컵의 일반적인 안팎 표면과 가장자리는 식별 가능하다. |

**한 프레임의 핵심 증거**

- 매끈하고 손잡이가 없는 외벽
- 내벽에 붙은 하나의 완전한 고리
- 고리의 두 접합점
- 고리를 통과해 잔을 들어 올리는 검지
- 컵의 테두리와 바닥 위치

**정상 현상·장식·착시·오류와의 혼동**

- 기발한 제품 디자인이나 실제 도자기 작품으로 읽힐 수 있다.
- 잔 안에 별도의 작은 컵을 넣은 것으로 오인할 수 있다.
- 높은 사선 시점이 확보되지 않으면 외부 손잡이가 원근 때문에 안쪽에 보이는 착시로 읽힐 수 있다.
- 불완전한 고리나 벽을 관통한 손가락은 생성 오류처럼 보일 수 있다.
- 이상한 디자인임을 알아보는 것만으로 사진 전체의 초현실성이 분명해졌다고 판정해서는 안 된다.

**정지 이미지에서 확인할 수 있는 것**

- 손잡이의 안쪽 위치와 내벽의 두 접합점
- 프레임에 보이는 외벽에는 외부 손잡이가 나타나지 않는다는 점
- 손가락이 내부 고리를 사용하는 접촉
- 형태와 용도 사이의 시각적 어긋남

**정지 이미지에서 확인할 수 없는 것**

- 이 컵이 실제로 제작 불가능하다는 주장
- 사용자가 느끼는 불편함이나 불쾌함의 정도
- 컵의 열이나 실제 무게
- 관객에게 반드시 초현실적으로 읽힌다는 주장
- 카메라에서 보이지 않는 뒤쪽에 다른 손잡이나 구조가 전혀 없다는 사실

**기존 범위와의 중복·차이·보완 가치 — 원본 대조 전**

가까운 분류군: 사물의 전이와 병치, 이중 이미지와 지각 불일치.

소품의 존재만 바꾸지 않고, 동일 사물에 속한 기능 부분의 위치와 그것을 사용하는 손의 관계를 함께 지정한다. 일상 속 약한 초현실을 만들 가능성이 있으나 단순한 디자인 변형으로 읽힐 위험도 함께 검증해야 한다.

반영 규칙: 기존에 내부·외부 기능 부분 전환을 같은 사용 동작과 함께 명시한 후보가 있으면 재사용하거나 정제한다. 그러한 실행 가능한 관계가 없을 때만 신규 세부 후보로 추가한다. 키워드만 유사한 경우에는 관계 증거의 유무를 따로 확인한다.

**출처가 실제로 뒷받침하는 내용**


[S01 — Madoz. Objetos 1990–1999](https://www.museoreinasofia.es/en/exhibition/madoz-objetos-1990-1999/)

- 확인 사실: Reina Sofía의 Madoz 전시 설명은 일상 사물의 그대로인 상태·조작·제작, 형식적·상징적 유비, 대립하는 의미의 결합과 사실적인 사물의 존재감을 설명한다.
- 일반화·해석: 익숙한 사물의 정체성을 보존하면서 기능적 관계를 한 군데 바꾸는 방법으로 일반화했다.
- 뒷받침하지 않는 것: 안쪽 손잡이 컵이 Madoz의 특정 작품이라는 주장, 이 컵이 물리적으로 불가능하다는 주장, 제안 장면의 surreal 강도나 생성 성공률.


### C05. 식탁 위의 작은 날씨

**처리:** 기존 원리 정제 우선 / **순서:** 우선 시범 검토  
**축:** 공간·내외부 맥락, 환경·분위기  
**적용 영역:** 자연 현상, 인물, 일상 실내  
**예상 정서(미검증):** 서정성, 온화함, 작은 경이

**일반화한 시각 원리 — 해석**

보통 넓은 외부 환경에 속하는 현상을 일상적인 실내의 한정된 자리에 놓아 장소에 대한 기대를 바꾼다. 주변 생활과 건축은 그대로 유지하여 하나의 현상과 장소 사이의 관계가 낯섦을 만든다.

**독자적으로 저술한 장면 — 한국어**

햇빛이 드는 작은 식당에서 성인이 식탁의 한쪽에 앉아 신문을 읽는다. 비어 있는 맞은편 자리 위에는 사람 머리보다 조금 큰 흰 구름 하나가 테이블과 천장 사이에 떠 있다. 구름의 가장자리는 반투명하고 불규칙하며, 구름 아래 테이블은 말라 있고 주변 공기는 맑다. 인물은 평소처럼 아침 시간을 보낸다. 구름과 테이블, 구름과 천장 사이의 빈 공간이 모두 보인다.

**Independently authored scene — English**

In a small sunlit dining room, an adult reads a newspaper at one end of the table. Above the empty seat opposite floats a single white cloud slightly larger than a human head, separated from both table and ceiling. Its edges are irregular and translucent; the tabletop below is dry and the surrounding air is clear. The reader continues an ordinary morning routine. Open space is visible both below and above the cloud.

**일상적 기대에서 벗어나는 지점**

외부 날씨의 일부로 기대되는 구름이 생활 공간 안에서 독립된 자리를 차지한다. 장면의 의미에 기계·케이블·인공 신체가 필요하지 않으며, 이것은 실제 제작 과정에서 장치를 사용하지 않는다는 주장이 아니다.

**현실 기준**

- 익숙한 크기의 식탁·의자·신문·성인
- 일반적인 실내 천장과 벽
- 마른 테이블과 맑은 주변 공기
- 구름에 과도하게 반응하지 않는 일상 행동

**필요한 관계**

| 항목 | 조건 |
| --- | --- |
| 대상 | 신문을 읽는 성인 식탁과 의자 실내의 흰 구름 벽과 천장 |
| 소유·동일성 | 별도의 조건 없음 |
| 배치 | 구름은 맞은편 빈자리 위, 테이블과 천장 사이의 공중에 있다. 인물은 식탁의 다른 쪽에 앉아 있다. |
| 접촉 | 별도의 조건 없음 |
| 상태 | 구름은 반투명하고 불규칙한 가장자리를 가진다. 주변 공기는 맑고 구름 아래 테이블은 말라 있다. 인물은 신문을 읽는다. |
| 경계 | 구름과 천장·테이블 사이에 빈 공간이 보인다. 구름의 경계와 실내 건축의 경계가 구분된다. |

**한 프레임의 핵심 증거**

- 명확한 실내 공간의 벽과 천장
- 실내 공중에 국소적으로 모인 구름 같은 덩어리
- 구름의 위아래 빈 공간
- 평범한 식탁과 일상 행동

**정상 현상·장식·착시·오류와의 혼동**

- 뜨거운 음식이나 주전자의 수증기
- 무대 연기 또는 안개
- 솜 장식
- 구름 모양의 천장 조명
- 구름과 천장이 이어져 걸린 물건처럼 보이는 구도
- 사진상 보이지 않는 장치를 사용한 실제 연출

**정지 이미지에서 확인할 수 있는 것**

- 구름처럼 보이는 국소적 현상이 실내의 특정 위치를 차지하는지
- 생활 공간과 구름의 크기·거리 관계
- 주변의 정상적인 일상과 대비되는 정도

**정지 이미지에서 확인할 수 없는 것**

- 구름의 실제 구성 물질
- 떠 있는 상태의 지속 시간
- 구름의 생성·소멸·이동 과정
- 장치 없이 만들어졌는지
- 그 집에 항상 존재하거나 인물을 따르는 구름인지

**기존 범위와의 중복·차이·보완 가치 — 원본 대조 전**

가까운 분류군: 사물의 전이와 병치, 규모와 포함 세계, 인접 리미널·드림코어.

구름이나 실내 자연 현상이 이미 있다면 소품 수준의 신규성은 낮다. 보완 가치는 환경 현상의 장소 불일치를 일상적 규모로 명시하고, 위아래 빈 공간·마른 표면·일상 행동처럼 판독 가능한 관계를 제공하는 데 있다.

반영 규칙: 원본에 환경 현상의 실내 전이와 필수 공간 증거가 있으면 그대로 재사용하거나 강도 변형에 쓴다. 구름·몽환 같은 키워드만 있으면 관계를 정제한다. 해당 원리가 없을 때에만 신규 추가한다.

**출처가 실제로 뒷받침하는 내용**


[S06 — Nimbus](https://www.berndnaut.nl/works/nimbus/)

- 확인 사실: Berndnaut Smilde의 공식 Nimbus 페이지는 특정 장소에서 수초간 존재했다가 사라지는 구름 작업과, 최종적으로 사진이 그 순간의 기록으로 남는다는 성격을 설명한다. 페이지에는 Nimbus De.Groen(2017), Nimbus De Toekomst(2019), Nimbus Roebourne(2017)이 명시되어 있다.
- 일반화·해석: 환경 현상이 예상 밖의 장소에 출현하는 관계와, 정지사진이 일시적 존재를 기록한다는 점을 일반화했다.
- 뒷받침하지 않는 것: 출처는 식당·신문 독서 장면, 그 장면의 온화한 감정 효과, 장치를 전혀 쓰지 않는 제작, 지속적인 공중 부유 또는 실제 불가능 현상을 입증하지 않는다. 식탁 장면은 독자 제안이다.


### C06. 낮 하늘 아래 밤처럼 남은 거리

**처리:** 미수록일 때 신규 검토 / **순서:** 후속 시범 검토  
**축:** 환경·분위기, 동시적 상태의 불일치  
**적용 영역:** 건축, 자연 환경, 인물, 일상 거리  
**예상 정서(미검증):** 고요함, 경이, 낯섦, 약한 불안

**일반화한 시각 원리 — 해석**

각각은 평범한 환경 조건이지만, 같은 장소에서 함께 보일 때 서로 맞지 않는 낮·밤의 인상을 결합한다. 별도의 불가능 사물 없이 하나의 환경 관계가 장면 전체의 해석을 바꾼다.

**독자적으로 저술한 장면 — 한국어**

접은 세탁물을 든 성인이 조용한 주택가 골목 입구에 서 있다. 머리 위에는 정오처럼 밝은 푸른 하늘과 흰 구름이 펼쳐져 있지만, 골목의 집들과 길은 깊은 밤의 조도로 남아 있고 가로등과 몇 개의 창문만 빛난다. 하늘과 집의 지붕선은 하나의 이어진 외부 공간으로 보인다. 인물은 이 모순에 놀라지 않고 평범하게 집으로 돌아가는 중이다.

**Independently authored scene — English**

An adult carrying folded laundry stands at the entrance to a quiet residential lane. Above is a bright blue midday sky with white clouds, while the houses and street retain the illumination of deep night, lit only by a streetlamp and a few windows. The sky and rooflines form one continuous outdoor setting. The person treats the scene as an ordinary walk home.

**일상적 기대에서 벗어나는 지점**

동일한 외부 공간의 하늘과 지상 환경이 대체로 같은 시간대의 조명 조건을 공유할 것이라는 기대가 어긋난다. 이 후보는 낮·밤 인상의 동시적 불일치를 목표로 하며, 실제로 두 시간이 공존한다는 물리적 확증을 목표로 하지 않는다.

**현실 기준**

- 평범한 주택 지붕선과 골목
- 하늘과 건물이 연속되는 하나의 외부 공간
- 일상적인 가로등과 창문 조명
- 평범한 귀가 행동

**필요한 관계**

| 항목 | 조건 |
| --- | --- |
| 대상 | 밝은 낮 하늘과 구름 골목의 집들과 길 가로등과 창문 조명 세탁물을 든 성인 |
| 소유·동일성 | 하늘과 골목은 하나의 외부 장면에 속하며 별도 그림·화면·액자에 속하지 않는다. |
| 배치 | 하늘은 같은 골목의 지붕선 위에 연속적으로 보인다. 인물은 골목 입구에 있다. |
| 접촉 | 별도의 조건 없음 |
| 상태 | 하늘은 밝은 정오처럼 읽힌다. 지상 공간은 한밤처럼 어둡고 인공조명이 주요 밝은 부분을 만든다. |
| 경계 | 지붕선과 하늘의 경계는 정상적인 외부 공간의 경계이며 화면 삽입의 테두리처럼 보이지 않는다. |

**한 프레임의 핵심 증거**

- 낮으로 읽히는 밝은 하늘과 흰 구름
- 밤으로 읽히는 지상 공간 및 인공조명
- 둘을 같은 장소로 연결하는 지붕선과 거리
- 초현실적 물건에 의존하지 않는 평범한 건축과 인물

**정상 현상·장식·착시·오류와의 혼동**

- 깊은 그늘
- 강한 역광
- 노출 부족
- 황혼이나 특수한 기상
- HDR 또는 합성 사진의 노출 불일치
- 밝은 하늘 광고판이나 배경막
- 단순히 어두운 거리 사진으로 읽히는 경우

**정지 이미지에서 확인할 수 있는 것**

- 낮과 밤의 상반된 환경 인상이 같은 프레임에서 함께 읽히는지
- 관찰자가 이 관계를 장면의 중심적 인상으로 언급하는지
- 단순한 그늘·역광 해석이 우세한지

**정지 이미지에서 확인할 수 없는 것**

- 실제 시간대가 두 개 공존하는지
- 하늘과 지상의 시간 흐름이 다른지
- 촬영 노출·합성·조명 설치의 실제 방식
- 특정 감정이나 강도 등급이 모든 관찰자에게 동일하게 발생하는지

**기존 범위와의 중복·차이·보완 가치 — 원본 대조 전**

가까운 분류군: 재귀와 시간의 흔적, 이중 이미지와 지각 불일치, 인접 리미널·드림코어.

기존 시간 후보가 기억·잔상·재귀에 집중되어 있다면, 과거·미래 서사를 요구하지 않는 동시적 환경 조건의 충돌을 보완한다. 다만 리미널·드림코어에 동일한 조명 불일치 관계가 이미 있을 수 있어 신규성은 확정하지 않는다.

반영 규칙: 원본에서 하늘·지상의 시간대 인상 불일치가 이미 구체적 관계로 표현되어 있으면 재사용한다. 어두운 거리·몽환 분위기 같은 단어만 있으면 구별되는 관계로 정제한다. 원리가 없을 때에만 신규 추가한다.

**출처가 실제로 뒷받침하는 내용**


[S07 — René Magritte — Empire of Light, 1953–54 소장판](https://www.guggenheim-venice.it/en/art/works/empire-of-light/)

- 확인 사실: Peggy Guggenheim Collection은 René Magritte의 Empire of Light 소장판을 1953–54년으로 기록한다. 공식 설명은 밝은 낮 하늘과 어두운 밤 거리를 결합하며, 이 단일한 낮·밤 결합 이외에 다른 환상적 요소가 없다는 점을 명시한다.
- 일반화·해석: 하나의 관계만으로 장면 전체의 초현실적 인상을 이끌 수 있고, 강도를 이상현상 개수로 정의하면 안 된다는 설계에 참고했다.
- 뒷받침하지 않는 것: 출처는 새로 제안한 세탁물·귀가 장면, 생성 이미지에서의 강도 등급, 실제 두 시간의 공존, 모든 관찰자의 동일한 인상 또는 낮·밤 사진 판독의 신뢰도를 입증하지 않는다.


### C07. 도로에서 들려 천처럼 접히는 흰 줄

**처리:** 정상 현상 구분 전 보류 / **순서:** 보류  
**축:** 공간·경계, 재질, 행동·의미  
**적용 영역:** 건축·도시공간, 사물  
**예상 정서(미검증):** 조용한 낯섦, 가벼운 유머, 작은 경이로움

**일반화한 시각 원리 — 해석**

바닥을 구분하는 표면의 표시가 원래 위치와의 연속성을 유지한 채 두께·처짐을 가진 독립된 대상으로 바뀐다.

**독자적으로 저술한 장면 — 한국어**

흐린 아침의 조용한 주택가 횡단보도. 흰색 줄 하나는 거친 아스팔트에 평평하게 칠해져 있지만, 그 줄의 한쪽 끝만 도로에서 벗어나 얇은 천처럼 낮게 접힌 채 보도 가장자리에 걸쳐 있다. 바닥에 붙은 구간부터 들린 구간까지 같은 흰 줄이 끊김 없이 이어진다. 들린 끝의 얇은 단면과 그 아래의 작은 그림자가 보이며, 나머지 도로와 보도는 평범하다.

**Independently authored scene — English**

At a quiet residential crosswalk on an overcast morning, one white stripe lies flat on rough asphalt, but its far end lifts away from the road and folds like thin cloth over the curb. The same white stripe remains visibly continuous from the section attached to the ground to the raised section. Its thin edge and the small shadow underneath are visible, while the rest of the road and pavement remain ordinary.

**일상적 기대에서 벗어나는 지점**

공간을 구분하는 평면 표시가 독립 물체의 접힘과 처짐을 얻는다. 다만 실제 도로 표시 테이프나 박리된 도료로 설명될 가능성이 높아, 그 해석이 우세하면 초현실 관계가 충분히 전달되지 않은 것으로 판단한다.

**현실 기준**

- 알아볼 수 있는 일반 횡단보도
- 거친 아스팔트 입자
- 평범하게 부착된 나머지 흰 줄
- 일반적인 보도 경계석과 도로 높이
- 일관된 흐린 아침의 빛

**필요한 관계**

| 항목 | 조건 |
| --- | --- |
| 대상 | 횡단보도 흰 줄 한 개의 부착 구간과 들린 끝 아스팔트 도로 보도 가장자리와 경계석 |
| 소유·동일성 | 들린 부분은 별도의 천 조각이 아니라 도로에 붙은 동일한 흰 줄의 연장이다. |
| 배치 | 줄의 한쪽은 도로 표면에 붙어 있다. 연속된 다른 끝은 낮게 들려 보도 가장자리에 걸쳐 있다. 표시가 붙은 상태에서 들린 상태로 바뀌는 지점이 프레임 안에 있다. |
| 접촉 | 부착 구간과 아스팔트가 닿아 있다. 들린 끝 일부는 보도 가장자리에 닿을 수 있다. 중간의 들린 부분 아래에는 도로와의 간격이 보인다. |
| 상태 | 같은 줄에 평평한 표시 상태와 천 같은 접힘 상태가 공존한다. 주변 도로에는 수리 작업이나 다른 변형을 추가하지 않는다. 줄이 움직이거나 살아 있다고 설정할 필요가 없다. |
| 경계 | 붙은 구간과 들린 구간 사이의 연속성 들린 끝의 얇은 단면 줄과 바닥 사이의 빈 공간과 그림자 줄이 시작부터 별도의 매트였다고 읽히게 만드는 두꺼운 외곽은 피한다. |

**한 프레임의 핵심 증거**

- 횡단보도임을 식별할 수 있는 일반적인 주변 줄
- 바닥에 붙은 구간부터 들린 끝까지의 연속
- 변환이 일어나는 경계
- 들린 부분의 접힘·단면·아래 그림자
- 아스팔트와 보도 높이의 현실 기준

**정상 현상·장식·착시·오류와의 혼동**

- 정상적인 도로 표시 테이프의 들뜸이나 수리 현상일 수 있다.
- 실제 도료의 박리나 얇은 필름의 접힘으로 읽힐 수 있다.
- 횡단보도 위에 놓은 천이나 고무 매트일 수 있다.
- 거리 설치미술이나 장식으로 읽힐 수 있다.
- 전환부가 끊기거나 두꺼워지면 단순 소품으로 보일 수 있다.
- 접힘이 매우 작으면 정상적인 균열·박리와 구별하기 어렵다.
- 의도된 변화가 아니라 도로 형태의 생성 오류로 읽힐 수 있다.

**정지 이미지에서 확인할 수 있는 것**

- 줄의 연속성
- 붙은 부분과 들린 부분의 공존
- 접힘·단면·그림자
- 주변의 정상적인 도로 표시와 대비

**정지 이미지에서 확인할 수 없는 것**

- 흰색 부분의 실제 재료가 도료인지 테이프인지 천인지
- 표시가 실제로 재질 변화를 일으켰다는 주장
- 줄이 스스로 들렸거나 움직였다는 인과·과정
- 숨은 지지나 거리 설치물이 없다는 주장

**기존 범위와의 중복·차이·보완 가치 — 원본 대조 전**

가까운 분류군: 사물의 전이와 병치, 이중 이미지와 지각 불일치.

다른 사물 하나를 거리 위에 놓는 병치와 달리, 원래 배경에 속한 경계 표시가 독립 대상이 되는 연속 관계를 명시한다. 다만 실제 보수·박리 현상과의 구별이 약하므로 먼저 진단 대상으로 보류할 가치가 있다.

반영 규칙: 기존에 배경 표시가 독립 물체로 전환되며 연속 경계를 보이는 후보가 있으면 정제 또는 재사용한다. 없다면 신규 추가 전 일반 도로 테이프·박리 사진에 준하는 정상 대조와 비교한다. 관객의 주된 설명이 도로 수리이면 신규 초현실 후보 승격을 보류한다.

**출처가 실제로 뒷받침하는 내용**


[S08 — Road Line](https://andygoldsworthystudio.com/road-line/)

- 확인 사실: Goldsworthy 공식 Road Line 페이지의 2021년 10월 제안문 발췌는 도로의 경계석 한 줄이 도로에서 갈라져 캠퍼스를 지나는 연속선이 되고, 도로에서 떨어져 그림·길·여정으로 읽히는 발상을 설명한다.
- 일반화·해석: 원래 다른 공간을 구분하던 기능적 선이 자체적으로 주목받는 대상이 된다는 역할 전환을 일반화했다.
- 뒷받침하지 않는 것: Goldsworthy가 흰 도로 표시를 천처럼 변형한 작품을 만들었다는 주장, 화강석이나 도료의 실제 재질 변화, 위 장면의 정확한 형태. 제안문의 날짜를 완공 연도로 확정하지 않는다.


[S16 — Pavement Marking Handbook — Preformed Tapes: Application](https://www.txdot.gov/manuals/trf/pmh/material_selection/pavement_marking_material_descriptions-i1020814/preformed_tapes__application.html)

- 확인 사실: TxDOT 공식 설명은 노면표시 테이프를 접착제로 노면에 붙이는 방식과 접착 실패 가능성을 기술한다.
- 일반화·해석: 흰 줄의 단순 들뜸과 접힘은 정상적인 재료·보수 상황일 수 있어 초현실 관계의 충분한 증거로 취급하지 않는다.
- 뒷받침하지 않는 것: 모든 횡단보도가 테이프라는 주장, 한국의 특정 노면표시 공법, 이 새 장면의 실제 재료를 확정하는 주장.


### C08. 가는 풀잎 끝에 얹힌 조약돌

**처리:** 미수록일 때 신규 검토 / **순서:** 후속 시범 검토  
**축:** 인과·지지, 재질, 크기  
**적용 영역:** 자연  
**예상 정서(미검증):** 온화한 경이로움, 작은 부조리, 고요함

**일반화한 시각 원리 — 해석**

접촉은 분명히 보여 주되, 가늘고 유연해 보이는 지지체가 상대적으로 큰 단단한 물체를 거의 처짐 없이 떠받치게 하여 물성에 따른 지지 기대와 충돌시킨다.

**독자적으로 저술한 장면 — 한국어**

평범한 길가의 풀포기에서 가느다란 풀잎 하나가 길게 수평으로 뻗어 있다. 그 끝에는 잎 폭의 여러 배에 이르는 둥근 조약돌 하나가 얹혀 있지만, 돌 바로 아래의 잎은 거의 처지지 않는다. 같은 풀포기의 다른 잎은 자연스럽게 휘어 있다. 낮은 측면 사선 구도로 돌과 잎의 접촉점, 그 아래의 빈 공간, 풀잎이 지면 가까운 밑동으로 이어지는 모습을 한 프레임에 보여 준다.

**Independently authored scene — English**

A single narrow blade of grass extends horizontally from an ordinary roadside clump. A rounded pebble several times wider than the blade rests near its tip, yet the grass directly beneath it barely bends. Other blades on the same plant curve naturally. A low oblique side view shows the stone's contact with the blade, the empty space beneath it, and the blade's continuous connection back toward the plant's base near the ground.

**일상적 기대에서 벗어나는 지점**

가늘고 휘기 쉬워 보이는 풀잎 끝이 상대적으로 큰 돌을 받치면서 거의 처지지 않는다. 그러나 돌의 단단한 표면은 실제 무게의 증거가 아니므로 물리적 불가능성이 입증되는 장면으로 부르지 않는다. 판정 대상은 관객에게 보이는 물성·지지 기대의 어긋남이다.

**현실 기준**

- 일반적인 길가 풀포기의 생김새
- 같은 풀포기 다른 잎의 자연스러운 휨
- 가느다란 잎의 폭과 표면 결
- 조약돌의 둥글고 단단해 보이는 표면
- 지면과 풀 밑동의 연속
- 돌과 잎의 상대적인 폭

**필요한 관계**

| 항목 | 조건 |
| --- | --- |
| 대상 | 길가의 풀포기 한 개 그 풀포기에 이어진 가는 풀잎 한 장 해당 잎의 폭보다 여러 배 넓은 조약돌 한 개 |
| 소유·동일성 | 돌을 받치는 잎과 주변의 휘어진 잎은 같은 풀포기에서 나온다. 돌은 잎과 합쳐진 조직이 아니라 별도의 물체다. |
| 배치 | 돌은 밑동이나 여러 잎이 교차하는 곳이 아니라 길게 뻗은 단일 잎의 끝 가까이에 놓인다. 돌과 잎 아래에 지면까지의 빈 공간이 드러난다. 연속된 잎이 지면 가까운 풀의 밑동까지 추적 가능하게 배치된다. |
| 접촉 | 돌의 아래 면 일부가 하나의 잎 윗면에 닿는다. 돌이 주변 잎·다른 돌·지면과 동시에 닿는 모습은 없어야 한다. 프레임에서 돌이 잎과 떨어져 보이면 지지 불일치 대신 부유 관계가 되어 후보의 원리가 달라진다. |
| 상태 | 지지하는 잎은 거의 수평이고 돌 아래에서 크게 휘지 않는다. 주변의 다른 잎은 자연스럽게 휘어 유연성의 비교 기준을 제공한다. 돌과 풀의 재질은 정상적으로 보이며 발광·인공 부품·추가 사건은 필요하지 않다. |
| 경계 | 돌과 잎의 접촉 경계는 구분된다. 잎이 돌을 관통하거나 돌 표면과 융합되지 않는다. 잎 아래의 빈 공간이 원근 중첩으로 가려지지 않는다. |

**한 프레임의 핵심 증거**

- 돌의 폭과 지지하는 잎의 폭 차이
- 끝 가까이에 위치한 실제 접촉점
- 거의 처지지 않는 지지 잎과 자연스럽게 휘어진 다른 잎
- 접촉점 아래의 빈 공간
- 단일 잎이 풀의 밑동까지 이어지는 모습
- 주변 물체가 돌을 함께 받치지 않는 관찰 가능한 배치

**정상 현상·장식·착시·오류와의 혼동**

- 작은 조약돌이나 단단한 잎맥이라면 정상적으로 지지될 수 있다.
- 단단해 보이는 표면만으로 돌의 질량을 알 수 없다.
- 돌이 가벼운 모형일 수 있고, 풀이 굳혀지거나 내부 보강되었을 수 있다.
- 카메라에서 가려진 지지체나 접착을 배제할 수 없다.
- 위에서 촬영하면 돌이 지면이나 다른 가지에 놓인 채 겹쳐 보일 수 있다.
- 잎과 돌이 합쳐지거나 접촉점이 사라지면 생성 오류 또는 단순 부유로 읽힌다.
- 정상 현상으로 읽히는 작은 크기 차이는 후보의 초현실 가독성을 약하게 만든다.

**정지 이미지에서 확인할 수 있는 것**

- 돌과 잎의 상대 크기
- 접촉점의 위치
- 보이는 잎의 휨과 연속
- 아래 빈 공간
- 같은 풀포기의 다른 잎과의 형태 비교

**정지 이미지에서 확인할 수 없는 것**

- 조약돌의 실제 무게와 내부 재료
- 풀잎의 실제 강성·보강·접착 여부
- 숨은 지지체의 부재
- 실제 중력이나 물리 법칙이 위반되었다는 주장
- 이 균형이 지속된 시간이나 이전·이후의 운동

**기존 범위와의 중복·차이·보완 가치 — 원본 대조 전**

가까운 분류군: 사물의 전이와 병치, 규모와 포함 세계.

단순히 물체를 떠 있게 하는 대신 접촉을 유지하고 지지체의 물성과 상대 크기를 비교하게 한다. 인물·건축·기술적 외형이 없어도 자연물만으로 성립하는 후보이며, 장면 의미에 기계가 필요하지 않다는 뜻이지 실제 제작 도구가 없다는 뜻은 아니다.

반영 규칙: 기존에 약한 지지체와 큰 물체의 접촉·처짐·빈 공간을 명시한 후보가 있으면 자연물 변형으로 정제한다. 단순 부유나 크기 키워드만 있다면 관계의 실행 가능성을 비교한 뒤 신규 추가 여부를 판단한다. 파일럿에서 정상적인 작은 돌 지지로 읽히면 상대 크기와 접촉 증거를 정제하거나 보류한다.

**출처가 실제로 뒷받침하는 내용**


[S09 — Peter Fischli, David Weiss — The Way Things Go, 1987](https://www.moma.org/collection/works/80908)

- 확인 사실: MoMA는 Fischli와 Weiss의 1987년 영화 The Way Things Go가 불안정하게 균형 잡힌 물체를 다룬 Equilibres 사진에서 출발했다고 설명한다.
- 일반화·해석: 사물의 지지와 균형 자체를 사진 한 장의 핵심 관계로 삼는 원리를 일반화하고, 자연물의 물성 기대를 비교하는 새 장면으로 옮겼다.
- 뒷받침하지 않는 것: Equilibres가 이 풀잎과 돌 장면을 포함한다는 주장, 해당 작가들이 불가능한 물리를 구현했다는 주장, 풀잎이 돌을 지지할 수 없다는 물리적 증명, 새 장면의 정확한 형태와 강도.


### C09. 허리 높이 찻잔을 닦는 일상

**처리:** 기존 후보 재사용 우선 / **순서:** 재사용·비교 기준  
**축:** 크기·비례, 사용 관계  
**적용 영역:** 인물, 사물, 일상 실내  
**예상 정서(미검증):** 유머, 태연한 낯섦, 경이

**일반화한 시각 원리 — 해석**

크기 불일치를 단독 형용사로 지정하는 대신, 정상적인 사람·가구·사용 행동과의 비례 관계로 읽게 한다. 동일한 하나의 크기 관계를 배치와 행동의 중요도로 달리 제시할 수 있다.

**독자적으로 저술한 장면 — 한국어**

평범한 아파트 부엌에서 성인이 허리 높이의 흰 찻잔 가장자리를 행주로 닦고 있다. 찻잔은 싱크대 앞 바닥에 놓여 있고, 한 손은 두꺼운 손잡이에 닿아 있다. 나머지 조리대, 접시, 의자는 모두 일상적인 크기다. 인물의 몸통과 다리, 찻잔의 밑면, 싱크대가 함께 보이며 사람과 찻잔은 비슷한 깊이에 놓여 있다.

**Independently authored scene — English**

In an ordinary apartment kitchen, an adult wipes the rim of a waist-high white teacup with a dishcloth. The cup stands on the floor in front of the sink, with one hand resting on its thick handle. The counter, plates, and chair remain at everyday scale. The person’s torso and legs, the base of the cup, and the sink are visible together, with person and cup at a similar depth.

**일상적 기대에서 벗어나는 지점**

손으로 들어 사용하는 작은 찻잔이 사람의 허리까지 오는 비례를 갖지만, 생활 공간과 청소 행동은 평범하게 유지된다. 크기 불일치는 대상 수의 증가가 아니라 사람·찻잔·부엌 사이의 상대 비례에서 발생한다.

**현실 기준**

- 정상적인 성인 신체 비례
- 일상 크기의 싱크대와 조리대
- 정상 크기의 주변 식기
- 사람과 찻잔의 같은 바닥 및 비슷한 깊이

**필요한 관계**

| 항목 | 조건 |
| --- | --- |
| 대상 | 성인 허리 높이 흰 찻잔 행주 싱크대와 조리대 일반 크기의 주변 식기·의자 |
| 소유·동일성 | 거대한 손잡이와 그릇 몸체는 하나의 찻잔에 속한다. 행주는 인물이 찻잔을 닦는 데 사용한다. |
| 배치 | 찻잔과 인물은 싱크대 앞 같은 바닥에 비슷한 깊이로 놓인다. |
| 접촉 | 한 손이 찻잔 손잡이에 닿는다. 다른 손의 행주가 찻잔 가장자리에 닿는다. 찻잔 밑면이 바닥에 놓인다. |
| 상태 | 찻잔은 정상적인 찻잔 형태를 유지하되 인물의 허리 높이에 이른다. 주변 가구와 식기는 일상적인 크기다. 인물은 청소 행동을 하고 있다. |
| 경계 | 찻잔의 밑면과 바닥 접점이 보인다. 손·행주·찻잔의 접촉 경계가 명료하다. |

**한 프레임의 핵심 증거**

- 사람의 크기를 판단할 몸통·다리
- 찻잔 전체와 바닥 접점
- 사람과 찻잔의 접촉
- 정상 크기 싱크대·조리대
- 같은 깊이로 읽히는 공간 단서

**정상 현상·장식·착시·오류와의 혼동**

- 카메라 바로 앞 작은 찻잔을 이용한 강제원근
- 미니어처 부엌
- 대형 광고용 소품 또는 실제 설치물
- 인물의 신체 크기가 변한 것으로 읽히는 경우
- 손이 찻잔과 이어지지 않는 생성 오류

**정지 이미지에서 확인할 수 있는 것**

- 인물·찻잔·부엌 사이의 상대 비례
- 같은 공간에서 거대한 찻잔을 일상적으로 다루는 관계
- 강제원근 대신 접촉 관계가 크기 비교를 지지하는 정도

**정지 이미지에서 확인할 수 없는 것**

- 찻잔의 정확한 실제 치수
- 촬영 세트나 소품의 실제 규모
- 찻잔의 실제 재질이나 사용 가능성
- 찻잔이 커진 사건 또는 성장 과정

**기존 범위와의 중복·차이·보완 가치 — 원본 대조 전**

가까운 분류군: 규모와 포함 세계, 사물의 전이와 병치, 포스트휴먼 일상.

이미 규모 관계군이 있으므로 이 후보를 새 표현 원리로 추가할 근거는 약하다. 보완 가치는 기존 거대 사물 후보에 정상 대조항·같은 깊이·접촉·일상 사용을 붙여 사진 한 장에서 읽히게 하고, 강도 비교의 재사용 기준 사례로 삼는 데 있다.

반영 규칙: 원본의 거대 일상 사물 후보를 먼저 재사용한다. 필요한 경우 상대 비례와 사용 관계만 정제한다. 찻잔이라는 소품 차이만으로 새 후보를 만들지 않는다.

**출처가 실제로 뒷받침하는 내용**


[S10 — René Magritte — Les valeurs personnelles (Personal Values), 1952](https://www.sfmoma.org/artwork/98.562/)

- 확인 사실: SFMOMA는 René Magritte의 Les valeurs personnelles / Personal Values(1952)에서 익숙한 일상 소품에 사람 크기의 비례를 부여하고 실내 벽의 하늘로 안팎을 뒤집는다고 설명한다.
- 일반화·해석: 상대 규모의 변화를 정상적인 방과 사람의 사용 관계에 연결하면 단일 관계의 주목도와 중요성을 조절하는 비교 사례로 쓸 수 있다고 해석했다.
- 뒷받침하지 않는 것: 출처는 허리 높이 찻잔을 닦는 인물 장면, 강도 0~3의 효과, 실제 크기나 생성 모델의 원근·접촉 정확성을 입증하지 않는다. 새 부엌 장면은 독자 제안이다.


### C10. 벽을 바닥처럼 삼은 독서

**처리:** 미수록일 때 신규 검토 / **순서:** 후순위 확장  
**축:** 공간·방향, 물리적 기대, 접촉과 사용 관계  
**적용 영역:** 인물, 건축, 사물, 일상 실내  
**예상 정서(미검증):** 태연한 유머, 경이, 온화한 낯섦

**일반화한 시각 원리 — 해석**

사진 전체를 기울이는 대신 하나의 공간 안에 서로 다른 위·아래 기준을 함께 제시한다. 선택된 인물과 가구의 접촉·자세·처짐 방향이 국소적으로 같은 기준을 따르고, 정상 방향의 대조항은 유지한다.

**독자적으로 저술한 장면 — 한국어**

밝은 아파트 복도에서 한 성인은 정상적인 바닥에 서 있다. 다른 성인은 옆벽을 바닥처럼 삼아 작은 의자에 앉아 책을 읽는다. 두 번째 인물의 신발바닥과 의자 다리는 벽면에 놓이고, 헐렁한 소매는 그 벽을 향해 처져 있다. 복도의 바닥 직선과 열린 방문은 공간의 정상 방향을 유지한다. 두 인물과 벽·바닥의 만나는 선이 한 프레임에 들어온다.

**Independently authored scene — English**

In a bright apartment corridor, one adult stands on the ordinary floor. Another sits reading in a small chair with the side wall serving as their floor. The reader’s shoe soles and chair legs rest against the wall, and a loose sleeve hangs toward that wall. Floor lines and an open doorway establish the corridor’s ordinary orientation. Both people and the junction between wall and floor remain within one frame.

**일상적 기대에서 벗어나는 지점**

한 실내 공간에서 몸과 가구가 공통된 아래 방향을 공유할 것이라는 기대가 어긋난다. 벽면 독서자의 자세·접촉·옷의 처짐은 하나의 대체 방향을 따르며 정상 바닥의 인물은 기존 기준을 유지한다.

**현실 기준**

- 정상 바닥 위에 서 있는 성인
- 복도 바닥 직선과 열린 방문
- 벽·바닥이 만나는 선
- 뒤틀리지 않은 건축 형태

**필요한 관계**

| 항목 | 조건 |
| --- | --- |
| 대상 | 정상 바닥 위 성인 벽면에서 책을 읽는 성인 작은 의자 책 복도의 벽·바닥·문 |
| 소유·동일성 | 헐렁한 소매는 벽면 독서자의 옷에 속한다. 벽면 독서자는 의자에 앉아 책을 들고 있다. |
| 배치 | 첫 인물은 정상 바닥 위에 서 있다. 두 번째 인물과 의자는 같은 복도의 옆벽을 생활 바닥처럼 사용한다. |
| 접촉 | 첫 인물의 신발은 정상 바닥에 닿는다. 독서자의 신발바닥과 의자 다리는 옆벽에 닿는다. 독서자의 몸은 의자에 앉아 있고 손은 책을 잡고 있다. |
| 상태 | 첫 인물은 정상 방향으로 서 있다. 독서자의 몸·가구·옷의 처짐은 벽을 아래로 삼는 방향을 따른다. 건축 자체는 일반적인 직교 형태를 유지한다. |
| 경계 | 벽과 바닥의 만나는 선이 두 방향을 구별한다. 인물·의자와 벽의 접촉 부위가 가려지지 않는다. |

**한 프레임의 핵심 증거**

- 정상 바닥 인물과 벽면 독서 인물의 서로 다른 방향
- 독서자의 신발·의자 다리와 벽의 접촉
- 소매의 처짐 방향
- 정상적인 바닥·문·벽의 연속 공간

**정상 현상·장식·착시·오류와의 혼동**

- 사진 전체를 회전한 경우
- 벽화나 평면 인물 그림
- 회전 세트
- 곡예나 보조 장치
- 벽에 고정한 설치물
- 인체 자세나 접촉이 틀어진 생성 오류
- 소매 방향만 불일치하여 의도된 규칙이 아닌 오류로 읽히는 경우

**정지 이미지에서 확인할 수 있는 것**

- 한 공간 안에 두 방향 기준이 함께 보이는지
- 선택된 인물·가구·접촉·처짐이 동일한 국소 기준을 따르는지
- 건축 변형 없이 사용 관계가 바뀌어 보이는지

**정지 이미지에서 확인할 수 없는 것**

- 실제 중력장의 방향
- 인물이나 가구를 지지하는 숨은 장치의 유무
- 정지 자세가 얼마나 지속되는지
- 인물이 벽을 따라 걸어온 과정
- 몸이 실제로 느끼는 무게나 힘

**기존 범위와의 중복·차이·보완 가치 — 원본 대조 전**

가까운 분류군: 유기적 건축, 이중 이미지와 지각 불일치, 포스트휴먼 일상.

기존 공간 왜곡이나 중력 변경 후보와 겹칠 수 있다. 차이가 있다면 건축 형태 자체의 변형보다 정상적인 건축을 서로 다른 방향으로 사용하는 관계에 집중한다는 점이다. 증거 관계가 많고 생성 오류와 혼동하기 쉬워 약한 초현실 보강의 첫 순위로 권하지 않는다.

반영 규칙: 원본에 국소적 위·아래 기준 변경이 있으면 그 후보를 재사용·정제한다. 유기적인 건축 외형만 있고 사용 방향의 변경이 없을 때에만 신규 후보를 검토한다. 파일럿에서 접촉·처짐의 판독 신뢰도가 낮으면 보류한다.

**출처가 실제로 뒷받침하는 내용**


[S11 — M. C. Escher — Relativity, 석판화, 1953년 7월](https://escherinhetpaleis.nl/en/about-escher/masterpieces/relativity)

- 확인 사실: Museum Escher in The Palace는 M. C. Escher의 Relativity를 1953년 7월 석판화로 기록하며, 서로 다른 중력장을 가진 세 세계와 벽이 바닥이 되는 방향 관계를 설명한다.
- 일반화·해석: 전체 프레임의 회전과 구별하려면 서로 다른 방향 기준이 한 프레임에 함께 있고, 각 국소 공간의 사용 관계가 일관되어야 한다는 원리로 해석했다.
- 뒷받침하지 않는 것: 출처는 아파트 독서 장면, 실제 중력장의 변경, 사진 모델의 접촉·옷 처짐 생성 성능, 강도 등급 또는 온화한 감정 효과를 입증하지 않는다. 새 장면은 독자 제안이다.

### D01. 먼지 속 깨끗한 원형 자리

**새로 저술한 한국어 장면**

한동안 사용하지 않은 방의 식탁 위에 고운 먼지가 쌓여 있지만, 둥근 자리 하나만 먼지가 없어 깨끗하다. 그 자리에는 아무 물체도 없고, 주변에는 무엇을 치웠는지 확정할 수 있는 단서가 없다. 자연스러운 옆빛이 먼지와 깨끗한 표면의 차이를 보여 준다.

**Newly authored English scene**

Fine dust covers a table in an unused room, except for one clean circular patch. No object occupies the patch, and the surroundings provide no definitive clue about what may have been removed. Natural side light reveals the difference between the dusty surface and the clean circle.

**관찰 가능한 것**

- 주변에 쌓인 먼지
- 먼지가 없는 원형 부분
- 해당 부분을 차지하는 물체가 현재 보이지 않는다는 사실
- 먼지와 표면의 국소적 대비

**그것만으로 추론할 수 없는 것**

- 그 자리에 있었던 물체가 반드시 찻잔이라는 주장
- 찻잔 손잡이 형태까지 바닥 먼지에 찍힌다는 주장: 일반적인 찻잔 손잡이는 바닥에 닿지 않는다.
- 누가 무엇을 언제 치웠는지
- 원형 부분이 물체의 흔적인지 일부러 닦은 자국인지
- 물체가 초자연적으로 사라졌다는 주장
- 과거의 시간이나 기억이 실제로 물질화되었다는 주장

**교정 용도**

- 정상적인 부재의 흔적이나 조용한 분위기만으로 초현실 처리가 추가되었다고 단정하지 않는 0–1 경계 대조 사례로 사용한다. 원형 자국이 무엇의 흔적인지는 명시하지 않으며, 관객이 추론한 서사를 정지 이미지에서 확인된 사실과 분리해 기록한다. 별도의 신규 초현실 시각 후보 수에 포함하지 않는다.

**관련 근거:** [S12 — Dust Sculptures](https://www.erwinwurm.com/artworks/dust-sculptures)


### D02. 수영장 착시: 초현실적 외관과 실제 공간 구조를 분리하기

**새로 저술한 한국어 장면**

맑은 정원 연못을 위에서 내려다본 사진. 수면 아래에는 평상복을 입은 성인이 마른 듯한 안락의자에 앉아 책을 읽는 모습이 보인다. 수면의 반사와 물결은 인물 위를 가로지르고, 가장자리의 돌 테두리는 평범한 정원 연못의 크기를 알려 준다. 이는 출처 작품의 사진 설명이 아니라, 같은 판독 문제를 시험하기 위해 새로 저술한 장면이다.

**Newly authored English scene**

A view down into a clear garden pond shows an adult in everyday clothes reading in a dry-looking armchair beneath the surface. Reflections and ripples pass across the figure, while the stone rim establishes the scale of an ordinary garden pond. This is a newly authored test scene for the same interpretation problem, not a description of a photograph of the source artwork.

**관찰 가능한 것**

- 수면으로 읽히는 경계와 그 아래에 보이는 인물·의자
- 수면의 반사·물결이 인물의 보이는 모습에 미치는 시각적 간섭
- 평범한 행동과 잠긴 것처럼 보이는 공간 관계의 병존

**그것만으로 추론할 수 없는 것**

- 인물이 물속에서 호흡하고 있는지
- 옷이나 책이 실제로 말라 있는지
- 수면 아래 공간 전체가 물로 채워져 있는지
- 얼마나 오래 그 자세로 있었는지
- 유리·별도 공간·반사·사진 합성을 사용하지 않았는지
- 장면이 실제 물리적으로 불가능한지

**교정 용도**

- 초현실적 인상이 읽히는가와 실제 물리적 불가능성을 증명하는가를 분리하여 평가한다.
- The Swimming Pool의 가나자와 설치판은 실제로 투명 유리 위 약 10cm의 물과 그 아래 들어갈 수 있는 빈 공간으로 만들어진다. 실제 제작 가능한 착시도 비일상적 관계로 읽힐 수 있다는 진단 기준으로 쓴다.
- 후보의 목표가 착시·외관상 불일치라면 실제 설치 가능성만으로 실패 처리하지 않는다. 목표가 특정 세계 규칙의 명료한 묘사라면 다른 공간 구조로 읽히는 비율을 별도로 기록한다.
- 정지 이미지 후보 문장에 '숨을 쉰다', '젖지 않는다', '오래 머문다'처럼 사진으로 확인할 수 없는 속성을 자동으로 추가하지 않는다.
- 수영장 일반 개념이나 최초 제시 연도와 특정 설치판의 제작연도를 섞지 않는다. 해당 공식 출처가 기록한 가나자와 설치판은 2004년이다.

**관련 근거:** [S13 — Leandro Erlich — The Swimming Pool, 2004 설치판](https://www.kanazawa21.jp/data_list.php?d=7&g=30&lng=e)


### D03. 물방울의 위치만으로 운동 방향과 인과를 확정할 수 없음

**새로 저술한 한국어 장면**

평범한 부엌 탁자 위 물이 담긴 유리잔 바로 위에, 물 표면과 분리된 물방울 한 개가 보인다. 잔의 테두리, 물 표면, 물방울 아래의 빈 공간을 한 장의 정지 이미지에 함께 담는다.

**Newly authored English scene**

A single detached water droplet is visible above a glass of water on an ordinary kitchen table. The rim, water surface, and clear gap beneath the droplet are shown together in one still frame.

**관찰 가능한 것**

- 촬영된 순간 물방울이 물 표면에서 분리된 위치에 보인다.
- 물방울과 잔의 테두리 및 물 표면 사이의 공간 관계를 확인할 수 있다.
- 프레임에 나타난 형상과 위치는 기술할 수 있다.

**그것만으로 추론할 수 없는 것**

- 물방울이 올라가는지 내려가는지.
- 물방울이 잔에서 튀어 오른 것인지 위에서 떨어지는 것인지.
- 역방향 운동, 중력의 반전 또는 지속적인 공중 정지가 일어나는지.
- 특정 인물이나 사물이 물방울의 움직임을 일으켰는지.
- 이전 상태와 이후 상태 또는 변화의 시간 순서.

**교정 용도**

- 물방울의 위치를 '역행', '시간 정지', '원인과 결과의 반전'으로 자동 라벨링하지 않는지 점검하는 진단용 장면이다. S09에서 영화의 연쇄 사건과 정지 사진의 균형 구성을 구별하는 맥락을 참고하되, 그 자료가 이 새 물방울 장면이나 운동 방향을 직접 입증한다고 쓰지 않는다.

**관련 근거:** [S09 — Peter Fischli, David Weiss — The Way Things Go, 1987](https://www.moma.org/collection/works/80908)


## 7. 강도 비교의 공통 원칙

다음 비교는 저술 가설이며 실제 생성 결과가 아니다. 1·2·3 모두 핵심 관계가 판독되어야 하고, 단계는 관계가 사진에서 맡는 역할로 구분한다. 단순 확대·소품 증가·안개 증가를 강도 정의로 사용하지 않는다. 모든 비교에서 사용자 의미를 보존하는 것이 먼저다.

## 8. 동일 주제의 0·1·2·3 비교안


### I01. 현관 화분 돌봄: 반사에서만 피어난 꽃

**고정 사용자 요구:** 평범한 집 현관에서 성인이 작은 화분을 돌보는 온화한 사진.

**선택한 추가 관계:** 실제 화분은 꽃 없는 잎과 줄기만 보이지만, 같은 화분의 거울상에는 흰 꽃 한 송이가 보인다. 꽃 이외의 화분 모양, 잎 배치와 주변 반사는 서로 대응한다.

**사용자 의미 보존 조건**

- 같은 성인이 같은 화분에 물을 주며 돌보는 행동을 유지한다.
- 장소는 생활 흔적이 있는 평범한 집 현관이고, 정서는 온화하다.
- 화분 자체의 현실 크기와 성인의 신체 크기를 유지한다.
- 작은 거울은 모든 단계의 기본 공간에 존재하는 정상적인 소품이다.

**1·2·3에서 고정할 것**

- 추가 관계는 실제 식물과 거울상 사이의 선택적인 꽃 유무 불일치 하나뿐이다.
- 흰 꽃은 한 송이이며 크기, 꽃잎 형태와 줄기에 붙은 위치를 고정한다.
- 실제 식물에는 꽃이 없고, 잎과 줄기 및 화분의 상대 크기는 같다.
- 같은 성인의 물주기 행동, 주간 조명, 장소와 온화한 정서를 유지한다.
- 단계에 따라 카메라 위치, 화면 내 배치와 시선의 우선순위만 조절한다. 꽃이나 거울의 수를 늘리지 않는다.

| 값 | 저술 차이 | 예상 주된 인상 |
| --- | --- | --- |
| 0 | 평범한 집 현관에서 성인이 벤치 위 작은 화분에 물을 준다. 화분 옆 거울에는 실제 식물과 같은 꽃 없는 잎과 줄기가 반영된다. 인물의 편안한 자세와 일상적인 돌봄이 중심인 사진. | 평범하고 온화한 화분 돌봄. |
| 1 | 같은 현관에서 성인이 같은 화분에 물을 주는 모습을 넉넉한 구도로 담는다. 인물의 자세와 돌봄 행동이 먼저 읽힌다. 화면 옆쪽 거울에는 실제 식물에 없는 흰 꽃 한 송이가 작지만 판독 가능한 크기로 보이고, 꽃 이외의 화분과 잎은 실제 모습과 대응한다. | 익숙한 돌봄 장면에 서정적인 낯섦이 보조적으로 스며듦. |
| 2 | 같은 성인의 물주기와 실제 화분, 옆 거울을 함께 비교하기 쉬운 사선 구도로 촬영한다. 실제 줄기에는 꽃이 없고, 대응되는 거울상에는 같은 위치에 흰 꽃 한 송이가 분명히 보인다. 돌봄 행동과 반사 불일치가 모두 쉽게 읽히며 현관의 일상적인 크기와 조명은 유지된다. | 화분 돌봄과 분명한 반사 불일치가 함께 읽히는 온화한 초현실 사진. |
| 3 | 같은 현관과 같은 물주기 장면에서 실제 식물과 꽃이 있는 거울상의 대조가 구도를 이끌도록 촬영한다. 성인의 손과 물주기, 실제 꽃 없는 줄기, 대응되는 거울 속 흰 꽃을 한 프레임에서 유지한다. 꽃은 더 커지거나 늘어나지 않으며, 돌봄이 반사 속 다른 가능성과 만나는 관계가 사진의 주된 인상을 만든다. | 돌봄의 일상이 반사 속 다른 가능성과 만나는 관계가 사진 해석을 이끎. |

**단계별 관찰 기준과 인접 단계의 모호성**


#### surreal 0

관찰 기준:

- 실제 화분과 거울상이 정상적으로 대응한다.
- 사용자가 요구한 장소와 돌봄 행동을 유지한다.
- 초현실 효과를 만들기 위한 꽃이나 반사 불일치를 추가하지 않는다.

인접 단계와 구분하기 어려운 점:

- 거울의 각도 때문에 가려진 잎이 다르게 보이는 정상 현상과 생성된 반사 오류를 구별해야 한다.
- 사용자가 원래 요청하지 않은 꽃을 실제 화분에도 추가하면 비교의 기준 장면이 달라진다.

English scene:

An adult waters a small potted plant on a bench in an ordinary home entryway. The nearby mirror reflects the same flowerless leaves and stems as the real plant. The photograph centers on a relaxed posture and an everyday act of care.


#### surreal 1

관찰 기준:

- 첫 자유 묘사에서는 화분 돌봄이 주된 내용으로 나오는지 확인한다.
- 화면을 살펴보면 설명 없이 실제 식물과 반사 속 꽃의 차이를 찾을 수 있어야 한다.
- 불일치를 알아본 뒤에도 인물의 일상이 사진의 중심으로 남는지 평가한다.

인접 단계와 구분하기 어려운 점:

- 꽃이 너무 작거나 흐려 읽히지 않으면 은근한 성공이 아니라 관계 구현 실패일 수 있다.
- 작은 꽃이라도 관찰자가 장면의 핵심 상징으로 읽으면 2 또는 3으로 평가할 수 있다.

English scene:

In the same entryway, an adult waters the same potted plant in a spacious composition led by the person's relaxed act of care. A mirror near the side of the frame shows one small but legible white flower absent from the real plant; the pot and leaves otherwise correspond to their real counterparts.


#### surreal 2

관찰 기준:

- 관찰자가 꽃이 거울 속에만 있다는 관계를 독립적으로 설명할 수 있는지 확인한다.
- 실제 화분과 반사 속 화분이 같은 대상이라는 연결이 명확해야 한다.
- 돌봄 행동이 사라지지 않으면서 초현실성이 명시적인 특징이 되는지 평가한다.

인접 단계와 구분하기 어려운 점:

- 꽃과 인물 사이의 상징적 관계가 강하게 읽히면 이미 3에 가까울 수 있다.
- 거울과 실제 식물의 소유 관계가 불분명하면 별개의 화분 두 개로 읽힐 수 있다.

English scene:

An oblique view makes the adult watering the plant, the real pot, and the nearby mirror easy to compare. The real stem has no flower, while its corresponding reflection clearly bears one white flower. Both the act of care and the reflection mismatch remain readily legible within the ordinary scale and lighting of the entryway.


#### surreal 3

관찰 기준:

- 첫 자유 묘사에서 반사 속 다른 상태가 사진의 핵심으로 언급되는지 확인한다.
- 반사를 정상화했을 때 사진의 주된 의미가 달라지는지 묻는다.
- 화분을 돌보는 원래 행동과 온화한 정서는 계속 확인되어야 한다.

인접 단계와 구분하기 어려운 점:

- 거울의 화면 면적이 커졌다는 사실만으로 3으로 판정하지 않는다.
- 대조가 분명하더라도 관찰자가 여전히 인물의 돌봄만을 중심으로 읽으면 2에 머물 수 있다.

English scene:

In the same entryway and watering scene, the composition is led by the contrast between the real flowerless plant and its flowering reflection. Keep the adult's hands and watering action, the real bare stem, and the corresponding white flower in the mirror visible together. The flower does not grow or multiply; the relationship between everyday care and a different reflected possibility leads the photograph.

**공통 증거와 한계**

- 실제 화분과 거울상, 꽃이 붙을 줄기 부분을 한 프레임에 보여 준다.
- 화분의 고유한 형태나 작은 흠집, 대응되는 잎 배치로 같은 대상임을 연결한다.
- 거울 테두리와 주변의 정상 반사로 그림이나 별도 식물이 아니라 반사로 읽히게 한다.
- 꽃이 실제 식물 뒤에 가려져 있을 뿐이라는 설명이 쉽게 생기지 않도록 주요 줄기와 잎 배치를 드러낸다.
- 정지 이미지가 확인하는 것은 상태 불일치이며, 미래의 개화나 시간 지연은 확인하지 못한다.

**성공으로 집계하면 안 되는 결과**

**공통 증거와 한계**

### I04. 사용자 지정 판타지 보존: 작은 용과 아침 식사, 접힌 대리석

**고정 사용자 요구:** 성인과 작은 용이 평범한 집 식탁에서 함께 아침을 먹는 친밀하고 평온한 사진.

**선택한 추가 관계:** 대리석으로 보이는 식탁 상판의 한쪽 모서리만 천처럼 아래로 접혀 늘어지며, 상판의 석재 무늬와 표면이 접힌 부분까지 연속된다.

**사용자 의미 보존 조건**

- 작은 용은 사용자가 명시한 존재이므로 0을 포함한 모든 단계에 실제 장면의 구성원으로 유지한다.
- 작은 용을 삭제하거나 장난감·그림·장식으로 치환하지 않는다.
- 성인과 용이 같은 식탁에서 아침을 함께 먹는 행동과 친밀한 정서를 유지한다.
- 인물, 용, 식탁과 음식의 상대 크기는 고정한다.
- 용의 존재 자체에 대해 에이전트가 추가한 초현실 처리라고 집계하지 않는다.

**1·2·3에서 고정할 것**

- 접힌 모서리는 하나이고 접힌 면적, 곡률, 두께의 외관과 식탁에 대한 상대 크기를 고정한다.
- 대리석 무늬와 상판의 표면은 정상 부분에서 접힌 부분까지 하나로 이어진다.
- 성인과 작은 용의 존재, 크기, 식사 행동과 친밀한 분위기는 같다.
- 용의 불꽃, 공중에 뜬 음식, 추가 변형이나 복수의 접힌 모서리를 만들지 않는다.
- 주목과 구도를 바꾸되 상판의 변형 정도를 늘리지 않는다.
- 실제 물성이 부드러워졌다고 증명하는 대신, 석재 외관과 천 같은 형태의 충돌을 시각 목표로 삼는다.

## 9. 보강 우선순위와 반영 결정

### 9.1 가장 먼저 할 일

첫 순위는 후보 수를 늘리는 일이 아니라 **원본 범위 확정, 관계와 증거의 정제, 0의 보존 원칙을 검증하는 비교 자료 마련**이다. 원본 대조가 불가능한 상태에서 새 데이터라는 이유만으로 자동 병합하지 않는다.

### 9.2 조건부 반영 순서

| 처리 | 우선 대상 | 이유와 반영 조건 |

C04의 특이한 컵은 실제 제품으로 제작 가능하고, C03의 자세는 실제로 취할 수 있다. 이것만으로 후보에서 제외할 필요는 없다. 다만 관찰자가 단순 제품 디자인이나 가구 이동으로만 읽는다면 해당 배치가 목표한 초현실적 역할을 만들지 못한 것으로 기록한다.

### 9.3 확장하지 않은 방향

- 기계·케이블·복합 신체를 더 세분화하는 안은 이번 보완 가설에 비추어 우선하지 않았다. 해당 원리가 부적절하다는 판단은 아니다.
- 구름·문·거울·눈·새 같은 흔한 소품은 독립 원리로 세지 않았다. 위치 불일치, 선택적 대응, 역할 전환의 예시로 다룬다.
- 안개, 빈방, 먼지, 필름 그레인, 낮은 채도만으로 초현실 후보를 확정하지 않았다. 인접 분위기 데이터와의 연결은 원본 대조가 필요하다.
- ‘반사가 늦는다’, ‘손길이 꽃을 피운다’, ‘방이 기억한다’처럼 시간·인과·인지 서사가 필요한 문장은 관찰 가능한 상태 관계와 나누었다.
- Whiteread의 Ghost처럼 빈 공간을 물체로 만드는 원리는 조사했으나 이번 우선 후보에 넣지 않았다. NGA의 공식 시각 설명도 사진만으로 제작 원리가 명백하지 않을 수 있음을 지적한다. 정확한 대응 공간을 함께 보이는 설계가 없다면 설명 의존도가 높다. [S15](https://www.nga.gov/artworks/131285-ghost)

## 10. 향후 검증 계획

이 절은 아직 수행하지 않은 계획이다. 아래 장수·시간·판정 방식은 초기 운영안을 제안한 것이며, 통계적으로 검증된 표본 설계나 보편적 임계값이 아니다.

### 10.1 원본 감사와 생성 실험을 분리

원본 감사는 ‘기존 데이터가 무엇을 저술하고 있는가’를 확인한다. 생성 실험은 ‘그 저술이 특정 모델에서 어떤 사진과 인상으로 구현되는가’를 확인한다. 문헌의 작품을 확인한 사실은 이 두 검증을 대신하지 않는다.

초기 실험은 **비교군 4개 × 설정 4단계 × 생성 반복 3회 = 48장**으로 제안한다. 먼저 한 모델에서 주요 실패 양상을 확인하고, 판정이 가능해진 뒤 사용 예정 모델로 범위를 넓힌다. 세 반복을 충분한 통계적 검증으로 간주하지 않는다.

### 10.2 생성 조건의 통제

- 같은 비교군의 모델·정확한 버전·화면비·해상도·기본 스타일을 고정한다.
- 가능하면 동일 인물·장소 참조와 대응 시드를 사용한다. 시드가 같다고 장면이 동일하게 고정된다고 가정하지 않는다.
- 1·2·3에서는 관계의 종류·개수와 핵심 형태를 고정한다. 크기 비교에서는 대상 간 실제 설정 비례도 고정한다.
- 바뀐 배치, 시점, 대비, 시선 유도, 서사적 중심성만 저술 로그에 남긴다.
- 부정 프롬프트나 ‘오류처럼 보이지 않게’라는 문장만으로 증거 설계를 대체하지 않는다.
- 관계를 더 잘 보이게 하려다 사용자가 요구한 인물·행동·정서를 잃으면 성공으로 계산하지 않는다.

### 10.3 두 단계 평가

**첫 단계: 프롬프트와 설정명을 가린 자유 묘사.** 무엇이 일어나고 있는지, 무엇이 이상한지, 어떤 정서가 주된 인상인지 기록한다. 짧은 첫 인상과 충분히 살펴본 후의 묘사를 나눌 수 있지만, 관찰 시간을 보편적인 강도 기준으로 사용하지 않는다.

**두 번째 단계: 원래 요구와 의도한 관계를 공개한 평가.** 다음 항목을 각각 기록한다.

| 항목 | 질문 |
| --- | --- |
| 의미 보존 | 누가 어디서 무엇을 하는가가 원래 요구와 맞는가. 명시된 판타지가 남아 있는가 |
| 관계 구현 | 목표 대상의 동일성·소유·접촉·가림·경계가 일관되는가 |
| 판독 | 설명 없이 관계를 특정할 수 있었는가. 설명 후에만 보였는가 |
| 역할 | 보조 요소, 분명한 특징, 주된 의미 중 어느 것으로 읽히는가 |
| 현실 기준 | 무엇과 비교해서 낯설다고 판단했는가 |
| 대체 설명 | 정상 현상, 장식·소품, 촬영 착시, 생성 오류 중 무엇으로도 읽히는가 |
| 정서 | 온화함·서정성·유머·경이 등의 목표가 유지되는가 |
| 총인상 | 사진 전체의 비현실감은 어느 정도인가. 설정 준수와 별도 기록 |
| 정상화 가정 | 선택한 관계를 정상적으로 되돌렸을 때 사진의 주된 의미가 얼마나 바뀌는가 |

가능하면 여러 평가자가 독립적으로 기록한 뒤 불일치를 검토한다. 관계 구현이 실패한 결과는 강도 판정에서 따로 표시하되 전체 생성 분모에서 삭제하지 않는다.

### 10.4 결과 보고 규칙

관계 구현 성공률, 사용자 의미 보존, 역할 판정 분포, 1↔2·2↔3 혼동, 목표 정서, 정상 현상·오류로 읽힌 이유를 따로 보고한다. 성공 이미지만 골랐다면 전체 생성 수와 선별 수를 함께 남긴다.

손가락이 망가지거나 반사 대응이 무작위로 깨진 사진이 ‘매우 기괴하다’고 평가되어도 surreal 3의 성공으로 집계하지 않는다. 반대로 의도한 관계가 전혀 보이지 않는 사진을 ‘아주 은근한 1’로 집계하지 않는다.

0의 평가는 추가 변경의 유무와 사용자 명시 요소의 보존을 우선한다. 특히 용이 포함된 비교군은 총 비현실감이 0<1<2<3의 순서를 반드시 따라야 한다는 성공 조건을 사용하지 않는다.

## 11. 남은 불확실성과 확정에 필요한 자료

1. **실제 공백:** 원본을 읽지 못했으므로 약한 일상 초현실, 비기술적 표현, 단계 비교가 정말 부족한지 미확정이다.
2. **중복:** 특정 ID 대조와 첨부 밖 코퍼스 중복 검사를 하지 않았다. 신규 후보라는 이름은 독창성·미수록을 인증하지 않는다.
3. **정지 이미지의 한계:** 실제 질량·경도, 숨은 지지, 시간 지연, 운동 방향, 지속성, 원인, 감정·기억의 소유자를 사진 한 장으로 확증할 수 없다.
4. **관객 차이:** 따뜻함·유머·경이·불안의 읽힘은 맥락과 관찰자에 따라 달라질 수 있다. 이번 장면에 대한 관객 실험은 없다.
5. **모델 차이:** 소유·반사·접촉·국소 중력의 구현 능력은 아직 시험하지 않았다. 특정 모델에서 성공한다고 다른 모델의 성공을 보장하지 않는다.
6. **강도 경계:** 1과 단순 장식, 2와 3의 중심성은 특히 경계가 흐리다. 일부 관계는 특정 단계로 안정적으로 저술되지 않을 수 있으며 그 결과도 유효한 발견이다.
7. **출처 접근:** 아래 출처 원장에 직접 읽은 범위를 기재했다. 접근 실패 페이지와 읽지 않은 전문을 확인된 사실의 근거로 쓰지 않았다.

기존 범위와 실제 공백에 대한 감사 결론을 마무리하려면 **72개 후보·16개 기록·182개 경로의 원본, 안정적인 ID, 이번 대조에 포함할 리미널·드림코어 자료 및 파일 버전**이 필요하다. 이 초안은 그 자료와 대조할 수 있는 관계·증거·출처·조건부 결정을 이미 갖추고 있다.

## 12. 출처 원장

모두 2026-10-24에 직접 열람 가능한 본문 또는 기관 서지·초록을 확인한 자료다. 작품의 실물, 전시 전체, 영상 전체 또는 모든 고해상도 이미지를 직접 검토했다는 뜻은 아니다. 아래 ‘확인 사실’과 ‘해석에 사용할 범위’를 구분했다. 출처 작품의 명성은 새 장면의 생성 성능이나 정서 효과의 근거로 사용하지 않았다.




### S01. Madoz. Objetos 1990–1999

**기관·작가:** Museo Nacional Centro de Arte Reina Sofía

[직접 열람한 페이지](https://www.museoreinasofia.es/en/exhibition/madoz-objetos-1990-1999/)

- 확인 사실: 1999년 10월 26일~2000년 1월 10일 전시. 일상 사물을 발견·조작·제작해 촬영하는 접근, 규모와 형식적·상징적 유비를 설명한다. Madoz를 초현실주의 자유연상으로 단순 환원하는 서술을 경계한다.
- 사용할 수 있는 범위: 실제 제작 가능한 일상 사물의 관계와 사진적 존재감도 이번 설정의 연구 대상이 될 수 있다는 근거.
- 뒷받침하지 않는 내용: 이번에 저술한 안쪽 손잡이 컵의 존재·저작자·효과나 surreal 단계별 성공.


### S02. René Magritte — La reproduction interdite, 1937

**기관·작가:** Museum Boijmans Van Beuningen

[직접 열람한 페이지](https://www.boijmans.nl/en/collection/artworks/4232/la-reproduction-interdite)

- 확인 사실: 1937년 작품. 공식 연구 해설은 거울이 인물의 얼굴 대신 뒷머리를 보여 주고 옆의 책은 정상적으로 반사된다고 설명한다.
- 사용할 수 있는 범위: 선택적 불일치와 정상 대응의 내부 대조를 함께 설계할 수 있다는 해석.
- 뒷받침하지 않는 내용: 반사에 꽃이 생기는 장면이나 거울의 시간 지연·미래 예측.


### S03. Meret Oppenheim — Object, Paris, 1936

**기관·작가:** The Museum of Modern Art

[직접 열람한 페이지](https://www.moma.org/collection/works/80997)

- 확인 사실: 1936년 작품의 재료는 털로 덮은 찻잔·받침·숟가락이다. 공식 해설은 일상 사물을 예상 밖의 결합으로 제시하는 접근을 설명한다.
- 사용할 수 있는 범위: 사물의 익숙한 용도와 재질에서 기대되는 감각 사이의 충돌이라는 일반화.
- 뒷받침하지 않는 내용: 석재가 실제로 눌리거나 부드러워진다는 사실, 이번 베개·대리석 장면의 생성 가능성.


### S04. One Minute Sculptures

**기관·작가:** Erwin Wurm 공식 웹사이트

[직접 열람한 페이지](https://www.erwinwurm.com/artworks/one-minute-sculptures)

- 확인 사실: 단순한 소품과 자세 지시를 통해 참여자와 사물이 어색하거나 역설적인 관계를 이루도록 하는 작업이라고 설명한다. one minute는 반드시 정확한 60초를 뜻하지 않는다.
- 사용할 수 있는 범위: 몸의 기형화 없이 자세와 사물의 역할 관계를 바꾸는 접근.
- 뒷받침하지 않는 내용: 빈 의자를 안는 새 장면의 작품 귀속, 실제 애착·생명·돌봄 의도나 온화한 인상의 보장.


### S05. Erwin Wurm: One Minute Sculptures, 2016 전시

**기관·작가:** MAK Center for Art and Architecture

[직접 열람한 페이지](https://www.makcenter.org/exhibitions/erwin-wurm-one-minute-sculptures)

- 확인 사실: 2016년 1월 28일~3월 27일 전시 설명은 균형 잡기, 일상 사물의 바뀐 사용, 맥락과 지각의 관계를 다룬다.
- 사용할 수 있는 범위: 익숙한 행위와 사물의 사용 방식을 재구성하는 시각적 방법.
- 뒷받침하지 않는 내용: 일상에서 특이한 자세를 취한 모든 사진이 초현실적이라는 일반화.


### S06. Nimbus

**기관·작가:** Berndnaut Smilde 공식 웹사이트

[직접 열람한 페이지](https://www.berndnaut.nl/works/nimbus/)

- 확인 사실: 작가는 구름이 특정 장소에서 수초간 존재하다 사라지며 최종적으로 사진이 그 사건의 기록으로 남는다고 설명한다. 페이지는 Nimbus De.Groen(2017), Nimbus De Toekomst(2019), Nimbus Roebourne(2017)을 명시한다.
- 사용할 수 있는 범위: 실내에 놓인 구름 같은 현상의 장소 불일치가 사진 작업의 실제 원리라는 근거.
- 뒷받침하지 않는 내용: 구름이 장기간 정지한다는 주장, 제작 장치가 없었다는 주장, 이번 식탁 장면의 정확한 구성.


### S07. René Magritte — Empire of Light, 1953–54 소장판

**기관·작가:** Peggy Guggenheim Collection

[직접 열람한 페이지](https://www.guggenheim-venice.it/en/art/works/empire-of-light/)

- 확인 사실: 이 소장판의 연도는 1953–54. 밝은 낮 하늘과 어두운 밤 거리의 결합을 설명하며, 이 단일 역설 외에 다른 환상적 요소가 없다고 명시한다.
- 사용할 수 있는 범위: 한 관계가 작품 전체의 해석을 이끌 수 있다는 설계상의 선례.
- 뒷받침하지 않는 내용: 모든 관찰자가 이 관계를 surreal 3으로 평가한다는 실증 결과나 실제 두 시간이 공존한다는 물리적 주장.


### S08. Road Line

**기관·작가:** Andy Goldsworthy 공식 웹사이트

[직접 열람한 페이지](https://andygoldsworthystudio.com/road-line/)

- 확인 사실: 2021년 10월 제안문은 기존 도로의 화강석 경계석 선이 도로를 벗어나 캠퍼스 안의 독립적인 선과 경로가 되는 구상을 설명한다. 페이지에는 완성 구간도 있으나 제안문 날짜를 완공 연도로 쓰지 않았다.
- 사용할 수 있는 범위: 배경의 경계가 독립된 시각적 대상으로 역할을 바꾸는 일반화.
- 뒷받침하지 않는 내용: 도로의 흰 도료가 천으로 변했다는 사실, 제안 장면의 재질이나 정확한 형태.


### S09. Peter Fischli, David Weiss — The Way Things Go, 1987

**기관·작가:** The Museum of Modern Art

[직접 열람한 페이지](https://www.moma.org/collection/works/80908)

- 확인 사실: 1987년 영화이며, 불안정하게 균형 잡힌 물체를 촬영한 Equilibres 사진에서 출발했다고 해설한다. 영화의 연쇄 작용과 사진의 균형 구성을 구분한다.
- 사용할 수 있는 범위: 지지·균형 관계 자체가 사진의 주제가 될 수 있다는 선례와 정지사진/연쇄행동의 매체 구분.
- 뒷받침하지 않는 내용: 풀잎이 돌을 받치는 새 장면, 실제 물리 법칙 위반, 한 장에서 운동 방향이나 연쇄 인과가 입증된다는 주장. Equilibres 전체 제작 연대는 이 보고서에서 확정하지 않음.


### S10. René Magritte — Les valeurs personnelles (Personal Values), 1952

**기관·작가:** San Francisco Museum of Modern Art

[직접 열람한 페이지](https://www.sfmoma.org/artwork/98.562/)

- 확인 사실: 1952년 작품. 공식 해설은 익숙한 생활 소품이 사람 크기의 비례를 갖고 실내 벽의 하늘 표현이 안팎의 관계를 바꾼다고 설명한다.
- 사용할 수 있는 범위: 사물의 명칭보다 대상 간 비례와 사용 맥락이 크기의 낯섦을 만든다는 해석.
- 뒷받침하지 않는 내용: 이번 거대 찻잔 청소 장면, 실제 치수나 miniature/강제원근 배제, 단계별 인상 검증.


### S11. M. C. Escher — Relativity, 석판화, 1953년 7월

**기관·작가:** Museum Escher in The Palace

[직접 열람한 페이지](https://escherinhetpaleis.nl/en/about-escher/masterpieces/relativity)

- 확인 사실: 공식 설명은 서로 다른 중력장을 갖는 세 세계, 벽과 바닥의 상대성, 같은 계단을 서로 다른 방향으로 사용하는 인물을 기술한다.
- 사용할 수 있는 범위: 하나의 프레임에서 국소적인 위·아래 규칙이 달라지는 관계.
- 뒷받침하지 않는 내용: 실제 중력장이 존재한다는 증명, 이번 복도 장면의 촬영 또는 생성 성공.


### S12. Dust Sculptures

**기관·작가:** Erwin Wurm 공식 웹사이트

[직접 열람한 페이지](https://www.erwinwurm.com/artworks/dust-sculptures)

### S13. Leandro Erlich — The Swimming Pool, 2004 설치판

**기관·작가:** 21st Century Museum of Contemporary Art, Kanazawa

### S14. Võ & Henderson (2009), Does gravity matter? Effects of semantic and syntactic inconsistencies on the allocation of attention during scene perception

**기관·작가:** University of Edinburgh Research Explorer / Journal of Vision

### S15. Rachel Whiteread — Ghost, 1990

## 부록. 후보 데이터 사용 메모

동봉 JSON은 기존 운영 데이터에 바로 덮어쓰는 마이그레이션 파일이 아니라 독립적인 리서치 스키마다. candidates, diagnostics, intensity_comparisons, provenance.sources와 validation_plan을 포함한다. 기존 스키마와 ID를 확인한 뒤 대응해야 한다.

- intrinsic_surreal_level은 null이다. 후보 자체에 고정된 강도를 부여하지 않는다.
- agent_addition_allowed_at_level_0은 false이다. 다만 사용자가 명시한 동일 관계는 0에서도 보존한다.
- source facts, interpretations, newly authored scenes가 분리되어 있다.
- evidence_status는 설계 수준 E이며 generation_validated는 false다.
- 기존 후보 ID 목록이 빈 것은 중복이 없다는 뜻이 아니라 원본 대조를 하지 못했다는 뜻이다.
