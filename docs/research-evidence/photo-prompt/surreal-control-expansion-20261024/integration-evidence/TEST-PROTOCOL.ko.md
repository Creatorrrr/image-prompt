# 이번 반영의 검증 범위

사용자의 추가 요청으로 연구 산출물을 source·검색 릴리스에 반영하고, 참고 사진을 활용한 독립 서브에이전트 3개의 서로 다른 랜덤 컨셉을 실제 생성한다. 0~3 강도 비교용 32/48장 파일럿은 이번 3장 실험과 다르며 실행한 것으로 간주하지 않는다.

## 독립 저술

coordinator가 실제 현재 사용자 request bytes, 정확한 활성 span, 과거 실제 사용자 메시지의 `surreal` 인용, 입력 파일 hash를 먼저 envelope에 고정했다. 각 에이전트는 다른 arm과 후보 데이터를 읽기 전에 현재 canonical SKILL 및 허용된 neutral precore만 사용해 controls·baseline·core·ownership·feature selection·embodiment review를 확정했다. 미지정 control override는 사용하지 않는다. 명시 surreal 주제는 saved surreal=0에서도 보존한다. reference는 보이는 얼굴·헤어 외관이며 실제 정체·나이·성격 증거가 아니다.

A는 소재 유연성, B는 연결된 그림자의 자세 차이, C는 개구부 안팎의 공간 경계를 독립 선택했다. 최초 B와 C는 세탁기/바다 장면 정체성이 우연히 겹쳤다. 최초 B는 후보 검색과 이미지 호출 전에 중복 초안으로 보존하고, coordinator가 같은 실제 request와 span으로 b2 envelope를 새로 만들었다. B는 다른 arm의 프롬프트나 세부 정보를 받지 않고 해당 장면 정체성만 제외해 새 독립 초안을 확정했다. 실제 이미지 호출의 계획 분모는 A, B2, C 각 1회 총 3회다.

## 데이터·검색

19개 새 긍정 후보는 각각 한영 원문 전체, 영향 범위, 소유자/접점/경계/정상 비교, 혼동 경계, 주장 한계를 유지한다. 16개 진단은 긍정 검색에서 제외한다. 기존 source 6개는 원문을 고치거나 새 CID로 복제하지 않는다. 보류 C07에는 긍정 source/binding을 만들지 않는다. 어느 기록도 고정 surreal 강도나 native 승인으로 바꾸지 않는다.

설치 후보 세대는 현재 설치본에 이번 35개 새 기록과 38개 binding만 추가한다. 작업 트리에만 있던 별개 데이터나 dirty code를 함께 설치하지 않는다. 현재 canonical SKILL의 저술 규칙과 기존 qualified 실행 코드의 버전/hash는 별도로 기록한다. 작업 원본의 전체 derived index도 현재 source union에 맞게 갱신한다.

같은 80개 한영 개발 질의를 이전/이후 실제 H-F2 BM25F+local cosine에 수행한다. source를 보고 작성한 개발 세트이므로 독립 holdout이 아니다. rank, 실제 managed sampling exposure, 최종 inspiration/skip, native whole-source qualification, 픽셀 성공을 각각 구분한다. 정상 질의의 optional surreal source 노출 자체는 최종 잘못된 추가와 다르다.

## 이미지

각 arm은 새 세대를 사용한 실제 source별 검토·대안 비교·compose audit·정확한 native 입력 audit·reference transport를 거쳐 1장 생성한다. 사용한 새로운 CID가 없으면 그대로 기록한다. inspiration으로 변형한 일부 관계를 원본 source 전체의 충족이라고 판정하지 않는다.

에이전트와 coordinator는 저장된 동일 원본에서 reference 외관, 주제의 가시 관계와 핵심 접점·경계를 검토한다. 부분 구현과 관측 불가는 완성 관계 pass가 아니다. 정지 사진에서 실제 물성, 자율성, 중력 반전, 지속성, 시간, 신원이나 마음을 입증하지 않는다. 모든 실제 호출·실패·저장 오류를 분모와 증거에 남긴다. 에이전트 판단은 사용자 수용을 대신하지 않는다.
