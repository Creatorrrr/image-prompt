2026-10-24 KST. 상태: 원본 조사·기존 소스 대조·후보 설계·반영 계획 완료. 운영 데이터 반영과 이미지 검증은 후속 단계다.

이번 조사에서는 **초현실 원리가 없다는 결론을 수정하고, 기존 원리를 실제 사진의 관계로 구체화하는 보강**을 우선한다. 새로운 장면은 기존 문장의 의미를 바꿔 끼우지 않고 완성 변형으로 제안한다. 설정 강도는 후보의 고정 등급이 아니라, 사용자 의미를 보존한 사진 전체에서 해당 관계가 맡는 역할이다.

## 1. 원본 접근과 증거 범위

[기준 대화](https://chatgpt.com/c/6adc3342-1ccc-83ec-b74b-6f5a0f8edb14)를 `read_thread(turnLimit=10)`로 조회했다. 한 사용자 요청과 한 최종 답변이 있었으며 `hasMore=false`였다. 생성 파일은 도구의 attachments 목록에 없어서 사용자 지시에 따라 로그인된 Chrome의 파일 미리보기·다운로드 UI로 두 파일을 가져왔다.

- [Pro 보고서 원본](input/pro-research-report.ko.md): 140,658 bytes.
- [Pro 후보 JSON 원본](input/pro-candidate-draft.json): 142,145 bytes. 후보 10개, 진단 3개, 비교군 4개·16장면, 출처 16개를 실제 파일에서 확인했다.
- [대화 조회 원본](input/thread-read.json), [취득 경로와 SHA256](evidence/acquisition.json).

Pro는 기존 72개 후보 원문·16개 진단·182개 경로를 읽지 못했다고 명시했다. 따라서 그 자료의 신규/정제/재사용 판단은 잠정 의견이다. 이번에는 실제 로컬 원문과 조건·effects를 대조했다. Pro의 파일 보관 질문 등 대화 안의 추가 요청은 조사 자료로만 취급했고, 그 대화로 새 메시지를 보내거나 Library 업로드를 수행하지 않았다.

## 3. 대조 방법과 한계

`audit_corpus.py`는 manifest의 모든 후보 ID와 모듈 해시를 확인하고, 긍정 source의 루트 `en/ko/phrase_en/phrase_ko`를 BM25로 선별한다. 영어 단어와 한국어 2글자 조각을 사용하는 **연구용 어휘 선별**이다. 실제 H-F2의 BM25F+로컬 embedding 실행이나 실제 검색 순위 측정이 아니다.

- 전체 긍정 21,281개 중 루트 긍정 문장을 가진 15,108개를 선별 대상으로 삼았다.
- Pro 후보 10개, 원리 질의 20개, 추가 저술 후보 10개에 대해 총 40질의를 실행했다.
- 관련 모듈을 포함해 707개 고유 source를 선별 스냅샷으로 저장했다. 707개 모두를 수동으로 승인했다는 뜻은 아니다.
- 최종 판단과 직접 연결된 44개 source의 전체 레코드를 별도로 보존하고 원문·조건·effects를 검토했다. [판단 소스](evidence/decision-source-snapshots.json).

`visual_profile` 내부, 중첩 realization, 별도 의미 필드의 전체 의미를 이 루트 문장 선별이 완전히 덮지는 않는다. 예를 들어 일부 그림자 자료는 루트 EN이 짧은 제목이고 실제 관계는 다른 필드에 있다. 따라서 어휘 검색 0건으로 전체 코퍼스의 의미 부재를 선언하지 않는다. 신규성 판정은 항상 **인용한 이웃 원문 대비의 차이**이며 전역 의미 중복 검사 완료 주장이 아니다.

단순한 부유·거대함·기계·유기 외피가 없어서 데이터가 부족한 것은 아니다. **원리 이름, 한 장의 관계, 실제로 읽을 수 있는 증거, 지각적 역할을 같은 것으로 다루는 곳**이 보강 우선 영역이다.

## 5. 외부 조사로 확인한 설계 근거

25개 1차 출처·작가/미술관 자료를 취득 원장에 기록했다. 일부는 서지/초록만 확인했으며 그 한계도 명시했다. 다음은 데이터 설계에 직접 영향을 준 판단이다.

1. 물리적으로 제작 가능한 장면도 범위에 포함한다. 일상 사물의 발견·조작·제작과 관계 유추를 다룬 [Reina Sofía의 Madoz 해설](https://www.museoreinasofia.es/en/exhibition/madoz-objetos-1990-1999/)과, 소품·자세·용도 변경의 맥락을 설명한 [MAK Center의 Wurm 전시문](https://www.makcenter.org/exhibitions/erwin-wurm-one-minute-sculptures)이 이를 뒷받침한다. 모든 특이한 제품이나 자세가 원하는 인상을 보장한다는 뜻은 아니다.
2. 한 관계가 전체 인상을 이끌 수 있다. [Guggenheim의 Empire of Light](https://www.guggenheim-venice.it/en/art/works/empire-of-light/)는 낮 하늘/밤 거리라는 하나의 역설을 설명한다. 이는 요소 수를 강도로 삼지 않을 설계상의 선례이며 `surreal=3`의 실험적 증명은 아니다.
3. 정상적인 부분과의 대비가 선택적 어긋남을 읽게 할 수 있다. [Boijmans의 작품 기록](https://www.boijmans.nl/en/collection/artworks/4232/la-reproduction-interdit)과 [MoMA의 해설](https://www.moma.org/audio/playlist/180/2381)은 인물과 거울의 비정상 대응을 다룬다. 실제 화분·꽃 장면은 이번 저술이다.
4. 사진적 정합성은 초현실 효과와 구별한다. [Johansson의 작업 설명](https://www.erikjo.com/about/)은 조명과 원근의 일관성을 강조한다. 의도한 이탈을 남기면서 주변을 설득력 있게 만드는 보조 조건이지, 정상 반사나 접촉 그림자 자체가 초현실 효과라는 뜻은 아니다.
5. 상태와 지속·인과를 분리한다. [Smilde의 Nimbus](https://www.berndnaut.nl/works/nimbus/)는 수초간의 현상과 사진 기록을 구분한다. [Guggenheim의 Fischli/Weiss 교육 자료, pp.8–9](https://www.guggenheim.org/wp-content/uploads/2019/12/guggenheim-teaching-materials-fischli-weiss.pdf)는 잠시 균형을 이룬 사물 사진을 설명한다. 지속 부유·실제 물리 위반·도구의 자율성은 단일 정지 상태만으로 확정하지 않는다.
6. 설명을 아는 것과 이미지에서 알아보는 것은 다르다. [NGA의 Ghost 시각 설명](https://www.nga.gov/artworks/131285-ghost)은 방 내부를 뜬 원리가 사진에서 명백하지 않을 수 있음을 밝힌다. 빈 공간 물체화 후보에 원형 용기와 양형을 함께 보이는 설계를 넣은 이유다.
7. 정상 광학도 강한 낯섦을 만들 수 있다. [Eliasson의 여러 색 그림자](https://olafureliasson.net/artwork/your-uncertain-shadow-colour-2010/), [Erlich 수영장의 유리/물 구조](https://www.kanazawa21.jp/data_list.php?d=7&g=30&lng=e), [Turrell의 작가 설명](https://www.momaps1.org/en/post/237-james-turrell-on-meeting)은 지각적 효과와 물리적 원인을 나눠 검토할 근거다. 정상 구조의 가능성이 곧 초현실 인상 부재는 아니다.
8. 기묘한 관계가 자동으로 발견된다고 가정하지 않는다. [Võ & Henderson 2009의 기관 초록](https://www.research.ed.ac.uk/en/publications/does-gravity-matter-effects-of-semantic-and-syntactic-inconsisten/)은 연구한 두 과제에서 주시 이후 처리 증가를 보고한다. 전문 PDF는 403이었으며, 모든 사진·관객에 적용되는 임계값이나 주목 법칙으로 확대하지 않았다.

새 구체 장면의 기하·정서·강도는 저술 가설이다. 작품·작가의 실제 구성이라고 귀속하지 않는다. [출처별 열람 범위](sources.json).

특히 Pro의 C09 ‘규모 원리 재사용’은 **개념 연구 차원에서만 맞는다**. 현재 `cand_f78b8c…`는 의자와 작은 문, `cand_55c2da…`는 사물이 광대한 환경으로 변한 장면, `cand_99877…`는 정상 찻잔과 거대한 먼 배경이다. 어느 원문도 허리 높이 찻잔을 닦는 관계와 같지 않다. 재사용이라고 이름 붙여 source의 전체 의미를 바꿔서는 안 된다.

C07 보류의 이유는 현실에서 제작 가능해서가 아니다. 현재 제안이 평범한 보수·박리 장면과 구별되는 관계나 의도한 인상을 아직 충분히 설계·검증하지 못했기 때문이다. 반대로 C04·R20은 제작 가능한 조형/정렬이더라도 기능·재현 관계의 낯섦을 연구할 가치가 있다. 이 구분을 일관되게 유지한다.

## 7. 시각 의미 레지스트리의 구조

기존 12군을 없애거나 역사적 장르 정의를 바꾸지 않는다. 새 12개 원리는 기존 가족군과 교차 연결하는 **연구용 의미 층**이다.

- 원리: 무엇의 어떤 관계가 바뀌는가.
- 완성 실현: 현재 보이는 대상·소유자·상태·접점·경계는 무엇인가.
- 증거 설계: 선택한 실현의 모든 핵심을 한 사진에서 어떻게 구별할 것인가.
- 혼동 경계: 정상 광학·조형·제품·흔적·생성 오류로도 읽히는가.
- 주장 한계: 시간·인과·의식·생명·기억·동의·실제 물성은 무엇까지 미확인인가.
- 표현 역할: 보조/명확/주도는 장면별 의도와 실제 리뷰의 별도 값이다.

‘온화함·서정성·유머’는 관계의 대체물이 아닌 의도된 반응 가설이다. ‘비기술적 장면’도 실제 제작 도구가 전혀 없었다는 주장이 아니다. 출처 작품의 주제나 인물의 실제 생애를 새로운 사진의 참조 인물에게 부여하지 않는다.

등록·검색 노출·소스 적합성·최종 반영·실제 픽셀·사용자 선호를 하나의 L/R/E/V 점수로 합치지 않는다. Pro의 구분은 연구 설명에 유용하지만 현행 native 자격이나 새 품질 게이트로 자동 승격하지 않는다.

## 8. 강도 비교와 평가 설계

[강도 비교 계획](calibration-plan.json)은 Pro의 4개 비교군을 보존하고, 도자 커튼·우산 그림자·서리 가지·봉제 문틀 4개를 추가해 총 8군·32장면으로 구성했다. 새 4군은 장면 설계 수준이며 generator-ready frozen core가 아니다. 이미지 호출은 수행하지 않았다.

비교에서는 관계 1개를 1·2·3에서 같은 형태로 유지할 수 있는 군을 우선해 역할 차이를 살핀다. 이 통제는 **실험 설계**이며 모든 실제 창작에서 관계 개수·형태·크기를 고정하라는 새 규칙이 아니다.

평가 순서:

1. 단계 숫자·프롬프트를 가린 상태에서 보이는 대상·사건·주된 인상을 자유 서술한다.
2. 사용자 요구와 의도한 관계를 제시하고 의미 보존·관계 구현·판독 여부를 확인한다.
3. 해당 관계가 보조/명확/주도 중 무엇으로 읽히는지와 정상 대체 설명을 기록한다.
4. 작품 선호·정서·주제 적합성을 별도로 판단한다.

관계 미구현, 관측 불가, 정상 대체 해석 우세, 강도 역할 불일치, 사용자 의미 상실을 구분한다. 작은 관계가 안 보이는 것은 강도 1 성공이 아니고, 손·반사의 생성 오류가 강한 인상을 준 것은 강도 3 성공이 아니다. 사용자 지정 용이 남아 있는 `surreal=0`의 전체 비현실감이 높아도 설정 실패가 아니다.

첫 검토는 4군×4단계의 16장으로 실패 유형을 찾고, 관계가 판독될 때 Pro의 3반복 48장 파일럿으로 확장하는 순서가 합리적이다. 이는 장수 보장·통계적 검증·이번 작업에서의 이미지 생성 승인이 아니다. 동일 seed는 지원될 때만 기록하며 구도 동일성을 보장한다고 하지 않는다. 원본·실패 이미지·전체 호출 수를 모두 보존한다.

## 9. 반영 우선순위와 완료 조건

상세 파일·단계·검증·롤백은 [IMPLEMENTATION-PLAN.ko.md](IMPLEMENTATION-PLAN.ko.md)에 있다.

1. **첫 묶음:** P0의 9개 새 완성 변형과 기존 R23 작은 문 재사용을 검토한다. 반사·재질·기능·날씨·규모·그림자·건축·국소 예외를 함께 다루므로 소품 하나의 변주에 편중되지 않는다.
2. **둘째 묶음:** C03/C06/C08과 R12/R14/R15/R18/R20. 정상 대체 해석·설명 의존성·신체 접촉의 관측성을 먼저 검토한다. R15가 새 보완을 주지 않으면 승격하지 않는다.
3. **후속:** C10/R19의 복잡한 방향·액체 관계. R21 계단 루프 등 기존 후보는 전체 계약을 유지하며 재사용한다. C07은 보류한다.

‘충분’의 판단은 총 후보 수가 아니다. 첫 묶음에서 서로 다른 원리가 실제 요청으로 발견되고, 완성 관계를 요청 의미 안에서 사용할 수 있고, 0에서 추가 처리가 생기지 않으며, 1·2·3에서 관계 판독과 역할 차이가 리뷰될 때 단계적으로 충분성을 판단한다. 이번 리서치만으로 이 이미지·사용자 기준을 충족했다고 선언하지 않는다.

## 10. 이번 작업의 실제 산출물
