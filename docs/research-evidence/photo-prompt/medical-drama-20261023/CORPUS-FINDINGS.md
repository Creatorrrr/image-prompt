# 기존 코퍼스와의 차이

읽기 시점 manifest에 연결된 95개 모듈에서 후보 21,252개와 바인딩 16,069개를 확인했다. 모듈별 SHA와 읽기 전후 일치 여부는 [corpus-snapshot.json](corpus-snapshot.json)에 저장했다. 이는 실시간 검색 성능 수치가 아니다.

`content.en`, `ko`, `definition`, `phrase_en`, `phrase_ko`의 literal 검사에서는 `stethoscope` 2, `triage` 1, `handoff` 62, `splint` 1건 등이 나왔다. `surgical gown`, `nasal cannula`, `lithotomy` 등의 정확한 문자열은 해당 지정 필드에서 0이었다. aliases·연구 메타데이터·개념상의 다른 표현까지 포함한 부재 증명은 아니다. 기존 의료 장비 소스가 정식 용어 대신 외부 구조를 서술하는 사례를 실제로 확인했다.

청진기 2개는 `a veterinary stethoscope`, `a stethoscope prop`으로 소품 수준이다. 전자는 한국어 필드가 영어를 반복하고 있다. 이를 일반 사람 진찰의 기구로 바꿔쓰기보다 원래 수의학 의미와 조건을 보존하고 번역 수정 여부를 별도로 검토한다. 신규 D01은 귀·손·청진판·환자의 가슴을 연결하는 전체 행위이므로 더 넓은 효과 검토가 필요하다.

`triage` 예시는 건축물 안전 판정이며 관련 primary tag 전제를 갖는다. `splints` 예시는 가는 나뭇조각·불쏘시개다. `handoff`에는 석기시대 기구 수리나 허구 길드 물증 인계가 포함된다. 이런 어휘 중첩은 기존 소스를 임상 용어에 기계적으로 합치면 안 된다는 근거다. 62건 전체가 비의료라는 결론을 내리거나 실제 hybrid 검색 실패로 계산하지 않았다.

## 정본 재사용 비교

[existing-source-mapping.json](existing-source-mapping.json)은 22개 재사용 제안의 **실제 소유 파일, 전체 record, 한영 문장, intrinsic conditions/effects, application contract, 모든 manifest binding, 비교용 의료 레지스트리 기록**을 저장한다. R01–R22의 ID 대응은 [VISUAL-CARDS.md](VISUAL-CARDS.md)에 있다.

|범위|재사용할 의미|이번에 새로 필요한 부분|
|---|---|---|
|R01–R05|수술등·기구대, 분리된 ICU 장치, 전실·문 경계, 영안실 문, 현미경·슬라이드|진료·돌봄·재활·회진·업무 인계의 행위자 관계|
|R06–R14|독립 검경, 배액·주입·입/목 호흡관, 검사 가운, 검체병·슬라이드|캐뉼라/비위관, 산소마스크, 각 손·피부·장치 연결, 주사기펌프|
|R15–R18·R22|봉합·피부층·어두운 표면·잔존지·흉터의 한정된 외형|상처 원인·진단을 분리하는 문맥; 실제 고도 손상은 보류|
|R19–R21|사생활 가림막, 성인 연출 세트, 세워진 수술포|가림막과 수술포의 목적·형태를 서로 교체하지 않음|

R15의 CID는 현재 바이오펑크 모듈이 소유하며 의료 레지스트리 D16의 짧은 요약과 실제 문장이 다르다. 이 연구에서는 정본 문장과 바인딩을 사용했다. 레지스트리에서 가져온 그래프는 검토용이며 새 native 의미의 근거가 아니다. 다시 qualification할 때 정본과 그래프를 대조해야 한다.

기존 R19의 닫힌 가운·가림막, R20의 완전 착의 성인·백의·장갑, R21의 얼굴과 가려진 하체 작업 구역은 선택 시 그대로 의미를 가진다. 관련 용어를 검색했다는 이유로 강제하지 않고 명시적 노출·인원·역할·구도 요청과 전체 의미가 맞을 때만 선택한다. R18의 `healed`도 묘사된 상태와 실제 치유 증명을 분리해 검토한다.

## 아직 하지 않은 것

현재 설치 검색에서 새 후보 노출, 기존 native 자격 재검증, 인덱스 재구축, 새 프롬프트 작성·생성 호출은 하지 않았다. 각 정본의 해시가 후속 구현 시 달라졌다면 이 스냅샷을 현재 상태라고 쓰지 말고 전체 비교를 갱신한다.
