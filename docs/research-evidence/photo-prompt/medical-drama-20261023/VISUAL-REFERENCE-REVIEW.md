# 공개 도판의 직접 관찰 범위

2026-10-23 KST, 공개 OpenStax 도판을 인앱 브라우저에서 열고 스크린샷의 실제 픽셀을 관찰했다. 원격 이미지를 내려받거나 재배포하지 않았다. 페이지의 저작권과 이용 조건은 원 출처를 따른다.

세 도판은 [수술 중 고려사항 표 26.4](https://openstax.org/books/medical-surgical-nursing/pages/26-2-intraoperative-considerations)에서 실제 연결을 따라 찾았다. 잭나이프 이미지 링크는 웹 도구에서 실패했으며 픽셀을 보았다고 표시하지 않았다. 역사 복식 두 소장품도 설명·부품 기록만 읽었다.

후보 문장에는 도판에서 보이지 않는 임상 효과를 추가하지 않았다. 이 기록은 출처 도판의 관찰이며 생성 이미지 검증 기록이 아니다.
