# 접근·근거·검증의 범위

원 대화는 기본 도구에서 잘린 뒤 로그인된 Chrome의 보이는 본문과 표에서 전체 추출했다. 사용자 요청과 답변을 보존하고 관련 없는 사이드바·입력 UI는 제거했다. 원 대화의 링크는 조사 출발점이며 원 대화의 인용 표시 자체를 사실 검증으로 쓰지 않았다.

외부 출처 49개의 접근 상태는 [sources.json](sources.json)에 개별 기록했다. 공개 본문, 특정 구간, PDF 텍스트, 검색에 노출된 본문, 짧은 검색 요약, 실패를 구분한다. 웹 응답의 navigation만 확인한 경우를 본문 전체 독해로 표시하지 않았다. 임상 지침은 해당 기관·국가의 문맥이며 개별 환자 치료나 법적 효력의 지침으로 작성한 자료가 아니다.

WMA 페이지는 직접 열기에서 502가 났고 검색 노출분만 확인했다. 현 환자와의 성적 관계에 관한 특정 조항을 현행 전문에서 확인했다고 주장하지 않는다. WHO 재활 페이지는 직접 열기 timeout 뒤 검색 본문을 사용했다. WHO 존중받는 산모·신생아 돌봄은 출판 개요를 확인했으며 전체 책을 읽지 않았다.

Fanlore sickfic·whump는 검색 노출분을 확인했으나 직접 페이지는 403이었다. Hurt/Comfort 직접 페이지와 Oxford 참조 장은 접근 불가이며 근거 앵커에서 제외했다. 원문에 있는 개념이라는 출처만 보존한다. 특히 Oxford 전문·초록에서 성문화 정의나 역사적 주장을 읽었다고 쓰지 않았다.

직접 이미지 픽셀을 본 것은 OpenStax 체위 도판 3개다. 박물관 제복·케이프는 catalogue 서술·부품 기록만 읽었으며 원물의 재질·봉제·접힘을 픽셀로 검증한 것이 아니다. [도판 관찰 기록](VISUAL-REFERENCE-REVIEW.md)을 참조한다.

신규 후보의 구도·손·옷·소품 배치는 작성자의 시각적 제안이다. 출처가 해당 장면의 임상 정확성·소유 그래프·감정 효과를 증명하는 것은 아니다. 346개 행은 원문 보존·연결 범위이지 개별 정의의 검증 완료 수가 아니다. 100개 신규 초안도 중복 검토가 끝난 순증 운영 데이터 수가 아니다.

운영 코퍼스의 literal 검사는 지정 필드의 문자열 검사다. 실제 semantic/hybrid 검색은 실행하지 않았다. 현재 installed recorder의 읽기 전용 검사 PASS는 Python 의존성과 원장 지원 상태의 확인이며 연구 데이터의 노출·선택·생성·설치를 확인한 것이 아니다.

연구 무결성 검사는 참조 존재·역참조·한영 필드·완전 소스 복사·파일 해시·보호 파일 변화를 확인한다. 임상적 정확성 전체, 정당한 동의, 특정 진단, 실제 술기 안전성, native 자격, 픽셀 충족, 미적 개선, 사용자 수락을 검증하지 않는다. 후속 반영 전에 변한 정본은 재기준화한다.
