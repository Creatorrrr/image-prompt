## 데이터와 프롬프트

독립 초안·코어·테스트케이스를 후보 데이터 접근 전에 동결했다. 저장 기본값은 sensual=1, fetish=0, creativity=1, surreal=0으로 유지했다. 조회는 명시된 봉인 릴리스 `1d3013b5e422e72eb80bdd75189ebe25575ffa92aecc3378ed8ba79358b897bd`에서 세 슬롯과 주제·초안 검색을 더한 5개 검색으로 수행했다. 37개 고유 자료, 40개 쿼리 발생을 전체 조건·효과와 함께 검토했다.

새 의료 자료는 C07, D06, A10, A01 네 항목이 노출됐다. D06의 전체 커프·관·측정기 문장은 독립 초안에 이미 있었으며 최종안에 유지했다. A01의 마주 앉기·열린 책상 끝·옆 벽 진찰대 문장은 제한적인 배치 보강으로 유지했다. 둘 다 `inspiration_only`이며 `native_approval=false`를 그대로 유지했다. 검색·메타데이터와 실제 픽셀 판정을 분리했다.

참조 이미지는 얼굴·머리의 외형 안내로 실제 첨부했다. 실제 신원, 직업, 나이, 동의나 진단은 주장하지 않았다. 출력의 측정기 숫자는 화면 안 표시일 뿐 실제 측정 정확성·장치 기능·치료 결과를 입증하지 않는다.

초안·최종안·8개 완전한 대안을 `composition-comparison.md`에 비교했다. 최종 선택은 차분한 진료 만남과 참조 얼굴을 유지하면서 탁자 위 호스 경로를 분리하려는 구도다. 실제 이미지는 시선 교환, 얼굴 존재감, 전경의 의료 장비와 창빛이 잘 연결되어 시각적으로 설득력 있으나, 위의 두 전체 게이트 결손은 남는다.
