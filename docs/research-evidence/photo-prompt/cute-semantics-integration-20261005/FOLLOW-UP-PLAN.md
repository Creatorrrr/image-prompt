현재 요청의 데이터 반영과 독립 3개 컨셉 테스트는 완료했다. 다음 보강은 이번 실패와 노출 gap을 다루되, 이미 동결한 core·testcase·이미지 판정을 보존한다.

| 순서 | 조사·반영 작업 | 완료 기준 |
|---|---|---|
| 1 | 현재 세 pack의 대상 후보·프로필 누락을 슬롯 활성화, 구성요소 충족, bounded inventory, 질의 문장, 후보 순위별로 분리한다. 원래 core와 pack을 그대로 재현하고 의미가 같지만 표현이 다른 독립 holdout을 사전에 고정한다. | 누락마다 검증 가능한 원인과 실제 DATA ID·질의·슬롯을 기록한다. alias 추가가 가능한 문제와 검색 정책 문제를 구분한다. |
| 2 | 기존 정의에 완전히 대응하는 표현만 paraphrases 및 concept_terms에 더한다. 사진적 캐치라이트·한쪽 발 접지·두 손 접촉처럼 실제 구성요소가 다른 상태는 별도 후보로 유지한다. 넓은 문화어를 고정 형태나 의무로 만들지 않는다. | 기존 의미·owner·effects·전제 조건 보존과 독립 holdout 검색 결과를 함께 통과한다. 테스트에서 관측한 한 문장을 그대로 alias로 붙여 성공을 만드는 방식은 쓰지 않는다. |
| 3 | 원인 검증 후 DATA를 새 버전으로 동결하고 새 core·새 testcase에서 전후 데이터를 비교한다. 선택형 후보·프로필의 실제 노출과 선택을 각각 기록한다. | 보강 전후 팩 비교에서 의미 보존과 노출 차이를 확인한다. 프로필 참조와 직접 활성화를 혼동하지 않는다. |
| 4 | 새로 추가한 15개 후보의 접촉·소유·가시성을 소규모 개별 케이스로 검사한 뒤 복잡한 합성 장면으로 확장한다. 손가락은 겹침이 적은 투영과 충분한 촬영 거리를 먼저 검사하고, 고개 각도는 사전에 정한 화면 축과 범위로 평가한다. | 각 필수 구성요소가 같은 원본에 보인다. 가림·누락·부분 표현은 실패로 남긴다. 현재 박물관의 실패 기준을 완화하거나 초기 원본을 교체하지 않는다. |
| 5 | 실제 사용자 선호 판단과 기술적 형태 판정을 별도로 받는다. 등불 축제는 이미지 미반환 상태를 유지하고, 새 실행이 허용될 때 기존 차단 요청과 연결해 기록한다. | 실제 반환된 원본만 채점하고, 사용자 수락은 직접 판단 근거가 있을 때만 갱신한다. |

이 문서는 다음 실행의 계획이다. 이번 결과에 새 후보 전체의 픽셀 통과, 생성 품질 향상의 인과 증거, 차단된 이미지의 내용 또는 사용자 수락을 소급해 부여하지 않는다.
