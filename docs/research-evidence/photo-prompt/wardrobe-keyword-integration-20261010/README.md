# 의상 키워드의 소유자·관계 데이터 반영과 독립 이미지 시험

2026-10-10 요청에 따라 이전 연구의 전체 범위를 원본 데이터로 반영했다. 후보·프로필·번들 각각 146개를 추가했고 관련 검사 72개를 통과했다. 독립 arm 3개가 실제 생성 도구를 각각 한 번 호출해 이미지 2장과 출력 심사 차단 1건을 기록했다. 전체 필수 픽셀 조건을 통과한 이미지는 없다. [최종 결과](RESULTS.md)와 [DELIVERY.json](DELIVERY.json)은 데이터 검증과 실제 이미지 판정을 구분한다.

## 데이터 반영

- 원본 연구: `../wardrobe-keyword-semantics-20261010/`의 503개 표제어, 125개 카드, 150개 후보 초안.
- 관찰 가능한 관계 카드 114개를 처리했다. 이 중 기존 후보 ID 4개를 유지하고, 나머지 구체 선택 변형에 후보·시각 프로필·번들 각각 146개를 추가했다.
- 11개 모호성·선택·주석 카드는 유지보수 기록에 보존한다. 원래의 20개 조합은 선택 참고이며, 23개 제외 조건은 과거 문맥에만 속한다.
- 키워드 사전의 표제어를 구체 변형의 동의어로 일괄 복사하지 않았다. 광택·비침·연결·상태가 다른 것은 각각의 대상과 끝점을 작성했다.
- 사전 슬롯 19개를 재사용했다. 원본 추가는 새 후보 확장과 새 시각 프로필 확장에 묶고 현재 source manifest에 등록했다.
- 기존 미완료 변경은 삭제하거나 재설정하지 않았다. 파생 인덱스는 최종 작성 원본의 합집합을 기반으로 다시 만든다.

## 연구 초안에서 구체화한 점

53개 선택 변형의 미작성 관계 끝점을 채웠다. 예를 들어 홀터의 목 연결과 스파게티 끈의 어깨 연결, 메리제인 인스텝과 발목 샌들의 고정, 커프의 봉제·접힘·독립 착용을 나눴다. 넓은 카드의 변수는 허용된 하나의 구체 선택으로 작성했으며, 해당 선택을 보편 정의로 주장하지 않는다.

원자료의 추정이나 불명확성을 그림의 확정 사실로 바꾸지 않았다. 보이는 실과 광택은 화학적 섬유 함량·숨은 지지 방식·연대·사적 동기의 증거가 아니다. 의상 곡선과 관절 위치도 참조 인물의 실제 체형·연령·신원을 확정하지 않는다.

손과 천의 접촉, 다리의 자세, 소품의 배치, 지역 비침, 인쇄 숫자, 카메라 시점이 영향을 받으면 해당 효과를 선언했다. 트레이 전달과 사탕 전달은 허용된 두 행위자의 존재를 전제로 한다. 선택 후보 하나가 잠긴 인물 수를 바꿔 다른 인물을 만들 수 있다는 뜻은 아니다.

새 관계의 전체 문장을 직접 요구한 경우를 위한 좁은 exact 활성화만 작성했다. 넓은 스타일명·색상명·사전 키워드·부분 일치·BM25F/임베딩 근접 결과는 자동 의무가 아니다. 후보를 채택하면 그 선택의 전체 증거와 원본 픽셀 게이트를 적용한다.

## 최초 조회의 발견 경로 보완

첫 게시 세대에서 각 arm은 서로 독립적으로 고정한 core를 실제 조회했다. 신규 일반 후보는 A 1개, B 0개, C 2개였고, 신규 시각 개념은 세 arm 모두 0개였다. 세대에 데이터가 포함된다는 검사와 자연스러운 작성문에서 그 데이터가 발견된다는 검사는 다르다. 기존 완전 문장만으로 작성한 구성요소 match terms가 후자를 제한했다.

146개 프로필 전부에 긍정적인 짧은 관찰 표현을 추가했다. 여러 구성요소가 있는 관계는 서로 다른 그룹을 모두 충족해야 발견된다. 선택 변형은 서로 다른 표현을 유지하며, 이 발견 경로는 exact 활성화나 채택 후의 전체 증거·픽셀 기준을 대신하지 않는다. 특정 arm의 후보 순위를 올리거나 core를 새 데이터에 맞춰 다시 쓰지 않았다.

WK095의 치마 압축은 원자료의 일반적인 좌면 접촉 관계로 복원했다. 처음 작성한 특정 의자 제약은 필요하지 않았으며 벤치에서도 같은 관계를 표현할 수 있다. 첫 pack과 해당 진단을 보존하고, envelope·controls·core·baseline·selection을 byte 그대로 유지한 별도 run에서 보완 세대를 다시 조회한다. 이는 인덱스 보완 전후의 발견 비교이며 이미지 재시도가 아니다.

부모의 비교에서 세 arm의 중립 작성 입력은 동일했다. A는 검색 seed도 유지했으나 B와 C는 새 run에서 검색 seed가 달라졌다. 따라서 B·C의 후보 수 전후 변화는 seed를 통제한 인과 실험이 아니다. 전체 연구는 새 데이터가 현재 검증 세대에서 발견·선택·작성·전송·렌더에 쓰이는 경로를 시험하며, 데이터 수정만의 성능 증가를 추정하지 않는다.

## 독립 시험의 경계

부모가 실제 사용자 원문을 그대로 고정한 envelope를 각 arm에 전달했다. 서로 다른 request ID를 제외하면 원문과 활성 범위는 같다. 각 에이전트는 처음부터 최신 스킬과 정확히 허용된 중립 precore 입력만 읽고 독립 컨셉·feature selection·기초 프롬프트·core를 고정한다. 연구 문서나 다른 arm의 산출물은 컨셉 작성에 사용하지 않는다.

컨셉의 구체 의상·소품·행동은 에이전트 선택이며 사용자 지시로 재라벨하지 않는다. 각 arm의 core 동결 뒤 같은 검증 런타임 세대에서 후보를 조회한다. 호환되는 신규 후보를 선택한 뒤 감사한 최종 프롬프트와 실제 첨부한 동일 참조 사진으로 최초 이미지 1장씩 시험한다. 참조 역할은 보이는 얼굴·헤어이며 실제 인물의 신원이나 전신 유사성에 대한 주장과 구분한다.

각 이미지의 필수 관계는 같은 저장 이미지의 원본 해상도에서 확인한다. 일부만 보이거나 끝점이 가려지면 통과가 아니다. 전체 상황·미학, 정확한 요청 충족, 기술적 감사, 사용자 수용은 각각 별도로 기록한다. 3개 사례의 성공이나 실패를 146개 후보 전체의 성공률 또는 데이터 단독 인과로 일반화하지 않는다.

## 유지보수 계보

`extension-maintenance/wardrobe-owner-relations-20261010-v1.json` 이후 기록은 초기 스키마·paraphrase 계약의 수정, 불투명성/투광성의 교차 경로 잠금 보완, v6의 선택적 발견 표현과 일반 좌면 의미 복원을 보존한다. 현재 확장의 `maintenance_ref`가 가리키는 최종 기록과 원본 해시를 검증한다. 과거 기록은 덮어쓰지 않는다.

첫 회귀의 두 실패 중 하나는 `one tray`와 `same tray`를 다른 문자열로 취급한 검사 오류였고, 다른 하나는 불투명 몸판·시어 소매의 transmission 잠금 경로가 빠진 실제 선언 결함이었다. 검사 오류는 같은 객체 지시를 검증하도록 수정했고 실제 결함은 양쪽 carrier의 opacity/transmission 효과를 추가했다. 실패 로그와 수정 후 로그를 모두 남겼다.

전체 unittest discover는 첫 조회 피드백에 따른 원본 보완 전에 중단했다. `full-suite.log`는 전체 통과 증거가 아니다. 최종 원본과 인덱스에 대해 실행한 변경 관련 검사 범위와 결과는 최종 DELIVERY에 기록한다.
