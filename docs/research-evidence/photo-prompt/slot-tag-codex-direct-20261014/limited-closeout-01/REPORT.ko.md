## 필수 확인

고정 사례는6종이다. 기존 입력·코드가 같은 검색/제시/issued receipt/구성, 부적합 역할·조건 거부, 의미 있는 조건부 템플릿의 연구상 오진단 방지, 실제 owner/alias/receiver·원래 잠금, source authority 우회 회귀는 [정확한 기존 증거](ESSENTIAL-EVIDENCE.json)로 재사용했다. 기존 source102 실제 BM25F+로컬 cosine/RRF·receipt·6220 구성은 비활성 연구 증거이며 quality WARN을 포함한다. 그 연구 검증에는 로컬 문서37건·질의150건의 추론이 있었고, 이번 축소 마감은 해당 증거를 재사용하여 새 추론0회다. 현재 운영 데이터의 의미 평가로 바꾸어 부르지 않는다.

[이번 무결성 확인](INTEGRITY.json)은 전체 운영 본문·종류·출처·조건·효과·catalog·binding·정책이 원본과 같고, 모든 ID/참조 검증·중복 관계0·고아 binding0임을 확인했다. [실제 runtime 확인](OPERATING-VERIFICATION.json)은 기존 발행 세대fe5b593c를 lazy_verified로 acquire하고 실제 payload1개 일치, cache64MiB와 descriptor 상한 내 동작을 확인했다. 코드6개 pin과 index/corpus 결합은 그대로여서 인덱스 재빌드·벡터 추론이 필요 없었다. 최초 확인의 frozen-generation 모델 경로 오류는 검증 import만 기존 설치 경로로 고쳐 재실행했으며 원 이력은 Git과 실행 보고에 보존했다.

이번 운영 변경이 없으므로 새 전 슬롯·다국어/core benchmark, 기존/신규1,000개 표본, 반복 peer/루트 동일 검사, 실제 이미지·픽셀 평가는 생략했다. 전수 분류는 사용자 중지 시점의 worker 결과만 보존했고 의미 승인으로 통합하지 않았다. 기존32개 조건부 템플릿 종류 보정 등 미적용 문제와 전체 태그 누락/중복/의미 품질 위험은 후속으로 남는다. 무결성 통과는 전체 의미 정확도를 보증하지 않는다. 같은 모델 분업은 독립 사람·전문가 평가가 아니다.
