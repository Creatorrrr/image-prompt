A new candidate touching an envelope-relevant visibility address is conflicting or unknown until independently reviewed; no extra E or value-compatibility fiction resolves it.

## Pure API and trust boundary

`bind_source(full_context, envelope_contract)` validates structural source bindings and returns immutable bytes. Full context contains exact CID/RID, full source record, whole positive fields and ordinary units, canonical facts/E refs, ownbindings and complete selected closure/conditions/guards/profiles, source snapshot/catalog hashes. Its digest is NOT source authority. `source_binding()` produces a structural binding only.

`compare(..., expected=IndependentPins(...), primitives=...)` additionally requires exact independent externally retained source bindings, B1 view hash, pre-discovery inventory hash and manual assessment hash. These expected pins must come from trusted full-source and whole-request review/publication, never from the discovered candidate or its self-signed receipt. Python objects/hashes do not authenticate authority. The harness supplies independently fixed synthetic authority only; it does not certify the current source. Following the frozen manual_role_views pattern, a self-rehashed altered context/receipt fails against a retained expected binding. A caller deliberately replacing both trust roots is outside what a pure Python helper can detect.

The supplied view is the SAME frozen50fd92 B1 resolved view. No owner selector, descendant enumeration or second resolution runs inside compare. Exact expanded facts and canonical receiver unions are compared to source E facts and retained unchanged. Property comparison uses frozen `photo_contracts.property_effects_allowed` with that view's owner graph, preserving actual aliases/part-ancestor checks. No substring property alias exists. Normal exact/parent property protection is retained. The original permission scope is always checked independently before any envelope decision; envelope cannot waive it.

The pre-discovery inventory identifies every actual graph owner and exact scoped members, every actual core semantic anchor and every locked whole dimension, independently read inputs/spans, reviewer and reason, and exact core/input/topology binding. Machine coverage checks reject missing/extra/stale/unreviewed rows; semantic completeness is still a manual review responsibility. A hash-valid omission can be caught against a separately retained complete inventory, not deduced from natural language by the kernel.

Every canonical source E × protected anchor/whole-dimension pair needs a separate manually reviewed affects/disjoint/unknown decision, reason and input evidence. Source-positive basis is separately bound per canonical E. Affects adds a permission comparison at that actual protected address; it does not claim a generated value. Unknown rejects. Disjoint is not inferred from dimension or property vocabulary and cannot waive an original lock. All cross-candidate E pairs likewise need a manual joint decision; actual overlapping property/owner footprints are still rejected independently. Value compatibility of overlapping effects is not implemented; affects/unknown reject conservatively.

`compare` returns permission-only success plus the unchanged original E set/scope and required preservation obligations, or explicit rejection reasons. It does not apply E, produce output, validate guards, grant eligibility or audit final rendered preservation. No boolean guard-waiver or source-qualified flag is accepted.
