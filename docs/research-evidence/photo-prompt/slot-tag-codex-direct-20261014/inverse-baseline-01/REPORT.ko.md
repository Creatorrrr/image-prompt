# 기존 139개 역할의 실제 역검색 기준선

전체 공통 positive 후보 18,180개를 검색 대상으로 유지하고, 기존 139개 역할 명세마다 BM25F·로컬 임베딩·RRF를 실제 실행했다. 역할 태그를 검색 허용 목록으로 사용하지 않았다. 모든 역할의 각 lane과 최종 순위가 원본에서 다시 만든 lexical 전수 검색·전체 저장 벡터 스캔의 결과와 일치했다. 이는 순위 계산과 검색 범위에 관한 검증이다.

로컬 `google/embeddinggemma-2` 고정 공간에서 신규 질의 입력 139개를 추론했다. 캐시 적중 0개, 미확정 실행 0개, Gemini 호출 0건이다. 질의는 후보 값과 장면을 넣지 않은 한·영 역할 명세이며, 후보 없이 동결한 실제 요청 core에 결합된 runtime 질의를 대신하지 않는다.

검색·재생·전수 스캔을 합한 reader 통계는 919,366회 읽기, 15,924,386,176 bytes다. 그중 vector 읽기는 860,268회, 14,111,405,240 bytes이며, payload 읽기 55,224회와 posting 읽기 3,873회가 기록됐다. 이 합계를 일반 검색 한 번의 비용이나 cold-read 비용으로 표시하지 않는다. 검색과 오라클을 모두 수행한 관측 시간은 2,673.204초였다. reader cache 최대 67,108,864 bytes는 프로세스 RSS·모델 메모리 한도가 아니다.

각 lane 최대 384개 후보의 합집합에는 전체 실행을 통틀어 고유 후보 10,596개가 등장했다. 동일 후보를 태그별 문서나 여러 ranking vote로 복제하지 않았다. 검색에 등장하지 않은 후보도 별도의 18,250개 원문 전수 검토 대상에 그대로 남아 있다.

저장 후 별도 검사에서 139개 질의·임베딩 trace·source/catalog/index/space 결합, 후보별 정확한 원본 hash·출처, 각 lane의 ID 유일성, RRF 독립 재생을 확인했다. 이 별도 검사는 저장된 전수 스캔을 다시 실행한 것으로 집계하지 않는다. [검사 대장](SAVED-SEARCH-VERIFICATION.json)과 [실제 검색 결과](inverse-search-baseline-query-139-01.json)에 상세 근거가 있다.

**5C 의미 심사와 native 자격화는 미완료다.** 상위 후보는 Codex가 본문·효과·조건·참조를 직접 읽어 역할 적합성을 판정 중이다. 새 역할 2개를 포함한 제안 catalog 141개, 최종 운영 원본·태그·core·runtime에 대한 검색은 이 기준선이 검증하지 않는다. 기존 catalog·source/index를 고정한 중간 연구 증빙이며, 운영 데이터·벡터 공간·활성 generation을 변경하지 않았다.
