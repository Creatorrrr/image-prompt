## Validation never issues trust

`native.validate` validates source structure, modes, quotes, units, roles, source guards, profiles and references. `native.compact` validates and transports that structure. Neither issues a transport capability. Self-rehashing valid metadata can therefore pass structural validation without becoming adoptable. `native.qualification`, strict admission and selected-resolution/permission require a previously issued exact transport identity.

Only an explicit `freeze_source_authority(full_data, expected_snapshot_sha256=independently_reviewed_hash, reviewer=...)` or the private RuntimeSnapshotProvider hook after immutable generation/source/code/layout verification issues identity. The explicit freeze checks every qualified full source and closure before atomically issuing its full and compact bytes. The runtime hook registers the exact verified generation guards; a raw SearchReader checksum alone issues nothing. These trusted orchestration actions require independently chosen input authority. Candidate data, native review metadata, ordinary validator calls, compact self-hashes and composed receipts cannot invoke them through serialization. Arbitrary Python modification of internal registries is outside this serialized-input boundary; unlike V2, merely calling a public structural validator with an untrusted record is inside the boundary and cannot issue trust.
