# 오로라의 대기층 기준과 기존 지평선 표현 보존 — DATA 28

원래 정의·구성요소·증거와 원자료 재사용 메모는 행성 지평선 또는 대기층을 기준으로 한 오로라를 허용합니다. 일반 구성 지시·렌더 게이트·유일한 runtime label은 지평선만 요구했습니다. 세 곳을 정렬하되 기존 지평선 label은 그대로 두고 대기 기준의 label을 뒤에 추가했습니다.

호·커튼 주름·좁은 광선의 조합은 그대로 필수입니다. 정의의 다른 OR 문장을 근거로 이 원래 복합 형태까지 느슨하게 바꾸지 않았습니다. 지평선을 명시하는 정확 alias와 예시, 사용자가 고정한 지평선 요구도 유지했습니다.

## 검토에서 먼저 거부한 초안

처음 제안은 기존 지평선 label을 교체하여 옛 label의 수용을 깨뜨렸고, 대기층 위에 발광한다는 불필요한 공간 해석을 넣었습니다. 독립 검토가 이를 발견해 적용 전에 보류했습니다. 교체 대신 기존 label 보존+중립적인 대기 기준 label 추가로 고친 제안을 다시 동결·승인했습니다. 최초 초안과 재현 증거를 보존했습니다.

## 고정 전후 검증

첫 공개 CLI 시도 중 독립 표국 DATA가 반영되어 원문 안정성 검사가 실패했습니다. 그 4개 실행은 기록만 남기고 검증된 BEFORE로 쓰지 않았습니다. 요청·core·seed를 바꾸지 않고 표국 변경이 완전히 적용된 상태에서 4개를 다시 동결 실행했습니다.

안정된 BEFORE에서 대기층과 지평선 양성은 대상 계약을 활성화했고, 일반 발광 구름과 두 기준이 모두 없는 장면은 활성화하지 않았습니다. 완전한 구성은 대기 기준 label만 기존 허용 label과 달라 실패했고 지평선과 두 대상 없는 대조는 통과했습니다. 증거는 원래 'horizon or atmospheric layer'라는 통합 앵커를 유지한 뒤 실제 선택한 대기 분기를 설명합니다. 대기만 적은 모든 자연어 증거를 새로 허용한 수정이 아닙니다.

이 자료는 원문을 참고한 인공 정규 계약 검증입니다. NOAA 자료를 새로 물리 검증한 실험, 일반 질의 검색률, 이미지 품질 평가로 해석하지 않습니다.

## 인덱스와 비용

1,510개 프로필의 벡터 텍스트·BM25F·벡터와 9,739개 일반 인덱스 문서는 모두 그대로입니다. index의 registry fingerprint만 실제 원문과 다시 결합했습니다. 호출·비용 증가는 0이며 기존 요청 추정/준비금 구분을 유지합니다.

## KEEP 감사

함께 검토한 아인슈타인 링, 도킹, 로버, 도개교, 화살구멍, 오랑주리, 베란다, 역사적 승강장 등은 이 단계에서 바꾸지 않았습니다. 일부 요약과 상세 의무의 범위 차이는 더 강한 원문·상태 근거 없이 부분 완화하면 안 됩니다. 별도 문턱·주거 설비·이동 감사의 5개 프로필도 실제 materializer에서 허용 대안을 유지하며 23개 구성요소 생략 검사가 거부됩니다. 이 KEEP 결과를 수정 행이나 신규 DATA cycle로 세지 않습니다.

## 완료된 AFTER

4개 공개 CLI와 4개 전체 구성 감사가 모두 통과합니다. 대기 기준 사례의 runtime-expression 실패만 통과로 바뀌고 기존 지평선 사례는 계속 통과합니다. 양성 두 팩은 검토한 구성 지시·게이트 설명·label 배열 및 파생 pack ID만 바뀝니다. 음성 두 팩은 JSON 전체 동일하며 모든 후보·설명·슬롯 순서와 경고도 동일합니다. 85개 동결 BEFORE 파일 해시를 확인했습니다.

새 회귀3개 포함 space·현행 경계 집중29개와 사전 검증이 통과했습니다. 전체 저장소 또는 CI 통과를 뜻하지 않습니다. 실제 이미지를 생성하거나 확인하지 않았으므로 지평선/대기층의 픽셀 정확도 향상을 주장하지 않습니다.
