# 봄 패션 키워드의 시각 의미·후보 데이터 강화 리서치와 반영 계획

조사일: 2026-10-09 KST. 입력은 [봄 패션 용어 조사](https://chatgpt.com/c/6ac7dd42-01f0-83ee-b2e1-92d1775f13d5)의 15개 분류, 289개 키워드 행이다. 원문의 검색 조합 15개와 코디 예시 8개도 별도로 보존했다. API 본문은 20,000자에서 잘렸으므로 Chrome에서 URL·제목·렌더된 표를 함께 확인해 범위를 완성했다.

289개 행을 **118개 의미 카드, 281개 선택형 후보 문장 초안**으로 구체화했다. 각 카드는 관찰 구성, 의복·장식의 소유자, 관계, 혼동 경계, 적용 속성 제안, 관찰 조건, 기존 데이터 검토 이웃, 출처를 가진다. 섬유 성분 4개, 바이어스 컷, 브라리스 등 6개 행은 보이지 않는 사실을 직접 증명하는 후보를 만들지 않고 요청 명세로 유지한다. 나머지 283개 행에는 하나 이상의 직접 후보 초안이 연결되어 있다.

실제 반영은 **기존 의미의 동등성 검토 → 단일 변형의 구체 그래프와 효과 범위 확정 → 기존 도메인 원본 보강 → 파생 인덱스 재생성 → 검색·선택·구성 검증 → 런타임 게시 → 요청된 이미지 검증** 순서로 진행하는 것이 적절하다. 281개는 신규 엔트리 수가 아니라 검토할 표현 대안의 수다. 이번 작업은 연구 문서와 반영 계획 작성까지이며 실행 데이터 통합과 이미지 생성은 수행하지 않았다.

## 3. 원문 정의를 보강하거나 제한해야 하는 핵심 연구 결과

### 3.1 목선의 모양과 끈의 지지는 별도 축

스위트하트는 두 볼록한 곡선과 중앙의 낮은 지점이라는 윗선 형태를 가진다. 스트랩리스는 어깨·목으로 이어지는 끈이 없는 배치다. 스위트하트에 끈이 있을 수 있고, 스트랩리스의 윗선은 수평일 수도 있다. 따라서 `neckline contour`와 `support path`를 독립적으로 선택한다. [Jovani의 목선 비교](https://www.jovani.com/blog/formal-events/strapless-dress/).

U넥·스쿠프·딥 V·플런징은 이름의 강도만으로 고정 깊이를 넣기보다 폭, 곡률, 중앙 최저점, 좌우 끝점과 몸 기준 위치를 저장한다. 일부 자료는 U를 넓은 스쿠프로 설명하고 원문은 세로로 길 수도 있다고 설명한다. 이 차이를 동의어 하나로 덮지 않는다. 홀터도 목을 경유하는 경로와 등 커버리지를 별도 선택한다. [Mood의 목선 분류](https://blog.moodfabrics.com/all-about-necklines/).

관찰 기준은 같은 상의의 양쪽 윗선과 중앙 낮은 점, 또는 요청된 끈의 시작·경유·끝점을 확인하는 것이다. 머리카락이나 겉옷 때문에 끈이 보이지 않으면 스트랩리스 판정은 보류한다. 카울은 U자 외곽 하나가 아니라 같은 원단이 아래로 처져 중첩된 접힘을 형성하는 변형으로 다룬다. [Seamwork Claudette](https://www.seamwork.com/pdf-sewing-patterns/claudette-cowl-neck-dress).

### 3.2 드롭 암홀·컷어웨이·레이서백의 공존

드롭 암홀은 팔구멍의 아래 끝점이 낮아진 관계이고, 컷어웨이는 어깨·상부 몸판 쪽의 잘려 들어간 외곽이다. 레이서백은 뒷면 원단이나 끈이 가운데로 모이는 구성이다. 실제 Oner 제품은 드롭 암홀과 좁은 레이서백을 함께 명시한다. 서로 배타적인 상의 종류로 만들면 이 조합을 잃는다. [Oner의 드롭 암홀 제품](https://uk.oneractive.com/products/precisionmove-drop-armhole-tank-top-white).

드롭 숄더는 어깨 연결선 위치이므로 암홀 깊이와 혼합하지 않는다. 깊은 암홀 아래에 별도 이너가 있으면 바깥 옷의 열린 경계와 이너의 가림이 동시에 존재한다. 따라서 `outer_top.armhole.lower_endpoint`, `inner_top.coverage`, `layer order`를 각각 표현하고 어느 옷에 속하는 경계인지 판정한다.

### 3.3 뷔스티에·코르셋·컵·언더버스트의 구분

실제 뷔스티에 제품은 컵 봉제선, 언더버스트 와이어, 보닝을 별도 구성으로 명시한다. 모든 뷔스티에에 동일한 요소를 필수로 강제하지 않고, 선택된 제품형 변형의 컵·몸판·채널·여밈만 관찰한다. 원문이 인용한 Met 소장품은 이름과 작품 메타데이터를 확인했지만 텍스트에서 몸에서 떨어지는 단단한 구조까지 확증하지 못했다. 그 주장은 별도 관찰·제품 근거가 필요하다. [Natalie Rolt Elina](https://www.natalierolt.com/products/elina-bustier), [Met Bustier](https://www.metmuseum.org/art/collection/search/693847).

몰디드와 패디드의 독립성은 비패딩 몰디드 제품 설명에서 확인된다. 와이어·지지력·압박감도 외부 곡선만으로 검증하지 않는다. [Bravissimo의 T셔츠 브라 설명](https://www.bravissimo.com/tshirt-bras-for-big-boobs/). 언더붑의 용례는 성인 패션 문맥의 가림 상태로 보존한다. [Vogue Korea의 해당 용례](https://www.vogue.co.kr/2022/05/18/%EC%85%80%EB%9F%BD%EC%9D%98-%EC%96%B8%EB%8D%94%EB%B6%91-%EC%8A%A4%ED%83%80%EC%9D%BC%EB%A7%81/).

다트는 짧은 수렴선, 프린세스 심은 몸판을 길게 나누는 곡선 연결로 표현한다. 세로 선이 보인다고 보닝이 내부에 있다고 판정하지 않는다. 코르셋의 역사적 보닝·여밈 구성도 현대 모든 상의의 보편 규격으로 복제하지 않는다. [Seamwork의 다트 변환](https://www.seamwork.com/sewing-patterns/pattern-hack-turn-darts-into-princess-seams), [V&A의 코르셋 연구](https://www.vam.ac.uk/articles/corsets-crinolines-and-bustles-fashionable-victorian-underwear).

### 3.4 크롭·밑위·컷아웃·링 연결의 관계

크롭은 상의 길이, 로·하이라이즈는 하의 허리선의 위치다. 크롭 상의라고 배꼽이 자동으로 보여야 하지 않는다. 상의 밑단이 하의 허리선 위·동일·아래 중 어디에 있는지를 관계로 저장한다. 같은 캐미솔 패턴도 길이와 내장 레이어를 별도 옵션으로 제공한다. [Paradise Patterns Sommar](https://paradisepatterns.com/products/sommar-camisole-pdf-sewing-pattern-with-built-in-bralette-low-support-thin-straps-cropped-or-hip-length-sizes-bust-28-58-reversible).

실제 컷아웃, 투명 메시, 피부색 안감은 서로 다른 패널 상태다. 검증할 때는 잘린 외곽, 빈 구역, 그 아래에 있는 피부·이너·안감의 소유자를 구분한다. 광택 있는 피부색 원단을 피부 노출로 판정하지 않는다. O링 연결형은 링이 두 탭 또는 패널의 양 끝을 잇는 경우와, 링이 한 곳에 달린 장식인 경우를 분리한다. 링 모양 프린트는 구조 연결을 충족하지 않는다.

사이드붑·언더붑·미드리프는 특정 재단 이름에 묶이지 않는 가림 결과다. 원문의 성인 패션 표현을 보존하면서 요청된 부위와 가림 경계를 명시해야 후보가 선택되도록 설계한다. 몸의 크기·자세·표정·관계를 별도 요청 없이 바꾸는 효과는 포함하지 않는다.

### 3.5 스커트 길이·슬릿·랩·스코트

미니·미디·맥시의 실제 범위는 제품과 자료에 따라 다르다. 확인한 Mood 문서는 미디를 무릎 부근으로 설명해 원문의 더 긴 범위와 다르다. 최종 데이터에는 무릎 위·아래, 종아리 중간, 발목 부근 같은 기준점을 추가하고 고정 센티미터를 이름에서 추출하지 않는다. 하이로는 앞뒤 길이 관계, 튤립은 앞판의 겹침과 외곽으로 기록한다. [Mood의 스커트 분류](https://blog.moodfabrics.com/all-about-skirt-silhouettes/).

슬릿은 트임의 위쪽 끝점과 밑단까지 열린 경로가 같은 치마에 속해야 한다. 정면·옆면·두 개 트임을 별도 변형으로 둔다. 랩처럼 보이는 앞판은 실제 조절 가능한 겹침일 수도, 고정된 포 랩일 수도 있다. 사진에서 조절 기능을 추정하지 않는다. [Seamwork의 포 랩 제작 예](https://www.seamwork.com/sewing-patterns/pattern-hacks-how-to-draft-a-faux-wrap-skirt).

### 3.6 니트·소재·비침과 안쪽 레이어

포인텔은 작은 구멍의 배열만으로 끝내지 않고 구멍 둘레를 이루는 실과 반복 조직을 관찰하도록 제안한다. 오픈워크·크로셰·레이스·메시는 구멍의 크기·연결·반복과 바탕 구조를 분리한다. 인쇄된 점무늬나 피부의 점을 니트 구멍으로 판정하지 않는다. 루프·웨일·코스와 게이지는 조직을 설명하는 근거지만, 정확한 게이지나 신장률은 사진에서 확정할 수 없다. [CottonWorks의 니트 교육 자료](https://cottonworks.com/learning-hub/knitting/knit-basics/).

시어는 현재 조명과 층 구성에서 무엇이 얼마나 통과해 보이는지다. 얇은 흰 셔츠 위로 불투명 이너가 보이는 것과 맨살이 보이는 것은 다르다. `outer fabric → transmitted appearance → inner layer`를 저장해 안쪽 가림이 사라지는 오류를 막는다. 패턴 색·그림자·강한 역광 때문에 생긴 밝기 차이도 실제 투과와 구분한다.

시폰·조젯·오간자는 얇음 하나로 통합하지 않는다. 처짐, 표면 입자, 접힌 가장자리의 유지 정도 등 명시된 외관 변형을 선택한다. 해당 사전은 직접 접근에 실패했으므로 검색에서 확인한 항목 수준의 근거이며 모든 혼방을 검증하지 않았다. [Mood 원단 사전](https://www.moodfabrics.com/pages/fabric-dictionary).

코튼·리넨·실크·비스코스는 섬유 성분이고, 평직·능직·새틴·저지 등은 조직이다. 같은 섬유로 다른 조직·가공·광택이 가능하므로 이름에서 한 외관을 강제하지 않는다. 바이어스 컷은 실 방향과 재단 공정의 명세로 유지하고, 사진에는 늘어진 방향과 드레이프만 별도로 검증한다. 번아웃도 투명·불투명 구역은 관찰할 수 있으나 화학 공정과 레이저 절개를 외관 하나로 동일시하지 않는다. [CottonWorks의 직물 조직](https://cottonworks.com/learning-hub/weaving/basic-woven-fabric-designs/), [V&A Vionnet](https://www.vam.ac.uk/articles/madeleine-vionnet-an-introduction), [Mood의 번아웃 설명](https://www.moodfabrics.com/collections/burnout-lasercut-drapery-fabrics).

### 3.7 셔링·루칭·스모킹과 장식 고정점

한국어 유통 표현의 ‘셔링’은 여러 주름을 넓게 가리키기도 한다. 영어 elastic shirring, ruching, decorative smocking을 하나의 시각 의무로 만들지 않는다. 선택한 변형에서 평행한 모음 봉제줄, 중앙 고정점으로 향하는 접힘, 반복 장식 스티치를 구분한다. 고무실과 신축률은 내부 명세다. [Seamwork 셔링](https://www.seamwork.com/sewing-tutorials/a-guide-to-elastic-shirring), [Seamwork 개더](https://www.seamwork.com/sewing-tutorials/gathering).
