# 매 실행의 영감과 작품 선택을 넓히는 스킬 개선안

사용자의 수정 의도는 이 사진 스킬이 처리하는 모든 요청에서 특정 형태·구성·소재·장소·조명 등이 자동으로 반복 선택되지 않고, 현재 요청과 영감에 따라 서로 다른 작품을 만들도록 하는 것이다. 인물 사진에서는 복장과 표정도 이 범위에 포함된다. 이 문서는 단일 실행의 작성 절차를 다루며, 기존 분석과 시험 기록은 보존한다.

목표는 현재 맥락에서 새롭게 착상하고 선택하는 것이다. 같은 요청에 같은 요소를 다시 쓰는 것이 적절할 수 있다. 반복 여부를 기준으로 요소를 자동 금지하거나, 정해진 의상을 순환하거나, 과거 출력 기록을 필수 입력으로 만들지 않는다. 정확한 사용자 지시가 있으면 그 지시를 보존한다.

## 적용 범위와 분기 기준

공통 작성 절차는 특정 단어의 포함 여부와 무관하게 적용한다. ‘유혹적’, ‘귀여운’, ‘지적인’은 적용 범위를 설명하는 예시일 뿐이다. 대상·행동·관계·스타일·구도·추상적인 인상, 이들을 섞은 요청, 다른 언어와 새로운 표현, 별도 키워드 없이 장면을 설명한 문장에도 같은 원칙을 적용한다. 인물·제품·음식·건축·자연 등 사진 스킬이 담당하는 주제 전반을 포함한다.

탐색의 범위와 깊이는 전체 요청에서 확정된 의미, 사용자가 열어 둔 선택, 해석의 불확실성, 해결된 창의성 제어값으로 결정한다. 단어 목록·정규식·특정 인상 분류를 창작 지침의 활성화 조건으로 추가하지 않는다. 기존 출력과의 차이나 반복 감지도 활성화 조건으로 삼지 않는다. 이전 기록 없이 한 번 사용하는 경우에도 작동해야 한다.

사용자가 지정했거나 요청의 의미를 성립시키는 필수 형태·속성·관계는 보존한다. 정확한 복장·색상·구도 등을 요청했다면 열린 범위에서만 작성자의 선택을 적용한다. 새로운 표현이나 복합 요청은 전체 문맥에서 해석하고, 의미를 결정하기 어려울 때에는 기존 의미 해결 절차를 따른다.

## 현재 절차에서 확인한 지점

- 세 시험의 복장은 후보 조회 전 독립 초안에 이미 있었고, 최종 복장 문장은 그대로였다. 이 반복을 후보 데이터의 고정 의상 선택으로 설명할 근거는 없다.
- 현재 Phase 1은 흥미로운 사진의 방향을 정하고 열린 선택의 대안을 비교하도록 이미 안내한다. 그러나 실제 기록의 비교는 장소·관계·행동 중심이었고, 소재와 복장은 익숙한 저녁 외출 미감에 모였다. 추상적인 창작 지침이 실제 선택을 넓히지 못한 사례다.
- 일반 설정은 `creativity=1`이며 절제된 변주를 안내한다. 강한 발상 개발 계약은 창의성 3에서 후보팩이 생성된 뒤 활성화된다. 일반 실행의 첫 착상을 직접 넓히는 장치로 쓰기에는 시점과 범위가 제한돼 있다.
- 고창의성 계약은 최소 네 제안, 서로 다른 연산자, 한 규칙 변화와 발견 경로를 요구한다. 이것은 특정한 개념적 작품을 개발하는 방식이다. 일상적이거나 사실적인 사진의 독창성을 모두 이 형식으로 정의할 필요는 없다.
- Phase 3은 열린 작성자 선택의 교체를 허용하지만, 마지막 의미 검토는 구체적인 모순이 없으면 초안을 유지한다. 예술적인 재선택은 그 의미 검토 이전의 작성 단계에서 수행해야 한다.

## 1. 요청의 전체 의미를 읽고, 이번 작품의 착상을 먼저 선택한다

대상·행동·관계·스타일·인상은 전체 문맥에서 무엇을 보여 주어야 하는지 결정하는 근거다. 명시되거나 의미상 필수인 요소와 작성자가 선택할 수 있는 구현을 구분한다. 열린 선택을 익숙한 형태·배색·배경·조명 묶음으로 자동 치환하지 않는다. 인상이나 강도를 요청한 경우에도 이 공통 원칙을 적용한다.

현재 요청, 허용된 참조 범위에서 눈에 보이는 단서, 독립적인 시각 판단으로 이번 작품의 흥미로운 존재감·형태·순간·관계를 선택한다. 무엇에 시선이 끌리는지, 대상과 공간이 어떤 관계를 만드는지, 소재와 움직임이 어떤 리듬을 만드는지가 착상의 근거가 될 수 있다. 이 예시는 순환 메뉴나 매번 채워야 할 항목이 아니다. 실제 인물의 성격·욕망·지능·신상을 참조 사진에서 추론하지 않는다.

형태·배치·색·소재·구도·빛, 인물이 있으면 복장·표정·몸짓도 그 착상을 함께 구현하도록 선택한다. 하나의 부수 요소를 주제나 인상 전체의 필수 정의로 고정하지 않는다. 순수한 미적 선택도 허용하며, 모든 세부에 인과적 기능 설명을 붙이도록 강제하지 않는다.

## 2. 익숙한 첫 답을 잠깐 재고할 수 있는 선택 절차를 둔다

열린 선택이 있는 요청에서는 처음 떠오른 실현을 바로 최종안으로 취급하지 않는다. 같은 사용자 의미를 유지하면서 전체 사진이 질적으로 달라지는 실현을 짧게 비교한다. 색상이나 작은 장식만 바꾼 동일 장면을 별개의 착상으로 세지 않는다. 정확한 요청에는 불필요한 대안이나 추가 설정을 만들지 않는다.

선택 기준에 관객의 흥미, 주제의 구체적인 존재감, 형태·순간·관계의 힘, 감각적인 리듬과 전체의 통일성을 명시한다. 주제에 실제로 해당하는 기준을 적용하며, 모든 사진에 인물이나 서사를 만들도록 강제하지 않는다. 관습적으로 가장 알아보기 쉬운 실현이라는 이유만으로 다른 적합한 실현을 제외하지 않는다. 사용자 의미와 필수 시각 관계의 명료함은 유지한다.

익숙한 요소가 이번 작품에 가장 적합하면 선택할 수 있다. 핵심은 그것을 무조건적인 기본값으로 쓰지 않고, 현재 작품의 방향에 맞춰 다시 판단하는 것이다. 추가 검토를 반복 루프로 만들지 않는다.

## 3. 모든 창의성 수준에서 작성자의 선택이 작동하도록 한다

창의성 수치는 요청에서 얼마나 멀리 재해석할 수 있는지와 탐색의 깊이를 조절한다. 낮은 값에서도 열린 형태·구성·빛·표현을 현재 맥락에 맞게 새로 선택할 수 있다. 기본적인 창작 판단을 수준 3에서만 시작하지 않는다.

저장된 숫자를 일괄 상향하는 방식을 첫 수정으로 삼지 않는다. 먼저 일반 Phase 1의 작성 지침에서 ‘요청 가까이 머무는 것’이 ‘늘 익숙한 시각 묶음을 유지하는 것’으로 해석되지 않게 한다. 제어 정의를 바꾼다면 기존 숫자의 의미와 사용자 소유 설정을 보존하면서 이 구분을 명확히 한다.

한 규칙 변화나 발견 경로를 중심으로 하는 기존 고창의성 계약은 별도 개념 개발 방식으로 다룬다. 향후 일반적인 높은 창의성 사진과 그 개념적 형식을 구분할 필요가 있는지 검토한다. 이것을 바꾸려면 계약·감사·관련 회귀를 함께 수정하고, 과거 실행과 고정 증거는 보존해야 한다. ‘모든 요청에 네 제안과 규칙 변화’를 추가하는 것은 권장하지 않는다.

## 4. 후보 데이터를 이번 착상에 맞게 해석한다

사용자 의미와 독립 초안의 동결 전에 프로젝트의 후보·프로필·인덱스·기존 출력은 읽지 않는 경계를 유지한다. 첫 착상을 위해 고창의성 참고 파일이나 후보 메뉴를 사전 단계로 옮기지 않는다. 일반 작성 지침은 사전 단계에서 허용되는 `SKILL.md` 안에 둔다.

후보팩 생성 후에는 현재 착상을 더 잘 구현하는 의미와 형태를 선택하고, 열린 작성자 선택은 필요하면 교체·단순화한다. 처음 고른 소재·시간대·배치·동작이 작성자 선택이었다면 최초 선택이라는 이유만으로 보호하지 않는다. 사용자 요구, 전체 의미, 선택한 계약의 모든 구성요소는 보존한다.

시각 의미·후보 데이터의 용어 및 대체 표현 매칭은 각 표현의 의미와 시각적 구성요소를 찾는 역할을 유지한다. 이 매칭 결과를 공통 창작 절차의 활성화 조건으로 사용하지 않는다. 데이터를 보강할 때에는 필수 의미와 선택 가능한 구현 예를 구분하고, 소유 대상·구성요소·관계·적용 맥락의 조건을 보존한다. 조회 누락은 해당 항목과 검색 경로의 근거에 따라 수정하며, 특정 단어를 위해 별도의 의상·소재 기본값을 추가하지 않는다.

의미 모순을 고치는 마지막 검토와, 작품의 선택을 개선하는 작성 단계의 역할은 구분한다. 모순이 없는 초안도 열린 범위에서 예술적인 개선의 대상이 될 수 있다. 이미 완료된 시험의 초안이나 판정 기준을 사후에 바꾸어 성공으로 재분류하지 않는다.

## 5. 가벼운 기록으로 선택의 근거를 남긴다

기존 `interpreted_intent`에는 이번에 선택한 전체 착상과 관객이 경험할 주된 인상을 간결하게 담는다. `visual_priorities`에는 그것을 실제로 보이게 만드는 몇 개의 관계를 기록한다. 의미 있는 후속 수정은 기존 `authorial_decisions`에 남긴다.

새로운 요소 메뉴, 고정 대안 수, 반복 금지 목록, 순환 기록, 보편적인 독창성 점수나 새 설정값을 필수로 만들지 않는다. 단일 실행에서 스킬의 작성 절차만으로 작동해야 한다. 예술적 판단 기록을 사용자 요구나 새 잠금 조건으로 승격하지 않는다.

## 적용 순서

1. **일반 작성 지침부터 바꾼다.** 모든 요청에 공통으로 적용되는 Phase 1의 착상·비교·선택 기준과 Phase 3의 최초 작성자 선택 재평가를 명확히 한다. 특정 단어를 검사하는 분기 없이 기존 필드·숫자·검색 순서를 유지한다.
2. **제어 설명을 따로 보정한다.** 낮은 창의성 값이 계속 익숙한 구현을 고정하는 것으로 해석된다면 해석 거리와 시각적 선택의 신선함을 구분한다. 정의 스냅샷 변경은 해시 바인딩과 회귀에 영향을 줄 수 있으므로 함께 확인한다.
3. **고창의성 계약은 별도로 검토한다.** 일반적인 고창의성 사진과 현재 개념적인 규칙 변화 형식의 적용 범위를 구분하는 변경은 버전·감사·회귀를 함께 조정한다. 무거운 제안 절차를 매 사용에 강제하지 않는다.

## 검증 방법

서로 다른 독립 세션과 프로젝트 환경에서 열린 주제, 같은 열린 주제의 반복 사용, 형태·복장·색상·구도 등을 명확히 지정한 정밀 요청을 각각 시험한다. 작성 중 다른 시험 결과나 과거 작품을 제공하지 않는다. 기존 지침과 개선 지침을 비교하고 실제 요청·참조 범위·제어값을 추적 가능하게 보존한다.

먼저 초기 기본 프롬프트가 특정 형태·소재·배색·조명·구도·인물 차림을 여러 주제의 상시 답으로 사용하고 있는지 본다. 그 다음 후보 보강이 서로 다른 착상을 다시 동일한 외관으로 모으는지 확인한다. 평가에서 주제와 제약별 선택 경향을 확인하며, 실행 중 이전 작품과 무조건 달라야 하는 규칙을 적용하지 않는다.

주제 충실도, 작품 전체의 매력, 착상과 형태의 결합, 필수 구성요소와 관계의 완전성을 함께 평가한다. 단어나 요소 종류가 많아진 것만으로 개선을 증명하지 않는다. 이미지 시험이 요청되면 원본 픽셀과 전체 인상을 각각 확인한다. 프롬프트와 감사 통과를 이미지 증거로 대체하지 않고, 이미지가 반환되지 않으면 미판정으로 남긴다.

사용자의 후속 요청에 따라 일반 작성 지침을 실제 `SKILL.md`의 Phase 1과 Phase 3에 반영했다. 모든 요청에 공통인 적용 기준, 착상·비교·선택 기준, 초기 작성자 선택의 재평가를 명시했다. 제어 정의·DATA·검색 코드·역사적 증거는 그대로다. 낮은 창의성에서도 작성자 판단이 작동한다는 설명을 일반 지침에 포함했으며, 조건부 제어 정의 보정과 고창의성 계약의 별도 검토는 변경하지 않았다.

스킬 검증과 작성 격리·소유권에 관한 기존 테스트 18개가 통과했다. 새 대화 기록을 상속하지 않는 독립 에이전트 3개에서 동일 참조를 사용한 실행 시험을 완료했고, 기본 도구 3회로 이미지 3장을 반환받았다. 서로 다른 착상과 실제 DATA 보강을 확인했지만 선택 표정·추가 눌림·정밀 선 정렬에 실패가 남았다. A의 카탈로그 순서 편차와 A·B의 오트밀색 니트 반복도 기록했다. 계약 유지와 생성 성공을 보편적인 예술적 개선 증거로 확대하지 않는다. 자세한 결과는 [공통 작성 지침 독립 시험 보고서](../research-evidence/photo-prompt/universal-authorship-qualification-20261005/REPORT.ko.md)에 보존한다.
