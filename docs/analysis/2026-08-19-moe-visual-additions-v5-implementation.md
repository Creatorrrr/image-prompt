## 결론

- NTR: 기존 의미와 11개 후보를 유지하고 시각 관점만 5개 계보로 분리
- 신규 선택 요소: 기존 추가 6개 + 이번 추가 10개 = 16개

- 병합 별칭: 267개
- 결정적 사전검증: canonical 45개 + 별칭 267개 = 312/312 PASS

v5는 전체 문법을 복제하지 않는다. `illustration_moe_grammar_v5.json`은 v4 바이트, 추가 자산, 유효 의미·시각·검색 근거·호환성 해시를 묶는 작은 manifest다. 명시적 v4/v3/v2 경로는 각각 이전 v6/v5/v4 팩을 재현한다.

## 특별 경계

### 고양이 자세

`고양이 자세`와 `cat pose`는 `ambiguous` 별칭이다. 자동 활성화하지 않고 다음 계보 중 하나를 요구한다.

- `고양이 네발 자세`: 중립 네발 지지와 유연한 등선
- `고양이 발 포즈` / `냥냥 포즈`: 얼굴 옆에서 말린 양손
- `고양이 요가 자세` / `Marjaryasana`: 손목-어깨, 무릎-골반 정렬과 둥근 척추 단계

### 금태양과 NTR

금태양은 외형, NTR은 관계 위상이다. 금태양 단독 선택은 관계 이동을 만들지 않는다. 둘을 함께 명시했을 때만 금발·태닝·스타일과 세 역할·기존 결속·바뀐 관계를 각각 증명하는 synergy clause가 적용된다.

### 성인·민감 의미

암표범 자세, 판치라, 금태양, 안경소녀, 문학소녀, 암살자, 군인, 파일럿, 타이즈와 NTR 런타임은 명백한 성인을 요구한다. 민감 명칭을 프롬프트에서 생략해도 정규화 정의와 안전 판단 계보는 남고, 관찰 가능한 구성요소는 모두 결합된다. 판치라는 비노골적 부분 가림만 허용하며 암살자는 표적 계획만 보이는 비노골적 사전행동으로 제한한다.

### 문화·직무·의복 경계

- 구미호는 한국 설화 계보를 유지하고 키츠네·호리정과 합치지 않는다.
- 드래곤은 서양 네발형·와이번·한국/동아시아 용의 다리와 날개 구조를 섞지 않는다.
- 도깨비는 고정된 오니형 외모보다 물건 기원과 설화 사건으로 증명한다.
- 암살자·군인·파일럿은 한 소품이나 복장이 아니라 표적·부대·비행 과업 관계로 증명한다.
- 타이즈와 기존 스타킹은 상부 연결 구조가 반대이므로 별도 요소이며 동시 선택은 fail-closed한다.
- 붕대는 의료·지지 구조만 보존하고 상처 원인, 자해, 학대, 구속을 추론하지 않는다.

```text

                 +
moe_visual_additions_v1 (1 refinement + 16 new profiles)
                 |
                 v
```
