# 마법소녀 데이터 반영 및 이미지 테스트 상태

2026-11-07 작업 결과. 최초 작업은 사용자가 요청한 시간에 맞춰 이미지
생성 전에 중단했고, 이후 사용자의 재개 요청으로 세 이미지를 생성하고
픽셀 검토를 완료했다. 후속 결과와 최초 중단 이력은 아래에 구분해 남긴다.

## 재개 후 생성 및 픽셀 검토

세 독립 실행은 기존에 발급된 검색 자료와 각자의 동결된 구상을 유지했고,
첨부된 참고 이미지를 실제로 전달해 native 이미지 도구를 각 1회 호출했다.
구성 및 이미지 요청 감사는 세 팔 모두 통과했다. 신규 후보는 모두
`inspiration_only`이며 native 후보 승인이나 인과적 품질 개선의 증거가 아니다.

세 이미지의 review record는 유효하나 위 관찰 불가 항목 때문에 기술적
qualification은 모두 fail이다. 각 팔의 `final-prompt.txt`, 픽셀 관찰과
`visual-review.json`, `image_runs.ndjson`에 근거를 남겼다. 독립 실행
`run_manifest.json`은 1·3번에서 확인됐다. 2번은 이미지 반환 뒤 recorder
오류가 났으나 같은 결과를 `resume`으로 복구했고 이미지 재호출은 없었다.
복구된 2번 ledger에는 독립 팔 metadata가 없으며, 이미 기록된 동일 operation에
공식 manifest를 추가하는 지원 경로는 확인되지 않았다. 따라서 2번의 독립 팔
선언은 다른 실행 자료로 추적할 수 있으나 공식 manifest로 인증되지 않았다.
사후 근거와 한계는 `generated/magical-girl-tests/arm2/independence-provenance-note.md`에
별도로 남겼다.
대조 이미지를 생성하지 않아 데이터가
이미지 품질을 인과적으로 개선했는지는 확인할 수 없고, 사용자 선호도는
아직 확인되지 않았다.

## 검색과 복원

선택된 H-F2 세대는 `05eeb9e7620231c6911d559ec159f86189bf0fc90ec198cd41258f718ea0d604`,
native 세대는 `7bf18c2e1c9c248095c3dcd8c5dccf8ad6ccfb5b25c6b7692819109a1242b4f1`이다.
기존 양성 문서 25,742개와 뷰 26,927개에 신규 문서 219개와 뷰 438개를
추가했다. 헤어 보·부러진 도구·다크 폼에 대한 용어 및 서술 질의 여섯 개에서
기대 후보가 각 1위였다. 이는 개발용 검색 확인이지 이미지 품질 증명이 아니다.

V3 원본 인덱스와 H-F2/native 묶음을 갱신했고, 별도 환경에서 오프라인 복원과
인덱스 조각 1,045개의 해시, 복원 후 검색을 검증했다. 묶음은 Git에 포함되지
않는 `generated/magical-girl-hf2-20261107/offline-release/archives/`에 있다.
별도 보관·전달이 필요하며 모델과 Python 런타임은 묶음에 포함되지 않는다.

## 최초 작업의 세 독립 테스트: 이미지 생성 전 중단 이력

세 에이전트는 각자 무작위 컨셉과 동일한 사용자 제공 참조 이미지에 대한
독립 초안을 먼저 동결했다. 첫 검색은 테스트 사본의 모델 경로 오류로 모두
결과 없이 실패했고 원본 실행 기록을 보존했다. 원본 Codex 실행 기록과
실패 거래를 한정적으로 재조정한 후, 별도 run에서 세 코어를 다시 동결하고
검색을 진행했다. 재조정 기록은 기존 run의 재개나 일반적인 부분 검색 복구를
허용하지 않는다. 절차와 증거의 한계는
[한정 재조정 기록](../photo-h-f2-early-failure-reconciliation.md)에 있다.

| 테스트 | 독립 컨셉 | 검색·후보 검토 | 초안에 반영한 신규 자료 |
| --- | --- | --- | --- |
| 1 | 황혼 해변에서 종이별을 받는 장면 | 질의 5개, 고유 후보 30개 | `cand_13d45123835feb0dd741d4309ae1c93e`: 손바닥 앞의 원형 발광 문양 |
| 2 | 온실에서 꽃을 깨우는 마법 정원사 | 질의 8개, 고유 후보 45개 | `cand_328aaabded56df34b26c272fa710c6b3`: 인물 옆 곡선 광선 |
| 3 | 달빛 온실에서 변신 콤팩트를 발견하는 장면 | 질의 5개, 고유 후보 34개 | `cand_f7491e0b3ae885ca6d68352bfa96ad13`: 거울 달린 열린 콤팩트 |

당시 세 후보는 모두 `inspiration_only`로 프롬프트 초안에 기재됐고, native 채택이나
최종 감사 통과를 뜻하지 않는다. 최초 구성 감사는 필수 빈 배열 등 입력 형식
누락으로 실패했다. 수정된 입력의 재감사는 시간 한도에 맞춰 중단했다. 각 팔의
상태는 `pack_bound`, 관리된 이미지 호출은 **각 0회**였다. 그 시점에는 결과
이미지, 이미지 ledger, 픽셀 평가 및 사용자 수용 판단이 없었다.

각 초안과 근거는 Git 비추적 경로 `generated/magical-girl-tests/arm1/`,
`arm2/`, `arm3/`에 있다. 이후 사용자 요청에 따라 같은 실행을 재개해 위의
생성·검토를 마쳤다. 기존 실패 저널과 재조정 영수증은 별도로 보존한다.
