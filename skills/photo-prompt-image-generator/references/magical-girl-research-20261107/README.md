# 마법소녀 용어: 시각 의미 조사와 반영 계획

조사일: 2026-11-07. 상태: **조사·계획**, 실행 데이터·인덱스 미변경. 최신 집계는 [검토 현황](research-progress.md)과 행별 원장을 따른다.

## 범위와 증거 수준

[원 대화](https://chatgpt.com/c/6aee3bf0-55b8-83e8-95b9-c5fb61495f29)의 전체 응답을 Chrome 화면에서 확인했다. 조회 도구는 한 응답을 20,000자로 잘랐고, Chrome에는 마지막 18절과 답변 종료가 보였다. `term-inventory.csv`는 1~17절의 표 294행과 18절 조합 7행을 원래 행 단위로 기록한다. 하나의 행에 다른 개념이 들어 있는 경우가 많으므로 301은 독립 개념 수가 아니다. 13절은 3개 하위 표로 나눴다. 원문에 없던 추가 동의어, 행 밖의 상세 예시와 모든 영어·일본어 표기를 완전하게 담은 사전은 아니다. 원문의 설명도 2차 정리이며 다음 장의 출처가 지지하는 범위를 넘는 개별 정의는 검증 대기다. 최초 수동 전사 이후 Chrome 원문 표와 행별 재대조한 결과는 아래 후속 현황을 따른다.

이 문서의 구체적인 시각 제안은 출처에서 확인된 유일한 시각 정의가 아니라 **저자가 만든 선택적 예시**다. 출처, 추론, 제안, 실제 제품의 동작 확인을 구분한다. 제안에 값이 없으면 임의의 색, 연령, 성별, 노출, 폭력, 장식, 세계관 또는 고유 작품명을 추가할 근거가 아니다.

## 독립 출처 및 판단 범위

1. [스가와 아키코, 마법소녀 장르사](https://www.nippon.com/en/articles/-/12106/): 샐리형은 마법 세계에서 인간 세계로 온 존재, 아코형은 평범한 인물이 마법을 획득하는 비교 틀이고 혼합 사례도 논한다. 유형은 서사와 기원이지 단일한 의상 공식이 아니다. [사이토 구미코 논문 초록](https://www.cambridge.org/core/journals/journal-of-asian-studies/article/magic-shojo-and-metamorphosis-magical-girl-anime-and-the-challenges-of-changing-gender-identities-in-japanese-society/AAA8B9C5895D35A48C9EFC28495D4F9B)은 장르 역사·젠더 규범의 복합성을 제시한다. 본문 전체는 이번에 확인하지 않았다. [도에이의 작품 목록](https://corp.toei-anim.co.jp/ja/press/press-3787431780457364035.html)은 회사가 열거한 해당 작품군·방송 시기 사례다.
2. [V&A 로리타 패션](https://www.vam.ac.uk/articles/lolita-fashion-japanese-street-style): 프릴·머리 장식 등의 패션 관행과 코스프레를 구분한다. 패션명만으로 캐릭터 연령이나 성적 의미를 추론하지 않는다. [V&A 복식 지지 구조](https://www.vam.ac.uk/articles/corsets-crinolines-and-bustles-fashionable-victorian-underwear)와 [Met의 1760~70년 파니에 실물](https://www.metmuseum.org/art/collection/search/139668): 코르셋·크리놀린·버슬과 당시 후프 지지구의 차이를 보여준다. 현대 일본 상품명 파니에의 범위 전체를 이 실물로 정의할 수 없다.
3. [Met의 복식 용어집](https://resources.metmuseum.org/resources/metpublications/pdf/Infra_Apparel.pdf): 역사적 코르셋·크리놀린 등의 용례를 확인한다. 시대별 정의는 현시대의 모든 의상에 일률 적용하지 않는다. [Getty AAT 새틴 기록 검색 결과](https://www.getty.edu/vow/AATFullDisplay?find=&logic=AND&note=work&subjectid=300132902)는 새틴을 직조기법 기준의 직물로 분류한다. 직접 열기는 제한되어 검색 결과까지만 확인했다. 새틴이라는 이름만으로 섬유 성분을 확정하지 않는다.
4. [프리큐어 공식 장난감 정보](https://www.bandai.co.jp/catalog/item.php?jan_cd=4549660442530000)는 특정 힐링 스틱 제품의 사례다. [세일러문 피규어 공식 설명](https://tamashiiweb.com/item/15683/)은 특정 캐릭터의 교환 손·허리에 손을 둔 자세·고유 아이템을 구분한다. 개별 제품의 포즈나 실루엣을 장르 필수 요소로 확장하지 않는다.
5. [마기아 레코드 공식 용어집](https://anime.magireco.com/keyword/)은 검색 결과에서 소울 젬·그리프 시드·마녀·계약의 작품 내부 관계를 확인했다. 직접 열기는 403이어서 이번에 원문 전체를 검증하지 못했다. 해당 명칭은 작품 네임스페이스의 개념이며 일반 마법 보석·씨앗·마녀와 자동 동의어가 아니다.
6. [Adobe의 애니메이션 원리](https://www.adobe.com/creativecloud/animation/discover/principles-of-animation.html)는 예비 동작과 팔로스루·오버래핑의 시간 관계를 설명한다. 정지 이미지 한 장의 포즈만으로 진행 시간이나 재사용된 영상 뱅크를 입증할 수 없다.
7. [BFI 바디 호러 작품 소개](https://www.bfi.org.uk/lists/10-great-body-horror-films)는 신체 변화와 물질성을 다룬 사례군이다. 어두운 색, 고어, 인형화, 정신 지배, 전투 손상은 별개의 축이다. [FIT Power Mode 전시](https://exhibitions.fitnyc.edu/power-mode/)는 코르셋·가죽·부츠·하네스 등의 의미가 착용자와 관찰자에 따라 달라질 수 있음을 논한다. 소재나 파츠 자체를 성적 의도, 관계, 동의, 나이의 증거로 두지 않는다.

외부 근거는 위의 범위에 한정한다. 나노하·사쿠라 고유 도구 각각, 팬덤 용어의 커뮤니티별 차이, 모든 원단·봉제·머리 모양·개별 포즈는 아직 개별 확인이 필요하다. 위 출처들이 294개 행 모두를 검증한 것은 아니다.

## 의미 모델과 용어별 처리

### 장르·서사: 01–03

- 샐리/아코형은 `기원`·`능력 획득`에, 일상/아이돌/전사/팀/견습은 `서사 역할`·`활동`에 둔다. 한 캐릭터에 중첩 가능하며 한 유형이 특정 나이·성별·색·치마를 요구하지 않는다. 성인 히로인과 성인향은 별도 필드다. 성별 전환, 의복 전환 및 젠더 표현 변화도 각각 기록한다.
- 비밀 정체·계약·대가·고갈·시간 제한·타임루프·전향·희생은 시간, 인과 또는 배경 지식이 필요하다. 장면 바깥 사실을 픽셀에서 판정하지 않는다. 예를 들어 `깨진 보석을 쥔 지친 자세`는 고갈을 **시사하는 선택지**이지 계약·대가의 증명이 아니다. 결계는 공간 경계, 손에 든 방패는 물체로 구분한다.
- 변신 자체, 장면의 연속, 재사용 뱅크, 주문, 이름 선언, 완료 포즈를 나눈다. 단일 이미지에서는 `시작 전 / 진행 중 / 완료 / 해제 / 중단` 중 요청한 순간만 표현하며, 동시에 전후가 보이는 분할 화면은 명시 선택한다. 빛 리본이 의상을 감싸는지, 입자가 어느 파츠가 되는지, 장치와 손이 어디서 만나는지를 별도 관계로 기술한다. 소리·구호는 별도 문자 요청 없이는 글자 생성의 근거가 아니다.

### 복식·얼굴·재료: 04–10

- 스타일은 여러 구성품의 선택지 묶음이고 개별 파츠와 독립이다. 세일러풍은 칼라 모양과 앞뒤 방향, 공주풍은 실루엣/장신구, 아이돌풍은 무대복 구성, 기사풍은 갑옷의 위치, 사이버풍은 기계 파츠와 발광의 연결을 각각 기술한다. 어느 것도 지정되지 않은 파츠를 강제하지 않는다.
- 머리는 `묶음 수·위치·길이·형태`, 머리 장식은 `대상·부착 위치·방향`, 눈은 `홍채·반사광·얼굴 문양`으로 분리한다. 별 모양 캐치라이트가 눈동자의 실제 발광이나 감정 상태의 증거는 아니다. 헤드드레스는 상위어이므로 보닛·티아라와 자동 동치 처리하지 않는다.
- 몸통은 `옷 객체 → 부위 → 부착물`: 보디스/요크, 칼라, 네크라인, 브로치/리본, 허리 장식으로 나눈다. 코르셋의 내부 보닝은 보이지 않을 수 있고 장식 레이싱만으로 실제 지지 구조를 확정하지 않는다. 오프숄더와 스트랩리스는 겹칠 수 있으나 동의어가 아니다. 바스크 보디스와 페플럼도 몸판과 부착된 허리 장식으로 나눈다.
- 소매의 형태(퍼프/벨/비숍), 몸판과의 연결 여부(분리형), 손목의 옷 끝/독립 장식, 손을 덮는 장갑/갑주와 어깨의 견장/갑주를 각각 표현한다. 예: `분리 소매와 몸판 사이의 피부 또는 배경이 드러나는 간격`은 소매 분리를 판별하는 관계다. 프레임 밖이거나 가려져 있으면 미관찰이다.
- 치마는 재단(서클), 주름(플리츠·박스), 단(티어드), 외부 겹침(오버스커트), 안쪽 지지(페티코트·후프), 뒤쪽 돌출(버슬), 드레스의 뒷자락(트레인)을 구별한다. A라인은 윤곽이고 구조의 증거가 아니다. 예: `수평으로 연결된 세 단`과 `안쪽에 별도 속치마`는 각기 다른 명제다.
- 니삭스/오버니/사이하이는 끝 위치, 타이츠는 허리 연결, 홀드업은 지지 방식, 허벅지 가터와 가터벨트는 착용 위치와 연결 관계를 분리한다. 신발 높이·굽·앞코·여밈도 별개다. 눈에 보이지 않는 허리 연결이나 고정 기능을 가정하지 않는다.
- 프릴·플라운스는 형태/구성, 레이스·튤 등은 직물, 보·로제트는 장식 형태, 자수·아플리케는 제작 방식이다. 레이스 직물과 lace-up 여밈을 동음어로 묶지 않는다. 라텍스/PVC/페이턴트 가죽은 다른 재료이고 강한 반사광만으로 재료를 식별할 수 없다. 사용자가 소재를 지정하면 유지하되 이미지 평가에서 확인 불가능한 조성은 별도로 둔다.

### 모티프·도구·포즈: 11–13

- 모티프는 모양과 매체를 짝지어 기록한다: `하트가 가슴 브로치에`, `별이 지팡이 끝에`, `나비가 머리핀에`, `동일 색이 의상과 효과에 반복`. 사랑·희망·재탄생 등은 선택 가능한 연상이지 보편 정의가 아니다. 일반 카드와 타로는 판본별 슈트·트럼프·카드 구성을 기록한다. 타로에도 슈트가 있으므로 서로 무관하거나 배타적인 체계로 취급하지 않는다. 날개가 실제 신체인지 소품인지 표시한다.
- 완드/로드/스태프는 형태와 길이, 셉터는 상징적 역할을 분리한다. 콤팩트의 열림·거울·경첩, 브로치의 부착, 펜던트의 목걸이, 반지/팔찌의 착용 부위를 보존한다. 부적은 기능, 펜던트는 형태다. 한 소품의 여러 기능은 명시된 경우만 허용한다. 무기, 보호막, 마스코트/사역마는 물리적 외형과 역할을 분리한다.
- 포즈는 몸의 지지점·팔/손 방향·시선·도구 접촉·상대 위치를 기록한다. 시전은 손/도구→대상/효과 경로, 등 맞대기는 두 인물의 등 접촉, 합동 시전은 인물별 손/무기→공통 목표를 보존한다. 부유는 양발과 지면 사이 간격, 도약은 움직임 단서이며 동일하지 않다. 포즈명만으로 의도·실제 감정을 확정하지 않는다.

### 효과·어두운 상태·성인 맥락: 14–17

- 효과는 `발생점·방향·도착점·형태·밝기·앞뒤 가림`, 카메라는 `높이/각도/프레이밍`, 움직임은 `시점/궤적`으로 분리한다. 마법진은 기하 도형, 시질은 문양, 오라는 주변 영역, 림 라이트는 외곽 조명이다. 글로·블룸·스타버스트를 무조건 마법진과 한 묶음으로 넣지 않는다.
- 흑화·악역화는 언어와 팬덤에 따라 범위가 겹칠 수 있으므로 가치관·진영·행위 변화를 구체적으로 분리한다. 침식은 변화 과정, 세뇌/빙의는 외부 통제, 폭주는 제어 상실이라는 서로 다른 측면으로 기록한다. 각각 명시된 맥락 외에는 검은 옷만으로 판단하지 않는다. 상처/흉터/붕대, 피 얼룩/원인, 고어/공포 분위기, 석화/인형화, 촉수/덩굴/구속을 분리한다. 관찰 가능한 상태와 내러티브 원인·피해의 이전 사건은 별도다.
- 16절의 패션, 촬영 태도, 팬서비스, 취향, 폭력적 성적 감상 용어는 서로 동의어가 아니다. 성적 맥락에서 성인이 명백한 인물만 다루고, 미성년자 또는 미성년자로 읽히는 인물의 성적 표현과 비동의 폭력의 성적 표현은 후보로 만들지 않는다. `료나` 등은 용어의 설명·검색 맥락으로만 다루며 양성 장면 후보로 승격하지 않는다. 의상 구조와 비성적 손상·공포 개념은 관련 근거와 요청에 따라 독립적으로 보존한다.

## 실행 계획과 완료 기준

1. **원문 대조와 분해.** 301행을 원문과 재대조하고 원래 한·영·일 표기와 정의를 보존한다. `MG-08-008`처럼 묶인 비대칭/하이로, `MG-17-005`의 세 지팡이는 원본 행을 유지하면서 원자 개념 ID로 분해한다. 각 원자에 유형(대상/속성/관계/사건/설정/작품 고유/제작 용어), 의미, 대조어, 출처 및 한계, 상태를 부여한다. 필수/선택·상위/하위/유사/비동의 관계를 구분하고 영·일 표현은 근거 확인 전 가설로 표시한다.
2. **기존 자산 대조.** 원문 단어를 KO/EN/JA와 설명식 질의로 후보·바인딩·뷰·일러스트 연구 전체에 검색한다. 검색은 후보 발견에만 쓰고, 발견한 각 CID/RID의 전체 명제·조건·효과·소유자·잠금과 반환 뷰를 읽는다. 각 원자에 `정확 재사용 / 부분 사례 / 맥락만 / 진단 / 근거 부족 / 미검토`와 이유·CID·실제 출처 필드를 기록한다. 0건이나 어휘 미일치는 부재의 증거가 아니다.
3. **근거 보강.** 유형별로 학술/공식 작품·박물관/실물·제작자 자료를 수집하고, 출처별로 작품·시대·표현 매체·직접 지지되는 명제를 명시한다. 특히 17절 각 고유 도구, 팬덤어의 범위, 원단과 복식 구조는 개별 검증 전 보류한다. 상충하는 용례는 의미별로 남기며 근거가 약한 항목은 삭제하지 않고 보류한다.
4. **시각 의미 및 후보 설계.** 실체/부위/배치/재질/상태/수/소유자/가림/행동/접촉/시점/조건을 구조화하고 각 원자마다 최소 하나의 유효한 처리 경로를 결정한다. 보이는 의미는 전체 관계를 담은 선택적 한영 후보로 제안하고, 비가시적 서사는 맥락 전용으로 남긴다. 중복은 전체 조건과 효과가 동등할 때만 연결한다. 고유명과 일반 개념, 사진 소품과 실제 마법, 일러스트 효과를 분리한다. 기존 스키마가 표현하지 못하는 조건은 임의 슬롯에 우겨 넣지 않고 설계 과제로 남긴다.
5. **바인딩·맥락 뷰.** 승인된 양성 후보만 적합한 기존 슬롯에 선택적으로 연결하고, 진단은 양성 검색에서 제외한다. 한영 전체 정의·요청된 구성요소·관계·제약을 유지하는 whole/context 뷰를 작성하고 원본 포인터, 해시, 출처 범위, 구현자 판정을 기록한다. 서사만으로 특정 색·복장·성적 의도·실제 상해·연령을 주입하지 않는 충돌 진단도 추가한다. 새 사진 자산은 `photo-candidate-module/v3`, `photo-candidate-slot-bindings/v3` 및 현재 뷰 생성기의 실제 입력 계약을 준수한다. 일러스트에는 별도의 현행 자산·해시·라우팅 계약을 쓴다.
6. **결정적 검증.** 원문 행→분해 원자→근거→기존/신규 후보→바인딩→뷰의 역참조를 자동 검사하고, 누락·해시 불일치·중복 ID·미해결 용어를 보고한다. 대조 쌍에는 코르셋/보디스, 후프/페티코트, 양말/타이츠, 가터/가터벨트, 실제 방패/결계, 서사/증거, 변신 시퀀스/뱅크, 고유명/일반명을 포함한다. 명시된 금지·부정·숫자·소유자·가림과 성인 여부도 별도로 검증한다.
7. **검색·시각 검증.** 변경 전 기준과 고정된 독립 한영 질의 세트를 마련하고, 포함/배제·동음이의·장르 단독·전신/클로즈업·다중인물·명시 금지 사례를 평가한다. 후보 발견, 반환 순위, 실제 선택·컴포지션 감사, 생성물의 구성요소 픽셀 판독, 사용자 수용을 각각 기록한다. 가려진 속치마·미세한 재질·시간적 인과는 관찰 불가로 처리한다. 성공적인 검색/생성은 시각적 개선의 증거가 아니다.
8. **릴리스.** 기존 manifest의 병행 변경을 읽어 병합하고 소스·바인딩·뷰를 고정한 뒤 별도 인덱스를 빌드한다. 설치 전 고정 질의와 회귀를 검증하고 현재 선택된 런타임, 배포 잠금, 생성물의 해시 일치를 확인한다. 실패 시 기존 포인터를 유지하고 결과를 남긴다. 설치·활성화는 별개 단계다. 본 조사에서는 어느 데이터나 런타임도 변경하지 않았다.

완료는 301개 원문 행의 추적과 분해, 각 원자의 근거·판정 또는 구체적 보류 사유, 기존 자산 비교, 양성/진단 분리, 소스/뷰/인덱스 일치, 독립 질의와 시각 테스트 결과가 모두 보고될 때만 주장한다. 보류가 남으면 개수와 ID를 보고하고 미검증 항목을 완전 반영이라고 부르지 않는다.

이 절의 수치는 1차 검토 시점의 기록이며, 현재 수치는 다음 절을 따른다.

Chrome의 원문 표 20개를 직접 추출해 기존 목록의 301행과 일대일로 대조했다. 순서와 한국어 표제는 **301/301 일치**, 누락·오기는 발견되지 않았다. `source-reconciliation.json`에는 원문의 전체 표제, 영·일 표기, 설명, 작품 열과 표/행 위치를 그대로 보존한다. 이 비교는 원 대화의 기술이 사실이라는 검증이 아니다.

현재 이 후속 조사는 **미완료**다. 301행 중 71행에 출처 한 개 이상을 범위와 함께 연결했다. 그중 35행은 출처가 전체 정의가 아닌 일부·개별 사례만을 다루고, 3행은 공식 검색 결과만 볼 수 있었다. 나머지 230행은 아직 개별 외부 근거를 검토하지 않았다. 완전하게 검증된 71개라는 의미가 아니다. 원문의 묶음 용어는 행 하나에 여러 개념을 포함하므로 한 출처가 한쪽만 지지하는 경우도 있다.

기존 후보는 13개 원문 행에 연결된 17건의 비교만 수행했으며, 13행 역시 다른 후보와 전체 범위의 검토가 끝난 상태가 아니다. 나머지 288행은 기존 후보의 의미·조건을 검토하지 않았다. 비교한 후보의 원본 모듈·정규화 해시·조건·효과와 일부 바인딩을 `source-reconciliation.json`에 남겼다. 사진 런타임 노출과 픽셀 검증은 모두 미실시다. `review-progress.csv`는 각 행의 현재 검증 범위와 미검토 대상을 보여준다.

`candidate-discovery-multilingual.jsonl`은 원문 한영 표제를 `·`, 쉼표, 슬래시로 기계적으로 쪼개고 후보 `content`의 양성 설명·별칭 필드에 부분 문자열 검색을 수행한 **단서 목록**이다. 현행 manifest의 86개 후보 모듈 28,026개 레코드를 대상으로 했고, 202행에서 한 개 이상의 문자열이 나타났다. 어간 부분 일치·영어 다의어·맥락 문자열과 예시가 섞일 수 있고, 별칭 추출은 인간의 의미 분해가 아니다. 각 행에서 최대 5개만 표시하므로 전수 후보 목록도 아니다. 건수는 후보의 적합성·정확 재사용·부재·런타임 노출을 입증하지 않는다.

새로 확인한 차이: [University of Fashion 용어집](https://www.universityoffashion.com/resources/terminology/)은 페플럼의 허리 치마형 효과를 한 조각 재단이나 삽입형으로도 설명한다. 따라서 원문의 ‘붙이는 부분’만을 필수 구조로 삼지 않는다. 같은 용어집은 뷔스티에를 주로 스트랩 없는 형태로 설명하는 반면 [별도 복식 용어집](https://fashionhistory.ca/classic/glossary/)은 몸에 맞는 상의로 폭넓게 설명한다. 이 차이는 고정 동의어를 강제하지 않고 출처별 용례로 보존해야 한다.

다음 순서는 `review-progress.csv`의 **미검토 230행의 출처 확인**, 전체 301행에 대한 의미별 분해, 288개 미검토 행 및 이미 부분 검토된 13행의 후보 전체 조건 대조, 실제 소스·바인딩·뷰 설계와 독립 검증이다. 이 단계들이 끝나기 전에는 ‘빠짐없이 검증’이나 실행 데이터에 반영 완료라고 표현하지 않는다.


## 2026-11-07 2차 후속 검토: 당시 상태

이 절의 수치는 이후 병렬 조사 전 시점이다. 최신 수치는 [검토 현황](research-progress.md)을 따른다.

**아직 완료되지 않았다.** 원문 일대일 대조는 301/301행 완료지만 독립 출처가 한 건이라도 연결된 행은 97/301행이다. 이 가운데 53행은 부분 또는 개별 사례, 36행은 특정 범위의 독립 자료, 8행은 직접 페이지에 접근하지 못해 검색 결과만 확인한 상태다. 나머지 204행은 개별 출처 검토가 시작되지 않았다. 한 행이 복수 개념을 담을 수 있으므로 이 수치는 독립 개념 검증률이 아니다. 출처 연결 자체도 정의 전체의 검증을 뜻하지 않는다. `source-reconciliation.json`의 `external_evidence`에는 자료가 실제로 지지하는 명제와 나머지 한계가 적혀 있다.

기존 후보 비교는 18개 행에 걸친 34건이다. 해당 18행도 다른 후보의 검토가 열려 있고 나머지 283행은 후보별 검토가 없다. 34건은 각 후보의 원문 레코드 전체 해시, 조건·효과·발견된 슬롯 바인딩을 기록하고 원본과 해시를 재대조했다. 특히 오드아이의 중심/부분 홍채색은 서로 다른 양쪽 홍채색과 구별했고, 견갑에 다른 의복이 결합된 예는 폴드런 일반의 동의어로 취급하지 않았다. 동일 후보가 원문 여러 행에 발견될 수 있으므로 비교 건수는 고유 후보 수와 다르다. 프로필의 활성화·제외·구성요소와 적용 계약 역시 원본 레코드에서 따로 읽어야 하며, 효과만 보고 판정하면 안 된다.

`candidate-discovery-all.jsonl`은 기존 단서의 앞 5개 제한을 없애 301행의 11,134개 행–후보 문자열 일치를 모두 기록한다. 202행에 적어도 한 일치가 있고 99행에는 없다. `reproduce-candidate-discovery.py`가 manifest SHA-256 `e04e4ef09b3333fecc4eeda5e934386545c9558398fa1eee87fd84e81ce307b0` 기준 검색을 재현한다. 검색 대상은 86개 사진 후보 모듈의 28,026개 레코드에서 `en`, `ko`, `definition`, `aliases`, `semantics.definition`, `concept_candidate.concept_terms` 필드다. 기계적 한·영·일 원표제 분리와 부분 문자열 검색이므로 짧은 다의어의 오탐이 많고, 미수록 동의어·다른 필드·일러스트 및 뷰·설치 인덱스의 누락이 있다. 따라서 이 11,134건은 검증한 후보도 전체 의미상 관련 후보도 아니고, 0건은 후보 부재가 아니다. `review-progress.csv`의 남은 일치 수는 대조한 동일 모듈·ID만 제외한 작업 큐다.

### 남은 실행 계획의 구체화

1. `review-progress.csv`의 204개 미검토 행부터 각 원문의 원자 명제를 분해한다. 조합 예시는 자체 창작 조합이라는 성격과 개별 구성요소의 근거를 분리하고, 확립된 용어가 아닌 묘사에는 임의의 권위 정의를 만들지 않는다. 묶음 항목은 각 하위 개념마다 별도 근거, 출처 인용 위치, 매체·시대 범위와 불일치를 기록한다. 97행의 부분·접근 제한도 미결 조건으로 다시 열어 둔다.
2. 11,134개 문자열 단서의 각 모듈·ID를 중복 제거한 뒤, 진단/프로필/양성 옵션과 전체 명제, 적용 계약, 활성화·배제, 효과·소유자·바인딩을 확인한다. 단서에 없는 동의어·표현식·연구 뷰·일러스트 자산도 별도 확장한다. 매 행의 `미검토/정확 범위의 사례/부분/대조어/진단/보류`와 잔여 개수를 기록한다. 자동 문자열 분류만으로 완료 처리하지 않는다.
3. 근거와 기존 후보가 검토된 원자마다 `재사용 조건`, `부분만 지지`, `새 후보 제안`, `맥락만`, `진단`, `보류`를 결정한다. 가시 관계의 소유자·수·방향·접점·가림, 서사의 시간·인과, 고유명 및 매체 경계를 한영 전체 문장으로 고정한다. 구현할 매니페스트·후보·바인딩·검색 뷰와 별도의 일러스트 경로를 구체 매핑하고 미지원 스키마는 막는다.
4. 소스–근거–판정–후보–바인딩–뷰–인덱스의 양방향 추적, 고정 질의와 제외 질의, 기존 후보 전체 조건 보존, 부정·수량·소유자·미관찰 처리를 검증한다. 인덱스 설치 전 기존 런타임과 병행 변경을 다시 읽고, 검색·조합·픽셀 및 사용자 평가를 별도로 보고한다. 조사 완료와 데이터 구현·활성화는 별개의 결과다.

**완료 판정은 위 작업의 실제 결과가 301행과 분해 원자마다 추적되고 모든 후보 대조 범위가 명시됐을 때만 가능하다.** 현재는 이 조건을 충족하지 않는다.

## 병렬 검토 결과와 최종 인계

최신 수치와 검토 깊이는 자동 집계한 [검토 현황](research-progress.md), 행별 미해결과 재현 가능한 입력 해시는 [미해결 백로그](unresolved-backlog.md)를 따른다. [독립 출처 감사](agent-source-quality-audit.md)는 301행의 **첫 번째 기재 출처**에 대한 직접 확인·부분 확인·접근 실패를 기록한다. 출처가 존재하거나 한 행의 한 부분을 지지한다는 사실과 원문 행 전체가 검증되었다는 사실을 구분한다. 개별 `agent-sources-*` 파일은 출처·남은 세부 명제와 조합별 한계를 보존한다.

사진 후보 원장의 `full_record`는 기록자가 해당 전체 명제·중첩 계약·조건·효과·바인딩을 직접 비교한 건이며 `core_proposition_only`는 핵심 명제 수준이다. 원표제 검색에서 발견된 모든 단서를 최소한 핵심 명제 수준으로 분류했지만, 다른 표현·다른 필드·일러스트 자산·현재 실행 인덱스의 전체 의미 후보를 모두 찾았다는 뜻은 아니다. 미관찰이나 불명확은 부재 또는 일치로 강제하지 않는다. 모든 원자 개념과 실제 관련 후보의 심층 검증이 끝나지 않았으므로 리서치 전체를 완료로 표시하지 않는다.

- 기존 후보 중 일반 주름치마를 설명하면서 효과 필드에 특정 주름 방식을 적은 사례가 있어, 문장과 효과의 차이를 반영 전 검토해야 한다. 같은 원문 단어라도 소유자·개수·의상 조합·조건부 동작·바인딩이 다르면 완전 동의어로 병합하지 않는다.
- [일러스트 자산 감사](agent-illustration-audit.md)와 [일러스트 행별 비교](agent-illustration-comparisons.md)는 사진과 별도다. 301행에 연결한 일부 일러스트 항목은 일반 보존 가드 또는 맥락 앵커이지 그 행의 시각 의미를 구현하는 후보가 아니다.

상세한 데이터 구조, 후보·바인딩·맥락/검색 뷰, 검증과 인덱스 릴리스 순서, 현행 H-F2 빌드의 제약은 [구현 반영 계획](agent-implementation-plan.md)에 기록했다. 사용자가 요청한 재검토 상한을 따른다. 기존 기록에 모든 검토 횟수가 남아 있지는 않으므로 횟수가 세 번 미만이라고 증명되지 않는 경우 임의로 다시 검토하지 않고 보류 사유를 남긴다. 조사 결과 자체는 사진·일러스트 실행 데이터나 인덱스에 반영·활성화하지 않았다.
