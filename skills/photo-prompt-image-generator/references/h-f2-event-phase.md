# Source-witnessed aftermath material

Version7 compares a bounded bilingual aftermath intent with complete selected
primary source evidence. It follows the unchanged full-pool BM25F and cosine
lanes, RRF10 and carried-literal ordering. It changes no query text, embedding,
lane score, source bytes, population, field weight or native adoption contract.
All scored CIDs remain in the saved full order. The material return is an audited
projection of compatible source witnesses, capped at eight with no padding.

## Intent and source evidence

An affirmative physical residual effect and a completed/prior event are both
needed. An English negative comparison is no longer mandatory boilerplate.
Supported English and Korean expressions retain exact Unicode query offsets.
Quoted text, negative clauses, comparison counterparts, future-only requests,
ongoing initiating action and a time-of-day request without material evidence do
not supply the positive aftermath intent. The unchanged query/embedding still
feeds both score lanes. Unsupported intents retain ordinary retrieval.

Source phase facts come only from the verified selected RID's primary fields.
The compiler checks actual primary assertions even when the short D name lacks
phase vocabulary; lookup aliases, native tags, provenance and unselected branches
cannot supply facts. Ordinary `traces left behind` and an explicitly failed
recipe's kitchen mess can supply physical aftermath evidence. A post-event hour
alone, arbitrary wear, stationary pose and capture context cannot. Residual
settling motion differs from its initiating action. An emerging target form or
ongoing transformation does not become completed aftermath merely because a
field calls its material an `aftermath trace`. Conflicting active/post-event
primary assertions are not accepted as a positive source.

The compiler binds each selected-primary assertion and context to the actual
CID/RID, source SHA, pointer/literal and full field text; context witnesses also
carry field-text SHA and Unicode offsets. Receipt replay reopens and hashes the
primary source, including sources withheld from material rows. Missing source
providers, altered excluded records and fabricated witness evidence fail audit.

## Scene and extra context

Generic aftermath requests may use physical post-event material that has no
additional authored context requirement. A specific scene/owner request needs a
compatible source scene family; it cannot borrow a generic timing idea or an
unrelated setting as proof of that owner. The current bounded families include
an extinguished candle, a quiet event setting, a failed recipe, and a former-
luxury setting. Unproven owners produce an explicit empty supported projection
when no matching source contract exists, without another search or top8 fallback.
An empty controlled return is abstention, not positive recall or proof that the
whole corpus lacks the concept.

Additional primary meaning remains attached to its source:

- `supernatural_physical_effect`: explicit spell residue or a supported magical
  physical-effect relation. Mood, lighting or stage-magic words alone do not
  establish it.
- `mortality_symbolism`: an explicit mortality/vanitas interpretive relation.
  Supporting symbolism does not assert an actual death or magical cause.
- `former_luxury_decline`: an authored history of opulence/decline. Worn velvet,
  tarnish, dust or luxury objects alone do not assert that history.
- `quiet_event_setting`: the source's explicit quiet post-event spatial state.
  Its chair/cup traces remain part of that complete setting meaning.
- `failed_recipe`: an explicitly failed recipe context, retaining its harmless
  kitchen-mess meaning rather than converting it into arbitrary generic residue.

Both sides matter. An absent, excluded or quoted context does not authorize a
context-qualified source. Required contexts must be witnessed by the source;
optional permissions remain optional and allow advisory discovery without
becoming requester-owned obligations. Query context and scene witnesses retain
their original offsets. Source compatibility never grants native authority.
Whole-source conditions, effects, guards and later authoring review still apply.

## Return and verification

Compatible sources form the positive prefix of the complete CID-deduplicated
order. RRF10 order is stable within groups. No unknown surface/pose/capture row
fills a short return. Zero compatible witnesses returns zero with an explicit
reason. The view exposes scene/context intent, returned IDs, accepted context
requirements and withheld context requirements; an accepted source is not
reported as withheld. Original lane values are retained exactly.

Maintenance must freeze queries and expectations before baseline execution,
reuse the original 212 texts and actual vectors, execute genuinely new local
query embeddings for new texts, and validate the qualified and separately
installed copies before atomic default selection. The 2026-10-21 expansion adds
96 English/Korean cases covering phase, scene, language, required/optional/
negative/quoted context and owner mismatches. These are finite preauthored
controls, not blind evidence or universal natural-language understanding.
Source-gap abstentions are reported separately from positive recall. Native
CURRENT, historical releases, receipts and unrelated working changes remain
protected. Search integrity does not establish native admission, rendered-image
quality or user acceptance. Older v1-v5 behavior and evidence remain in their
sealed historical generations and maintenance reports.


## Ordinary material and previously unsupported owned events

Version7 recognizes an explicitly extinguished candle and its smoke in verified
Korean primary text, even when the D document begins with an English component.
A lookup-only label cannot supply this assertion. Negated, absent, quoted or
ongoing Korean statements do not qualify. The existing wick/smoke/wax records
remain unchanged, including limits on inferring safety or causal history from
pixels. The request supplies its declared earlier event; the returned physical
state grants no native approval. Neutral candle material may support a generic
physical-aftermath request because it has no additional authored symbolism.
Optional vanitas permission admits neutral material alongside the symbolic
source; required symbolism still needs the actual symbolic source.

Three bounded owned-event families require an affirmative owner, residual
material and support together on both query and selected-primary source:

- a dog's completed crossing, pawprints and the floor;
- completed bread slicing, crumbs and the cutting board;
- a fully opened parcel, torn wrapping and the table.

Their authored causal scene must be declared, so these event realizations do
not pad a generic aftermath request. A boot tread, soil aggregates, an ongoing
opening, the wrong support or an absent/negated owner cannot substitute. Unknown
owners still abstain when no matching qualified source exists. No candidate ID,
benchmark case ID, slot ID or query-file path participates in this logic.

See [the source review](aftermath-gap-source-review.md) for the two existing
ordinary records and three new authored realizations. Candidate additions
require actual local document embeddings and fresh global BM25 statistics;
unchanged BM25 arrays cannot be claimed after a corpus population change.
Maintenance separates a code-only replay from the data-enriched replay and
preserves the original query texts and actual query vectors. Previous empty
expectations may change only with the explicit enrichment purpose and reviewed
matching source meaning; the frozen query meaning itself remains unchanged.


A source rejection such as “failed recipe cannot supply this relation” does not
make recipe failure a positive requirement. This is distinct from a claim limit
such as “mortality symbolism cannot prove a death event”, which retains the
symbolic context. No authored exclusion is removed from the source.

An affirmed ongoing action with an explicitly rejected completed-aftermath
counterpart uses the reciprocal exclusion path. It stably moves only verified
completed-phase sources behind the other scored rows and never pads the material
return with those rejected sources. English negative clauses and Korean
“아니라” counterparts retain exact query offsets; a quoted sign cannot supply
this physical exclusion. Unknown source phase remains ordinary advisory material,
not proof that the source depicts an ongoing action. All source rows and lane
scores stay present; no extra query, model or retrieval lane is invoked.
