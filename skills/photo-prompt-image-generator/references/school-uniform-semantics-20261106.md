# School-uniform visual semantics — 2026-11-06

The authored school-uniform research extension comprises 28 optional bilingual
visual candidates, eight context-only diagnostics, 28 optional bindings, and
50 research routes in `assets/photo_school_uniform_semantics_20261106.json`,
`assets/photo_candidate_school_uniform_20261106.json`, and
`assets/photo_candidate_school_uniform_bindings_20261106.json`. The reviewed
search-view module `assets/photo_candidate_retrieval_views_school_uniform_20261106.json`
contains 28 whole and 28 source-grounded context views. Diagnostics are not
positive visual choices. The research propositions are authored alternatives;
the sources document the relevant garment concepts, not the complete suggested
scene geometry. The research plan and specific boundaries are in
`docs/research-evidence/photo-prompt/school-uniform-20261106/research-plan.md`.

The working source manifest and its rebuilt native search layout include the
new candidate and binding modules. The source manifest, generated native layout,
H-F2 installed release and a particular run receipt are separate states. Consult
`retrieval-runtime.json` and that run's receipt for the currently selected sealed
release. The added search views provide discovery text, not native admission or
permission to alter frozen properties. Full conditions, effects, wearer, count,
contacts, garment layers and visible endpoints still need independent review.

Existing school-life and school-appearance candidates already cover many related
forms. Similar names alone do not make propositions identical: for example the
existing B06 compares different sock types, while SU26 describes a pair of loose
socks on one wearer. Source routes that require existing-source comparison or
further historical/technical evidence remain marked accordingly. The extension
does not claim that every term of the research conversation has been individually
verified or registered. Visible garments do not establish a person's age,
enrollment, intention, history or consent. A required hidden detail is
unobservable, not a pixel pass. Retrieval, native qualification, actual prompt
use, rendered pixels and user acceptance are separate results.

The 2026-11-06 reference-guided tests used H-F2 `0ef54b40e9585889ffcc2c54d189c19e8e66fc95430179e4aaba6c186693a880`.
All three retrieved newly added material; only the sailor test used a new
candidate as inspiration for a clearer insert/collar boundary. Its image showed
both parts but did not clearly fill the entire V opening. The other two tests
had the photographed features in their independently frozen baselines. These
uncontrolled samples do not prove a causal image-quality improvement. The
images, exact prompts and per-run limits remain local under `generated/`.
