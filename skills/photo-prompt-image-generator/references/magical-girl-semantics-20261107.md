# 마법소녀 용어의 시각 의미와 적용 범위

후보의 출처가 가리키는 원문 대조 원장은
`magical-girl-research-20261107/source-reconciliation.json`에 보존한다.
외부 근거의 지원 범위와 한계, 원문 301행 및 기존 후보 비교 기록을 담는다.
출처가 붙었다는 사실은 각 원문의 모든 명제를 독립 검증했다는 의미가 아니다.
분리된 연구 전용 의미 원장·맥락 뷰·세부 검토 파일과 해당 생성 도구는
제거했다. 원장 안의 과거 검토 파일명은 현재 로컬 파일이 아닌 역사적
식별자이며, 출처 위치는 그 폴더의 README에서 확인한다.

두 후보 모듈은 원문별 진단 301개와 별도 선택형 시각 명제 219개를 담는다.
새 시각 예시는 서로 다른 원문 212행에 연결되며 나머지 89행은 진단·연구
맥락으로 남긴다. 이는 각 행의 모든 의미가 시각적으로 실현됐다는 수치가 아니다.
양성 후보 219개 각각에는 바인딩과 원문 전체·주제 맥락 검색 뷰가 있다.
`photo_candidate_retrieval_views_magical_girl_20261107.json`의 438개 뷰는
후보의 정확한 한영 원문에 결박되며, 별칭은 검색 보조일 뿐 필수 표현이
아니다. 진단은 양성 뷰와 바인딩에서 제외한다. 시각 후보는 하나의 예시이며
그 용어 전체의 정의, 일반적인 복장, 장르의 필수 요소 또는 사용 승인이 아니다.

서사·시간·원인·내면 상태와 실제 물질·연령·정체성은 사진의 보이는 단서와
구분한다. 작품 고유 명칭은 일반 형태의 동의어로 넓히지 않으며, 별도로
명시된 성인 조건은 해당 후보의 원래 조건을 따른다. 차폐된 구성요소는
관찰 불가로 남긴다. 검색 노출, 후보 선택, 생성된 이미지의 실제 관찰과
이미지 품질 향상은 서로 다른 검증 단계다.
