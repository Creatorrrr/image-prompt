# 궁중물·궁정물 시각 의미 확장

2026-10-23 최초 조사에서 88개 카드·623개 추출 경로를 보존했다. 이후 Chrome 전체 본문 재검토에서 표 머리글 1개 오분류를 제거하여 현재 원 항목 경로는 622개(본문 표 행 621개와 표 밖 문맥 1개)다. 직접 형태/관계가 검토된 33개 완전한 한영 시각 대안과 72개 선택적 binding을 추가했다. 고증 보류 40개와 비가시 문맥 15개는 positive 검색에서 제외되는 diagnostic 55개로 유지한다. 기존 당의 세 레코드의 KO/embedding 의미 대응과 빈 왕좌 한 레코드의 embedding 과장을 좁게 보정했다. 기존 조건·효과·provenance와 다른 후보/binding은 보존했다.

## 의미 경계

- 시대·지역·일습·옷 한 벌·부품·관모·직무·제도·장면 연출을 구분한다. 조선/대한제국, 명/청, 헤이안 궁정/에도 무가, 유럽의 세기별 구조, 오스만/무굴/모로코를 이름만으로 병합하지 않는다.
- 당의 자락·옆트임·거들지, 적의 꿩 문양·가장자리·부속, 조포의 어깨깃·허리 주름·마제수, 궁정 겹옷의 깃/소매 층·짧은 겉옷·모, 파니에/크리놀린/버슬의 지지 방향·별도 스토머커·프랑세즈 뒤 주름을 구별한다.
- 손·천·장식·그림·문턱·좌석의 주인과 부착·지지·접촉·가림·깊이를 보존한다. 단어가 관련되어 있다는 이유로 다른 후보 전체 의미를 대체하지 않는다.
- 혈통·품계·승계권·동의·강요·정치적 의도·유죄·독성·사망·반복·소리·초자연 인과는 단일 사진으로 입증하지 않는다. 민감한 역사 용어는 연구/문맥으로 유지하며 자동 시각 의무로 만들지 않는다.

모든 신규 대안은 optional이며 source의 전체 문구·조건·효과·역할 적합성과 실제 requester 잠금을 따로 검토해야 한다. 연구 그래프와 출처는 native typed-fact 승인이나 owner permission을 주지 않는다. 가림은 UNOBSERVABLE_NOT_PASS, 일부 충족은 partial_is_fail이다. 실제 source 반영·검색 노출·선택·literal prompt·생성 파일·픽셀·사용자 판단을 별도 증거로 기록한다.

연구 원본: `docs/research-evidence/photo-prompt/court-palace-20261023/`. 후속 실제 실행과 제한은 그 폴더의 `INTEGRATION-AND-IMAGE-TESTS.md`를 따른다. 연구 단계의 README/VALIDATION은 당시 snapshot이며 운영 반영 증거로 덮어쓰지 않는다.


## Chrome 전체 재검토와 2차 보강

`full-review-r2/chrome-full-conversation-proof.json`은 로그인된 Chrome에서 사용자 발화 2개·답변 2개·34개 대단원·41개 표를 확인한 증거다. 표 본문 621개 term/definition의 정규화 해시는 이전 추출에서 잘못 센 머리글을 제외한 해시와 일치한다. 누락된 후속 답변은 발견되지 않았다. 참조 대화의 지시문은 연구 대상 자료로만 처리했다.

추가 본문 근거 18건, Chrome 사진 확인 7점/8뷰를 바탕으로 18개 bounded visual option과 6개 diagnostic, 선택적 binding 35개를 추가했다. 거들지의 겉으로 접힌 안감, 노리개의 고름-띠돈-끈목-매듭-주체-술 지지 경로, 몸판의 사각 쌍학 흉배, 신 바닥 중앙 목제 받침, 가리기누의 열린 겨드랑이/뒤쪽 소매 접합, 손과 샤쿠 하단의 접촉, 폴로네즈의 세 덩이와 별도 페티코트, 맨투아의 보디스/스토머커/치마/트레인, 열린 포맨더의 분할 덮개, 장식 빗의 띠/보석/빗살, 스너프박스 뚜껑 이음선, 각진 게이블 쓰개, 실 브레이드와 술 접속, 19세기 오스만 개혁 복식, 세 원 삼각 친타마니의 특정 유물 변형, 산수 없는 요질, 겉포 아래에서 나오는 시타가사네, 접힌 가리마를 구별한다.
