## Contract boundaries

Object-relative, actor-relative and image-relative references must remain distinct. A source’s contact is owned by that prop and both named endpoints. Quoted text and a museum title do not assert physical placement. A request for chips/rust with location preserved is prop state, not permission to move the toolbox. Negating holding still permits compatible grounded/set-down material; no blanket abstention follows from contrast cohort status. Advisory partial material can be useful with explicit limits, but cannot supply absent actors, containers, surfaces, specialized meanings or native permission.

Recommend a generic source-witnessed relationship layer only if independently validated: retain actor/prop/surface ownership, support/contact/direction endpoints, quotation/negation scope and preservation locks. Do not add CID tables, tags as votes, test-query templates or a broad threshold based on these 24 cases. The baseline has been executed but no repaired run or improvement has yet been measured.
