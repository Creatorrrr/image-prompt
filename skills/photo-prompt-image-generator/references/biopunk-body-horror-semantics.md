# Biopunk and body horror visual semantics

The 2026-10-21 extension adds 162 semantic cards: 135 directly inspectable still
realizations, six static proxies for temporal ideas, and 21 context, sequence or
audio records. The first 141 are complete optional visual candidates; the 21
diagnostics remain outside positive image-material retrieval. All 259 original
research terms retain an explicit route rather than acquiring a compulsory
shape from their genre label.

The source modules are `photo_candidate_biopunk_body_horror_20261021.json` and
`photo_candidate_biopunk_body_horror_bindings_20261021.json` under `assets/`.
`photo_biopunk_body_horror_semantics_20261021.json` retains the bilingual source,
directed relations, actual owners, confusion boundaries, source access scope,
render observations, adoption decisions and keyword routing. This registry is
semantic review data, not a second engine fact, effect or permission owner.

Each visual source has a complete English description and Korean counterpart.
It specifies the whole visible realization, such as both ends of a supply line,
a membrane and its bounded attachment rim, or a surface and the structure it
covers. Sibling cards are alternatives. Preserve each selected source's actual
owner, required boundary and relation. Hidden endpoints are unobservable;
partial realization does not pass the complete source case.

The 202 persistent role bindings are presentation relationships. Actual slot
meaning, source conditions, affected owners/properties, frozen requester locks
and applicability still need independent review. A field or role tag cannot
create a missing body part, participant, adult context or scientific identity.
For example, the adult contact realization retains an adult-context guard.
The six static temporal proxies establish only the depicted state, never
pulsation, elapsed transformation or irreversibility.

The concrete geometries are project-authored fictional realizations. Scientific
and critical references support terminology and interpretation boundaries;
they do not attest these exact invented scenes. Visible anatomy does not prove
diagnosis, biological function, tissue chemistry, agency, consent, reproductive
status, historical identity or an actual viewer's attraction or disgust.
Critical, taboo and audio terms remain contextual when their necessary evidence
cannot be established in a single photograph.

The extension preserves all pre-existing candidate bodies, intrinsic guards,
effects, bindings, role specifications and policies. It changes no ranking
kernel, weights, query authoring rules or automatic negative policy. Both the
editable source index and the sealed installed whole-pool generation must match
the adopted source. `retrieval-runtime.json` selects the installed release;
editing the source module alone does not update it.

The new sources remain unqualified for whole-source native cue adoption. H-F2
may expose them for complete-source review and optional `inspiration_only`
material decisions under the existing composition contract. A retrieved score,
source registry, hash check or successful prompt audit is not pixel evidence.
Independent generated-image reports must distinguish discovery, source use,
literal prompt realization, saved-image relations and requester acceptance.

## Scoped source integration and validation boundary

The scoped commit adds these modules to the committed corpus and rebuilds its
editable search closure from that base plus this extension only. It does not
include pending cosmic-horror data, unrelated candidate edits, neutral-catalog
compatibility code or later workflow changes. The shared working tree may still
contain those separate changes.

The installed-runtime pointer is deliberately outside this commit: the tested
local release also contains other pending work. A source/index commit does not
activate a new installed generation. Publish and qualify a matching reviewed
installed release separately before claiming the new sources are available to
new managed runs in a clean checkout.

See [validation and remaining limits](biopunk-body-horror-validation-20261021.md)
for the distinction between the isolated source/index checks and the three
earlier image attempts. One generated image supports a particular F08 interface;
the complete testcase failed, and two attempts returned no image. This does not
qualify the full extension for native adoption or establish an image-quality gain.
