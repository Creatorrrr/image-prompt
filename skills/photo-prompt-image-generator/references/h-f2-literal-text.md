# Carried literal text ordering

H-F2 retains its complete positive pool, unchanged authored query and query
embedding, one BM25F evaluation and one local cosine evaluation. Its existing
bounded lexical correction and RRF10 scores are unchanged. A subsequent
`photo-h-f2-carried-literal-order/v2` step can stably order candidates by a
directly witnessed inscription constraint. It changes order, never scores,
source text, source words, eligibility, or native adoption authority.

An explicit `exact word`, `exact phrase`, `exact letters`, `exact numerals` or
`exact text` assertion can identify one literal and an `on`/`across` carrier.
Quoted contents preserve exact case, whitespace and punctuation. Unquoted
contents need a direct realization boundary. Quoted mentions, explicit negative
contexts, multiple literals, unsupported wording and missing carrier evidence
retain ordinary ranking. This bounded English extractor is not a multilingual
parser, general instruction-following guarantee or complete owner resolver.

Carrier spans stop before `inside`/`within` scene-location adjuncts as well as
the existing contextual boundaries. A terminal generic `surface` addresses the
bearing face of the preceding carrier rather than an object named surface;
the original full quote is retained, the preceding head and at least two
non-wrapper content terms are still required. Named parts such as `panel` and
`pane`, different owners and reversed noun order remain distinct. This bounded
normalization grants no owner/part relation or source permission.

Source contracts are compiled independently of queries from the initial direct
sentence of the original D document. A declaration-preserving source must
explicitly retain the already declared/requested/supplied inscription's complete
character sequence and capitalization on that same carrier. The carrier head
must agree and at least two meaningful carrier terms must overlap. A fixed
literal source needs an explicit inscription assertion with its actual value.
Negative/quoted mentions, later aliases and incomplete preservation claims
cannot create a contract. Mixed fixed-word/preservation assertions remain
unsupported. These textual witnesses support advisory ordering, not a claim of
complete semantic or native source qualification.

Only when a same-carrier positive contract exists, order the full pool into:

1. Sources that preserve the declared sequence, or explicitly match its exact
   fixed literal on the matching carrier.
2. Sources with no established literal contract for this request.
3. Sources explicitly prescribing a different literal on the matching carrier.

Original RRF10 order is stable within each group. No source is removed, no fixed
word is silently substituted, and no candidate ID, slot name or benchmark text
is used by the policy. Without a positive same-carrier replacement, even a
suspected conflicting example leaves the order unchanged. An unsupported
inscription may therefore still have poor retrieval; downstream requester locks
and direct semantic review remain authoritative.

Material `query_scope.literal_text` records request offsets, source witness
offsets, source text hashes, compatible/conflicting IDs and before/after winners.
Receipt auditing independently reconstructs raw lane fusion, the prior bounded
lexical correction and this stable ordering against the sealed D documents,
without another search or embedding. A changed literal, forged source witness or
reordered score file is rejected even when its checksum is refreshed.

Maintenance compares frozen query text, actual cached query vectors, both lane
score arrays, the entire pool and every full final order. Qualify a new sealed
release before selecting the default, then rerun the identical suite on the
installed copy. Native CURRENT and historical bound runs remain independent.
