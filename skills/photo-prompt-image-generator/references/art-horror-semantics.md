# Art Horror semantic extension

The source registry `assets/photo_art_horror_semantics_20261023.json` retains
64 complete visual relations, 29 context distinctions, 154 keyword routes,
19 reference-work routes and six combination routes. Reference descriptions and
metadata retain their access limits; registration does not assert full viewing.
63 new optional visual sources and 29 diagnostics are registered in
`photo_candidate_art_horror_20261023.json`; the room-model relation reuses one
existing complete source without rewriting it. The companion binding module
uses actual catalog slots rather than research-only dimension names.

Genre labels never require low saturation, darkness, gore, eroticism, a studio
look or every related motif. Context diagnostics do not enter positive material
retrieval. Owner continuity, material qualifiers, physical contacts, bounded
representation layers, count and all distinguishing endpoints remain part of
the full source meaning. A liquid is not automatically blood; a model, mask,
prosthetic, fabric or depicted injury is not an actual injured body.

The research graph is review metadata. Source registration, retrieval, native
qualification, optional authorial use, exact runtime transport, image pixels
and requesting-user acceptance remain separate. `native_approval: false` does
not grant whole-source adoption. `partial_is_fail`, `UNOBSERVABLE_NOT_PASS` and
`BLOCKED_UNSCORED` apply to their respective review layers.

Research, source-access limits, bilingual cards, overlap decisions and the
immutable successor release are recorded under
`docs/research-evidence/photo-prompt/art-horror-20261023/`.
