# Marine literature semantics

The [research and image evidence](../../../docs/research-evidence/photo-prompt/marine-literature-20261024/README.md)
retains the referenced conversation's 23 tables and 247 term rows, 96 research
cards, 20 bounded sources and 40 unexecuted evaluation cases. Research history
remains immutable; later integration and retest results are separate records.

The extension registers 87 optional bilingual visual sources, 247 excluded
context diagnostics and 166 optional bindings. Three complete existing sources
are reused without mutation. The sidecar retains owners, directed endpoints,
confusion boundaries, provenance and simultaneous-observation gates. Source
metadata and citations confer no native qualification.

The discovery repair adds short English object names without changing the
original bilingual visual propositions, application contracts, conditions or
effects. Advisory rendering notes distinguish actor-relative laterality from
screen position and require visible support, complete paths and actual shadow
receivers. They do not weaken any pixel gate.

The [independent retest](../../../docs/research-evidence/photo-prompt/marine-literature-20261024/retest-20261024/RESULTS.md)
used the same portrait and three independently frozen concepts, followed by one
actual image call per arm. One generic text-within-carrier attribute transferred
to prompt, actual input and original pixels. No complete new card was adopted;
all three complete pixel contracts failed. Appearance resemblance is bounded to
visible face and hair. Identity, age, affiliation and genre-specific success
are not established by a label, costume or generic institutional satire.

A task-bearing conversation title must not automatically become the entire
visual topic. The explicit tested release used an exact topical substring with
the complete prior user message retained for provenance. The regression and
its runtime-dependent source snapshot remain in the research evidence. That
newer kernel and independent unpublished neutral-authoring code are not part of
this data-only publication; the selected runtime configuration is preserved.

`partial_is_fail`, `UNOBSERVABLE_NOT_PASS` and the distinction between source
registration, installed exposure, authored use, exact transport, original
