# Primary-source material scope

The 2026-10-21 weak-slot expansion adds 91 complete discovery candidates across 21 roles:66 from the expanded scene/expression/language/context audit and 25 from cross-checking the original queries. Source reviews are in [expanded notes](weak-slot-source-review/20261021/expanded/subject.md) and [original-query supplement notes](weak-slot-source-review/20261021/original308/subject.md), with one exact hashed note per slot. Each candidate retains its complete positive text, application contract, intrinsic conditions, effects, owners and provenance. Existing source records, bindings, policies and selected-realization boundaries remain cumulative.

H-F2 still runs exactly one BM25F traversal and one local-cosine lane over the whole positive RID pool, fuses with RRF10 and deduplicates CIDs. Query bytes, query embedding inputs, model binding and raw score arrays are preserved by the code-only change. Global BM25 statistics legitimately change when authored documents are added. A source-checked ordering and material projection follows scoring; it does not prefilter the corpus, add a second search or create native authority.

`photo_h_f2_query_scope.py` combines seven bounded semantic comparators. Query assertions are inferred from affirmative meaning, not slot tags, benchmark identities or candidate IDs. Explicit quotation, negation, owner relations, preserved parameters, depiction and external-context boundaries remain separate. Actual selected-RID effects identify possible properties; those effects are only hints. A source profile with no mutating footprint may establish an explicit exclusion, but is never eligible for positive promotion. Positive support still requires exact named selected-primary source fields, complete source meaning and retained constraints. `application_contract` constrains applicability but never becomes an independent positive fact or lexical ranking vote.

Each material packet retains exact query spans, selected-primary field locators and source hashes, effect/constraint hashes, support/conflict ledgers, full-order hash and the declared projection. The production auditor recompiles the sealed source closure and replays ordering from saved raw scores without searching or invoking a model. It rejects altered witnesses, owners, selected branches, intrinsic effects, conditions, projection counts, full order and source bodies even after checksums are recomputed.

Physical carried text uses a distinct primary-carrier literal contract: exact Unicode characters, case, whitespace, line arrangement and leading zeros stay attached to the same actual declared carrier. A carrier's painted finish does not establish the inscription's manufacture. External publication captions cannot supply image glyphs, physical temperature, ancestry or another owner's features. Completed-event aftermath projection retains its separate higher-priority source/scene contract.

Public proof traces are normalized to strict JSON after internal comparison, making independent serialization and replay deterministic.

A recognized positive property request returns only its witnessed compatible material, up to 8 sources. Unfilled budgets stay unfilled. Explicitly excluded or unprovided property declarations do not pad ordinary results. Nominal taxonomy descriptions without an instantiated scene retain ordinary discovery material, marked unproven. Concrete excluded or unprovided property changes cannot use unknown filler; an unmodeled owned relation cannot outrank a separately modeled affirmative image property. Equal declared visual prominence does not create a primary/secondary priority tier. Missing independently required adult context stays unproven; one original hand-age query intentionally retains an empty return for that reason. This bounded exclusion is not a full native guard execution.

Qualification evidence covers the unchanged prior 308 plus 504 preauthored new queries (812 total),252 strict expanded positive targets,252 contrasts,63 original weak-slot actionable cases and 96 aftermath cases. The 63 original cases comprise 62 supported meanings and one correctly unproven prerequisite. Strict target bindings are evaluation artifacts and never enter runtime routing. This finite source-based evaluation is not a blind language benchmark, exhaustive natural-language guarantee, native adoption approval or generated-image quality proof.

Actual adoption still requires the independent native source, selected realization, owner/receiver, guard, permission and whole-effect workflow. Material `native_approval` and semantic-approval flags remain false. New proposals are not permission to bypass a deferred/failed binding or any condition on another source. Maintainers must stage and qualify code and authored data explicitly, install an immutable release, compare deployed searches, and atomically select the default only after the complete regression gate passes. No native `CURRENT` pointer is moved by this maintenance path.
