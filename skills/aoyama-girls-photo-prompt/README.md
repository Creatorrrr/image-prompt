# Aoyama Girls Photo Prompt

A keyword-to-photographic-prompt skill reconstructed from the referenced design. It turns a short phrase into a theme-led scene using subject individuality, social symbolism, camera relationship, transitional action, meaningful framing, and disciplined selection.

The package keeps routing and output behavior in SKILL.md and separates the longer method into six references:

- 01: philosophy and relational portrait model
- 02: keyword-to-brief engine
- 03: composition, camera, distance, and light
- 04: final and negative prompt compiler
- 05: series continuity, selection, and sequencing
- 06: 100-point quality control and repair

Examples and behavioral acceptance cases are included for maintainers. The project installation is the matching link under .agents/skills.
