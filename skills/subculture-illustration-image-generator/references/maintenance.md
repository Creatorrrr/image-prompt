# Current illustration asset maintenance

Preserve the canonical meaning and authenticated source lineage used by the current loaders. The evidence manifests and referenced shards under the three `research_evidence_*` directories are operating assets. They contain meaning contracts and provenance rather than saved test results.

Run `scripts/validate_illustration_assets.py` to validate source records, typed candidate roles, topic/format aliases, compatibility, source effect policies, composition carriers, literal realization and selected-owner contracts, retry policy, and the current moe meaning/visual grammar. A pass establishes asset integrity; it is not rendered-image or audience qualification.

Use the deterministic meaning and grammar builders to update current moe data. Keep the immutable base grammars because the current v5/v7 loader authenticates their hashes. `compile_universal_composition_carriers.py --check` compares the live three assets against `assets/universal_composition_targets_v1.json`; this minimal authoring inventory contains canonical targets only, with no requests, expected outcomes, or test cases.

Do not infer a new meaning from a label, invent source authority, lower an obligation, or copy source prose into prompts. Exact/variant/carrier/related/ambiguous alias distinctions and adult/reference controls retain their current semantics. Related or ambiguous terms never activate an element. Keep all source-supported component groups, owner/target relations, resource and pixel constraints, and sensitive runtime-label rules.

Validate candidate, compatibility and semantic assets together. Rebuild their sibling hashes with the authoring tool rather than editing a generated hash. Keep the photo and illustration sources separate: this package must not import the photo generator or mutate its pool, index or operating selectors. Use a directly authored current request contract for functional checks. New outputs belong under the workspace `generated/` directory unless the requester supplies another path.
