# 전통 의복 시각 의미 후보팩 및 독립 5-arm 픽셀 검증

완료일: 2026-08-31

## 결론

후보팩 1.31과 시각 의미 프로필을 갱신하고 인덱스를 재생성했다. 데이터·라우팅·감사 계약은 집중 8개와 공통 회귀 40개 테스트에서 모두 통과했다. 무작위 17개 풀에서 중복 없이 선택한 다섯 의복을 서로 출력물을 공유하지 않는 독립 에이전트에서 생성한 결과, 프롬프트 감사 5/5와 렌더 요청 감사 5/5가 통과했고 이미지도 5/5 생성됐다. 실제 픽셀의 목표 의복 게이트는 25개 중 23개가 통과했으며, 엄격한 기술 자격은 3/5 arm만 통과했다.

각 arm은 내장 이미지 생성기를 정확히 한 번 호출했고 재시도나 모델 하향은 없었다. 원본 이미지 SHA-256, 후보팩 ID, 프롬프트 ID, 참조 이미지 SHA-256, intent-lock SHA-256, 생성 도구와 독립성 선언은 각 `run_manifest.json`과 `image_runs.ndjson`에 기록했다.

## 데이터 반영 범위

- 의복 시스템 후보 28개, 구성 원자 20개, 의복 액세서리 6개, 직물 텍스처 6개, 직물 표면 6개를 후보팩에 반영했다.
- 케바야, 치파오, 니비 사리, 안데스 판초, 서아프리카 그랑 부부에는 각각 5개 렌더 게이트를 가진 하드 시각 프로필을 추가했다.
- 포괄 명칭(`traditional dress`, `folk costume`, `전통 의복` 등)은 특정 의복을 하드 라우팅하지 않는다.
- 정확한 명칭과 맥락은 하드 의무가 될 수 있지만, 구성요소 서술·BM25F·임베딩 결과는 선택 후보로만 남는다.
- 의복은 착용자의 민족성·국적·종교·신분·진정성을 증명하지 않는다.

## 사전 생성 경계에서 발견한 사항

다섯 core-only 최초 후보팩은 에이전트가 사후 선택한 의복을 자동 하드 의무로 승격하지 않았다. 이는 임베딩 후보를 의무로 조용히 승격하지 않는 v6 경계와 일치한다. 각 arm은 고정된 `interpreted_intent`에 출처가 결속된 `photo-visual-intent/v1`을 별도로 만들고 난 뒤 최종 후보팩을 구성했다. 최초 실패팩은 가능한 범위에서 보존했다. 다만 arm-05 최초 pre-intent 바이트는 보존 전에 덮어써졌고, 이후 재현한 no-hard-route 팩은 원본과 바이트 동일하지 않다는 점을 프로비넌스에 명시했다.

## 주장 경계

프롬프트 감사 PASS는 픽셀 PASS가 아니다. 안데스 판초와 니비 사리는 프롬프트·렌더 요청 감사가 통과했지만 실제 이미지의 필수 게이트 하나씩이 실패했다. 첨부 참조는 성인 피사체의 외형 연속성 기준으로만 사용했으며 생체 신원 확인은 수행하지 않았다. 다섯 결과 모두 요청자의 미적 수용 판단은 아직 `pending`이다.
