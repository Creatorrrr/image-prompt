# 얼굴형 시각 의미 5-arm 생성 검증

## 데이터 반영

- 요청 시에만 활성화되는 얼굴형 합성 프로필 11개를 `face_shape_relation` 슬롯과 하드 시각 의무 레지스트리에 함께 추가했다.
- 이마·관자·광대·볼·하악·턱끝·세로 구간·측면 돌출을 분리하는 지역 원자 16개와, 외곽 관찰용 프레이밍 원자 6개를 추가했다.
- 각 프로필은 전체 외곽, 세로 관계, 폭 소유권, 하안면 종결, 혼동 통제의 5개 구성 요소·프롬프트 증거·픽셀 게이트를 가진다.
- `V-line`, `U-line`, `瓜子脸` 계열은 런타임 라벨 대신 관찰 가능한 윤곽 정의만 출력한다. 일반 프리셋에는 얼굴형을 자동 삽입하지 않는다.
- 13개 근거 행, 66개 프로필/398개 정확 표현의 시각 인덱스, 6,764개 의미 인덱스를 검증했다.

## 결론

얼굴형 의미 데이터와 v6 후보팩은 다섯 실험 모두에서 정확히 하나의 하드 프로필로 라우팅되었고, 후보팩·조합 프롬프트·런타임 요청 감사도 모두 통과했다. 이미지 생성은 5회 중 4회 성공했고 1회는 전송 연결 오류로 픽셀이 반환되지 않았다.

실제 픽셀의 엄격한 5-gate 판정은 4개 평가 가능 렌더 중 2개가 완전 통과했다. 평가된 개별 게이트로는 17/20이 통과했다. A와 D는 목표 얼굴 비율 자체는 대부분 보였지만, 긴 머리카락이 관자 또는 턱 외곽을 가려 `partial_is_fail` 규칙에 따라 실패했다. 따라서 데이터·프롬프트 동작은 통과, 렌더 충실도는 `revise`로 판정한다.

| Arm | 얼굴형 프로필 | 랜덤 복합 콘셉트 | 생성 | 픽셀 게이트 | 엄격 판정 |
|---|---|---|---:|---:|---|
| A | oval | 달빛 난초 온실의 꽃가루 궤적 포렌식 | 성공 | 3/5 | 실패 — 외곽·혼동 통제 |
| B | round compact | 극지 전파관측소의 저잡음 수신기 교정 | 성공 | 5/5 | 통과, 사용자 판단 대기 |
| C | diamond | 침수된 바로크 기록보관소의 벨럼 건조 장치 | 연결 오류 | 미평가 | 결론 유보 |
| D | upper-face-to-chin taper | 화산유리 키네틱 쿠튀르의 흑요석 꽃잎 피팅 | 성공 | 4/5 | 실패 — 전체 외곽 |
| E | definition-only seed relation | 새벽 시립 관측소의 천구 측량 | 성공 | 5/5 | 통과, 사용자 판단 대기 |

## 산출물

- 종합 픽셀 판정: `shared/coordinator_pixel_review.json`
- 공통 프로토콜: `shared/test_protocol.json`
- 각 arm의 프롬프트·팩·감사·원본 이미지·ledger: `arm-a/`부터 `arm-e/`
- 연구·데이터 설계: `docs/analysis/2026-08-31-female-face-shape-visual-semantics.md`

첨부 사진은 `appearance_reference`로만 전달했다. 결과의 동일인 여부나 생체 신원은 판정하지 않았으며, 각 얼굴형의 관찰 가능한 윤곽 관계만 평가했다. 사용자의 미적 판단은 아직 받지 않았으므로 기술 판정과 분리해 둔다.

## 회귀 경계

얼굴형·시각 의무·프로필 검색·BM25F 집중 테스트 50개는 통과했다. 전체 730개 스위트에서 이번 의미 인덱스 증가로 발생한 고정 엔트리 수 1건은 6,764로 갱신하고 단일 재검증을 통과했다. 남은 golden 6건, illustration 사진 baseline 4건, pose 근거 문구 1건은 얼굴형 변경 전 태그로도 재현되거나 비-얼굴 행을 가리켜 수정하지 않았다. 상세 근거는 `artifacts/photo-prompt-face-shape-semantics-20260831/regression_boundary.json`에 있다.
