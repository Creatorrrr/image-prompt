# 여성 사복 5-arm 독립 렌더 검증

작성일: 2026-09-01  
결론: 후보팩·프롬프트·런타임 감사는 모두 통과했지만 실제 픽셀은 5개 프로필 중 4개, 25개 필수 게이트 중 21개만 통과했다. 따라서 엄격한 렌더 충실도 판정은 `revise`다.

## 독립성 및 실행 조건

- 서로 다른 5개 서브에이전트가 타깃을 알기 전에 랜덤 시드와 복잡한 장면의 authorial core를 각각 작성하고 해시로 고정했다.
- 코어 고정 후 버튼다운, 콜드숄더, 랩 블라우스, 점프수트, 큐롯을 하나씩 배정했다.
- 각 실행은 첨부 이미지를 성인 피사체의 얼굴·전반적 외형 연속성 참고로만 사용했다. 생체 동일성이나 원본 의복의 증거로 사용하지 않았다.
- 각 arm은 네이티브 이미지 생성을 정확히 1회 수행했고 재시도나 유료 API fallback을 사용하지 않았다.
- Phase A 코어의 `wardrobe`, `styling_details`, `color_palette`는 v6 생성기가 허용하는 `style`, `color`로만 호환 정규화했다. 원본 코어는 그대로 보존했고 의미 변경은 없었다.

## 픽셀 판독

- 버튼다운: 앞중심 전체 플래킷, 좌우 포인트 칼라, 양쪽 칼라 끝의 작은 단추와 몸판 체결 관계가 한 이미지에서 모두 보인다.
- 콜드숄더: 왼쪽 컷아웃은 보이지만 오른쪽 컷아웃·브리지가 긴 머리카락 아래 완전히 가려졌다. 양측 구조를 동시에 증명해야 하므로 부분 성공을 인정하지 않았다.
- 랩 블라우스: 두 앞판, 실제 겹침 깊이, 랩 V선, 옆 타이, 가짜 사선이 아닌 구조가 모두 보인다.
- 점프수트: 몸판-허리-가랑이 연속성, 인심 아래 두 다리 분기, 두 긴 밑단이 한 벌로 읽힌다.
- 큐롯: 공통 허리·밑위, 가랑이·인심, 두 넓은 바지통, 종아리 부근 두 밑단이 보이며 스커트와 팔라초 대체를 배제한다.

## 증거 경계

- 데이터 구조 검증, 후보팩 생성 성공, 프롬프트 감사, 런타임 요청 감사, 저장된 실제 픽셀, 사용자 미감은 서로 다른 증거다.
- 5개 타깃 프로필의 프롬프트 및 런타임 감사 통과는 픽셀 통과를 뜻하지 않는다.
- 사용자 미감과 외형 연속성 평가는 아직 `pending`이며 기술 판정 점수에 포함하지 않았다.

상세 기계 판정은 `shared/coordinator_pixel_review.json`, 각 프롬프트와 원본 이미지는 `arms/` 아래에 보존되어 있다.
