# 여성 포즈 시각 의미 데이터 — 5-arm 독립 생성 검증

## 결과

다섯 독립 arm이 서로 다른 복합 장면을 동결한 뒤 같은 인물 사진을 얼굴 외형 참고로만 사용해 이미지를 생성했다. 총 9회 이미지 호출에서 arm-01, arm-02, arm-03이 엄격 PASS, arm-04와 arm-05가 엄격 FAIL이었다. 25개 픽셀 게이트 중 20개가 통과했고, 하나라도 빠지면 해당 arm 전체를 FAIL로 처리했다.

프롬프트·후보팩·런타임 감사는 다섯 arm 모두 통과했지만, 그것을 픽셀 성공으로 간주하지 않았다. 판정은 각 arm에서 선택한 한 장의 저장 이미지 원본을 기준으로 했다.

## 후보팩 작동성 해석

- 정확한 하드 프로필 트리거는 3/3 모두 공개 후보팩에 노출되고 선택됐다. 그중 arm-01과 arm-02는 프로필의 모든 픽셀 게이트까지 통과했고, arm-05는 명명 부위만 맞았을 뿐 실제 연속 배경 공극을 만들지 못했다.
- 배정한 후보 ID 15개 중 공개 후보팩에 실제 노출된 것은 `head_shoulder_opposition` 1개였다. 따라서 나머지 의미가 픽셀에 보이더라도 이는 동결한 저자 코어 문구의 실현이지, 후보팩 선택이 작동했다는 증거는 아니다.
- 후속 개선 우선순위는 새 원자 후보의 검색·노출 재현율이다. 특히 `crossed_ankles_narrow_base`와 `bent_elbow_torso_negative_space`는 생성 모델이 근접 대체물을 만들기 쉬우므로, 후보 노출 강화와 실패 대체물 차단 문구를 함께 시험해야 한다.
