# 북해빙궁 반로환동 쿨데레 A/B 평가

## 결론

이번 1회 독립 페어에서는 비스킬 대조군이 픽셀 전달력에서 이겼다. 두 블라인드 평가자 모두 대조군을 선택했고, 평균은 대조군 `90.0`, 스킬 arm `80.5`로 `9.5`점 차였다. 이는 한 쌍의 확률적 결과이므로 반복 가능한 인과적 우월성을 증명하지는 않는다.

스킬은 얼굴 유사도, 프롬프트 압축, 요청-코어-런타임 추적성에서 우세했다. 반면 대조군은 늙은 성인 제자, 공격, 방패, 몸으로 가로막기, 보호된 결과를 큰 형태로 한눈에 보이게 만들어 북해빙궁·반로환동 고수·쿨하지만 보호하는 관계를 더 명확히 전달했다.

## 통제 조건

- 두 생성 arm은 서로 다른 작업 디렉터리에서 다른 arm의 입력과 결과를 보지 않았다.
- 동일한 얼굴 참조를 외모에만 사용하고 구도는 자유롭게 했다.
- 각 arm은 내장 이미지 생성 호출을 정확히 한 번만 실행했고 재시도하지 않았다.
- 평가 프로토콜은 결과 매핑을 공개하기 전에 작성했다.
- 두 평가자는 참조 얼굴, 익명 썸네일, 익명 원본 픽셀만 보았다.

## 정량 결과

| 지표 | 스킬 | 비스킬 대조군 |
|---|---:|---:|
| 첫 호출 전달 | 성공 1/1 | 성공 1/1 |
| 프롬프트 단어 수 | 긍정 172 / 런타임 190 | 351 |
| 블라인드 픽셀 평균 | 80.5 | 90.0 |

스킬의 긍정 프롬프트는 대조군보다 `51.0%`, 실제 런타임 문자열도 `45.9%` 짧았다.

## 왜 이런 차이가 났는가

스킬 prompt는 손목 보호대를 묶고, 눈빛이 누그러지고, 손가락이 이완되고, 금 간 장갑이 봉합되며, 양쪽에 같은 학 문양이 보이는 미세한 연쇄를 요구했다. 얼굴과 손의 친밀한 장면은 잘 나왔지만, 제자의 신원·나이·부상·봉합 변화·문양 연속성 가운데 일부는 픽셀에서 약해졌다. 블라인드 평가는 얼굴 유사도만 스킬에 뚜렷한 우위를 줬다.

대조군은 회색 머리의 늙은 성인 제자를 명확히 보여 주고, 공격을 얼음 방패로 막으면서 다른 손으로 뒤로 끌어 보호하는 거시적 사건을 썼다. 얼굴 유사도는 낮아졌지만, ‘젊은 외모의 고대 고수’와 ‘차갑지만 같은 대상에게 행동으로 드러나는 보호’를 썸네일에서도 이해하기 쉬웠다.

후보팩은 여섯 개의 창작 후보를 모두 거부했고 최종 긍정 프롬프트는 동결된 기본 프롬프트와 같았다. 따라서 이번 실행에서 후보 검색은 창의적 개선보다 구조적 감사와 추적성에 기여했다.

## 스킬 성능 판정

- 의미 보존·감사 가능성: `PASS`
- 첫 호출 이미지 전달: `PASS`
- 프롬프트 효율: 스킬 우세
- 얼굴 외모 보존: 스킬 우세
- 단일 프레임 컨셉 전달: 대조군 우세
- 렌더 픽셀 우월성: 이번 페어에서는 `FAIL`
- 반복 가능한 인과적 우월성: 표본 `n=1`이므로 미확립
- 사용자 최종 선호: 대기 중

## 절차상 한계

- 최초 코어 JSON은 의미 변경 없이 스키마 표기만 후보팩 이전에 한 번 고쳐야 했다.
- `SKILL.md`의 합성 감사 옵션 `--candidate-pack`과 현재 CLI의 `--pack`이 달랐다.
- 현재 실행 기록기는 독립 매니페스트에서 v2-v4만 받아 v6 매니페스트를 만들 수 없었다. 해시, pack, 합성, 런타임 요청, 이미지와 일반 ledger는 보존했다.

## 다음 개선 가설

스킬의 관계 계약은 유지하되, 작은 장갑 봉합·문양 같은 다중 세부보다 `성인 대상의 얼굴/고유 표식`, `명백한 연령 대비`, `큰 실루엣의 보호 행동`, `이미 벌어진 단일 결과`를 우선하도록 해야 한다. 이 변경은 새 대조 실험에서 검증해야 하며, 이번 한 장만으로 일반 규칙을 확정할 수는 없다.
