# 판타지 시각 의미·후보팩 5-arm 렌더 검증 보고서

## 결론

조사 키워드 가운데 `golem`, `fantasy portal`, `alchemist`, `summoner`, `magic circle`, `living armor`, `wyvern`, `hydra`, `phoenix rebirth`, `griffin`을 10개 시각 의미 프로필과 5개 v6 후보팩에 연결하고, 서로 독립된 5개 에이전트가 각기 다른 복잡한 장면을 작성·감사·생성·자체 검토했다. 첫 이미지 이후 각 팔에 한 번만 가시성 재시도를 허용했고, 재시도 이미지는 다른 에이전트가 프롬프트와 출처를 보지 않은 채 블라인드 교차검토했다.

- 소스/인덱스: **PASS** — 144 profiles, 894 exact terms, 7,278 semantic entries, 16 shards.
- 후보팩: **5/5 PASS** — 각 pack에 해당 프로필 2개와 hard gate 10개가 포함됨.
- 최종 프롬프트 감사: **5/5 PASS** (`quality=warn`은 비차단).
- 실제 런타임 요청 감사: **5/5 PASS**.
- 픽셀의 대상 키워드 게이트: **2/5 arm 완전 통과** — arm 01, arm 04.
- 공통 외형·성인·해부·행동 게이트까지 포함한 전체: **1/5 arm 완전 통과** — arm 01.
- 사용자 취향 판단: **pending**. 기술 판정과 분리했다.

부분, 모호함, 크롭, 한 축척에서만 보이는 증거는 모두 실패로 처리했다. 생성 에이전트와 블라인드 에이전트가 다르게 판정한 게이트는 실패 합집합을 최종값으로 채택했다.

## 데이터와 후보팩에 반영한 내용

선정된 10개 프로필은 다음 관찰 계약을 강제한다.

1. 골렘: 비생물 재료로 조립된 완전한 한 몸, 이음부, 스스로 하는 행위, 조각상 대체 금지.
2. 판타지 포털: 완전한 경계, 경계 양쪽의 서로 다른 공간, 실제 통과, 문턱 주변의 국소 효과.
3. 연금술사: 작업자와 연결 장치, 입력·중간·출력 상태, 국소 물질 전이 및 잔류물.
4. 소환사: 한 작업자, 경계가 있는 출현원, 별도 개체, 상호 지향, 정적 동료 대체 금지.
5. 마법진: 표면에 닫힌 경계, 안/밖 상태 차이, 경계에서 멈추는 국소 효과, 장식 대체 금지.
6. 살아 있는 갑옷: 관절 갑각, 비어 있음의 가시적 증거, 자율 동작, 착용자 대체 금지.
7. 와이번: 한 몸, 어깨의 정확히 두 날개가 앞쪽 부속지 위치를 차지하고 골반의 뒷다리 두 개만 체중을 지지함.
8. 히드라: 한 몸통의 서로 분리된 목 뿌리, 최소 세 개의 완전한 목 경로와 서로 다른 머리 실루엣.
9. 불사조 재생: 이전의 파괴 상태, 같은 원인의 연속 전이, 새 새의 상승, 재생 지점에 국한된 결과.
10. 그리핀: 독수리 머리·부리·깃털 앞몸과 날개 두 장, 사자 뒷몸·뒷다리·발·꼬리, 이음부의 연속성.

초기 후보팩을 합성하기 전에 결함도 발견했다. 에이전트가 동결한 binding이 프로필의 `min_content_words`보다 짧을 수 있었고, 이후 감사기는 그 짧은 원문과 더 긴 최소 증거를 동시에 요구해 후보팩을 충족 불가능하게 만들었다. 이미지 호출 전 이를 중단하고 다음을 고쳤다.

- binding을 동결하기 전에 최소 내용어 수, 필수 anchor, 금지어, blanket-negative를 검사한다.
- 와이번의 앞다리 부재를 부정문이 아닌 `어깨 날개가 가슴의 유일한 앞쪽 부속지 쌍을 차지한다`는 양의 기하로 표현한다.
- 인덱스와 후보팩 5개를 다시 생성했다.

검증은 `11 passed, 78 subtests passed`, 인덱스 검사는 `144 profiles, 894 exact terms`로 통과했다. 결함 상태에서는 이미지 호출이 없었다.
