# 북해빙궁 반로환동 쿨데레 미소녀 — 스킬 재시도 평가

## 결론

이번 재시도 이미지는 이전 스킬 결과보다 요청자의 우선순위와 피드백에 훨씬 가깝다. 두 블라인드 리뷰어 모두 새 결과를 선택했고, 새 결과는 평균 **92.0/100**, 이전 결과는 **80.5/100**이었다. 다만 조건당 첫 시도 한 장뿐이므로 스킬 자체의 일반적 인과 우월성을 증명한 것은 아니다.

## 실행 통제

- 생성 담당은 이전 프롬프트·이미지·평가표·메모리를 보지 않은 독립 서브에이전트였다.
- `photo-candidate-pack/v6`, creativity `0.5`, 팩 1회, 이미지 호출 1회, 재시도 0회.
- 조합 감사 PASS, 런타임 감사 PASS. 307단어 길이는 320단어 절대 상한 안이지만 권장 길이를 넘겨 경고가 있었다.
- 팩에서 실제 채택한 새 재료는 열린 차원의 좌측 1/3 비대칭 구도뿐이다. 나머지 후보는 의미 희석·중복·갈등 때문에 거절했고, 잠긴 사용자 의미는 typed core에서 유지했다.

## 블라인드 점수

리뷰어 1은 `A=이전`, `B=새 결과`; 리뷰어 2는 순서를 반대로 받았다.

| 항목 | 이전 | 새 결과 | 변화 |
|---|---:|---:|---:|
| 미소녀 /30 | 28.5 | 27.5 | -1.0 |
| 쿨데레 /25 | 16.5 | 21.5 | +5.0 |
| 반로환동 /15 | 10.0 | 14.5 | +4.5 |
| 북해빙궁 /10 | 8.5 | 10.0 | +1.5 |
| 참조와 독립된 연출 /10 | 8.0 | 10.0 | +2.0 |
| 화보 완성도 /10 | 9.0 | 8.5 | -0.5 |
| **합계 /100** | **80.5** | **92.0** | **+11.5** |

두 리뷰어 모두 새 결과의 7개 하드게이트를 전부 PASS로 판정했다. 이전 결과는 ‘동등한 성인 동료이며 비모성·비의료적 관계’ 게이트를 두 명 모두 FAIL로 보았고, 쿨한 표면과 고대 권위도 약하게 평가했다.

## 무엇이 좋아졌나

- 얼굴 참조를 직접 되풀이하지 않았다. 전신에 가까운 좌측 1/3 구도, 상대를 향한 낮은 옆시선, 검 인계 동작이 원본의 어깨 너머 근접샷·카메라 응시와 분명히 다르다.
- 마망/힐러 인상이 사라졌다. 접촉 치료나 손을 감싸는 돌봄 대신, 물리적 거리를 둔 성인 무인끼리 검을 주고받는다.
- 검, 빙기, 얼음 비석·빙벽, 무기 진열, 의전복과 관 장식이 북해빙궁과 오래된 문파 수장 권위를 직접 보강한다.
- 미소녀 우선순위도 유지된다. 얼굴 크기가 작아져 이전보다 1점 낮아졌지만, 여주인공은 여전히 화면의 지배적 초점이며 27.5/30이다.

## 남은 약점

블라인드 리뷰에서는 전체적인 ‘차가운 표면 + 특정 동료에게만 보이는 배려’가 통과했다. 하지만 생성 담당의 더 엄격한 문구별 픽셀 검토에서는 다음이 완전히 살아남지 못했다.

- 눈꺼풀만 아주 살짝 부드러워지는 미세 표정은 축소 화면에서 명확하지 않다. 두 블라인드 리뷰어도 이 세부 항목을 각각 3/5로 평가했다.
- 검을 떨어뜨렸던 직전 상태가 한 프레임 안에 보이지 않는다.
- 두 검의 쪼개진 옥 장식이 같은 동료를 잇는 표지로 명확하지 않다.
- 중앙 얼음 비석의 가짜 문자와 복잡한 손·검 장식이 약간 산만하다.

따라서 이번 결과는 ‘참조 표정을 우연히 이어받은 것’이 아니라 장면과 관계를 새로 설계한 결과라고 볼 근거가 충분하다. 다만 쿨데레의 숨은 온기는 얼굴 미세표정보다 **검을 건네는 행동과 시선의 맥락**에 더 많이 의존한다.

## 스킬 성능 판단

이번 한 쌍의 결과에서는 스킬 흐름이 피드백 반영에 유효했다. 사용자 우선순위와 동료 관계를 검색 전에 잠그고, 팩은 열린 구도 차원만 보강했으며, 충돌 후보는 버렸다. 그 결과 이전의 치료·돌봄 화보가 성인 동료 간 무공 장면으로 바뀌었다.

그러나 `n=1`이며 프롬프트 자체도 의도적으로 수정되었으므로, **새 픽셀이 더 낫다**는 결론과 **스킬이 일반적으로 더 우수하다**는 결론은 구분해야 한다. 전자는 두 블라인드 리뷰어가 지지하고, 후자는 아직 반복 실험이 필요하다.
