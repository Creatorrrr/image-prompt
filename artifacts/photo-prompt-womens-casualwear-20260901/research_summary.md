# 여성 사복 시각 의미·후보팩 연구 요약

작성일: 2026-09-01  
범위: 앞선 `여성 사복 종류 조사`에서 특히 혼동 위험이 높은 버튼다운 셔츠, 콜드숄더 톱, 랩 블라우스, 점프수트, 큐롯 팬츠를 이미지 생성·검수 가능한 시각 계약으로 변환한다.

## 연구 원칙

- 품목명만 저장하지 않고 `상위 품목 + 국소 부품 + 부품 간 연결 + 몸 랜드마크와의 관계 + 혼동군`으로 분해한다.
- 이름이 프롬프트에 들어갔다는 사실은 이미지 반영 증거가 아니다. 각 프로필은 5개 렌더 게이트를 모두 실제 픽셀에서 통과해야 한다.
- 소재는 보이는 조직·접힘·광택·드레이프만 기술한다. 섬유 조성, 촉감, 품질, 가격, 착용감은 픽셀로 입증하지 않는다.
- 핏은 착용자의 몸에 대한 판단이 아니라 의복의 여유량, 어깨점, 몸통 간격, 밑단 위치 같은 의복 소유 관계로 표현한다.
- 첨부 이미지는 얼굴과 전반적 외형 연속성을 위한 참조일 뿐이다. 생체 동일성 확인이나 원본 의복의 증거로 사용하지 않는다.

## 1. 버튼다운 셔츠

운영 정의: 완전한 앞중심 단추 플래킷과 별개로, 좌우 포인트 칼라 끝이 각각 작은 단추를 통해 셔츠 몸판에 실제 고정된 셔츠다.

필수 관찰 요소:

1. 완전한 앞중심 단추 플래킷
2. 서로 구분되는 좌우 포인트 칼라 끝
3. 칼라 끝마다 하나씩 있는 두 작은 단추
4. 단추가 칼라 끝의 단춧구멍을 지나 몸판에 체결되는 관계
5. 단순 버튼업, 폴로 플래킷, 장식 스터드, 가려진 한쪽 칼라가 아님

핵심 후보: `button_down_poplin_shirt_tailored_trousers`, `button_down_collar_point_fastening`, `woven_poplin_crisp_fold_surface`.

## 2. 콜드숄더 톱

운영 정의: 네크라인은 목과 어깨 위쪽을 계속 지나고, 양쪽 어깨에 경계가 닫힌 창 형태의 컷아웃이 있으며, 그 아래 소매가 몸판에 계속 연결된 상의다.

필수 관찰 요소:

1. 양쪽 컷아웃 위를 지나는 연속 네크라인
2. 경계가 닫힌 두 어깨 창
3. 컷아웃 아래에서 이어지는 양쪽 소매
4. 찢어진 구멍이 아닌 마감된 가장자리와 패브릭 브리지
5. 오프숄더, 민소매, 원숄더가 아님

핵심 후보: `cold_shoulder_knit_top_midi_skirt`, `cold_shoulder_cutout_sleeve_bridge`, `rib_knit_stretch_recovery_surface`.

## 3. 랩 블라우스

운영 정의: 서로 추적 가능한 두 앞판이 사선으로 교차하고, 한 판이 다른 판 아래로 실제 이어지며, 이 겹침이 V 네크라인과 옆 여밈으로 하나의 기능적 폐쇄 구조를 만드는 블라우스다.

필수 관찰 요소:

1. 각각 추적 가능한 두 앞판 가장자리
2. 아래 판이 위 판 아래로 이어지는 실제 겹침 깊이
3. 교차 가장자리와 같은 경로를 이루는 랩 V 네크라인
4. 겹침을 유지하는 옆 타이, 단추 또는 고정선
5. 사선 프린트, 가짜 봉제선, 장식 리본, 스카프가 아님

핵심 후보: `wrap_front_blouse_straight_trousers`, `wrap_front_diagonal_overlap_tie`, `fluid_satin_luster_drape_surface`, `lightweight_crepe_matte_drape_surface`.

## 4. 점프수트

운영 정의: 상체 몸판이 허리와 가랑이까지 한 벌로 연속되고, 가랑이 아래에서 인심을 사이에 둔 두 바지통으로 분기되는 일체형 의류다. 긴 다리형은 점프수트, 짧은 다리형은 롬퍼·플레이수트 변형으로 구분한다.

필수 관찰 요소:

1. 상체에서 허리까지의 단일 의복 연속성
2. 허리에서 가랑이까지의 연속성
3. 인심이 분리하는 두 바지통
4. 두 긴 밑단 또는 두 짧은 밑단으로 읽히는 변형 길이
5. 드레스, 매칭 상의·바지, 보디수트 위 별도 바지가 아님

핵심 후보: `tailored_full_length_jumpsuit`, `jumpsuit_bodice_crotch_leg_continuity`, `tailored_jumpsuit_continuous_line`.

## 5. 큐롯 팬츠

운영 정의: 공통 허리밴드와 바지 밑위를 가지며, 보이는 가랑이·인심을 통해 두 개의 넓은 바지통으로 나뉘고, 두 밑단이 대체로 종아리 부근에서 끝나는 크롭트 와이드 팬츠다.

필수 관찰 요소:

1. 공통 허리밴드와 바지 밑위
2. 보이는 가랑이 또는 인심
3. 독립적으로 읽히는 두 넓은 바지통
4. 종아리 부근에서 끝나는 두 별도 밑단
5. 단일 미디스커트 판, 플리츠 그림자, 바닥 길이 팔라초가 아님

핵심 후보: `culotte_button_front_blouse`, `culotte_inseam_leg_separation`, `cropped_wide_leg_culotte_geometry`. 보조 혼동 후보로 `skort_outer_panel_inner_shorts`, `pleat_fold_ridge_valley_geometry`, `palazzo_full_length_wide_leg_geometry`를 분리했다.

## 공통 표현 축

- `wardrobe_style`: 품목 조합과 전체 코디
- `garment_detail`: 칼라·컷아웃·앞판·가랑이·인심 같은 국소 구조
- `silhouette_proportion`: 의복과 몸 랜드마크 사이의 길이·여유·분기 관계
- `surface_material`: 평직의 선명한 접힘, 립 니트 골, 새틴형 방향 광택, 크레이프형 무광 입자처럼 픽셀에서 관찰 가능한 표면 거동

## 근거와 적용 한계

- [ICOM Costume terminology](https://costume.mini.icom.museum/publications-2/terminology/): 유행 별칭을 그대로 상위 분류로 삼지 않고, 일반 품목에서 정밀 변형으로 내려가며 몸과의 관계로 기록하는 원칙을 채택했다. 박물관 분류 체계이므로 현대 리테일 별칭 전체를 정의하지는 않는다.
- [Fashionpedia](https://arxiv.org/abs/2004.12276): 품목·부품·세부 속성을 분리하고 위치가 보이는 속성으로 검증하는 방식을 채택했다. 데이터셋과 모델 자체도 국소화·세부 속성 혼동 오류가 있으므로 네이티브 크기 픽셀 검수를 생략하지 않는다.
- [ISO 8559-1:2017](https://committee.iso.org/standard/61686.html?browse=tc): 길이와 비례를 막연한 짧음·김이 아니라 허리·종아리·발목 같은 몸 랜드마크 관계로 기술하는 근거로 사용했다. 렌더에서 표준 치수나 적합성을 주장하지 않는다.
- [Cornell 3D Body Scanner glossary](https://www.bodyscan.human.cornell.edu/scene5b96.html): 착용 여유와 디자인 여유를 구분하고, 오버사이즈를 착용자의 몸 특성이 아닌 의복 실루엣 설계로 표현한다.

## 테스트 판정 경계

- 구조 데이터 검증, 후보팩 생성, 프롬프트 감사, 렌더 요청 감사, 실제 픽셀 검수는 서로 다른 증거층이다.
- 한 이미지에서 해당 프로필의 5개 게이트가 모두 확인되어야 PASS다. 일부만 보이면 FAIL이다.
- 생성 차단 또는 이미지 누락은 FAIL로 점수화하지 않고 UNSCORED로 기록한다.
- 최종 사용자 미감·유사성 판단은 자동 픽셀 판정과 분리해 `pending`으로 남긴다.
