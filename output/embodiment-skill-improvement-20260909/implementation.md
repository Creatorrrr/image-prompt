# 신체·동작 사전 검토 개선

`photo-prompt-image-generator`의 기본 작성 절차와 실행 감사에 신체·동작 검토를 추가했다. 프롬프트의 공간 관계를 모델이 검토하도록 하고, 코드는 검토 기록이 현재 프롬프트에 대응하는지 검사한다. 자동 관절 계산이나 해부학적 정확성 증명은 구현하지 않았다.

## 반영한 동작

1. 기본 프롬프트를 고정하기 전에 신체 소유권, 관절 연결과 도달, 지지와 균형, 접촉과 공간, 가림과 원근을 검토한다. 모순되거나 중요한 정보가 빠진 작성자 연출은 이때 수정한다.
2. 검토 결과는 사용자 요구와 분리한 `embodiment_review.json`에 남긴다. 후보 검색에는 이 기록을 넣지 않는다. 기본 v6 스킬 명령이 `--embodiment-review-json`을 전달한다.
3. 최종 합성에서 카메라·구도·옷·접촉 설명이 추가되면 전체 문장을 다시 검토한다. 검토 누락, 해결되지 않은 항목, 근거 문구 누락, 검토 이후 문장 변경은 감사를 통과하지 못한다.
4. 실제 생성 입력에도 검토한 문장을 그대로 사용하도록 연결한다. 생성 직전 긍정 문장을 추가하려면 합성 단계로 돌아가 다시 검토한다.
5. 이미지 생성이 요청된 경우에는 적용 가능한 항목을 최초 생성의 픽셀 검토에도 추가한다. 재시도 이력을 만들어 기존 수리 전용 검사를 억지로 적용하지 않는다.

특정 팔, 좌우, 각도, 의상, 차량을 공통 규칙으로 넣지 않았다. 요청한 비인간 신체나 의도적인 비현실성은 보존한다. 모든 자세를 단순화하거나 접촉을 없애거나 팔다리를 가려서 검사만 통과시키는 방식도 금지했다. 정물처럼 중요한 신체 동작이 없는 장면은 이유를 적고 비적용으로 처리할 수 있다.

## 검증

- 새 단위·파이프라인 테스트 20개 통과: 검토 버전 연결, 미해결 상태 차단, 사용자 의도 보존, 검색 격리, 실제 CLI 연결, 최종·실행 문장 변경, 출력 검토 항목 연결을 확인했다.
- 고정 전 자료 격리 검사, 스킬 구조 검사, 사전 검사 통과.
- 시각 프로필 인덱스 검사 통과: 프로필 502개, 정확 일치 용어 2,007개.
- 장면 표현 검사 112개 경로 모두 통과.
- 변경 전 관련 검사 55개 통과 기록은 기준선으로만 보관했다. 변경 후 전체 검사 통과로 계산하지 않는다.
- 전체 1,148개 회귀 검사는 기존 실패를 발견했고 높은 시스템 부하로 중단했다. 전체 완료나 전체 통과를 주장하지 않는다. 발견한 실패 13개 테스트는 변경 전 소스 복사본과 같은 현재 자료를 사용해 별도로 대조하여 모두 재현했다. 세부 항목으로는 하위 사례를 포함한 assertion 실패 15건과 오류 2건이다. `failure-comparison.json`에 대조 방법과 원본 기록을 남겼다.

테스트의 신체·픽셀 검토 기록은 합성한 검사 입력이다. 실제 이미지 판단이나 독립적인 프롬프트 작성 실험으로 계산하지 않는다. 원래 첨부 이미지와 이전 생성 이력은 수정하지 않았고, 새 이미지 생성도 실행하지 않았다. 따라서 실제 해부학적 오류 감소율은 아직 미검증이다.

## 적용 범위와 한계

새 기본 스킬 절차는 검토 파일을 요구한다. 저장된 과거 팩과 이 옵션을 사용하지 않는 직접 CLI 호환 호출은 기존 동작을 유지하며, 새 신체 검토를 받았다고 간주하지 않는다.

검토 상태를 모델이 잘못 판단하거나, 다시 검토하지 않고 해시만 갱신하면 코드는 그 의미상의 잘못을 알아낼 수 없다. 코드가 보장하는 것은 기록의 형식·연결·유효 상태와 근거 문구의 존재다. 올바른 검토가 이루어져도 이미지 생성 모델이 문장을 어길 수 있으므로 결과 픽셀 검토가 별도로 필요하다.

변경한 소스·문서·테스트는 11개 경로다. 기존 swimwear 자료·인덱스 변경과 다른 스킬의 삭제 상태는 이 개선에 포함하지 않았다. 정확한 변경은 `intervention.diff`, 파일 바이트는 `candidate-source-hashes.json`, 개선 판단은 `iteration.json`에 남겼다. 커밋과 푸시는 수행하지 않았다.
