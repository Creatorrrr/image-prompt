# 개화기 거리 이미지: 스킬 / 무스킬 비교

동일한 한국어 요청과 동일한 첨부 초상 사진(SHA-256 `437ae5cc9e99efc573060eb248ac21873f5ff81c36347e10efc5fcb6234d6a0e`)을 사용했다. 두 조건 모두 이미지 생성 1회, 결과 1024×1536이다. 스킬 이미지 SHA-256은 `b45a8b5778b0e9a2bf36d7974444388585071514d734e7a2e25b30106c343c3d`, 무스킬 이미지 SHA-256은 `250aa4e4e249d23b63c35a32311ba8502ee7e1c3127e449d698ebad102adef43`이다. 무스킬 조건은 이전 결과를 보지 않는 별도 서브에이전트가 독립 입력 폴더에서 원문 요청과 초상 사진만으로 생성했다.

## 판단

이번 한 쌍에서는 스킬의 뚜렷한 우위를 확인하지 못했다. 스킬 결과는 던진 사람의 손→공중 햄버거→구걸하는 손의 연결이 더 명확하다. 무스킬 결과는 햄버거의 먹다 남은 부분과 비대칭적인 지나가는 사람 시점이 조금 더 잘 보인다. 둘 다 불쌍한 표정과 급히 찍은 사진의 느낌은 요청보다 약하다.

직전 스킬 실행에서 실제 채택된 후보팩 항목은 그림자·접지 관련 조명 요소 1건이다. 이 비교는 스킬 전체 작성 과정과 직접 생성의 차이를 보여주며, 후보팩만의 효과를 따로 측정하지 않는다.

생성 자체가 비결정적이고 각 조건에서 한 장씩만 만들었다. 두 결과의 프롬프트 길이와 작성 방식도 달라 이 결과만으로 스킬 전체나 후보팩의 인과 효과를 판단할 수 없다. 첨부 사진과의 유사성은 보이는 외형 비교이며 동일인 신원 확인이 아니다. 개화기풍 배경의 사료적 정확성도 검증하지 않았다.
